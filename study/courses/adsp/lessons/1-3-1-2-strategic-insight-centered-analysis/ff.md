## 1. 일차원적 분석의 한계

### 1.1 일차원적 분석의 의미

**일차원적 분석의 한계**에서 일차원적 분석은 한 부서·한 지표·한 시점·한 문제만 좁게 최적화하는 분석을 뜻한다. 현황을 파악하고 운영 효율을 높이는 데 유용하지만, 부서 간 상충관계와 고객의 전체 경험, 장기 전략을 놓칠 수 있다.

대표 모습은 다음과 같다.

- 과거 실적을 정형 보고서로 반복 집계한다.
- 영업·마케팅·생산·재무가 각자의 지표만 최적화한다.
- 이미 알려진 문제의 비용 절감에만 분석을 쓴다.
- 데이터와 결과가 업무 프로세스·의사결정에 연결되지 않는다.
- 정확도·보고서 수를 성과로 보고 실제 행동 효과는 측정하지 않는다.

일차원적이라는 표현이 단순 분석은 쓸모없다는 뜻은 아니다. 기본 집계와 기능 최적화는 전략 분석의 토대다. 문제는 국지적 개선을 전사적 가치나 지속적 경쟁우위와 같은 것으로 착각하는 데 있다.

### 1.2 부문 최적화의 함정

| 부서 목표 | 단독 최적화 행동 | 전사적 부작용 가능성 |
|---|---|---|
| 영업 매출 | 큰 할인으로 판매 확대 | 이익 감소·가격 신뢰 훼손 |
| 생산 가동률 | 대량 생산·긴 배치 | 재고·품절 품목·변화 대응 악화 |
| 물류 비용 | 배송 빈도 축소 | 고객 대기·반품·이탈 증가 |
| 상담 처리시간 | 빠른 종료 | 해결률 하락·재문의 증가 |
| 위험 손실 | 승인 기준 강화 | 우량 신규 고객·성장 기회 상실 |

각 지표는 합리적이어도 연결 결과는 나쁠 수 있다. 고객 생애가치, 주문–생산–배송 전체 비용, 위험 대비 수익처럼 경계를 넘는 지표가 필요하다.

### 1.3 사후 설명과 예측의 한계

과거 보고는 무엇이 일어났는지 알려 주지만 변화 전에 행동할 시간을 주지 못할 수 있다. 예측을 추가한다고 자동으로 전략적이지도 않다. 예측 결과를 누가 언제 어떤 선택에 사용할지, 개입으로 결과가 바뀌는지 정해야 한다.

이탈 가능성이 높은 고객을 정확히 찾았어도 이미 마음을 정해 어떤 혜택에도 반응하지 않는다면 예측은 실행가치가 낮다. 이탈 위험과 **유지 활동에 반응할 가능성**을 구분해야 한다.

### 1.4 데이터·조직 사일로

부서마다 고객·상품·매출 정의가 다르고 성과평가가 충돌하면 분석도 분리된다. 기술적으로 데이터를 한 저장소에 모아도 공동 의사결정과 책임이 없으면 사일로는 남는다.

전략 인사이트 분석은 경계 전체의 데이터 계보와 가치 흐름을 본다. 그러나 모든 데이터를 한 번에 통합하려고 멈추기보다 핵심 의사결정에 필요한 정의·연결부터 합의한다.

### 1.5 분석 깊이와 전략 폭의 균형

너무 넓은 전략 질문은 실행할 수 없고, 너무 좁은 기술 질문은 가치와 단절된다. 다음처럼 연결한다.

```text
전략 목표: 신뢰할 수 있는 당일 배송 경험
  ↓
가치사슬: 주문 약속–재고–피킹–배차–고객 통지
  ↓
의사결정: 약속시간 산정, 재고 배치, 지연 개입
  ↓
분석 과제: 구간별 지연 원인, 도착 예측, 개입 효과
```

각 과제는 좁게 검증할 수 있지만 같은 전략 목표와 균형지표를 공유한다.

## 2. 산업별 분석 애플리케이션

### 2.1 애플리케이션을 보는 방법

**산업별 분석 애플리케이션**은 산업의 고객가치·규제·운영구조·데이터 생성 방식에 따라 자주 나타나는 활용 유형이다. 애플리케이션 이름을 외우는 것보다 “어떤 의사결정을 어떤 데이터로 개선하는가”를 이해한다.

```text
산업 구조와 핵심 가치
  → 반복되는 의사결정·위험
  → 이용 가능한 데이터
  → 분석 애플리케이션
  → 업무 행동과 성과·통제
```

다른 산업의 방법을 가져올 수 있지만, 데이터 의미와 오류 비용·규제·현장 제약을 다시 검증해야 한다.

### 2.2 금융·보험

주요 의사결정은 신용·가격, 부정 거래, 고객관계, 자산·유동성·위험 관리다.

- 신용 위험과 상환 가능성 평가
- 이상 거래·보험 부정 탐지와 조사 우선순위
- 고객 이탈·다음 필요 예측과 상담 지원
- 포트폴리오 위험·손익 시나리오 분석
- 심사·상담 프로세스의 병목·품질 분석

오탐으로 정상 거래를 막거나 특정 집단의 금융 접근을 제한할 수 있으므로 전체 정확도뿐 아니라 오류 비용, 설명·이의제기, 규제와 집단별 결과를 본다. 탐지 점수는 처벌 확정이 아니라 조사 우선순위로 사용하는 등 적용 단계를 설계한다.

### 2.3 유통·전자상거래

고객 발견–구매–배송–재구매의 전체 경험과 상품·재고 흐름이 핵심이다.

- 수요 예측과 상품·점포별 재고 배치
- 추천·검색·개인화와 상품 조합
- 가격·프로모션의 증분 효과 분석
- 고객 세분화·생애가치·이탈 관리
- 배송 약속·반품·상담 원인 분석

추천 클릭률만 최적화하면 다양성과 장기 만족이 낮아질 수 있다. 프로모션 매출 증가는 원래 구매할 고객의 할인 비용을 포함할 수 있다. 재고 최적화도 품절 비용, 폐기, 납기, 공급 위험을 함께 본다.

### 2.4 제조·에너지

설비·공정·품질·공급망처럼 물리적 제약과 안전이 중요하다.

- 설비 상태 감시와 예방·예지 정비
- 공정 조건과 품질·수율 관계 분석
- 생산 계획·작업 순서·에너지 최적화
- 원자재·공급업체 품질과 납기 위험
- 디지털 품질 추적과 원인 분석

센서 이상을 실제 설비 이상과 구분하고 시간 동기화·정비 이력을 연결한다. 예측이 작업 안전 규칙을 대신하지 않으며, 오경보로 인한 불필요 정지와 놓침으로 인한 사고·불량 비용을 비교한다.

### 2.5 통신·플랫폼 서비스

- 망 품질·용량·장애 예측과 자원 배치
- 고객 이탈·요금제·서비스 경험 분석
- 비정상 사용·부정 가입 탐지
- 콘텐츠·관계망·추천과 참여 분석
- 상담·현장 출동·장애 복구 최적화

평균 품질이 좋아도 특정 지역·단말·시간대에서 문제가 집중될 수 있다. 참여시간을 늘리는 목표는 과도한 사용·유해 콘텐츠·사회적 비용과 충돌할 수 있으므로 장기 만족·안전 지표를 둔다.

### 2.6 의료·공공

- 환자 위험 선별과 진료·병상 자원 배치
- 치료·정책 효과와 서비스 격차 분석
- 감염·재난·교통 수요와 대응 지원
- 복지 대상 발굴과 부정 수급 조사 우선순위
- 민원·공공시설·환경 자원 배치

건강·복지·치안 분석은 오류가 권리와 안전에 직접 영향을 준다. 데이터 대표성, 설명, 인간 전문가 검토, 이의제기, 사생활을 강화한다. 과거 서비스 이용이 적다는 이유로 필요가 낮다고 해석하면 접근이 어려웠던 집단을 다시 배제할 수 있다.

### 2.7 공통 패턴과 산업 특수성

여러 산업에서 고객 세분화·수요 예측·이상 탐지·최적화가 반복된다. 그러나 목표와 오류 비용은 다르다.

| 공통 분석 | 유통에서의 의미 | 의료에서의 의미 | 핵심 차이 |
|---|---|---|---|
| 수요 예측 | 재고·인력 배치 | 병상·의료인력 배치 | 안전·접근성과 품절 비용 |
| 이상 탐지 | 부정 결제 후보 | 위험 징후 환자 | 오탐·미탐의 영향과 검토 |
| 추천 | 상품·콘텐츠 발견 | 진료 의사결정 지원 | 전문가 책임·설명·근거 수준 |
| 세분화 | 마케팅·경험 설계 | 집단별 건강 정책 | 낙인·차별·보호 필요 |

업계 성공 사례의 방법보다 가치 구조·데이터 조건·운영 변화가 우리 조직과 같은지 확인한다.

## 3. 전략적 분석 과제의 선택

### 3.1 전략에서 과제로 내려온다

**전략적 분석 과제의 선택**은 보유 데이터나 유행 기술에서 시작하지 않고 조직의 핵심 가치·목표와 중요한 의사결정에서 분석 기회를 찾는 것이다.

1. 전략 목표와 고객·사회 가치, 위험 한도를 확인한다.
2. 가치사슬과 핵심 프로세스의 의사결정을 그린다.
3. 성과 격차·불확실성·병목과 분석 질문을 찾는다.
4. 데이터·기술·조직 실행 가능성과 대안을 확인한다.
5. 가치·실행·위험·학습·재사용 기준으로 비교한다.
6. 포트폴리오와 단계적 검증·중단 조건을 정한다.

현업의 반복 문제에서 상향식으로 기회를 찾을 수도 있고 전략 목표에서 하향식으로 질문을 도출할 수도 있다. 어느 한쪽만 고집하지 않고 연결한다. 구체적인 분석 과제 발굴 방법론은 후속 과목 범위에서 더 깊게 다룬다.

### 3.2 평가 기준

| 축 | 평가 질문 |
|---|---|
| 전략 가치 | 핵심 목표·고객가치·경쟁우위에 얼마나 기여하는가? |
| 실행 가능성 | 데이터·기술·인력·시간·의사결정 권한이 있는가? |
| 행동 가능성 | 결과를 누가 어떤 프로세스에서 사용할 수 있는가? |
| 위험 | 사생활·공정성·안전·규제·평판 영향은 통제 가능한가? |
| 학습·재사용 | 공통 데이터·역량·다른 과제에 기반을 만드는가? |
| 측정 가능성 | 현재 기준과 실제 증분 효과를 검증할 수 있는가? |

예상 가치가 높아도 행동 권한·데이터가 없으면 단계적으로 준비해야 한다. 쉽게 구현된다고 전략적으로 중요한 것은 아니다. “가치 높음/실행 낮음”은 탐색·기반 과제로, “가치 낮음/실행 높음”은 자동 우선이 아니라 빠른 가치와 자원 기회비용을 검토한다.

### 3.3 과제 포트폴리오

- 빠른 성과: 가치와 실행성이 높고 짧게 검증 가능한 과제
- 핵심 전략: 가치가 크지만 데이터·조직 변화가 필요한 과제
- 기반 역량: 공통 데이터 품질·실험·운영을 만드는 과제
- 탐색: 미래 기회와 가정을 작은 비용으로 검증하는 과제
- 의무·위험: 규제·안전·품질상 반드시 수행할 과제

모든 자원을 빠른 성과에 쓰면 구조적 역량이 남지 않고, 거대한 전략 과제만 하면 가치를 늦게 증명한다. 포트폴리오의 의존성과 공통 기반을 본다.

### 3.4 과제 정의서

선택된 과제에는 다음이 있어야 한다.

```text
전략 목표·핵심 가치
업무 문제와 현재 기준
의사결정 주체·행동·사용 시점
분석 질문과 결과 형태
필요 데이터·품질·권한
가치·위험·균형 지표
가정·제약·선행 과제
시범 범위·중단·확장 조건
책임자·운영·학습 계획
```

“이탈 예측 모델 개발”은 기술 작업에 가깝다. “첫 90일 이탈을 줄이기 위해 고객지원 팀이 연락 대상을 매일 선택하고, 무작위 비교로 증분 유지율과 불만·비용을 평가한다”가 더 실행 가능한 과제 정의다.

## 4. 종합 사례: 제조 서비스 전환

장비 제조사가 일회성 판매에서 가동시간 보장 서비스로 전략을 바꾸려 한다. 각 부서는 판매량, 생산 가동률, 부품 재고만 분석해 왔다. 이는 유용하지만 고객의 핵심 가치인 “장비가 멈추지 않는 것”과 단절된 일차원 분석이다.

산업 애플리케이션 후보는 고장 예측, 정비 우선순위, 부품 수요, 원격 지원, 계약 가격이다. 모든 것을 동시에 하지 않고 고객 손실과 조직 행동을 본다. 고장 예측 정확도가 높아도 정비팀·부품이 제때 움직일 수 없다면 가치가 없다.

첫 과제는 “향후 7일 내 고장 확률”보다 “정비 계획자가 다음 주 점검 순서를 조정해 비계획 정지를 줄이는 의사결정 지원”으로 정의한다. 설비 중요도·예측·부품·작업자 가용성을 연결하고, 오경보 정비비와 놓침 손실·안전을 균형지표로 둔다. 시범 결과가 좋으면 서비스 계약과 제품 설계 피드백으로 확장한다.

## 5. 전략 과제 판단 절차

1. 산업의 가치 창출 방식과 우리 조직의 전략·차별화를 구분한다.
2. 부서 지표가 전사 고객가치와 충돌하는 지점을 찾는다.
3. 산업별 애플리케이션을 아이디어로 보되 데이터·오류·규제를 재해석한다.
4. 분석 결과를 사용할 의사결정·행동·책임자를 먼저 확인한다.
5. 전략 가치·실행 가능성·위험·학습·측정 가능성으로 비교한다.
6. 빠른 성과·핵심 전략·기반·탐색·의무 과제의 균형을 잡는다.
7. 현재 기준·시범·중단·확장 조건을 가진 과제 정의서를 만든다.
8. 실제 효과와 부작용을 관찰해 포트폴리오를 재조정한다.

## 6. 시험에서 자주 틀리는 판단

### 함정 1. 일차원적 분석은 항상 쓸모없다

기본 운영 개선에 유용하지만 전략·부서 경계를 넘는 가치와 연결되지 않을 때 한계가 있다.

### 함정 2. 예측 분석은 모두 전략적이다

행동 주체·개입·핵심 가치와 연결되지 않으면 미래 숫자를 보여 주는 데 그칠 수 있다.

### 함정 3. 산업의 대표 애플리케이션은 그대로 복제하면 된다

데이터 정의·오류 비용·규제·업무 흐름이 달라 재검증해야 한다.

### 함정 4. 전체 정확도가 높으면 어떤 산업에서도 좋은 모형이다

금융·의료·안전에서는 집단별 오류와 오탐·미탐 비용, 설명·검토가 중요하다.

### 함정 5. 구현이 쉬운 과제가 언제나 우선이다

전략 가치와 자원 기회비용이 낮으면 쉬워도 우선순위가 낮을 수 있다.

### 함정 6. 예상 가치가 큰 과제는 준비 없이 즉시 전체 적용한다

데이터·행동·위험 가정을 작은 시범과 단계 조건으로 검증한다.

### 함정 7. 과제 포트폴리오는 단기 수익 과제만 모은다

핵심 전략·공통 기반·탐색·의무 위험 과제를 균형 있게 관리한다.

## 9. 정답과 해설

1. **2** — 부서 목표는 합리적이어도 고객 여정과 다른 부서 비용을 포함하면 전체 가치가 악화될 수 있다.
2. **1** — 처리시간이라는 한 지표를 최적화해 해결률·고객경험을 훼손한 부문 최적화 사례다.
3. **1** — 예측 대상이 개입에 반응하지 않거나 실행 주체·권한이 없으면 정확한 점수도 행동 가치가 낮다.
4. **2** — 애플리케이션 이름은 공통이어도 데이터 의미·오류·규제·현장 행동은 달라진다.
5. **1** — 단순 매출은 할인 없이는 구매하지 않았을 증분과 원래 구매할 고객에게 준 비용을 구분하지 못한다.
6. **2** — 건강·안전에 직접 영향이 있으므로 집단별 오류와 전문가 책임·설명이 중요하다.
7. **4** — 유행 기술은 전략 가치와 실행 효과를 보장하지 않는다.
8. **3** — 선행 데이터·조직 역량을 만들고 작은 실험으로 가치와 위험을 확인한 뒤 확장한다.
9. **3** — 의사결정 주체·행동·효과·비용이 명시되어 실제 업무와 검증에 연결된다.
10. **2** — 빠른 성과만 추구하거나 거대한 전략 과제만 추진하는 편향을 막고 공통 기반·의존성을 관리한다.

## 10. 핵심 요약

- **일차원적 분석의 한계**는 부서·지표·사후 보고의 국지적 최적화가 전사 고객가치와 장기 전략을 놓치는 데 있다.
- 예측도 행동 주체·개입 효과·업무 프로세스와 연결되지 않으면 전략 분석이 아니다.
- **산업별 분석 애플리케이션**은 공통 패턴이 있어도 산업의 가치·데이터·오류 비용·규제에 맞게 재설계해야 한다.
- 금융·유통·제조·통신·의료·공공은 같은 기법도 적용 목적과 통제 강도가 다르다.
- **전략적 분석 과제의 선택**은 핵심 가치·의사결정에서 시작해 가치·실행·위험·학습·측정 가능성을 비교한다.
- 과제 정의서와 균형 포트폴리오, 작은 시범·중단·확장 조건으로 실제 효과를 학습해야 한다.
