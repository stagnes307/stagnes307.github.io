# 2-1-1-2. 분석 대상과 방법의 유형

> **학습 범위**: 이 레슨은 ADsP `데이터분석 기획 > 데이터분석 기획의 이해 > 분석 기획 방향성 도출` 중 **`최적화와 통찰`**, **`솔루션과 발견`**, **`분석 유형별 접근 방식`**을 다룬다. 분석 주제와 분석 방법이 알려졌는지를 구분하고, 네 조합에 맞는 기획·검증·산출물과 전환 경로를 판단하는 것이 목표다.

네 유형은 산업이나 알고리즘을 분류하는 표가 아니다. 같은 고객 이탈 문제도 조직에 검증된 점수화 방식이 있으면 최적화형이 될 수 있고, 새로운 시장에서 이탈의 정의조차 불명확하면 발견형이 될 수 있다. 시험에서는 축을 뒤집거나 “알려짐”을 데이터 보유 여부와 혼동하는 선택지가 자주 나온다.

---

## 1. 두 축으로 분석 상황을 진단한다

### 1.1 분석 주제의 알려짐

분석 주제는 무엇을 설명·예측·개선할지 구체적으로 정의되었는가를 뜻한다. 단순히 업무 현상을 말할 수 있다는 것으로 충분하지 않다. 대상, 기준 시점, 결과 변수 또는 판단 기준, 의사결정과 성공 조건이 합의되어야 “알려진 주제”에 가깝다.

- 알려진 주제: “출고 시점에 다음 24시간 내 배송 지연 여부를 예측한다.”
- 불명확한 주제: “물류 데이터에서 새로운 개선 기회를 찾아라.”

### 1.2 분석 방법의 알려짐

분석 방법은 해당 질문과 데이터에 적용할 절차가 조직에서 충분히 이해·검증되었는가를 뜻한다. 알고리즘 이름을 아는 것과 다르다. 필요한 데이터, 전처리, 기준모델, 검증 방식, 운영 적용 조건이 정리되어야 한다.

- 알려진 방법: 기존 수요예측 절차와 검증 기준을 새 지점에 반복 적용
- 불명확한 방법: 비정형 상담 기록에서 원인을 찾을 기법과 평가 기준을 비교해야 함

### 1.3 네 조합

| 분석 주제 | 분석 방법 | 유형 | 핵심 질문 |
|---|---|---|---|
| 알려짐 | 알려짐 | 최적화 | 더 정확·빠르고 효율적으로 만들 수 있는가 |
| 불명확 | 알려짐 | 통찰 | 익숙한 방법으로 어떤 의미 있는 주제를 볼 수 있는가 |
| 알려짐 | 불명확 | 솔루션 | 명확한 문제에 어떤 해결 방법이 적합한가 |
| 불명확 | 불명확 | 발견 | 어떤 문제와 방법이 가치 있는지 어떻게 탐색할까 |

외울 때는 행·열 위치보다 “무엇”과 “어떻게”가 알려졌는지 매번 문장으로 판정한다.

## 2. 최적화와 통찰

## 2.1 최적화: 주제와 방법이 모두 알려짐

**`최적화와 통찰`** 중 최적화는 분석 주제와 방법이 모두 알려진 상태에서 성능, 비용, 속도, 안정성 또는 업무 효과를 개선하는 접근이다.

예를 들어 카드 이상거래 탐지 대상과 기존 규칙·모델·검증 절차가 확립되어 있다면 다음을 개선할 수 있다.

- 오탐을 줄이면서 주요 사기를 놓치지 않는 임계값 조정
- 특징 계산 시간을 줄여 실시간 응답 기준 충족
- 오래된 데이터로 인한 성능 저하 탐지
- 검토 인력 한도에 맞춘 경보 우선순위 개선

최적화는 기존 방식을 무조건 유지하는 것이 아니다. 비교 기준이 명확하므로 새 방법도 후보가 될 수 있다. 다만 개선 전 기준선, 동일한 검증 데이터, 비용·제약과 통계적·업무적 유의성을 확인해야 한다.

```text
기준 모델 성능과 운영비용 측정
        ↓
개선 가설 한정
        ↓
동일 조건 후보 비교
        ↓
업무 효과·안전 제약 확인
        ↓
점진 적용 또는 원복
```

최적화의 함정은 보이는 지표 하나만 높이는 것이다. 정확도를 높이려다 처리시간이 업무 기준을 넘거나, 평균 비용을 줄이면서 특정 고객 집단 오류가 커질 수 있다.

## 2.2 통찰: 방법은 알려졌고 주제가 불명확

통찰은 보유한 분석 방법이나 관점은 있지만 무엇이 중요한 분석 주제인지 아직 명확하지 않은 상태다. 조직은 탐색적 시각화, 세분화, 연관 분석, 프로세스 분석 등 익숙한 방법으로 데이터의 패턴을 살피고 새로운 질문을 구체화한다.

소매 조직이 고객 세분화 절차를 갖고 있지만 어떤 마케팅 문제가 핵심인지 모른다면 구매 빈도·최근성·금액 등으로 군집을 살피고, “신규 고가치 고객의 두 번째 구매 지연” 같은 주제를 도출할 수 있다.

통찰형 접근에서는 다음을 관리한다.

1. 탐색할 데이터와 기간을 정한다.
2. 익숙한 방법이 만들 수 있는 왜곡과 한계를 적는다.
3. 우연한 패턴을 검증할 별도 자료나 후속 가설을 둔다.
4. 업무 담당자가 해석 가능한 형태로 패턴을 설명한다.
5. 발견한 주제를 과제 후보로 전환할 가치·실행 조건을 평가한다.

방법이 알려졌다고 결과의 의미까지 보장되는 것은 아니다. 군집 번호는 자연스러운 고객 유형의 진실이 아니라 선택한 변수·거리·군집 수에 따른 결과다.

## 3. 솔루션과 발견

## 3.1 솔루션: 주제는 알려졌고 방법이 불명확

**`솔루션과 발견`** 중 솔루션은 해결할 문제가 분명하지만 적절한 분석 방법이 정해지지 않은 상태다. 여러 방법 후보를 설계·실험해 요구를 만족하는 해결안을 찾는다.

예를 들어 “설비 고장을 최소 12시간 전에 경고하되 하루 허용 오탐은 3건 이하”라는 주제는 명확하다. 그러나 규칙, 생존분석, 분류모델, 이상탐지 중 무엇이 적합한지는 데이터와 운영 조건을 검증해야 한다.

솔루션형 절차는 다음과 같다.

1. 문제 정의와 성능·운영 제약을 고정한다.
2. 단순 규칙·현행 방식 같은 기준선을 만든다.
3. 데이터 구조와 라벨 품질에 맞는 후보 방법을 선정한다.
4. 동일한 분할·지표·비용 조건에서 비교한다.
5. 설명성, 처리시간, 유지보수와 배포 가능성을 함께 평가한다.
6. 선택 근거와 탈락 이유를 기록한다.

가장 복잡한 방법이 솔루션인 것은 아니다. 현장 센서 교체나 점검 프로세스 개선이 모델보다 효과적일 수 있다. 분석 방법과 비분석적 해결을 함께 비교한다.

## 3.2 발견: 주제와 방법이 모두 불명확

발견은 무엇을 분석할지와 어떻게 분석할지가 모두 열려 있는 상태다. 신사업 데이터 탐색, 새로운 위험 신호 발굴처럼 높은 불확실성 아래 학습하는 접근이다.

발견형은 무계획 자유 연구가 아니다. 다음 경계를 둔다.

- 탐색 목적과 조직 전략의 연결
- 접근 가능한 데이터·윤리·법적 범위
- 탐색 기간·예산·인력
- 유망한 신호를 판단할 기준
- 후속 검증으로 넘어갈 관문
- 가치가 없을 때 중단·기록할 기준

```text
넓은 기회 영역
  → 작은 데이터 탐색
  → 후보 패턴·질문 생성
  → 업무 가치·재현성 검토
  → 주제 또는 방법 구체화
  → 통찰형/솔루션형/최적화형 과제로 전환
```

탐색 데이터에서 흥미로운 패턴을 발견한 뒤 같은 데이터로 효과를 확정하면 선택 편향이 생긴다. 별도 데이터·기간·현장 실험으로 재검증한다.

## 4. 분석 유형별 접근 방식

**`분석 유형별 접근 방식`**은 유형마다 기획의 초점, 산출물, 실패 위험을 다르게 두는 것이다.

| 유형 | 초기 초점 | 대표 산출물 | 주요 위험 | 다음 전환 |
|---|---|---|---|---|
| 최적화 | 기준선과 개선 목표 | 비교시험, 개선안 | 한 지표 과최적화 | 새 문제 발견 시 통찰 |
| 통찰 | 탐색 범위와 해석 | 패턴, 가설, 과제 후보 | 우연·자의적 해석 | 주제 확정 후 최적화/솔루션 |
| 솔루션 | 문제·제약과 후보 비교 | 방법 비교, 선택 근거 | 최신 기법 선호 | 방법 검증 후 최적화 |
| 발견 | 학습 경계와 관문 | 기회 영역, 탐색 근거 | 무제한 탐색·선택 편향 | 주제/방법 구체화 |

### 4.1 데이터 계획

최적화는 기존 데이터 흐름의 안정성과 비교 가능성이 중요하다. 통찰은 넓은 변수와 맥락 데이터가 유용하지만 사후 해석 위험을 관리한다. 솔루션은 목표 라벨·검증 설계와 방법별 요구 데이터가 중요하다. 발견은 데이터 카탈로그와 작은 탐색 표본으로 가능성을 확인하되 전체 데이터로 성급히 확장하지 않는다.

### 4.2 평가 계획

최적화는 기준선 대비 개선, 솔루션은 후보 간 공정 비교, 통찰은 패턴의 안정성과 업무 해석, 발견은 학습 가치와 후속 검증 가능성을 본다. 모든 유형에서 개인정보·편향·안전·운영 비용은 별도 제약이다.

### 4.3 이해관계자 참여

최적화에는 현행 프로세스 운영자가 필요하다. 통찰에는 도메인 전문가의 해석이 중요하다. 솔루션에는 분석·기술 전문가와 결과 사용자가 함께 후보를 평가한다. 발견에는 전략 담당자와 데이터 소유자가 탐색 경계와 가치 기준을 승인해야 한다.

## 5. 유형 판정 절차

### 단계 1: 분석 주제를 문장으로 쓴다

대상, 기준 시점, 원하는 결과, 사용할 행동과 성공 기준을 적는다. 빠진 요소가 많으면 주제가 불명확할 가능성이 높다.

### 단계 2: 방법의 검증 근거를 확인한다

비슷한 데이터·목표에서 사용한 절차, 기준모델, 성능·운영 결과가 있는지 본다. 제품 도입 자료나 논문 존재만으로 조직에 알려진 방법이라고 단정하지 않는다.

### 단계 3: 네 유형에 임시 배치한다

판정 근거와 남은 가정을 함께 기록한다. 이 표는 고정 라벨이 아니라 현재 불확실성을 보여 주는 진단 도구다.

### 단계 4: 유형에 맞는 최소 다음 행동을 고른다

- 최적화: 기준선 측정과 개선 가설 시험
- 통찰: 제한된 탐색과 가설 생성
- 솔루션: 후보 방법·비분석 대안 비교
- 발견: 기회 영역과 탐색 관문 설정

### 단계 5: 검토 시점에 재분류한다

방법이 검증되거나 주제가 명확해지면 유형이 이동한다. 유형 이동은 실패가 아니라 불확실성이 줄었다는 증거다.

### 유형별 전환 신호

유형을 고정 이름으로 관리하기보다 다음 신호를 검토한다.

| 현재 유형 | 관찰 신호 | 다음 판단 |
|---|---|---|
| 최적화 | 개선 폭이 포화되고 새로운 오류 집단이 발견됨 | 새 주제의 통찰 탐색 |
| 통찰 | 반복되는 패턴과 사용할 의사결정이 합의됨 | 주제 확정, 방법 검증 여부 재판정 |
| 솔루션 | 한 방법이 여러 기간·집단에서 운영 기준 충족 | 최적화·운영 개선으로 이동 |
| 발견 | 가치 있는 질문은 생겼으나 방법 후보가 없음 | 솔루션형 비교 과제로 전환 |
| 발견 | 방법의 가능성은 보이나 업무 질문이 모호함 | 통찰형 도메인 해석 강화 |

전환할 때 최초 탐색 자료와 검증 자료를 구분하고, 새 유형에 맞춰 성공 기준과 책임자를 다시 승인한다. 발견형에서 많은 후보 중 하나를 고른 뒤 동일 자료의 높은 성능만 제시하면 선택 편향이 남는다. 솔루션형에서 방법이 확립됐더라도 입력 분포·업무 정책이 변하면 다시 방법의 알려짐을 검토해야 한다. 따라서 유형은 프로젝트 명칭이 아니라 특정 시점의 증거 상태다.

## 6. 통합 사례: 배송 지연 개선

같은 물류 조직에서도 질문에 따라 유형이 다르다.

1. **최적화**: 기존 지연 예측모델의 오탐을 10% 줄인다. 주제·절차가 이미 검증됐다.
2. **통찰**: 확립된 프로세스 마이닝으로 배송 흐름을 탐색해 병목 구간을 찾는다. 방법은 알지만 핵심 문제가 열려 있다.
3. **솔루션**: 지연 12시간 전 경고라는 목표에 규칙·분류·생존모형 중 적합한 방식을 비교한다.
4. **발견**: 새로 수집한 차량·날씨·고객상담 데이터에서 가치 있는 물류 기회를 탐색한다.

발견형 탐색에서 “특정 날씨와 지연이 함께 증가한다”는 패턴을 찾으면 주제가 구체화된다. 이후 원인과 예측 가능성을 검증하는 솔루션형 과제로 옮기고, 방법이 확립되면 최적화형 운영 개선으로 발전할 수 있다.

## 7. 판단 체크리스트

- [ ] 주제의 대상·시점·결과·행동·성공 기준을 확인했다.
- [ ] 방법이 해당 데이터와 제약에서 검증됐다는 근거가 있다.
- [ ] 알려짐 여부를 데이터 보유나 담당자 확신과 혼동하지 않았다.
- [ ] 유형에 맞는 기준선·탐색 범위·후보 비교·관문을 정했다.
- [ ] 분석 외 해결 방법도 후보에 포함했다.
- [ ] 탐색 데이터와 검증 데이터를 구분했다.
- [ ] 모델 지표와 업무 가치·운영 제약을 함께 평가한다.
- [ ] 이해관계자와 데이터 소유자의 역할이 정해졌다.
- [ ] 유형 전환 조건과 다음 검토 시점이 있다.
- [ ] 선택·탈락·중단 근거를 재현 가능하게 기록한다.

## 8. 자주 틀리는 시험 함정

1. 최적화를 주제만 알려지고 방법은 모르는 유형으로 바꿔 외운다.
2. 통찰을 주제는 알려지고 방법이 모르는 경우로 혼동한다.
3. 솔루션은 주제와 방법이 모두 알려진 경우라고 판단한다.
4. 발견형에는 일정·범위·중단 기준이 필요 없다고 본다.
5. 분석 방법을 “알고리즘 이름을 들어 본 상태”로 판정한다.
6. 네 유형을 조직이나 산업에 고정된 속성으로 본다.
7. 유형이 중간에 바뀌면 최초 기획 실패라고 생각한다.
8. 통찰형 패턴을 별도 검증 없이 원인으로 확정한다.
9. 솔루션형에서 복잡한 모델을 단순 기준선보다 우선한다.
10. 최적화에서 기존 지표 하나만 개선하고 업무 부작용을 보지 않는다.

## 9. 확인 문제

### 문제 1

### 문제 2

분석 방법을 알고 있다는 것과 알고리즘 이름을 안다는 것의 차이는 무엇인가?

### 문제 3

### 문제 4

통찰 유형에서 우연한 패턴을 지식으로 오인하지 않기 위한 조치는 무엇인가?

### 문제 5

솔루션 유형에서 단순 기준선과 비분석적 대안을 함께 비교해야 하는 이유는 무엇인가?

### 문제 6

발견 유형에 반드시 필요한 관리 경계를 네 가지 쓰시오.

### 문제 7

분석 유형이 프로젝트 도중 바뀔 수 있는 이유를 설명하시오.

### 문제 8

배송 지연 사례에서 방법은 알려졌지만 주제가 불명확한 접근의 예를 쓰시오.

### 문제 9

분석 유형을 판정하고 다음 행동을 선택하는 절차를 요약하시오.

## 10. 정답과 해설

### 문제 1 정답과 해설

분석 대상, 기준 시점, 원하는 결과, 결과를 사용할 의사결정·행동과 성공 조건이 구체적으로 합의되어야 한다.

### 문제 2 정답과 해설

알고리즘 이름은 후보 지식일 뿐이다. 알려진 방법은 필요한 데이터·전처리·기준선·검증·운영 적용이 비슷한 문제에서 이해되고 검증된 절차다.

### 문제 3 정답과 해설

최적화는 주제와 방법이 모두 알려진 상태다. 현재 기준선을 동일 조건에서 측정하고 비용·안전 제약을 지키며 성능·효율·업무 효과를 개선한다.

### 문제 4 정답과 해설

탐색 범위와 선택 과정을 기록하고, 도메인 전문가가 해석하며, 별도 기간·표본이나 후속 가설 검정·현장 실험으로 재현성을 확인한다.

### 문제 5 정답과 해설

복잡한 모델의 추가 가치와 비용을 측정하고, 프로세스·규칙·데이터 수집 개선이 더 싸고 안전하게 목표를 달성하는지 판단하기 위해서다.

### 문제 6 정답과 해설

전략과 연결된 탐색 목적, 허용 데이터·윤리 범위, 기간·예산, 유망 신호, 단계별 승인, 후속 검증과 중단 기준이 필요하다.

### 문제 7 정답과 해설

탐색으로 주제가 구체화되거나 후보 실험으로 방법이 검증되면 알려짐 상태가 바뀐다. 재분류는 불확실성이 줄어든 결과다.

### 문제 8 정답과 해설

확립된 프로세스 마이닝 방법으로 배송 흐름을 탐색해 어느 병목이 중요한 분석 주제인지 찾는 통찰형 접근을 들 수 있다.

### 문제 9 정답과 해설

주제를 대상·시점·결과·행동으로 구체화 → 방법의 검증 근거 확인 → 네 조합에 임시 배치 → 유형별 최소 행동 선택 → 검토 시점에 근거로 재분류 순이다.

## 11. 핵심 요약

- **`최적화와 통찰`**에서 최적화는 주제·방법 모두 알려진 개선형, 통찰은 방법은 알려졌지만 주제가 불명확한 탐색형이다.
- **`솔루션과 발견`**에서 솔루션은 주제는 알려지고 방법이 불명확한 비교형, 발견은 두 축 모두 불명확한 기회 탐색형이다.
- **`분석 유형별 접근 방식`**은 최적화의 기준선, 통찰의 패턴 검증, 솔루션의 후보 비교, 발견의 탐색 경계처럼 유형별 초점을 다르게 두는 것이다.
- “알려짐”은 담당자의 확신이나 알고리즘 이름이 아니라 명확한 문제 정의와 해당 조건에서 검증된 절차를 근거로 판단한다.
- 네 유형은 고정 딱지가 아니라 현재 불확실성을 보여 주며, 학습에 따라 발견 → 통찰/솔루션 → 최적화로 이동할 수 있다.
