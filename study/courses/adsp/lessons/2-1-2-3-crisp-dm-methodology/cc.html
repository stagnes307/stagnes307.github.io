학습 범위: 이 레슨은 ADsP 데이터분석 기획 > 데이터분석 기획의 이해 > 분석 방법론 중 업무·데이터 이해, 데이터 준비와 모델링, 평가와 전개를 다룬다. CRISP-DM의 여섯 단계인 업무 이해–데이터 이해–데이터 준비–모델링–평가–전개를 구분하고, 단계 사이의 반복과 의사결정 기준을 실제 분석 사례에 적용하는 것이 목표다.

CRISP-DM은 Cross-Industry Standard Process for Data Mining의 약자다. 이름에 데이터 마이닝이 들어가지만 업무 목표 정의에서 결과 전개까지 포괄한다. 시험에서는 평가와 모델링을 바꾸거나 전개를 단순한 모델 배포로 좁히는 선택지를 주의해야 한다.

02

2. 업무·데이터 이해

03

2.1 업무 이해

업무·데이터 이해 중 업무 이해는 조직의 목적을 분석 문제와 수행 계획으로 변환하는 단계다. 다음 활동을 포함한다.

업무 목표 결정

현재 상황, 해결하려는 문제, 결과 사용자, 가능한 행동, 제약을 확인한다. “예측 정확도 90%”는 업무 목표가 아니다. 예를 들어 “갱신 상담 인력 안에서 고위험 고객에게 먼저 연락해 유지율을 높인다”가 업무 목표다.

상황 평가

보유 자원, 요구사항, 가정, 위험, 용어, 비용·편익을 조사한다. 데이터 소유자·업무 사용자·분석·IT 운영자의 역할과 의존성을 확인한다.

데이터 마이닝 목표 결정

업무 목표를 분석 가능한 질문과 기술 지표로 바꾼다. “갱신 30일 전 고객별 이탈 확률을 산출하고 하루 상담 가능 건수에서 이탈자의 70% 이상을 포착한다”처럼 대상·시점·출력을 구체화한다.

프로젝트 계획 수립

단계, 일정, 도구, 데이터 접근, 산출물, 검토 관문과 변경 절차를 계획한다. 아직 데이터 품질을 모르므로 가정과 재계획 조건을 함께 둔다.

업무 목표유지 활동의 순효과와 고객 경험 개선
분석 목표기준 시점의 이탈 위험 순위 산출

04

2.2 데이터 이해

데이터 이해는 초기 데이터를 수집하고 설명·탐색하며 품질을 검증하는 단계다.

초기 데이터 수집

원천, 기간, 추출 시각, 접근 방식과 표본 조건을 기록한다. 분석용 복사본이 원천의 어느 시점과 일치하는지 추적한다.

데이터 기술

행·열 수, 변수 형식·단위·범주, 키, 갱신 주기와 기본 통계를 확인한다. 데이터 사전의 정의와 실제 값을 비교한다.

데이터 탐색

분포, 변수 관계, 기간·집단 차이, 목표값 비율, 예상 밖 패턴을 시각화·요약한다. 탐색 결과는 가설을 만들 뿐 원인을 자동 증명하지 않는다.

데이터 품질 검증

결측, 중복, 이상, 단위·코드 불일치, 라벨 오류, 선택 편향, 시점 누수를 확인한다. 품질 문제는 단순 정제 목록이 아니라 업무 목표에 미치는 영향과 해결 책임을 포함한다.

코드 예시 · text

발견: 2025년 7월부터 상담 코드가 세분화됨
영향: 이전·이후 고객의 특징 분포가 달라짐
판단: 대응표로 공통 상위 분류 생성
검증: 기간별 분포와 모델 성능 비교
잔여 위험: 세부 사유는 과거에 복원 불가

데이터 이해 결과에 따라 분석 목표와 일정이 바뀔 수 있다. 필요한 목표값이 신뢰할 수 없다면 모델링을 서두르지 않고 업무 정의·수집 절차를 보완한다.

05

3. 데이터 준비와 모델링

06

3.1 데이터 준비

데이터 준비와 모델링 중 데이터 준비는 초기 데이터에서 모델링에 사용할 최종 데이터셋을 만드는 단계다. 실제 프로젝트에서 반복 작업 비중이 크며, 선택·정제·구성·통합·형식화 활동을 포함한다.

데이터 선택

업무 목표와 모델링에 필요한 행·열·기간을 선택한다. 제외 이유를 기록해 목표 모집단이 달라지지 않게 한다.

데이터 정제

결측·오류·중복·이상값을 원인에 따라 처리한다. 처리 전후 건수와 분포, 집단별 영향을 비교한다.

데이터 구성

파생 변수, 집계, 변환을 만든다. 기준 시점 이전 정보만 사용하고 계산 정의·시간 창·단위를 기록한다.

데이터 통합

여러 테이블·원천을 결합한다. 키의 유일성, 일대다 관계, 시점 유효성 때문에 행이 증식하거나 미래 레코드가 붙지 않는지 확인한다.

데이터 형식화

선택한 기법이 요구하는 변수 형태·순서·인코딩으로 바꾼다. 형식화가 업무 의미를 바꾸지 않는지 확인한다.

준비 과정은 코드·파이프라인으로 재현해야 한다. 학습, 평가, 운영에 동일한 변환을 적용하되 평균·범주 사전처럼 학습에서 추정할 값은 분리 뒤 계산한다.

07

3.2 모델링

모델링은 목적과 데이터에 맞는 기법을 선택하고 시험 설계에 따라 모델을 생성·평가하는 단계다.

모델링 기법 선택

분류·회귀·군집 등 문제 형태, 데이터량·변수, 비선형성, 설명 요구, 처리시간, 운영 제약을 고려한다. 단순 규칙이나 현행 방식도 기준모델로 포함한다.

시험 설계 생성

학습·검증·최종 평가의 역할, 교차검증, 시간·그룹 분리를 정한다. 같은 고객의 반복 기록이나 미래 시점이 양쪽에 섞이지 않게 한다. 지표와 임계값 선택 절차도 미리 둔다.

모델 생성

후보 기법과 매개변수를 제한된 계획으로 시험한다. 전처리·특징 생성까지 하나의 파이프라인으로 묶어 누수와 운영 불일치를 줄인다.

모델 기술 평가

설정한 지표로 후보를 비교하고 오차 유형, 집단·기간별 성능, 안정성, 복잡도, 처리시간을 본다. 검증 데이터에 반복 적합한 뒤 같은 자료를 최종 성능처럼 보고하지 않는다.

코드 예시 · text

후보 A: 성능 높음, 설명 복잡, 응답시간 초과
후보 B: 성능 소폭 낮음, 안정·설명·운영 기준 충족
기준선: 성능 낮음, 비용 매우 낮음
선택: 업무 손실과 운영 제약을 수치화해 결정
08

4. 평가와 전개

09

4.1 평가

평가와 전개 중 평가는 모델링 단계의 기술 평가를 넘어 결과가 업무 목표와 모든 요구를 충족하는지 검토하는 단계다.

결과 평가

업무 성공 기준, 비용·편익, 오류 영향, 공정성·안전, 사용자 해석과 실제 행동 가능성을 확인한다. 모델 성능이 높아도 상담 용량보다 경보가 많거나 규제로 사용할 수 없다면 적합하지 않다.

프로세스 검토

누락된 업무·데이터 조건, 잘못된 가정, 품질 문제, 데이터 누수, 승인되지 않은 변경이 없는지 전 과정을 점검한다. 좋은 결과를 얻었다는 이유로 검토를 줄이지 않는다.

다음 단계 결정

전개, 제한된 시험, 추가 반복, 목표 재정의, 중단 중 하나를 선택하고 근거를 기록한다. 중단도 가치 없는 투자를 막는 정상적인 판단이다.

10

4.2 전개

전개는 모델을 서버에 설치하는 것만 뜻하지 않는다. 분석 결과의 사용 형태에 따라 보고서 전달, 반복 점수 산출, 업무 시스템 통합, 정책 변경, 지식 공유가 될 수 있다.

전개 계획

사용자·빈도·인터페이스·권한, 인간 검토, 단계적 적용, 원복, 교육과 문서를 설계한다.

모니터링·유지 계획

입력 품질, 분포 변화, 성능·교정, 업무 효과, 오류·편향, 지연·비용을 누가 어떤 주기로 감시할지 정한다. 목표값이 늦게 생기면 선행 지표와 사후 평가를 구분한다.

최종 보고와 검토

결과뿐 아니라 범위, 데이터, 가정, 실패한 시도, 제한, 사용 조건을 전달한다. 프로젝트 회고로 재사용 자산과 방법론 개선을 남긴다.

12

6. CRISP-DM과 KDD의 관점 비교

두 방법론은 데이터 준비·분석·평가를 반복한다는 공통점이 있다. KDD는 데이터에서 지식을 발견하는 흐름을 선택–전처리–변환–마이닝–해석·평가로 강조한다. CRISP-DM은 업무 이해를 명시적 출발점으로 두고 데이터 이해·준비·모델링·평가 뒤 전개까지 프로젝트 생명주기를 구조화한다.

시험에서는 어느 것이 “항상 더 우수하다”고 보기보다 단계 이름과 강조점을 정확히 구분한다. 실제 조직은 목적에 맞게 요소를 결합할 수 있지만 시험 답은 제시된 방법론의 표준 순서를 따른다.

13

7. 사례: 구독 이탈 상담 우선순위

업무 이해

갱신 30일 전 하루 500명에게 상담할 수 있으며 자동 계약 거절에는 사용하지 않는다. 유지율과 순효과, 불만 증가를 업무 지표로 둔다.

데이터 이해

계약·이용·청구·상담 데이터를 수집하고 기간·결측·라벨을 본다. 해지 뒤 기록되는 상담 결과 코드를 발견해 누수 후보로 표시한다.

데이터 준비

고객–기준 시점 단위로 이전 90일 이용 변화와 결제 실패를 구성한다. 학습 기간에서만 변환 통계를 추정하고 시간 순서로 데이터를 분리한다.

모델링

현행 규칙, 해석 가능한 기준모델, 비선형 후보를 같은 지표·상담 용량에서 비교한다. 상위 500명 재현율과 확률 교정을 확인한다.

평가

장기·신규 고객별 오류와 상담 비용을 검토한다. 미래 상담 코드를 포함한 초기 후보는 성능이 좋아도 반려하고 준비 단계로 돌아간다.

전개

상담 관리자에게 위험등급·근거·최신 시각을 주고 사람이 최종 배정한다. 입력 결측, 집단별 접촉률, 유지율, 불만과 데이터 분포를 감시한다.

8. 수행 체크리스트

  • [ ] 업무 목표, 분석 목표, 성공 지표와 제약을 구분했다.
  • [ ] 사용자·행동·자원·위험과 프로젝트 계획을 정의했다.
  • [ ] 초기 데이터 원천·기간·시점과 품질을 기술·탐색했다.
  • [ ] 선택·정제·구성·통합·형식화가 재현 가능하다.
  • [ ] 학습에서 추정할 변환과 평가 자료를 분리했다.
  • [ ] 기준선과 후보가 같은 시험 설계·지표로 비교됐다.
  • [ ] 기술 성능뿐 아니라 업무 가치·공정성·운영 제약을 평가했다.
  • [ ] 전 과정의 가정·누수·누락을 검토했다.
  • [ ] 전개에 사용자·권한·원복·감시·재평가가 있다.
  • [ ] 단계 회귀와 최종 결정 근거가 기록됐다.
15

9. 자주 틀리는 시험 함정

  1. CRISP-DM을 데이터 준비나 모델링에서 시작한다고 본다.
  2. 업무 목표와 데이터 마이닝 목표를 동일한 문장으로 쓴다.
  3. 데이터 이해와 데이터 준비를 구분하지 않는다.
  4. 데이터 준비가 최초 한 번만 수행된다고 본다.
  5. 모델링의 기술 평가만으로 업무 적합 평가가 끝난다고 본다.
  6. 평가 단계는 모델 지표를 다시 계산하는 단계라고만 본다.
  7. 전개를 모델 서버 설치에만 한정한다.
  8. 단계 사이 회귀를 허용하지 않는 선형 방법론으로 외운다.
  9. 최종 평가 데이터를 후보 선택에 반복 사용한다.
  10. 높은 모델 성능이면 운영 용량·권한·공정성 검토가 필요 없다고 본다.

10. 확인 문제

문제 1

CRISP-DM의 여섯 단계를 순서대로 쓰시오.

문제 2

업무 목표와 데이터 마이닝 목표의 차이를 예로 설명하시오.

문제 3

데이터 이해 단계의 네 가지 대표 활동을 쓰시오.

문제 4

데이터 준비의 선택·정제·구성·통합·형식화 중 구성과 통합의 차이는 무엇인가?

문제 5

모델링 단계에서 시험 설계를 먼저 정해야 하는 이유는 무엇인가?

문제 6

모델링의 기술 평가와 평가 단계의 업무 평가를 구분하시오.

문제 7

CRISP-DM에서 전개가 모델 설치보다 넓은 이유는 무엇인가?

문제 8

KDD와 CRISP-DM의 공통점과 강조점 차이를 하나씩 쓰시오.

문제 9

구독 이탈 사례를 CRISP-DM 여섯 단계에 맞춰 요약하시오.

17

11. 정답과 해설

문제 1 정답과 해설

업무 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 전개 순이다. 실제 수행에서는 결과에 따라 이전 단계로 반복한다.

문제 2 정답과 해설

업무 목표는 상담 효율과 유지율을 높이는 것이다. 데이터 마이닝 목표는 갱신 30일 전 고객의 이탈 확률을 산출해 상위 500명에서 목표 재현율을 달성하는 식으로 기술적 질문·지표로 변환한다.

문제 3 정답과 해설

초기 데이터 수집, 데이터 기술, 데이터 탐색, 데이터 품질 검증이다. 그 결과는 목표·계획을 수정할 수 있다.

문제 4 정답과 해설

구성은 기존 데이터에서 파생 변수·집계를 만드는 활동이다. 통합은 여러 테이블·원천을 키와 시점 규칙으로 결합하는 활동이다.

문제 5 정답과 해설

후보를 본 뒤 유리한 분할·지표를 고르는 편향을 줄이고 모든 후보를 동일한 조건으로 비교하며 누수 없는 일반화 성능을 추정하기 위해서다.

문제 6 정답과 해설

기술 평가는 모델 지표·오차·안정성·처리시간을 본다. 업무 평가는 조직 목표, 비용·행동 가능성, 공정성·안전, 프로세스 누락까지 검토해 전개 여부를 판단한다.

문제 7 정답과 해설

결과가 보고서·정책·반복 점수·업무 시스템 등 다양한 형태로 사용될 수 있기 때문이다. 사용자·교육·권한·감시·유지·최종 보고도 포함한다.

문제 8 정답과 해설

둘 다 데이터 준비·분석·평가를 반복한다. KDD는 선택에서 지식 해석까지의 발견 흐름, CRISP-DM은 업무 이해와 전개를 포함한 산업 프로젝트 생명주기를 명시적으로 강조한다.

문제 9 정답과 해설

상담 업무·지표 정의 → 계약·이용 데이터 이해 → 시점 안전 변수와 분할 준비 → 기준선·후보 모델링 → 누수·집단·비용 업무 평가 → 사람 중심 상담 배정과 품질·효과 감시 전개 순이다.

18

12. 핵심 요약

  • CRISP-DM은 업무 이해–데이터 이해–데이터 준비–모델링–평가–전개의 여섯 단계를 반복적으로 연결한다.
  • 업무·데이터 이해는 조직 목표를 분석 목표·계획으로 바꾸고 초기 데이터의 구조·탐색·품질을 확인하는 과정이다.
  • 데이터 준비와 모델링은 선택·정제·구성·통합·형식화로 최종 데이터를 만들고 공정한 시험 설계에서 기준선과 후보 모델을 비교하는 과정이다.
  • 평가와 전개는 기술 성능을 넘어 업무 가치·위험·프로세스를 검토하고 결과의 사용·운영·감시·회고를 계획하는 과정이다.
  • 데이터나 평가가 가정을 반박하면 이전 단계로 돌아가며 변경 이유와 산출물·재검증 범위를 추적해야 한다.
