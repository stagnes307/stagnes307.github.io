# 2-2-1-1. 분석 과제 우선순위 평가

> **학습 범위**: 이 레슨은 ADsP `데이터분석 기획 > 분석 마스터플랜 > 마스터플랜 수립` 중 **전략적 중요도와 실행 용이성**, **시급성과 난이도**, **포트폴리오 사분면 평가**를 다룬다. 단순 점수 합계로 순위를 자동 결정하지 않고, 가치·긴급성·실행 가능성·의존성·위험을 공통 기준으로 비교해 균형 잡힌 과제 포트폴리오를 만드는 것이 목표다.

좋은 분석 아이디어가 많아도 인력·데이터·예산은 제한된다. 쉬운 과제만 고르면 전략 가치가 약하고, 가치가 큰 어려운 과제만 동시에 시작하면 성과가 나오기 전에 자원이 고갈될 수 있다. 우선순위 평가는 “중요한가?”와 “지금 실행 가능한가?”를 분리해 보고, 사분면과 의존 관계로 착수 방식까지 판단하는 과정이다.

---

## 1. 우선순위 평가의 원칙

| 원칙 | 의미 |
|---|---|
| 공통 정의 | 모든 후보를 같은 문제·목표·범위 수준으로 정리한 뒤 비교한다. |
| 가치와 실행 분리 | 중요하지만 어려운 과제와 쉽지만 가치 낮은 과제를 구분한다. |
| 근거 기록 | 점수뿐 아니라 데이터·기준선·가정과 평가자의 이유를 남긴다. |
| 위험 반영 | 개인정보·안전·오판·운영 부담을 편익과 함께 본다. |
| 의존성 반영 | 선행 데이터·기반 과제가 후속 가치 과제를 가능하게 하는지 본다. |
| 포트폴리오 균형 | 단기 성과, 전략 투자, 기반, 탐색을 조합한다. |
| 주기적 재평가 | 전략·데이터·기술·환경 변화에 따라 순위를 갱신한다. |

우선순위는 절대적 진리가 아니라 특정 시점의 전략과 제약에 따른 의사결정이다. 점수 모형은 토론을 구조화하지만 책임자의 판단을 대체하지 않는다.

```text
정의된 과제 후보
   ↓ 가치·전략·시급성 평가
   ↓ 실행 용이성·난이도·위험 평가
   ↓ 사분면 배치 + 의존성·자원 제약
   ↓ 착수·선행 검증·단계화·보류 결정
```

## 2. 전략적 중요도와 실행 용이성

### 2.1 전략적 중요도

**전략적 중요도와 실행 용이성** 중 전략적 중요도는 과제가 조직의 핵심 목표와 경쟁·공공 가치에 얼마나 직접 기여하는지를 뜻한다.

- 핵심 전략·성과지표와의 직접 연결 정도
- 고객·국민·현업 문제의 규모와 영향
- 수익, 비용, 위험, 품질, 안전의 예상 개선
- 규제·평판·사업 연속성에 미치는 영향
- 다른 과제와 역량을 가능하게 하는 기반·학습 가치
- 경쟁 차별화와 장기 옵션 가치

“경영진이 관심 있다”를 전략 점수의 유일한 근거로 쓰지 않는다. 어떤 목표의 어떤 기준선을 바꾸는지, 결과를 실제 행동에 적용할 수 있는지를 적는다. 편익은 과대 추정하기 쉬우므로 가정과 측정 계획을 함께 둔다.

### 2.2 실행 용이성

실행 용이성은 필요한 데이터·기술·조직·제도·업무 적용 조건이 준비되어 낮은 노력과 위험으로 성과를 낼 가능성이다.

| 실행 요소 | 확인 질문 |
|---|---|
| 데이터 | 존재·기간·품질·라벨·결합·권리가 충분한가 |
| 분석 | 질문에 적합한 방법과 검증 기준이 있는가 |
| 기술 | 저장·연산·통합·운영 환경을 확보할 수 있는가 |
| 조직 | 후원자·현업·분석·운영 책임자가 참여하는가 |
| 프로세스 | 결과를 적용할 의사결정과 변경 권한이 있는가 |
| 위험 | 오판·보안·공정성·규제 위험을 통제할 수 있는가 |
| 시간·비용 | 가치가 필요한 시점 안에 자원을 확보할 수 있는가 |

데이터가 많다는 사실과 실행 용이성은 다르다. 목표 라벨이 부정확하거나 운영 시점에 늦게 도착하면 어렵다. 기존 제품을 구매할 수 있어도 조직의 적용 프로세스와 책임이 없으면 용이하지 않다.

### 2.3 평가 척도 설계

예를 들어 1~5 등급을 사용할 수 있지만 각 등급의 관찰 가능한 기준을 정한다. “전략 중요도 5=매우 중요”보다 “최우선 전략 KPI에 직접 연결되고 임원 후원·기준선·행동 책임이 확정됨”처럼 쓴다. 실행 용이성도 “핵심 데이터 사용 승인과 품질 표본 검증 완료, 적용 시스템·현업 책임 준비”처럼 근거를 둔다.

척도의 방향을 통일한다. 실행 용이성은 높을수록 좋은데 난이도는 높을수록 어려우므로 같은 합산식에 넣을 때 변환을 명시해야 한다. 가중치는 전략에 따라 정하되 결과가 특정 가중치에 민감한지 확인한다.

### 2.4 가치가 큰 어려운 과제

전략 중요도가 높지만 실행 용이성이 낮은 과제를 무조건 버리지 않는다. 핵심 불확실성을 줄이는 데이터 진단, 프로토타입, 선행 기반 과제, 제한된 대상부터 시작하는 단계화를 적용한다. 장기 전략 과제를 단기 성과 과제와 함께 포트폴리오에 넣는다.

## 3. 시급성과 난이도

### 3.1 시급성

**시급성과 난이도** 중 시급성은 과제를 늦출 때 기회가 사라지거나 손실·위험이 커지는 정도다.

- 법·정책·계약 시행일이 정해져 있는가?
- 사고·손실·고객 이탈이 현재 빠르게 증가하는가?
- 시장 기회나 계절·행사처럼 유효 기간이 짧은가?
- 선행 의사결정 일정 전에 결과가 필요한가?
- 다른 프로젝트가 이 결과를 기다리는가?
- 지연 비용이 어느 정도인가?

경영진의 요청 날짜가 빠르다는 것만 시급성은 아니다. 지연했을 때 실제로 어떤 손실이 발생하는지 근거가 필요하다. 중요도는 장기 전략 가치, 시급성은 시간에 따른 가치·손실 변화라는 차이가 있다.

### 3.2 난이도

난이도는 과제 수행에 필요한 노력·복잡도·불확실성과 위험이다.

| 난이도 원천 | 사례 |
|---|---|
| 문제 | 목표·행동·성공 기준이 모호함 |
| 데이터 | 여러 원천, 낮은 품질, 라벨 부족, 권리 제약 |
| 분석 | 희귀 사건, 변화가 큼, 인과 검증 필요 |
| 기술 | 실시간·대규모·복잡한 통합·높은 가용성 |
| 조직 | 부서 갈등, 후원·현업 참여 부족 |
| 적용 | 기존 프로세스·평가·권한을 크게 변경 |
| 책임 | 생명·금융·권리에 영향, 설명·감사 요구 큼 |

난이도가 높다고 가치가 낮은 것은 아니다. 난이도는 일정·비용·실패 가능성과 단계화 필요성을 판단하는 축이다. 경험 있는 인력과 공통 플랫폼이 생기면 같은 과제의 난이도가 낮아질 수 있으므로 시간에 따라 갱신한다.

### 3.3 시급성-난이도 조합

| 시급성 | 난이도 | 판단 예 |
|---|---|---|
| 높음 | 낮음 | 빠른 착수 후보, 단 품질 기준 확인 |
| 높음 | 높음 | 범위 축소·전담 조직·임시 통제와 장기 해법 병행 |
| 낮음 | 낮음 | 자원 여유·학습 효과에 따라 묶음 실행 |
| 낮음 | 높음 | 장기 연구·기반 준비 또는 보류 |

높은 시급성·난이도 과제는 “무조건 즉시 전체 구현”이 아니다. 최소 안전·가치 범위를 정하고, 현재 위험을 줄일 임시 규칙과 데이터 기반·정식 분석을 병행할 수 있다.

## 4. 포트폴리오 사분면 평가

### 4.1 기본 사분면

**포트폴리오 사분면 평가**는 보통 가치·전략 중요도와 실행 용이성 또는 시급성과 난이도를 두 축에 놓아 과제 유형을 시각화한다.

```text
전략 가치 높음
      │ [전략 투자]          [우선 실행]
      │ 가치 높음·용이성 낮음  가치 높음·용이성 높음
      │
      │ [보류·재정의]        [빠른 성과/선별]
      │ 가치 낮음·용이성 낮음  가치 낮음·용이성 높음
      └──────────────────────── 실행 용이성 높음
```

- **우선 실행**: 가치와 실행성이 모두 높아 조기 성과 후보지만 과도한 동시 착수를 피한다.
- **전략 투자**: 가치가 높으나 어려워 데이터·기반·프로토타입과 단계화가 필요하다.
- **빠른 성과/선별**: 쉽지만 가치가 상대적으로 낮다. 학습·신뢰·공통 자산 효과가 있으면 제한적으로 선택한다.
- **보류·재정의**: 가치와 실행성이 낮다. 문제 재정의 또는 환경 변화 후 검토한다.

사분면 명칭은 조직마다 다를 수 있으므로 축의 방향과 의미를 확인한다. 사분면은 점수 차이를 시각화하는 도구이지 과제의 자동 처분 규칙이 아니다.

### 4.2 경계 과제와 불확실성

평가 점수는 측정 오차와 가정을 가진다. 경계선 가까운 과제는 단일 사분면으로 확정하기보다 점수 범위와 핵심 가정을 표시한다. 데이터 품질이 확인되면 실행 용이성이 크게 바뀌는 과제라면 짧은 진단으로 먼저 불확실성을 줄인다.

### 4.3 의존성과 포트폴리오 균형

낮은 직접 가치의 데이터 표준화 과제가 여러 고가치 과제의 선행 조건일 수 있다. 개별 사분면만 보면 후순위지만 포트폴리오 의존 그래프에서는 우선일 수 있다.

```text
[고객 ID 통합] ─┬→ 이탈 조기지원
                ├→ 추천 개인화
                └→ 채널별 고객가치 분석
```

포트폴리오는 다음을 균형화한다.

- 단기 성과와 장기 전략 투자
- 활용 과제와 공통 데이터·기술 기반
- 낮은 위험 학습과 높은 영향 혁신
- 운영 개선과 신규 제품·서비스
- 필수 규제·안전 과제와 선택 성장 과제
- 분석·데이터·현업·운영 자원의 동시 수용량

### 4.4 자원 제약과 동시 착수

우선순위가 높다고 모두 동시에 시작하면 핵심 데이터 담당자와 현업 검토자가 병목이 된다. 자원 유형별 용량, 과제 간 중복, 데이터·시스템 변경 충돌을 고려한다. 높은 순위는 반드시 “즉시 전체 착수”가 아니라 진단·기반·시제품 중 다음 행동의 우선순위를 뜻할 수 있다.

## 5. 정량 점수와 정성 판단

### 5.1 점수표 예시

| 평가 범주 | 지표 예 | 근거 |
|---|---|---|
| 전략 가치 | 핵심 목표 연결, 문제 영향, 재사용 가치 | 전략 문서·기준선 |
| 시급성 | 지연 손실, 마감, 의존 과제 | 계약·위험·일정 |
| 데이터 준비 | 존재·권리·품질·적시 | 프로파일·승인 상태 |
| 기술·조직 | 역량·환경·후원·적용 프로세스 | 준비도 점검 |
| 위험 | 오판·보안·공정성·운영 영향 | 위험 평가 |
| 노력 | 인력·기간·원가·복잡도 | 유사 실적·추정 |

가중 합산을 사용한다면 점수 방향, 가중치, 누락 처리, 평가 기준을 공개한다. 위험을 단순 감점으로만 처리하면 생명·법적 금지 같은 문턱 조건이 높은 가치 점수에 가려질 수 있다. 반드시 충족해야 할 안전·권리 조건은 별도 관문으로 둔다.

### 5.2 평가 편향 통제

- 후원자의 목소리가 큰 과제만 높게 평가하지 않는다.
- 수익은 숫자로 보이지만 안전·공정성은 누락되는 가용성 편향을 줄인다.
- 과거 투자 비용 때문에 가치 낮은 과제를 계속하는 매몰비용 오류를 경계한다.
- 복잡한 기술을 혁신 가치로 과대평가하지 않는다.
- 평가자가 자신의 부서 편익만 보지 않도록 공통 기준과 교차 검토를 둔다.
- 가정과 데이터 품질의 확신 수준을 점수와 함께 표시한다.

### 5.3 민감도와 시나리오

가중치나 예상 편익이 조금 바뀌면 순위가 뒤집히는지 확인한다. 순위가 불안정하면 정확한 숫자 경쟁보다 추가 검증이 필요한 가정을 찾는다. 규제 강화, 데이터 계약 실패, 인력 부족 같은 시나리오별 포트폴리오 변화를 검토한다.

## 6. 사례: 여섯 과제 포트폴리오

한 유통사는 다음 후보를 평가한다.

| 과제 | 가치 | 용이성 | 의존·판단 |
|---|---|---|---|
| 품절 위험 예측 | 높음 | 중간 | 재고 정확도 개선 필요 |
| 상품 추천 개선 | 높음 | 높음 | 조기 제한 시험 후보 |
| 고객 ID 통합 | 직접 가치는 중간 | 낮음 | 세 고가치 과제의 공통 선행 |
| 일일 보고 자동화 | 중간 | 높음 | 빠른 성과·분석 인력 절감 |
| 매장 영상 감정 추론 | 불확실 | 낮음 | 권리·정확성 위험, 보류·재정의 |
| 규제 보고 검증 | 높음·필수 | 중간 | 마감이 정한 시급 과제 |

사분면만 보면 고객 ID 통합은 뒤로 밀릴 수 있지만 품절·추천·고객가치 과제의 연결 품질을 결정한다. 기반 범위를 단계화해 우선 착수할 수 있다. 보고 자동화는 전략적 차별화는 작아도 분석 인력을 확보하고 신뢰를 쌓는 빠른 성과가 될 수 있다. 영상 감정 추론은 기술 흥미보다 문제·권리·행동을 재정의해야 한다.

최종 포트폴리오는 추천 제한 시험, 규제 보고, ID 통합 1단계, 보고 자동화를 자원 용량 안에서 배치하고 품절 예측은 재고 품질 관문 후 시작할 수 있다.

## 7. 우선순위 판단 절차

1. 후보 정의서의 목표·범위·데이터·행동 수준을 맞춘다.
2. 전략 가치와 시급성을 근거·기준선으로 평가한다.
3. 데이터·기술·조직·프로세스·위험의 실행 용이성과 난이도를 평가한다.
4. 안전·권리·규제의 필수 관문을 별도로 확인한다.
5. 가중치·등급 기준과 평가자의 근거·확신을 기록한다.
6. 사분면에 배치하되 경계 과제의 불확실성을 표시한다.
7. 선행·공통 기반·충돌 관계와 자원 용량을 반영한다.
8. 단기·장기·기반·필수 과제의 포트폴리오를 구성한다.
9. 민감도·시나리오를 검토하고 승인권자가 결정한다.
10. 데이터·전략·환경 변화 시 재평가 조건을 정한다.

## 8. 시험에서 자주 틀리는 포인트

1. 전략 중요도와 시급성을 같은 개념으로 본다.
2. 실행 용이성과 난이도의 점수 방향을 혼동한다.
3. 데이터량이 많으면 실행 용이성이 높다고 본다.
4. 난도가 높은 고가치 과제를 무조건 폐기한다.
5. 쉬운 과제를 모두 우선해 전략 포트폴리오를 잃는다.
6. 사분면을 자동 착수·폐기 규칙으로 사용한다.
7. 개별 직접 가치가 낮은 공통 기반 과제의 의존 효과를 놓친다.
8. 높은 순위 과제를 모두 동시에 시작해 공유 자원 병목을 만든다.
9. 생명·권리 위험을 낮은 감점으로만 처리해 높은 가치가 상쇄하게 한다.
10. 점수와 가중치를 객관적 진리로 보고 민감도·재평가를 생략한다.

## 정답과 해설

### 정답 1
공통 정의, 가치·실행 분리, 근거 기록, 위험 반영, 의존성 반영, 포트폴리오 균형, 주기적 재평가 중 다섯 가지다.

### 정답 2
전략적 중요도는 조직의 핵심 목표·가치·위험에 기여하는 정도이고, 실행 용이성은 데이터·기술·조직·프로세스·권리 조건 아래 낮은 노력과 위험으로 성과를 낼 가능성이다.

### 정답 3
데이터, 분석 방법, 기술·인프라, 조직·후원, 적용 프로세스, 위험 통제, 시간·비용 중 다섯 가지다.

### 정답 4
고객 데이터 표준화는 장기 전략에 매우 중요하지만 마감이 없을 수 있다. 다음 달 시행 규제 보고는 전략 차별화보다 지연 손실과 기한 때문에 시급할 수 있다.

### 정답 5
문제 모호성, 데이터 품질·권리, 분석 복잡성, 기술·실시간 통합, 조직 갈등, 업무 변경, 책임·규제 중 다섯 가지다.

### 정답 6
고가치·고용이성은 우선 실행, 고가치·저용이성은 전략 투자·단계화, 저가치·고용이성은 빠른 성과로 선별, 저가치·저용이성은 보류·재정의한다.

### 정답 7
여러 고가치 활용 과제의 데이터 식별·품질·접근을 가능하게 하여 포트폴리오 전체 가치를 높이기 때문이다. 의존 그래프로 간접 가치를 평가한다.

### 정답 8
높은 예상 편익 점수가 법적 금지·생명 안전·심각한 권리 위험을 수치상 상쇄하면 안 되기 때문이다. 필수 조건 미충족은 별도 중단·보완 판단이 필요하다.

### 정답 9
가중치, 채택률, 예상 편익 같은 불확실한 가정이 조금만 바뀌어도 순위가 뒤집히는 경우다. 추가 검증과 시나리오별 순위를 본다.

### 정답 10
데이터 담당자·현업 검토자·연산 환경 같은 공유 자원이 병목이 되고 모든 과제가 지연될 수 있다. 자원 유형별 용량과 의존을 반영해 진단·기반·시제품 착수 시점을 나눈다.

## 핵심 요약

- **전략적 중요도와 실행 용이성**은 과제가 핵심 가치를 만드는 정도와 데이터·기술·조직 조건에서 실현 가능한 정도를 분리해 평가한다.
- **시급성과 난이도**는 지연에 따른 기회·손실과 문제·데이터·기술·조직·책임 복잡성을 판단한다.
- **포트폴리오 사분면 평가**는 고가치·고용이성 우선 실행, 고가치·저용이성 전략 투자 등 과제 유형과 다음 행동을 시각화한다.
- 사분면과 점수는 자동 결정이 아니며 근거·확신·민감도와 필수 안전·권리 관문을 함께 본다.
- 공통 기반과 과제 의존성, 공유 자원 용량을 반영하지 않으면 개별 순위가 전체 포트폴리오를 왜곡한다.
- 단기 성과·장기 전략·기반·필수 과제를 균형 있게 구성하고 전략·데이터·환경 변화에 따라 재평가한다.
