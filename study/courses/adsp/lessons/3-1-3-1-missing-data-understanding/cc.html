학습 범위: 이 레슨은 ADsP 데이터분석 > R기초와 데이터 마트 > 결측값 처리와 이상값 검색 중 결측값의 유형과 발생 원인, 결측 패턴 확인, 결측이 분석에 미치는 영향을 다룬다. 결측을 단순히 빈 칸으로 보지 않고 값·행·집단·시간별 발생 구조와 메커니즘을 탐색해 분석 위험을 진단하는 것이 목표다.

구체적인 삭제·대치 방법의 선택은 다음 레슨에서 다룬다. 이 레슨에서는 어떤 값이 결측인지 정의하고, 왜 발생했으며, 어느 집단과 변수에 함께 나타나는지, 결과에 어떤 편향과 불확실성을 만들 수 있는지 확인한다. R 예제는 base R만 사용한다.

01

1. 결측값의 의미

결측값(missing value)은 관측 단위에 값이 존재해야 하지만 수집·저장·응답 과정에서 관찰되지 않은 상태다. 0, 빈 문자열, “해당 없음”, 측정 한계 미만과 구분해야 한다.

1. 결측값의 의미 · 학습 표 1
표현가능한 의미확인 방법
NAR의 일반 결측is.na()
NaN정의되지 않은 수치 계산is.nan(), is.na()도 TRUE
Inf, -Inf무한대 결과is.infinite()
"", 공백빈 문자열문자열 정제 후 비교
-999, 9999시스템의 결측 대체 코드일 수 있음데이터 사전·분포 확인
0실제 0 또는 잘못된 결측 코드업무 정의 확인
“해당 없음”구조적으로 측정 대상 아님일반 미응답과 별도 코드

R의 NA에는 논리형·정수형·실수형·문자형 등 자료형 맥락이 있다. NA == NA는 알 수 없는 값끼리 같다고 확정할 수 없어 NA를 반환하므로 is.na(x)로 확인한다.

코드 예시 · r

x <- c(10, NA, 0, NaN, Inf)
is.na(x)
is.nan(x)
is.infinite(x)

예상 결과에서 is.na(x)는 두 번째 NA와 네 번째 NaN에 TRUE, is.nan(x)는 NaN에만 TRUE, is.infinite(x)는 Inf에 TRUE다.

02

2. 결측값의 유형과 발생 원인

결측값의 유형과 발생 원인은 통계적 결측 메커니즘과 업무적 원인을 함께 본다.

03

2.1 MCAR: 완전 무작위 결측

MCAR(Missing Completely At Random)는 결측 여부가 관측된 값과 관측되지 않은 해당 값 모두와 관련이 없다고 보는 경우다.

예: 설문지 일부가 무작위 배송 사고로 손실되어 응답 내용·응답자 특성과 무관하게 사라졌다.

MCAR이면 완전 관측 사례가 원 모집단의 무작위 부분집합에 가까울 수 있다. 그러나 실제 데이터에서 강한 가정이며, 단순 검정 하나로 완전히 증명하기 어렵다.

04

2.2 MAR: 조건부 무작위 결측

MAR(Missing At Random)는 관측된 다른 변수로 조건을 주었을 때 결측 여부가 관측되지 않은 값 자체와 추가로 관련되지 않는다고 보는 경우다.

예: 소득 응답 결측률이 연령·직업에 따라 다르지만 같은 연령·직업 안에서는 실제 소득과 결측 여부의 추가 관계가 없다고 가정한다.

MAR은 “아무 원인 없이 무작위”가 아니다. 결측 발생이 관측 변수와 관련될 수 있으므로 그 변수를 분석·대치 모형에 반영해야 한다.

05

2.3 MNAR: 비무작위 결측

MNAR(Missing Not At Random)는 관측된 변수를 고려해도 결측 여부가 관측되지 않은 값 자체나 관측되지 않은 요인과 관련되는 경우다.

예: 소득이 매우 높은 사람이 실제 소득 때문에 응답을 피하거나, 증상이 심한 환자가 상태 때문에 추적 조사에 참여하지 못한다.

MNAR은 관측 데이터만으로 식별하기 어렵다. 후속 조사, 수집 과정 지식, 외부 자료, 민감도 분석이 필요하다. “결측률이 낮다”는 사실만으로 무시할 수 없다.

06

2.4 구조적 결측과 수집 결측

모든 결측을 MCAR/MAR/MNAR만으로 실무 코딩하지 않는다.

  • 구조적 결측: 미성년자에게 “혼인 기간” 질문이 적용되지 않음
  • 건너뛰기 규칙: “구매 경험 없음”이면 만족도 문항 미응답
  • 센서 장애: 특정 시간·장치의 모든 측정 누락
  • 조인 실패: 키 형식 차이로 외부 표의 값이 붙지 않음
  • 입력 거부: 개인정보·민감 문항 무응답
  • 측정 한계: 기기 검출 한계 아래로 정확한 수치 없음
  • 시스템 변경: 새 변수가 도입되기 전 과거 기간에 값 없음

구조적 “해당 없음”을 일반 결측으로 대치하면 의미 없는 값을 만든다. 원인 코드를 별도 보존한다.

07

3. 재현 가능한 탐색 데이터

코드 예시 · r

survey <- data.frame(
  id       = 1:8,
  age      = c(22, 35, 41, 29, 52, 47, 31, 60),
  channel  = c("web", "store", "web", "web", "store", "store", "web", "store"),
  income   = c(2800, NA, 5100, 3300, NA, 6200, NA, 7000),
  score    = c(8, 7, NA, 6, 9, NA, 5, 8),
  followup = c(1, 1, 0, 1, 0, 1, 0, 1)
)

survey

이 예제에서 결측 원인은 주어지지 않았다. 단순히 웹 고객의 소득 결측이 많아 보인다는 이유만으로 MAR라고 확정할 수 없다. 관측 패턴은 가설을 만들고 수집 절차와 추가 자료로 확인하는 출발점이다.

08

4. 결측 패턴 확인

결측 패턴 확인은 전체 결측률뿐 아니라 변수·행·집단·시간과 동시 결측 구조를 본다.

09

4.1 변수별 결측 수와 비율

코드 예시 · r

missing_n <- colSums(is.na(survey))
missing_rate <- colMeans(is.na(survey))
data.frame(variable = names(missing_n),
           missing_n = as.integer(missing_n),
           missing_rate = as.numeric(missing_rate))

예상 결과는 income 3건(0.375), score 2건(0.25), 나머지 0건이다. 전체 비율만 보고 중요성을 판단하지 않는다. 목표변수 1% 결측이 입력변수 20%보다 더 심각할 수 있다.

10

4.2 행별 결측 수와 완전 사례

코드 예시 · r

survey$row_missing_n <- rowSums(is.na(survey))
survey$complete <- complete.cases(survey[c("income", "score")])
survey[c("id", "row_missing_n", "complete")]

complete.cases()에 어떤 변수를 넣는지에 따라 완전 사례가 달라진다. 데이터 전체 열을 넣으면 분석에 쓰지 않는 메모 열의 결측 때문에 행을 제외할 수 있다.

11

4.3 동시 결측 패턴

코드 예시 · r

pattern <- data.frame(
  income_missing = is.na(survey$income),
  score_missing  = is.na(survey$score)
)
table(pattern$income_missing, pattern$score_missing)

두 변수가 함께 빠지는지, 서로 다른 과정에서 빠지는지 확인한다. 여러 센서가 같은 시간에 함께 결측이면 통신 장애 가능성이 있고, 특정 문항 묶음만 결측이면 설문 분기나 페이지 이탈 가능성이 있다.

12

4.4 집단별 결측률

코드 예시 · r

aggregate(is.na(income) ~ channel, data = survey, FUN = mean)
aggregate(is.na(score) ~ followup, data = survey, FUN = mean)

식 왼쪽의 표현이 결과 열 이름을 복잡하게 만들 수 있지만 값은 각 집단의 결측 비율이다. 표본이 8명뿐이므로 차이를 일반화하지 않는다. 실제 분석에서는 집단 크기와 불확실성을 함께 보고, 결측 여부를 0/1 변수로 만든 모형도 사용할 수 있다.

코드 예시 · r

survey$income_missing <- as.integer(is.na(survey$income))
glm(income_missing ~ age + channel,
    data = survey, family = binomial())

결측 지시변수 모형은 관측 변수와 결측의 관련성을 탐색하지만 MCAR·MAR·MNAR을 자동 판정하지 않는다. MNAR 여부는 관측되지 않은 값과의 관계이므로 관측자료만으로 확인하기 어렵다.

13

4.5 시간·공간·수집 경로별 패턴

실무에서는 날짜별 결측률, 장치·지점·조사원·앱 버전별 패턴을 본다. 시스템 배포일 이후 급증했다면 코드 변경, 특정 장치만 빠지면 센서·통신 문제일 수 있다.

코드 예시 · text

날짜 × 변수 결측률
장치 × 시간대 결측 연속 길이
설문 페이지 × 이탈 위치
원천 시스템 × 조인 실패율

결측의 연속 길이는 시계열 보간 가능성과 운영 장애의 크기를 판단하는 데 중요하다.

14

5. 결측이 분석에 미치는 영향

결측이 분석에 미치는 영향은 표본 크기 감소뿐 아니라 편향, 관계 왜곡, 불확실성 과소평가와 시스템 오류를 포함한다.

15

5.1 R 계산 결과의 전파

코드 예시 · r

mean(survey$income)
mean(survey$income, na.rm = TRUE)

첫 결과는 NA, 두 번째는 관측된 소득 5개의 평균인 4880이다. na.rm = TRUE는 결측을 해결한 것이 아니라 관측값만으로 계산한 것이다. 그 5명이 전체 8명을 대표하는지는 별도 문제다.

합계·평균마다 기본 결측 처리 방식이 다를 수 있으므로 함수 문서를 확인하고 분석 표본 수를 함께 보고한다.

16

5.2 표본 크기와 검정력

완전 사례만 쓰면 여러 변수 중 하나라도 결측인 행이 사라져 표본이 급격히 줄 수 있다. 표준오차가 커지고 작은 효과를 탐지하기 어려워진다. 집단별로 결측률이 다르면 표본 구성도 달라진다.

17

5.3 편향

결측이 결과나 집단 특성과 관련되면 관측된 평균·비율·회귀계수가 모집단과 달라질 수 있다. 고소득자의 무응답이 많으면 관측 소득 평균이 낮아질 수 있고, 증상이 심한 환자가 추적에서 빠지면 치료 결과를 낙관적으로 평가할 수 있다.

18

5.4 변수 관계 왜곡

분석마다 사용 가능한 행이 달라지면 상관행렬의 각 상관계수가 서로 다른 표본에서 계산될 수 있다. 이 행렬이 수학적으로 일관된 공분산 구조를 이루지 못할 수도 있다. 결과표에 유효 표본 수를 함께 제시한다.

19

5.5 운영 편향과 실패

학습 시 결측이 거의 없지만 운영 특정 지점에서 센서 결측이 많으면 모델 입력 오류나 성능 저하가 발생한다. 결측 자체가 시스템 장애 신호일 수 있으므로 결측률·연속 길이·집단별 변화를 운영 지표로 감시한다.

20

5.6 해석의 불확실성

결측 처리 후 하나의 완성 데이터만 보고하면 빠진 값에 대한 불확실성을 잊기 쉽다. 특히 결측 원인이 불명확하면 여러 가능한 가정에서 결론이 얼마나 달라지는지 민감도 분석이 필요하다.

21

6. 결측 진단 절차

단계 1: 결측 코드 표준화

데이터 사전과 원천 담당자를 통해 NA, 빈 문자열, 특수 숫자, “해당 없음”, 측정 한계 코드를 구분한다. 변환 전 원값과 사유를 보존한다.

단계 2: 분석 단위와 중요 변수 확인

목표, 핵심 입력, 식별키, 시간 변수를 구분한다. 같은 결측률도 변수 역할에 따라 영향이 다르다.

단계 3: 규모와 패턴 계산

변수·행별 수·비율, 동시 결측, 집단·시간·원천별 차이와 연속성을 확인한다. 분모와 필터를 기록한다.

단계 4: 수집 과정을 조사

설문 분기, 센서 장애, 앱 버전, 조인 규칙, 업무 입력 선택성을 확인한다. 통계표만으로 원인을 단정하지 않는다.

단계 5: 메커니즘 가설 수립

MCAR·MAR·MNAR 가능성과 구조적 결측을 구분하고 근거·반증 가능성을 기록한다. 여러 가정이 가능하면 모두 남긴다.

단계 6: 분석 영향 평가

유효 표본, 집단 구성, 목표와 관계, 운영 재현성, 민감도를 확인한다. 다음 레슨의 처리 후보와 필요한 추가 수집을 결정한다.

22

7. 사례: 고객 만족도 조사

온라인 응답자의 소득 결측률이 매장 응답자보다 높고, 낮은 만족도 응답자는 후속 설문에서 더 자주 이탈했다.

  1. 빈 문자열과 “응답 거부”를 일반 NA와 분리한다.
  2. 문항별·응답자별·채널별·페이지별 결측률을 계산한다.
  3. 소득 결측이 채널·연령과 관련되는지 탐색한다.
  4. 만족도 후속 결측이 이전 만족도와 관련되는지 본다.
  5. 관측 변수와 관련된 결측은 MAR 가능성을 고려하되 실제 소득·미관측 만족도와 관련된 MNAR 가능성도 배제하지 않는다.
  6. 완전 사례의 채널·연령 구성이 전체 모집단과 어떻게 달라지는지 비교한다.
  7. 처리 방법을 선택하기 전에 후속 연락·수집 절차 개선과 민감도 분석 필요성을 기록한다.

9. 자주 틀리는 시험 함정

  1. 0과 NA를 같은 값으로 본다.
  2. NaN과 Inf를 모두 일반 NA라고만 본다.
  3. NA == NA로 결측을 검사한다.
  4. MAR를 결측이 어떤 변수와도 관계없는 상태로 해석한다.
  5. MNAR을 관측 변수만으로 확정할 수 있다고 본다.
  6. 결측률 전체 평균만 보고 집단·시간 패턴을 놓친다.
  7. na.rm = TRUE가 결측 편향을 해결한다고 본다.
  8. 구조적 해당 없음을 일반 미응답처럼 대치한다.
  9. 변수 수가 늘어도 완전 사례 수가 크게 줄지 않는다고 본다.
  10. 학습 데이터의 결측 처리만 하고 운영 결측을 감시하지 않는다.

11. 정답과 해설

문제 1 정답과 해설

NA는 관측되지 않은 값, NaN은 0/0 같은 정의되지 않은 수치 결과, Inf는 무한대다. 0은 실제 측정값일 수 있으므로 업무 정의 없이 결측으로 바꾸면 안 된다.

문제 2 정답과 해설

MCAR은 결측이 관측·미관측 값과 무관, MAR은 관측 변수로 조건을 주면 미관측 값과 추가 관련이 없다는 가정, MNAR은 관측 변수를 고려해도 미관측 값이나 미관측 요인과 관련된 경우다.

문제 3 정답과 해설

구조적 결측은 질문·측정 자체가 적용되지 않은 상태다. 일반 값으로 대치하면 존재하지 않는 의미를 만들고 분모와 집단 정의를 왜곡한다.

문제 4 정답과 해설

colSums(is.na(df))로 수, colMeans(is.na(df))로 비율을 구할 수 있다. 각 열의 행 수가 분모가 되며 필터가 있다면 함께 기록한다.

문제 5 정답과 해설

회귀는 관측 변수와 결측 여부의 관련성만 보여 준다. MNAR의 핵심인 관측되지 않은 실제 값과의 관계는 직접 관찰할 수 없고, MAR도 수집 지식과 가정이 필요하다.

문제 6 정답과 해설

관측값만으로 평균을 계산할 뿐 결측 행이 무작위인지, 관측된 표본이 모집단을 대표하는지 보장하지 않는다. 유효 표본 수와 결측 메커니즘을 검토해야 한다.

문제 7 정답과 해설

여러 변수 중 하나라도 결측인 행이 빠져 표본·검정력이 감소한다. 결측이 결과·집단과 관련되면 남은 표본 구성이 달라져 추정치가 편향될 수 있다.

문제 8 정답과 해설

시간대별 결측률, 연속 결측 길이, 장치·버전별 집중, 여러 센서의 동시 결측, 배포·장애 시점과의 일치, 늦게 도착한 값과 실제 미수집을 확인한다.

문제 9 정답과 해설

결측 코드·사유 표준화 → 분석 단위·중요 변수 확인 → 변수·행·동시·집단·시간 패턴 계산 → 수집 과정 조사 → MCAR/MAR/MNAR·구조적 결측 가설 → 표본·편향·운영 영향 평가 순이다.

12. 핵심 요약

  • 결측값의 유형과 발생 원인은 NA 표현뿐 아니라 MCAR·MAR·MNAR 메커니즘과 구조적 비적용, 센서·설문·조인·시스템 원인을 함께 구분하는 것이다.
  • 결측 패턴 확인은 변수·행별 수와 비율, 동시 결측, 집단·시간·장치·수집 경로별 집중과 연속성을 탐색하는 과정이다.
  • 결측이 분석에 미치는 영향은 표본 감소, 편향, 관계 왜곡, 불확실성 과소평가, 운영 입력 실패와 성능 저하다.
  • na.rm = TRUE는 관측값만 계산할 뿐 대표성·편향을 해결하지 않으며 관측 패턴만으로 MNAR을 판정할 수 없다.
  • 결측 처리를 선택하기 전에 코드 의미, 수집 과정, 메커니즘 가정과 분석·운영 영향을 기록해야 한다.
