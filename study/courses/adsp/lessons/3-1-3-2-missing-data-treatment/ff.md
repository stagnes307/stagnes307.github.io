# 3-1-3-2. 결측값 처리 방법

> **학습 범위**: 이 레슨은 ADsP `데이터분석 > R기초와 데이터 마트 > 결측값 처리와 이상값 검색` 중 **`완전 제거와 부분 제거`**, **`단순 대치`**, **`모델 기반 대치와 선택 기준`**을 다룬다. 결측 메커니즘·변수 역할·분석 목적에 맞춰 삭제와 대치 방법을 선택하고, 학습 데이터에서 추정한 처리 규칙을 평가·운영 데이터에 재현하는 것이 목표다.

결측률만 보고 방법을 자동 선택하면 안 된다. 같은 5% 결측도 무작위 센서 손실인지, 고위험 환자의 추적 중단인지에 따라 편향이 다르다. 이 레슨은 앞에서 수행한 결측 탐색과 원인 가설을 입력으로 사용한다. R 예제는 base R만 사용하며 결측 처리 전 원본을 보존한다.

---

## 1. 결측 처리의 기본 원칙

결측 처리는 존재하지 않는 “정답”을 만들어 내는 작업이 아니라 가정 아래 분석 가능한 정보를 구성하는 작업이다. 반드시 다음을 기록한다.

- 어떤 값·행을 왜 처리했는가?
- 결측 메커니즘을 어떻게 가정했는가?
- 처리 통계·모형을 어느 데이터에서 추정했는가?
- 표본 수·분포·집단 구성이 어떻게 변했는가?
- 대치값의 불확실성을 어떻게 반영했는가?
- 다른 합리적 방법에서도 결론이 유지되는가?

```text
결측 코드·원인 확인
      ↓
변수 역할과 분석 목적 확인
      ↓
삭제·단순 대치·모델 기반 후보 비교
      ↓
학습 자료에서 규칙 추정
      ↓
검증·운영 자료에 동일 적용
      ↓
분포·성능·민감도·운영 감시
```

목표변수의 결측을 평균으로 채워 가짜 정답을 만드는 것과 입력변수의 결측을 대치하는 것은 다르다. 지도학습에서는 라벨의 신뢰 가능한 재수집·제외·별도 반지도학습 설계를 검토한다.

## 2. 재현 가능한 예제 데이터

```r
train <- data.frame(
  id      = 1:6,
  age     = c(22, 35, NA, 41, 52, 47),
  income  = c(2800, NA, 3600, 5100, 5700, 6200),
  channel = c("web", "store", "web", NA, "store", "store"),
  churn   = c(0, 1, 0, 1, 0, 1)
)

test <- data.frame(
  id      = 7:9,
  age     = c(30, NA, 58),
  income  = c(NA, 4500, 9000),
  channel = c("web", "store", NA)
)
```

`train`은 처리값을 추정하는 학습 자료, `test`는 그 규칙을 적용할 새 자료다. 실제 분석에서는 학습·검증·최종 평가 분할을 문제 구조에 맞게 정한다.

## 3. 완전 제거와 부분 제거

## 3.1 완전 사례 제거

**`완전 제거와 부분 제거`** 중 완전 제거(listwise deletion, complete case analysis)는 선택한 분석 변수 중 하나라도 결측인 행을 분석에서 제외하는 방식이다.

```r
analysis_vars <- c("age", "income", "channel", "churn")
train_complete <- train[complete.cases(train[analysis_vars]), ]
nrow(train_complete)
```

예제에서는 완전한 행만 남아 표본이 감소한다. 장점은 구현과 설명이 단순하고 분석마다 같은 사례를 사용할 수 있다는 것이다. 하지만 결측이 많거나 특정 집단에 집중되면 검정력과 대표성이 크게 떨어진다.

완전 사례 분석이 비교적 타당할 가능성은 결측이 MCAR에 가깝고, 제거 비율이 작으며, 남은 사례가 목표 모집단을 대표하고, 효율 손실이 허용될 때다. MCAR 여부를 단순 결측률만으로 확정하지 않는다.

### 제거 전후 비교

```r
data.frame(
  group = c("all", "complete"),
  n = c(nrow(train), nrow(train_complete)),
  churn_rate = c(mean(train$churn), mean(train_complete$churn))
)
```

표본 수뿐 아니라 목표비율, 연령·채널·기간 구성이 어떻게 바뀌는지 비교한다.

## 3.2 부분 제거

부분 제거(pairwise deletion, available case analysis)는 계산에 필요한 변수 쌍이나 통계마다 사용 가능한 사례를 이용한다. 예를 들어 상관계수에서 각 변수 쌍의 완전한 행을 사용한다.

```r
numeric_data <- train[c("age", "income", "churn")]
cor(numeric_data, use = "pairwise.complete.obs")
```

표본을 더 활용하는 장점이 있지만 각 상관계수가 서로 다른 행에서 계산된다. 유효 표본 수가 다르고 상관행렬이 일관된 공분산 구조를 이루지 못할 수 있다. 이후 다변량 분석이 같은 표본을 요구한다면 해석이 어려워진다.

### 변수 제거

결측률이 높다고 변수를 자동 삭제하지 않는다. 업무적으로 핵심이고 결측 자체가 정보일 수 있다. 변수의 가치, 수집 비용, 대체 가능성, 운영 안정성, 결측 원인을 비교한다. 제거하면 분석 질문이 바뀌는지도 확인한다.

## 4. 단순 대치

**`단순 대치`**는 한 개의 대표값이나 간단한 규칙으로 결측을 채우는 방식이다. 빠르고 재현하기 쉽지만 불확실성을 줄여 보이고 변수 관계·분산을 왜곡할 수 있다.

## 4.1 평균·중앙값 대치

```r
age_median <- median(train$age, na.rm = TRUE)
income_median <- median(train$income, na.rm = TRUE)

train_imp <- train
test_imp <- test

train_imp$age[is.na(train_imp$age)] <- age_median
test_imp$age[is.na(test_imp$age)] <- age_median
train_imp$income[is.na(train_imp$income)] <- income_median
test_imp$income[is.na(test_imp$income)] <- income_median

c(age_median = age_median, income_median = income_median)
```

예상 중앙값은 나이 41, 소득 5100이다. 중요한 점은 test의 소득 9000까지 포함해 중앙값을 다시 계산하지 않는 것이다. 평가 자료의 분포 정보를 쓰면 누수가 생긴다.

평균은 대칭 분포에서 중심을 반영하지만 이상값에 민감하다. 중앙값은 치우친 자료와 이상값에 더 강건하지만 두 방법 모두 분산을 줄이고 다른 변수와의 관계를 약화시킬 수 있다.

## 4.2 최빈값 대치

범주형 변수에는 학습 자료의 최빈 범주를 사용할 수 있다.

```r
mode_value <- function(x) {
  tab <- table(x, useNA = "no")
  names(tab)[which.max(tab)]
}

channel_mode <- mode_value(train$channel)
train_imp$channel[is.na(train_imp$channel)] <- channel_mode
test_imp$channel[is.na(test_imp$channel)] <- channel_mode
channel_mode
```

예제에서는 `store`가 반환된다. 동률일 때 `which.max()`는 첫 항목을 고르므로 실제 파이프라인은 동률 규칙을 명시해야 한다. 희귀하지만 중요한 범주가 사라지거나 최빈 범주 비율이 부풀 수 있다.

## 4.3 상수·별도 범주 대치

“Unknown”, “미측정” 같은 별도 범주나 특정 상수를 사용할 수 있다. 결측 상태를 보존해 모델이 구분할 수 있지만, 미응답·해당 없음·수집 오류를 한 범주로 합치지 않는다. 수치형에 -999를 넣으면 거리·평균·회귀를 왜곡하므로 범주 지시변수와 혼동하지 않는다.

## 4.4 집단별 대치

연령대·지역·상품군별 중앙값처럼 관측 변수로 조건을 주어 대치할 수 있다. 집단 정의가 충분한 표본을 갖고 운영 시점에 이용 가능해야 한다. 지나치게 세분하면 일부 집단에 관측값이 없어 다시 결측이 생긴다. 전체 대체값으로 돌아가는 규칙을 둔다.

## 4.5 시계열의 인접값·보간

직전값 사용, 다음값 사용, 선형 보간은 시간 순서 자료에서 고려할 수 있다. 그러나 긴 센서 장애 구간이나 급격한 변화에서는 실제 변동을 평탄화한다. 미래값을 운영 예측에 사용하면 시간 누수가 될 수 있다. 결측 연속 길이와 허용 간격을 제한한다.

## 4.6 결측 지시변수

```r
train_imp$income_missing <- as.integer(is.na(train$income))
test_imp$income_missing <- as.integer(is.na(test$income))
```

대치 전 원본에서 지시변수를 만들어야 한다. 결측 자체가 수집 경로나 위험과 관련될 때 정보를 보존할 수 있다. 하지만 지시변수가 결측 원인 편향을 자동 해결하는 것은 아니며 운영에서도 같은 의미로 생성되어야 한다.

## 5. 모델 기반 대치와 선택 기준

**`모델 기반 대치와 선택 기준`**은 다른 관측 변수의 관계와 불확실성을 이용해 결측값 후보를 만드는 방법과 선택 원칙을 다룬다.

## 5.1 회귀 대치

관측 사례로 `income ~ age + channel` 같은 모형을 적합해 결측 소득을 예측한다. 단일 예측값만 넣으면 모형 관계가 지나치게 강해지고 잔차 불확실성이 사라질 수 있다. 비선형성·범주·이상값과 모형 오지정을 점검한다.

개념적 base R 예시:

```r
fit_rows <- complete.cases(train[c("income", "age", "channel")])
fit <- lm(income ~ age + channel, data = train[fit_rows, ])

target_rows <- is.na(train$income) &
               complete.cases(train[c("age", "channel")])
pred <- predict(fit, newdata = train[target_rows, ])
```

예제 표본은 매우 작으므로 이 결과를 실제 모형으로 신뢰하지 않는다. 코드는 절차를 보여 주기 위한 것이다.

## 5.2 최근접 이웃·핫덱 대치

유사한 관측 사례의 값을 사용한다. 실제 관측값을 넣어 범위를 보존할 수 있지만 거리 척도·변수 스케일, 이웃 수, 고차원 문제와 희귀 집단을 고려한다. 핫덱은 동일 층·집단의 기증자 값을 사용할 수 있다.

## 5.3 다중 대치

다중 대치(multiple imputation)는 결측값을 하나로 확정하지 않고 여러 개의 대치 데이터셋을 생성한다. 각 데이터셋을 분석한 뒤 추정치와 대치 간 변동을 결합해 결측 불확실성을 반영한다.

```text
결측 모형과 보조변수 설정
  → 서로 다른 대치 데이터 m개 생성
  → 각 데이터에서 동일 분석 수행
  → 추정치·분산 결합
  → 가정과 민감도 보고
```

다중 대치는 단순히 같은 평균을 여러 번 넣는 것이 아니다. 적절한 대치 모형, 변수 형태, 제약, 분석 모형과의 양립성을 검토해야 한다. MNAR이면 MAR 기반 대치만으로 충분하지 않을 수 있어 가정별 민감도 분석을 병행한다.

## 5.4 선택 기준표

| 기준 | 확인 질문 | 방법 선택 영향 |
|---|---|---|
| 메커니즘 | MCAR·MAR·MNAR·구조적 중 무엇인가 | 삭제·모형·민감도 필요성 |
| 결측 규모 | 변수·행·집단에 얼마나 집중되는가 | 정보 손실·모형 안정성 |
| 변수 역할 | 목표, 핵심 입력, 보조 변수인가 | 라벨 처리·대치 중요도 |
| 자료형·구조 | 수치·범주·시계열·군집 자료인가 | 대치 모형과 제약 |
| 분석 목적 | 평균 추정, 예측, 군집 중 무엇인가 | 분산·관계 보존 필요 |
| 운영 | 새 결측에 같은 규칙을 적용 가능한가 | 파이프라인·기본 동작 |
| 위험 | 편향·공정성·의사결정 영향은 무엇인가 | 집단별 검증·인간 검토 |

## 6. 처리 방법 검증

### 6.1 관측값 가리기 실험

관측된 일부 값을 학습 구조에 맞게 가리고 대치한 뒤 실제값과 비교할 수 있다. 완전 무작위 가리기만 하면 실제 결측 패턴을 반영하지 못할 수 있으므로 집단·시간 패턴을 고려한다.

### 6.2 분포와 관계 비교

처리 전 관측값과 처리 후 전체의 평균·분산·분위수·범주 비율, 변수 간 관계를 비교한다. 대치값이 한 점에 몰리지 않는지 본다.

### 6.3 분석 결과 민감도

완전 사례, 중앙값+지시변수, 모델 기반·다중 대치 등 합리적 후보에서 추정 방향·크기·성능과 집단별 결과가 얼마나 달라지는지 본다.

### 6.4 운영 검증

운영 결측률이 학습 범위를 넘는지, 처음 보는 범주·전체 변수 결측 때 어떻게 동작하는지 시험한다. 대치 통계의 버전과 재계산 주기, 경보·중단 기준을 둔다.

## 7. 처리 의사결정 절차

1. 원본과 결측 사유 코드를 보존한다.
2. 분석 변수·목표·기준 시점과 결측 패턴·메커니즘 가설을 확인한다.
3. 삭제 시 표본·집단·성과 변화를 계산한다.
4. 단순·모델 기반 후보의 가정과 운영 가능성을 비교한다.
5. 데이터 분할 뒤 학습 자료에서만 대치 규칙을 적합한다.
6. 검증·평가·운영 데이터에 고정 규칙을 적용한다.
7. 분포·관계·성능·공정성과 민감도를 비교한다.
8. 선택 근거·잔여 위험·감시·재검토 조건을 기록한다.

## 8. 사례: 소득 결측이 있는 이탈 예측

소득은 채널·연령별 결측률이 다르고 이탈과도 관련되어 보인다.

- 완전 제거: 웹·젊은 고객이 더 많이 빠지는지 확인한다. 구성이 달라지면 편향 위험이 있다.
- 전체 중앙값: 구현은 쉽지만 채널·연령 관계와 분산이 줄어든다.
- 집단 중앙값+지시변수: 관측된 채널·연령을 활용하고 결측 상태를 보존하되 작은 집단의 안정성을 확인한다.
- 모델 기반/다중 대치: 여러 관측 변수를 활용하고 불확실성을 반영할 수 있지만 모형 가정·운영 복잡도가 증가한다.

학습 자료에서 대치 규칙을 만들고 시간상 이후 평가 자료에 적용한다. 완전 사례와 후보 처리에서 전체·채널별 성능과 확률 교정이 얼마나 다른지 비교한다. 소득 미응답이 실제 고소득과 관련된 MNAR 가능성이 있으면 가정별 민감도와 추가 수집을 검토한다.

## 9. 체크리스트

- [ ] 결측 코드·사유와 원본을 보존했다.
- [ ] 목표변수와 입력변수 결측을 구분했다.
- [ ] 삭제 전후 표본 수·집단·목표 분포를 비교했다.
- [ ] 부분 제거의 통계별 유효 표본 수를 보고했다.
- [ ] 단순 대치가 분산·관계를 줄일 수 있음을 검토했다.
- [ ] 대치 규칙을 데이터 분할 후 학습 자료에서 추정했다.
- [ ] 결측 지시변수는 대치 전 원본에서 만들었다.
- [ ] 모델 기반 대치의 가정과 대치 불확실성을 평가했다.
- [ ] 여러 합리적 방법에서 결론의 민감도를 확인했다.
- [ ] 운영 결측 변화·규칙 버전·중단 기준을 감시한다.

## 10. 자주 틀리는 시험 함정

1. 완전 제거는 결측 메커니즘과 관계없이 불편향이라고 본다.
2. 부분 제거의 모든 통계가 같은 표본을 사용한다고 본다.
3. 결측률이 높은 변수는 업무 가치와 무관하게 자동 삭제한다.
4. 평균 대치가 원래 분산과 상관을 보존한다고 본다.
5. 범주형 결측에 숫자 -999를 넣고 연속값처럼 계산한다.
6. 평가 데이터까지 포함해 대치 평균·중앙값을 계산한다.
7. 목표변수 결측을 평균으로 채워 정답으로 사용한다.
8. 다중 대치를 같은 값의 반복 복사로 이해한다.
9. 모델 기반 대치는 언제나 실제값을 복원한다고 본다.
10. 대치 뒤 분포·집단 성능·운영 결측을 확인하지 않는다.

### 문제 3

### 문제 4

### 문제 5

## 12. 정답과 해설

### 문제 1 정답과 해설

결측이 MCAR에 가깝고 제거 비율이 작으며 남은 사례가 모집단을 대표하고 분석에 필요한 표본·검정력이 유지될 때 비교적 타당할 수 있다.

### 문제 2 정답과 해설

각 계산에서 이용 가능한 사례를 더 많이 쓸 수 있다. 그러나 통계마다 표본과 크기가 달라 비교가 어렵고 상관행렬이 일관되지 않을 수 있다.

### 문제 3 정답과 해설

대표값에 관측이 몰려 분산을 작게 만들고 다른 변수와의 상관·회귀 관계를 약화하거나 왜곡할 수 있다. 중앙값은 이상값에는 강하지만 불확실성 문제는 남는다.

### 문제 4 정답과 해설

검증·평가 자료의 평균·범주 분포가 처리 규칙에 들어가면 미래 평가 정보를 미리 사용한 누수가 된다. 학습에서 고정한 규칙을 나머지 자료에 적용해야 한다.

### 문제 5 정답과 해설

동률일 때 선택 규칙과 희귀 범주의 손실, 최빈 범주 비율의 과대, 운영에 새로운 범주가 나타날 때의 처리를 확인한다.

### 문제 6 정답과 해설

대치 전 원본의 `is.na()`로 만든다. 결측 상태 정보를 보존하지만 원인 편향을 자동 제거하지 않고 운영에서 결측 의미가 바뀌면 관계도 바뀐다.

### 문제 7 정답과 해설

단일 회귀 대치는 보통 하나의 예측값을 넣어 대치 불확실성을 축소한다. 다중 대치는 여러 가능한 값을 가진 데이터셋을 분석·결합해 대치 간 변동을 반영한다.

### 문제 8 정답과 해설

결측 메커니즘, 규모·패턴, 변수 역할, 자료형·구조, 분석 목적, 운영 재현성, 편향·공정성 위험과 모형 가정을 고려한다.

### 문제 9 정답과 해설

원본 보존·진단 → 삭제 영향 계산 → 후보 가정 비교 → 데이터 분할 → 학습에서 규칙 적합 → 검증·평가에 적용 → 분포·성능·민감도 비교 → 운영 감시·재검토 순이다.

## 13. 핵심 요약

- **`완전 제거와 부분 제거`**는 구현이 단순하지만 표본·검정력·대표성 손실과 통계마다 다른 표본 사용 위험을 평가해야 한다.
- **`단순 대치`**는 평균·중앙값·최빈값·상수·집단·시간 규칙을 쓰며 빠르지만 분산·관계와 불확실성을 왜곡할 수 있다.
- **`모델 기반 대치와 선택 기준`**은 관측 변수 관계와 다중 대치의 불확실성을 활용하되 메커니즘·자료 구조·목적·운영·위험에 맞춰 선택하는 것이다.
- 처리 규칙은 분할 뒤 학습 자료에서 추정하고 평가·운영 자료에 동일 적용해 데이터 누수를 막는다.
- 하나의 처리 결과만 믿지 말고 삭제·대치 후보의 분포, 추정·성능, 집단 영향과 MNAR 가정 민감도를 비교한다.
