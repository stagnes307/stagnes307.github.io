# 3-1-3-3. 이상값 탐지와 처리

> **학습 범위**: 이 레슨은 ADsP `데이터분석 > R기초와 데이터 마트 > 결측값 처리와 이상값 검색` 중 **`이상값의 원인과 영향`**, **`통계량과 시각화를 이용한 탐지`**, **`이상값 처리 의사결정`**을 다룬다. 다른 관측과 크게 다른 값이 오류인지 희귀한 정상 사건인지 조사하고, 단변량·다변량·시간 맥락에서 탐지한 뒤 분석 목적과 영향에 맞춰 처리하는 것이 목표다.

이상값(outlier)은 곧 잘못된 값이 아니다. 대형 거래, 극한 기상, 실제 사기처럼 드물지만 분석 목적상 핵심일 수 있다. 탐지 규칙은 조사할 후보를 표시할 뿐 자동 삭제 명령이 아니다. R 예제는 base R만 사용한다.

---

## 1. 이상값의 의미

이상값은 다른 관측치의 전반적 패턴에서 멀리 떨어지거나 기대 관계를 크게 벗어난 관측이다. 판단 맥락에 따라 다음을 구분한다.

| 유형 | 예시 | 기본 판단 |
|---|---|---|
| 오류 이상값 | 나이 250세, 단위 변환 실패 | 원천 확인·수정 후보 |
| 희귀 정상값 | 실제 고액 주문, 기록적 폭우 | 보존·별도 모델 후보 |
| 조건부 이상값 | 여름 30℃는 정상, 겨울 30℃는 이상 | 시간·집단 조건 필요 |
| 집단 이상 | 개별 값은 정상이나 연속 패턴이 비정상 | 순서·구간 분석 필요 |
| 영향점 | 회귀계수를 크게 바꾸는 관측 | 민감도·영향 통계 확인 |
| 새로운 사건 | 기존 분포에 없던 장비 상태 | 운영 경보·개념 변화 검토 |

극단값(extreme value)은 값의 크기·순위 관점이고 영향점(influential point)은 분석 결과 변화 관점이다. 값이 극단적이어도 회귀선에 잘 놓이면 영향이 작을 수 있고, 설명변수 공간의 특이한 한 점은 값이 덜 극단적이어도 계수를 크게 바꿀 수 있다.

## 2. 이상값의 원인과 영향

## 2.1 발생 원인

**`이상값의 원인과 영향`** 중 원인은 데이터 생성·수집·처리·실제 현상으로 나눠 조사한다.

- 입력 오류: 소수점·부호·자리수 오입력
- 단위 오류: 원과 천원, kg과 g, 초와 밀리초 혼합
- 센서·통신 오류: 포화, 보정 실패, 패킷 깨짐
- 조인 오류: 잘못된 키로 다른 사람·시점의 값 결합
- 집계 오류: 다대다 조인으로 금액 중복
- 시스템 변경: 코드·측정 장치·정책 변화
- 표본 혼합: 서로 다른 모집단·세그먼트를 한 분포로 분석
- 자연 변동: 실제 희귀 사건이나 꼬리가 긴 분포
- 부정·장애: 분석이 찾으려는 핵심 비정상 사건

원인을 모르면 처리도 정당화하기 어렵다. “상자그림 밖이므로 삭제”는 업무 근거가 아니다.

## 2.2 통계에 미치는 영향

이상값은 평균, 분산, 상관, 회귀계수와 거리 기반 방법에 큰 영향을 줄 수 있다. 중앙값·IQR·MAD 같은 강건 통계량은 상대적으로 덜 민감하다.

```r
x <- c(10, 11, 12, 12, 13, 14, 15, 16, 100)
c(mean = mean(x), median = median(x), sd = sd(x), mad = mad(x))
```

평균은 약 22.56으로 대부분의 10~16 범위를 대표하지 못하지만 중앙값은 13이다. 표준편차도 약 29로 커진다. 이상값이 표준편차 자체를 부풀려 z점수 탐지에서 숨는 마스킹(masking)이 생길 수 있다.

## 2.3 분석·운영 영향

- 회귀선과 예측이 소수 관측에 끌린다.
- 군집 중심과 거리, 주성분 방향이 달라진다.
- 정규성·등분산 가정이 깨질 수 있다.
- 평균 기반 요약이 전형적인 값을 잘못 표현한다.
- 학습에서 제거한 범위가 운영에 나타나면 모델이 외삽한다.
- 정상 희귀 사건을 삭제하면 사기·장애 탐지 능력이 사라진다.

영향은 분석 목적에 따라 다르므로 처리 전후 결과를 비교한다.

## 3. 통계량과 시각화를 이용한 탐지

**`통계량과 시각화를 이용한 탐지`**는 하나의 임계값에 의존하지 않고 분포·집단·관계·시간을 여러 관점에서 살피는 과정이다.

## 3.1 범위와 업무 규칙

먼저 물리·업무상 불가능한 범위를 검사한다.

```r
age <- c(18, 32, 47, 250, -3)
which(age < 0 | age > 120)
```

범위 규칙은 가장 설명 가능하지만, 120세 기준 같은 값도 분석 대상·시대·정의에 맞아야 한다. 값이 범위 밖이면 원천·단위를 확인하고 자동으로 경계값에 붙이지 않는다.

## 3.2 IQR 규칙

사분위범위는 `IQR = Q3 - Q1`이다. 흔한 탐색 규칙은 다음 경계 밖을 후보로 표시한다.

\[
\text{Lower}=Q_1-1.5\,IQR,\qquad
\text{Upper}=Q_3+1.5\,IQR
\]

```r
q <- quantile(x, c(0.25, 0.75), names = FALSE)
iqr <- IQR(x)
bounds <- c(lower = q[1] - 1.5 * iqr,
            upper = q[2] + 1.5 * iqr)
x[x < bounds[1] | x > bounds[2]]
bounds
```

예제의 Q1=12, Q3=15, IQR=3이고 경계는 7.5와 19.5이므로 100이 후보가 된다. 표본이 작거나 이산·꼬리가 긴 분포에서는 정상값도 많이 표시될 수 있다.

## 3.3 z점수

\[
z_i=\frac{x_i-\bar{x}}{s}
\]

```r
z <- as.numeric(scale(x))
data.frame(x = x, z = round(z, 2))
```

평균과 표준편차에 민감하며 정규 분포에 가까운 자료에서 해석하기 쉽다. 예제의 100은 표준편차를 크게 만들어 z가 약 2.67이라 `|z| > 3` 규칙에 잡히지 않는다. 임계값 3은 보편 법칙이 아니다.

## 3.4 중앙값과 MAD

MAD는 중앙값에서 절대편차의 중앙값을 바탕으로 한 강건한 산포다. R의 `mad()`는 기본적으로 정규분포 일관성을 위한 상수를 곱한다.

```r
robust_z <- (x - median(x)) / mad(x)
data.frame(x = x, robust_z = round(robust_z, 2))
```

예제에서 중앙값은 13, R 기본 MAD는 약 2.97이고 100의 강건 점수는 약 29.34다. MAD가 0인 경우 동일값이 많다는 뜻이므로 별도 규칙이 필요하다.

## 3.5 시각화

```r
par(mfrow = c(1, 3))
boxplot(x, main = "Boxplot")
hist(x, breaks = 8, main = "Histogram", xlab = "x")
qqnorm(x); qqline(x, col = 2)
par(mfrow = c(1, 1))
```

- 상자그림: 사분위와 후보를 빠르게 표시하지만 원인은 말해 주지 않는다.
- 히스토그램·밀도: 꼬리, 다봉성, 변환 필요성을 본다.
- Q-Q 그림: 기준 분포와의 전반적 차이를 본다.
- 산점도: 두 변수 관계에서 벗어난 점과 집단 구조를 본다.
- 시계열 그림: 급변, 수준 변화, 연속 비정상 구간을 본다.

축 범위가 너무 넓거나 로그 변환이 부적절하면 패턴이 숨을 수 있다. 원자료와 합리적 변환을 함께 본다.

## 3.6 집단별 탐지

전체 분포에서 정상처럼 보여도 같은 상품·장치·연령대 안에서는 이상할 수 있다. 반대로 서로 다른 세그먼트를 합치면 한 집단 전체가 이상처럼 보인다.

```r
df <- data.frame(
  group = rep(c("A", "B"), each = 5),
  value = c(10, 11, 12, 13, 30, 100, 105, 110, 115, 120)
)
boxplot(value ~ group, data = df)
```

A의 30은 그룹 내 후보지만 전체 값만 보면 B의 정상 범위와 겹친다. 그룹 정의가 분석·운영 시점에 알려지는지도 확인한다.

## 3.7 다변량 이상값

각 변수는 정상 범위여도 조합이 드물 수 있다. 표준화 거리, 마할라노비스 거리, 군집·밀도 기반 방법을 사용할 수 있다. 마할라노비스 거리는 변수 상관을 고려하지만 평균·공분산 자체가 이상값에 민감하고 표본·차원 조건이 필요하다.

```r
m <- data.frame(a = c(1, 2, 3, 4, 8),
                b = c(2, 4, 6, 8, 3))
d2 <- mahalanobis(m, center = colMeans(m), cov = cov(m))
data.frame(m, distance2 = round(d2, 2))
```

거리 순위는 조사 후보를 제공한다. 카이제곱 임계값을 쓰려면 다변량 정규성 등 가정을 검토한다.

## 3.8 영향점 진단

회귀에서는 잔차, 레버리지, Cook 거리 등을 함께 본다.

```r
fit <- lm(b ~ a, data = m)
influence.measures(fit)
cooks.distance(fit)
```

잔차가 큰 점과 설명변수 공간에서 멀리 있는 점이 다를 수 있다. 작은 표본에서 자동 임계값으로 삭제하지 않고 해당 행과 계수 민감도를 조사한다.

## 4. 이상값 처리 의사결정

**`이상값 처리 의사결정`**은 원인, 유효성, 분석 목적, 영향과 운영 가능성에 따라 수정·보존·변환·강건 분석·제외 등을 선택하는 과정이다.

## 4.1 원천 확인과 수정

입력·단위·조인 오류가 확인되고 신뢰할 원값이 있으면 수정한다. 추측값으로 덮지 않는다. 원값이 없으면 결측으로 전환할지, 해당 행을 제외할지 분석 영향에 따라 판단한다.

## 4.2 그대로 보존

희귀하지만 정상이고 목표 모집단에 포함되면 보존한다. 대형 거래처럼 별도 업무 규칙이 필요한 경우 세그먼트 분석이나 상호작용을 사용한다.

## 4.3 변환

양의 꼬리가 긴 값에 로그 변환을 적용하면 규모 차이를 완화할 수 있다.

```r
log_x <- log1p(x)
```

`log1p(x)`는 `log(1+x)`를 안정적으로 계산한다. 음수·단위·0의 의미와 해석 변화, 운영 역변환을 확인한다. 변환은 오류를 고치는 방법이 아니다.

## 4.4 경계 조정·윈저화

상하 분위수 등으로 값을 제한할 수 있다. 극단 영향은 줄지만 값의 순위·분포를 인위적으로 바꾸고 동일 경계값을 많이 만든다. 경계는 평가 자료를 보고 조정하지 않고 학습 자료에서 정해 고정한다.

## 4.5 강건한 방법

중앙값·절사평균, 강건 회귀, 나무 기반 방법 등 이상값 영향이 덜한 요약·모형을 고려한다. 강건하다는 이유로 데이터 오류 조사를 생략하지 않는다.

## 4.6 제외

분석 모집단 밖이거나 복구 불가능한 오류라는 근거가 있을 때 제외한다. 제외 전후 표본 구성, 결과·계수·집단 영향과 재현 규칙을 보고한다. “결과가 좋아져서” 제외하면 선택 편향이다.

## 4.7 별도 모델·경보

정상 거래와 고액 거래의 생성 과정이 다르면 분리 모델을 쓰거나 이상 자체를 탐지 목표로 삼는다. 경보 처리 인력과 오탐 비용을 포함한다.

## 5. 처리 판단 절차

1. 분석 단위·변수 정의·물리·업무 범위를 확인한다.
2. IQR·MAD·z점수·시각화·관계·시간으로 후보를 표시한다.
3. 원천 시스템, 단위, 조인, 수집·정책 변경과 실제 사건을 조사한다.
4. 오류, 희귀 정상, 조건부·집단 이상, 영향점을 분류한다.
5. 보존·수정·변환·강건 방법·경계 조정·제외·별도 분석 후보를 비교한다.
6. 처리 규칙은 학습 데이터에서 정하고 검증·운영에 고정 적용한다.
7. 처리 전후 분포, 추정·모델 성능, 집단 결과와 업무 비용을 비교한다.
8. 근거·규칙·버전·잔여 위험·운영 경보를 기록한다.

## 6. 사례: 고액 거래 분석

거래금액 100배의 관측 세 건이 발견되었다.

- 첫 관측은 원천이 천원인데 원으로 변환하면서 다시 1000을 곱한 오류다. 원천 근거로 수정한다.
- 둘째는 실제 법인 대량구매다. 정상 모집단에 포함되므로 삭제하지 않고 고객 유형을 반영하거나 별도 세그먼트로 분석한다.
- 셋째는 계정 탈취 의심 거래다. 정상 평균 분석에서는 영향이 크지만 사기 탐지에서는 핵심 목표다. 경보 사례로 보존한다.

같은 숫자 크기라도 원인과 분석 목표에 따라 처리가 다르다. 처리 전후 평균·회귀·분류 성능과 집단별 오류를 비교한다.

## 8. 자주 틀리는 시험 함정

1. 상자그림 수염 밖의 값을 모두 오류로 본다.
2. 이상값과 영향점을 같은 개념으로 본다.
3. z점수 3을 모든 분포의 절대 기준으로 사용한다.
4. 이상값이 평균·표준편차를 키워 z점수에 숨을 수 있음을 놓친다.
5. 서로 다른 집단을 합쳐 하나의 경계로 판단한다.
6. 단변량 정상 범위면 다변량 이상일 수 없다고 본다.
7. 로그 변환이 입력·단위 오류를 수정한다고 본다.
8. 평가 결과가 좋아지는 경계를 평가 자료에서 선택한다.
9. 실제 사기·장애 같은 목표 사건을 이상이라는 이유로 삭제한다.
10. 제외 후 표본·계수·집단 영향과 운영 규칙을 보고하지 않는다.

## 9. 확인 문제

### 문제 1

이상값, 극단값, 영향점의 차이를 설명하시오.

### 문제 2

이상값의 발생 원인을 네 가지 범주로 예시하시오.

### 문제 3

IQR 규칙의 상·하한 공식을 쓰고 예제 x의 후보를 찾으시오.

### 문제 4

예제의 100이 `|z| > 3`에 잡히지 않을 수 있는 이유는 무엇인가?

### 문제 5

MAD 기반 탐지의 장점과 주의점을 쓰시오.

### 문제 6

단변량으로 정상이어도 다변량 이상일 수 있는 이유는 무엇인가?

### 문제 7

이상값을 삭제하기 전에 비교할 처리 대안을 쓰시오.

### 문제 8

평가 데이터에서 윈저화 경계를 정하면 안 되는 이유는 무엇인가?

### 문제 9

이상값 후보 탐지부터 처리·운영 감시까지의 절차를 요약하시오.

## 10. 정답과 해설

### 문제 1 정답과 해설

이상값은 전체 패턴에서 벗어난 관측, 극단값은 분포의 매우 크거나 작은 값, 영향점은 포함 여부가 추정·모델을 크게 바꾸는 관측이다. 서로 겹칠 수 있지만 동일하지 않다.

### 문제 2 정답과 해설

입력·단위 오류, 센서·통신 오류, 조인·집계 오류, 시스템·정책 변경, 모집단 혼합, 실제 희귀 사건·사기·장애를 들 수 있다.

### 문제 3 정답과 해설

하한은 `Q1 - 1.5×IQR`, 상한은 `Q3 + 1.5×IQR`이다. x의 Q1=12, Q3=15, IQR=3으로 경계는 7.5와 19.5이며 100이 후보다.

### 문제 4 정답과 해설

100 자체가 평균과 표준편차를 크게 올려 자신의 표준화 거리를 줄이는 마스킹이 생긴다. 예제 z는 약 2.67로 3보다 작다.

### 문제 5 정답과 해설

중앙값 기반이라 극단값에 강건하다. 다만 MAD가 0인 반복값 자료, 작은 표본, 다봉·집단 혼합에서는 별도 규칙과 시각적 확인이 필요하다.

### 문제 6 정답과 해설

각 변수 값은 흔해도 변수들의 조합이 상관 구조에서 매우 드물 수 있다. 산점도나 상관을 고려한 거리·모형 잔차가 이를 찾는다.

### 문제 7 정답과 해설

원천 수정, 그대로 보존, 세그먼트·별도 모델, 로그 등 변환, 강건 통계·모형, 경계 조정과 결측 전환을 원인·목적에 맞게 비교한다.

### 문제 8 정답과 해설

평가 결과에 유리한 경계를 골라 최종 성능을 과대평가하는 누수가 생긴다. 학습 자료에서 규칙을 정해 평가·운영에 고정 적용해야 한다.

### 문제 9 정답과 해설

정의·범위 확인 → 통계·시각화 후보 표시 → 원천·업무 원인 조사 → 오류·희귀 정상·영향 분류 → 처리 후보 비교 → 학습에서 규칙 결정 → 전후 민감도 검증 → 근거·운영 경보 기록 순이다.

## 11. 핵심 요약

- **`이상값의 원인과 영향`**은 입력·단위·센서·조인 오류와 실제 희귀 사건을 구분하고 평균·분산·모델·운영에 주는 영향을 평가하는 것이다.
- **`통계량과 시각화를 이용한 탐지`**는 업무 범위, IQR·z점수·MAD, 상자그림·분포·산점도·시계열, 다변량 거리와 영향 통계를 결합한다.
- **`이상값 처리 의사결정`**은 자동 삭제가 아니라 원천 수정, 보존, 변환, 강건 방법, 경계 조정, 제외, 별도 모델을 원인·목적에 따라 선택하는 과정이다.
- 탐지 임계값은 후보 조사 규칙이며 집단·분포·표본과 운영 조건에 따라 해석한다.
- 처리 규칙은 학습 자료에서 정하고 처리 전후 추정·성능·집단 영향과 운영 이상률을 비교·기록해야 한다.
