# 3-2-1-2. 자료의 척도와 표본추출

> **학습 범위**: 이 레슨은 ADsP `데이터분석 > 통계분석 > 통계학 개론` 중 **`명목·서열·등간·비율 척도`**, **`확률 표본추출`**, **`표본오차와 비표본오차`**를 다룬다. 변수의 숫자가 허용하는 비교·연산을 척도로 판단하고, 모집단의 각 단위가 알려진 확률로 선택되는 표본설계를 구분하며, 표본 변동과 조사 과정의 오류를 분리하는 것이 목표다.

숫자로 코딩되었다고 모두 평균을 낼 수 있는 것은 아니다. 고객번호 100과 200의 차이는 양적 거리를 뜻하지 않고, 만족도 1~5는 순서는 있지만 간격이 같다고 보장되지 않는다. 표본도 “무작위처럼 보임”이 아니라 선택확률과 절차가 명시되어야 확률표본이다.

---

## 1. 측정 척도의 의미

척도(scale of measurement)는 값이 어떤 정보와 연산을 보존하는지 나타낸다. 높은 수준의 척도는 낮은 수준의 정보를 포함하지만, 실제 측정 정의와 변환에 따라 판단해야 한다.

| 척도 | 보존 정보 | 의미 있는 비교·연산 | 대표 예 |
|---|---|---|---|
| 명목 | 같음·다름 | 빈도, 비율, 최빈값 | 지역, 혈액형, 고객번호 |
| 서열 | 순서 | 대소, 중앙값, 분위수 | 등급, 순위, 단일 리커트 문항 |
| 등간 | 순서+같은 간격 | 차이, 평균, 표준편차 | 섭씨온도, 달력 연도 |
| 비율 | 등간+절대적 0 | 비율, 곱·나눗셈 포함 | 길이, 질량, 매출, 경과시간 |

## 2. 명목·서열·등간·비율 척도

## 2.1 명목척도

**`명목·서열·등간·비율 척도`** 중 명목척도는 범주를 구분하는 이름만 제공한다. 숫자 코드는 라벨일 뿐 크기·간격 의미가 없다.

- 고객번호 200이 100보다 두 배 큰 고객이 아니다.
- 우편번호 평균은 지역의 중심을 뜻하지 않는다.
- 성별·상품유형은 빈도·비율·최빈값·교차표로 요약한다.

R에서는 범주형으로 명시한다.

```r
region_code <- factor(c(1, 2, 1, 3),
                      levels = c(1, 2, 3),
                      labels = c("Seoul", "Busan", "Other"))
table(region_code)
prop.table(table(region_code))
```

## 2.2 서열척도

서열척도는 범주 사이 순서는 알지만 간격이 같다고 보장하지 않는다.

- 경주 1·2·3위
- 위험 등급 낮음·중간·높음
- 교육 수준 범주
- “매우 불만–불만–보통–만족–매우 만족” 단일 문항

1위와 2위의 차이가 2위와 3위 차이와 같지 않다. 중앙값·분위수·순위 기반 방법이 자연스럽다. 실무에서 여러 리커트 문항 합계를 근사적 등간으로 다루기도 하지만, 척도 구성·신뢰도·목적에 대한 근거가 필요하며 단일 문항이 자동 등간이 되는 것은 아니다.

```r
risk <- ordered(c("low", "high", "medium", "low"),
                levels = c("low", "medium", "high"))
table(risk)
```

## 2.3 등간척도

등간척도는 값 차이가 같은 양을 의미하지만 0이 절대적 부재를 뜻하지 않는다.

섭씨 20℃와 10℃의 차이 10℃는 30℃와 20℃의 차이와 같지만, 20℃가 10℃보다 “두 배 따뜻하다”고 할 수 없다. 섭씨 0℃는 열에너지의 부재가 아니기 때문이다.

달력 연도도 2020년과 2010년 차이는 10년이지만 2020년이 1010년의 두 배라는 비율 해석은 의미 없다.

## 2.4 비율척도

비율척도는 절대적 0이 있어 비율 비교가 의미 있다.

- 질량 10kg은 5kg의 두 배
- 판매량 0개는 판매 없음
- 경과시간 20분은 10분의 두 배
- 온도 K는 물리적 절대영점 기준에서 비율 해석 가능

그러나 매출 증가율에서 기준값 0, 음수 이익, 환율처럼 실제 업무 변수를 다룰 때는 분모와 해석을 확인한다. 척도가 높다고 모든 통계모형 가정이 자동 충족되는 것은 아니다.

## 2.5 변환으로 척도가 바뀔 수 있다

나이는 비율척도지만 “청년·중년·고령”으로 구간화하면 서열척도가 되고 정보가 줄어든다. 상품 가격 순위만 저장하면 원래 가격 차이와 비율을 복원할 수 없다. 변수 이름이 아니라 현재 데이터가 보존하는 정보를 기준으로 판단한다.

## 3. 확률 표본추출의 원리

**`확률 표본추출`**은 모집단 각 단위가 표본에 포함될 알려진 0이 아닌 확률을 가지며, 무작위 장치로 선택되는 설계다. 선택확률을 알아야 설계가중치와 표본오차를 계산하고 모집단으로 추론할 근거를 마련할 수 있다.

### 표본추출틀

추출할 모집단 단위의 목록이나 구조다. 고객 명부, 주소 목록, 학교 목록 등이 해당한다. 중복·누락·폐업 단위가 있으면 포함오차가 생긴다. 완벽한 무작위 추출도 불완전한 틀 밖의 사람을 대표하지 못한다.

## 4. 단순무작위추출

단순무작위추출(SRS)은 크기 n의 가능한 모든 표본이 같은 선택확률을 갖도록 뽑는 방식이다.

```r
frame <- data.frame(
  id = 1:20,
  stratum = rep(c("A", "B"), each = 10),
  cluster = rep(1:5, each = 4)
)

set.seed(307)
srs_id <- sample(frame$id, size = 5, replace = FALSE)
srs_id
```

구조가 단순하고 추론이 명확하지만 모집단 목록이 필요하고 희귀 집단이 표본에 적게 포함될 수 있다.

복원추출은 뽑은 단위를 다시 넣어 같은 단위가 여러 번 선택될 수 있고, 비복원추출은 한 번만 선택된다. 일반적인 유한 조사 표본은 비복원인 경우가 많다.

## 5. 계통추출

계통추출(systematic sampling)은 정렬된 목록에서 무작위 시작점을 고르고 일정 간격 k마다 선택한다. \(k \approx N/n\)이다.

```r
N <- nrow(frame)
n <- 5
k <- N / n
set.seed(307)
start <- sample(1:k, 1)
systematic_id <- seq(start, N, by = k)
systematic_id
```

목록 전체에 고르게 퍼지고 실행이 쉽다. 그러나 목록의 주기성과 추출 간격이 맞으면 편향될 수 있다. 예를 들어 매 네 번째 행마다 특정 교대조가 반복되면 해당 집단만 선택될 수 있다.

N이 n으로 나누어떨어지지 않는 경우 순환 계통추출 등 정확한 절차를 설계한다. 임의 반올림으로 포함확률을 모호하게 만들지 않는다.

## 6. 층화추출

층화추출(stratified sampling)은 모집단을 겹치지 않는 층으로 나누고 각 층에서 확률표본을 뽑는다. 층 내 동질성이 높고 층 간 차이가 크면 추정 정밀도를 높일 수 있으며, 중요한 소수집단을 보장할 수 있다.

```r
set.seed(307)
stratified_id <- unlist(lapply(split(frame$id, frame$stratum),
                               function(ids) sample(ids, 3)))
stratified_id
```

각 층에서 3명씩 뽑았으므로 원래 층 크기와 다른 비례일 수 있다. 모집단 추정에는 층별 선택확률의 역수인 가중치를 반영한다.

- 비례층화: 층 크기에 비례해 표본 배분
- 불비례층화: 희귀·중요 층을 더 많이 뽑음
- 최적배분: 층 크기·변동·조사비용을 고려

층은 모든 단위의 층 정보가 추출 전에 알려져야 한다.

## 7. 군집추출과 다단계추출

군집추출(cluster sampling)은 학교·지역처럼 자연스러운 집단을 먼저 표본으로 뽑고 선택 군집의 모든 단위 또는 일부를 조사한다.

```r
set.seed(307)
chosen_clusters <- sample(unique(frame$cluster), size = 2)
cluster_sample <- frame[frame$cluster %in% chosen_clusters, ]
cluster_sample
```

전국 개인 목록 없이 지역·학교 목록으로 조사할 수 있어 비용을 줄인다. 그러나 같은 군집 구성원은 비슷해 정보 중복이 커지고 단순무작위보다 표본오차가 클 수 있다. 분석에서 군집 설계와 군집 수를 반영해야 한다.

층화는 모든 층에서 표본을 뽑아 층 차이를 통제하려는 반면, 군집은 일부 군집을 선택해 조사 비용을 줄이는 경우가 많다. 시험에서 둘을 혼동하지 않는다.

다단계추출은 지역 → 학교 → 학생처럼 여러 단계에서 확률추출한다. 최종 포함확률은 각 단계 조건부 선택확률의 곱으로 계산한다.

## 8. 비확률 표본과의 구분

편의표본, 판단표본, 할당표본, 눈덩이표본은 포함확률을 알기 어렵다. 접근이 어려운 집단 탐색이나 초기 연구에 유용할 수 있지만 확률표본 공식으로 표본오차를 계산하거나 모집단 대표성을 자동 주장할 수 없다.

“온라인에서 무작위로 보이는 응답”은 응답자가 링크를 볼·참여할 확률이 알려지지 않으므로 단순무작위표본이 아니다.

## 9. 표본오차와 비표본오차

## 9.1 표본오차

**`표본오차와 비표본오차`** 중 표본오차(sampling error)는 모집단 전체가 아니라 표본을 관측해 통계량이 모수와 우연히 달라지는 오차다. 확률표본에서는 설계에 따라 표준오차로 변동을 추정할 수 있다.

단순무작위표본에서 평균의 표준오차는 독립·동일분포 근사에서

\[
SE(\bar X) \approx \frac{s}{\sqrt n}
\]

이다. 유한 모집단에서 비복원 추출 비율이 크면 유한모집단수정

\[
\sqrt{\frac{N-n}{N-1}}
\]

을 곱할 수 있다. 복잡표본은 층·군집·가중치를 반영한 설계 기반 표준오차가 필요하다.

표본 크기가 커지면 일반적으로 표본오차는 감소하지만 4배 표본이 표준오차를 약 절반으로 줄이는 제곱근 관계다.

## 9.2 비표본오차

비표본오차(nonsampling error)는 표본추출의 우연한 변동 외 조사 전 과정에서 생긴다.

| 유형 | 예시 | 완화 방향 |
|---|---|---|
| 포함오차 | 추출틀 누락·중복 | 틀 정비·보조자료 비교 |
| 무응답오차 | 특정 특성 집단이 응답하지 않음 | 추적·가중·민감도 |
| 측정오차 | 유도 질문, 장비 보정 실패 | 문항 시험·표준화·교정 |
| 면접원오차 | 조사자에 따른 질문 차이 | 교육·모니터링 |
| 처리오차 | 코딩·입력·조인·가중 오류 | 검증 규칙·재현 코드 |
| 시점오차 | 서로 다른 기준일 자료 결합 | 기준 시점·버전 관리 |

비표본오차는 전수조사에서도 발생하고 표본을 늘린다고 자동 감소하지 않는다. 큰 웹 설문의 작은 표준오차가 선택·무응답 편향을 가릴 수 있다.

## 10. 표본설계 판단 절차

1. 목표 모집단·관측 단위·시점과 추정할 모수를 정의한다.
2. 표본추출틀의 누락·중복·갱신 상태를 평가한다.
3. 중요 층, 자연 군집, 비용·거리, 희귀집단과 정밀도 목표를 확인한다.
4. SRS·계통·층화·군집·다단계 후보의 선택확률과 실행성을 비교한다.
5. 표본 크기와 층·군집 배분, 무응답 대응을 정한다.
6. 추출 난수·절차·가중치와 교체 규칙을 사전에 기록한다.
7. 분석에서 설계·가중치·유효 표본 수와 표본오차를 반영한다.
8. 비표본오차를 별도 점검하고 일반화 범위를 보고한다.

## 12. 자주 틀리는 시험 함정

1. 고객번호의 평균을 의미 있는 양적 평균으로 본다.
2. 서열척도의 인접 범주 간격이 같다고 본다.
3. 섭씨 20℃가 10℃의 두 배라고 해석한다.
4. 나이를 구간화해도 비율척도 정보가 그대로 남는다고 본다.
5. 편의표본의 개별 선택확률이 알려졌다고 본다.
6. 층화추출과 군집추출의 목적을 바꾼다.
7. 계통추출은 목록 순서와 무관하게 항상 안전하다고 본다.
8. 불비례 층화 결과를 가중치 없이 모집단 비율로 사용한다.
9. 표본이 크면 비표본오차도 사라진다고 본다.
10. 전수조사에는 측정·무응답·처리 오류가 없다고 본다.

## 13. 확인 문제

### 문제 1

고객번호, 만족도 등급, 섭씨온도, 체중의 척도를 각각 쓰시오.

### 문제 2

등간척도와 비율척도의 0과 비율 해석 차이를 설명하시오.

### 문제 3

확률 표본추출의 필수 조건은 무엇인가?

### 문제 4

단순무작위추출과 계통추출의 차이와 계통추출의 위험을 쓰시오.

### 문제 5

층화추출과 군집추출을 목적·선택 방식으로 비교하시오.

### 문제 6

불비례 층화표본에서 가중치가 필요한 이유는 무엇인가?

### 문제 7

표본오차와 비표본오차를 예와 함께 구분하시오.

### 문제 8

표본 크기를 4배로 늘릴 때 단순 조건에서 표준오차는 어떻게 변하는가?

### 문제 9

목표 모집단에서 확률표본을 설계·분석하는 절차를 요약하시오.

## 14. 정답과 해설

### 문제 1 정답과 해설

고객번호는 명목, 만족도 등급은 서열, 섭씨온도는 등간, 체중은 비율척도다. 숫자 모양이 아니라 보존되는 순서·간격·절대 0을 본다.

### 문제 2 정답과 해설

등간척도의 0은 임의 기준이므로 차이는 의미 있지만 몇 배인지는 의미 없다. 비율척도의 0은 양의 부재를 나타내므로 비율 비교가 가능하다.

### 문제 3 정답과 해설

모집단 각 단위가 알려진 0이 아닌 포함확률을 가지며 무작위 절차로 선택되어야 한다. 추출틀과 단계별 확률을 기록한다.

### 문제 4 정답과 해설

SRS는 가능한 표본을 직접 무작위 선택한다. 계통추출은 무작위 시작 뒤 일정 간격으로 고르며, 목록의 주기와 간격이 맞으면 특정 유형이 과대·과소 포함될 수 있다.

### 문제 5 정답과 해설

층화는 모집단을 층으로 나누고 모든 층에서 뽑아 대표·정밀도를 높인다. 군집은 자연 집단 중 일부를 뽑아 목록·이동 비용을 줄이지만 군집 내 유사성으로 오차가 커질 수 있다.

### 문제 6 정답과 해설

층마다 뽑힐 확률이 다르므로 표본의 단순 비율은 과다추출 층을 과대 반영한다. 선택확률의 역수 등을 반영해 모집단 구성으로 복원한다.

### 문제 7 정답과 해설

표본오차는 뽑힌 단위가 달라 표본평균이 모평균과 다른 우연 변동이다. 비표본오차는 명부 누락, 무응답, 질문·장비 측정, 입력·처리 오류 등이다.

### 문제 8 정답과 해설

표준오차가 대략 \(1/\sqrt n\)에 비례하므로 다른 조건이 같다면 4배 표본은 표준오차를 약 절반으로 줄인다.

### 문제 9 정답과 해설

모집단·모수 정의 → 추출틀 평가 → 층·군집·비용 진단 → 설계·표본크기 결정 → 무작위 추출·선택확률 기록 → 무응답·가중 처리 → 설계 기반 오차 추정 → 비표본오차와 한계 보고 순이다.

## 15. 핵심 요약

- **`명목·서열·등간·비율 척도`**는 각각 같음, 순서, 같은 간격, 절대 0과 비율 정보를 추가하며 의미 있는 연산이 다르다.
- **`확률 표본추출`**은 각 단위의 알려진 0이 아닌 선택확률과 무작위 절차를 요구하며 SRS·계통·층화·군집·다단계 설계가 있다.
- 층화는 모든 층에서 표본을 뽑아 정밀도·대표성을 높이고, 군집은 일부 자연 집단을 선택해 비용을 줄이는 대신 군집 내 상관을 반영한다.
- **`표본오차와 비표본오차`**는 각각 표본의 우연 변동과 포함·무응답·측정·처리 과정의 오류이며 큰 표본이 후자를 자동 제거하지 않는다.
- 척도·표본설계·가중치와 오류 구조를 반영하지 않은 정교한 계산은 모집단에 대한 잘못된 확신을 만들 수 있다.
- 표본 결과를 보고할 때는 추출틀, 선택확률, 가중치, 응답률과 설계 기반 불확실성을 함께 제시한다.
