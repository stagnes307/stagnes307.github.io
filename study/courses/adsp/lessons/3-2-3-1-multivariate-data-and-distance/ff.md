# 3-2-3-1. 다변량 자료와 거리

> **학습 범위**: 이 레슨은 ADsP `데이터분석 > 통계분석 > 다변량 분석` 중 **다변량 자료의 구조**, **공분산행렬과 상관행렬**, **거리와 유사도**를 다룬다. 여러 변수를 한 관측 단위의 프로파일로 구성하고, 변수 간 공동 변화를 행렬로 읽으며, 자료의 척도와 의미에 맞는 거리·유사도를 선택하는 것이 목표다.

다변량 분석에서는 한 행을 하나의 점으로 보고 여러 열을 좌표축으로 생각한다. 그러나 현실의 열은 매출액·방문 횟수·등급·구매 여부처럼 척도와 의미가 다르다. 숫자를 그대로 계산한다고 언제나 의미 있는 가까움이 되는 것은 아니다. 거리 계산 전에 관측 단위, 변수 유형, 스케일, 결측과 가중 원칙을 확정해야 한다.

## 1. 다변량 자료의 구조

### 1.1 행렬로 보는 데이터

**다변량 자료의 구조**는 보통 `n×p` 데이터 행렬 X로 표현한다. `n`은 관측 개수, `p`는 변수 개수다.

```text
                 변수 1   변수 2   ...   변수 p
관측 1             x11      x12    ...     x1p
관측 2             x21      x22    ...     x2p
  ...               ...      ...    ...     ...
관측 n             xn1      xn2    ...     xnp
```

- 한 **행**은 고객, 제품, 지역, 시점 등 하나의 관측 단위다.
- 한 **열**은 동일한 정의와 척도로 모든 관측에서 측정한 변수다.
- 한 행의 p개 값은 해당 관측의 다변량 프로파일 또는 p차원 좌표다.
- 변수별 평균을 모은 벡터는 평균벡터, 관측 간 차이는 벡터의 차이로 표현할 수 있다.

한 고객이 여러 시점에 반복 등장한다면 행들이 독립적인 고객 표본이 아니다. 같은 고객 안의 상관 구조를 고려해야 하며, 고객 단위 분석인지 고객-시점 단위 분석인지 명시한다. 서로 다른 집계 수준을 무심코 결합하면 해석 단위가 깨진다.

### 1.2 변수 유형과 표현

| 변수 유형 | 예 | 주의할 점 |
|---|---|---|
| 연속형 | 매출액, 체류시간 | 단위와 극단값, 변환 필요성 |
| 이산형 | 방문 횟수, 구매 건수 | 수치 간격이 실제 차이를 뜻하는지 확인 |
| 순서형 | 만족도 1~5, 등급 | 순서는 있지만 간격이 같다고 단정하기 어려움 |
| 명목형 | 지역, 채널 | 숫자 코드를 거리의 크기로 사용하면 안 됨 |
| 이진형 | 구매 여부, 증상 유무 | 0-0 일치와 1-1 일치의 의미가 같은지 판단 |

명목형 지역을 서울=1, 부산=2, 제주=3으로 바꾸고 유클리드 거리를 계산하면 제주와 서울이 부산과 서울보다 두 배 멀다는 인위적 순서가 생긴다. 범주형은 더미 표현이나 범주에 맞는 불일치 척도를 검토한다. 순서형도 등급 간 간격을 동일하게 둘 근거가 있는지 확인한다.

### 1.3 중심화와 표준화

중심화는 각 값에서 변수 평균을 빼는 과정이다. 표준화는 보통 중심화한 뒤 표준편차로 나눈다.

```text
중심화: xij(c) = xij - x̄j
표준화: zij = (xij - x̄j) / sj
```

중심화 후 변수 평균은 0이 된다. 표준화하면 변수의 단위가 제거되고 표본 표준편차가 1이 된다. 연봉이 원 단위이고 방문 횟수가 회 단위일 때 원자료 유클리드 거리는 연봉 차이에 지배될 가능성이 크다. 두 변수를 동등하게 반영하려는 목적이면 표준화가 합리적일 수 있다.

그러나 표준화가 언제나 정답은 아니다. 단위 자체가 업무 중요도를 담고 있거나, 변동이 매우 작은 잡음 변수를 표준화하면 잡음이 과도하게 확대될 수 있다. 기준 모집단과 시점이 달라지면 평균·표준편차도 달라지므로 학습 자료에서 정한 변환값을 적용 자료에 일관되게 사용한다.

### 1.4 결측과 이상치

거리 계산은 두 관측의 여러 변수를 동시에 사용하므로 결측 하나가 다수의 쌍 비교를 막을 수 있다. 가능한 대응은 완전 사례 사용, 변수별 또는 모형 기반 대체, 공통 관측 변수만으로 거리 계산 등이 있지만 각각 선택 편향, 불확실성 축소, 쌍마다 다른 기준이라는 위험이 있다.

극단값은 평균·공분산·표준편차와 유클리드 거리에 큰 영향을 준다. 입력 오류인지 실제 희귀 사례인지 확인하고, 강건한 위치·척도 또는 다른 거리의 필요성을 검토한다. 삭제·대체 규칙은 결과를 보기 전에 업무 근거와 함께 정한다.

### 1.5 고차원에서의 주의

변수가 많아지면 가까운 거리와 먼 거리의 상대적 대비가 약해질 수 있고, 관련 없는 변수와 중복 차이가 누적되어 신호가 희석된다. 업무상 무관한 변수와 분석 시점 이후의 누출 정보를 제외한다. 차원 축소 기법은 다음 레슨의 범위다.

## 2. 공분산행렬과 상관행렬

### 2.1 평균벡터와 공분산행렬

p개 변수의 중심을 평균벡터로 나타내면 다음과 같다.

```text
x̄ = (x̄1, x̄2, …, x̄p)ᵀ
```

**공분산행렬과 상관행렬** 중 표본 공분산행렬 S는 모든 변수 쌍의 공분산을 `p×p`로 배열한 행렬이다.

```text
        [ s11  s12  ...  s1p ]
S   =   [ s21  s22  ...  s2p ]
        [ ...  ...  ...  ... ]
        [ sp1  sp2  ...  spp ]

sjk = Σi{(xij-x̄j)(xik-x̄k)} / (n-1)
```

대각 원소 `sjj`는 변수 j의 분산이고, 비대각 원소 `sjk`는 변수 j와 k의 공분산이다. `sjk=skj`이므로 대칭행렬이다. 공분산의 부호는 두 변수가 평균에서 같은 방향으로 움직이는지 반대 방향으로 움직이는지를 보여 준다.

공분산 크기는 두 변수의 단위 곱에 의존한다. 매출액 단위를 원에서 만 원으로 바꾸면 관련 구조는 같아도 공분산 수치가 바뀐다. 따라서 단위가 다른 변수 쌍의 관계 강도를 공분산 절댓값만으로 비교하면 안 된다.

### 2.2 상관행렬

상관행렬 R은 각 변수 쌍의 상관계수를 배열한 `p×p` 대칭행렬이다.

```text
rjk = sjk / (sj sk)

        [  1   r12  ...  r1p ]
R   =   [ r21   1   ...  r2p ]
        [ ...  ...  ...  ... ]
        [ rp1  rp2  ...   1  ]
```

대각 원소는 자신과의 상관이므로 1이고, 비대각 원소는 -1과 1 사이에 있다. 상관행렬은 변수를 표준화한 자료의 공분산행렬과 같다. 양의 단위 변환에는 불변이어서 척도가 다른 변수의 선형 관계 강도를 비교하기 쉽다.

| 구분 | 공분산행렬 S | 상관행렬 R |
|---|---|---|
| 대각 원소 | 각 변수의 분산 | 1 |
| 비대각 원소 | 변수 쌍 공분산 | 변수 쌍 상관계수 |
| 단위 영향 | 받음 | 양의 선형 단위 변환에 불변 |
| 적합한 상황 | 같은 단위이거나 실제 분산 크기가 중요 | 단위·척도가 달라 표준화 관계를 볼 때 |

상관행렬을 쓰면 모든 변수를 자동으로 동등하게 중요한 것으로 취급한다는 점도 기억한다. 변동이 아주 작은 측정 잡음까지 표준화하면 상대적 영향이 커질 수 있다.

### 2.3 행렬의 구조적 성질

공분산행렬은 대칭이고 `aᵀSa≥0`인 양의 준정부호 행렬이다. 변수 하나가 다른 변수의 정확한 선형결합이면 행렬이 특이해 역행렬이 없을 수 있다. 표본이 적거나 중복 변수가 많을 때도 추정이 불안정하므로 표본 크기·결측·이상치를 함께 확인한다.

### 2.4 작은 예로 읽기

표준화된 방문 횟수 X1, 구매액 X2, 문의 건수 X3의 상관행렬이 다음과 같다고 하자.

```text
       X1    X2    X3
X1   1.00  0.80 -0.10
X2   0.80  1.00  0.05
X3  -0.10  0.05  1.00
```

방문 횟수와 구매액은 강한 양의 선형 관계를 보이고, 문의 건수는 두 변수와 선형 관계가 약하다. 하지만 `0.05`는 아무 관계도 없음을 보장하지 않는다. 비선형 관계, 집단별 관계, 이상치와 표본 불확실성을 그래프로 확인한다. 상관관계는 원인 방향도 알려 주지 않는다.

## 3. 거리와 유사도

### 3.1 거리의 기본 성질

**거리와 유사도**는 두 관측의 프로파일이 얼마나 다른지 또는 비슷한지를 수치화한다. 일반적인 거리 d는 다음 성질을 기대한다.

1. 비음성: `d(x,y)≥0`
2. 동일성: 같은 점의 거리는 `d(x,x)=0`
3. 대칭성: `d(x,y)=d(y,x)`
4. 삼각부등식: `d(x,z)≤d(x,y)+d(y,z)`

이 조건을 모두 만족하면 수학적 거리척도다. 유사도는 보통 값이 클수록 비슷하다는 뜻이며, `1-유사도`가 언제나 삼각부등식을 만족하는 것은 아니다. 알고리즘이 요구하는 성질을 확인한다.

### 3.2 수치형 자료의 거리

두 p차원 관측 x와 y에 대해 대표 거리는 다음과 같다.

```text
유클리드 거리: d2(x,y) = √[Σj(xj-yj)²]
맨해튼 거리:   d1(x,y) = Σj|xj-yj|
민코프스키:    dq(x,y) = [Σj|xj-yj|^q]^(1/q), q≥1
```

- 유클리드 거리는 직선 최단거리이며 큰 좌표 차이를 제곱해 강조한다.
- 맨해튼 거리는 축을 따라 이동한 절댓값 차이의 합으로, 큰 차이에 대한 강조가 상대적으로 덜하다.
- 민코프스키 거리는 q 선택에 따라 유클리드와 맨해튼을 포괄한다.

표준화 유클리드 거리는 각 변수 차이를 표준편차로 나눠 합한다. 단위가 다른 수치 변수들을 비교할 때 유용하지만 변수 간 상관은 반영하지 않는다.

### 3.3 마할라노비스 거리

마할라노비스 거리는 변수의 분산뿐 아니라 공분산 구조를 반영한다.

```text
dM(x,y) = √[(x-y)ᵀ S⁻¹ (x-y)]
```

변동이 큰 방향의 차이는 상대적으로 덜 크게 보고 변수 간 공분산도 반영한다. 다만 역행렬이 필요하므로 중복 변수, 작은 표본, 많은 차원, 이상치로 S가 불안정하면 거리도 불안정하다.

### 3.4 방향 기반 유사도

코사인 유사도는 두 벡터 사이 각도를 이용한다.

```text
cos(x,y) = (x·y) / (||x|| ||y||)
```

벡터 크기보다 구성 비율이나 방향이 중요할 때 유용하다. 예를 들어 문서의 단어 빈도나 품목별 구매 구성에서 전체 구매량이 달라도 비슷한 비율이면 높은 유사도를 가질 수 있다. 영벡터는 노름이 0이라 정의되지 않으며, 중심화 여부와 음수 값의 의미에 따라 해석 범위가 달라진다.

코사인 유사도는 크기 차이를 무시할 수 있다. 구매 비율이 같지만 총액이 1만 원과 1천만 원인 고객이 매우 비슷하게 평가될 수 있으므로 목적이 규모까지 반영하는 것인지 확인한다.

### 3.5 이진·집합 자료의 유사도

두 고객이 구매한 품목 집합 A와 B의 자카드 유사도는 교집합 크기를 합집합 크기로 나눈다.

```text
J(A,B) = |A∩B| / |A∪B|
자카드 거리 = 1 - J(A,B)
```

자카드는 두 관측이 모두 0인 품목, 즉 둘 다 구매하지 않은 항목을 일치로 세지 않는다. 매우 희소한 구매·증상·클릭 데이터에서 1의 공동 존재가 중요한 경우 유용하다. 반면 0-0 일치도 중요한 이진 속성이라면 단순 일치계수 등 다른 척도를 검토한다.

해밍 거리는 같은 길이의 범주·이진 벡터에서 서로 다른 위치의 개수를 센다. 위치별 중요도가 다르면 가중 기준을 별도로 정한다.

### 3.6 거리 선택 비교

| 자료·목적 | 후보 | 핵심 판단 |
|---|---|---|
| 같은 척도의 연속형 좌표 | 유클리드 | 큰 차이와 이상치가 제곱으로 강조됨 |
| 좌표별 절대 차이 누적 | 맨해튼 | 축별 변화량 합의 의미가 적절한지 |
| 단위가 다른 수치 변수 | 표준화 거리 | 표준화가 업무 중요도를 왜곡하지 않는지 |
| 상관된 연속형 변수 | 마할라노비스 | 공분산 추정과 역행렬이 안정적인지 |
| 크기보다 구성 방향 | 코사인 유사도 | 전체 규모를 무시해도 되는지 |
| 희소한 1의 공동 존재 | 자카드 유사도 | 0-0 일치를 제외하는 것이 맞는지 |
| 위치별 불일치 개수 | 해밍 거리 | 모든 위치의 가중치가 같은지 |

척도 선택은 공식 이름이 아니라 **무엇을 같다고 볼 것인가**에 대한 업무 정의다. 고객 유사도라면 구매 총액, 품목 구성, 방문 시점 중 어느 것을 중요하게 보는지 먼저 합의한다.

---

## 4. 구체 사례: 고객 프로파일 비교

세 고객의 월 구매액과 방문 횟수가 다음과 같다고 하자.

| 고객 | 구매액(만원) | 방문 횟수 |
|---|---:|---:|
| A | 100 | 2 |
| B | 110 | 8 |
| C | 300 | 3 |

원자료 유클리드 거리에서 구매액이 결과를 지배한다. A-B는 `√(10²+6²)≈11.66`, A-C는 `√(200²+1²)≈200.00`이다. 표준화하면 상대적 차이로 비교하지만, 구매액의 실제 차이가 업무상 더 중요하면 동등 가중 표준화도 부적절할 수 있다.

이번에는 관심 품목 집합이 다음과 같다고 하자.

```text
A = {책, 문구, 전자기기}
B = {책, 문구, 식품}
C = {여행, 식품}

J(A,B) = 2/4 = 0.50
J(A,C) = 0/5 = 0
```

A와 B는 두 품목을 함께 구매해 A와 C보다 유사하다. 구매하지 않은 수천 개 품목을 공동 0으로 세지 않은 점이 핵심이다. 반대로 보안 설정처럼 둘 다 기능을 끈 상태도 중요한 일치라면 자카드만으로는 정보가 빠질 수 있다.

품목별 구매 비율이 같고 총량만 100배 다른 고객은 코사인 유사도가 높을 수 있다. 추천 구성에는 맞아도 고객 등급화에는 규모 정보가 필요하다.

---

## 5. 실전 판단 절차

1. **관측 단위를 정의한다.** 한 행이 고객인지 거래인지 고객-월인지 고정한다.
2. **변수 역할과 시점을 확인한다.** 분석 시점 이후 정보나 결과 누출 변수를 제외한다.
3. **변수 유형을 분류한다.** 연속·이산·순서·명목·이진을 구분한다.
4. **척도와 분포를 점검한다.** 단위, 범위, 왜도, 극단값, 상수 변수를 확인한다.
5. **결측 원인과 처리 원칙을 정한다.** 쌍마다 비교 기준이 달라지는지 기록한다.
6. **공분산행렬과 상관행렬을 함께 읽는다.** 실제 분산 규모와 표준화 관계를 구분한다.
7. **가까움의 업무 의미를 문장으로 쓴다.** 규모, 방향, 공동 존재, 불일치 중 무엇이 중요한지 정한다.
8. **거리·유사도를 선택한다.** 수학적 성질과 알고리즘 요구 조건도 확인한다.
9. **표준화·가중의 민감도를 비교한다.** 선택에 따라 이웃 관계가 크게 바뀌는지 본다.
10. **대표 쌍을 원자료로 검증한다.** 가까운 쌍과 먼 쌍이 현업 판단에도 납득되는지 확인한다.

## 6. 시험에서 자주 틀리는 포인트

- 데이터 행렬에서 n과 p를 뒤바꾸거나, 행의 관측 단위를 확인하지 않는다.
- 명목형 범주에 부여한 숫자 코드를 실제 거리로 해석한다.
- 단위가 크게 표현된 변수가 유클리드 거리를 지배하는 문제를 놓친다.
- 표준화는 언제나 성능을 높이고 모든 변수의 의미를 보존한다고 단정한다.
- 공분산행렬 대각 원소를 표준편차라고 하거나 상관행렬 대각을 0이라고 한다.
- 공분산 절댓값만으로 단위가 다른 변수 쌍의 관계 강도를 비교한다.
- 상관행렬이 원인 방향이나 비선형 관계까지 보여 준다고 생각한다.
- 마할라노비스 거리는 어떤 표본에서도 안정적으로 계산된다고 가정한다.
- 코사인 유사도가 높은 두 벡터는 크기까지 비슷하다고 해석한다.
- 자카드 유사도에서 공동 0을 공동 1과 똑같이 일치로 센다.

## 8. 정답과 해설

### 정답 1

n은 고객·제품 같은 관측 또는 사례의 수이고, p는 각 관측에서 측정한 변수의 수다. 한 행은 동일한 관측 단위를 일관되게 나타내야 한다.

### 정답 2

명목형 숫자 코드는 이름표일 뿐 순서와 간격을 뜻하지 않는다. 이 계산은 서울-제주 차이가 서울-부산 차이의 두 배라는 인위적 구조를 만들어 실제 지역 유사성을 왜곡한다.

### 정답 3

원과 횟수처럼 단위가 달라 수치가 큰 변수가 거리를 지배하고 각 변수를 동등하게 반영하려면 표준화를 검토한다. 반대로 실제 단위의 차이가 업무 중요도를 담거나 작은 분산의 잡음 변수가 있으면 표준화가 의미를 왜곡할 수 있다.

### 정답 4

대각 원소는 각 변수의 분산이고, 비대각 원소는 해당 두 변수의 공분산이다. 공분산행렬은 대칭이어서 서로 순서를 바꾼 원소가 같다.

### 정답 5

각 변수를 평균 0, 표준편차 1로 표준화한 뒤 구한 공분산행렬은 원자료의 상관행렬과 같다. 상관행렬의 대각은 1이고 비대각은 변수 쌍 상관계수다.

### 정답 6

유클리드 거리는 차이를 제곱해 합하므로 한 좌표의 큰 차이를 더 강조한다. 맨해튼 거리는 절댓값 차이를 합해 상대적으로 큰 단일 차이의 지배가 덜하다.

### 정답 7

변수별 분산뿐 아니라 변수 간 공분산, 즉 상관된 방향의 변동 구조를 반영한다. 다만 공분산행렬이 특이하거나 추정이 불안정하면 역행렬과 거리도 불안정하다.

### 정답 8

두 벡터의 방향이 같아 코사인 유사도가 매우 높거나 1이 될 수 있다. 이는 전체 크기 차이를 무시하므로 목적상 문서 길이나 고객 총구매량이 중요하다면 다른 정보나 척도를 함께 써야 한다.

### 정답 9

희소 자료에서는 두 고객이 사지 않은 수많은 품목이 공동 0으로 쌓여 실제 관심사 공유보다 유사도를 과장할 수 있다. 자카드는 적어도 하나가 1인 항목 중 공동 1의 비율을 본다.

### 정답 10

잡음과 중복 차이가 누적되고 가까운 거리와 먼 거리의 상대적 대비가 약해질 수 있다. 목적에 맞는 변수 선별, 스케일·가중 검토, 대표 쌍 검증과 독립자료 평가를 수행한다.

## 9. 핵심 요약

- **다변량 자료의 구조**는 n개 관측과 p개 변수의 행렬이며, 행의 관측 단위와 열의 척도를 먼저 확정한다.
- 중심화는 평균을 빼고, 표준화는 보통 표준편차까지 나눈다. 표준화는 단위 영향을 줄이지만 언제나 적절한 것은 아니다.
- **공분산행렬과 상관행렬**은 모두 `p×p` 대칭행렬이다. 공분산행렬의 대각은 분산, 상관행렬의 대각은 1이다.
- 공분산은 단위에 의존하고, 상관은 표준화된 선형 관계를 나타낸다. 둘 다 인과나 모든 비선형 구조를 보장하지 않는다.
- **거리와 유사도**는 무엇을 비슷하다고 볼지에 따라 선택한다. 유클리드·맨해튼·마할라노비스·코사인·자카드는 강조하는 정보가 다르다.
- 수치형·범주형·이진형을 무심코 한 거리식에 넣지 말고 스케일, 결측, 이상치, 가중과 공분산 안정성을 확인한다.
- 계산된 이웃 관계는 대표 관측 쌍의 원자료와 업무 의미로 검증하고, 고차원에서는 잡음·중복 변수의 누적을 경계한다.
