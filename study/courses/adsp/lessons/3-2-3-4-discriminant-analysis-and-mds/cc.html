1. 학습 목표와 두 기법의 구분

판별분석은 집단 라벨이 있는 지도학습 문제이고, 다차원척도법(MDS)은 대상 사이 가까움과 멂을 좌표로 표현하는 비지도 시각화 방법이다. 학습 후에는 판별함수의 역할, 선형·이차 판별의 가정, 사전확률과 오분류 판단을 설명하고, MDS의 입력·목적·스트레스와 공간 배치의 불변성을 해석할 수 있어야 한다.

02

2. 판별함수와 집단 분류

2.1 판별분석의 목적

판별함수와 집단 분류에서는 과거 관측치의 설명변수 x와 집단 g를 이용해 집단별 분포를 추정하고, 새 x가 어느 집단에서 나왔을 가능성이 큰지 판단한다. 고객 등급, 제품 품질 상태, 종 분류처럼 집단이 미리 정의된 상황에 사용한다.

선형판별분석(LDA)은 각 집단이 다변량 정규분포를 따르고 공분산행렬 Σ를 공유한다고 가정하는 전형적 모형이다. 집단 k의 판별점수는 상수항을 포함해 다음 형태로 쓸 수 있다.

δk(x) = xᵀΣ⁻¹μk - 1/2 μkᵀΣ⁻¹μk + log(πk)

μk는 집단 k의 평균벡터, πk는 사전확률이다. 가장 큰 δk를 주는 집단으로 분류한다. 두 집단 판별점수의 차이가 x의 선형식이 되므로 결정 경계가 선형이다.

2.2 선형판별과 이차판별

이차판별분석(QDA)은 집단마다 다른 공분산행렬 Σk를 허용한다. 점수에 공분산행렬식과 x의 이차항이 포함되어 결정 경계가 곡선이 될 수 있다.

2. 판별함수와 집단 분류 · 학습 표 2
항목LDAQDA
공분산집단 공통집단별 별도

QDA가 더 유연하다고 항상 우수하지 않다. 각 집단 표본이 적거나 변수가 많으면 공분산 추정 오차가 커져 과대적합될 수 있다. LDA의 단순성이 검증 자료에서 더 나을 수 있다.

2.3 사전확률과 오분류 비용

사전확률 πk는 새 관측치가 자료를 보기 전에 각 집단에 속할 가능성이다. 학습 표본의 집단 비율을 사용할 수 있지만, 표본을 의도적으로 균형 추출했다면 실제 운영 비율과 다를 수 있다. 실제 모집단 비율이나 정책적 기준을 명시한다.

오분류 비용도 중요하다. 정상 고객을 위험으로 판단하는 비용과 위험 고객을 정상으로 놓치는 비용이 다르면 단순 최대 사후확률 대신 기대 손실이 작은 결정을 선택한다.

기대손실(행동 a | x) = 각 실제 집단의 손실 × 사후확률의 합

시험에서는 사전확률이 판별점수의 log(πk) 항을 통해 분류 경계를 바꿀 수 있다는 점을 이해한다. 평균과 공분산이 같아도 사전확률 설정이 달라지면 경계 주변 관측치의 분류가 바뀔 수 있다.

2.4 가정과 진단

판별분석 전에 다음을 점검한다.

  • 종속 집단 라벨이 상호배타적이고 업무적으로 유효한가?
  • 설명변수가 집단별로 대체로 다변량 정규성을 만족하는가?
  • LDA라면 집단 공분산 구조가 충분히 비슷한가?
  • 변수 간 완전한 선형관계로 공분산행렬이 특이하지 않은가?
  • 극단치가 평균과 공분산을 지배하지 않는가?
  • 학습과 평가 자료가 섞이지 않았는가?

정규성·등분산 검정의 p값 하나만으로 기계적으로 선택하지 않는다. 표본 크기, 그래프, 공분산 차이, 교차검증 성능과 해석 목적을 함께 본다. 변수 수가 표본에 비해 지나치게 크면 차원 축소나 규제 방법을 별도로 검토한다.

2.5 판별계수와 구조 해석

표준화 판별계수의 절댓값이 크면 다른 변수를 통제한 판별함수 기여가 큰 것으로 볼 수 있으나, 설명변수 상관에 민감하다. 구조계수는 원변수와 판별점수의 상관을 보여 준다. 둘을 함께 보고 집단 평균의 방향을 확인한다.

계수 부호도 판별축 방향을 반전하면 함께 바뀔 수 있다. 부호 하나보다 어느 집단이 높은 점수 쪽에 놓이는지, 변수 변화가 상대 점수에 어떤 영향을 주는지 설명한다.

2.6 고정 입력 base R 분류 사례

두 집단의 공통 공분산을 추정해 마할라노비스 거리와 사전확률로 새 관측치를 분류한다.

x <- rbind( c(2.0, 2.5), c(2.5, 2.2), c(3.0, 2.8), c(2.7, 3.1), c(6.0, 5.8), c(6.5, 6.2), c(5.8, 6.7), c(6.7, 5.9) ) group <- factor(rep(c('A', 'B'), each = 4)) new_x <- matrix(c(4.8, 5.1), nrow = 1)

means <- rowsum(x, group) / as.vector(table(group)) cova <- cov(x[group == 'A', , drop = FALSE]) covb <- cov(x[group == 'B', , drop = FALSE]) pooledcov <- (3 * cova + 3 * cov_b) / 6 prior <- c(A = 0.5, B = 0.5)

d2 <- vapply( levels(group), function(g) mahalanobis(newx, means[g, ], pooledcov), numeric(1) ) score <- -0.5 * d2 + log(prior) names(which.max(score))

공통 공분산을 사용한 LDA 점수에서 집단별 공통 상수는 비교에 영향을 주지 않아 생략했다. 입력과 사전확률은 고정되어 외부 패키지·난수에 의존하지 않는다. 실제 적용에서는 학습 자료 안에서 얻은 거리만 보고 성능을 낙관하지 말고 별도 검증 절차를 사용한다.

03

3. 다차원척도법의 목적

3.1 입력과 출력

다차원척도법의 목적은 n개 대상 사이의 거리 또는 비유사도 관계를 k차원 좌표로 배치해 구조를 이해하는 것이다. 브랜드 유사성, 도시 간 거리, 제품 속성 차이처럼 원래 좌표가 없고 쌍별 관계만 있어도 사용할 수 있다.

입력 비유사도행렬은 일반적으로 대칭이고 대각 원소가 0이며 음수가 없어야 한다. 거리 공리를 완전히 만족하지 않는 주관적 비유사도도 있을 수 있으므로 사용한 MDS 유형과 적합도를 확인한다.

3.2 계량 MDS와 비계량 MDS

고전적 MDS는 유클리드 거리행렬을 내적행렬로 바꾸고 고유분해해 좌표를 구한다. 거리 제곱행렬 D²와 중심화행렬 J = I - 11ᵀ/n에 대해 다음 행렬을 사용한다.

B = -1/2 J D² J

B의 큰 양의 고유값과 고유벡터로 저차원 좌표를 만든다. 음의 고유값이 크면 입력 거리가 유클리드 공간에 잘 맞지 않음을 시사한다.

비계량 MDS는 거리의 정확한 크기보다 비유사도의 순서 관계를 보존하려 한다. 관측 비유사도와 배치 거리 사이에 단조 관계를 맞추며 스트레스를 줄인다.

3.3 차원 수와 스트레스

낮은 차원은 보기 쉽지만 관계를 더 많이 왜곡한다. 차원 수를 늘리면 적합은 좋아지기 쉬우나 시각화·해석 장점이 줄어든다.

대표적인 정규화 스트레스는 다음과 같은 형태다.

Stress = √[Σ(dij - d̂ij)² / Σdij²]

dij는 입력 비유사도, d̂ij는 배치 좌표의 거리다. 구현마다 가중치와 정규화 정의가 다를 수 있어 서로 다른 도구의 수치를 이름만 보고 직접 비교하지 않는다. 스트레스가 작을수록 거리 재현은 좋지만, 절대 임계치는 대상 수·자료 구조·차원과 정의에 따라 달라진다.

3.4 고정 입력 base R MDS 사례

다섯 제품의 세 속성 점수로 유클리드 거리를 만들고 2차원에 배치한다.

profile <- matrix( c(8, 2, 3, 7, 3, 4, 2, 8, 7, 3, 7, 8, 5, 5, 5), nrow = 5, byrow = TRUE, dimnames = list(paste0('제품', 1:5), c('간편성', '전문성', '가격')) )

dissimilarity <- dist(scale(profile)) mds <- cmdscale(dissimilarity, k = 2, eig = TRUE) mds$points mds$eig

originald <- as.vector(dissimilarity) fittedd <- as.vector(dist(mds$points)) stresslike <- sqrt( sum((originald - fittedd) ^ 2) / sum(originald ^ 2) ) stress_like

scale로 속성 척도를 맞춘 뒤 cmdscale을 사용했다. stress_like는 이 예제에서 정의한 단순 정규화 거리 오차이며 모든 MDS 소프트웨어의 Stress-1과 같다고 단정하지 않는다.

4. 공간 배치 결과 해석

4.1 상대 거리 중심 해석

공간 배치 결과 해석에서는 점 사이의 상대적 가까움과 멂이 핵심이다. 제품1과 제품2가 가까우면 선택한 비유사도 정의에서 비슷하다는 뜻이다. 원점에서 멀다는 사실 자체는 품질이 높거나 낮다는 뜻이 아니다.

MDS 배치는 평행이동·회전·반사해도 점 사이 거리가 같다. 따라서 다른 실행 결과가 좌우 반전되거나 회전되어도 동일한 해일 수 있다. 축 1과 축 2에 주성분처럼 자동 의미가 부여되지 않는다. 외부 속성과 좌표의 관계, 극단에 위치한 대상의 원특성을 검토해 사후적으로 축 의미를 붙인다.

4.2 군집과 이상 대상

가까운 점 무리는 유사한 대상군 후보지만 MDS 자체가 군집 수를 확정하지 않는다. 시각적 무리를 곧바로 공식 세그먼트라고 선언하지 말고 원거리, 스트레스와 별도 군집 분석 결과를 확인한다.

외딴 점은 독특한 대상일 수도 있고 입력 거리 오류일 수도 있다. 거리 계산 변수의 단위, 결측 처리, 비유사도 응답 품질을 원자료에서 확인한다.

4.3 결과 검증 절차

  1. 거리 또는 비유사도의 정의와 전처리를 명시한다.
  2. 행렬 대칭성·대각 0·결측과 이상 값을 검사한다.
  3. 후보 차원별 스트레스 또는 고유값을 비교한다.
  4. 셰퍼드 도표 등으로 입력 비유사도와 배치 거리를 확인한다.
  5. 큰 잔차를 보이는 대상 쌍을 원자료로 추적한다.
  6. 회전·반사에 불변인 상대 거리 중심으로 해석한다.
  7. 축 이름과 군집 해석은 외부 근거로 교차 확인한다.

5. 통합 업무 사례와 산출물

소매사가 기존 고객의 우수·일반 집단을 분류하고, 동시에 다섯 브랜드의 소비자 인지 지도를 만들려 한다고 하자. 고객 분류에는 라벨과 행동변수를 사용해 판별모형을 학습한다. 브랜드 지도에는 쌍별 비유사도 평균을 사용해 MDS를 수행한다. 두 결과를 같은 분류 모형으로 부르면 안 된다.

판별 산출물은 집단 정의, 변수, 평균·공분산, 사전확률, 분류 규칙, 검증 혼동표와 비용 해석이다. MDS 산출물은 거리 정의, 차원 수 근거, 좌표, 스트레스·고유값, 큰 잔차 쌍, 상대 위치 해석과 불변성 주의다.

06

6. 시험 함정과 자주 틀리는 포인트

  1. 판별분석을 비지도 군집화라고 본다. 알려진 집단 라벨을 사용한다.
  2. LDA가 집단별 공분산을 모두 다르게 둔다고 본다. 공통 공분산을 가정한다.
  3. QDA가 언제나 더 좋다고 본다. 추정량이 많아 작은 표본에서 불안정할 수 있다.
  4. 사전확률이 분류에 영향을 주지 않는다고 본다. 판별점수와 경계를 바꿀 수 있다.
  5. 학습 자료 적중률만 보고 성능을 확정한다. 독립 검증이 필요하다.
  6. MDS에 집단 라벨이 필수라고 본다. 대상 간 거리·비유사도가 입력이다.
  7. 스트레스가 클수록 적합이 좋다고 본다. 일반적으로 작을수록 거리 재현이 좋다.
  8. MDS 축의 절대 방향에 고정 의미가 있다고 본다. 회전·반사·평행이동에 불변이다.
  9. 가까운 점은 모든 원변수에서 동일하다고 본다. 사용한 거리와 선택 차원에서 가깝다는 뜻이다.
  10. MDS 점 무리를 자동 확정 군집으로 본다. 별도 근거와 검증이 필요하다.

  4. 판별분석은 좌표를 전혀 사용하지 않는다.

9. 정답과 해설

  1. 정답 1. 판별분석은 알려진 집단과 설명변수의 관계로 새 관측치를 분류한다.
  2. 정답 2. LDA는 집단 평균은 다르되 공분산행렬을 공유한다고 가정한다.
  3. 정답 1. QDA는 집단마다 공분산을 추정하므로 집단 표본이 적을수록 추정 변동이 커진다.
  4. 정답 1. 사전확률은 log(πk) 항 등을 통해 경계 주변의 분류에 영향을 준다.
  5. 정답 1. MDS는 쌍별 거리 또는 비유사도가 가능한 한 보존되도록 좌표를 배치한다.
  6. 정답 1. 비계량 MDS는 비유사도의 절대 크기보다 순위의 단조 관계에 초점을 둔다.
  7. 정답 1. 같은 정의와 자료에서는 스트레스가 작을수록 저차원 거리의 재현 오차가 작다.
  8. 정답 1. 반사·회전·평행이동은 상대 거리를 바꾸지 않아 동일한 배치를 표현할 수 있다.
  9. 정답 2. 축 의미는 자동으로 정해지지 않으므로 외부 속성과 극단 대상의 특성을 대조한다.
  10. 정답 2. 판별은 라벨 기반 분류, MDS는 비유사도 기반 공간 표현이라는 목적 차이가 있다.
10

10. 핵심 요약

  • 판별함수와 집단 분류는 집단별 평균·공분산·사전확률을 이용해 새 관측치의 집단을 판단한다.
  • LDA는 공통 공분산과 선형 경계, QDA는 집단별 공분산과 이차 경계를 사용한다.
  • 사전확률과 오분류 비용은 실제 운영 분류 기준에 영향을 준다.
  • 다차원척도법의 목적은 대상 간 거리·비유사도를 저차원 좌표로 표현하는 것이다.
  • 계량 MDS는 거리 크기, 비계량 MDS는 비유사도 순서 보존에 초점을 둔다.
  • 차원 수는 스트레스·고유값·해석 가능성을 함께 보고 선택한다.
  • 공간 배치 결과 해석은 절대 축보다 상대 거리와 큰 잔차에 집중하며 회전·반사 불변성을 기억한다.
  • 지도 분류인 판별분석과 비지도 관계 지도인 MDS를 입력·목적·평가 기준으로 구분한다.
