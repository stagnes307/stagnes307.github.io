FF 원문 제목3-2-4-2. 시계열 평활과 분해 · 이동평균법 · 지수평활법 · 가법·승법 분해

이 레슨은 시계열의 단기 불규칙 변동을 평활하고 추세·계절·불규칙 성분으로 분해하는 방법을 다룬다. 구성 요소·정상성 진단은 앞 레슨, ARIMA 식별과 예측구간·오차 평가는 다음 레슨들 범위다.

01

1. 학습 목표와 방법 선택 흐름

평활은 관측값의 들쭉날쭉한 변동을 줄여 기저 수준과 패턴을 보기 쉽게 만드는 작업이다. 분해는 관측계열을 추세-순환, 계절, 불규칙 성분으로 나누어 설명한다. 학습 후에는 이동평균 창의 길이와 정렬을 판단하고, 지수평활의 α가 최근값 가중치에 미치는 영향을 설명하며, 계절 진폭을 근거로 가법·승법 분해를 선택할 수 있어야 한다.

작업 순서는 다음과 같다.

  1. 시간 간격, 계절 주기, 결측과 이상점을 확인한다.
  2. 목적이 시각적 평활인지, 단기 수준 예측인지, 구성 요소 분해인지 정한다.
  3. 추세·계절성과 진폭 변화로 후보 방법을 정한다.
  4. 평활 창 또는 α와 초기값을 명시한다.
  5. 끝점 손실, 위상 지연과 잔차 구조를 확인한다.
  6. 원계열과 평활·분해 성분을 같은 시간축에서 비교한다.
  7. 방법 선택과 남은 자기상관·한계를 기록한다.
02

2. 이동평균법

2.1 단순 이동평균

이동평균법은 현재 시점 주변 또는 최근 m개 관측값의 평균으로 불규칙 변동을 완화한다. 후행 m항 이동평균은 다음과 같다.

Mt = (Yt + Yt-1 + … + Yt-m+1) / m

m이 크면 더 매끄럽지만 변화에 늦게 반응하고, 작으면 원계열에 민감하다. 따라서 창 길이는 평활 목적과 변동 주기를 근거로 정한다.

2. 이동평균법 · 학습 표 1
창 길이평활 정도변화 반응주요 위험
짧음약함빠름불규칙 변동이 많이 남음
김강함느림전환점 지연·세부 구조 소실
계절 주기와 같음계절 효과 상쇄 가능추세-순환 추정끝점 결측

후행 이동평균은 과거 정보만 사용해 실시간 계산에 적합하지만 평활 결과가 시간적으로 뒤처질 수 있다. 중심 이동평균은 창의 가운데 시점에 평균을 배치해 시각적 추세 추정에 적합하지만 미래 관측도 사용하므로 마지막 시점의 실시간 예측값으로 쓸 수 없다.

2.2 중심 이동평균과 짝수 주기

3항 중심 이동평균은 t-1, t, t+1의 평균을 t에 놓는다. 홀수 창은 가운데가 명확하다. 월별 12항처럼 짝수 창은 평균의 중심이 두 시점 사이에 위치하므로 다시 인접한 두 이동평균을 평균하는 중심화가 필요하다. 이를 2×12 중심 이동평균이라고 표현하기도 한다.

계절 주기만큼의 중심 이동평균은 계절효과가 한 주기 안에서 상쇄된다는 가정 아래 추세-순환 성분을 추정한다. 영업일 수나 이동 휴일 때문에 계절 위치가 변하면 완전히 제거되지 않을 수 있다.

2.3 가중 이동평균

가중 이동평균은 창 안의 관측값에 서로 다른 가중치를 부여한다.

Mt = w0Yt + w1Yt-1 + … + wm-1Yt-m+1

보통 가중치 합은 1로 둔다. 최근값에 더 큰 가중치를 주면 반응이 빨라지지만 잡음에도 민감해질 수 있다. 가중치는 사후적으로 가장 좋아 보이는 값만 고르지 말고 검증 기간과 업무 반응 속도를 기준으로 선택한다.

2.4 고정 입력 계산 사례

y <- c(12, 14, 13, 18, 20, 19, 24) ma3centered <- stats::filter( y, filter = rep(1 / 3, 3), sides = 2 ) cbind(y, ma3centered)

첫 시점과 마지막 시점에는 완전한 중심 창이 없어 NA가 생긴다. 이를 0으로 채우면 존재하지 않는 추세값을 만든다. 끝점 추정이 필요하면 후행 창이나 별도 모형을 선택하고 그 의미를 구분한다.

후행 3항 평균은 다음처럼 고정 계산할 수 있다.

ma3trailing <- vapply( 3:length(y), function(i) mean(y[(i - 2):i]), numeric(1) ) ma3trailing

3. 지수평활법

3.1 단순 지수평활

지수평활법은 최근 관측값에 상대적으로 큰 가중치를 주고 과거로 갈수록 가중치를 지수적으로 감소시킨다. 추세와 계절성이 뚜렷하지 않은 수준 계열의 단순 지수평활은 다음과 같다.

St = αYt + (1 - α)St-1, 0 < α ≤ 1

다음 한 시점의 수준 예측은 보통 St를 사용한다. 식을 반복 전개하면 최근 Yt의 가중치는 α, 한 시점 전은 α(1-α), 더 과거는 α(1-α)²처럼 줄어든다.

3. 지수평활법 · 학습 표 2
α최근 관측 가중평활변화 반응
작음작음강함느림
큼큼약함빠름
1에 가까움거의 최근값매우 약함잡음에도 민감

α가 0에 가까우면 초기 수준의 영향이 오래 남고, 1이면 St가 거의 현재 관측값이 된다. 작은 α가 무조건 좋거나 큰 α가 무조건 최신 정보를 잘 쓴다는 식으로 판단하지 않는다. 목적 기간의 예측오차와 구조 변화 속도를 비교한다.

3.2 초기값

S1을 첫 관측값으로 두거나 초기 몇 관측의 평균으로 둘 수 있다. 모수 추정 절차가 초기 수준을 함께 최적화하기도 한다. 계열이 짧으면 초기값 선택이 결과에 오래 영향을 주므로 보고서에 명시한다. 충분히 긴 안정 계열에서는 영향이 점차 감소한다.

3.3 추세·계절 확장

단순 지수평활은 일정 수준 주변의 계열에 적합하다. 추세가 있으면 수준과 추세를 갱신하는 Holt 방식, 추세와 계절이 있으면 계절 성분까지 갱신하는 Holt-Winters 방식을 검토한다. 가법 계절 방식은 계절 진폭이 일정하고 승법 방식은 수준에 비례한다는 가정을 둔다.

이 확장법의 이름만 보고 적용하지 않는다. 감쇠 추세 필요성, 계절 주기, 초기 계절값, 양수 제약과 검증 성능을 확인한다. ARIMA와의 구체 비교는 다음 레슨 이후 범위다.

3.4 고정 입력 base R 사례

단순 지수평활을 직접 계산하면 α의 의미가 선명하다.

demand <- c(100, 108, 105, 115, 120, 118) alpha <- 0.30 level <- numeric(length(demand)) level[1] <- demand[1]

for (t in 2:length(demand)) { level[t] <- alpha demand[t] + (1 - alpha) level[t - 1] }

cbind(demand, level) nextforecast <- level[length(level)] nextforecast

모든 입력이 고정되어 외부 파일·패키지·난수를 사용하지 않는다. α를 0.8로 바꿔 두 수준 경로를 비교하면 큰 α가 최신 변화를 빠르게 따라가지만 더 흔들리는 모습을 확인할 수 있다.

3.5 이동평균과 지수평활 비교

4. 가법·승법 분해

4.1 가법 분해

가법·승법 분해 중 가법 모형은 다음과 같다.

Yt = Tt + St + Rt

Tt는 추세-순환, St는 계절, Rt는 불규칙 잔차다. 계절 진폭이 계열 수준과 무관하게 원 단위에서 비슷할 때 적합하다. 계절조정값은 Yt - St로 구한다.

4.2 승법 분해

승법 모형은 다음과 같다.

Yt = Tt × St × Rt

계절효과가 수준의 일정 비율처럼 작용할 때 적합하다. 계절조정값은 Yt / St다. 승법 계절지수 1.20은 해당 계절이 추세 수준보다 약 20% 높은 효과를 가진다는 뜻이고 0.85는 약 15% 낮다는 뜻이다.

승법 분해는 0이나 음수 값에서 해석과 계산이 곤란하다. 모든 값이 양수이고 비율 효과가 타당한지 확인한다. 로그를 취하면 log(Yt) = log(Tt) + log(St) + log(Rt)로 가법 형태가 되지만 0 처리와 역변환 편향을 고려해야 한다.

4.3 고전적 분해 절차

계절 주기가 m인 고전적 분해는 대략 다음 순서다.

  1. m항 중심 이동평균으로 추세-순환 Tt를 추정한다.
  2. 가법은 Yt - Tt, 승법은 Yt / Tt로 계절-불규칙 값을 구한다.
  3. 같은 계절 위치 값을 여러 주기에 걸쳐 평균해 계절지수를 구한다.
  4. 가법 계절지수 합이 한 주기에서 0, 승법 평균이 1이 되도록 조정한다.
  5. 계절조정 계열에서 추세를 제외해 불규칙 잔차를 구한다.

고전적 분해는 계절 패턴이 시간에 따라 고정된다고 가정하고 양끝의 추세 추정값을 잃는다. 급격한 구조 변화와 이상치에 민감하다. 분해 결과의 잔차에 추세·계절 자기상관이 남으면 구성 요소가 충분히 분리되지 않은 것이다.

4.4 고정 입력 base R 분해 사례

분기별 추세와 고정 계절효과를 가진 6년 자료다.

quarter <- 1:24 seasonaleffect <- rep(c(-8, 2, 5, 1), 6) value <- 100 + 2 * quarter + seasonaleffect quarterly <- ts(value, start = c(2021, 1), frequency = 4)

additivefit <- decompose(quarterly, type = 'additive') additivefit$trend additivefit$seasonal additivefit$random plot(additive_fit)

decompose는 고전적 이동평균 분해를 수행한다. 끝점 trend와 random에 NA가 생길 수 있다. 이 합성 자료는 가법 구조로 만들었으므로 결과를 설명하기 쉽지만 실제 자료에서는 잔차와 계절 안정성을 검증해야 한다.

4.5 분해 결과 해석

  • 추세 성분에서 장기 방향과 전환점을 본다.
  • 계절 성분의 단위가 원 단위인지 비율인지 구분한다.
  • 잔차에서 평균 편향, 분산 변화, 자기상관과 이상점을 본다.
  • 계절조정값과 원계열을 혼동하지 않는다.
  • 추세 끝점이 없는 이유를 결측 데이터로 오해하지 않는다.

분해는 인과 원인을 증명하지 않는다. 특정 월 계절지수가 높다는 것은 반복 패턴을 요약한 것이며 프로모션이 원인이라는 결론에는 외부 근거가 필요하다.

05

5. 방법 선택 사례와 판단 절차

월별 문의량이 완만히 증가하고 매년 같은 달에 비슷한 절대 폭으로 증가한다고 하자.

  1. 시간도표와 계절 위치별 그래프로 고정 진폭을 확인한다.
  2. 12항 중심 이동평균으로 추세-순환 후보를 본다.
  3. 가법 분해로 월별 계절지수를 추정한다.
  4. 잔차 ACF에 계절 패턴이 남는지 확인한다.
  5. 실시간 수준 갱신이 별도 목적이면 추세·계절 확장 지수평활을 검토한다.

산출물에는 기간·빈도, 창 길이 또는 α, 초기화, 가법·승법 선택 근거, 평활값, 구성 성분, 끝점 결측, 잔차 진단과 구조 변화 한계가 포함된다.

06

6. 시험 함정과 자주 틀리는 포인트

  1. 이동평균 창이 클수록 언제나 좋다고 본다. 평활은 강하지만 변화가 지연되고 정보가 사라진다.
  2. 중심 이동평균을 실시간 미래예측으로 본다. 미래 쪽 관측도 사용한다.
  3. 짝수 계절 주기에서 중심 위치 문제를 무시한다. 추가 중심화가 필요하다.
  4. α가 작을수록 최근 관측에 큰 가중치를 준다고 본다. 큰 α가 최근값에 민감하다.
  5. 단순 지수평활이 강한 추세·계절을 자동 처리한다고 본다. 확장 모형이 필요하다.
  6. 가법과 승법을 값 크기만으로 선택한다. 계절 진폭이 수준과 어떤 관계인지 본다.
  7. 승법 계절지수 1.2를 1.2 단위 증가라고 해석한다. 약 20% 높은 비율 효과다.
  8. 0이 포함된 자료에 승법 분해를 무조건 적용한다. 곱셈·로그 해석이 곤란하다.
  9. 분해 잔차는 반드시 백색잡음이라고 본다. 남은 구조를 검증해야 한다.
  10. 분해된 계절 패턴을 인과효과로 단정한다. 외부 사건과 설계 근거가 필요하다.

9. 정답과 해설

  1. 정답 1. 더 많은 값을 평균하면 잡음은 줄지만 전환점과 최신 변화 반응이 느려진다.
  2. 정답 1. 중심형은 시점 앞뒤 관측을 사용해 평균을 가운데에 배치한다.
  3. 정답 1. 짝수 개 관측의 평균 위치는 관측 시점 사이여서 다시 인접 평균으로 맞춘다.
  4. 정답 1. 현재값 가중치가 α이므로 α가 클수록 최신 변화와 잡음에 빠르게 반응한다.
  5. 정답 1. 단순 지수평활은 일정 수준 주변에서 변동하는 계열을 대상으로 한다.
  6. 정답 1. 절대 계절 효과가 일정하면 성분을 더하는 가법 구조가 자연스럽다.
  7. 정답 1. 승법 지수 1이 기준이며 0.8은 기준 수준의 80%, 즉 약 20% 낮음을 뜻한다.
  8. 정답 1. 한 계절 주기의 중심 이동평균으로 계절을 상쇄해 추세-순환을 추정한다.
  9. 정답 1. 잔차 계절 상관은 계절지수 안정성이나 분해 방식이 맞지 않을 가능성을 보여 준다.
  10. 정답 2. 평활 정도만이 아니라 사용 목적, 구조, 끝점, 반응성과 남은 오차를 함께 본다.
10

10. 핵심 요약

  • 이동평균법은 창 안의 값을 평균해 불규칙 변동을 줄이며 창 길이와 정렬이 반응 속도를 정한다.
  • 중심 이동평균은 추세 관찰에 유용하지만 양끝 손실과 미래 관측 사용에 주의한다.
  • 지수평활법은 최근값에서 과거로 갈수록 지수적으로 감소하는 가중치를 사용한다.
  • 단순 지수평활의 α가 클수록 최신 변화와 잡음에 민감하고 초기값 영향도 기록해야 한다.
  • 추세·계절이 뚜렷하면 수준만 다루는 단순 지수평활의 확장을 검토한다.
  • 가법·승법 분해는 계절 진폭이 일정한지 수준에 비례하는지로 구분한다.
  • 고전적 분해는 이동평균으로 추세를 구하고 계절지수와 잔차를 분리하지만 끝점·구조 변화에 약하다.
  • 평활·분해 뒤 잔차의 자기상관과 이상점을 확인해야 남은 구조를 놓치지 않는다.
