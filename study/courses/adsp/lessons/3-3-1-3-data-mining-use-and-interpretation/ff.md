# 3-3-1-3. 데이터 마이닝 활용과 해석

> **학습 범위**: 이 레슨은 ADsP `데이터분석 > 정형 데이터 마이닝 > 데이터 마이닝 개요` 중 **`예측·분류·군집·연관 문제`**, **`모형 정확도와 설명 가능성`**, **`분석 결과의 업무 적용`**을 다룬다. 업무 질문을 적합한 데이터 마이닝 문제로 변환하고, 정확도·설명·운영 제약을 균형 있게 해석하며, 결과를 실제 의사결정과 감시 가능한 업무 절차로 연결하는 것이 목표다.

모델은 업무 결정을 대신하는 마법 상자가 아니다. 동일 데이터도 “얼마인가”, “어느 범주인가”, “어떤 집단인가”, “무엇이 함께 나타나는가”에 따라 문제·평가·출력이 달라진다. 분석 결과를 상관에서 인과로 확대하거나 점수만 전달한 뒤 활용을 끝냈다고 보는 것을 경계한다.

---

## 1. 업무 질문을 마이닝 문제로 변환한다

먼저 결과를 사용할 사람·시점·행동을 정의하고 필요한 출력 형태를 정한다.

| 업무 질문 | 마이닝 문제 | 출력 예 |
|---|---|---|
| 다음 주 상품 수요는 얼마인가 | 예측·회귀 | 수요 값·구간 |
| 이 거래는 정상인가 사기인가 | 분류 | 범주·확률·경보 |
| 비슷한 고객군은 무엇인가 | 군집 | 군집 번호·특성 |
| 함께 구매되는 상품은 무엇인가 | 연관 | 규칙·지지도·신뢰도 |

“매출을 높인다”는 아직 마이닝 문제가 아니다. 가격별 수요 예측, 고객 반응 분류, 장바구니 연관 탐색 등 여러 문제로 구체화할 수 있다. 어떤 행동을 선택할지에 따라 답이 달라진다.

## 2. 예측·분류·군집·연관 문제

## 2.1 예측

**`예측·분류·군집·연관 문제`** 중 예측은 알려진 입력으로 미래 또는 미관측 수치·상태를 추정한다. 넓게는 분류도 예측에 포함되지만 ADsP 문맥에서 수치 예측과 범주 분류를 구분해 설명할 수 있다.

수치 예측 예:

- 다음 달 상품별 판매량
- 주택 가격
- 설비 고장까지 남은 시간
- 고객 생애가치

확인할 요소는 기준 시점, 예측 지평, 갱신 주기, 오차 비용, 예측구간이다. 하루 뒤와 1년 뒤 예측은 같은 성능으로 비교하지 않는다. 평균 오차가 같아도 품절을 만드는 과소예측과 재고를 만드는 과대예측 비용이 다를 수 있다.

## 2.2 분류

분류는 범주형 목표변수의 클래스를 예측한다.

- 정상/사기
- 이탈/유지
- 불량 유형 A/B/C
- 문서 주제

확률점수와 최종 범주를 구분한다. 기준값을 바꾸면 양성 탐지와 오탐이 달라진다. 클래스 불균형에서는 정확도 하나가 부적절할 수 있으며 혼동행렬·ROC 등은 다음 레슨에서 상세히 다룬다.

## 2.3 군집

군집은 사전 클래스 라벨 없이 유사한 관측을 묶어 내부는 비슷하고 집단 간은 다르게 만드는 비지도학습이다.

군집 번호는 실제 세계의 정답 라벨이 아니다. 변수 선택, 거리, 스케일, 군집 수와 초기값에 따라 달라진다.

```r
x <- data.frame(
  visits = c(2, 3, 4, 15, 16, 18),
  amount = c(20, 25, 35, 200, 220, 240)
)

set.seed(307)
km <- kmeans(scale(x), centers = 2, nstart = 20)
data.frame(x, cluster = km$cluster)
```

base R의 `kmeans()`로 고정 자료를 군집화한 예다. `scale()`을 하지 않으면 금액 척도가 방문 횟수보다 거리에 더 큰 영향을 줄 수 있다. 군집을 “저가치·고가치”라고 이름 붙이기 전에 각 특성과 업무 활용을 검증한다.

## 2.4 연관

연관분석은 거래·사건에서 항목이 함께 나타나는 패턴을 찾는다. 규칙 \(A\Rightarrow B\)의 대표 척도는 다음과 같다.

\[
support(A\Rightarrow B)=P(A\cap B)
\]

\[
confidence(A\Rightarrow B)=P(B\mid A)
\]

\[
lift(A\Rightarrow B)=\frac{P(B\mid A)}{P(B)}
\]

100건 중 A 20건, B 40건, A와 B 동시 12건이면 지지도 0.12, 신뢰도 0.6, 향상도 \(0.6/0.4=1.5\)다. 향상도 1보다 크면 A 조건에서 B가 전체보다 자주 나타나지만 인과를 뜻하지 않는다.

연관 규칙이 많으면 최소 지지도·신뢰도·향상도뿐 아니라 중복, 실행 가능성, 계절·집단 안정성을 검토한다.

## 3. 문제 유형 비교

| 관점 | 예측·회귀 | 분류 | 군집 | 연관 |
|---|---|---|---|---|
| 목표 라벨 | 연속값 | 범주 | 없음 | 거래 내 항목 |
| 대표 출력 | 수치·구간 | 확률·클래스 | 집단·중심 | 조건부 규칙 |
| 평가 | 오차·교정 | 혼동행렬·순위 | 응집·분리·안정성 | 지지도·신뢰도·향상도 |
| 주요 함정 | 미래 누수·외삽 | 불균형·기준값 | 군집 실체화 | 상관을 인과로 해석 |
| 활용 | 수요·가격·시간 | 선별·경보 | 세분화·탐색 | 진열·추천·교차판매 후보 |

하나의 과제에 여러 유형을 결합할 수 있다. 군집별 이탈 분류를 만들거나 연관 규칙으로 후보 변수를 만든 뒤 수요를 예측할 수 있다. 그러나 각 단계의 검증과 데이터 누수를 구분한다.

## 4. 모형 정확도와 설명 가능성

**`모형 정확도와 설명 가능성`**은 항상 반대되는 두 극이 아니다. 좋은 데이터·적절한 구조로 둘 다 개선할 수 있지만, 실제 선택에서는 성능·설명·비용·위험을 함께 비교한다.

## 4.1 정확도의 범위

정확도는 문제에 맞는 평가 자료·지표에서 정의해야 한다.

- 새로운 기간·고객에서 일반화되는가?
- 평균뿐 아니라 중요한 집단·꼬리에서 유지되는가?
- 확률점수가 실제 빈도와 맞게 교정되는가?
- 기준선보다 실질적으로 개선되는가?
- 데이터·정책 변화 뒤에도 유지되는가?

학습 점수나 무작위 행 분할 점수만 높다고 실제 정확도가 높은 것은 아니다.

## 4.2 설명 가능성의 층위

1. **전체 구조 설명**: 어떤 변수가 전반적으로 중요하고 방향이 어떤가?
2. **개별 결과 설명**: 특정 고객이 높은 점수를 받은 주요 근거는 무엇인가?
3. **과정 설명**: 어떤 데이터·버전·검증·승인으로 결과가 만들어졌는가?
4. **업무 설명**: 사용자가 어떤 조건에서 무엇을 해야 하고 하지 말아야 하는가?

계수·나무 경로가 보인다고 설명이 완전한 것은 아니다. 상관 변수, 상호작용, 대리변수, 데이터 편향이 해석을 바꿀 수 있다. 사후 설명도 모델 동작의 근사일 수 있으므로 안정성과 충실도를 확인한다.

## 4.3 설명과 인과의 구분

모델에서 중요한 변수가 결과의 원인이라는 뜻은 아니다. 높은 이탈위험 고객에게 최근 상담이 많다는 관계는 상담이 이탈을 일으켰기 때문이 아니라 문제가 생겨 상담이 늘었을 수 있다. 개입 효과에는 실험·인과 설계가 필요하다.

## 4.4 선택 기준

| 상황 | 정확도 요구 | 설명 요구 | 판단 예 |
|---|---|---|---|
| 내부 수요 집계 | 오차·안정성 중요 | 전체 요인 설명 유용 | 운영 비용과 재현성 우선 |
| 신용·의료 지원 | 오류 비용 매우 큼 | 개별 근거·감사 중요 | 인간 검토와 강한 통제 |
| 탐색 군집 | 정답 라벨 없음 | 집단 특성·안정성 중요 | 해석 가능한 변수와 반복 검증 |
| 추천 후보 | 순위 성능 중요 | 사용자·운영 설명 필요 | 다양성·부작용 함께 평가 |

설명성이 필요한 곳에서 성능을 전혀 보지 않거나, 성능이 높은 곳에서 설명·감사를 생략하는 양자택일은 피한다.

## 5. 분석 결과의 업무 적용

**`분석 결과의 업무 적용`**은 출력이 실제 업무 흐름에서 행동·성과·책임으로 이어지게 설계하는 과정이다.

## 5.1 사용 시나리오

```text
사용자: 갱신 상담 관리자
시점: 매주 월요일, 갱신 30일 전
입력: 최신 데이터 시각·품질 상태
출력: 위험 순위, 확률, 주요 근거
행동: 하루 처리 한도 내 상담 배정
금지: 점수만으로 계약 거절
기록: 실제 연락·결과·이의제기
```

점수가 높다는 것과 반드시 조치해야 한다는 것은 다르다. 조치의 비용·효과·규제와 사용자의 권한을 고려한다.

## 5.2 기준선과 현장 평가

기존 규칙·무작위·단순 평균 같은 기준선과 비교한다. 오프라인 점수가 높아도 현장 사용자가 결과를 늦게 받거나 행동할 자원이 없으면 가치가 없다. 제한된 A/B 시험·단계 전개로 업무 효과와 부작용을 측정할 수 있다.

모델 효과와 개입 효과를 구분한다. 위험을 잘 맞히는 모델이라도 상담 프로그램이 효과가 없으면 유지율은 오르지 않는다.

## 5.3 인간 검토와 자동화 수준

- 정보 제공: 보고서·패턴을 사람이 해석
- 우선순위 지원: 점수로 검토 순서 제안
- 승인 지원: 모델 제안 후 사람이 최종 결정
- 제한 자동화: 낮은 위험·명확한 조건에서 자동 처리
- 완전 자동화: 높은 신뢰·통제·복구가 있을 때만

오류 피해, 이의제기, 설명 요구, 시간 한도에 따라 정한다. 고위험 결정을 효율만 보고 완전 자동화하지 않는다.

## 5.4 시스템·운영 통합

배치·실시간 제공, 인터페이스, 권한, 지연, 실패 기본동작, 버전·원복을 설계한다. 학습과 운영의 변수 계산이 같아야 한다. 입력값이 없거나 범위를 벗어나면 조용히 임의 점수를 내지 않고 상태를 표시한다.

## 5.5 모니터링

| 감시 층위 | 예시 |
|---|---|
| 데이터 | 결측률, 범주·분포, 스키마, 지연 |
| 모델 | 오차, 순위, 교정, 집단별 성능 |
| 시스템 | 처리량, 응답시간, 실패·원복 |
| 업무 | 매출·비용·해결률·사용률 |
| 위험 | 차별·민원·오류 피해·이의제기 |

목표값이 늦게 생기면 즉시 확인할 입력·점수 분포와 사후 성능을 구분한다. 경보 임계값과 책임자, 재학습·중단 기준을 둔다.

## 6. 결과 해석 절차

### 단계 1: 문제·대상·기준 시점 확인

어떤 모집단·기간·행동에 대한 결과인지 확인한다. 학습 범위 밖에 적용하지 않는다.

### 단계 2: 평가 설계와 기준선 확인

분할·누수·표본 수·지표와 단순 기준선을 본다. 모델 이름보다 평가 근거가 먼저다.

### 단계 3: 출력 의미와 불확실성 확인

확률인지 점수인지, 군집 번호인지, 연관 규칙인지 구분한다. 임계값·구간·표본 변동과 오류 비용을 함께 본다.

### 단계 4: 설명의 한계 확인

전역·개별 설명, 상관·인과, 대리변수와 집단 안정성을 검토한다.

### 단계 5: 업무 행동과 제약 연결

사용자·시점·가능·금지 행동, 처리 용량, 인간 검토와 이의제기를 정한다.

### 단계 6: 점진 적용·감시

기준선 대비 현장 효과와 부작용을 시험하고 데이터·모델·업무·위험 감시를 운영한다.

## 7. 사례: 온라인 쇼핑 분석 포트폴리오

회사는 구매 전환과 고객 경험을 개선하려 한다.

- 예측: 다음 주 상품 수요와 오차구간을 예측해 발주량을 지원한다.
- 분류: 결제 시점 사기확률을 산출해 검토 큐를 우선순위화한다.
- 군집: 최근성·빈도·금액으로 고객군을 탐색하고 안정성과 차별적 행동 가능성을 검증한다.
- 연관: 함께 구매되는 항목 규칙을 후보로 찾되 인기도가 높은 상품 때문에 생긴 규칙은 향상도로 점검한다.

사기 모델 정확도가 높아도 정상 고객 차단 비용이 크므로 자동 차단보다 인간 검토를 둔다. 고객군 이름은 군집 중심을 보고 붙이며 보호 특성의 대리변수를 점검한다. 연관 규칙은 추천 실험에서 구매·다양성·불편을 함께 측정한다.

- [ ] 기준 시점·예측 지평·분석 단위가 명확하다.
- [ ] 군집 번호와 연관 규칙을 실제 원인·정답처럼 해석하지 않았다.
- [ ] 정확도가 독립 평가와 중요한 집단에서 측정됐다.
- [ ] 설명의 전역·개별·과정·업무 수준을 구분했다.
- [ ] 변수 중요도를 인과 효과로 바꾸지 않았다.
- [ ] 사용자·시점·행동·금지 행동과 처리 용량이 있다.
- [ ] 모델 효과와 업무 개입 효과를 별도로 측정했다.
- [ ] 인간 검토·이의제기·원복 수준이 위험에 맞다.
- [ ] 데이터·모델·시스템·업무·위험 감시가 연결된다.

## 9. 자주 틀리는 시험 함정

1. 연속값 예측과 범주 분류의 출력·평가를 같은 것으로 본다.
2. 군집 결과를 사전에 존재한 정답 클래스라고 본다.
3. 연관 규칙의 높은 신뢰도를 인과관계로 해석한다.
4. 향상도 없이 인기 상품 규칙을 유용하다고 본다.
5. 학습 정확도를 실제 일반화 정확도로 보고한다.
6. 설명 가능한 모델이면 데이터 편향·대리변수 문제가 없다고 본다.
7. 중요 변수를 바꾸면 결과가 같은 만큼 변한다고 해석한다.
8. 점수 전달만으로 업무 적용이 완료됐다고 본다.
9. 모델 성능과 개입 프로그램의 효과를 같은 것으로 본다.
10. 운영에서 데이터·업무 효과·집단 성능 감시를 생략한다.

## 11. 정답과 해설

### 문제 1 정답과 해설

예측은 연속값·구간, 분류는 범주·확률을 낸다. 군집은 사전 라벨 없이 유사 집단, 연관은 함께 나타나는 항목의 조건부 규칙을 찾는다.

### 문제 2 정답과 해설

군집은 선택한 변수·거리·스케일·군집 수·초기값에 따른 알고리즘 결과다. 안정성·업무 의미를 검증하기 전 실제 집단으로 단정할 수 없다.

### 문제 3 정답과 해설

지지도는 12/100=0.12, 신뢰도는 12/20=0.6, 향상도는 0.6/(40/100)=1.5다.

### 문제 4 정답과 해설

독립 평가의 누수·표본 구조, 기준선, 집단·기간별 안정성, 확률 교정, 오류 비용, 처리시간·운영 재현성을 확인한다.

### 문제 5 정답과 해설

전체 설명은 모델 전반의 변수·관계와 평균적 동작을, 개별 설명은 특정 관측의 점수에 기여한 근거를 다룬다. 둘은 서로 대체하지 않는다.

### 문제 6 정답과 해설

중요도는 예측 관계를 반영하며 교란·역인과·상관 변수·대리변수의 영향을 받는다. 변수를 개입했을 때 결과 변화에는 인과 설계가 필요하다.

### 문제 7 정답과 해설

사용자, 사용 시점, 입력 최신성, 출력과 근거, 가능한·금지 행동, 처리 용량, 인간 검토, 결과 기록·이의제기·감시를 포함한다.

### 문제 8 정답과 해설

모델 효과는 결과를 얼마나 잘 예측·선별하는지다. 개입 효과는 그 점수로 상담·추천 같은 행동을 했을 때 실제 업무 결과가 얼마나 바뀌는지다.

### 문제 9 정답과 해설

문제·범위 확인 → 평가·기준선 확인 → 출력·불확실성 해석 → 설명·인과 한계 검토 → 사용자·행동·제약 설계 → 제한 시험 → 데이터·모델·업무·위험 감시 순이다.

## 12. 핵심 요약

- **`예측·분류·군집·연관 문제`**는 각각 수치, 범주, 비지도 집단, 동시 출현 규칙이라는 다른 출력과 평가·함정을 가진다.
- **`모형 정확도와 설명 가능성`**은 독립 평가 성능과 전역·개별·과정·업무 설명을 위험·비용에 맞게 함께 판단하는 것이다.
- 군집·연관·변수 중요도는 패턴이며 정답 집단이나 인과 효과로 자동 해석하지 않는다.
- **`분석 결과의 업무 적용`**은 사용자·시점·행동·용량·인간 검토·시스템·감시를 설계하고 현장 효과를 기준선과 비교하는 과정이다.
- 모델 효과와 개입 효과를 분리하고 데이터·모델·시스템·업무·공정성 변화를 지속적으로 감시해야 가치가 유지된다.
- 적용 조건과 재검증 기록을 함께 남긴다.
