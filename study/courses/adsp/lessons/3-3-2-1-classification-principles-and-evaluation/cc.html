FF 원문 제목3-3-2-1. 분류분석의 원리와 평가

학습 범위: 이 레슨은 ADsP 데이터분석 > 정형 데이터 마이닝 > 분류분석(Classification) 중 분류 문제와 목표변수, 혼동행렬 기반 평가지표, ROC 곡선과 AUC를 다룬다. 범주형 목표를 예측하는 문제를 정의하고, 양성 클래스와 기준값에 따른 혼동행렬 지표를 계산하며, 여러 기준값의 민감도–위양성률 관계와 AUC를 해석하는 것이 목표다.

분류모델은 대개 점수나 확률을 만든 뒤 기준값으로 클래스를 정한다. 따라서 성능은 모델 하나의 고정 속성이 아니라 양성 정의, 평가 표본, 기준값, 오류 비용에 따라 달라진다. 정확도 하나로 불균형 자료를 판단하지 않는다.

01

1. 분류 문제와 목표변수

분류 문제와 목표변수에서 분류는 입력변수 (X)로 범주형 목표변수 (Y)의 클래스 또는 클래스 확률을 예측하는 지도학습이다.

  • 이진분류: 사기/정상, 이탈/유지
  • 다중분류: 불량 원인 A/B/C, 문서 주제
  • 순서형 분류: 위험 낮음/중간/높음
  • 다중라벨 분류: 한 문서에 여러 주제 동시 부여

문제 유형에 따라 출력·손실·평가가 다르다. 다중분류를 여러 독립 이진문제로 바꾸면 클래스가 상호배타적인지 확인한다.

02

1.1 양성 클래스의 정의

양성(positive)은 숫자 1이나 좋은 결과를 뜻하지 않는다. 탐지·조치하려는 관심 사건이다. 질병, 사기, 불량을 양성으로 둘 수 있다. 보고서에 양성 클래스를 명시하지 않으면 민감도와 특이도를 뒤집을 수 있다.

03

1.2 기준 시점과 라벨

코드 예시 · text

기준 시점: 거래 승인 직전
입력: 그때 이용 가능한 거래·계정 정보
목표: 이후 조사로 확정된 사기 여부
출력: 사기 확률과 검토 여부

라벨이 조사 완료 뒤 생성되어도 평가 정답으로 쓸 수 있지만 입력에는 넣을 수 없다. 미확정·선별 조사만 된 사례는 라벨 편향을 만들 수 있다.

04

1.3 확률점수와 클래스

모델이 (hat p=P(Y=1mid X))를 내면 기준값 c에서

[ hat Y=begin{cases} 1,&hat pge c\ 0,&hat p<c end{cases} ]

로 분류할 수 있다. c=0.5가 항상 최적은 아니다. 유병률, 오탐·미탐 비용, 처리 용량과 확률 교정에 따라 정한다.

05

2. 혼동행렬

혼동행렬 기반 평가지표는 실제 클래스와 예측 클래스를 교차한 네 개 수에서 계산한다.

2. 혼동행렬 · 학습 표 1
실제 예측양성음성
양성TP: 참양성FN: 거짓음성
음성FP: 거짓양성TN: 참음성
  • TP: 실제 양성을 양성으로 탐지
  • FN: 실제 양성을 놓침
  • FP: 실제 음성을 잘못 경보
  • TN: 실제 음성을 정상으로 판정

행·열 배치는 소프트웨어마다 다를 수 있으므로 위치를 외우지 말고 라벨을 확인한다.

06

3. 혼동행렬 지표 공식

07

3.1 정확도와 오류율

[ Accuracy=frac{TP+TN}{TP+TN+FP+FN} ]

[ Error Rate=frac{FP+FN}{N}=1-Accuracy ]

전체 정답 비율이다. 양성이 1%인 자료에서 모두 음성으로 예측해도 정확도 99%이므로 불균형 문제에서 단독 사용하면 위험하다.

08

3.2 민감도·재현율

[ Sensitivity=Recall=TPR=frac{TP}{TP+FN} ]

실제 양성 중 찾아낸 비율이다. 질병·사기·고장 누락 비용이 클 때 중요하다.

09

3.3 특이도와 위양성률

[ Specificity=TNR=frac{TN}{TN+FP} ]

[ FPR=frac{FP}{TN+FP}=1-Specificity ]

실제 음성을 정상으로 맞힌 비율과 잘못 양성 경보한 비율이다.

10

3.4 정밀도

[ Precision=PPV=frac{TP}{TP+FP} ]

양성으로 예측한 것 중 실제 양성 비율이다. 검토 인력이 제한되거나 오탐 비용이 클 때 중요하다. 민감도와 달리 모집단 양성 비율에 영향을 크게 받는다.

11

3.5 음성예측도

[ NPV=frac{TN}{TN+FN} ]

음성 예측 중 실제 음성 비율이다. 역시 유병률·기저율에 영향을 받는다.

12

3.6 F1 점수

[ F1=2frac{Precisiontimes Recall}{Precision+Recall} =frac{2TP}{2TP+FP+FN} ]

정밀도와 재현율의 조화평균이다. TN을 직접 반영하지 않으므로 음성 성능이 중요한 상황에서는 다른 지표도 함께 본다.

13

3.7 균형정확도

[ Balanced Accuracy=frac{Sensitivity+Specificity}{2} ]

각 클래스의 재현을 같은 비중으로 평균해 불균형에서 전체 정확도보다 유용할 수 있다.

14

4. 계산 예제

200건에서 TP=40, FP=10, FN=20, TN=130이라고 하자.

4. 계산 예제 · 학습 표 2
지표계산값
정확도(40+130)/2000.850
민감도40/(40+20)0.667
특이도130/(130+10)0.929
정밀도40/(40+10)0.800
F180/(80+10+20)0.727
위양성률10/(130+10)0.071

정확도 85%만 보고하면 양성 60건 중 20건을 놓친 사실이 숨는다.

코드 예시 · r

TP <- 40; FP <- 10; FN <- 20; TN <- 130
accuracy <- (TP + TN) / (TP + FP + FN + TN)
recall <- TP / (TP + FN)
specificity <- TN / (TN + FP)
precision <- TP / (TP + FP)
f1 <- 2 * precision * recall / (precision + recall)
c(accuracy = accuracy, recall = recall, specificity = specificity,
  precision = precision, f1 = f1)

분모가 0인 지표는 정의되지 않을 수 있다. 모델이 양성을 하나도 예측하지 않으면 정밀도 분모가 0이다. 임의로 0이나 1로 두지 말고 보고 규칙을 명시한다.

15

5. 기준값과 오류 비용

기준값을 낮추면 일반적으로 양성 예측이 늘어 TP와 FP가 함께 증가하고, 민감도는 높아지며 특이도·정밀도는 낮아질 수 있다. 기준값을 높이면 반대다.

오류비용으로 기대손실을 정의할 수 있다.

[ Cost(c)=C{FN},FN(c)+C{FP},FP(c) ]

실제 비용은 고정값이 아닐 수 있다. 사기 미탐은 금액에 따라 다르고 오탐은 고객 이탈을 만들 수 있다. 처리 가능한 경보 수와 집단별 영향도 제약으로 둔다.

코드 예시 · r

actual <- c(1, 0, 1, 0, 1, 0, 0, 1)
score  <- c(.90, .80, .70, .60, .55, .40, .30, .20)
threshold <- .50
pred <- as.integer(score >= threshold)
table(actual = factor(actual, levels = c(1, 0)),
      predicted = factor(pred, levels = c(1, 0)))

이 예에서 TP=3, FP=2, FN=1, TN=2다. 기준값을 바꾸면 혼동행렬도 바뀐다.

16

6. ROC 곡선

ROC 곡선과 AUC 중 ROC(Receiver Operating Characteristic) 곡선은 모든 기준값에서 x축 FPR, y축 TPR을 그린다.

코드 예시 · text

기준값 매우 높음 → 모두 음성 → (FPR,TPR)=(0,0)
기준값을 낮춤    → 양성 예측 증가 → 오른쪽·위쪽 이동
기준값 매우 낮음 → 모두 양성 → (1,1)

왼쪽 위에 가까울수록 낮은 위양성률에서 높은 민감도를 보인다. 대각선은 무작위 순위에 해당한다. ROC는 특정 운영 기준값을 자동 선택하지 않는다.

base R로 ROC 점 계산

코드 예시 · r

thresholds <- c(Inf, sort(unique(score), decreasing = TRUE), -Inf)

roc <- do.call(rbind, lapply(thresholds, function(th) {
  pred <- as.integer(score >= th)
  TP <- sum(pred == 1 & actual == 1)
  FP <- sum(pred == 1 & actual == 0)
  FN <- sum(pred == 0 & actual == 1)
  TN <- sum(pred == 0 & actual == 0)
  data.frame(threshold = th,
             tpr = TP / (TP + FN),
             fpr = FP / (FP + TN))
}))

plot(roc$fpr, roc$tpr, type = "s", xlim = c(0, 1), ylim = c(0, 1),
     xlab = "False Positive Rate", ylab = "True Positive Rate")
abline(0, 1, lty = 2)

동점 점수의 처리, 보간 방식에 따라 세부 ROC 점 표현이 달라질 수 있다.

17

7. AUC

AUC(Area Under the ROC Curve)는 ROC 아래 면적이다.

  • 1: 모든 양성을 모든 음성보다 높은 점수로 완벽 순위
  • 0.5: 무작위 수준 순위
  • 0.5 미만: 점수 방향이 반대일 가능성 검토

AUC는 무작위로 고른 양성의 점수가 무작위로 고른 음성보다 높을 확률로 해석할 수 있고 동점은 절반으로 처리한다. 확률이 실제 빈도와 맞는 교정이나 특정 기준값의 비용을 말해 주지 않는다.

사다리꼴 근사

코드 예시 · r

roc_sorted <- roc[order(roc$fpr, roc$tpr), ]
auc <- sum(diff(roc_sorted$fpr) *
           (head(roc_sorted$tpr, -1) + tail(roc_sorted$tpr, -1)) / 2)
auc

직접 구현은 학습용이다. 실무에서는 동점·가중치·신뢰구간을 검증한 도구를 사용하되 계산 정의를 확인한다.

18

8. ROC·AUC의 한계와 보완

클래스 불균형

ROC의 FPR 분모는 많은 음성 전체라 극심한 불균형에서 오탐 절대 건수가 커도 작게 보일 수 있다. 양성 예측의 품질이 중요하면 정밀도–재현율 곡선과 경보 수를 함께 본다.

비용과 기준값

AUC가 높은 모델이 실제 비용 최소 기준에서 반드시 좋지는 않다. ROC 곡선이 서로 교차하면 관심 FPR 영역에 따라 선택이 달라진다.

교정

순위가 좋아 AUC가 높아도 예측확률 0.8인 사례가 실제 약 80% 양성인지는 별도다. 확률을 의사결정 비용에 쓰려면 교정 곡선·Brier 점수 등을 검토한다.

집단·시간 안정성

전체 AUC가 좋아도 특정 병원·고객군·기간에서 낮을 수 있다. 표본 수와 불확실성을 포함해 분해한다.

19

9. 다중분류 평가

다중분류 혼동행렬은 실제·예측 클래스별 표다. 클래스별로 한 클래스를 양성, 나머지를 음성으로 보아 지표를 계산할 수 있다.

  • macro 평균: 클래스별 지표를 같은 가중치로 평균
  • weighted macro: 클래스 크기로 가중
  • micro 평균: 모든 클래스의 TP·FP·FN을 합쳐 계산

희귀 클래스를 중요하게 볼 때 macro가 유용하고 전체 사건 기여를 볼 때 micro가 유용할 수 있다. 평균 방식과 클래스 지원 수를 명시한다.

20

10. 분류 평가 판단 절차

  1. 목표 클래스·양성·라벨 확정 시점과 적용 모집단을 정의한다.
  2. 고객·시간·기관을 고려한 독립 평가 데이터를 정한다.
  3. 확률점수와 클래스, 기준값 선택 자료를 구분한다.
  4. 혼동행렬과 정확도·민감도·특이도·정밀도·F1을 계산한다.
  5. ROC·AUC로 순위 능력을 보고 불균형이면 정밀도·경보 수를 보완한다.
  6. 오류비용·처리용량·공정성에 맞는 기준값을 검증자료에서 고른다.
  7. 테스트에서 고정 기준값 성능과 불확실성·집단·기간을 보고한다.
  8. 운영에서 입력·교정·혼동지표·경보 수·업무 효과를 감시한다.
21

11. 체크리스트

  • [ ] 양성 클래스와 기준 시점을 명시했다.
  • [ ] 확률점수와 기준값 적용 클래스를 구분했다.
  • [ ] 혼동행렬 행·열 라벨과 분모를 확인했다.
  • [ ] 불균형에서 정확도만 보고하지 않았다.
  • [ ] 민감도·정밀도·특이도를 업무 비용과 연결했다.
  • [ ] 기준값을 테스트가 아닌 검증자료에서 선택했다.
  • [ ] ROC가 TPR 대 FPR 곡선임을 확인했다.
  • [ ] AUC를 교정·특정 기준값 성능과 혼동하지 않았다.
  • [ ] 전체뿐 아니라 집단·기간·경보 절대 수를 봤다.
  • [ ] 다중분류 평균 방식과 클래스별 표본 수를 보고했다.

12. 자주 틀리는 시험 함정

  1. 양성을 항상 좋은 결과 또는 숫자 1이라고 본다.
  2. 정확도와 정밀도를 같은 지표로 본다.
  3. 민감도의 분모를 예측 양성 수로 둔다.
  4. 특이도와 위양성률을 같은 방향으로 해석한다.
  5. F1이 TN 성능까지 충분히 반영한다고 본다.
  6. 기준값을 낮추면 민감도와 특이도가 모두 증가한다고 본다.
  7. ROC의 x축을 정밀도, y축을 재현율로 본다.
  8. AUC가 높으면 확률 교정도 완벽하다고 본다.
  9. 테스트에서 가장 좋은 기준값을 골라 같은 성능을 보고한다.
  10. 다중분류 macro와 micro 평균을 구분하지 않는다.

14. 정답과 해설

문제 1 정답과 해설

모델은 양성 확률 또는 순위 점수를 내고, 미리 정한 기준값 이상을 양성으로 바꾼다. 기준값이 바뀌면 같은 점수에서도 혼동행렬이 달라진다.

문제 2 정답과 해설

TP는 실제·예측 양성, FP는 실제 음성·예측 양성, FN은 실제 양성·예측 음성, TN은 실제·예측 음성이다.

문제 3 정답과 해설

정확도 170/200=0.85, 민감도 40/60≈0.667, 특이도 130/140≈0.929, 정밀도 40/50=0.8, F1=80/110≈0.727이다.

문제 4 정답과 해설

모두 음성으로 예측해도 99% 정확도를 얻지만 양성을 하나도 찾지 못한다. 민감도·정밀도·특이도와 오류비용을 함께 봐야 한다.

문제 5 정답과 해설

양성 예측이 늘어 실제 양성을 더 찾아 민감도가 증가하는 한편 음성을 양성으로 잘못 예측해 위양성률도 증가하는 경향이 있다.

문제 6 정답과 해설

x축은 FPR=1-특이도, y축은 TPR=민감도다. 왼쪽 위는 낮은 위양성률로 높은 양성 탐지를 뜻한다.

문제 7 정답과 해설

무작위 양성 점수가 무작위 음성보다 높을 확률로 해석할 수 있다. 특정 기준값의 비용·혼동행렬과 확률 교정을 말해 주지 않는다.

문제 8 정답과 해설

정밀도–재현율, 양성 예측·오탐 절대 건수, 처리 용량과 집단별 지표를 함께 본다.

문제 9 정답과 해설

양성·표본 정의 → 독립 분할 → 검증자료의 점수·혼동지표·ROC 계산 → 오류비용·용량으로 기준값 선택 → 기준값 고정 → 테스트 성능·불확실성·집단 보고 → 운영 감시 순이다.

15. 핵심 요약

  • 분류 문제와 목표변수는 범주형 결과를 예측하며 양성 정의, 기준 시점, 확률점수와 기준값을 명확히 해야 한다.
  • 혼동행렬 기반 평가지표는 TP·FP·FN·TN에서 정확도, 민감도, 특이도, 정밀도, F1을 계산하고 오류비용에 맞춰 해석한다.
  • ROC 곡선과 AUC는 여러 기준값의 FPR–TPR과 순위 능력을 요약하지만 교정·특정 기준값 비용·운영 용량을 대신하지 않는다.
  • 불균형 자료에서는 정확도와 ROC만 보지 않고 정밀도–재현율, 경보·오탐 절대 수와 집단별 성능을 함께 본다.
  • 기준값은 검증자료에서 선택하고 테스트에서는 고정된 전체 절차를 최종 평가해 운영 모니터링으로 연결한다.
