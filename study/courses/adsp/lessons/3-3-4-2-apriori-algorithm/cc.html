FF 원문 제목3-3-4-2. Apriori 알고리즘

학습 범위: 이 레슨은 ADsP 데이터 분석 > 데이터 마이닝 > 연관분석 중 빈발 항목집합, Apriori 원리와 후보 생성, 최소 지지도와 규칙 생성을 다룬다. 항목 조합을 무작정 모두 세지 않고 하위집합의 빈발 여부로 후보를 가지치기하는 원리, 단계별 지지도 계산, 빈발 항목집합에서 방향 규칙을 만드는 절차를 정확히 이해하는 것이 목표다.

상품이 1,000개면 가능한 비어 있지 않은 항목집합은 2^1000-1개다. 모든 조합을 직접 세는 것은 현실적이지 않다. Apriori는 “어떤 항목집합이 자주 나타나지 않으면 그것을 포함하는 더 큰 집합도 자주 나타날 수 없다”는 단순하지만 강력한 성질로 탐색 공간을 줄인다.

01

1. 빈발 항목집합

1.1 지지도 개수와 최소 지지도

빈발 항목집합은 사용자가 정한 최소 지지도 이상으로 나타나는 항목집합이다. 전체 거래 수가 N, 항목집합 X를 포함한 거래 수가 σ(X)라면 다음과 같다.

코드 예시 · text

support(X) = σ(X) / N
X가 빈발 ⇔ support(X) ≥ minsup

최소 지지도 minsup=0.20, 거래 1,000건이라면 최소 지지도 개수는 200건이다. 경계값을 포함하는 ≥인지 구현을 확인하되 일반적으로 기준 이상을 빈발로 본다.

1.2 k-항목집합 표기

  • Ck: 평가할 후보 k-항목집합 모음
  • Lk: 최소 지지도를 통과한 빈발 k-항목집합 모음

Apriori는 C1을 세어 L1을 만들고, L1으로 C2를 생성해 L2를 만들며, 더 이상 빈발 항목집합이 없을 때까지 반복한다.

코드 예시 · text

C1 → 지지도 필터 → L1
L1 → 결합·가지치기 → C2 → 지지도 필터 → L2
L2 → 결합·가지치기 → C3 → 지지도 필터 → L3
...

빈발은 수익성·인과성·추천 가치와 같지 않다. 단지 거래 자료에서 최소 빈도 이상 관찰됐다는 뜻이다.

02

2. Apriori 원리

2.1 하향 폐쇄 성질

Apriori 원리와 후보 생성의 핵심은 지지도의 반단조성 또는 하향 폐쇄 성질이다.

빈발 항목집합의 모든 비어 있지 않은 부분집합도 반드시 빈발이다.

동치인 대우는 다음과 같다.

빈발하지 않은 항목집합의 모든 상위집합은 빈발할 수 없다.

항목집합 X에 항목을 더해 Y를 만들면 Y를 포함하는 거래는 반드시 X도 포함한다. 따라서 X⊂Y이면 support(Y)≤support(X)다. 항목을 추가할수록 지지도는 증가할 수 없다.

2.2 가지치기의 논리

{빵, 우유}가 최소 지지도를 통과하지 못했다면 {빵, 우유, 치즈}, {빵, 우유, 치즈, 버터}도 통과할 수 없다. 더 큰 집합을 포함하는 거래 수가 그 부분집합보다 많아질 수 없기 때문이다.

반대로 {빵}과 {우유}가 둘 다 빈발이라고 {빵, 우유}가 반드시 빈발인 것은 아니다. 각각은 자주 팔려도 서로 다른 거래에서 팔릴 수 있다. Apriori 원리는 필요조건을 주지만 상위집합의 빈발성을 보장하는 충분조건은 아니다.

2.3 시험 핵심 문장

  • 빈발 k-항목집합의 모든 (k-1) 부분집합은 빈발이다 → 맞다.
  • 어떤 부분집합 하나라도 비빈발이면 그 후보는 제거한다 → 맞다.
  • 모든 부분집합이 빈발이면 상위집합도 자동 빈발이다 → 틀리다. 실제 지지도를 세야 한다.
  • 항목을 추가하면 지지도는 같거나 감소한다 → 맞다.
03

3. Apriori 후보 생성

3.1 전체 알고리즘

코드 예시 · text

입력: 거래 데이터 D, 최소 지지도 minsup
1. 모든 1-항목집합의 지지도를 세어 L1 생성
2. k=2로 설정
3. L(k-1)의 항목집합을 자기결합하여 Ck 생성
4. 후보의 모든 (k-1) 부분집합이 L(k-1)에 있는지 검사해 가지치기
5. 데이터베이스를 스캔해 Ck의 지지도 개수 계산
6. minsup 이상인 후보만 Lk에 유지
7. Lk가 비어 있지 않으면 k를 1 증가시키고 3으로 반복
8. 모든 Lk의 합을 빈발 항목집합으로 반환

3.2 결합 단계

정렬된 (k-1)-항목집합 두 개가 앞의 k-2개 항목이 같고 마지막 항목만 다르면 결합해 k-항목 후보를 만든다.

예를 들어 L2에 {A,B}, {A,C}, {A,D}, {B,C}가 있다면:

  • {A,B}와 {A,C}를 결합해 {A,B,C} 후보
  • {A,B}와 {A,D}를 결합해 {A,B,D} 후보
  • {A,C}와 {A,D}를 결합해 {A,C,D} 후보

정렬 기준을 고정하면 같은 후보의 중복 생성을 줄인다.

3.3 가지치기 단계

후보 {A,B,D}의 2-항목 부분집합은 {A,B}, {A,D}, {B,D}다. 이 중 {B,D}가 L2에 없다면 후보를 제거한다. 전체 후보의 실제 지지도를 세기 전에 불가능한 조합을 없앤다.

코드 예시 · text

후보 c가 Ck에 남는 조건:
모든 (k-1)-부분집합 s⊂c에 대해 s∈L(k-1)

부분집합 검사는 바로 한 단계 아래만 확인해도 된다. L(k-1) 자체가 이미 그 아래 모든 부분집합의 빈발 조건을 통과했기 때문이다.

3.4 지지도 계수

가지치기를 통과한 후보에 대해 각 거래가 후보를 포함하는지 검사해 개수를 센다. 구현은 후보 트리, 해시, 비트 벡터 등을 사용해 효율화할 수 있다. 전통적 Apriori는 k 단계마다 데이터베이스를 다시 읽을 수 있어 거래와 후보가 많으면 입출력 비용이 크다.

04

4. 단계별 계산 사례

다섯 거래와 최소 지지도 개수 3을 사용하자.

4. 단계별 계산 사례 · 학습 표 1
거래항목
T1{A, B, C}
T2{A, C}
T3{A, B, D}
T4{B, C}
T5{A, B, C}

4.1 L1 생성

4. 단계별 계산 사례 · 학습 표 2
후보 C1지지도 개수판정
{A}4빈발
{B}4빈발
{C}4빈발
{D}1제거

따라서 L1={{A},{B},{C}}다. D가 비빈발이므로 D를 포함하는 모든 더 큰 후보는 만들 필요가 없다.

4.2 L2 생성

L1을 결합하면 C2={{A,B},{A,C},{B,C}}다.

4. 단계별 계산 사례 · 학습 표 3
후보 C2포함 거래지지도 개수판정
{A,B}T1,T3,T53빈발
{A,C}T1,T2,T53빈발
{B,C}T1,T4,T53빈발

세 후보 모두 최소 개수 3을 통과해 L2=C2다.

4.3 L3 생성

{A,B}와 {A,C}를 결합해 {A,B,C}를 만든다. 세 개의 2-항목 부분집합 {A,B}, {A,C}, {B,C}가 모두 L2에 있으므로 가지치기를 통과한다.

{A,B,C}는 T1과 T5에만 포함되어 지지도 개수 2다. 최소 개수 3보다 작아 L3은 비고 알고리즘이 끝난다.

이 사례는 모든 2-부분집합이 빈발이어도 3-항목집합은 비빈발일 수 있음을 보여 준다.

05

5. 최소 지지도와 규칙 생성

5.1 빈발 집합과 규칙은 다른 단계

최소 지지도와 규칙 생성은 다음 두 단계로 구분한다.

  1. 최소 지지도로 빈발 항목집합을 찾는다.
  2. 각 빈발 항목집합을 서로 겹치지 않는 선행부와 후행부로 나누고 최소 신뢰도를 통과하는 규칙을 찾는다.

빈발 항목집합 F에서 비어 있지 않은 진부분집합 X를 고르면 X⇒F\X라는 규칙을 만들 수 있다.

코드 예시 · text

confidence(X⇒F\X) = support(F) / support(X)

예를 들어 빈발 집합 {A,B,C}에서 다음 규칙들이 가능하다.

  • {A,B}⇒{C}
  • {A,C}⇒{B}
  • {B,C}⇒{A}
  • {A}⇒{B,C}
  • {B}⇒{A,C}
  • {C}⇒{A,B}

3개 항목이므로 2^3-2=6개의 방향 규칙이 가능하다.

5.2 규칙 지지도와 신뢰도

같은 빈발 집합 F에서 생성한 규칙들은 모두 support(F)라는 같은 규칙 지지도를 가진다. 하지만 신뢰도는 선행부 X의 지지도가 분모라 방향에 따라 다르다.

최소 신뢰도를 통과해도 향상도가 1 이하일 수 있다. 후행부가 원래 흔하면 높은 신뢰도가 자명할 수 있으므로 향상도와 업무 가치를 이후에 평가한다.

5.3 신뢰도 기반 가지치기

고정된 빈발 집합 F에 대해 후행부에 항목을 더하면 선행부가 줄고 그 지지도는 같거나 커지므로 신뢰도 support(F)/support(선행부)는 같거나 작아지는 성질을 이용할 수 있다. 작은 후행부 규칙이 최소 신뢰도를 통과하지 못하면 그 후행부를 포함하는 더 큰 후행부 후보를 가지치기할 수 있다.

이는 지지도의 Apriori 원리와 적용 단계가 다르다. 항목집합 생성에서는 최소 지지도, 규칙 생성에서는 최소 신뢰도가 주요 필터다.

06

6. 임계값이 계산량과 결과에 미치는 영향

6.1 최소 지지도가 낮을 때

  • 더 많은 1-항목과 긴 항목집합이 빈발로 남는다.
  • 후보 수와 데이터 스캔 비용이 급증한다.
  • 희귀하지만 의미 있는 규칙을 찾을 수 있다.
  • 우연·잡음 규칙과 검토 부담이 늘어난다.

6.2 최소 지지도가 높을 때

  • 후보와 규칙 수가 줄고 계산이 빨라진다.
  • 대중적인 항목 위주의 안정적 규칙이 남는다.
  • 세부 세그먼트나 희귀 고가 조합을 놓칠 수 있다.

단일 지지도를 모든 항목에 적용하면 인기 상품과 희귀 상품의 빈도 차이를 충분히 반영하지 못할 수 있다. 품목군·채널별 탐색, 최대·폐쇄 빈발 집합, FP-Growth 같은 대안도 검토한다.

6.3 최소 신뢰도의 영향

신뢰도 기준을 높이면 방향 규칙 수가 줄지만 후행부가 흔한 규칙이 계속 남을 수 있다. 향상도·절대 건수·재현성 필터가 필요하다. 임계값은 정답 숫자가 아니라 계산 가능성과 업무 검토 가능성을 맞추는 설계 변수다.

07

7. 효율과 대안

7.1 Apriori의 비용

항목과 거래가 많고 최소 지지도가 낮으면 Ck가 매우 커지며 데이터베이스를 여러 번 스캔한다. 긴 거래에는 포함 가능한 조합이 많아 후보 계수가 비싸다.

개선 아이디어는 다음과 같다.

  • 희귀·불필요 항목과 길이 짧은 거래를 목적에 맞게 정리한다.
  • 해시 트리·비트셋으로 후보 포함 검사를 빠르게 한다.
  • 거래 ID 집합의 교집합으로 지지도를 세는 수직 표현을 사용한다.
  • 빈발 패턴 트리를 압축하는 FP-Growth를 사용한다.
  • 결과 중 폐쇄 또는 최대 빈발 항목집합만 요약한다.

7.2 폐쇄·최대 빈발 집합

  • 폐쇄 빈발 항목집합: 같은 지지도를 가진 진상위집합이 없는 빈발 집합
  • 최대 빈발 항목집합: 빈발인 진상위집합이 전혀 없는 빈발 집합

최대 집합은 가장 압축적이지만 모든 부분집합의 정확한 지지도를 복원하지 못할 수 있다. 폐쇄 집합은 더 많은 정보를 보존한다. ADsP에서는 Apriori 핵심 원리와 단계가 우선이며 이 구분은 결과 축약 관점으로 이해한다.

08

8. 실전 절차와 검증

코드 예시 · text

거래 단위·항목 계층 정의
→ 항목 빈도와 거래 길이 탐색
→ 목적에 맞는 최소 지지도 설정
→ C1 계수 후 L1 생성
→ L(k-1) 결합·부분집합 가지치기로 Ck 생성
→ 후보 지지도 계수 후 Lk 생성
→ 더 이상 Lk가 없을 때 종료
→ 빈발 집합을 선행부·후행부로 분할
→ 최소 신뢰도와 향상도·절대 건수 필터
→ 기간·채널 재현성과 업무 가치 검증

시험에서 자주 나오는 함정

  • 비빈발 집합의 상위집합은 빈발일 수 있다 → 아니다. 지지도 반단조성으로 불가능하다.
  • 모든 부분집합이 빈발이면 후보도 반드시 빈발이다 → 아니다. 실제 지지도를 계산해야 한다.
  • Apriori는 큰 항목집합부터 작은 집합으로 내려간다 → 아니다. 1-항목부터 상향식으로 확장한다.
  • 후보 생성의 결합만 하고 부분집합 검사는 생략해도 원리는 같다 → 결과는 같을 수 있어도 Apriori의 핵심 가지치기 효율을 잃는다.
  • 빈발 항목집합을 찾으면 방향 규칙이 자동으로 최소 신뢰도를 통과한다 → 아니다. 각 방향의 신뢰도를 계산한다.
  • 최소 지지도를 낮추면 일반적으로 후보와 계산량이 감소한다 → 반대다. 증가한다.
  • {A,B,C}의 한 2-부분집합이 비빈발이면 {A,B,C}는 가지치기한다 → 맞다.
09

핵심 요약

  • 빈발 항목집합은 최소 지지도 이상의 거래에 나타나는 항목 조합이다.
  • Apriori 원리는 빈발 항목집합의 모든 부분집합이 빈발이며, 비빈발 집합의 모든 상위집합은 비빈발이라는 지지도 반단조성이다.
  • L(k-1)의 항목집합을 결합해 Ck를 만들고, 모든 (k-1) 부분집합이 빈발인지 검사한 뒤 실제 지지도를 센다.
  • 모든 부분집합이 빈발인 것은 후보가 될 필요조건일 뿐 실제 빈발성을 보장하지 않는다.
  • 빈발 항목집합을 비어 있지 않은 선행부와 후행부로 나눈 뒤 최소 신뢰도로 방향 규칙을 필터링한다.
  • 낮은 최소 지지도는 희귀 패턴을 살리지만 후보 폭발·잡음·검토 비용을 늘리므로 절대 건수와 업무 목적을 함께 고려한다.

11

정답 및 해설

정답 1

항목집합 X의 지지도 σ(X)/N이 최소 지지도 이상이면 빈발이다. σ(X)는 X를 포함한 거래 수이고 상대 지지도는 이를 전체 거래 수 N으로 나눈 값이다.

정답 2

빈발 항목집합의 모든 부분집합은 빈발이다. 대우로는 어떤 항목집합이 비빈발이면 그것을 포함하는 모든 상위집합도 비빈발이다.

정답 3

Y를 포함하는 모든 거래는 부분집합 X도 반드시 포함하므로 Y의 포함 거래 집합은 X의 포함 거래 집합의 부분집합이다. 따라서 개수와 지지도는 증가할 수 없다.

정답 4

Ck는 실제 지지도를 평가할 후보 k-항목집합 모음이고, Lk는 그 후보 중 최소 지지도를 통과한 빈발 k-항목집합 모음이다.

정답 5

모든 (k-1)=2 항목 부분집합, 즉 {A,B}, {A,C}, {B,C}가 L2에 있는지 검사한다. 하나라도 없으면 후보를 제거한다.

정답 6

아니다. 부분집합의 빈발성은 후보가 될 필요조건일 뿐이다. 세 항목이 동시에 나타나는 거래는 최소 지지도보다 적을 수 있으므로 직접 계수해야 한다.

정답 7

비어 있지 않은 진부분집합을 선행부로 고르므로 2^4-2=14개다.

정답 8

confidence(X⇒F\X)=support(F)/support(X)다. 규칙의 합집합은 F이기 때문이다.

정답 9

더 많은 항목집합이 빈발로 남아 후보와 계산량이 증가하고, 희귀 패턴을 발견할 가능성도 높아진다. 동시에 잡음 규칙과 검토 부담도 늘어난다.

정답 10

각 k 단계에서 거래 데이터베이스를 반복 스캔할 수 있고, 항목이 많거나 최소 지지도가 낮으면 결합으로 생성되는 후보 항목집합 수가 폭발한다.
