2-1-1-1. 결측값과 이상값 진단

🔍 지우기 전에,
먼저 의심하자

데이터 정제에서 가장 먼저 할 일은 값을 없애거나 바꾸는 게 아니야. 먼저 어떤 값이 정제 대상인지 진단해야 해.

🧭 먼저 잡아야 할 핵심: “이상하다”와 “잘못됐다”는 다르다

데이터 정제의 판단은 세 단계로 구분하면 돼.

STEP 1
탐색
수상한 값을 찾는다
→
STEP 2
판단
오류인지 의미를 확인한다
→
STEP 3
처리
삭제·대체·유지를 결정한다
예: 나이 = 120세

흔하지 않으니까 이상값 후보는 맞아. 하지만 실제 120세인 사람일 수도 있어. 따라서 바로 삭제하면 안 돼.

예: 나이 = -3세

단순히 통계적으로 특이한 정도가 아니라 변수의 의미상 불가능한 값이야. 정제 필요성이 훨씬 강해.

이상값(outlier) ≠ 오류값(error)

🕳️ 1. 결측값 탐색

결측값은 관측되어야 할 값이 비어 있는 상태야. pandas에서는 보통 NaN, None 등이 결측으로 인식돼.

가장 먼저 보는 코드

df.isna().sum()

열별 결측값 개수를 확인해.

age        3
income    12
gender     0

이 결과라면 income에 결측이 가장 많이 있다는 뜻이야. 

df.isna().mean()
df.isna().mean() * 100

mean()을 이용하면 열별 결측 비율을 볼 수 있어.

전체 구조를 빠르게 확인하는 방법

df.info()

Non-Null Count를 보면 각 열의 비결측 데이터 수를 확인할 수 있어. 

df.describe(include='all')
코드 주로 확인하는 것
df.info()자료형, non-null 개수
df.isna().sum()결측값 개수
df.isna().mean()결측값 비율
df.describe()수치형 분포
df.describe(include='all')범주형까지 포함한 요약

import numpy as np

단, 무조건 변환하면 안 돼. Unknown이 정말 결측을 뜻하는지는 데이터 정의를 먼저 확인해야 해.

📊 3. 이상값 탐색

이상값은 주변 값들과 비교했을 때 유난히 다른 관측값이야. 이상값을 찾는 방법은 크게 두 종류로 생각하면 편해.

의미를 이용한 이상값 탐색

  • 나이 -5
  • 시험점수 130 / 100
  • 월 15월
  • 비율 -20%
  • 사람 키 25m
df[df['age'] < 0]

df[
    (df['score'] < 0) |
    (df['score'] > 100)
]

변수의 의미를 이용하는 논리적·도메인 기반 검증이야.

분포를 이용한 이상값 탐색

도메인상 가능한 값이어도 다른 데이터와 비교하면 지나치게 클 수 있어.

3000 · 3500 · 4000 · 4200 · 5000 · 50000

이런 경우 50000은 이상값 후보가 될 수 있어.

📐 IQR로 이상값 찾기

IQR은 데이터를 4등분해서 분포의 가운데 50% 폭을 이용하는 방식이야.

Q1
아래쪽 25% 지점
Q3
아래쪽 75% 지점
IQR
Q3 - Q1
하한: Q1 − 1.5 × IQR
상한: Q3 + 1.5 × IQR
Q1 = df['income'].quantile(0.25)
Q3 = df['income'].quantile(0.75)

IQR = Q3 - Q1

lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR
outlier = df[
    (df['income'] < lower) |
    (df['income'] > upper)
]
IQR은 삭제 공식이 아니야. IQR 범위를 벗어났다는 것은 “이 데이터를 한 번 확인해봐”라는 신호에 가까워.

📦 4. describe()로 이상값 냄새 맡기

df.describe()

나이 변수라면 min=-5, max=999가 바로 눈에 띄지. 즉 describe()는 이상값을 확정하는 함수라기보다 어디를 조사할지 찾는 진단 도구라고 보면 돼. 

df['city'].value_counts(dropna=False)
Seoul     800

이 경우 이상값 문제가 아니라 표기 불일치일 가능성도 발견할 수 있어.

⚖️ 6. 가장 중요한 단계: 정제가 필요한가?

결측값이라면

df.isna().mean()
일부 행만 결측인가?
특정 열 전체에 많이 발생했나?
중요한 변수인가?
목표변수에 결측이 있는가?
사용할 분석 방법이 결측값을 허용하는가?

결측값이 있다고 해서 항상 행을 삭제하는 건 아니야. 이후에는 행 삭제, 열 삭제, 평균·중앙값·최빈값 대체, 그룹별 대체, 추정, 결측 자체를 정보로 활용하는 방법까지 연결돼.

🚨 이상값도 마찬가지야

첫 번째 질문: 물리적으로 가능한가?
age = -10 → 거의 명백한 오류.
두 번째 질문: 실제로 발생 가능한가?
income = 1,000,000,000 → 극단적이지만 실제로 가능할 수 있음.
세 번째 질문: 분석 결과를 크게 왜곡하는가?
평균이나 선형 모델처럼 극단값에 민감한 방법에서는 영향이 커질 수 있어.
네 번째 질문: 측정 오류인가, 중요한 사건인가?
금융 사기 탐지에서는 이상치가 오히려 찾으려는 대상일 수 있어.
이상값 탐색은 삭제 후보를 찾는 과정이 아니라
검토 대상을 찾는 과정이다.

🏁 이번 단원의 도착점

2-1-1-1. 결측값과 이상값 진단에서 가져가야 할 건 함수 목록이 아니라 판단 순서야.

결측값은 isna()로 시작하되 숨은 결측값까지 의심한다.
이상값은 도메인 기준과 통계적 기준을 구별한다.
정제 대상이라고 탐지된 값과
실제로 제거해야 하는 값은 같지 않다.

이 원칙만 확실하면 이후의 결측값 처리, 이상값 처리, 데이터 변환이 자연스럽게 연결돼.
