흔하지 않으니까 이상값 후보는 맞아.

하지만 실제 120세인 사람일 수도 있어.

반대로 나이가 -3세라면?

단순히 통계적으로 특이한 정도가 아니라

🕳️ 1. 결측값 탐색

결측값은 관측되어야 할 값이 비어 있는 상태야.

pandas에서는 보통 NaN, None 등이 결측으로 인식돼.

가장 먼저 보는 코드
Python
실행됨
df.isna().sum()

열별 결측값 개수를 확인해.

예를 들어 결과가

age        3
income    12
gender     0

라면 income에 결측이 가장 많이 있다는 뜻이야.

비율까지 보고 싶으면:

Python
실행됨
df.isna().mean()

True = 1, False = 0처럼 계산되기 때문에 열별 결측 비율이 나와.

Python
실행됨
df.isna().mean() * 100

으로 쓰면 퍼센트로 볼 수 있고.

전체 구조를 빠르게 확인하는 방법
Python
실행됨
df.info()

Non-Null Count를 보면 각 열의 비결측 데이터 수를 확인할 수 있어.

그리고 데이터 자체의 전체적인 상태를 볼 때는:

Python
실행됨
df.describe(include='all')

도 유용해.

핵심 역할을 구별하면:

코드	주로 확인하는 것
df.info()	자료형, non-null 개수
df.isna().sum()	결측값 개수
df.isna().mean()	결측값 비율
df.describe()	수치형 분포
df.describe(include='all')	범주형까지 포함한 요약
🕵️ 2. 진짜 조심할 것: “숨은 결측값”

시험이나 실제 데이터에서는 이 부분이 꽤 중요해.

다음 값들을 생각해봐.

NaN
None
""
"NA"
"N/A"
"unknown"
"-"
-999

사람 눈에는 전부 “값이 없는 것처럼” 보일 수 있어.

하지만 pandas가 전부 자동으로 결측값으로 판단하는 건 아니야.

예를 들어:

Python
실행됨
df.isna().sum()

을 실행해도 "unknown"이나 -999는 일반적인 값으로 남아 있을 수 있어.

그래서 범주형 데이터라면 이런 식의 확인도 중요해.

Python
실행됨
df['gender'].value_counts(dropna=False)

또는

Python
실행됨
df['gender'].unique()

예를 들어 결과가

M
F
Unknown
NaN

이라면 Unknown을 실제 하나의 범주로 볼지, 결측으로 볼지 판단해야 하지.

필요하다면:

Python
실행됨
import numpy as np

df['gender'] = df['gender'].replace('Unknown', np.nan)

처럼 변환할 수 있어.

단, 여기서 중요한 건 무조건 변환하면 안 된다는 것이야.

Unknown이 정말 결측을 뜻하는지는 데이터 정의를 먼저 확인해야 해.

📊 3. 이상값 탐색

이상값은 주변 값들과 비교했을 때 유난히 다른 관측값이야.

하지만 이상값을 찾는 방법은 크게 두 종류로 생각하면 편해.

의미를 이용한 이상값 탐색

가장 먼저 해야 하는 방법이야.

예를 들어:

나이 -5

시험점수 130 / 100

월 15월

비율 -20%

사람 키 25m

이런 값들은 분포를 계산하기 전에 변수의 의미만으로도 의심할 수 있어.

pandas에서는 조건식으로 찾을 수 있지.

Python
실행됨
df[df['age'] < 0]

또는

Python
실행됨
df[(df['score'] < 0) | (df['score'] > 100)]

이런 검사를 흔히 논리적·도메인 기반 검증이라고 생각하면 돼.

분포를 이용한 이상값 탐색

도메인상 가능한 값이어도 다른 데이터와 비교하면 지나치게 클 수 있어.

예를 들어 대부분의 연봉이

3000
3500
4000
4200
5000

인데 한 사람만

50000

이라면 이상값 후보가 될 수 있지.

여기서 많이 쓰는 방법이 IQR이야.

📐 IQR로 이상값 찾기

IQR은 먼저 데이터를 4등분해 생각해.

Q1: 아래쪽 25% 지점

Q3: 아래쪽 75% 지점

IQR = Q3 - Q1

그리고 일반적으로 다음 범위를 벗어난 데이터를 이상값 후보로 본다.

Q1−1.5×IQR

보다 작거나,

Q3+1.5×IQR

보다 큰 값이야.

pandas에서는 이렇게 구현할 수 있어.

Python
실행됨
Q1 = df['income'].quantile(0.25)
Q3 = df['income'].quantile(0.75)

IQR = Q3 - Q1

lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

이상값을 실제로 골라내면:

Python
실행됨
outlier = df[
    (df['income'] < lower) |
    (df['income'] > upper)
]

한 번에 조건만 만들 수도 있어.

Python
실행됨
mask = (
    (df['income'] < lower) |
    (df['income'] > upper)
)

그리고

Python
실행됨
df[mask]

로 이상값 후보 행을 확인해.

여기서 시험 사고방식

IQR은 삭제 공식이 아니야.

IQR 범위를 벗어났다는 것은

“이 데이터를 한 번 확인해봐.”

라는 신호에 가까워.

정상적인 고소득자가 들어 있다면 큰 값이어도 유지해야 할 수 있어.

📦 4. describe()로 이상값 냄새 맡기

실기에서는 코드를 길게 쓰기 전에 먼저:

Python
실행됨
df.describe()

를 보는 습관이 좋아.

예를 들어 나이 변수에서:

min      -5
25%      29
50%      38
75%      47
max     999

가 나왔다고 해보자.

그러면 min=-5, max=999가 바로 눈에 띄지.

즉,

Python
실행됨
df.describe()

는 이상값을 확정하는 함수라기보다 어디를 조사할지 찾는 진단 도구라고 보면 돼.

범주형은 반대로:

Python
실행됨
df['city'].value_counts(dropna=False)

처럼 빈도를 보는 게 좋아.

예를 들어

Seoul     800
Busan     300
seoul       2
서울         1
NaN        10

이라면 이상값 문제가 아니라 표기 불일치일 가능성도 발견할 수 있지.

정제 대상은 결측값과 이상값만 있는 게 아니라는 것도 연결해서 기억해둬.

⚠️ 5. 특수한 값도 확인하기

수치 데이터에서는 NaN 말고도 이런 값이 들어갈 수 있어.

inf
-inf

무한대 값이야.

isna()만으로는 충분하지 않을 수 있어.

예를 들어:

Python
실행됨
import numpy as np

np.isinf(df['x']).sum()

으로 확인할 수 있어.

따라서 실제 진단에서는 머릿속에 이렇게 분리해두면 좋아.

결측값
 └─ NaN / None / 숨은 결측값

비정상 수치
 └─ inf / -inf

이상값
 ├─ 도메인상 불가능한 값
 └─ 통계적으로 지나치게 특이한 값
⚖️ 6. 가장 중요한 단계: 정제가 필요한가?

여기서 실기 사고가 한 단계 올라가.

값을 발견했다고 바로 처리하지 않아.

결측값이라면

먼저 묻는다.

결측이 얼마나 많은가?

Python
실행됨
df.isna().mean()

그리고:

일부 행만 결측인가?

특정 열 전체에 많이 발생했나?

중요한 변수인가?

목표변수에 결측이 있는가?

사용할 분석 방법이 결측값을 허용하는가?

를 판단해야 해.

결측값이 있다고 해서 항상 행을 삭제하는 건 아니야.

가능한 선택지는 이후에 배우게 될:

행 삭제

열 삭제

평균·중앙값·최빈값 대체

그룹별 대체

다른 방법으로 추정

결측 자체를 하나의 정보로 활용

등이 있어.

🚨 이상값도 마찬가지야

이상값을 발견하면 다음 순서로 생각하면 좋아.

첫 번째 질문: 물리적으로 가능한가?

age = -10

→ 거의 명백한 오류.

두 번째 질문: 실제로 발생 가능한가?

income = 1,000,000,000

→ 극단적이지만 실제로 가능할 수 있음.

세 번째 질문: 분석 결과를 크게 왜곡하는가?

평균이나 선형 모델처럼 극단값에 영향을 많이 받는 방법이라면 문제가 커질 수 있어.

네 번째 질문: 측정 오류인가, 중요한 사건인가?

예를 들어 금융 사기 탐지에서는 이상치가 오히려 찾으려는 대상일 수 있어.

이상값을 제거해버리면 중요한 정보를 없애는 셈이지.

그래서 기억할 문장은 하나야.

이상값 탐색은 삭제 후보를 찾는 과정이 아니라 검토 대상을 찾는 과정이다.

🧠 7. 실기에서 바로 쓸 수 있는 진단 순서

데이터를 받으면 이런 흐름으로 보는 게 안정적이야.

Python
실행됨
# 1. 데이터 구조
df.shape
df.info()

# 2. 일부 데이터
df.head()

# 3. 기술통계
df.describe(include='all')

# 4. 결측값
df.isna().sum()
df.isna().mean()

# 5. 범주형 값 확인
df['category'].value_counts(dropna=False)

# 6. 수치형 이상값 후보 확인
Q1 = df['x'].quantile(0.25)
Q3 = df['x'].quantile(0.75)
IQR = Q3 - Q1

lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

df[(df['x'] < lower) | (df['x'] > upper)]

하지만 이걸 그대로 외우는 것보다 더 중요한 건 각 코드의 질문을 아는 것이야.

코드	데이터에게 묻는 질문
shape	데이터가 얼마나 큰가?
info()	자료형과 결측 상태는 어떤가?
describe()	분포가 이상하지 않은가?
isna()	명시적 결측값이 있는가?
value_counts()	이상한 범주나 숨은 결측이 있는가?
IQR	분포에서 지나치게 떨어진 값이 있는가?
조건식	의미상 불가능한 값이 있는가?

이렇게 연결해서 기억하면 코드가 안 외워져도 복구하기 쉬워.

income의 NaN을 찾아낼 수 있어.

하지만 gender='Unknown'은 잡히지 않아.

Python

은 매우 크지만 실제 고소득자일 수도 있어.

따라서 통계적으로 이상값 후보라고 해서 바로 삭제하면 안 돼.

정제 필요성 판단

결론은 각각 달라질 수 있어.

→ 결측 처리 검토

→ 오류 가능성이 매우 높음

→ 이상값 후보지만 정상 관측일 가능성 검토

같은 데이터에서도 정제 방식이 모두 다르다는 게 핵심이야.

정제 필요성 판단

🏁 이번 단원의 도착점

2-1-1-1. 결측값과 이상값 진단에서 가져가야 할 건 함수 목록이 아니라 판단 순서야.

결측값은 isna()로 시작하되 숨은 결측값까지 의심한다.

이상값은 도메인 기준과 통계적 기준을 구별한다.

그리고 가장 중요하게,

정제 대상이라고 탐지된 값과 실제로 제거해야 하는 값은 같지 않다.

이 원칙만 확실하면 이후의 결측값 처리, 이상값 처리, 데이터 변환이 자연스럽게 연결돼.
