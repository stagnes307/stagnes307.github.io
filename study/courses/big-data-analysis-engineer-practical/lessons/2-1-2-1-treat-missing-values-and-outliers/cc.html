🎯 1. 결측값과 이상값은 왜 같은 문제가 아니야?

결측값 — 값이 없는 상태

결측값은 관측되어야 할 값이 빠져 있는 상태야. pandas에서는 보통 np.nan처럼 나타나.

import numpy as np np.nan
고객나이구매금액
A2530000
BNaN45000
C38NaN
df.isna() df.isna().sum() df.notna()

이상값 — 값은 있지만 비정상적으로 튀는 상태

예를 들어 사람의 나이가 다음과 같다고 해보자.

22, 25, 28, 31, 29, 999

999는 값 자체는 존재해. 그래서 결측값은 아니야. 하지만 일반적인 나이 데이터의 범위를 생각하면 이상값일 가능성이 매우 높지.

🧭 2. 처리 기준 설정 — 바로 삭제하면 안 되는 이유

정제에서 가장 위험한 습관은 “NaN 발견 → 삭제”, 또는 “튀는 값 발견 → 삭제”야. 데이터를 지워도 되는지는 그 값의 의미와 양을 보고 결정해야 해.

기준 01

결측값의 비율

100개 중 2개 결측과 100개 중 70개 결측은 같은 방식으로 처리하면 안 돼.

df.isna().mean() df.isna().mean() * 100
기준 02

변수의 중요성

분석의 핵심 식별 변수인지, 거의 쓰이지 않는 보조 변수인지에 따라 전략이 달라질 수 있어.

기준 03

값의 성격

수치형은 평균·중앙값, 범주형은 최빈값처럼 데이터 유형에 맞는 대체 기준을 생각해야 해.

결측값 처리는 결측 비율, 변수의 중요도, 데이터 유형을 보고 제거 또는 대체를 결정한다.

🗑️ 3. 제거 적용 — dropna()

행 제거

df.dropna()

기본적으로 결측값을 하나라도 가진 행을 제거해.

import pandas as pd import numpy as np df = pd.DataFrame({ 'age': [20, 30, np.nan, 40], 'income': [200, np.nan, 300, 400] })
indexageincome
020200
130NaN
2NaN300
340400
1번과 2번 행은 한 열이라도 NaN이 있어서 제거돼.

특정 열을 기준으로 제거

df.dropna(subset=['age'])

전체 열을 보는 게 아니라 age가 결측인 행만 삭제한다.

df.dropna(subset=['age', 'income'])

열 자체를 삭제

df.dropna(axis=1)

결측값이 존재하는 열을 제거해. 정보 손실이 크기 때문에 처리 기준이 명확할 때 사용한다고 생각하면 돼.

🔄 4. 값 대체 적용 — fillna()

평균으로 대체

df['age'] = df['age'].fillna(df['age'].mean())

20, 30, NaN, 40이라면 평균 30으로 대체되어 20, 30, 30, 40이 돼.

중앙값으로 대체

df['age'] = df['age'].fillna(df['age'].median())

200, 220, 240, 260, 10000처럼 극단값이 있으면 평균은 크게 흔들릴 수 있어.

이상값 영향이 크다 → 평균보다 중앙값을 고려한다.

최빈값으로 대체

df['grade'].mode() df['grade'].mode()[0] df['grade'] = df['grade'].fillna(df['grade'].mode()[0])

mode()는 Series 형태로 반환되므로 보통 첫 번째 값을 가져와.

특정 값으로 대체

df['age'] = df['age'].fillna(0) df['region'] = df['region'].fillna('Unknown')

다만 0이 실제 의미 있는 값이라면 조심해야 해. “정보 없음”이 “실제 0”으로 바뀌면 의미가 변해버려.

📏 5. 이상값 처리 기준 — 먼저 “이상”을 정의해야 해

결측값은 NaN이라는 비교적 분명한 표식이 있지만 이상값은 그렇지 않아. 그래서 기준이 필요해. 빅데이터 분석에서 자주 배우는 방법 중 하나가 IQR 기준이야.

IQR range map
제1사분위수
Q1 = 25%
제3사분위수
Q3 = 75%
사분위 범위
IQR = Q3 − Q1
Q1 = df['x'].quantile(0.25) Q3 = df['x'].quantile(0.75) IQR = Q3 - Q1 lower = Q1 - 1.5 * IQR upper = Q3 + 1.5 * IQR
df[(df['x'] < lower) | (df['x'] > upper)]

여기서 |는 pandas 조건식에서 OR 역할을 해. 즉 하한보다 작거나 또는 상한보다 큰 값을 찾는 거야.

✂️ 6. 이상값 제거 적용

df = df[ (df['x'] >= lower) & (df['x'] <= upper) ]

정상값은 동시에 두 조건을 만족해야 하니까 &, 즉 AND를 사용해.

이상값 찾기
(df['x'] < lower) | (df['x'] > upper)
바깥쪽 둘 중 하나면 되므로 OR.
정상값 남기기
(df['x'] >= lower) & (df['x'] <= upper)
두 경계 안에 동시에 있어야 하므로 AND.
Bailey: “하한 미만 그리고 상한 초과인 값 찾겠다고 & 쓰면 어떻게 되지? 한 숫자가 동시에 양쪽에 있을 수 있나?”

그렇지. 거의 불가능하지. 그래서 이상값 탐지는 OR, 정상 범위 필터링은 AND라는 구조가 자연스럽게 나온다.

🩹 7. 이상값도 꼭 삭제해야 하는 건 아니야

30, 32, 35, 37, 1000

1000이 입력 오류라면 삭제하거나 수정하는 게 타당해. 그런데 고객 구매금액이고 정말로 고액 구매 고객이 존재한다면, 이 값은 단순 오류가 아니라 분석적으로 중요한 관측값일 수도 있어.

이상값 = 무조건 잘못된 값
아니야.
더 정확한 생각
통계적 기준에서 일반적인 범위를 벗어난 관측값.

그래서 처리 기준을 세울 때 도메인 의미까지 확인해야 해.

🔍 10. 실기에서 특히 조심할 함정

dropna() 했는데 원본이 안 바뀌는 경우

df.dropna()

이렇게만 하면 결과를 반환할 뿐 원래 df가 자동으로 바뀌는 것은 아니야.

df = df.dropna() df['x'] = df['x'].fillna(df['x'].median())

mode()와 mode()[0]

df['x'].mode() df['x'].mode()[0]

최빈값 하나를 fillna()에 넣으려는 상황에서는 보통 mode()[0] 형태를 사용해.

이상값 제거 전후 순서

결측값 처리 → 이상값 처리 → 분석

시험 문제에서는 요구사항을 먼저 읽고, 문제가 지시하는 처리 순서를 그대로 따라가는 게 가장 안전해.
