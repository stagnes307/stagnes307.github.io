🎯 1. 먼저 구분하자: 결측값과 이상값은 왜 같은 문제가 아니야?
결측값 — 값이 없는 상태

결측값은 관측되어야 할 값이 빠져 있는 상태야.

pandas에서는 보통 다음처럼 나타나.

Python
실행됨
import numpy as np

np.nan

예를 들어:

고객	나이	구매금액
A	25	30000
B	NaN	45000
C	38	NaN

B의 나이와 C의 구매금액은 결측값이야.

기본 확인은 이렇게 해.

Python
실행됨
df.isna()

열별 결측값 개수:

Python
실행됨
df.isna().sum()

반대로 결측값이 아닌 값은:

Python
실행됨
df.notna()
이상값 — 값은 있지만 비정상적으로 튀는 상태

예를 들어 사람의 나이가 다음과 같다고 해보자.

22, 25, 28, 31, 29, 999

999는 값 자체는 존재해. 그래서 결측값은 아니야.

하지만 일반적인 나이 데이터의 범위를 생각하면 이상값(outlier)일 가능성이 매우 높지.

즉,

구분	핵심 질문
결측값	값이 존재하는가?
이상값	존재하는 값이 정상적인 범위인가?

이 차이를 먼저 잡아두면 뒤의 처리 기준이 훨씬 쉬워져.

🧭 2. 처리 기준 설정 — 바로 삭제하면 안 되는 이유

정제에서 가장 위험한 습관은 이거야.

“NaN 발견 → 삭제”

또는

“튀는 값 발견 → 삭제”

데이터를 지워도 되는지는 그 값의 의미와 양을 보고 결정해야 해.

결측값은 세 가지를 먼저 본다
결측값의 비율

예를 들어 어떤 열에 100개의 데이터가 있는데 결측값이 2개라면 삭제를 고려할 수 있어.

반대로 100개 중 70개가 결측이라면 단순히 70개 행을 삭제하면 데이터 자체가 크게 훼손돼.

결측률은 이렇게 계산할 수 있어.

Python
실행됨
df.isna().mean()

퍼센트로 보고 싶으면:

Python
실행됨
df.isna().mean() * 100
해당 변수의 중요성

예를 들어 고객의 회원번호가 분석의 핵심 식별 변수라면 결측 여부가 매우 중요할 수 있어.

반면 분석에 거의 쓰이지 않는 보조 변수라면 처리 전략이 달라질 수 있지.

값의 성격

수치형과 범주형은 대체 방식이 다를 수 있어.

나이, 소득 → 평균·중앙값 등

지역, 등급 → 최빈값 등

여기까지를 한 문장으로 압축하면:

결측값 처리는 결측 비율, 변수의 중요도, 데이터 유형을 보고 제거 또는 대체를 결정한다.

🗑️ 3. 제거 적용 — dropna()

결측값을 제거하는 대표 함수가 dropna()야.

🧹 행 제거
Python
실행됨
df.dropna()

기본적으로 결측값을 하나라도 가진 행을 제거해.

예를 들어:

Python
실행됨
import pandas as pd
import numpy as np

df = pd.DataFrame({
    'age': [20, 30, np.nan, 40],
    'income': [200, np.nan, 300, 400]
})

원본:

index	age	income
0	20	200
1	30	NaN
2	NaN	300
3	40	400
Python
실행됨
df.dropna()

결과:

index	age	income
0	20	200
3	40	400

왜 1번과 2번 행이 없어졌는지 보이지?

한 열이라도 NaN이 있었기 때문이야.

특정 열을 기준으로 제거

실기에서는 이 형태도 중요해.

Python
실행됨
df.dropna(subset=['age'])

이 코드는 전체 열을 보는 게 아니라,

age가 결측인 행만 삭제한다.

여러 열을 조건으로 사용할 수도 있어.

Python
실행됨
df.dropna(subset=['age', 'income'])
열 자체를 삭제
Python
실행됨
df.dropna(axis=1)

결측값이 존재하는 열을 제거해.

하지만 실무든 시험이든 열 전체 삭제는 정보 손실이 크기 때문에 처리 기준이 명확할 때만 사용한다고 생각하면 돼.

🔄 4. 값 대체 적용 — fillna()

삭제하지 않고 결측값을 다른 값으로 채울 수도 있어.

핵심 함수:

Python
실행됨
df.fillna()
🔢 평균으로 대체
Python
실행됨
df['age'] = df['age'].fillna(df['age'].mean())

예를 들어 나이가:

20, 30, NaN, 40

이라면 평균은:

30

따라서 결과는:

20, 30, 30, 40
중앙값으로 대체
Python
실행됨
df['age'] = df['age'].fillna(df['age'].median())

평균보다 중앙값이 특히 유리한 상황이 있어.

예를 들어 소득이:

200, 220, 240, 260, 10000

이라고 해보자.

10000 때문에 평균은 크게 올라가.

이런 식으로 극단값의 영향을 많이 받는 데이터에서는 중앙값이 더 안정적일 수 있어.

그래서 기억하기 좋은 관계가 있어.

이상값 영향이 크다 → 평균보다 중앙값을 고려한다.

🔤 최빈값으로 대체

범주형 데이터에서는 최빈값을 사용할 수 있어.

Python
실행됨
df['grade'].mode()

주의할 점 하나.

mode()는 Series 형태로 반환되기 때문에 보통 첫 번째 값을 가져와.

Python
실행됨
df['grade'].mode()[0]

따라서:

Python
실행됨
df['grade'] = df['grade'].fillna(df['grade'].mode()[0])
특정 값으로 대체

때로는 임의의 값을 사용할 수도 있어.

Python
실행됨
df['age'] = df['age'].fillna(0)

또는 범주형에서:

Python
실행됨
df['region'] = df['region'].fillna('Unknown')

다만 0이 실제 의미 있는 값이라면 조심해야 해.

예를 들어 소득의 결측값을 0으로 바꾸면,

“소득 정보를 모름”

이

“소득이 0원임”

으로 의미가 변해버릴 수 있어.

이게 처리 기준을 먼저 세워야 하는 이유야.

📏 5. 이상값 처리 기준 — 먼저 “이상”을 정의해야 해

결측값은 NaN이라는 비교적 분명한 표식이 있지만 이상값은 그렇지 않아.

그래서 기준이 필요해.

빅데이터 분석에서 자주 배우는 방법 중 하나가 IQR 기준이야.

📦 IQR의 구조

데이터를 작은 값부터 큰 값까지 정렬했을 때:

Q1 = 제1사분위수, 25%

Q3 = 제3사분위수, 75%

그리고

IQR = Q3 - Q1

이걸 이용해서 보통 다음 범위를 잡아.

하한 = Q1 - 1.5 × IQR
상한 = Q3 + 1.5 × IQR

이 범위를 벗어난 값을 이상값 후보로 보는 거야.

pandas에서는:

Python
실행됨
Q1 = df['x'].quantile(0.25)
Q3 = df['x'].quantile(0.75)

IQR = Q3 - Q1

lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

이상값 확인:

Python
실행됨
df[(df['x'] < lower) | (df['x'] > upper)]

여기서 정말 중요한 문법이 하나 있어.

Python
실행됨
|

이건 pandas 조건식에서 OR 역할을 해.

즉:

Python
실행됨
(df['x'] < lower) | (df['x'] > upper)

는

하한보다 작거나 또는 상한보다 큰 값

이라는 뜻이야.

✂️ 6. 이상값 제거 적용

IQR 기준으로 정상 범위만 남기려면 조건을 반대로 잡으면 돼.

Python
실행됨
df = df[
    (df['x'] >= lower) &
    (df['x'] <= upper)
]

여기서는 &, 즉 AND를 사용해.

왜냐하면 정상값은 동시에 두 조건을 만족해야 하니까.

x ≥ 하한
그리고
x ≤ 상한
이상값 찾기와 정상값 남기기의 차이

이 두 코드는 자주 헷갈려.

이상값 찾기:

Python
실행됨
(df['x'] < lower) | (df['x'] > upper)

정상값 남기기:

Python
실행됨
(df['x'] >= lower) & (df['x'] <= upper)

Bailey라면 여기서 아마 이렇게 찌를 거야.

“하한 미만 그리고 상한 초과인 값 찾겠다고 & 쓰면 어떻게 되지? 한 숫자가 동시에 양쪽에 있을 수 있나?”

그렇지. 거의 불가능하지.

그래서 이상값 탐지는 OR, 정상 범위 필터링은 AND라는 구조가 자연스럽게 나온다.

🩹 7. 이상값도 꼭 삭제해야 하는 건 아니야

여기가 결측값 처리와 연결되는 부분이야.

이상값을 발견했다고 해서 반드시 제거할 필요는 없어.

예를 들어:

30, 32, 35, 37, 1000

1000이 입력 오류라면 삭제하거나 수정하는 게 타당해.

그런데 이 데이터가 고객 구매금액이고 정말로 고액 구매 고객이 존재한다면?

1000은 단순 오류가 아니라 분석적으로 중요한 관측값일 수도 있어.

따라서:

이상값 = 무조건 잘못된 값

이 아니야.

더 정확한 생각은:

통계적 기준에서 일반적인 범위를 벗어난 관측값

이야.

그래서 처리 기준을 세울 때 도메인 의미까지 확인해야 해.

🧠 8. 시험용으로 세 가지 결정을 하나의 틀로 묶자

데이터 하나를 발견했을 때 다음처럼 생각하면 돼.

결측값이면
결측값 발견
    ↓
결측 규모와 변수 중요도 확인
    ↓
┌──────────────┐
│              │
제거           대체
│              │
dropna()       fillna()
               │
        평균 / 중앙값 / 최빈값 등
이상값이면
이상값 후보 발견
       ↓
판정 기준 설정
       ↓
IQR / 업무 기준 등
       ↓
실제 오류인가?
       ↓
제거 / 대체 / 유지

둘의 공통 원리는 하나야.

기준을 세운 뒤 처리한다.

바로 이게 이번 소단원의 제목인 “처리 기준 수립과 적용”과 연결돼.

💻 9. 실기 코드 흐름으로 한 번에 연결하기

다음 코드는 시험에서 머릿속에 갖고 있으면 좋은 형태야.

Python
실행됨
import pandas as pd
import numpy as np

# 결측값 확인
df.isna().sum()

# 결측값 제거
df = df.dropna(subset=['age'])

# 평균 대체
df['income'] = df['income'].fillna(df['income'].mean())

# 중앙값 대체
df['age'] = df['age'].fillna(df['age'].median())

# 최빈값 대체
df['grade'] = df['grade'].fillna(df['grade'].mode()[0])

# 이상값 판단 기준
Q1 = df['income'].quantile(0.25)
Q3 = df['income'].quantile(0.75)
IQR = Q3 - Q1

lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

# 이상값 확인
outlier = df[
    (df['income'] < lower) |
    (df['income'] > upper)
]

# 이상값 제거
df = df[
    (df['income'] >= lower) &
    (df['income'] <= upper)
]

코드를 통째로 외우기보다 각 줄의 역할을 연결해서 기억하는 게 좋아.

목적	핵심 코드
결측 확인	isna().sum()
결측 제거	dropna()
결측 대체	fillna()
평균	mean()
중앙값	median()
최빈값	mode()[0]
사분위수	quantile()
이상값 조건	< lower | > upper
정상범위 조건	>= lower & <= upper
