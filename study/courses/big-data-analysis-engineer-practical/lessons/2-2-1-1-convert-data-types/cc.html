2-2-1-1 · 자료형과 표현 변환

🧪 타입을 바꾸기 전에
의미부터 지켜라

빅데이터분석기사 실기에서 자료형 변환은 단순히 astype()을 쓰는 문제가 아니야. 실제 흐름은 항상 현재 자료형 확인 → 데이터의 실제 표현 확인 → 목표 자료형으로 변환 → 변환 결과 검증으로 이어진다.

핵심 경고: object를 보자마자 무조건 숫자로 바꾸면 위험해. "1,200", "미상", "2026-08-01", "00123"은 모두 문자열처럼 보이지만 의미가 전혀 다르다.

🎯 이번 단원의 핵심

현재 자료형 확인 → 데이터의 실제 표현 확인 → 목표 자료형으로 변환 → 변환 결과 검증
01

현재 유형 확인

dtype뿐 아니라 값의 실제 모양까지 본다.

02

표현 정리

쉼표, %, 공백, 특수 문자열을 처리한다.

03

목표 유형 변환

숫자, 날짜, 문자, 범주형 중 의미에 맞게 선택한다.

04

결과 검증

자료형뿐 아니라 결측과 값의 의미도 점검한다.

🔍 1. 현재 유형 확인 — 지금 데이터가 무엇인지 먼저 본다

가장 먼저 볼 것은 dtype이야.

df.dtypes
df['age'].dtype
df.info()
import pandas as pd

df = pd.DataFrame({
    'age': ['20', '31', '45'],
    'sales': ['1,200', '2,500', '900'],
    'date': ['2026-01-01', '2026-01-03', '2026-01-05']
})

print(df.dtypes)
age      object
sales    object
date     object
dtype: object
열 현재 표현 의미 적절한 목표
age"20"나이정수형
sales"1,200"매출표현 정리 후 숫자형
date"2026-01-01"날짜datetime

시험에서 자주 생기는 착각

df['sales'].astype(int)

"1,200"은 쉼표 때문에 정수로 바로 해석할 수 없어. 그래서 표현을 먼저 정리해야 하는 경우와 자료형만 바꾸면 되는 경우를 구분해야 한다.

🔄 2. 목표 유형 변환 — 무엇으로 바꿀 것인가

값이 이미 깨끗하다면 astype()이 가장 직관적이야.

df['age'] = df['age'].astype(int)
df['score'] = df['score'].astype(float)
df['code'] = df['code'].astype(str)

식별자 예시

00123
00457

숫자처럼 보여도 숫자가 아닐 수 있다

int('00123')
# 123

상품코드·지역코드·우편번호 같은 식별자를 정수로 바꾸면 앞의 00이 사라진다. 자료형은 단순한 모양이 아니라 변수의 의미로 결정해야 해.

🧹 3. 표현을 정리한 뒤 변환하기

df['sales']

0    1,200
1    2,500
2      900
df['sales'] = (
    df['sales']
    .str.replace(',', '', regex=False)
    .astype(int)
)

🛡️ 4. pd.to_numeric() — 숫자 변환에서 더 안전한 방법

실제 데이터에는 숫자로 바꿀 수 없는 값이 섞일 수 있어.

20
31
미상
45
df['age'] = pd.to_numeric(
    df['age'],
    errors='coerce'
)

errors='coerce'는 숫자로 변환할 수 없는 값을 NaN으로 바꾼다.

하지만 여기서 끝내면 안 돼

errors='coerce'는 편해서 오히려 위험해. 원래 정상 데이터였는데 변환 과정에서 잘못 NaN이 생겨도 실행은 계속되기 때문이야. 그래서 반드시 변환 후 검증이 붙어야 한다.

📅 5. 날짜 자료형 변환

날짜가 문자로 들어와도 의미가 날짜라면 datetime으로 변환한다.

df['date'] = pd.to_datetime(df['date'])
df['date'].dt.year
df['date'].dt.month
df['date'].dt.day
df['date'] = pd.to_datetime(
    df['date'],
    errors='coerce'
)

변환 불가능한 날짜는 NaT가 된다. 숫자의 NaN과 비슷하게 날짜 결측값이라고 보면 돼.

🧩 6. 범주형 변환

df['grade'] = df['grade'].astype('category')

성별, 등급, 지역처럼 값의 종류가 제한된 변수에 사용할 수 있어. 다만 값이 반복된다는 이유만으로 무조건 category로 바꿀 필요는 없다. 문제에서 요구하는 분석 목적에 따라 선택하면 돼.

⚠️ 7. 퍼센트 표현은 의미까지 확인한다

df['rate'] = df['rate'].str.replace('%', '', regex=False)
df['rate'] = pd.to_numeric(df['rate'])
df['rate'] = df['rate'] / 100

"35%" → 35는 표현과 자료형을 바꾼 것이고, 35 → 0.35는 비율의 의미에 맞게 값을 변환한 것이야.

✅ 변환보다 중요한 마지막 단계 — 변환 결과 검증

검증 1 — 자료형이 목표대로 바뀌었는가

df.dtypes
df['age'].dtype

검증 2 — 실제 값이 정상적인가

df.head()
df['age'].head()

검증 3 — 새로운 결측값이 생겼는가

before_na = df['age'].isna().sum()

df['age'] = pd.to_numeric(
    df['age'],
    errors='coerce'
)

after_na = df['age'].isna().sum()

0 → 5처럼 늘었다면 변환 과정에서 5개가 새롭게 결측값이 된 거야.

검증 4 — 값의 범위가 상식적인가

df['age'].describe()

나이가 -5, 999처럼 나오면 dtype은 맞아도 데이터는 이상할 수 있어.

검증의 두 축

문법적 성공

의미적 성공

값, 결측, 범위, 비율의 의미가 유지되었는가?

① 지금 무엇인가 → ② 무엇이어야 하는가 → ③ 어떻게 바꿀까 → ④ 무엇이 망가졌는지 확인했나

자료형 변환의 진짜 실력은 astype()을 아는 게 아니라 변환 후 데이터의 의미가 보존됐는지 확인할 줄 아는 것이야.
