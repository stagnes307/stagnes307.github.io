🧩 새 열을 설계하는 기술 · 파생변수 생성

이번 단원의 핵심은 있는 열로부터 분석에 더 직접적인 새 열을 만드는 것이야. 실기에서는 개념만 아는 것보다 pandas 구현 → 값 검증 → 잘못된 생성 방지를 한 흐름으로 익혀야 해.

🎯 먼저 잡을 핵심 — 파생변수는 왜 만들까?

파생변수(derived variable)는 이미 존재하는 변수들을 계산·결합·변환해서 새롭게 만든 변수야.

price = 가격
quantity = 수량
↓
total_price = 가격 × 수량

기본 예제

import pandas as pd

df = pd.DataFrame({
    'price': [10000, 15000, 20000],
    'quantity': [2, 3, 1],
    'height': [170, 165, 180],
    'weight': [65, 55, 80]
})

df['total_price'] = df['price'] * df['quantity']

여기서 total_price가 파생변수야. 구조는 아주 단순해.

기존 변수 → 의미 있는 연산 → 새로운 변수

🔗 1. 기존 변수 조합 — 어떤 식으로 합칠까?

pandas에서는 같은 행의 열 값끼리 직접 계산할 수 있어. 예를 들어 가격과 수량을 곱하면 각 행의 총구매금액이 만들어져. 

df['total_price'] = df['price'] * df['quantity']

df['sum'] = df['A'] + df['B']
df['diff'] = df['A'] - df['B']
df['product'] = df['A'] * df['B']
df['ratio'] = df['A'] / df['B']

나눗셈에서 보는 위험 신호

df['A'] / df['B']처럼 나눗셈이 나오면 분모인 B에 0이 있는지 생각해야 해. 파생변수 생성은 계산 + 검증이 한 세트야.

🛠️ 2. 파생변수 구현 — 시험에서 많이 쓰는 패턴

두 변수의 연산

df['새변수'] = 연산식

df['total_price'] = df['price'] * df['quantity']

비율 변수 만들기

df['price_per_quantity'] = df['price'] / df['quantity']

총매출 ÷ 고객 수, 총금액 ÷ 수량처럼 절대 크기보다 상대적 관계를 보고 싶을 때 자주 써.

여러 열의 합계와 평균

score['total'] = score[['kor', 'eng', 'math']].sum(axis=1)

score['mean'] = score[['kor', 'eng', 'math']].mean(axis=1)

여기서 axis=1은 같은 행의 여러 열을 묶어서 계산한다는 뜻이야. 학생별 총점·평균처럼 행 하나에서 새로운 값을 만드는 파생변수에 자주 등장해.

표현계산 방향실기에서의 감각
axis=0열별 계산각 과목·각 변수의 전체 요약
axis=1행별 계산한 행의 여러 열을 합쳐 새 값 생성

⚖️ 3. 조건에 따라 변수 만들기

import numpy as np

score['level'] = np.where(
    score['mean'] >= 80,
    'high',
    'low'
)
np.where(조건, 참일 때 값, 거짓일 때 값)

산술 계산뿐 아니라 조건을 이용해 새로운 범주형 변수도 만들 수 있어.

파생변수의 두 갈래

📐 4. 대표적인 파생변수 예 — BMI

키와 체중을 이용해 BMI를 만들 수 있어. 데이터의 키가 cm라면 먼저 m 단위로 바꾸는 관계를 반영해야 해. 

df['height_m'] = df['height'] / 100
df['bmi'] = df['weight'] / (df['height_m'] ** 2)

# 한 번에 작성
df['bmi'] = df['weight'] / ((df['height'] / 100) ** 2)

파생변수 사고 순서

  1. 01원래 변수 확인 — height(cm), weight(kg)
  2. 02필요한 단위 확인 — cm → m
  3. 03관계식 적용 — weight / height²
  4. 04새로운 변수 생성 — BMI

🔍 5. 생성 결과 확인 — 여기까지 해야 완성

새 열을 만들었다고 끝이 아니야. 원본 변수와 파생변수를 나란히 놓고 결과가 관계식대로 만들어졌는지 확인하는 습관이 중요해.

검증 포인트

  • 원본 열과 새 열을 함께 본다.
  • 몇 행은 직접 계산해 값이 맞는지 확인한다.
  • 비율 변수면 0 또는 비정상값을 확인한다.

🧭 9. 파생변수 문제를 풀 때의 고정 절차

01

무엇을 이용하지?

문제에서 사용할 기존 열을 찾는다.

02

어떻게 계산하지?

합·곱·비율·평균·조건 등 관계를 결정한다.

03

어디에 넣지?

새로운 열 이름에 계산 결과를 저장한다.

04

결과가 맞나?

원본 열과 새 열을 나란히 검증한다.

파생변수 생성은 단순히 새 열을 추가하는 일이 아니야. 기존 데이터가 가진 관계를 더 분석하기 좋은 형태로 표현하는 작업이라고 이해하면 이후 변수 선택과 모델링 단계까지 자연스럽게 연결돼.
