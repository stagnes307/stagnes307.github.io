식별자와 설명변수를 구별해야 한다

id처럼 값은 서로 다르지만 고객 특성을 설명하지 않는 변수는 제외 후보가 될 수 있어. 하지만 “ID처럼 생겼으니 무조건 삭제”라고 외우면 위험해. 실제 의미를 보고 판단해야 해. 

X = df.drop(columns=['id', 'target'])
y = df['target']
확인 주로 보는 것
df.columns변수 이름
df.info()자료형, 결측치
df.describe()수치형 변수 분포
df.nunique()변수별 고유값 개수

고유값이 1이라면 모든 행에서 값이 동일하다는 뜻이야. 이런 변수는 데이터를 구별하지 못하므로 일반적으로 분석 정보가 거의 없어.

⚖️ 선택 기준 적용 — 어떤 변수를 남길까?

데이터 자체를 보고 제거

상수 변수
df.nunique()

모든 값이 동일하면 제거 후보가 될 수 있어.

결측치가 지나치게 많은 변수
X.isnull().mean()

문제에서 기준을 주면 그 기준을 적용해야 해.

missing_ratio = X.isnull().mean()

selected = missing_ratio[missing_ratio < 0.5].index
X = X[selected]
결측률이 몇 % 이상이면 반드시 삭제한다는 절대 기준은 없어. 시험에서는 문제에서 제시한 조건을 우선 적용해야 해.

변수 간 관계를 보고 선택

X.corr(numeric_only=True)

예를 들어 height_cm과 height_m처럼 거의 같은 정보를 담은 변수가 있다면 하나를 줄일지 검토할 수 있어. 다만 상관계수가 높다고 무조건 삭제하는 것은 아니야.

🎯 타깃과의 관계도 선택 기준이 된다

분류
from sklearn.feature_selection import SelectKBest
from sklearn.feature_selection import f_classif

selector = SelectKBest(
    score_func=f_classif,
    k=3
)

X_selected = selector.fit_transform(X, y)

점수가 높은 변수 K개 선택
score_func=f_classif
분류 문제에서 변수와 목표변수 관계 평가
k=3
3개 선택

selector = SelectKBest(

    k=3
)
분류 → f_classif 회귀 → f_regression

🧩 변수 선택 방법의 큰 분류

Filter

모델을 학습시키기 전에 통계적 특성을 이용해 변수를 고른다. 상관관계, 분산, 카이제곱, ANOVA F-value 등이 대표적이야.

Wrapper

변수 조합을 바꿔가며 실제 모델 성능을 확인한다. 대표적으로 RFE가 있어.

Embedded

모델을 학습하는 과정 자체에서 변수 중요도가 결정된다. 트리 계열의 feature importance가 대표적인 예야. 

from sklearn.feature_selection import RFE
from sklearn.linear_model import LogisticRegression

model = LogisticRegression()

selector = RFE(
    estimator=model,
    n_features_to_select=3
)

selector.fit(X, y)
3

⚠️ 가장 중요한 함정 — 데이터 누수

테스트 데이터의 정보를 이용해서 변수 선택 기준을 학습하면 안 돼. 선택기는 일반적으로 학습 데이터에만 fit하고, 같은 기준으로 train과 test를 변환해야 해. 

selector.fit(X_train, y_train)

X_train_selected = selector.transform(X_train)
X_test_selected = selector.transform(X_test)
전체 데이터에 먼저 fit()하고 그 뒤 train/test로 나누면 테스트 정보가 선택 과정에 섞일 수 있어. 이게 데이터 누수(data leakage)야.

🧠 시험장에서 바로 떠올릴 3단계

1

후보 변수 파악

X = df.drop(columns='target')
y = df['target']
2

기준 적용

selector = SelectKBest(f_classif, k=3)
selector.fit(X, y)
3

결과 확인

selected_columns = X.columns[selector.get_support()]
X와 y를 구분하고 → 선택 기준을 X에 적용하고 → support로 선택된 열을 확인한다.

📌 실기용 압축 기억판

단계 질문 대표 코드
후보 파악 무엇을 입력 변수로 쓸까? df.columns · X/y 분리
기준 적용 무엇을 남길까? SelectKBest · RFE · corr

적용 동일한 기준을 어떻게 유지할까? transform()
fit()

선택 기준을 학습한다.

transform()

학습한 기준으로 데이터를 변환한다.

이 구조를 이해하면 변수 선택 문제를 단순 암기가 아니라 전처리 파이프라인의 한 단계로 볼 수 있게 돼.
