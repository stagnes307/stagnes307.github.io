01 · PURPOSE

🎯 분석 목적 구분

분류 Classification

지도학습

목표변수가 범주형일 때 사용해. 대출 승인/거절, 고객 이탈/유지, 정상/불량처럼 결과가 “어느 종류인가”로 표현돼.

나이, 소득, 거래횟수
       ↓
    분류모형
       ↓
   이탈 / 유지

핵심: 결과가 범주다.

회귀 Regression

지도학습

목표변수가 연속적인 수치일 때 사용해. 주택 가격, 매출액, 수요량, 고객 구매금액처럼 크기 자체가 의미를 가져.

면적, 위치, 연식
       ↓
    회귀모형
       ↓
 523,000,000원

핵심: 결과가 수치다.

군집 Clustering

비지도학습

군집에는 미리 주어진 정답 y가 없어. 대신 데이터 사이의 유사성을 이용해 비슷한 관측값끼리 묶어.

고객 특성 데이터
      ↓
    군집모형
      ↓
Cluster 0 / 1 / 2

핵심: 정답 없이 구조를 찾는다.

같은 “그룹 나누기”라도 구조는 다르다.

이미 일반고객·우수고객·VIP라는 정답 레이블이 있고 새 고객의 등급을 맞히면 분류. 정답 없이 데이터 자체에서 고객 유형을 발견하면 군집이야.

02 · CANDIDATES

🧩 후보 모형 특성

분석 목적을 정한 뒤에는 그 목적을 수행할 수 있는 여러 후보 모형을 비교해. 중요한 건 “분류 = 특정 알고리즘 하나”가 아니라는 점이야.

목적 후보 모형 특성
분류 로지스틱 회귀 확률 기반, 비교적 해석하기 쉬움
분류 의사결정나무 규칙 구조가 명확하고 해석이 쉬움
분류 랜덤포레스트 여러 트리를 결합해 안정적인 예측
분류 Gradient Boosting 계열 오류를 순차적으로 보완하며 높은 예측력 추구
분류 KNN / SVM 이웃 또는 결정 경계를 이용해 클래스 판별
회귀 선형회귀 변수와 목표값의 관계를 선형적으로 표현
회귀 의사결정나무 회귀 비선형 관계도 표현 가능
회귀 랜덤포레스트 / Boosting / KNN 회귀 여러 방식으로 연속적인 수치를 예측

CLASSIFIER

RandomForestClassifier()

목표변수가 범주라면 분류 구조.

REGRESSOR

RandomForestRegressor()

목표변수가 연속 수치라면 회귀 구조.

같은 Random Forest라는 이름 안에서도 분류와 회귀가 갈려. 그래서 모델 이름을 보고 목적을 추론하기보다, 목적을 먼저 판단하고 그에 맞는 모델 클래스를 고르는 것이 더 안전해.

03 · OUTPUT

📤 모형 출력 형태

분석 목적을 이해했다는 건 모델이 무엇을 출력해야 하는지도 예상할 수 있다는 뜻이야.

분류 출력

최종 클래스 또는 클래스에 속할 확률을 출력할 수 있어.

고객 A → 이탈
고객 B → 유지

고객 A → 이탈 확률 0.83

predict → 클래스

predict_proba → 클래스 확률

회귀 출력

기본 출력은 연속적인 숫자야.

예상 매출액 → 12,530,000
예상 가격 → 482,000,000
예상 수요량 → 8,341

predict의 결과가 곧 예측 수치.

군집 출력

각 관측값이 어느 군집에 속하는지 나타내는 군집 레이블을 얻어.

고객 A → Cluster 0
고객 B → Cluster 2
고객 C → Cluster 0

0, 1, 2는 등급이 아니라 단순한 그룹 식별자야. 의미는 군집 특성을 분석한 뒤 사람이 붙여.

04 · EXAM LOGIC

🔍 실기에서는 어떻게 판단하는가

1

목표값이 있는가?

없다면 군집 같은 비지도학습 후보를 먼저 생각해.

2

목표값이 어떤 의미인가?

종류·상태·등급이면 분류, 연속적인 양·크기면 회귀.

3

원하는 출력이 무엇인가?

클래스 → 분류 · 확률 → 분류 · 연속 수치 → 회귀 · 데이터 그룹 → 군집

4

그 다음 후보 모형을 비교한다.

해석 가능성, 데이터 특성, 비선형성, 성능, 과적합 가능성, 계산 비용 등을 본다.

FAULT LINES

⚠️ 자주 섞이는 세 가지

숫자 0/1이면 회귀다?

아니야. 0=정상, 1=불량처럼 범주를 코딩한 숫자라면 분류야.

고객을 그룹으로 나누면 무조건 군집이다?

이미 VIP 등의 정답 레이블이 있다면 새 고객의 등급 예측은 분류야.

모델 이름만 보면 목적을 알 수 있다?

Random Forest처럼 분류와 회귀 양쪽에 쓰이는 모델도 있어. 목적이 먼저야.

PRACTICAL CHAIN

목적 결정이 먼저, 알고리즘 선택은 나중

분석 목적 → 목표변수 구조 → 후보 모형 → 출력 형태 → 평가 방법

이후 모형 평가를 배울 때도 이 구분이 그대로 이어져. 분류와 회귀는 출력 형태가 다르기 때문에 평가지표도 달라진다. 지금 잡은 구조가 다음 단원의 발판이 되는 이유야.
