🧭 먼저 잡을 핵심 관계

분석모형을 고를 때 제일 먼저 보는 건 “어떤 알고리즘이 유명한가?”가 아니야.

분석 목적 → 목표변수의 형태 → 후보 모형 → 모형의 출력

이 순서가 핵심이야.

예를 들어 고객 데이터를 분석한다고 해보자.

고객이 이탈할지/안 할지 알고 싶다 → 범주를 맞힘 → 분류

고객의 다음 달 구매금액을 알고 싶다 → 숫자를 맞힘 → 회귀

고객을 비슷한 성향끼리 나누고 싶다 → 정답 레이블이 없음 → 군집

즉, 같은 고객 데이터라도 분석 목적이 달라지면 모형 구조가 달라져.

🎯 1. 분석 목적 구분
무엇을 예측하려는가, 아니면 구조를 찾으려는가

빅데이터 분석에서 먼저 구분해야 할 건 크게 지도학습과 비지도학습이야.

구분	핵심 질문	목표값 존재	대표 분석
지도학습	정답을 예측할 수 있는가?	O	분류, 회귀
비지도학습	데이터 내부 구조를 찾을 것인가?	X	군집

여기서 실기에서 특히 중요한 연결은 이거야.

분류 Classification

목표변수가 범주형일 때 사용해.

예를 들면:

대출 승인 / 거절

고객 이탈 / 유지

정상 / 불량

질병 있음 / 없음

모형은 입력 데이터 X를 받아서 어느 클래스에 속하는지 판단해.

나이, 소득, 거래횟수
        ↓
     분류모형
        ↓
   이탈 / 유지

핵심은 결과가 범주라는 거야.

회귀 Regression

목표변수가 연속적인 수치일 때 사용해.

예를 들면:

주택 가격

매출액

수요량

고객 구매금액

면적, 위치, 연식
        ↓
     회귀모형
        ↓
   523,000,000원

분류와 회귀 모두 정답 y가 있는 지도학습이지만,

분류는 종류를 예측하고
회귀는 값을 예측한다.

이 차이가 가장 중요해.

군집 Clustering

군집은 앞의 두 가지와 구조 자체가 달라.

미리 주어진 정답 y가 없어.

대신 데이터 사이의 유사성을 이용해서 비슷한 관측값끼리 묶어.

고객 특성 데이터
      ↓
   군집모형
      ↓
┌────┬────┬────┐
군집1  군집2  군집3

예를 들어 고객 세분화를 한다면 처음부터

“이 고객은 VIP이다.”

라는 정답이 주어지는 게 아니라,

모형이 고객들의 소비 패턴을 보고 비슷한 고객을 묶은 다음 사람이 그 집단의 의미를 해석해.

그래서 고객 세분화, 유형 발견, 데이터 구조 탐색 같은 표현이 보이면 군집을 떠올리면 돼.

🧩 2. 후보 모형 특성

이제 목적을 정했으면 그 목적을 수행할 수 있는 후보 모형들을 비교해야 해.

분류의 대표 후보
모형	핵심 특성
로지스틱 회귀	확률 기반, 해석하기 비교적 쉬움
의사결정나무	규칙 구조가 명확하고 해석하기 쉬움
랜덤포레스트	여러 트리를 결합해 안정적인 예측
Gradient Boosting 계열	순차적으로 오류를 보완하며 높은 예측력 추구
KNN	가까운 데이터의 클래스를 이용
SVM	클래스 사이의 결정 경계를 찾음

여기서 중요한 건 “분류 = 특정 알고리즘 하나”가 아니라는 것이야.

분류라는 것은 분석 목적이고, 이를 수행할 수 있는 알고리즘이 여러 개 있는 거지.

분류 목적
   ├─ 로지스틱 회귀
   ├─ 의사결정나무
   ├─ 랜덤포레스트
   ├─ Boosting
   ├─ KNN
   └─ SVM
회귀의 대표 후보
모형	핵심 특성
선형회귀	변수와 목표값의 관계를 선형적으로 표현
의사결정나무 회귀	비선형 관계도 표현 가능
랜덤포레스트 회귀	여러 회귀 트리의 결과를 결합
Gradient Boosting 회귀	오차를 순차적으로 보정
KNN 회귀	주변 데이터의 값을 이용

여기서 하나 짚자.

의사결정나무나 랜덤포레스트는 분류에만 쓰는 모형이 아니야.

목표변수가 범주면 분류 모델, 수치면 회귀 모델로 사용할 수 있어.

예를 들어:

RandomForestClassifier → 분류
RandomForestRegressor  → 회귀

실기에서 모델 클래스를 선택할 때도 이 구분이 그대로 나타나.

📤 3. 모형 출력 형태

이 부분이 의외로 중요해.

분석 목적을 이해했다는 건 결국 모델이 무엇을 출력하는지 예측할 수 있다는 뜻이거든.

분류의 출력

분류는 보통 두 종류의 출력을 생각할 수 있어.

클래스 예측
고객 A → 이탈
고객 B → 유지
고객 C → 이탈

즉,

Python
실행됨
model.predict(X)

의 결과처럼 최종 예측 클래스가 나올 수 있어.

클래스 확률
고객 A → 이탈 확률 0.83
고객 B → 이탈 확률 0.21

이런 확률값도 얻을 수 있어.

특히 이진분류에서는 흔히

P(y = 1)

형태의 확률을 활용해.

그래서 분류에서는 다음 둘을 구별해야 해.

predict → 클래스
predict_proba → 클래스에 속할 확률

📈 회귀의 출력

회귀는 기본적으로 연속적인 숫자를 출력해.

예:

예상 매출액 → 12,530,000
예상 가격   → 482,000,000
예상 수요량 → 8,341

따라서

Python
실행됨
model.predict(X)

의 결과가 곧 예측 수치가 돼.

분류처럼 클래스 확률을 구하는 구조가 기본 목적은 아니야.

🧭 군집의 출력

군집은 각 관측값이 어느 군집에 속했는지 나타내는 군집 번호 또는 군집 레이블을 얻을 수 있어.

예를 들어 K-means라면:

고객 A → Cluster 0
고객 B → Cluster 2
고객 C → Cluster 0

여기서 아주 중요한 점이 하나 있어.

Cluster 0이 낮은 등급이고 Cluster 2가 높은 등급이라는 뜻은 아니야.

0, 1, 2 같은 숫자는 기본적으로 단순한 그룹 식별자일 뿐이야.

각 군집의 평균 소비액, 연령, 방문 빈도 등을 살펴본 다음

Cluster 0 → 고액 충성 고객
Cluster 1 → 저빈도 신규 고객
Cluster 2 → 할인 민감 고객

처럼 사람이 해석을 붙이는 거야.

🔗 세 개념을 한 번에 연결하기

이 단원의 핵심 구조를 압축하면 이렇게 돼.

                분석 목적
                    │
       ┌────────────┼────────────┐
       │            │            │
      분류          회귀          군집
       │            │            │
  범주형 목표값   연속형 목표값    목표값 없음
       │            │            │
  지도학습        지도학습       비지도학습
       │            │            │
 클래스/확률      연속 수치      군집 레이블

이 구조가 머릿속에 있으면 처음 보는 분석 과제가 나와도 모형을 좁힐 수 있어.

🔍 실기에서는 어떻게 판단하는가

실기에서 데이터가 주어졌다고 해서 바로 모델부터 고르면 안 돼.

먼저 종속변수 또는 목표변수를 확인하는 습관을 들이는 게 좋아.

목표변수가 0 / 1

예:

churn
0
1
0
1

숫자로 표시됐다고 해서 회귀가 아니야.

0과 1이 이탈 여부라는 범주를 표현하는 코드라면 분류야.

이게 중요한 함정이야.

데이터 타입이 숫자인가와
변수의 의미가 수치인가는 다르다.

목표변수가 가격
price
310.5
482.1
275.8

가격의 크기 자체가 의미를 가지므로 연속형 수치 예측 → 회귀로 보는 게 자연스러워.

목표변수가 없다

고객의 구매 행동만 있고 미리 정의된 고객 유형이 없다면:

age
income
purchase_count
avg_purchase

이 자료를 이용해 고객 유형 자체를 발견하려는 목적은 군집이야.

⚠️ 자주 섞이는 세 가지
숫자 0/1이면 회귀다?

아니야.

0 = 정상, 1 = 불량이라면 숫자는 단순히 범주를 코딩한 것이야.

따라서 분류.

고객을 여러 그룹으로 나누면 무조건 군집이다?

아니야.

이미 과거 데이터에

일반고객 / 우수고객 / VIP

라는 정답 레이블이 있고 새 고객의 등급을 맞히는 거라면 분류야.

정답 없이 데이터 자체에서 그룹을 찾아내면 군집이고.

즉,

그룹 개수보다 정답 레이블의 존재 여부가 중요하다.

모델 이름만 보고 분석 목적을 판단한다?

위험해.

예를 들어 Random Forest는

RandomForestClassifier
RandomForestRegressor

둘 다 존재해.

따라서 먼저 모델 이름이 아니라 문제의 출력이 무엇이어야 하는지를 판단해야 해.

🧠 실기용 판단 공식

문제를 읽으면 이 순서로 생각하면 돼.

① 목표값이 있는가?

없다 → 군집 같은 비지도학습 후보.

있다 → 다음으로.

② 목표값이 어떤 의미인가?

종류·상태·등급 → 분류

연속적인 양·크기 → 회귀

③ 원하는 출력은 무엇인가?

클래스 → 분류

클래스 확률 → 분류

연속 수치 → 회귀

데이터 그룹 → 군집

④ 같은 목적의 후보 모형을 비교한다

그 뒤에야

해석 가능성

데이터 특성

비선형성

성능

과적합 가능성

계산 비용

등을 고려해서 후보 모델 가운데 하나를 선택해.

즉,

목적 결정이 먼저, 알고리즘 선택은 나중이야.

🧱 실기 코드와 연결해서 기억하기

개념과 Python 모델을 연결하면 더 잘 남아.

분석 목적	대표 클래스 형태	출력
분류	Classifier	클래스 또는 확률
회귀	Regressor	연속 수치
군집	KMeans 등	군집 레이블

예를 들어 이름만 봐도:

Python
실행됨
RandomForestClassifier()

Classifier → 분류

Python
실행됨
RandomForestRegressor()

Regressor → 회귀

라는 구조가 드러나.

하지만 시험에서는 이 이름을 외워서 목적을 역추론하기보다 목적을 먼저 판단하는 것이 더 안전해.

🌱 이 단원에서 만들어야 하는 진짜 구분

세 문장을 정확히 구별할 수 있으면 3-1-1-1의 핵심은 잡힌 거야.

분류

정답 레이블이 있고, 범주를 예측한다.

회귀

정답값이 있고, 연속적인 수치를 예측한다.

군집

정답 레이블 없이, 데이터 내부의 유사한 집단을 찾는다.

그리고 그 다음 연결은:

분석 목적
→ 목표변수 구조
→ 후보 모형
→ 출력 형태
→ 평가 방법

이후 모형 평가를 배울 때도 이 구분이 그대로 이어져. 분류와 회귀는 출력이 다르기 때문에 평가지표도 달라진다는 게 다음 연결점이야.
