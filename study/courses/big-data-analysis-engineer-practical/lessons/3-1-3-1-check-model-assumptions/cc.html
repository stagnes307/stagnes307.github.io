🔍 1. 필요 가정 파악

모형의 가정(assumption)은 그 모형의 추정값·검정·해석을 신뢰하기 위해 데이터나 오차가 만족해야 하는 조건이야.

≠

선형회귀 코드는 데이터만 넣어도 돌아가지만, 잔차가 심하게 이분산이고 독립성까지 깨져 있다면 회귀계수는 계산돼도 표준오차·신뢰구간·유의성 판단은 흔들릴 수 있어.

모형 특히 확인할 가정
선형회귀 선형성, 독립성, 등분산성, 잔차 정규성, 심한 다중공선성 여부
로지스틱 회귀 관측치 독립성, 설명변수와 logit의 선형성, 심한 다중공선성 여부
t검정·ANOVA 독립성, 정규성, 등분산성 등
시계열 모형 정상성, 잔차 독립성·백색잡음 여부 등
의사결정나무 선형성·정규성 같은 전통적 분포 가정이 상대적으로 적음
시험 함정: “회귀분석에서는 설명변수 X가 정규분포를 따라야 한다”는 식으로 외우면 안 돼. 선형회귀의 정규성 가정은 일반적으로 오차항 또는 잔차에 관한 이야기야.

🧪 2. 가정 점검 — 무엇을 어떻게 확인할까?

선형성 — X와 Y의 관계가 직선적으로 설명 가능한가?

선형회귀는 반응변수와 설명변수 사이의 관계를 선형 결합으로 표현해.

Y = β₀ + β₁X₁ + ··· + βₚXₚ + ε

그런데 실제 관계가 Y = X² 같은 곡선 구조라면 직선 하나로 설명하기 어려워. 그래서 산점도, 잔차도, 부분잔차도 등을 보고 잔차가 0 주변에 무작위로 흩어지는지 살펴본다. 잔차가 U자 모양처럼 체계적인 곡선 패턴을 보이면 비선형 구조를 놓쳤을 가능성이 커.

독립성 — 한 관측치의 오차가 다른 관측치와 연결되어 있지 않은가?

특히 시간 순서가 있는 데이터에서 중요해. 오늘의 오차가 어제의 오차와 계속 비슷하게 움직인다면 오차들이 서로 독립이라고 보기 어렵지.

Durbin-Watson
≈ 2
자기상관이 크지 않음
Durbin-Watson
≈ 0
양의 자기상관 가능성
Durbin-Watson
≈ 4
음의 자기상관 가능성

등분산성 — 오차의 퍼짐이 일정한가?

등분산성은 설명변수나 예측값이 달라져도 오차의 분산이 일정하다는 뜻이야.

Var(εᵢ) = σ²

바람직한 잔차 패턴

잔차가 0을 중심으로 비슷한 폭으로 흩어진다.

이분산성이 의심되는 패턴

예측값이 커질수록 퍼짐이 커지는 깔때기 모양.

대표적인 점검 방법은 잔차-적합값 그래프, Breusch-Pagan 검정, White 검정 등이야.

정규성 — 잔차가 정규분포를 따르는가?

선형회귀에서 일반적으로 보는 것은 X 자체나 Y 자체의 정규성보다 오차항 또는 잔차의 정규성이야. 대표적인 방법은 히스토그램, Q-Q plot, Shapiro-Wilk 검정이야. Q-Q plot의 점들이 기준 직선 주변에 비교적 잘 놓이면 정규성이 크게 깨지지 않았다고 볼 수 있어.

정규성은 특히 회귀계수의 검정이나 신뢰구간 같은 통계적 추론과 관계가 깊다는 점을 기억해.

🔗 3. 다중공선성 — 설명변수끼리 너무 비슷하지 않은가?

다중공선성(multicollinearity)은 여러 설명변수가 서로 강하게 관련될 때 생겨. 주택가격 예측에서 주택 면적, 방 개수, 건물 규모처럼 서로 강하게 연결된 변수가 많으면 각 변수의 고유한 효과를 분리하기 어려워질 수 있어.

Variance Inflation Factor
VIFⱼ = 1 / (1 − Rⱼ²)

Rⱼ²가 1에 가까워질수록 다른 설명변수들이 Xⱼ를 거의 설명할 수 있다는 뜻이고, 분모가 0에 가까워지면서 VIF는 커져.

Rⱼ² ↑
1 − Rⱼ² ↓
VIF ↑
다른 설명변수와의 중복성·다중공선성 가능성 ↑

실무나 교재에서는 VIF 5 또는 10 이상을 경고 기준으로 쓰기도 하지만, 절대적인 자연법칙 같은 기준은 아니야.

⚠️ 4. 가정 점검보다 더 중요한 것 — 위반 영향 판단

가정이 위반됐다고 해서 곧바로 모델을 폐기하는 게 아니야. 중요한 건 그 위반이 어떤 결과를 흔드는지야.

이분산성
표준오차 신뢰성 저하
t 통계량·p-value·신뢰구간 영향
유의성 판단 오류 가능
t = β̂ / SE(β̂)

그래서 “이분산성은 나쁘다”라고 단독으로 외우는 것보다 이분산성 → 표준오차 문제 → 검정 결과의 신뢰성 저하라는 인과관계를 기억해야 해.

🧠 5. 가정마다 ‘망가지는 것’이 다르다

가정 문제 무엇이 문제인가 대표 영향
비선형성 모델 형태가 실제 관계와 맞지 않음 체계적인 예측오차, 설명력 저하
오차의 비독립성 잔차끼리 관련됨 표준오차·검정 신뢰성 저하
이분산성 잔차 분산이 일정하지 않음 표준오차와 추론 문제
잔차 비정규성 오차분포 가정 위반 특히 소표본에서 검정·신뢰구간 영향
다중공선성 설명변수끼리 강하게 연결 회귀계수 불안정, 표준오차 증가, 해석 어려움

예측 문제

가정 위반이 실제 예측값의 정확도나 체계적 오차에 직접 영향을 줄 수 있어.

추론 문제

표준오차, p-value, 신뢰구간, 회귀계수 해석 같은 통계적 추론이 더 크게 흔들릴 수도 있어.

따라서 가정을 검사한 뒤에는 반드시 “내 분석 목적에서 이 위반이 실제로 얼마나 심각한가?” 까지 판단해야 해.

🛠️ 6. 가정을 위반했다면 어떻게 대응할까?

비선형성

변수 변환 → 다항항·상호작용항 고려 → 비선형 모형 검토

이분산성

변수 변환 → 강건한 표준오차 고려 → 적절한 다른 모형 검토

자기상관

시간 구조를 반영하는 모형 → 시계열적 오차 구조 반영

다중공선성

중복 변수 제거 → 변수 선택 → 차원 축소 → 규제화 방법 검토

핵심은 기계적으로 하나의 처방을 붙이는 게 아니야. 위반의 원인, 분석 목적, 데이터 구조를 보고 대응해야 해.
