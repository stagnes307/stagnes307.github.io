문자열 컬럼은 많은 머신러닝 알고리즘에서 그대로 계산할 수 없어. 예를 들어 gender가 object라면 변환이 필요할 수 있어.

age int64 income float64 gender object purchase int64

숫자로 저장되어 있다 = 반드시 좋은 모형 입력이다, 는 아니야.

서울=1, 부산=2, 대구=3처럼 바꾸면 모형에 따라 존재하지 않는 순서 관계를 학습할 수도 있어. 그래서 범주형 변수의 의미를 보고 인코딩 방법을 선택해야 해.

🛠️ 3-2-2-1-2. 데이터 조작

목표변수 분리

X = df.drop(columns='target') y = df['target'] # 식별자까지 제거하는 경우 X = df.drop(columns=['target', 'id'])

범주형 변수 처리

X = pd.get_dummies(X) # 특정 열만 X = pd.get_dummies( X, columns=['gender', 'city'] )

더미 변수가 늘어나면서 열 개수가 증가할 수 있으니 전후의 X.shape를 확인해 보면 좋아.

스케일 조정

age가 20~70인데 income이 1,000~100,000처럼 크기 차이가 크면 일부 알고리즘은 영향을 받아. KNN, K-means, SVM, 로지스틱 회귀, 신경망 등에서는 스케일링이 중요해질 수 있어.

from sklearn.preprocessing import StandardScaler scaler = StandardScaler() X_scaled = scaler.fit_transform(X)

🚨 fit_transform()과 transform()의 차이

학습 데이터와 평가 데이터가 있을 때 평가 데이터에 다시 fit_transform()을 하면 평가 데이터의 평균과 표준편차를 새로 학습해버려.

잘못된 구조
X_train = scaler.fit_transform(X_train) X_test = scaler.fit_transform(X_test)
올바른 구조
X_train = scaler.fit_transform(X_train) X_test = scaler.transform(X_test)

핵심 원리

학습 데이터에서 기준을 배우고(fit), 그 기준을 다른 데이터에 적용한다(transform).

🧪 3-2-2-1-3. 학습 데이터 검증

결측값

X.isnull().sum() X.isnull().sum().sum()

전체 결과가 0이면 결측값이 없는 상태야.

무한값

import numpy as np np.isinf( X.select_dtypes(include=np.number) ).sum()

결측값만 없다고 해서 데이터가 반드시 정상인 것은 아니야.

자료형

X.dtypes X.select_dtypes( include='object' ).columns

사용할 모델이 문자열을 직접 지원하지 않으면 인코딩이 필요해.

X와 y의 행 수

X.shape y.shape # 정상 예 # X: (1000, 10) # y: (1000,)

모든 관측치마다 정답이 하나 있어야 해.

⚠️ Train/Test 컬럼 불일치

범주형 데이터를 학습 데이터와 평가 데이터에 각각 따로 더미 변환하면 서로 다른 범주가 존재할 수 있어서 컬럼 개수가 달라질 수 있어.

Train

city_Busan city_Daegu city_Seoul

Test

city_Busan city_Seoul
X_train.shape X_test.shape X_train.columns X_test.columns

모형 입장에서는 “나는 12개 변수를 배웠는데 왜 예측할 때 11개를 주지?”가 되는 셈이야.

🧠 데이터 누수 Data Leakage

데이터 누수는 평가할 때 원래 알면 안 되는 정보를 학습 과정에서 미리 사용하는 거야. 전체 데이터에 먼저 스케일러를 fit한 뒤 train/test를 나누면 평가 데이터의 정보가 전처리 기준에 들어갈 수 있어.

1
원본 데이터
2
Train / Test 분리
3
Train으로 fit
4
같은 기준으로 transform
