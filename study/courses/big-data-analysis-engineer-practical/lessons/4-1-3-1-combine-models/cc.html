모형 결합과 성능 확인

같은 답을 반복하는 모델보다 서로의 오류를 보완하는 모델을 결합한다. 예측을 섞은 뒤에는 최고 단일모형과 같은 조건에서 다시 겨룬다.

  • 결합 대상 선정
  • 예측 결합
  • 단일모형과 성능 비교

1

결합 대상은 성능과 다양성으로 고른다

기본 성능이 부족한 무작위 모델을 섞는다고 좋아지지 않는다. 최소 검증 성능을 통과한 후보 중 오류가 덜 겹치는 조합을 찾는다.

①
최소 성능 통과각 후보가 목적 지표의 기본 수준을 만족하는가?
②
오류 패턴 확인같은 평가 행에서 예측 불일치와 오류 겹침을 본다.
③
알고리즘 다양성선형 경향·비선형 규칙·배깅의 서로 다른 강점을 조합한다.
④
운영 가능성메모리, 예측시간, 모델 파일과 실패 대응 비용을 확인한다.
2

예측을 결합하는 세 가지 방식

하드 보팅은 레이블을, 소프트 보팅은 확률을 결합한다. 가중치는 반드시 검증 단계에서 정한다.

LABEL

하드 보팅

mode(ŷ₁, ŷ₂, ŷ₃)

각 모델의 최종 레이블에 한 표씩 준다. 확률 미지원 모델도 참여하지만 확신 정보는 버린다.

PROBABILITY

소프트 보팅

(p₁ + p₂ + p₃) / 3

양성 확률을 평균한다. 순위 지표와 임계값 조정에 유리하지만 확률 품질을 확인해야 한다.

VALIDATED WEIGHT

가중 소프트 보팅

Σwᵢpᵢ / Σwᵢ

검증 근거가 좋은 후보에 더 큰 비중을 준다. 테스트셋으로 가중치를 탐색하면 누수다.

4

6

결합에서 특히 조심할 누수와 함정

결합 규칙도 학습된 의사결정이다. 후보·가중치·임계값을 테스트에 맞추면 마지막 성능이 낙관적으로 변한다.

테스트로 가중치 탐색

여러 가중치를 테스트셋에서 시험해 최고 조합을 고르면 테스트 정보가 결합기에 유입된다.

스태킹의 학습 예측 재사용

메타모델은 기본모델의 자기 학습 행 예측이 아니라 OOF 예측으로 학습해야 한다.

확률 열 순서 오인

predict_proba의 열은 classes_ 순서다. 관심 양성 확률 열인지 확인한다.

앙상블이라는 이유로 채택

최고 단일모형보다 낮거나 향상이 운영비용보다 작다면 단일모형이 더 합리적이다.
