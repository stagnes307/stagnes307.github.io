5-2-1-1. 제1유형 계산값 제출

계산 성공을 제출 성공으로 바꾸는 마지막 3단계: 조건을 코드로 번역하고, 형식을 잠근 뒤, 올바른 소문항에 최종값을 입력한다.

근거 범위 · 공식 체험환경 운영을 위한 보충 학습이다. 실제 파일·열·자릿수·화면 지시는 해당 문제와 최신 안내가 우선한다.

풀이 코드 작성읽기 → 조건 적용 → 계산 → 중간 검증을 분리한다.
제출 형식 확인원값은 유지하고 요구 자릿수는 마지막에 적용한다.
계산값 입력별도 답안 화면의 소문항 순서와 마지막 제출을 확인한다.

한 번에 끝내는 제출 파이프라인

계약 읽기

파일, 열, 필터, 결측, 계산, 자릿수를 표시한다.

코드 작성

연산 순서를 문제 문장과 같은 방향으로 배치한다.

중간 검증

행 수, 대상값, 원 계산값이 기대 범위인지 본다.

형식화

마지막 한 번만 반올림하고 제출 문자열을 만든다.

입력·제출

소문항별 칸에 옮긴 뒤 최종 제출 상태를 확인한다.

원값과 제출값을 나란히 본다

Python 검증 패턴예시 자릿수: 2
selected = df.loc[df["group"].eq("A"), "score"].dropna()
assert len(selected) > 0

raw_answer = float(selected.mean())
assert math.isfinite(raw_answer)

digits = 2  # 실제 문제 지시로 교체
submit_text = f"{raw_answer:.{digits}f}"

print("대상값", selected.tolist())
print("원값", raw_answer)
print("제출값", submit_text)

답안 화면 역대조

코딩 화면에서 끝내지 말고 별도 답안 화면의 문항 번호와 형식을 다시 읽는다.

소문항 1 · 소수 둘째 자리까지
12.50

형식 확인 후 제출 상태 점검

함정: 입력칸 수정과 재제출은 다른 동작이다.

반올림은 연산의 마지막 문

원 데이터 → 필터·결측 처리 → 전체 계산 → 최종 반올림 → 입력 문자열

중간 단계마다 반올림하면 평균·비율·차이에서 누적 오차가 생길 수 있다. 문제에서 중간 반올림을 명시하지 않았다면 원 정밀도를 유지한다. 정수, 고정 소수, 지수 표기 등 허용 형식은 매 소문항 지시에서 확인한다.

확인 문제

A 그룹 평균을 소수 둘째 자리까지 제출한다. 안전한 순서는?

A 그룹 선택 → 필요한 결측 처리 → 평균 → 마지막 반올림·형식화 → 답안 입력이다.

계산값 12.5가 나왔다. 왜 그대로 입력하지 않고 형식을 확인하는가?

입력 UI가 고정 자릿수를 요구한다면 12.50처럼 표현해야 할 수 있다. 수학적 값과 제출 형식은 분리해서 확인한다.

답안 칸의 값을 고쳤다. 이제 끝인가?

아니다. 공식 체험 가이드의 마지막 제출 원칙에 따라 수정본을 다시 제출하고 최종 상태를 확인한다.

요약 · 값 하나에도 검증 사슬을 남긴다

  • 풀이 코드 작성: 파일·열·조건·결측·연산 순서를 분리한다.
  • 제출 형식 확인: 원값을 유지하고 마지막에 지정 형식으로 바꾼다.
  • 계산값 입력: 소문항 번호, 오류 메시지, 마지막 제출을 확인한다.
