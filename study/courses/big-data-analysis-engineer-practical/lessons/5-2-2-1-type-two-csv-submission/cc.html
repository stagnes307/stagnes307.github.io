실패 신호: `Unnamed` 열, 두 개 이상의 열, 행 수 감소, 새 하위 폴더.

공식 체험 가이드의 한 열 CSV 모형

평가 데이터 N행→예측 N개→지정 헤더 1개→인덱스 없이 저장

공식 체험 가이드는 예측 칼럼 1개, 자동 인덱스 제거, 지정 파일명 사용, 별도 디렉터리 금지를 안내한다. 실제 문제에 다른 제출 형식이 명시되면 실제 지시가 우선한다.

확인 문제

평가 데이터가 500행, 지정 헤더가 `pred`라면 기본 제출 구조는?

500행 × 1열이며 열 이름은 정확히 `pred`다. 실제 문제의 헤더 지시가 다르면 그 지시를 따른다.

재읽은 파일에 `Unnamed: 0`과 `pred`가 보인다. 무엇을 고치는가?

자동 인덱스를 함께 저장한 것이다. Python은 `index=False`, R은 `row.names=FALSE`로 다시 저장하고 재검증한다.

예측값을 큰 순서로 정렬하면 왜 안 되는가?

평가 데이터 원래 행과 예측의 대응이 깨진다. 예측 성능과 별개로 제출 행 순서는 원본 평가 순서를 유지해야 한다.

요약 · 저장이 아니라 재읽기가 완료 신호

  • 예측 코드 작성: 같은 특징·전처리 기준으로 평가 원순서 예측을 만든다.
  • 지정 파일·열 구성: 한 열, 지정 헤더·파일명, 자동 인덱스 제거를 지킨다.
  • CSV 제출 검증: 실제 파일을 다시 읽어 열·행·결측·예측 종류를 점검한다.
