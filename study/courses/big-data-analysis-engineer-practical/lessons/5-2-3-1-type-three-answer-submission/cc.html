가설에서 결과 성분, 결과 성분에서 제출 칸까지. 통계량·p-value·계수를 이름으로 꺼내고 소문항별 자릿수와 순서를 고정한다.

공식 체험환경 보충 · 화면 예시의 자릿수를 모든 문제의 규칙으로 일반화하지 않는다. 검정법·가설 방향·열·유의수준·표현은 실제 문제 지시가 우선한다.

통계 계산 코드 작성표본 구조·가설 방향·요구 성분을 먼저 정하고 계산한다.

소문항별 값 입력결과 성분에 번호를 붙여 별도 답안 화면에 옮긴다.

연습 문제 해석

`score`의 모평균이 70과 다른지 양측 검정하고 검정통계량과 p-value를 소수 셋째 자리까지 제시한다.

표본 · `score` 유효 관측값
H₀ · 모평균 = 70
H₁ · 모평균 ≠ 70
요구 성분 · statistic, p-value

제출 장부

사용 표본 수n 확인
원 통계량반올림 전
원 p-value0~1 검사
소문항 1통계량 문자열
소문항 2p-value 문자열

결과 위치가 아니라 결과 이름을 사용한다

Python · 계산, 범위 검사, 소문항 라벨
sample = pd.to_numeric(df["score"], errors="raise")
result = stats.ttest_1samp(
    sample,
    popmean=70,
    alternative="two-sided"
)

statistic = float(result.statistic)
p_value = float(result.pvalue)
assert math.isfinite(statistic)
assert 0.0 <= p_value <= 1.0

digits = 3  # 실제 소문항 지시로 교체
stat_text = f"{statistic:.{digits}f}"
p_text = f"{p_value:.{digits}f}"

print("소문항1 통계량", stat_text)
print("소문항2 p-value", p_text)

확인 문제

같은 사람의 전후 점수에 독립 표본 검정을 바로 적용하면 안 되는 이유는?

두 측정이 같은 대상에 묶여 독립이 아니기 때문이다. 문제 조건이 대응 구조라면 대응 표본 방법을 선택한다.

원 p-value 0.0106을 소수 둘째 자리까지 반올림하면?

제출 문자열은 0.01이다. 원값은 계산 과정에서 유지하고 최종 입력을 만들 때 한 번 형식화한다.

출력 첫째 값이 estimate, 둘째 값이 statistic이다. 위치로 복사해도 되는가?

안 된다. 결과 객체에서 이름으로 요구 성분을 추출하고 소문항 번호를 붙여 입력한다.

  • 반올림 형식 확인: 원값을 보존하고 소문항마다 마지막에 형식화한다.
