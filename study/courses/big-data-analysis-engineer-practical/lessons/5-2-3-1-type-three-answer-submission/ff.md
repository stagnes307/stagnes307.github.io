# 5-2-3-1. 제3유형 통계 계산값 제출

> **범위 안내**: 이 레슨은 한국데이터산업진흥원(K-DATA)의 공식 실기 체험환경과 「빅데이터분석기사 실기 체험 환경 가이드」를 근거로 한 제출 절차 보충 학습이다. 체험문제는 실제 시험의 출제 경향과 다를 수 있다. 실제 검정 방법, 가설 방향, 파일명, 열 이름, 유의수준, 반올림 자릿수와 답안 순서는 해당 문제 화면을 최종 기준으로 삼는다.

정확한 토픽은 **통계 계산 코드 작성**, **반올림 형식 확인**, **소문항별 값 입력**이다. 제3유형은 통계 함수를 호출하는 것만으로 끝나지 않는다. 가설과 검정 방향을 올바르게 정하고, 함수 결과에서 요구 성분을 골라, 반올림을 마지막에 적용한 뒤 별도의 답안 제출 화면에 소문항 순서대로 입력해야 한다.

---

## 1. 공식 체험환경의 제출 구조

공식 가이드에서 제3유형은 문제 풀이 화면과 답안 제출 화면이 분리되어 있다. 풀이 화면에서 각 문항을 해결한 다음 답안 제출 화면으로 이동하고, 문항별 소문항 순서와 지정 제출 형식에 맞춰 값을 입력한다. 입력 형식이 맞지 않으면 오류 안내가 표시될 수 있다. 답안을 여러 번 제출할 수 있으며 마지막 제출 답안이 채점 대상이라고 안내한다.

가이드에는 “반올림하여 소수점 둘째 자리까지 작성” 같은 형식 예가 나온다. 이는 체험 화면의 예시이지 모든 문항에 고정된 자릿수 규칙이 아니다. 어떤 문항은 정수, 어떤 문항은 검정통계량과 p-value, 어떤 문항은 회귀계수나 신뢰구간을 서로 다른 자릿수로 요구할 수 있다.

## 2. 토픽 ① 통계 계산 코드 작성

### 2.1 문제를 여덟 칸으로 분해한다

통계 계산 전에 다음을 한 줄씩 적는다.

1. **데이터**: 어느 파일과 어느 열을 쓰는가?
2. **표본 구조**: 한 표본, 독립 두 표본, 대응 표본, 범주형 표 중 무엇인가?
3. **모수·효과**: 평균, 비율, 분산, 독립성, 회귀계수 중 무엇을 묻는가?
4. **귀무가설**: 같음, 차이 없음, 독립 등 기준은 무엇인가?
5. **대립가설**: 양측, 작다, 크다 중 어느 방향인가?
6. **가정**: 독립성, 정규성, 등분산성 등 무엇을 확인해야 하는가?
7. **요구 출력**: 통계량, 자유도, p-value, 계수, 신뢰구간 중 무엇인가?
8. **표현**: 반올림 자릿수와 소문항 순서는 무엇인가?

이 분해 없이 `ttest`라는 단어만 보고 함수를 고르면 대응 표본을 독립 표본으로 계산하거나 양측 p-value를 단측 답으로 제출하는 실수가 생긴다.

### 2.2 Python 단일표본 t 검정 예제

아래는 “`score`의 모평균이 70과 다른지 양측 검정하고, 검정통계량과 p-value를 소수 셋째 자리까지 제시”하는 **연습 예제**다. 실제 문제의 기준값, 대립가설과 자릿수로 교체해야 한다. `scipy`가 제공되는지는 실행환경에서 먼저 확인한다.

```python
from io import StringIO
import math
import pandas as pd
from scipy import stats

csv_text = """id,score
1,68
2,72
3,75
4,69
5,74
6,71
7,73
8,70
"""
df = pd.read_csv(StringIO(csv_text))

required = ["id", "score"]
assert list(df.columns) == required
assert df["score"].notna().all()

sample = pd.to_numeric(df["score"], errors="raise")
mu0 = 70
result = stats.ttest_1samp(sample, popmean=mu0, alternative="two-sided")

statistic = float(result.statistic)
p_value = float(result.pvalue)
assert math.isfinite(statistic)
assert 0.0 <= p_value <= 1.0

digits = 3  # 실제 문제 지시로 교체
stat_text = f"{statistic:.{digits}f}"
p_text = f"{p_value:.{digits}f}"

print("n:", len(sample))
print("mean:", sample.mean())
print("statistic raw:", statistic)
print("p-value raw:", p_value)
print("소문항1 통계량:", stat_text)
print("소문항2 p-value:", p_text)
```

`alternative` 인수를 사용할 수 있는지와 정확한 값은 제공 함수의 도움말에서 확인할 수 있다. 특정 인터페이스가 없으면 양측 p-value를 단측으로 바꾸는 논리를 검정통계량의 방향과 함께 검토해야 한다. 단순히 2로 나누면 반대 방향 통계량에서도 잘못된 답을 만들 수 있다.

### 2.3 실제 파일과 열 검증

파일명과 열 이름은 문제 화면에서 그대로 가져온다. 다음의 `data/type3.csv`와 `score`는 뼈대용 예시다.

```python
from pathlib import Path
import pandas as pd

input_path = Path("data/type3.csv")  # 실제 제시 경로로 교체
value_col = "score"                  # 실제 지정 열로 교체

assert input_path.is_file(), f"파일 없음: {input_path}"
df = pd.read_csv(input_path)
print(df.shape)
print(df.columns.tolist())
print(df.head())

assert df.columns.is_unique
assert value_col in df.columns, f"누락 열: {value_col}"
before_na = df[value_col].isna().sum()
values = pd.to_numeric(df[value_col], errors="coerce")
after_na = values.isna().sum()
assert after_na == before_na, "숫자 변환 실패값이 추가됨"
```

결측 처리 지시가 없다면 임의로 평균 대체하지 않는다. 검정 함수가 결측을 자동 제거하는지도 확인하고, 실제 사용 표본 수를 출력한다. 표본 수가 바뀌면 자유도와 p-value도 바뀐다.

### 2.4 R 단일표본 t 검정 예제

R 기본 `stats`에서도 같은 연습을 실행할 수 있다.

```r
text_data <- "id,score
1,68
2,72
3,75
4,69
5,74
6,71
7,73
8,70"

df <- read.csv(text=text_data)
stopifnot(identical(names(df), c("id", "score")))
stopifnot(!anyNA(df$score))

sample <- df$score
mu0 <- 70
result <- t.test(sample, mu=mu0, alternative="two.sided")

statistic <- unname(result$statistic)
p_value <- result$p.value
stopifnot(is.finite(statistic))
stopifnot(p_value >= 0, p_value <= 1)

digits <- 3  # 실제 문제 지시로 교체
stat_text <- sprintf(paste0("%.", digits, "f"), statistic)
p_text <- sprintf(paste0("%.", digits, "f"), p_value)

print(result)
cat("소문항1 통계량:", stat_text, "\n")
cat("소문항2 p-value:", p_text, "\n")
```

R 결과 객체는 함수마다 성분 이름이 다르다. 전체 출력을 보고 숫자 위치를 세어서 가져오지 말고 `names(result)`, `str(result)` 또는 도움말로 `statistic`, `parameter`, `p.value`, `estimate`, `conf.int` 등 요구 성분을 명시적으로 선택한다.

### 2.5 독립·대응 표본을 구분한다

같은 사람의 전후 측정은 대응 표본일 수 있고, 서로 다른 두 집단은 독립 표본일 수 있다. 데이터가 두 열로 주어졌다는 모양만으로 판단하지 않는다.

```python
from scipy import stats

before = [72, 65, 80, 71, 69]
after = [75, 67, 81, 76, 70]

# 같은 대상의 전후 측정이라는 문제 조건일 때만 paired 사용
paired = stats.ttest_rel(after, before, alternative="two-sided")
print(paired.statistic, paired.pvalue)
```

```r
before <- c(72, 65, 80, 71, 69)
after <- c(75, 67, 81, 76, 70)
paired <- t.test(after, before, paired=TRUE, alternative="two.sided")
print(paired)
```

독립 표본에서 등분산 여부에 따라 인수가 달라질 수 있다. 문제 지시와 가정 확인 결과에 따라 선택하고, 익숙한 기본값을 무심코 사용하지 않는다.

## 3. 토픽 ② 반올림 형식 확인

### 3.1 계산과 표시를 분리한다

검정통계량, p-value, 회귀계수 등은 원값을 유지한다. 다른 계산에 사용할 값이라면 반올림 전 값을 쓰고, 답안으로 표시할 마지막 단계에서만 자릿수를 적용한다.

```python
raw = 0.0106
digits = 2
rounded_number = round(raw, digits)
submit_text = f"{rounded_number:.{digits}f}"

print(raw)             # 0.0106
print(rounded_number)  # 0.01
print(submit_text)     # '0.01'
```

공식 가이드 화면은 요구 형식이 소수점 둘째 자리일 때 `0.011`처럼 자릿수를 초과한 입력에 형식 오류가 날 수 있음을 예시로 보여 준다. 이것은 “모든 답을 둘째 자리로 쓰라”는 규칙이 아니다. 각 소문항의 지시를 읽고 자릿수를 별도로 정한다.

### 3.2 반올림·버림·올림을 바꾸어 쓰지 않는다

- **반올림**을 요구하면 언어의 반올림 동작과 경계값을 확인한다.
- **버림**을 요구하면 `round()`로 대체하지 않는다.
- **올림**을 요구하면 양수·음수에서 방향이 어떻게 정의되는지 확인한다.
- “소수 셋째 자리에서 반올림하여 둘째 자리까지”와 “소수 셋째 자리까지”를 구분한다.

부동소수점 수는 내부 이진 표현 때문에 경계에서 예상과 다르게 보일 수 있다. 문제가 특정 함수를 지시하면 그 함수를 따르고, 그렇지 않으면 계산값과 형식화 결과를 모두 출력하여 점검한다. 임의의 작은 수를 더해 답을 조정하는 방식은 피한다.

### 3.3 지수 표기와 부호를 확인한다

p-value가 매우 작으면 `1.2e-07`처럼 지수 표기로 출력될 수 있다. 입력 칸이 허용하는 형식과 문제 지시를 확인한다. 검정통계량의 음수 부호를 빼먹거나 절댓값으로 바꾸지 않는다. 통계량의 부호는 표본 평균 차이의 방향이나 계수 방향을 나타낼 수 있다.

```python
values = {"통계량": -2.34761, "p-value": 0.000124}
print("통계량:", f"{values['통계량']:.3f}")
print("p-value:", f"{values['p-value']:.4f}")
```

소문항마다 자릿수가 다를 수 있으므로 하나의 `digits`를 모든 값에 복사하지 않는다.

## 4. 토픽 ③ 소문항별 값 입력

### 4.1 출력에 번호를 붙인다

결과 객체의 출력 순서와 답안 화면 소문항 순서가 같다고 가정하지 않는다. 제출 직전에는 요구 순서대로 별도의 목록을 만든다.

```python
submission = [
    ("소문항1 검정통계량", stat_text),
    ("소문항2 p-value", p_text),
]

for label, text in submission:
    print(f"{label}: {text}")
```

R에서도 명시적으로 출력한다.

```r
submission <- c(
  "소문항1 검정통계량"=stat_text,
  "소문항2 p-value"=p_text
)
print(submission)
```

답안 화면으로 이동한 뒤 문제 번호, 소문항 라벨, 요구 자릿수를 다시 읽고 하나씩 옮긴다. 입력 후 형식 오류 메시지가 없는지 확인한다.

### 4.2 판단 문장과 숫자 입력을 구분한다

문제가 숫자만 입력하라고 하면 `기각`, `채택`, `유의함` 같은 말을 숫자 칸에 붙이지 않는다. 반대로 별도 소문항에서 판단을 요구하면 유의수준과 p-value를 비교하되 “귀무가설을 채택한다”보다 “기각하지 못한다”처럼 증거 수준을 정확히 표현한다.

```python
alpha = 0.05  # 실제 문제 지시로 교체
decision = "귀무가설 기각" if p_value < alpha else "귀무가설을 기각하지 못함"
print(decision)
```

유의수준을 문제에서 주지 않았는데 임의로 고정해 판단하지 않는다.

### 4.3 마지막 제출 상태를 확인한다

공식 가이드상 답안을 여러 번 제출할 수 있고 마지막 제출이 채점 대상이다. 검산 후 값을 수정했다면 답안 칸만 고치지 말고 다시 제출하여 수정본이 마지막 제출이 되었는지 확인한다. 여러 문항을 이동하며 입력할 때 다른 문항의 칸에 값을 덮어쓰지 않았는지도 마지막에 순서대로 훑는다.

## 5. 오류 대응

| 증상 | 가능한 원인 | 우선 확인 |
|---|---|---|
| p-value가 0 또는 1 밖 | 잘못된 성분·계산식 | 결과 객체 이름과 선택 성분 |
| 통계량 부호가 예상과 반대 | 차이 순서 반대 | `x-y`인지 `y-x`인지 문제 정의 |
| 표본 수가 줄어듦 | 결측 자동 제거 | 원본·사용 표본 수와 결측 위치 |
| 자유도가 다름 | 독립/대응·등분산 설정 차이 | 표본 구조와 함수 인수 |
| 입력 형식 오류 | 자릿수 초과·문자 포함 | 소문항의 제출 형식 예시 |
| 값은 맞지만 칸이 틀림 | 결과 출력 순서 의존 | 번호 붙인 제출 목록과 화면 대응 |

오류 메시지는 첫 원인부터 읽는다. 패키지가 없으면 시험 중 설치를 시도하는 대신 실제 제공 여부와 대체 가능한 기본 함수를 확인한다. 함수가 반환한 `NaN`을 0으로 바꾸어 제출하지 않는다. 표본이 비어 있거나 분산이 0인 등 계산 자체의 전제가 깨졌는지 먼저 조사한다.

---

## 6. 시험 함정 체크리스트

- 양측과 단측 대립가설을 반대로 설정했다.
- 독립 표본과 대응 표본을 데이터 모양만 보고 골랐다.
- 등분산 가정을 확인하지 않고 기본 인수를 사용했다.
- 결측 제거 후 실제 표본 수와 자유도를 확인하지 않았다.
- 결과 객체에서 통계량 대신 추정값을 골랐다.
- p-value를 백분율로 바꾸었다.
- 중간값을 먼저 반올림해 다음 계산에 사용했다.
- 음수 부호를 빠뜨리거나 절댓값을 제출했다.
- 소문항별 서로 다른 자릿수를 한 형식으로 통일했다.
- 답안 칸을 수정했지만 마지막 제출을 하지 않았다.

### 문제 2

원 p-value가 `0.0106`이고 문제에서 소수 둘째 자리까지 반올림하라고 했다. 제출 문자열은 무엇이며 언제 반올림해야 하는가?

### 문제 3

함수 출력이 `estimate`, `statistic`, `p.value` 순으로 보인다. 화면의 소문항은 “검정통계량, p-value” 순서다. 안전한 제출 방법은 무엇인가?

## 정답과 해설

1. **정답: 두 측정값이 같은 대상에 묶여 있어 독립이 아니기 때문이다.** 문제 조건이 전후 대응 구조라면 대응 표본 방법을 사용해야 한다.
2. **정답: `0.01`이다.** 원값은 계산 과정에서 유지하고 최종 답안을 만들 때 한 번 반올림한다. 실제 자릿수 지시는 각 문제를 따른다.
3. **정답: 이름으로 `statistic`과 `p.value`를 추출하고, ‘소문항1 통계량’, ‘소문항2 p-value’처럼 번호를 붙여 형식화한 뒤 입력한다.** 화면 출력 위치를 세어 복사하면 다른 성분을 옮길 수 있다.
