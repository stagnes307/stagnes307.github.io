5-3-1-1. 공식 체험환경 전 과정 연습

문제를 여는 순간부터 마지막 제출 상태를 확인할 때까지. 화면 이동에도 끊기지 않는 확인·실행·검토·제출 루틴을 만든다.

체험과 실제를 구분 · 공식 가이드는 체험환경의 저장·메모 제한과 실제 시험의 정상 작동을 구분한다. 체험문제의 내용과 화면을 실제 출제 정책으로 확대 해석하지 않는다.

데이터와 문제 확인유형, 파일·열, 조건, 산출물, 제출 형식을 계약으로 만든다.
코드 실행과 결과 검토전체 재실행 가능한 코드와 짧은 검증 출력을 유지한다.
답안·파일 최종 제출유형별 제출 화면과 마지막 제출 상태를 분리해 확인한다.

체험환경과 실제 시험을 섞지 않는다

체험환경에서 관찰되는 제한

저장 기능 비활성화와 문제 이동 시 코드·메모 초기화가 있을 수 있다. 메모 기능도 체험에서 제한될 수 있다.

공식 가이드가 구분한 실제 시험

저장과 메모가 정상 작동한다고 설명하고 코드를 주기적으로 저장하며 풀 것을 권장한다. 실제 화면의 안내를 확인한다.

공식 가이드상 메모장은 풀이 화면에서 사용하며 답안 제출 화면에는 제공되지 않는다. 문제별 탭 이동 옵션과 저장 안내를 확인하고, 체험환경의 기능 제한을 실제 시험 정책으로 일반화하지 않는다.

확인 문제

체험환경에서 이동 후 코드가 사라졌다. 실제 시험에도 저장이 없다는 뜻인가?

아니다. 공식 가이드는 체험환경의 제한과 실제 시험의 정상 작동을 구분한다. 실제 화면과 최신 안내를 확인한다.

제2유형 파일이 생성되면 즉시 제출해도 되는가?

파일명·위치·한 개의 지정 헤더·자동 인덱스 부재·평가행 수·결측을 재읽어 확인한 뒤 제출한다.

제3유형 통계량을 코딩 화면에 출력하면 제출 완료인가?

아니다. 별도 답안 제출 화면에서 소문항 순서와 형식에 맞춰 입력하고 마지막 제출 상태를 확인해야 한다.

Warning이 보이지만 결과 숫자도 나왔다. 어떻게 하는가?

표본 제거, 형 변환, 수렴 등 결과 영향 여부를 확인한다. 정상 결과와 무관함이 확인된 경우에만 넘긴다.
