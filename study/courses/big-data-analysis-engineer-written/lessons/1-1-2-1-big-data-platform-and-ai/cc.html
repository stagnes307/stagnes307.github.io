빅데이터 플랫폼과 인공지능

이 단원은 두 문장부터 잡으면 돼.

빅데이터 플랫폼은 대규모 데이터를 수집 → 저장 → 처리 → 분석 → 활용할 수 있게 만든 통합 환경이야.

인공지능은 이렇게 축적된 데이터에서 규칙과 패턴을 학습해 판단·예측을 수행하는 기술이고.

한마디로 플랫폼은 데이터가 흐르는 기반, AI는 그 데이터로 지능적인 결과를 만드는 기술이야.

01 · PLATFORM

빅데이터 플랫폼은 왜 필요한가?

기업의 데이터는 한곳에 얌전히 있지 않아. 웹에서는 클릭 로그가 생기고, 앱에서는 행동 데이터가 발생하고, 공장에서는 센서가 계속 신호를 보내고, SNS에는 텍스트와 이미지가 쌓여.

문제는 데이터의 양도 크고, 발생 속도도 빠르고, 형태도 제각각이라는 거야. 그래서 단순한 데이터베이스 하나가 아니라 전체 흐름을 연결하는 플랫폼이 필요해.

이 전체 생명주기를 지원하는 환경이 바로 빅데이터 플랫폼이야.

STEP 01

수집 — 데이터를 가져온다

웹 로그, SNS, 센서, 데이터베이스, 외부 공개 데이터처럼 서로 다른 원천에서 데이터를 플랫폼 안으로 가져오는 단계야.

핵심

정형 데이터 + 반정형 데이터 + 비정형 데이터를 모두 받아들일 수 있어야 해.

STEP 02

저장 — 대량의 데이터를 보관한다

빅데이터에서는 규모가 크기 때문에 데이터를 여러 컴퓨터에 나누어 저장하는 분산 저장이 중요해져.

분산 저장

대규모 데이터를 여러 노드에 나누어 저장하는 방식. 대표 개념으로 Hadoop의 HDFS를 떠올리면 돼.

STEP 03

처리 — 계산 가능한 상태로 만든다

저장된 로그를 정제하고 변환해서 상품별 클릭 수, 고객별 방문 횟수, 시간대별 구매율처럼 분석 가능한 형태로 바꿔야 해.

처리 방식 의미
배치 처리 일정량의 데이터를 모은 뒤 한꺼번에 처리
실시간 처리 데이터가 발생하면 빠르게 연속적으로 처리

하루치 매출 통계는 배치 처리, 카드 이상 거래 즉시 탐지는 실시간 처리에 가까워.

STEP 04–05

분석과 활용 — 의미를 행동으로 바꾼다

처리된 데이터에서는 고객의 구매 가능성, 서비스 해지 가능성, 금융사기 가능성 같은 패턴을 찾아. 통계 분석, 데이터 마이닝, 머신러닝, 인공지능이 여기서 활용돼.

분석 결과는 차트, 대시보드, 보고서, 추천 시스템, 자동 의사결정 시스템으로 전달돼. 결국 플랫폼의 목적은 데이터를 모으는 것 자체가 아니라 가치로 바꾸는 것이야.

02 · PLATFORM CHARACTERISTICS

빅데이터 플랫폼의 핵심 특성

각각을 외우기보다 “대량·다양·빠른 데이터를 안정적으로 다루려면 무엇이 필요한가?”라고 생각하면 자연스럽게 연결돼.

확장성

데이터가 늘어나도 버틴다

여러 서버를 추가하는 수평적 확장, 즉 Scale-out이 중요해.

분산성

여러 컴퓨터가 일을 나눈다

분산 저장과 분산 처리가 대규모 플랫폼의 핵심 기반이 돼.

유연성

다양한 형태를 받아들인다

텍스트·이미지·영상·센서 로그처럼 서로 다른 데이터 유형을 다뤄야 해.

안정성과 가용성

일부 장애에도 계속 동작한다

노드 하나가 고장 나도 전체 서비스가 멈추지 않도록 설계해야 해.

  1. 1
    빅데이터 플랫폼

  2. 2
    데이터 처리

    불필요하거나 잘못된 데이터를 정제하고 분석 가능한 형태로 변환해.

  3. 3
    인공지능

    AI가 고객들의 구매 패턴을 학습해.

  4. 4
    서비스

    특정 고객에게 구매 가능성이 높은 상품을 추천해.

  5. 5
    새로운 데이터

    고객이 추천 상품을 클릭하거나 구매하면서 다시 데이터가 생겨.

그래서 빅데이터와 AI는 서로를 강화하는 관계라고 보면 돼.

05 · DATA QUALITY

데이터는 많기만 하면 될까?

AI, 특히 머신러닝은 데이터에서 패턴을 학습해. 따라서 대규모 데이터는 다양한 상황을 학습할 기반을 마련해줘.

함정

데이터 양 ↑ = AI 성능 무조건 ↑

25, 31, 28, -800, 912, null

데이터가 많더라도 품질이 엉망이면 결과도 나빠질 수 있어. 그래서 데이터의 양 + 데이터의 품질 + 적절한 알고리즘이 함께 중요해.

Garbage In, Garbage Out

08 · EXAM TRAPS

필기시험에서는 어디를 헷갈리게 할까?

플랫폼을 특정 기술 하나로 보는 함정

Hadoop = 빅데이터 플랫폼 전체라고 보면 안 돼. Hadoop은 플랫폼을 구성하는 기술일 수 있지만 플랫폼은 수집부터 활용까지의 더 넓은 환경이야.

빅데이터와 AI를 동일시하는 함정

둘은 같은 개념이 아니야. 빅데이터는 AI 없이도 활용할 수 있고, 모든 AI가 반드시 초대규모 데이터를 요구하는 것도 아니야.

데이터 양만 강조하는 함정

많다고 무조건 좋은 게 아니야. 품질이 낮은 데이터를 대량 학습시키면 잘못된 모델이 만들어질 수 있어.

저장만 플랫폼 기능이라고 보는 함정

플랫폼은 단순 저장소가 아니라 수집 → 저장 → 처리 → 분석 → 활용의 전체 생명주기를 지원하는 환경이야.

09 · LAST-MINUTE MEMORY

시험 직전 압축 기억법

① 빅데이터 플랫폼

대규모·다양한 데이터를 수집 → 저장 → 처리 → 분석 → 활용하기 위한 통합 환경

② 빅데이터와 AI

빅데이터는 AI가 학습할 데이터 기반을 제공하고, AI는 데이터에서 패턴·예측·가치를 만든다.

③ 둘의 차이

빅데이터는 데이터 중심, AI는 학습·추론 중심이며 서로 동일한 개념은 아니다.

이 세 문장이 머릿속에서 바로 나오면 이 단원의 중심은 잡힌 거야.
