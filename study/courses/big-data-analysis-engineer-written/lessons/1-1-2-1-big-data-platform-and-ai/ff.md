# 🧠 [데이터가 모이고, 지능이 작동하는 곳] 1-1-2-1. 빅데이터 플랫폼과 인공지능

#빅데이터분석기사 #빅데이터플랫폼 #인공지능 #필기핵심

---

이번 단원은 **두 문장만 제대로 잡으면 전체가 연결돼.**

> **빅데이터 플랫폼** = 대규모 데이터를 **수집 → 저장 → 처리 → 분석 → 활용**할 수 있게 만든 통합 환경
> **인공지능** = 이렇게 축적된 데이터에서 **규칙과 패턴을 학습해 판단·예측을 수행하는 기술**

즉, **플랫폼은 데이터가 흐르는 기반**, **AI는 그 데이터를 이용해 지능적인 결과를 만드는 기술**이라고 잡으면 돼.

참고로 지금부터의 학습 상태는 `저장`이라고 입력하면 저장해서 이어갈 수 있어.  또 `.cc 주제`처럼 입력하면 같은 내용을 HTML 학습 화면으로 볼 수도 있어. 

## 🏗️ 1. 빅데이터 플랫폼은 왜 필요한가?

먼저 **플랫폼(platform)**이라는 말을 정확히 잡자.

기업에 데이터가 있다고 해도 데이터가 한곳에 얌전히 모여 있는 게 아니야.

* 웹사이트에서는 클릭 로그가 발생하고
* 앱에서는 사용자 행동 데이터가 생기고
* 공장에서는 센서 데이터가 계속 들어오고
* SNS에서는 텍스트와 이미지가 만들어지고
* 회사 내부에는 고객·매출 데이터베이스가 있어.

문제는 **데이터의 양도 크고, 발생 속도도 빠르고, 형태도 제각각**이라는 거야.

그래서 단순한 데이터베이스 하나만으로는 부족해.

### 데이터가 지나가는 전체 길

빅데이터 플랫폼은 보통 다음 흐름을 지원해.

**데이터 발생**

↓

**① 수집**

↓

**② 저장**

↓

**③ 처리**

↓

**④ 분석**

↓

**⑤ 시각화·활용**

이 흐름 자체가 시험에서 굉장히 중요해.

---

### ① 수집 — 데이터를 가져온다

여러 곳에서 발생한 데이터를 플랫폼 안으로 가져오는 단계야.

예를 들면:

* 웹 로그
* SNS 데이터
* 센서 데이터
* 데이터베이스 데이터
* 외부 공개 데이터

여기서 핵심은 **다양한 형태의 데이터를 받아들일 수 있어야 한다**는 거야.

즉,

**정형 데이터 + 반정형 데이터 + 비정형 데이터**

를 모두 다룰 수 있어야 해.

---

### ② 저장 — 대량의 데이터를 보관한다

수집한 데이터를 안전하게 보관해야겠지.

빅데이터에서는 데이터 규모가 매우 크기 때문에 일반적으로 **분산 저장**이 중요해져.

#### 분산 저장의 생각

데이터 1PB를 컴퓨터 한 대에 전부 넣는 것보다,

**여러 컴퓨터에 나누어 저장**

하는 방식이 훨씬 현실적이야.

대표적인 개념으로 Hadoop의 **HDFS** 같은 분산 파일 시스템을 떠올리면 돼.

여기서 시험용 핵심:

**분산 저장 = 대규모 데이터를 여러 노드에 나누어 저장**

---

### ③ 처리 — 데이터를 계산 가능한 상태로 만든다

저장했다고 끝이 아니야.

데이터를 정제하거나 변환하고 계산해야 해.

예를 들어 쇼핑몰이 이런 데이터를 가지고 있다고 하자.

`고객 A / 상품 17 / 클릭 / 13:02`

이런 로그가 수십억 개 있다면,

* 상품별 클릭 수
* 고객별 방문 횟수
* 시간대별 구매율

같은 형태로 처리해야 분석할 수 있어.

대표적인 처리 방식은 크게:

**배치 처리**와 **실시간 처리**

로 구분해서 생각하면 좋아.

| 처리 방식  | 의미                     |
| ------ | ---------------------- |
| 배치 처리  | 일정량의 데이터를 모은 뒤 한꺼번에 처리 |
| 실시간 처리 | 데이터가 발생하면 빠르게 연속적으로 처리 |

따라서 하루치 매출 통계를 밤에 계산한다면 **배치 처리**, 카드 이상 거래를 발생 즉시 탐지한다면 **실시간 처리**가 더 적합해.

---

### ④ 분석 — 데이터에서 의미를 찾는다

처리된 데이터에서는 이제 패턴이나 관계를 찾아.

예를 들어:

* 어떤 고객이 상품을 구매할 가능성이 높은가?
* 어떤 고객이 서비스를 해지할 가능성이 높은가?
* 어떤 거래가 금융사기일 가능성이 높은가?

여기서 **통계 분석, 데이터 마이닝, 머신러닝, 인공지능** 등이 활용돼.

그래서 빅데이터 플랫폼과 AI가 연결되는 거야.

---

### ⑤ 시각화·활용 — 분석 결과를 실제 행동으로 바꾼다

분석 결과가 아무리 정확해도 사람이 사용할 수 없다면 의미가 작지.

따라서 결과를

* 차트
* 대시보드
* 보고서
* 추천 시스템
* 자동 의사결정 시스템

등으로 제공할 수 있어.

결국 빅데이터 플랫폼의 목적은 **데이터를 모으는 것 자체가 아니라 데이터를 활용 가능한 가치로 바꾸는 것**이야.

## ⚙️ 2. 빅데이터 플랫폼의 핵심 특성

구성 요소를 외우는 것보다 **왜 이런 플랫폼이 필요한지**를 이해하면 특성도 자연스럽게 따라와.

### 확장성 — 데이터가 늘어나도 버틴다

데이터가 10배로 증가했다고 시스템 전체를 버릴 수는 없잖아.

그래서 데이터나 사용량 증가에 맞추어 시스템을 확장할 수 있어야 해.

특히 빅데이터에서는 여러 서버를 추가하는 **수평적 확장(Scale-out)**이 중요하게 등장해.

---

### 분산성 — 여러 컴퓨터가 일을 나누어 한다

대규모 저장과 처리를 한 시스템이 모두 담당하지 않고 여러 노드가 분담해.

그래서 빅데이터 플랫폼에서는

**분산 저장 + 분산 처리**

가 중요한 기반 개념이 돼.

---

### 유연성 — 다양한 데이터를 다룬다

기존의 관계형 데이터베이스는 정형 데이터에 강했어.

하지만 빅데이터 환경에서는

텍스트, 이미지, 영상, 센서 로그 등 다양한 데이터가 들어오지.

따라서 **다양한 데이터 유형과 처리 방식에 대응할 수 있는 유연성**이 필요해.

---

### 안정성과 가용성

서버가 여러 대라면 그중 하나가 고장 날 수도 있어.

그렇다고 전체 서비스가 중단되면 안 돼.

그래서 장애가 발생해도 전체 시스템이 계속 동작할 수 있도록 **장애 대응과 가용성**이 중요해.

## 🤖 3. 빅데이터와 인공지능은 같은 것일까?

여기서 시험에서 틀리기 쉬운 경계가 하나 있어.

**빅데이터 ≠ 인공지능**

서로 관련은 매우 깊지만 같은 개념은 아니야.

### 빅데이터가 하는 일

핵심 관심사는 **데이터**야.

* 어떻게 수집할까?
* 어떻게 저장할까?
* 어떻게 빠르게 처리할까?
* 어떻게 분석 가능한 형태로 만들까?

### 인공지능이 하는 일

핵심 관심사는 **지능적 기능**이야.

* 어떻게 학습할까?
* 어떻게 분류할까?
* 어떻게 예측할까?
* 어떻게 판단할까?

그래서 이렇게 구분하면 정확해.

| 빅데이터                  | 인공지능                      |
| --------------------- | ------------------------- |
| 대규모 데이터의 수집·저장·처리·분석  | 데이터를 이용한 학습·추론·예측         |
| 데이터 인프라의 성격이 강함       | 알고리즘·모델의 성격이 강함           |
| AI에 필요한 데이터를 제공할 수 있음 | 빅데이터에서 의미 있는 패턴을 발견할 수 있음 |

## 🔄 4. 그렇다면 둘은 어떻게 연결될까?

가장 중요한 관계야.

**빅데이터 → AI 학습 → 예측·판단 → 새로운 데이터 발생**

이라는 순환 구조가 만들어져.

예를 들어 쇼핑몰 추천 시스템을 보자.

### 추천 시스템의 흐름

고객들이 쇼핑몰에서 행동해.

`검색 → 클릭 → 장바구니 → 구매`

이 데이터가 계속 발생하지.

#### 1단계 — 빅데이터 플랫폼

수백만 고객의 행동 데이터를 수집하고 저장해.

↓

#### 2단계 — 데이터 처리

불필요하거나 잘못된 데이터를 정제하고 분석 가능한 형태로 변환해.

↓

#### 3단계 — 인공지능

AI가 고객들의 구매 패턴을 학습해.

예를 들면:

**노트북을 산 사람은 무선 마우스를 함께 살 가능성이 높다.**

↓

#### 4단계 — 서비스

AI가 특정 고객에게 적절한 상품을 추천해.

↓

#### 5단계 — 새로운 데이터

고객이 추천 상품을 클릭하거나 구매하면서 새로운 데이터가 다시 만들어져.

그래서 **빅데이터와 AI는 서로를 강화하는 관계**라고 볼 수 있어.

## 🧠 5. 왜 빅데이터가 AI 발전과 연결되는가?

AI, 특히 머신러닝은 데이터에서 패턴을 학습해.

그런데 학습할 데이터가 너무 적다면 현실의 다양한 상황을 충분히 경험하기 어려워.

빅데이터 환경에서는 대규모 데이터를 확보할 가능성이 커지기 때문에 AI가 더 다양한 패턴을 학습할 기반이 마련돼.

하지만 중요한 제한도 있어.

### 데이터는 많기만 하면 되는 게 아니다

이건 자주 생기는 오해야.

**데이터 양 ↑ = AI 성능 무조건 ↑**

는 아니야.

예를 들어 고객 연령 데이터가 이렇게 저장돼 있다고 해보자.

`25, 31, 28, -800, 912, null`

데이터는 많더라도 품질이 엉망이면 AI 학습 결과도 나빠질 수 있어.

따라서 AI에서는

**데이터의 양 + 데이터의 품질 + 적절한 알고리즘**

이 함께 중요해.

이 관계를 흔히 **Garbage In, Garbage Out**, 즉 잘못된 데이터를 넣으면 잘못된 결과가 나온다는 관점으로 이해할 수 있어.

## 🧩 6. 인공지능 안에서 머신러닝과 딥러닝의 위치

시험 공부를 하다 보면 용어가 한꺼번에 나오니까 구조를 미리 잡아두자.

**인공지능(AI)**
└─ **머신러닝(Machine Learning)**
　└─ **딥러닝(Deep Learning)**

즉,

**딥러닝 ⊂ 머신러닝 ⊂ 인공지능**

이야.

### 인공지능

인간의 지능적인 행동을 컴퓨터가 수행하도록 하는 넓은 분야.

### 머신러닝

사람이 모든 규칙을 직접 작성하지 않고 **데이터에서 규칙이나 패턴을 학습**하게 하는 방법.

### 딥러닝

머신러닝 중에서 **다층 인공신경망**을 이용하는 방법.

그래서 빅데이터와 특히 연결이 강한 영역 중 하나가 머신러닝·딥러닝이야.

## 🏭 7. 전체 구조를 한 장으로 연결해보자

빅데이터 시스템을 이렇게 보면 가장 편해.

```text
[데이터 발생]
웹 · 앱 · SNS · 센서 · DB
        ↓
      수집
        ↓
      저장
        ↓
      처리
        ↓
  분석 / 머신러닝
        ↓
   AI 모델 · 예측
        ↓
추천 · 탐지 · 자동화 · 의사결정
        ↓
   새로운 데이터 발생
        ↺
```

여기서 가운데의 **수집·저장·처리·분석 환경 전체가 빅데이터 플랫폼**이고, 그 데이터를 이용해 학습하고 예측하는 부분에 **AI**가 들어오는 거야.

## 🎯 8. 필기시험에서는 어디를 헷갈리게 할까?

### 플랫폼을 특정 기술 하나로 보는 함정

**Hadoop = 빅데이터 플랫폼 전체**

라고 생각하면 안 돼.

Hadoop 같은 기술은 플랫폼을 구성하는 중요한 기술일 수 있지만, **플랫폼이라는 개념은 데이터 수집부터 활용까지 포함하는 더 넓은 환경**이야.

---

### 빅데이터와 AI를 동일시하는 함정

빅데이터는 AI 없이도 분석하고 활용할 수 있어.

반대로 모든 AI 시스템이 반드시 엄청난 규모의 빅데이터를 요구하는 것도 아니야.

따라서 둘의 관계는

**동일한 기술**

이 아니라

**서로 결합하면 가치가 커지는 기술 영역**

이라고 이해해야 해.

---

### 데이터 양만 강조하는 함정

AI에 데이터가 중요하다고 해서 **많을수록 무조건 좋다**는 의미는 아니야.

품질이 낮은 데이터를 대량으로 학습시키면 오히려 잘못된 모델이 만들어질 수 있어.

---

### 저장만 플랫폼의 기능이라고 보는 함정

빅데이터 플랫폼은 단순 저장소가 아니야.

**수집 → 저장 → 처리 → 분석 → 활용**

의 전체 생명주기를 지원하는 환경이라는 게 핵심이야.

## 📌 9. 시험 직전 압축 기억법

이 단원은 아래 세 줄로 압축할 수 있어.

**① 빅데이터 플랫폼**

> 대규모·다양한 데이터를 **수집 → 저장 → 처리 → 분석 → 활용**하기 위한 통합 환경

**② 빅데이터와 AI**

> 빅데이터는 AI가 학습할 수 있는 **데이터 기반**을 제공하고, AI는 데이터에서 **패턴·예측·가치**를 만들어낸다.
