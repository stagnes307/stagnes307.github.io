데이터 확보와 분석 작업 계획

데이터 확보 계획은 분석에 필요한 입력을 어떻게 준비할지 정하는 계획이고, 분석 절차 및 작업 계획은 그 데이터를 가지고 누가, 언제, 어떤 순서로 분석할지 정하는 계획이야.

분석 목표
→
필요 데이터 결정
→
데이터 확보 → 분석 작업 → 결과

🎯 먼저 구조부터: 이 단원은 무엇을 계획하는가

분석을 시작한다고 바로 모델을 만드는 건 아니야. 먼저 분석에 필요한 데이터를 어떻게 마련할지, 그리고 확보한 데이터를 어떤 절차와 일정으로 분석할지를 결정해야 해.

데이터 확보 계획

분석에 필요한 재료 준비 계획. 어떤 데이터를 어디서 어떻게 확보할지를 다룬다.

분석 절차 및 작업 계획

재료를 가지고 진행하는 조리 순서와 일정표. 누가, 언제, 어떤 순서로 분석할지 다룬다.

🔍 실제 확보 가능성을 검토한다

접근 가능성

비용과 시간

데이터 품질

정확성, 완전성, 일관성, 최신성·적시성 등을 확인한다.

법적·보안 제약

개인정보, 데이터 사용 권한, 보안 정책, 외부 데이터 이용 조건을 확인한다.

데이터가 많다고 항상 좋은 건 아니야. 분석 목적에 맞고 신뢰할 수 있으며 실제로 사용할 수 있는 데이터인지가 더 중요해.

🗂️ 데이터 확보 계획을 한 덩어리로 묶기

필요 데이터 → 출처 → 확보 방법 → 품질 → 제약 → 저장·관리
계획 요소확인할 내용
필요 데이터분석 목적에 어떤 데이터가 필요한가
데이터 출처내부·외부 어디에 존재하는가
확보 방법DB 추출, API, 파일 수집, 조사 등
품질분석에 사용할 수준인가
비용·기간현실적으로 확보 가능한가
법·보안개인정보·권한 문제가 없는가
저장·관리확보한 데이터를 어떻게 관리할 것인가

핵심은 데이터 확보 계획이 단순한 데이터 수집 계획보다 넓다는 점이야. 필요한지, 구할 수 있는지, 믿을 수 있는지, 비용과 법적 제약은 어떤지까지 함께 본다.

⚙️ 2. 분석 절차 및 작업 계획

데이터 확보 방법을 정했다면 이제 분석 프로젝트를 실제 작업으로 바꿔야 해. 여기서는 분석 절차와 작업 계획을 구별하는 게 중요해.

분석 절차 = 무엇을 어떤 순서로 하는가

분석 절차

WHAT + ORDER

무엇을 어떤 순서로 할 것인가.

작업 계획

WHO + WHEN + HOW + OUTPUT

누가, 언제, 어떻게 수행하고 무엇을 만들 것인가.

🛠️ 작업 계획 = 절차를 실제 업무로 구체화한다

“데이터를 전처리한다”는 건 절차야. 하지만 프로젝트 실행을 위해서는 담당자, 기간, 자원, 앞뒤 작업, 산출물까지 구체적으로 정해야 하지.

작업을 세분화한다

데이터 준비
데이터 추출
데이터 결합
결측치 확인
이상치 처리
변수 변환

WBS · Work Breakdown Structure

큰 프로젝트를 관리 가능한 작은 작업 단위로 분해하는 것

어려운 약어 자체보다 이 의미를 기억하는 게 중요해. 분석 프로젝트의 큰 업무를 세부 작업으로 쪼개야 일정과 책임을 관리할 수 있어.

📅 일정과 선후관계를 계획한다

작업을 나눴으면 무작정 동시에 진행할 수 있는지 확인해야 해. 데이터 확보가 끝나지 않았는데 모델 검증부터 할 수는 없지.

  • 작업 시작·종료 시점
  • 예상 소요시간
  • 작업 간 선후관계
  • 병렬 수행 가능 여부
  • 주요 완료 시점
  • 인력과 자원

마일스톤 · Milestone

프로젝트에서 의미 있는 중요한 완료 시점이나 이정표.

데이터 확보 완료 전처리 완료 모델 후보 선정 완료 최종 분석 완료

⚠️ 필기에서 잘 섞이는 경계

데이터 확보 vs 데이터 전처리

확보는 필요한 데이터를 사용할 수 있도록 가져오는 단계, 전처리는 확보한 데이터를 분석에 적합한 형태로 바꾸는 단계.

DB에서 추출 → 확보 / 결측치 처리 → 전처리

분석 절차 vs 일정 계획

분석 절차는 작업의 논리적 진행 순서, 일정 계획은 각 작업을 언제 수행할지 정하는 것.

데이터 품질 vs 데이터 보안

품질은 분석에 쓸 만한 데이터인지, 보안은 적절한 권한과 방식으로 다루는지 본다.

마일스톤 vs 산출물

마일스톤은 중요한 완료 지점, 산출물은 실제 만들어지는 결과다.

🔑 필기용 핵심 문장

① 데이터 확보 계획은 분석 목적에 필요한 데이터를 정의하고, 출처·확보 방법·품질·비용·법적 제약 등을 검토하는 것이다.
② 분석 절차는 분석 업무의 논리적인 수행 순서를 정하는 것이다.
③ 분석 작업 계획은 분석 업무를 세분화하고 담당자·일정·자원·선후관계·산출물 등을 구체화하는 것이다.
④ 데이터 확보 계획과 분석 작업 계획은 서로 독립적인 것이 아니라, 확보 가능한 데이터를 기준으로 실제 분석 일정과 업무가 설계되는 연결 관계다.

시험장에서 가장 빠르게 떠올릴 문장

확보 계획 = 어떤 데이터를 어떻게 준비할까?
작업 계획 = 준비한 데이터로 누가 언제 무엇을 할까?
