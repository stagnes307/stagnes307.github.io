RAW DATA INSPECTION DESK 2-1-1-1

🧭 먼저 잡을 큰 그림

셋을 한 문장으로 나누면 이렇게 돼. 정제는 데이터 품질을 높이는 전체 작업이고, 결측값은 값이 없는 문제, 이상값은 값은 있지만 다른 관측과 비교해 유난히 튀는 문제야.

구분 핵심 질문 예
데이터 정제 데이터의 품질 문제를 어떻게 바로잡을까? 중복 제거, 형식 통일, 오류 수정
결측값 값이 없으면 어떻게 할까? NA, NULL, 빈칸
이상값 값은 있는데 유난히 튀면 어떻게 할까? 대부분 50~100인데 5,000

이상값 ≠ 오류값

나이 = 250세라면 입력 오류일 가능성이 높지만, 연봉 = 30억 원은 매우 드물어도 실제 값일 수 있어. 이상값을 발견했다고 곧바로 삭제하면 안 되는 이유가 바로 여기 있어.

01 · CLEANING

🧼 데이터 정제 — 무엇을 깨끗하게 만드는가?

데이터 정제(Data Cleaning)는 데이터에 존재하는 오류·누락·불일치·중복 등을 찾아 수정하거나 제거하여 데이터 품질을 높이는 과정이야.

전처리 안에서의 위치

데이터 전처리 → 데이터 정제 → 데이터 변환 → 데이터 축소 등

시험에서 “데이터 분석 전에 잘못되거나 누락된 값을 수정하고 중복을 제거하는 과정”이라고 나오면 데이터 정제를 떠올리면 돼.

중복 데이터

동일 관측치가 여러 번 저장된 경우. 고객번호 A103의 동일 주문이 두 번 들어갔다면 분석이 왜곡될 수 있어.

핵심: 동일 개체를 판단할 기준부터 정의

형식 불일치

서울 / 서울시 / 서울특별시, M / Male / 남처럼 같은 의미가 다른 형태로 저장된 경우야.

핵심: 하나의 기준으로 표준화

논리·범위 오류

나이 -5, 만족도 범위가 1~5인데 8, 퇴사일이 입사일보다 빠른 경우처럼 현실 또는 업무 규칙을 어기는 값.

핵심: 삭제보다 원자료 확인이 우선

02 · MISSING VALUES

🕳️ 데이터 결측값 처리 — 값이 없다면?

결측값(Missing Value)은 관측되어야 할 값이 기록되지 않은 상태야. 프로그램에서는 NA, NaN, NULL 등으로 나타날 수 있어.

왜 그냥 두면 문제가 될까?

사용 가능한 데이터가 줄어든다.

평균·분산 같은 통계량이 왜곡될 수 있다.

일부 알고리즘은 결측값을 직접 처리하지 못한다.

특정 집단에 결측이 몰리면 분석 결과가 편향될 수 있다.

🗑️ 결측값 처리 ① 삭제

행 삭제

결측값이 포함된 관측치를 제거하는 방법이야.

10, 20, 결측, 30 → 10, 20, 30

장점 · 간단하고 인위적인 값을 만들지 않는다.

단점 · 데이터가 줄고, 결측이 무작위가 아니면 편향될 수 있다.

열 삭제

특정 변수 대부분이 결측이면 해당 변수를 분석에서 제외하는 방법도 있어.

예: 10만 명 중 9만 명의 ‘취미’ 값이 없음 → 변수 제거를 검토.

단, 분석에 중요한 변수라면 결측률만 보고 함부로 삭제하면 안 돼.

🔧 결측값 처리 ② 대체

시험에서 특히 중요해. 자료형과 분포에 따라 대표 대체값이 달라져.

MEAN

평균값 대체

수치형 자료의 결측값을 평균으로 채우는 방법.

(10 + 20 + 30) ÷ 3 = 20

평균값이 반복되므로 분산을 작게 만들 수 있고, 이상값에도 민감해.

MEDIAN

중앙값 대체

이상값이 존재하거나 분포가 치우친 수치형 자료에서 평균보다 적합한 경우가 많아.

10, 11, 12, 13, 1000

이상값 존재 → 평균 민감 → 중앙값이 상대적으로 강건

MODE

최빈값 대체

가장 자주 등장한 값으로 채우는 방법. 범주형 자료에서 대표적으로 사용해.

서울 · 부산 · 서울 · 결측 · 서울
→ 서울로 대체
데이터 특징 대표 대체값
대칭적인 수치형 자료평균
이상값·왜도가 큰 수치형 자료중앙값
범주형 자료최빈값

앞뒤 값을 이용해 중간 값을 추정하는 방식. 특히 시계열 데이터에서 자연스럽게 등장해.

예측 모델 이용

다른 변수를 이용해 결측값을 추정할 수도 있어.

나이 + 직업 + 학력 → 소득 예측

KNN, 회귀모형 등 다양한 방법을 사용할 수 있지만 예측값은 어디까지나 추정값이야.

🧠 결측 발생 방식 — MCAR · MAR · MNAR

MCAR

Missing Completely At Random

결측 발생이 다른 변수나 결측값 자체와 관계가 없는 경우.

MAR

Missing At Random

결측 발생이 관측된 다른 변수와 관련되지만 결측값 자체와 직접 관련되지는 않는 경우.

MNAR

Missing Not At Random

결측 발생이 결측된 값 자체와 관련되는 경우.

03 · OUTLIERS

📈 데이터 이상값 처리 — 값이 너무 튄다면?

이상값(Outlier)은 다른 관측값들과 비교했을 때 지나치게 크거나 작은 값이야.

5148535049500

탐지 → 원인 확인 → 처리 결정

이상값은 잘못된 값일 수도 있고 실제로 존재하는 희귀한 값일 수도 있어. 따라서 이상값이라는 이유만으로 바로 삭제하면 안 돼.

IQR METHOD

📦 이상값 탐지 — IQR

사분위수는 데이터를 크기순으로 놓았을 때 위치를 나누는 값이야.

Q125%
Q250%
Q375%
IQR = Q₃ − Q₁
하한 = Q₁ − 1.5 × IQR
상한 = Q₃ + 1.5 × IQR

예시: Q1 = 20, Q3 = 40

1. IQR

40 − 20 = 20

2. 하한

20 − (1.5 × 20) = −10

3. 상한

40 + (1.5 × 20) = 70

따라서 −10보다 작거나 70보다 큰 값은 이상값 후보.

STANDARD SCORE

📐 이상값 탐지 — Z-score

관측값이 평균에서 표준편차 몇 배만큼 떨어져 있는지를 나타내는 방법이야.

z = (x − μ) / σ

일반적으로 |z| ≥ 3 정도인 값을 이상값 후보로 보는 경험적 기준이 자주 사용돼. 다만 평균과 표준편차 자체가 이상값의 영향을 받기 때문에 심한 이상값이 있을 때는 IQR 같은 강건한 기준이 유용할 수 있어.

🔎 그 밖의 이상값 탐지

시각화

박스플롯, 산점도, 히스토그램을 통해 극단적 관측값을 확인할 수 있어.

특히 박스플롯 ↔ IQR 연결을 기억.

도메인 기준

통계적으로 아주 튀지 않더라도 현실적으로 불가능할 수 있어. 사람의 나이가 180세라면 업무 지식으로 오류 여부를 판단할 수 있지.

통계적 기준 + 업무·도메인 지식

🛠️ 이상값을 발견한 뒤 어떻게 처리할까?

오류라면 수정

원자료 확인으로 정확한 값을 알 수 있다면 수정이 가장 좋아. 예: 키 1750cm → 원자료 확인 후 175cm.

삭제

명백한 오류인데 수정할 방법이 없는 경우 제거를 고려. 실제 희귀값을 잘못 삭제하면 분석 결과가 왜곡될 수 있어.

경계값 조정

극단값을 일정 백분위수 경계값으로 바꿔 영향력을 줄이는 방식. 대표적으로 윈저라이징(Winsorization).

데이터 변환

로그 변환 등으로 큰 값들의 차이를 압축해 극단값의 영향력을 줄일 수 있어.

강건한 방법

중앙값처럼 이상값에 덜 민감한 통계량이나 robust 방법을 이용해 이상값을 반드시 제거하지 않고도 분석할 수 있어.

🎯 빅데이터분석기사 필기에서 잡아야 할 함정

“결측값은 평균으로 대체하면 된다”

항상 그렇지 않아. 분포가 치우치거나 이상값이 있으면 중앙값이 더 적절할 수 있어.

“이상값은 제거한다”

오류인지 실제 희귀 관측인지 먼저 확인해야 해.

“IQR은 Q1 + Q3이다”

IQR = Q₃ − Q₁

“중앙값은 이상값의 영향을 더 크게 받는다”

반대야. 중앙값은 평균보다 이상값에 강건해.
