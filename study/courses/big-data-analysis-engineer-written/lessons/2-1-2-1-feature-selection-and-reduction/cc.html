변수 선택은 기존 변수 중 일부를 남기는 일이고, 차원축소는 여러 변수의 정보를 더 적은 새 변수로 압축하는 일이야. 이 차이를 잡으면 PCA, LDA, LASSO가 한꺼번에 정리돼.

🎯 먼저 잡아야 할 한 줄

변수가 너무 많으면 분석이 무조건 좋아지는 게 아니야. 불필요한 변수를 제거하거나, 여러 변수를 더 적은 수의 새로운 변수로 압축해야 할 때가 있어.

Feature Selection

필요 없는 변수를 버린다.

Dimensionality Reduction

여러 변수의 정보를 더 적은 변수에 압축한다.

🧩 왜 변수를 줄여야 할까?

고객 이탈을 예측하는데 변수가 5개가 아니라 5,000개 있다고 해보자. 정보가 많아질 수도 있지만, 동시에 분석을 어렵게 만드는 부담도 커져.

계산량 증가

학습 시간과 메모리 사용량이 커진다.

잡음 증가

분석에 필요 없는 변수가 신호를 흐릴 수 있다.

과적합 위험

모델이 학습 데이터에 지나치게 맞춰질 수 있다.

해석 어려움

어떤 변수가 중요한지 설명하기 어려워진다.

차원의 저주

변수의 수가 증가하면 공간의 크기가 급격하게 커져. 같은 수의 데이터가 있어도 고차원에서는 서로 멀리 떨어진 것처럼 보일 수 있어. 그래서 변수의 수를 무작정 늘리는 것보다 유용한 정보만 남기는 것이 중요해.

🔎 변수 선택 Feature Selection

🌱 변수 선택의 핵심

변수 선택은 기존 변수 자체를 변형하지 않아. 예를 들어 나이, 소득, 방문횟수, 고객번호가 있다면 분석에 의미 없는 고객번호만 제거하는 식이야.

X₁ = 나이
X₂ = 소득
X₃ = 방문횟수
X₄ = 고객번호

결과 → X₁, X₂, X₃

원래 변수 중 일부가 그대로 남기 때문에 일반적으로 차원축소보다 해석하기 쉬워.

🧠 변수 선택의 세 가지 접근

Filter Method모델 밖

상관계수, 카이제곱, ANOVA, 상호정보량, 분산 기준처럼 통계적 기준으로 먼저 거른다.

Wrapper Method모델 반복

변수 조합을 바꾸며 실제 모델 성능을 비교한다. 전진선택, 후진제거, 단계적 선택, RFE가 대표적이야.

Embedded Method모델 안

학습 과정 자체에 선택 기능이 들어 있다. LASSO와 트리 기반 변수 중요도가 대표적이야.

🧬 Embedded와 LASSO

Embedded Method는 모델을 학습하는 과정 자체에서 변수를 선택해. 대표적으로 LASSO 회귀와 의사결정나무 기반 변수 중요도가 있어.

LASSO

L1 규제를 사용하고, 일부 회귀계수를 정확히 0으로 만들 수 있어.

βⱼ = 0 → 해당 변수 사실상 제외

Ridge

L2 규제는 계수를 작게 만들지만 일반적으로 정확히 0으로 만들지는 않아.

시험 연결: 변수 선택 ↔ LASSO(L1)

시험용 연결

LASSO → L1 → 계수 0 가능 → 변수 선택

🔄 변수 선택과 무엇이 다른가?

변수 선택
X₁, X₂, X₃ → X₁, X₃

원래 변수 일부를 남김

≠
차원축소
X₁, X₂, X₃ → Z₁, Z₂

기존 변수의 조합으로 새 변수 생성

Z₁ = 0.7X₁ + 0.4X₂ + 0.6X₃

변수 선택은 해석력을 보존하기 쉽고, 차원축소는 정보 압축 능력이 강해. 대신 새 축 Z₁이 현실적으로 무엇을 의미하는지는 설명하기 어려울 수 있어.

📐 주성분분석 PCA

빅데이터분석기사에서 차원축소와 연결하면 가장 먼저 떠올려야 하는 방법이 PCA(Principal Component Analysis, 주성분분석)야.

🌐 PCA가 해결하려는 문제

두 변수가 매우 높은 상관관계를 가지면 거의 같은 정보를 담고 있을 수 있어. PCA는 그 정보를 새로운 축으로 바꿔서 더 적은 차원으로 표현해.

X₁, X₂ → PC₁, PC₂

데이터가 가장 많이 퍼져 있는 방향을 제1주성분 PC₁로 잡고, 그다음 PC₁과 직교하면서 남은 분산을 가장 많이 설명하는 방향을 제2주성분 PC₂로 잡아.

🧭 PCA의 핵심 원리

PC₁

가장 큰 분산

PC₂

두 번째로 큰 분산

PC₃

세 번째로 큰 분산

PCA는 데이터의 분산을 최대한 보존하면서 차원을 줄이는 방법이다.

🧮 주성분은 기존 변수의 선형결합

PC₁ = a₁X₁ + a₂X₂ + a₃X₃

주성분은 원래 변수 중 하나가 아니라 여러 변수의 선형결합으로 만들어진 새로운 축이야. 이게 변수 선택과의 결정적인 차이야.

🧬 고유값과 고유벡터

고유벡터 → 새로운 축의 방향
고유값 → 해당 축이 설명하는 분산의 크기

고유값이 큰 주성분일수록 더 많은 분산을 설명해.

📈 설명된 분산 Explained Variance

PCA에서는 몇 개의 주성분을 남길지 결정해야 해. 이때 누적 설명 분산 비율을 볼 수 있어.

PCA는 분산이 큰 방향을 중요하게 보는데, 단위 차이 때문에 연봉 수치가 압도적으로 커. 실제 중요도와 관계없이 연봉이 PCA를 지배할 수 있으므로 변수의 단위나 스케일이 크게 다르면 일반적으로 먼저 표준화해.

Z = (X − μ) / σ
PCA + 서로 다른 척도 → 표준화 고려

🧲 LDA — PCA와 비교해서 기억하기

LDA(Linear Discriminant Analysis, 선형판별분석)도 차원축소에 사용할 수 있어. PCA와 결정적으로 다른 점은 클래스 정보를 사용한다는 거야.

PCA

“데이터가 가장 많이 퍼지는 방향은?”

비지도 · 목표변수 사용 X · 분산 최대화

LDA

“A반과 B반을 가장 잘 가르는 방향은?”

지도 · 클래스 정보 사용 · 클래스 분리 최대화

PCALDA
비지도지도
목표변수 사용 X클래스 정보 사용
분산 최대화클래스 분리 최대화
데이터 구조 보존 중심분류 성능 중심

LDA에서는 클래스 내부 분산은 작게, 클래스 간 분산은 크게 만드는 방향을 찾고, 클래스 수가 C개라면 얻을 수 있는 판별축 수는 최대 C − 1이야.

🧱 SVD — 행렬을 분해해서 압축하기

X = UΣVᵀ

SVD(Singular Value Decomposition, 특이값 분해)는 행렬을 여러 성분으로 분해한 뒤 큰 특이값에 해당하는 성분만 남겨 주요 정보를 유지하면서 차원을 줄일 수 있어.

고차원 행렬 압축
추천 시스템
텍스트 분석
잠재 의미 분석

🧠 PCA와 SVD는 어떤 관계인가?

둘은 완전히 별개의 세계가 아니야. PCA를 계산하는 방법 중 하나로 SVD를 사용할 수 있어.

PCA → 어떤 축을 찾을 것인가
SVD → 행렬을 어떻게 분해할 것인가

🚨 필기에서 잘 낚이는 지점

PCA는 변수를 선택한다?

아니야. 기존 변수의 선형결합으로 새로운 주성분을 만든다.

제1주성분은 목표변수를 가장 잘 예측한다?

아니야. 제1주성분은 데이터의 분산을 가장 크게 설명하는 축이야.

LASSO는 차원축소인가?

넓게 보면 변수 수를 줄이지만, 시험에서는 보통 변수 선택 방법으로 분류해.

Ridge도 변수 선택을 한다?

L2는 계수를 줄이지만 일반적으로 정확히 0으로 만들지는 않아. 직접적 변수 선택은 LASSO의 L1과 더 강하게 연결돼.

PCA를 하면 항상 표준화해야 하나?

무조건이라고 단정하면 위험해. 다만 변수들의 단위나 척도가 크게 다르면 표준화가 매우 중요해.
