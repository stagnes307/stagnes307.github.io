# 🧭 [남길 것인가, 압축할 것인가] 2-1-2-1. 변수 선택과 차원축소

#빅데이터분석기사 #필기 #데이터전처리 #분석변수처리 #변수선택 #차원축소

---

## 🎯 먼저 잡아야 할 한 줄

변수가 너무 많으면 분석이 무조건 좋아지는 게 아니야. **불필요한 변수를 제거하거나, 여러 변수를 더 적은 수의 새로운 변수로 압축**해야 할 때가 있어.

여기서 두 방법이 갈려.

| 구분    | 변수 선택 Feature Selection | 차원축소 Dimensionality Reduction |
| ----- | ----------------------- | ----------------------------- |
| 핵심    | 기존 변수 중 일부만 **선택**      | 기존 변수들을 조합해 **새 변수 생성**       |
| 원래 변수 | 그대로 남음                  | 보통 새로운 축으로 바뀜                 |
| 해석력   | 비교적 높음                  | 상대적으로 낮아질 수 있음                |
| 대표 예  | 전진선택, 후진제거, LASSO       | PCA, SVD, LDA                 |
| 공통 목적 | 차원 감소, 계산량 감소, 과적합 완화   |                               |

즉,

> **변수 선택 = 필요 없는 변수를 버린다.**
> **차원축소 = 여러 변수의 정보를 더 적은 변수에 압축한다.**

이 구분이 이 단원의 중심축이야.

---

## 🧩 왜 변수를 줄여야 할까?

예를 들어 고객 이탈을 예측하는데 변수가 5개가 아니라 5,000개 있다고 해보자.

변수가 많으면 정보가 많아질 수도 있지만, 동시에 다음 문제가 생겨.

### 차원이 커질수록 생기는 문제

* 계산량 증가
* 학습 시간 증가
* 불필요한 잡음 증가
* 변수 간 높은 상관관계 발생
* 모델의 과적합 가능성 증가
* 결과 해석이 어려워짐
* 고차원 공간에서 데이터가 희박해짐

마지막 현상을 흔히 **차원의 저주(Curse of Dimensionality)**라고 해.

변수의 수가 증가하면 공간의 크기가 급격하게 커지기 때문에, 같은 수의 데이터가 있어도 서로 멀리 떨어져 있는 것처럼 보일 수 있어.

따라서 변수의 수를 무작정 늘리는 것보다 **분석에 유용한 정보만 남기는 것**이 중요해.

---

# 🔎 변수 선택 Feature Selection

## 🌱 변수 선택의 핵심

변수 선택은 기존 변수 자체를 변형하지 않아.

예를 들어 원래 데이터가

$$
X_1=\text{나이},\quad
X_2=\text{소득},\quad
X_3=\text{방문횟수},\quad
X_4=\text{고객번호}
$$

라면,

고객번호가 분석에 의미가 없다고 판단해서 제거할 수 있어.

결과는

$$
X_1,\;X_2,\;X_3
$$

처럼 **원래 변수 중 일부만 남는 것**이지.

그래서 변수 선택은 일반적으로 차원축소보다 **해석하기 쉽다**는 장점이 있어.

---

## 🧠 변수 선택의 세 가지 접근

머신러닝에서는 변수 선택 방법을 크게 다음 세 가지로 구분해.

### 1. Filter Method — 필터 방법

모델을 학습시키기 전에 **통계적인 기준으로 변수의 중요성을 평가**해.

예를 들면:

* 상관계수
* 카이제곱 검정
* 분산분석(ANOVA)
* 상호정보량(Mutual Information)
* 분산 기준

구조는 간단해.

**전체 변수 → 통계적 평가 → 중요한 변수 선택 → 모델 학습**

#### 특징

* 계산이 빠름
* 특정 모델에 의존하지 않음
* 변수 각각을 평가하는 경우가 많아 변수 간 상호작용을 충분히 반영하지 못할 수 있음

시험에서는 이렇게 기억하면 편해.

> **Filter = 모델 밖에서 먼저 거른다.**

---

### 2. Wrapper Method — 래퍼 방법

이번에는 실제로 모델을 여러 번 학습시켜 봐.

변수 조합을 바꿔가며 모델 성능을 평가하고, 가장 좋은 변수 조합을 선택하는 방식이야.

대표적으로:

* 전진선택법
* 후진제거법
* 단계적 선택법
* RFE(Recursive Feature Elimination)

가 있어.

#### 장점

변수 조합이 실제 모델 성능에 미치는 영향을 직접 확인할 수 있어.

#### 단점

모델을 반복 학습해야 하므로 **계산량이 많다.**

> **Wrapper = 모델로 직접 싸보면서 좋은 조합을 찾는다.**

---

## ➕ 전진선택법 Forward Selection

아무 변수도 없는 상태에서 시작해.

$$
\varnothing
$$

가장 유용한 변수 하나를 추가하고,

$$
X_1
$$

다음으로 성능을 가장 많이 개선하는 변수를 추가해.

$$
X_1+X_3
$$

이 과정을 반복한다.

즉,

**0개 → 1개 → 2개 → 3개 → …**

방향이야.

### 기억

> **전진 = 없는 상태에서 하나씩 넣는다.**

---

## ➖ 후진제거법 Backward Elimination

반대로 모든 변수를 포함한 상태에서 시작해.

$$
X_1+X_2+X_3+X_4
$$

가장 불필요한 변수를 하나씩 제거한다.

$$
X_1+X_2+X_3
$$

$$
X_1+X_3
$$

### 기억

> **후진 = 전부 넣고 하나씩 뺀다.**

---

## 🔄 단계적 선택법 Stepwise Selection

전진선택과 후진제거를 결합한 방식이야.

변수를 하나 추가한 다음,

> “잠깐, 전에 넣었던 변수 중 이제 필요 없어진 건 없나?”

를 다시 검사할 수 있어.

즉 **추가와 제거를 반복적으로 검토**한다는 점이 핵심이야.

| 방법     | 시작    | 움직임      |
| ------ | ----- | -------- |
| 전진선택   | 변수 없음 | 하나씩 추가   |
| 후진제거   | 모든 변수 | 하나씩 제거   |
| 단계적 선택 | 일부 변수 | 추가·제거 반복 |

이 세 개는 필기에서 이름과 방향을 바로 연결할 수 있어야 해.

---

### 3. Embedded Method — 임베디드 방법

모델을 학습하는 과정 자체에 변수 선택 기능이 들어 있어.

대표적으로:

* LASSO 회귀
* 의사결정나무 기반 변수 중요도

가 있어.

특히 **LASSO = L1 규제**를 기억해야 해.

LASSO는 일부 회귀계수를 정확히 0으로 만들 수 있어.

$$
\beta_j = 0
$$

계수가 0이면 해당 변수는 모델에서 사실상 제외되는 셈이지.

그래서 LASSO는 **규제와 변수 선택을 동시에 수행할 수 있다.**

### 시험 함정

**Ridge 회귀(L2)**도 계수를 줄이지만 일반적으로 계수를 정확히 0으로 만들지는 않아.

따라서 변수 선택과 더 직접적으로 연결되는 것은:

> **LASSO → L1 → 계수 0 가능 → 변수 선택**

이야.

---

## 🗂️ 세 방법을 한 번에 정리

| 방법       | 변수 평가 시점 | 모델 의존성 | 계산량 | 대표 방법       |
| -------- | -------- | -----: | --: | ----------- |
| Filter   | 학습 전     |     낮음 |  낮음 | 상관분석, 카이제곱  |
| Wrapper  | 모델 반복 학습 |     높음 |  높음 | 전진·후진·RFE   |
| Embedded | 모델 학습 중  |     높음 |  중간 | LASSO, Tree |

암기할 때는:

**Filter → 밖에서 거름**
**Wrapper → 모델을 감싸고 반복**
**Embedded → 모델 안에서 선택**

으로 연결하면 돼.

# 📦 차원축소 Dimensionality Reduction

## 🔄 변수 선택과 무엇이 다른가?

여기서 가장 중요한 차이를 다시 보자.

원래 변수가

$$
X_1,\ X_2,\ X_3
$$

라고 하자.

변수 선택은:

$$
X_1,\ X_3
$$

처럼 원래 변수 일부를 남긴다.

하지만 차원축소는:

$$
Z_1,\ Z_2
$$

처럼 **새로운 변수**를 만들어낸다.

예를 들어

$$
Z_1=0.7X_1+0.4X_2+0.6X_3
$$

일 수도 있어.

그래서 원래 변수의 정보를 보존하면서 변수 개수를 줄일 수 있지만, `Z₁이 현실적으로 정확히 무엇을 의미하는가?`는 설명하기 어려워질 수 있어.

> **변수 선택은 해석력을 보존하기 쉽고, 차원축소는 정보 압축 능력이 강하다.**

---

# 📐 주성분분석 PCA

빅데이터분석기사에서 차원축소와 연결하면 가장 먼저 떠올려야 하는 방법이 **PCA(Principal Component Analysis, 주성분분석)**야.

## 🌐 PCA가 해결하려는 문제

두 변수 \(X_1\), \(X_2\)가 매우 높은 상관관계를 가진다고 해보자.

둘이 거의 같은 정보를 담고 있다면 두 변수를 그대로 사용할 필요가 없을 수도 있어.

PCA는 이 정보를 새로운 축으로 바꿔.

$$
X_1,\ X_2
$$

↓

$$
PC_1,\ PC_2
$$

여기서 **PC는 Principal Component, 주성분**이야.

---

## 🧭 PCA의 핵심 원리

PCA는 데이터가 가장 많이 퍼져 있는 방향을 찾아.

그 방향이 **제1주성분 \(PC_1\)**이야.

그다음 \(PC_1\)과 직교하면서 남은 데이터의 분산을 가장 많이 설명하는 방향을 찾는다.

그게 **제2주성분 \(PC_2\)**야.

따라서:

$$
PC_1 \rightarrow \text{가장 큰 분산}
$$

$$
PC_2 \rightarrow \text{두 번째로 큰 분산}
$$

$$
PC_3 \rightarrow \text{세 번째로 큰 분산}
$$

순서가 된다.

### 핵심

> **PCA는 데이터의 분산을 최대한 보존하면서 차원을 줄이는 방법이다.**

---

## 🧮 주성분은 기존 변수의 선형결합

예를 들어

$$
PC_1
=
a_1X_1+a_2X_2+a_3X_3
$$

와 같이 만들어질 수 있어.

\(a_1,a_2,a_3\)는 각 변수가 주성분에 기여하는 정도를 나타낸다.

그래서 PCA 결과의 주성분은 원래 변수 중 하나가 아니야.

이 점이 변수 선택과 결정적으로 다르다.

---

## 📊 PCA에서 고유값과 고유벡터

필기에서 자주 연결되는 개념이야.

PCA에서는 데이터의 공분산 행렬 또는 상관행렬을 이용하고, 여기서 **고유값(eigenvalue)**과 **고유벡터(eigenvector)**를 구해.

직관적으로 보면:

* **고유벡터** → 새로운 축의 **방향**
* **고유값** → 해당 축이 설명하는 **분산의 크기**

라고 생각하면 돼.

따라서 고유값이 큰 주성분일수록 더 많은 정보, 즉 더 큰 분산을 설명한다.

---

## 📈 설명된 분산 Explained Variance

PCA에서는 몇 개의 주성분을 남길지 결정해야 하지.

예를 들어:

| 주성분 | 설명 분산 비율 |
| --- | -------: |
| PC1 |      55% |
| PC2 |      30% |
| PC3 |      10% |
| PC4 |       5% |

PC1과 PC2만 사용하면

$$
55\%+30\%=85\%
$$

의 분산을 설명해.

원래 4차원 데이터를 2차원으로 줄이면서 정보의 약 85%를 유지하는 셈이지.

그래서 **누적 설명 분산 비율**을 보고 주성분 개수를 결정할 수 있어.

---

## ⚖️ PCA 전에 표준화가 중요한 이유

이건 시험 함정으로 상당히 중요해.

예를 들어 두 변수가 있다고 해보자.

* 키: 150~190 cm
* 연봉: 30,000,000~100,000,000원

PCA는 분산이 큰 방향을 중요하게 보는데, 단위 때문에 연봉의 수치가 압도적으로 크다.

그러면 실제 중요도와 관계없이 연봉이 PCA를 지배할 수 있어.

따라서 변수의 단위나 스케일이 크게 다르면 일반적으로 먼저 표준화한다.

$$
Z=\frac{X-\mu}{\sigma}
$$

즉:

> **PCA + 서로 다른 척도 → 표준화 고려**

가 기본 연결이야.

---

## 🧠 PCA의 성질

PCA의 특징을 한 번에 묶으면:

* 비지도 학습 방식의 차원축소
* 종속변수 \(Y\)를 사용하지 않음
* 기존 변수들의 선형결합으로 새로운 주성분 생성
* 제1주성분이 가장 큰 분산을 설명
* 주성분끼리는 서로 직교
* 상위 몇 개의 주성분만 사용해 차원 감소
* 다중공선성 완화에 도움
* 데이터 시각화에도 활용 가능

여기서 특히 중요한 게:

> **PCA는 목표변수를 잘 예측하는 방향을 찾는 것이 아니라 데이터 자체의 분산이 큰 방향을 찾는다.**

야.

분산이 큰 방향이 반드시 예측에 가장 중요한 방향이라는 뜻은 아니야.

---

# 🧲 LDA — PCA와 비교해서 기억하기

**LDA(Linear Discriminant Analysis, 선형판별분석)**도 차원축소에 사용할 수 있어.

그런데 PCA와 결정적인 차이가 있다.

PCA는 **클래스 정보를 보지 않아.**

반면 LDA는 클래스 정보를 사용해서 서로 다른 클래스가 최대한 잘 구분되는 방향을 찾는다.

### 직관

PCA:

> “데이터가 가장 많이 퍼지는 방향이 어디지?”

LDA:

> “A반과 B반을 가장 잘 갈라놓는 방향이 어디지?”

따라서:

| PCA          | LDA        |
| ------------ | ---------- |
| 비지도          | 지도         |
| 목표변수 사용 X    | 클래스 정보 사용  |
| 분산 최대화       | 클래스 분리 최대화 |
| 데이터 구조 보존 중심 | 분류 성능 중심   |

LDA에서는 일반적으로

* 클래스 내부 분산은 작게
* 클래스 간 분산은 크게

만드는 방향을 찾는다.

또 클래스 수가 \(C\)개라면 LDA로 얻을 수 있는 판별축 수는 최대

$$
C-1
$$

이라는 것도 알아두면 좋아.

---

# 🧱 SVD — 행렬을 분해해서 압축하기

**SVD(Singular Value Decomposition, 특이값 분해)**도 차원축소와 자주 연결돼.

행렬 \(X\)를

$$
X=U\Sigma V^T
$$

처럼 분해한다.

여기서 큰 특이값에 해당하는 성분만 남기면 원래 행렬의 주요 정보를 유지하면서 차원을 줄일 수 있어.

SVD는 특히:

* 고차원 행렬 압축
* 추천 시스템
* 텍스트 분석
* 잠재 의미 분석

등과 연결된다.

필기에서는 세부 계산보다는

> **SVD = 행렬 분해 → 중요한 성분만 남겨 저차원 근사**

라는 구조를 기억하면 돼.

---

# 🧠 PCA와 SVD는 어떤 관계인가?

둘은 완전히 별개의 세계가 아니야.

PCA를 계산하는 방법 중 하나로 SVD를 사용할 수 있어.

즉:

* PCA → 통계적으로 **어떤 축을 찾을 것인가**
* SVD → 행렬을 **어떻게 분해할 것인가**

라는 관점 차이가 있어.

시험에서는 둘을 같은 용어로 취급하면 안 되지만, 서로 밀접하게 연결된다는 정도를 알아두면 충분해.

---

# 🔬 요인분석과 PCA도 구별하자

둘 다 여러 변수를 더 적은 차원으로 설명한다는 점 때문에 헷갈릴 수 있어.

하지만 목적이 달라.

### PCA

관측된 여러 변수의 정보를 최대한 적은 주성분으로 **압축**하려는 목적.

### 요인분석 Factor Analysis

여러 관측변수 뒤에 숨어 있는 **잠재적인 공통 요인**을 찾는 데 초점을 둔다.

예를 들면:

* 수학 성적
* 과학 성적
* 논리 시험 점수

뒤에 `논리적 사고력`이라는 잠재 요인이 있다고 보는 식이지.

따라서 시험에서는:

> **PCA = 정보 압축**
> **요인분석 = 잠재요인 발견**

으로 먼저 구별하면 좋아.

---

# ⚔️ 변수 선택 vs PCA

이 비교는 직접 물어도 이상하지 않을 정도로 중요해.

| 기준         | 변수 선택                   | PCA      |
| ---------- | ----------------------- | -------- |
| 차원 감소      | O                       | O        |
| 기존 변수 유지   | O                       | X        |
| 새로운 변수 생성  | X                       | O        |
| 해석 용이성     | 높음                      | 상대적으로 낮음 |
| 변수 간 상관 문제 | 일부 완화                   | 매우 유용    |
| 정보 압축      | 제한적                     | 강함       |
| 대표 방식      | Filter/Wrapper/Embedded | 주성분분석    |

예를 들어 의료 데이터에서

* 나이
* 체중
* 혈압

이라는 변수 이름 자체의 해석이 중요하다면 변수 선택이 유리할 수 있어.

반면 센서 데이터처럼 변수 수가 수백·수천 개이고 변수끼리 높은 상관관계를 가진다면 PCA 같은 차원축소가 효과적일 수 있어.

---

# 🚨 필기에서 잘 낚이는 지점

## 1. PCA는 변수를 선택한다?

아니야.

PCA는 기존 변수 중 일부를 선택하는 게 아니라 **기존 변수들의 선형결합으로 새로운 변수인 주성분을 만든다.**

---

## 2. PCA의 제1주성분은 목표변수를 가장 잘 예측한다?

아니야.

제1주성분은 **데이터의 분산을 가장 크게 설명**하는 축이야.

PCA는 기본적으로 목표변수를 사용하지 않는다.

---

## 3. LASSO는 차원축소인가?

넓은 의미로 변수 수를 줄이는 효과가 있지만, 시험 분류에서는 보통 **변수 선택 방법**으로 본다.

일부 계수를 0으로 만들어 기존 변수 일부를 제거하기 때문이야.

---

## 4. Ridge도 변수 선택을 한다?

L2 규제는 계수의 크기를 줄이는 데 강하지만 일반적으로 정확히 0으로 만들지는 않아.

직접적인 변수 선택과 더 강하게 연결되는 건 **LASSO의 L1 규제**야.

---

## 5. PCA를 하면 항상 표준화해야 하나?

무조건이라고 단정하면 위험해.

다만 **변수들의 단위나 척도가 크게 다르면 표준화가 매우 중요하다.**

시험에서는 보통 이 상황을 전제로 표준화 필요성을 묻는다.

---

# 🧠 시험용 연결망

이 단원을 다음처럼 머릿속에서 연결해 두면 좋아.

```text
변수가 너무 많다
│
├─ 기존 변수 자체를 남기고 싶다
│   ↓
│  변수 선택
│   ├─ Filter
│   ├─ Wrapper
│   │   ├─ 전진선택
│   │   ├─ 후진제거
│   │   └─ 단계적 선택
│   └─ Embedded
│       └─ LASSO(L1)
│
└─ 정보를 새로운 축으로 압축해도 된다
    ↓
   차원축소
    ├─ PCA
    │   ├─ 분산 최대화
    │   ├─ 비지도
    │   ├─ 고유값/고유벡터
    │   └─ 설명된 분산
    ├─ LDA
    │   └─ 클래스 분리 최대화
    └─ SVD
        └─ 행렬 분해 및 저차원 근사
```

---

# 🪄 최소 암기 세트

시험 직전에 정말 최소한만 남긴다면 이 여섯 줄이야.

**① 변수 선택**
기존 변수 중 필요한 변수만 남긴다.

**② Filter / Wrapper / Embedded**
학습 전 / 모델 반복 / 모델 내부.

**③ LASSO**
L1 규제 → 일부 계수 0 → 변수 선택 가능.

**④ PCA**
비지도 차원축소 → 분산 최대화 → 새로운 주성분 생성.

**⑤ LDA**
지도 방식 → 클래스 간 분리 최대화.

**⑥ PCA 표준화**
변수 척도가 다르면 표준화를 고려한다.

## 🧭 최종적으로 구분해야 하는 사고

문제에서 **“차원을 줄인다”**라는 표현만 보고 PCA부터 고르면 안 돼.

먼저 이렇게 판별해.

### 기존 변수 일부가 그대로 남는가?

그렇다면 **변수 선택** 가능성이 높아.

### 기존 변수의 선형결합으로 새로운 축을 만드는가?

그러면 **차원축소**, 특히 PCA를 생각해.

### 모델을 여러 번 돌리며 최적 변수 집합을 찾는가?

**Wrapper.**

### 모델 학습 과정에서 자동으로 변수가 선택되는가?

**Embedded.**

### 목표변수를 사용하지 않고 분산을 최대화하는가?

**PCA.**

### 클래스 간 구분을 최대화하는가?

**LDA.**

이 정도까지 구분되면 이 단원에서 단순 암기보다 한 단계 안정적으로 풀 수 있어.
