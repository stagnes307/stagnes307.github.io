파생변수 생성 = 기존 변수들을 이용해 새로운 의미의 변수를 만든다.

변수 변환 = 기존 변수가 가진 의미는 대체로 유지하면서 값의 형태·척도·분포를 바꾼다.

즉, 새로운 정보를 조합해서 만든 것이냐, 아니면 원래 변수를 분석하기 좋은 모습으로 바꾼 것이냐가 첫 번째 판단 기준이야.

🏗️ 파생변수 생성 — 기존 데이터에서 새로운 정보를 만든다

파생변수는 왜 만들까?

원래 변수만으로는 분석하려는 현상을 충분히 설명하지 못할 때가 있어. 예를 들어 키와 몸무게를 각각 보는 것보다 BMI를 만들면 체격과 관련된 하나의 새로운 정보를 얻을 수 있지.

BMI = 몸무게(kg) ÷ 키(m)2

파생변수는 이렇게 기존 변수에 숨어 있던 관계를 드러내서 분석력과 설명력을 높이는 데 사용해.

대표적인 생성 방식

산술 연산으로 만들기

원래 변수 파생변수
판매수량, 단가매출액 = 판매수량 × 단가
총구매금액, 방문횟수객단가 = 총구매금액 ÷ 방문횟수
수입, 지출잔액 = 수입 − 지출
불량수량, 생산수량불량률 = 불량수량 ÷ 생산수량

특히 비율, 차이, 합계, 평균 형태가 자주 등장해.

날짜·시간 정보에서 만들기

2026-08-26 15:00이라는 주문시간에서도 주문 월, 요일, 시간대, 주말 여부, 가입 후 경과일 같은 변수를 만들 수 있어. 실제 분석에서는 특히 시간의 경과량이 중요한 파생변수가 되는 경우가 많아.

집계해서 만들기

고객별 거래 데이터에서 최근 1개월 구매횟수, 고객별 평균 구매금액, 최대 구매금액, 최근 구매 이후 경과일 등을 만들 수 있어. 거래 하나하나에는 없었던 고객 수준의 특성이 새롭게 생긴 거야.

파생변수가 좋은 이유만 있는 건 아니야

다중공선성

원래 변수와 파생변수가 지나치게 비슷한 정보를 가지면 서로 강하게 상관될 수 있어.

데이터 누수

예측 시점에 알 수 없는 미래 정보를 이용해 파생변수를 만들면 모델 성능이 실제보다 좋아 보일 수 있어.

🔄 변수 변환 — 같은 변수를 분석하기 좋은 모습으로 바꾼다

파생변수가 새로운 특성 생성이라면, 변수 변환은 원래 변수의 값을 다른 형태로 표현하는 작업이야. 단위가 지나치게 다르거나, 분포가 심하게 치우쳐 있거나, 이상치의 영향이 너무 크거나, 특정 분석기법의 가정을 만족시키기 어려운 경우에 사용해.

SHAPE

📉 로그·제곱근

큰 값을 압축하고 치우친 분포를 완화하는 데 사용해.

SCALE

📏 표준화

평균 0, 표준편차 1의 공통 척도로 바꿔.

RANGE

📐 정규화

대표적으로 Min-Max를 이용해 값을 0~1 범위로 맞춰.

📉 로그·제곱근 변환 — 치우친 분포를 완화한다

로그 변환

X′ = log X

소득, 매출액, 거래금액처럼 큰 값 몇 개가 매우 크게 나타나는 오른쪽 꼬리가 긴 분포에 자주 사용해. 로그를 취하면 큰 차이가 압축되기 때문에 양의 왜도 완화, 큰 값의 영향 감소, 분산 안정화에 도움을 줄 수 있어.

변환 전
10 → 100 → 10,000
로그 변환 후
값의 간격이 상대적으로 압축됨

중요한 주의점

일반적인 로그 변환은 0이나 음수에 바로 적용할 수 없다. 그래서 데이터 상황에 따라 log(1+x) 같은 방법이 사용되기도 해.

제곱근 변환

X′ = √X

로그 변환보다 상대적으로 완만하게 큰 값을 압축해. 특히 횟수나 빈도 데이터에 사용할 수 있어.

역수 변환

X′ = 1/X

큰 값을 강하게 압축하지만 원래 변수와의 관계 방향까지 달라질 수 있어서 해석에 주의해야 해.

📏 표준화 — 평균 0, 표준편차 1

Z = (X − μ) / σ
X: 원래 값 · μ: 평균 · σ: 표준편차

표준화된 변수는 평균 0, 표준편차 1이 돼. 키가 cm 단위이고 연봉이 원 단위처럼 숫자의 크기가 완전히 다를 때, 각각을 평균으로부터 몇 표준편차 떨어져 있는가라는 공통 기준으로 비교할 수 있어.

시험 암기 포인트: 표준화 = Z-score = 평균 0, 표준편차 1

📐 정규화 — 일정 범위로 값을 맞춘다

X′ = (X − Xmin) / (Xmax − Xmin)
보통 0 ≤ X′ ≤ 1

최소값이 10, 최대값이 30이고 어떤 값이 20이라면 (20−10)/(30−10)=0.5가 돼.

표준화와 정규화의 차이

구분 표준화 Min-Max 정규화
대표식(X−μ)/σ(X−Xmin)/(Xmax−Xmin)
기준평균·표준편차최소·최대
결과평균 0, 표준편차 1보통 0~1
값의 범위제한 없음특정 범위
이상치 영향존재특히 크게 받을 수 있음
함정: “표준화하면 값이 0~1이 된다”는 설명은 틀려. 0~1은 보통 Min-Max 정규화라고 기억하면 돼.

🪜 구간화 — 연속형 값을 범주형으로 바꾼다

연속형 변수의 값을 여러 구간으로 나누는 것을 구간화(binning) 또는 이산화(discretization)라고 해.

27 → 20대 48 → 40대

동일 간격 방식

전체 범위를 동일한 폭으로 나눠.

동일 빈도 방식

각 구간에 들어가는 데이터 개수가 비슷하도록 나눠.

구간화를 하면 해석은 쉬워질 수 있지만 원래 숫자가 가진 세밀한 정보 일부를 잃는다.

🔤 범주형 변수 변환도 함께 알아두자

문자 형태의 범주는 많은 분석 알고리즘이 그대로 사용하기 어려워. 예를 들어 지역 = 서울 / 부산 / 대전은 더미변수 또는 원-핫 인코딩으로 바꿀 수 있어.

지역 서울 부산 대전
서울100
부산010
대전001

서울=1, 부산=2, 대전=3처럼 숫자만 부여하면 크기 순서가 있는 것처럼 오해될 수 있어. 명목형 범주에는 실제 서열이 없기 때문이야. 반대로 낮음 < 보통 < 높음처럼 본래 순서가 있는 순서형 변수라면 그 순서를 고려한 변환이 가능해.

“새로운 열이 만들어졌다 = 무조건 파생변수”는 위험하다

변수 변환 결과를 새 열에 저장할 수도 있어. income_log = log(income)이라는 새 열이 생겨도 개념적으로 핵심은 열의 개수보다 변환의 의미야.

스케일 변환이 특히 중요한 분석법

KNN K-means PCA SVM

거리나 분산의 크기에 영향을 많이 받는 알고리즘에서는 변수의 척도를 맞추는 게 중요해. 반대로 의사결정나무 계열은 일반적으로 스케일의 영향을 덜 받아.

정규화라는 표현은 문맥을 보자

통계·데이터베이스 등 분야에 따라 normalization의 의미가 달라질 수 있어. 이 단원의 변수 변환 문맥에서는 보통 Min-Max scaling처럼 값의 범위를 조정하는 것으로 이해하면 돼.
