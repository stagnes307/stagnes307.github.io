🔎 1. 불균형 상태 파악

다수 클래스와 소수 클래스

관측치 수가 많은 범주는 다수 클래스(Majority Class), 적은 범주는 소수 클래스(Minority Class)야.

클래스 데이터 수 비율
정상 9,500 95%
이상 500 5%

정확도의 함정

실제 환자가 5명뿐인 100명 데이터에서 전부 정상으로 예측해도 정확도는 95%가 될 수 있어. 그런데 환자는 한 명도 찾지 못했지.

시험 포인트

불균형 데이터에서는 “정확도가 높으므로 분류 성능이 좋다”라고 바로 결론 내리면 안 돼.

혼동행렬부터 읽기

실제 Positive 실제 Negative
예측 Positive TP FP
예측 Negative FN TN
Precision
TP / (TP + FP)

양성이라고 예측한 것 중 실제 양성 비율

Recall
TP / (TP + FN)

실제 양성 중 모델이 찾아낸 비율

F1-score
2 × Precision × Recall / (Precision + Recall)

Precision과 Recall의 조화평균

📈

SMOTE

소수 클래스 이웃 관계를 이용해 합성 표본을 만든다.

핵심: 단순 복제가 아님
⚙️

클래스 가중치

데이터 개수 대신 오류의 비용을 다르게 준다.

핵심: 소수 클래스 오류 비용 ↑

🧬 3. SMOTE는 어떻게 새 데이터를 만들까?

SMOTE는 Synthetic Minority Over-sampling Technique의 약자야. 기존 소수 클래스 관측치를 단순 복제하지 않고, 가까운 소수 클래스 관측치 사이에서 새로운 합성 관측치를 생성해.

A = (2, 2)
B = (4, 4)
Synthetic ≈ (3, 3)

실제로는 특정 소수 샘플과 가까운 이웃을 이용해 합성 표본을 만든다고 이해하면 돼. 단, 원래 데이터에 노이즈나 이상치가 많다면 잘못된 패턴을 확대할 수도 있어.

⚠️ 4. 샘플링 순서의 함정

샘플링은 먼저 훈련 데이터와 테스트 데이터를 나눈 뒤 훈련 데이터에 대해서만 적용하는 게 원칙이야.

전체 데이터
Train / Test 분리
Train에만 SMOTE
모델 학습
원래 Test로 평가
테스트 데이터까지 SMOTE에 사용하면 데이터 누수가 발생할 수 있어. 테스트 세트는 가능한 한 실제 분포를 반영해야 해.

📊 5. 처리 결과 비교

Accuracy
전체 정확도

불균형 데이터에서는 높게 나와도 소수 클래스를 못 잡을 수 있어.

Recall
놓치지 않기

실제 Positive 중 모델이 찾아낸 비율. 질병·사기 탐지처럼 놓치면 큰 문제일 때 중요해.

Precision
거짓 경보 줄이기

Positive라고 예측한 것 중 실제 Positive 비율이야.

F1-score
균형 평가

Precision과 Recall을 함께 고려할 때 유용해.

SMOTE 적용 전후 예시

적용 전
Accuracy97%
Precision80%
Recall30%
F144%
적용 후
Accuracy93%
Precision65%
Recall78%
F171%

Accuracy는 97%에서 93%로 떨어졌지만 Recall과 F1이 크게 올랐지. 소수 클래스 검출이 중요한 문제라면 처리 후 모델이 더 유용할 수 있어.

🧠 6. 시험에서 한 번에 구분하기

방법 핵심 원리 장점 주요 위험

클래스 가중치 오류 비용 변경 데이터 수를 바꾸지 않음 가중치 설정에 따라 결과 변화
Under 버린다 → 정보 손실
