시험에서는 계산 자체보다 통계량의 의미, 이상치에 대한 민감도, 그리고 어떤 상황에서 어떤 지표를 선택하는지가 자주 갈린다.

01 · EXPLORATORY DATA ANALYSIS

🧭 데이터 탐색은 “분석 전에 데이터를 이해하는 과정”이야

데이터를 받자마자 모델부터 돌리면 안 돼. 먼저 이 데이터가 어떤 모양인지, 믿을 만한지, 어떤 특징이 있는지 확인해야 해. 이 과정을 보통 탐색적 데이터 분석, 즉 EDA(Exploratory Data Analysis)라고 해.

데이터 구조 파악

관측치 수, 변수 수, 변수 유형, 값의 범위, 결측 여부를 먼저 본다.

데이터 품질 확인

결측값, 이상값, 중복값, 입력 오류가 있는지 점검한다.

분포 파악

중심과 퍼짐, 치우침을 함께 보면서 숫자의 실제 모습을 읽는다.

변수 관계 탐색

두 변수가 함께 움직이는지 산점도나 상관관계 등으로 살핀다.

변수 값 예시 데이터 유형
나이35수치형
성별남 / 여범주형
구매금액125,000수치형
고객등급Gold / Silver범주형

핵심: 변수 유형에 따라 탐색 방법이 달라져. 수치형 변수에는 평균·표준편차를 쓸 수 있지만, 성별 같은 명목형 변수의 평균은 의미가 없어.

이상치는 “보이면 제거”가 아니야

사람의 나이가 21, 34, 42, 999, 28이라면 999는 입력 오류일 가능성을 의심할 수 있어. 하지만 이상치가 있다고 해서 무조건 제거하지는 않아. 왜 그 값이 발생했는지 먼저 판단해야 해.

03 · CENTRAL TENDENCY

🎯 대표값 — 데이터의 중심은 어디인가

평균 Mean

x̄ = Σxᵢ / n

모든 값을 계산에 사용하므로 데이터 전체를 반영한다. 하지만 이 장점 때문에 극단값에도 크게 흔들린다.

예: 200, 220, 230, 250, 5000 → 대부분은 200대지만 5000이 평균을 크게 끌어올린다.

중앙값 Median

데이터를 크기순으로 정렬했을 때 가운데에 위치한 값이야. 10, 20, 30, 40, 1000의 중앙값은 30이야. 1000 같은 극단값이 있어도 위치 자체는 크게 변하지 않아.

→ 이상치가 많거나 분포가 심하게 치우친 경우 평균보다 중앙값이 더 적절할 수 있다.

최빈값 Mode

가장 자주 나타나는 값이야. 중요한 특징은 범주형 자료에도 사용할 수 있다는 것. 카드, 현금, 카드, 카드, 계좌이체라면 최빈값은 카드야.

통계량 의미 이상치 영향 범주형 사용
평균산술적 중심큼X
중앙값위치적 중심작음보통 X
최빈값가장 빈번한 값작음O

04 · DISPERSION

📏 산포도 — 데이터가 얼마나 퍼져 있는가

대표값만 보면 부족해. 예를 들어 48, 49, 50, 51, 52와 10, 30, 50, 70, 90의 평균은 모두 50이지만, 두 번째 데이터가 훨씬 넓게 퍼져 있어.

같은 평균, 다른 퍼짐

범위 Range

Range = max − min

계산은 가장 쉽지만 최솟값과 최댓값 두 개에 의존하므로 이상치에 매우 민감하다.

분산 Variance

σ² = Σ(xᵢ − μ)² / N

평균에서 떨어진 정도를 제곱해서 평균낸 값. 표본분산은 보통 n−1로 나눈다.

표준편차 Standard Deviation

s = √s²

분산에 제곱근을 취한다. 원래 자료와 같은 단위를 가지므로 해석이 쉽다.

시험 연결: 모집단 분산은 보통 N, 표본분산은 모집단 분산을 추정할 때 n−1로 나누는 형태를 기억해.

05 · QUARTILES

📦 사분위수와 IQR — 이상치에 덜 흔들리는 산포

IQR은 데이터의 가운데 50% 폭이야. 최솟값과 최댓값을 직접 쓰지 않기 때문에 범위보다 이상치의 영향을 덜 받아.

하한 이상치 기준

Q1 − 1.5 × IQR

상한 이상치 기준

Q3 + 1.5 × IQR

이 기준은 박스플롯에서 잠재적 이상치를 표시할 때 널리 사용돼.

06 · DISTRIBUTION SHAPE

↗️ 왜도 — 어느 방향으로 치우쳤는가

음의 왜도

왼쪽 꼬리가 길다.

평균 < 중앙값 < 최빈값 경향

대칭 분포

좌우가 대체로 대칭.

평균 ≈ 중앙값 ≈ 최빈값

양의 왜도

오른쪽 꼬리가 길다.

최빈값 < 중앙값 < 평균 경향

양의 왜도에서는 큰 값 몇 개가 평균을 오른쪽으로 끌어당기는 경우가 많아. 다만 이 순서는 전형적인 형태를 설명하는 관계이지 모든 분포에서 반드시 성립하는 절대법칙은 아니야.

07 · KURTOSIS

🏔️ 첨도 — 꼬리와 극단값 성향을 본다

첨도는 흔히 “분포가 얼마나 뾰족한가”라고 외우지만, 조금 더 정확하게는 분포의 꼬리와 극단적인 관측값이 나타나는 성향을 이해하는 지표야.

프로그램에 따라 정규분포의 첨도를 3으로 표시하기도 하고, 정규분포를 0으로 맞춘 초과첨도(excess kurtosis)를 사용하기도 해.

08 · CHOICE OF SUMMARY

🧠 평균과 중앙값을 선택하는 기준

SYMMETRIC

대칭적이고 이상치가 적다

평균 + 표준편차

전체 값의 정보를 적극적으로 활용할 수 있어.

SKEWED / OUTLIERS

비대칭적이거나 이상치가 많다

중앙값 + IQR

극단값 때문에 대표값이 왜곡되는 것을 줄일 수 있어.

예를 들어 연봉이 3천, 3천, 4천, 4천, 20억이라면 평균은 일반적인 직원을 잘 나타내지 못해. 중앙값이 훨씬 안정적인 대표값이 돼.

큰 관측값들이 평균을 오른쪽으로 끌어올렸을 가능성을 의심할 수 있다.

단서 2 · 최댓값 180

Q3 = 68과 크게 떨어져 있으므로 큰 값 쪽 이상치 가능성을 확인한다.

단서 3 · IQR 기준 계산

IQR = 68 − 43 = 25

상한 = 68 + 1.5 × 25 = 105.5

180은 이 기준에서는 잠재적인 이상치가 된다.

11 · EXAM FAULT LINES

⚠️ 필기에서 자주 헷갈리는 경계선

평균 vs 중앙값

평균은 이상치에 민감, 중앙값은 상대적으로 강하다.

분산 vs 표준편차

분산은 편차 제곱을 이용, 표준편차는 분산의 제곱근이며 원자료와 같은 단위를 갖는다.

범위 vs IQR

범위는 극단값을 직접 사용, IQR은 중앙 50%를 이용한다.

상관 vs 인과

두 변수가 함께 움직인다고 해서 인과관계가 증명되는 것은 아니다.

FINAL MEMORY FRAME

🎓 시험 직전 기억할 8개

  1. 1. EDA → 구조, 품질, 분포, 관계를 탐색한다.
  2. 2. 평균 → 모든 값을 사용하지만 이상치에 민감하다.
  3. 3. 중앙값 → 이상치와 비대칭 분포에 상대적으로 강하다.
  4. 4. 최빈값 → 범주형 자료에도 사용할 수 있다.
  5. 5. 분산 → 평균에서의 편차를 제곱해 산포를 나타낸다.
  6. 6. 표준편차 → 분산의 제곱근이며 원자료와 같은 단위다.
  7. 7. IQR = Q3 − Q1 → 데이터 중앙 50%의 범위다.
  8. 8. 평균·중앙값 차이, 왜도, 이상치를 함께 해석한다.
