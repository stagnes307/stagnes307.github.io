다변량 탐색은 변수 하나씩 보는 기술이 아니라, 여러 변수가 함께 만드는 관계의 구조를 읽는 기술이야.

MULTIVARIATE FIELD 관계 → 구조 → 해석

한 변수의 값보다, 변수들이 어떻게 연결되어 움직이는가가 중심이야.

01 · 핵심 관점

🎯 다변량 탐색은 “관계의 구조”를 본다

키, 몸무게, 운동시간, 체지방률이라는 변수가 있다고 해보자.

평균 키, 몸무게 분포, 운동시간의 이상치를 각각 따로 보는 건 일변량 탐색(univariate exploration)에 가까워.

하지만 실제 데이터에서는 이런 질문이 더 중요하지.

키가 큰 사람이 몸무게도 높은가?

운동시간이 늘어나면 체지방률은 낮아지는가?

몸무게와 체지방률이 비슷한 정보를 반복해서 담고 있지는 않은가?

이렇게 여러 변수 사이의 관계와 전체 패턴을 동시에 살피는 것이 다변량 데이터 탐색이야.

①

다변량 구조 파악

전체 데이터가 어떤 모양과 차원을 갖는지 본다.

②

변수 간 관계 확인

어떤 변수들이 함께 또는 반대로 움직이는지 본다.

③

관계 해석

발견한 패턴이 실제로 무엇을 의미하는지 판단한다.

02 · 다변량 구조

🧱 데이터 전체는 어떤 모양인가?

고객 나이 소득 구매금액 방문횟수
A2530001205
B4255002808
C3142001906

행(row)은 하나의 관측대상, 열(column)은 변수야.

한 고객은 단순히 “나이 25”인 사람이 아니라 (나이 25, 소득 3000, 구매금액 120, 방문횟수 5)라는 여러 변수의 조합으로 표현돼.

다변량 탐색에서 찾는 세 구조

  • • 변수 간 연관 구조
  • • 관측값의 군집 구조
  • • 차원의 구조

예를 들어 키·체중·허리둘레·BMI처럼 서로 강하게 연결된 변수들이 있다면, 여러 변수가 사실 몇 개의 공통된 특성으로 요약될 수도 있어.

이 사고가 뒤의 주성분분석(PCA), 요인분석, 군집분석 같은 다변량 분석으로 이어져.

구조를 보는 대표적인 도구

도구 무엇을 보는가
산점도두 연속형 변수 관계
산점도 행렬여러 연속형 변수의 쌍별 관계
공분산 행렬변수들이 함께 변하는 정도
상관행렬변수 간 선형관계의 방향과 강도
상관 히트맵상관행렬을 시각적으로 표현
평행좌표그래프여러 변수 값을 동시에 비교
PCA 등 차원축소고차원 데이터의 핵심 구조 요약

시험에서는 특히 공분산·상관계수·상관행렬을 연결해서 이해해야 해.

03 · 변수 간 관계

🔗 “같이 움직인다”를 어떻게 측정할까?

Covariance

공분산 — 방향을 먼저 본다

두 변수 X와 Y가 있을 때 공분산은 “X가 평균보다 커질 때 Y도 평균보다 커지는 경향이 있는가?”를 보는 값이야.

> 0
같은 방향
< 0
반대 방향
≈ 0
선형 동조 약함

단, 공분산은 측정 단위와 스케일의 영향을 받는다.

Correlation

상관계수 — 방향 + 강도를 표준화한다

피어슨 상관계수 r은 -1에서 +1 사이의 값을 가져.

-1
+1

r ≈ +1 · 강한 양의 선형관계

r ≈ 0 · 선형관계가 약함

r ≈ -1 · 강한 음의 선형관계

여기서 핵심은 선형관계야. 상관계수가 0이라고 해서 반드시 아무 관계도 없다는 뜻은 아니야.

산점도 행렬 — 여러 관계를 한꺼번에 본다

변수가 나이, 소득, 구매금액, 방문횟수처럼 여러 개라면 산점도 행렬은 변수들을 쌍별로 조합해 관계의 모양을 보여줘.

강한 양의 관계
강한 음의 관계
비선형 관계
이상치
군집
변수 간 중복성

상관행렬은 관계를 숫자로 요약하고, 산점도 행렬은 관계의 모양을 보여준다.

04 · 변수 유형

🧩 변수의 종류가 달라지면 관계를 보는 방법도 달라진다

연속형 ↔ 연속형

소득 ↔ 구매금액

산점도 · 공분산 · 상관계수

범주형 ↔ 범주형

성별 ↔ 상품선호
지역 ↔ 구매여부

교차표 · 빈도 · 비율 · 카이제곱 기반 관계 분석

범주형 ↔ 연속형

고객등급 ↔ 구매금액

평균 · 중앙값 · 분산 · 상자그림
“변수가 몇 개인가?”보다
“각 변수의 유형이 무엇이고, 어떤 관계를 확인하려는가?”가 더 중요해.

05 · 제3의 변수

🔥 변수 세 개가 등장하면 해석이 바뀔 수 있다

아이스크림 판매량과 익사 사고에 양의 상관관계가 보인다고 해보자.

그렇다고 아이스크림이 익사 사고를 발생시킨다고 결론 내리면 안 돼.

두 변수 모두 기온이라는 제3의 변수의 영향을 받을 수 있어.

상관관계 ≠ 인과관계

06 · 결과 해석

🧠 숫자를 발견하는 것보다 해석이 중요하다

01

상관관계의 방향과 강도를 구분한다

상관계수가 음수라고 해서 관계가 “나쁜 것”은 아니야. 부호는 방향을 의미하고, 절댓값은 대략적인 관계의 강도를 나타내. 예를 들어 r=-0.9는 r=0.2보다 훨씬 강한 선형관계야.

02

상관계수가 크다고 인과관계를 주장하지 않는다

“강한 상관관계가 발견되었다”와 “X가 Y의 원인이다”는 다른 주장이다. 탐색 단계에서는 “두 변수 사이에 강한 연관성이 관찰된다” 정도로 해석하는 것이 안전해.

03

이상치가 관계를 왜곡할 수 있다

멀리 떨어진 관측값 하나 때문에 상관계수가 크게 바뀔 수도 있어. 그래서 상관계수 확인 → 산점도 확인 → 이상치 확인을 함께 생각하는 습관이 좋아.

04

다중공선성도 탐색 단계에서 눈에 띈다

설명변수끼리 지나치게 강한 상관관계를 가지는 상황을 다중공선성(multicollinearity)이라고 해. 키(cm)와 키(m)를 동시에 설명변수로 넣는 것처럼 사실상 같은 정보를 중복해서 쓰는 경우가 대표적이야.

상관행렬에서 설명변수 간 상관이 지나치게 높다면 중복 정보 또는 다중공선성 가능성을 의심할 수 있어.

05

변수의 스케일도 확인한다

어떤 변수는 0~1, 다른 변수는 0~1,000,000 범위를 가질 수 있어. 특히 거리 기반 분석이나 PCA·군집분석으로 넘어가면 이 차이가 크게 작용할 수 있어.

그래서 단위·범위·분산을 살펴보고 필요하면 표준화 또는 정규화를 고려하게 돼.

08 · 시험 함정

⚠️ 시험에서 잘 걸리는 경계선

“상관계수가 0이다 → 두 변수는 독립이다”

항상 성립하지 않아. 상관계수 0은 주로 선형적 관계가 없다는 의미야. 비선형 관계가 있을 수도 있어.

“공분산이 크다 → 두 변수의 관계가 강하다”

그대로 비교하면 위험해. 공분산은 단위와 스케일의 영향을 받기 때문이야.

“상관계수가 높다 → 원인과 결과의 관계다”

아니야. 상관관계는 인과관계의 충분한 증거가 아니다.

“상관계수가 0이면 관계가 없다”

정확하게는 피어슨 상관계수가 0에 가까우면 선형관계가 약하다는 뜻이야. 비선형 관계는 존재할 수 있어.
