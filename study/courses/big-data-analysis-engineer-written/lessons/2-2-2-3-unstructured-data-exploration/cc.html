2-2-2-3. 비정형 데이터 탐색

이 단원의 중심은 용어 암기가 아니라 하나의 변환 과정이야. 구조화되지 않은 원본을 분석 가능한 특징으로 바꾸고, 그 특징에서 반복되는 관계와 의미를 찾는다.

🎯 먼저 잡을 핵심: 왜 바로 분석할 수 없을까?

STRUCTURED

고객번호 / 나이 / 구매금액

정형 데이터는 행과 열의 구조가 미리 정해져 있어서 각 값의 역할을 컴퓨터가 비교적 바로 파악할 수 있어.

UNSTRUCTURED

“배송은 빨랐는데 제품 포장이 너무 별로였어요.”

사람은 배송에는 긍정, 포장에는 부정이라는 의미를 읽지만 컴퓨터에게 처음에는 문자들의 연속일 뿐이야.

비정형 원본→ 전처리→ 특징 추출→ 패턴 탐색→ 의미 해석

🗂️ 1. 비정형 데이터 유형

비정형 데이터는 미리 정의된 데이터 모델이나 일정한 분석용 구조에 맞추기 어려운 데이터야. “아무 구조도 없다”는 뜻은 아니야. 문장에는 문법이 있고 이미지에는 픽셀 배열이 있지만, 관계형 테이블처럼 분석에 바로 사용할 고정 스키마가 사전에 주어져 있지 않다는 의미에 가까워.

유형예탐색하려는 것
텍스트뉴스, SNS, 이메일, 리뷰단어, 주제, 감성, 관계
이미지사진, 의료영상, 위성사진객체, 형태, 색상, 특징
오디오음성, 음악, 녹음음성 내용, 화자, 음향 특징
비디오CCTV, 동영상객체·행동·장면의 변화

정형 · 반정형 · 비정형의 경계

문서, 이미지, 음성, 영상

🧹 2. 탐색 전 처리

전처리는 데이터를 마구 삭제하는 일이 아니라 분석하고 싶은 의미는 보존하면서 잡음을 줄이는 과정이야.

TEXT PIPELINE

원문→정제→토큰화→불용어 제거→정규화→특징 표현

정제 — 잡음을 걷어낸다

특수문자, 불필요한 공백, HTML 태그, 중복 등 분석 목적상 필요 없는 요소를 제거하거나 수정해.

토큰화 — 분석 단위를 만든다

문장이나 문서를 단어·형태소 같은 토큰으로 나눈다. 한국어는 조사와 어미가 결합하기 때문에 형태소 분석이 중요할 수 있어.

불용어 제거 — 정보량이 낮은 표현을 줄인다

단, 무조건 제거하는 건 아니야. 감성 분석에서 안, 못 같은 부정 표현을 없애면 “좋다”와 “안 좋다”의 결정적인 차이를 잃을 수 있어.

정규화 — 같은 의미의 변형을 모은다

어간 추출은 규칙에 따라 어간에 가까운 형태를 얻고, 표제어 추출은 문법·사전 정보를 이용해 기본형을 찾는다. 목적은 같은 개념이 표현 차이 때문에 흩어지는 것을 줄이는 거야.

🔢 3. 텍스트를 숫자로 바꾸기

문자열을 정리했다고 많은 분석 알고리즘이 바로 계산할 수 있는 건 아니야. 그래서 텍스트를 수치적 특징으로 표현한다.

단어 빈도

데이터15회
분석12회
시험3회

TF-IDF

TF는 한 문서 안의 출현 정도, IDF는 여러 문서에 지나치게 흔한 단어의 중요도를 낮추는 역할을 해.

그 문서에서는 자주 나오지만 다른 문서에서는 흔하지 않은 단어를 중요하게 본다.

🔍 4. 패턴 탐색 — 준비된 특징에서 무엇을 발견할까?

질문은 하나야. 데이터 안에 반복적으로 나타나는 의미 있는 규칙이나 관계는 무엇인가?

빈도 분석

어떤 단어가 많이 등장하는지 탐색. 워드 클라우드는 직관적이지만 문맥과 관계 표현에는 한계가 있어.

동시출현 분석

어떤 단어들이 함께 등장하는지 분석. 단어를 노드, 관계를 링크로 표현할 수 있어.

군집화

비슷한 문서나 관측 대상을 유사성에 따라 묶는다.

토픽 모델링

문서 집합에 잠재된 주제를 발견한다. 대표 기법은 LDA.

감성 분석

텍스트의 긍정·부정 등 감성 방향을 분석한다.

CO-OCCURRENCE MAP

단순히 “배송”이 많이 나온다는 사실보다 배송 ↔ 빠르다, 포장 ↔ 파손처럼 함께 등장하는 관계가 더 많은 구조를 보여줄 수 있어.

군집화와 토픽 모델링은 같은가?

군집화

비슷한 관측 대상이나 문서를 묶는 것에 초점.

토픽 모델링

문서 집합 속 잠재 주제 구조를 발견하는 데 초점. LDA에서는 하나의 문서가 여러 주제의 혼합일 수 있어.

⚠️ 6. 헷갈리기 쉬운 지점

XML·JSON은 어디에 속할까?

반정형 데이터. 태그나 키처럼 구조를 알려주는 정보가 있지만 관계형 테이블처럼 고정된 행·열 스키마는 아니야.

불용어는 무조건 제거할까?

아니야. 분석 목적에 따라 결정해야 해. 특히 감성 분석에서는 부정 표현처럼 의미를 결정하는 요소를 보존해야 할 수 있어.

빈도가 높으면 항상 중요한 단어일까?

아니야. 여러 문서에 지나치게 흔한 단어는 문서를 구별하는 힘이 약해. 이 문제를 보완하는 대표 표현이 TF-IDF야.

워드 클라우드는 문맥까지 보여줄까?

아니야. 빈도나 중요도를 빠르게 훑는 데는 유용하지만 단어 사이 관계와 문맥을 충분히 설명하지는 못해.

🧩 7. 쇼핑몰 리뷰 100만 건에 전부 연결하기

원본

자유롭게 작성된 고객 리뷰는 비정형 텍스트 데이터다.

전처리

불필요한 문자와 태그를 정제하고, 단어나 형태소로 토큰화하고, 목적에 따라 불용어를 제거하고 표현을 정규화한다.

특징화

단어 빈도나 TF-IDF 등으로 텍스트를 분석 가능한 특징으로 표현한다.

탐색

배송 ↔ 파손 같은 관계는 동시출현, 비슷한 문의 집단은 군집화, 숨어 있는 주제는 토픽 모델링, 긍정·부정 반응은 감성 분석으로 살펴본다.

구조화되지 않은 원본에서 불필요한 변동을 제거하고 분석 가능한 특징을 만든 뒤, 반복되는 관계와 의미를 발견한다.
