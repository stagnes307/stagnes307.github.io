#빅데이터분석기사 #필기 #비정형데이터 #전처리 #패턴탐색

비정형 데이터는 표의 행·열처럼 미리 정해진 구조가 없는 데이터야. 그래서 이번 단원의 핵심은 복잡한 알고리즘보다 흐름을 먼저 잡는 거야. 원본 데이터를 바로 분석하기 어렵기 때문에 먼저 정제하고, 분석 가능한 표현으로 바꾸고, 그다음 의미 있는 패턴을 찾는다.

비정형 원본 → 전처리 → 분석 가능한 표현 → 패턴 탐색
구조를 먼저 구분하기

🧱 1. 비정형 데이터는 무엇이 다른가?

구분 구조 대표 예
정형 데이터 스키마가 명확함 관계형 DB, 엑셀 표
반정형 데이터 일정한 표 구조는 없지만 태그·키 등 구조 정보가 있음 XML, JSON, HTML
비정형 데이터 고정된 스키마가 없음 텍스트, 이미지, 음성, 동영상

시험에서는 특히 반정형과 비정형을 섞지 않는 게 중요해. JSON과 XML은 구조 정보가 있으므로 일반적으로 반정형 데이터로 본다.

비정형이라는 말은 아무 구조도 존재하지 않는다는 뜻이 아니야. 문장은 단어와 문법 구조를 가지고 있고, 사진도 픽셀의 배열로 저장돼. 다만 관계형 데이터베이스처럼 고객번호 · 나이 · 구매금액처럼 분석할 속성이 처음부터 명확하게 정의돼 있지 않다는 뜻이야. 그래서 분석 목적에 맞게 특징을 추출하거나 변환해야 해.

데이터가 가진 감각의 차이

🗂️ 2. 비정형 데이터 유형

텍스트 데이터

뉴스 기사, SNS 게시글, 이메일, 리뷰, 보고서처럼 자연어로 표현된 데이터야. 대표적인 분석 목적은 단어 출현 빈도, 문서 분류, 감성 분석, 주제 분석, 문서 간 유사도 분석 등이야.

“배송은 빠른데 제품 품질은 아쉽다.”
→ 문장을 그대로 쓰는 것이 아니라 단어와 특징으로 바꿔야 분석할 수 있다.

이미지 데이터

사진, 위성 영상, 의료 영상, CCTV 화면 등이 해당해. 이미지는 픽셀 값들의 집합이지만 분석 목적에 따라 윤곽, 색상, 질감, 형태, 객체의 위치 같은 특징을 다시 뽑는다.

음성·오디오 데이터

사람의 음성, 음악, 기계 소리 등이 대표적이야. 시간에 따라 변하는 신호이므로 잡음 제거, 음성 구간 탐지, 특징 추출, 음성의 텍스트 변환 같은 처리를 할 수 있어.

동영상 데이터

동영상은 이미지의 연속에 시간 정보와 경우에 따라 음성 정보까지 결합돼 있어. 따라서 객체뿐 아니라 움직임, 시간에 따른 변화, 행동, 장면 전환 같은 패턴도 분석 대상이 돼.

🧹 3. 탐색 전 처리

비정형 데이터는 대부분 원본을 바로 분석하기 어렵기 때문에, 먼저 분석 가능한 형태로 정제하고 변환해야 해.

①
불필요한 정보 제거

노이즈나 분석에 도움이 되지 않는 요소를 줄인다.

②
표현 통일

같은 의미가 여러 방식으로 표현되는 문제를 줄인다.

③
특징 추출

분석에 사용할 의미 있는 정보를 드러낸다.

즉, 전처리는 원본 데이터의 의미는 최대한 유지하면서 분석하기 좋은 형태로 바꾸는 과정이라고 보면 돼.

텍스트에서 가장 자주 보는 절차

📝 4. 텍스트 데이터 전처리

토큰화 Tokenization

문장이나 문서를 분석 가능한 작은 단위로 나누는 과정이야. 예를 들어 “빅데이터 분석은 재미있다”를 빅데이터 / 분석 / 재미있다처럼 나눌 수 있어. 이렇게 나뉜 단위를 토큰이라고 해.

불용어 제거 Stop-word Removal

분석에 큰 의미가 없는 단어를 제거하는 과정이야. 영어의 a, the 같은 표현이 대표적인 예지만, 어떤 단어가 불용어인지는 분석 목적에 따라 달라질 수 있어.

정규화 Normalization

표현 방식이 다른 단어들을 일정한 형태로 맞추는 과정이야. 대소문자나 표기상의 차이를 통일하는 작업이 여기에 들어갈 수 있어.

어간 추출과 표제어 추출

비슷한 의미를 가진 변형 단어를 기본적인 형태로 맞추는 처리야. 어간 추출 Stemming은 일정한 규칙을 이용해 어간을 추출하고, 표제어 추출 Lemmatization은 문법적 의미를 고려해 기본형을 찾는 쪽에 가깝다.

시험 경계: stemming은 규칙 중심, lemmatization은 언어적 기본형 중심.
텍스트만 전처리하는 것은 아니다

🖼️ 5. 이미지·음성도 전처리가 필요하다

이미지 전처리의 예

  • 이미지 크기 조정
  • 노이즈 제거
  • 밝기·대비 조정
  • 이미지 정규화
  • 필요한 영역 추출
  • 특징 추출

예를 들어 CCTV에서 자동차 번호판만 분석한다면 화면 전체보다 번호판 영역을 찾아 추출하는 과정이 중요할 수 있어.

음성 데이터 전처리의 예

  • 잡음 제거
  • 신호 정규화
  • 음성 구간 탐지
  • 특징 추출

데이터 종류가 달라져도 원리는 같다. 분석에 방해되는 요소를 줄이고, 의미 있는 특징을 드러내는 것이 전처리의 본질이야.

정제가 끝난 뒤 실제로 찾는 것

🔎 6. 패턴 탐색

전처리가 끝났다고 분석이 끝난 건 아니야. 이제 데이터 안에서 반복되는 구조나 의미 있는 관계를 찾아야 해. 이 단계가 패턴 탐색이야.

텍스트 마이닝 Text Mining

대량의 텍스트에서 유용한 정보와 패턴을 찾는 분석. 단어 빈도, 문서 분류, 군집, 연관 관계, 주제 등을 탐색할 수 있다.

감성 분석 Sentiment Analysis

텍스트에 나타난 긍정·부정 또는 감정적 성향을 분석한다. 상품 리뷰나 SNS 분석에서 자주 활용된다.

토픽 분석 Topic Analysis

여러 문서에서 반복되는 주제나 잠재적인 의미 구조를 찾는다. 많은 문서를 경제, 스포츠, 정치, 기술 같은 주제군으로 이해하는 데 활용할 수 있다.

군집과 분류

분류는 미리 정의된 범주에 데이터를 배정하고, 군집은 데이터의 유사성에 따라 자연스럽게 그룹을 만든다.

가장 중요한 경계

🧠 7. 전처리와 패턴 탐색을 섞지 않는 법

전처리

“분석할 수 있는 상태로 어떻게 만들 것인가?”

  • 토큰화
  • 불용어 제거
  • 정규화
  • 노이즈 제거
  • 특징 추출

“정제된 데이터에서 무엇을 발견할 것인가?”

  • 문서 분류
  • 감성 분석
  • 군집
  • 토픽 분석
  • 유사도 분석
불용어 제거 → 전처리

🎯 8. 시험에서 잡아야 할 핵심 경계

정형 vs 반정형 vs 비정형

JSON이나 XML은 보통 반정형 데이터로 본다. 이미지·음성·자연어 문서는 비정형 데이터의 대표 사례야.

전처리 vs 분석

토큰화와 불용어 제거는 분석 준비 과정이고, 감성 분석이나 토픽 탐색은 의미 있는 패턴을 발견하는 단계에 가깝다.

데이터 형태 vs 저장 방식

이미지가 파일로 규칙적으로 저장되어 있다고 해서 정형 데이터가 되는 건 아니다. 정형 여부는 분석 대상의 스키마가 명확하게 정의되어 있는가를 중심으로 본다.

📌 비정형 데이터 탐색 한 장 정리

비정형 데이터
고정된 스키마가 없는 데이터 → 텍스트·이미지·음성·동영상 등이 대표적

탐색 전 처리
분석 가능한 형태로 정제·변환 → 토큰화, 불용어 제거, 정규화, 노이즈 제거, 특징 추출 등

패턴 탐색
정제된 데이터에서 의미 있는 구조 발견 → 텍스트 마이닝, 감성 분석, 분류, 군집, 토픽 분석 등

“비정형 데이터를 정제해서 특징으로 만들고, 그 특징에서 패턴을 찾는다.”

🧭 네 개의 경계만 안정적으로 잡아도 된다

정형 ↔ 반정형 ↔ 비정형
원본 데이터 ↔ 분석 가능한 표현
전처리 ↔ 패턴 탐색
분류 ↔ 군집

이 네 가지가 잡히면 세부 용어를 따로 외우지 않아도 각 용어가 어느 단계에 놓이는지 훨씬 쉽게 판단할 수 있어.
