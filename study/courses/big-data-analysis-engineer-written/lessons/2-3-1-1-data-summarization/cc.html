📍 1. 중심: 데이터의 대표적인 위치는 어디인가?

예를 들어 다섯 사람의 점수가 60, 70, 70, 80, 90이라고 해보자.

평균 Mean

x̄ = Σxᵢ / n

위 자료에서는

x̄ = (60+70+70+80+90)/5 = 74

평균은 모든 관측값을 반영한다는 장점이 있어. 그런데 바로 그 특징 때문에 극단값에도 영향을 많이 받아.

중앙값 Median

60 · 70 · 70 · 80 · 90

자료를 크기순으로 놓았을 때 가운데 위치한 값이야. 따라서 중앙값은 70.

값의 구체적인 크기보다 순서와 위치가 중요해서 극단값에 비교적 강해. 소득이나 집값처럼 한쪽에 매우 큰 값이 존재할 수 있는 자료에서는 평균보다 중앙값이 대표값으로 더 적절할 수 있어.

최빈값 Mode

가장 자주 나타난 값 → 70

가장 자주 나타난 값이야. 범주형 데이터에도 사용할 수 있다는 점이 중요해.

예를 들어 고객이 가장 많이 선택한 결제수단이 신용카드라면, 숫자가 아니어도 최빈값을 말할 수 있어.

시험에서 구분하기

중심 요약핵심극단값 영향
평균모든 값을 이용큼
중앙값가운데 위치작음
최빈값가장 빈번한 값비교적 무관

이상치가 강한 자료 → 평균만 보고 판단하지 않는다.

📏 2. 산포: 데이터가 얼마나 흩어져 있는가?

두 집단의 평균이 같다고 해서 두 집단의 데이터 특성이 같은 것은 아니야.

A: 49, 50, 50, 50, 51 — 좁게 모임

B: 10, 30, 50, 70, 90 — 넓게 흩어짐

둘 다 중심은 50 근처지만 완전히 다른 데이터지. 이 차이를 보여주는 게 산포야.

범위 Range

범위 = 최댓값 − 최솟값

계산은 매우 쉽지만 최댓값과 최솟값 두 개에 크게 의존하므로 이상치의 영향을 많이 받아.

분산 Variance

각 데이터가 평균으로부터 얼마나 떨어져 있는지를 이용해 산포를 측정해.

σ² = Σ(xᵢ−μ)² / N

s² = Σ(xᵢ−x̄)² / (n−1)

여기서 시험 포인트. 표본분산의 분모는 n−1이야. 또 편차를 그냥 더하지 않고 제곱해서 평균보다 큰 값과 작은 값의 편차가 서로 상쇄되는 문제를 막아.

표준편차 Standard Deviation

s = √s²

분산보다 해석하기 편한 이유가 있어. 원래 데이터가 kg이라면 분산의 단위는 kg²이지만, 표준편차는 다시 kg이 돼. 그래서 원자료와 같은 단위로 산포를 읽을 수 있어.

사분위범위 IQR

IQR = Q₃ − Q₁

즉 가운데 50% 데이터가 차지하는 범위를 보는 거야. 중앙값과 마찬가지로 극단값에 비교적 강하기 때문에 이상치가 존재하거나 분포가 치우친 경우 유용해.

📐 3. 상대적 산포: 단위나 평균이 다르면?

표준편차만 단순 비교하면 곤란한 경우가 있어. 평균이 크게 다른 두 집단의 상대적인 변동성을 비교하고 싶다면 변동계수(CV)를 사용할 수 있어.

CV = s / x̄

필요하면 여기에 100%를 곱해 백분율로 나타내. 핵심은 표준편차를 평균에 대한 상대적인 크기로 바꾼다는 것. 그래서 서로 다른 규모의 자료에서 상대적 산포를 비교할 때 유용해.

📈 4. 분포 형태: 숫자들이 어느 방향으로 늘어져 있는가?

중심과 산포를 알았다고 데이터의 특징을 전부 아는 건 아니야. 이번에는 모양을 봐야 해.

왜도 Skewness

왜도는 분포의 비대칭 정도를 나타내.

가장 중요한 판단 기준은 꼬리가 향하는 방향이야.

  • 오른쪽으로 긴 꼬리 → 양의 왜도
  • 왼쪽으로 긴 꼬리 → 음의 왜도
  • 좌우 대칭 → 왜도 약 0

오른쪽으로 치우친 분포에서는 큰 극단값들이 평균을 오른쪽으로 끌어당기기 때문에 전형적으로

최빈값 < 중앙값 < 평균

관계가 나타날 수 있어. 반대로 왼쪽으로 치우치면 전형적으로

평균 < 중앙값 < 최빈값

이야. 단, 이 관계는 모든 가능한 분포에 반드시 성립하는 절대 법칙이라기보다 전형적인 단봉 분포를 이해하는 규칙으로 기억하는 게 정확해.

첨도 Kurtosis

첨도는 분포 형태, 특히 꼬리와 극단값이 나타나는 특성과 관련된 통계량이야. 시험 공부에서는 흔히 정규분포를 기준으로 첨도를 비교해.

일반적인 정규분포 첨도3
초과첨도 excess kurtosis0

즉 문제에서 첨도가 0이라고 할 때는 초과첨도인지 확인해야 해.

🧩 5. 요약값은 따로 읽으면 안 된다

이 단원의 진짜 목표는 공식을 외우는 것보다 요약값을 조합해서 데이터를 해석하는 능력이야.

평균100
중앙값70
표준편차큼

평균만 보면 "대표적인 값이 100 정도구나"라고 생각하기 쉬워. 하지만 중앙값이 70으로 훨씬 작다는 것은 일부 큰 값들이 평균을 끌어올리고 있을 가능성을 생각하게 해. 표준편차까지 크다면 자료가 상당히 퍼져 있다는 정보도 얻을 수 있고.

평균 100 → 중심에 대한 정보

중앙값 70 → 평균과 대표 위치 사이의 차이

큰 표준편차 → 높은 산포

평균 > 중앙값 → 오른쪽으로 긴 분포 가능성 검토

하나의 숫자로 결론내리지 않고 여러 통계량의 관계를 보는 거야.

이 관계까지 이해해 두면 단순 정의 문제뿐 아니라 해석형 문제에도 대응하기 쉬워.

🔑 암기보다 먼저 고정할 세 가지

평균과 중앙값의 차이

평균은 값의 크기 전체에 민감하고, 중앙값은 순서상의 가운데 위치를 본다.

분산과 표준편차의 차이

표준편차는 분산의 제곱근이며 원자료와 같은 단위를 가진다.

왜도의 방향

데이터가 많은 쪽이 아니라 긴 꼬리가 뻗은 방향을 본다.

이 세 가지가 안정되면 데이터요약 문제의 상당 부분이 연결돼.
