## 🧭 1. 표본추출은 왜 필요할까?

통계에서 우리가 정말 알고 싶은 대상은 보통 **전체 집단**이야. 그런데 전체를 전부 조사하는 건 비용과 시간이 너무 많이 들지.

예를 들어 전국 성인 4,000만 명의 평균 수면시간을 알고 싶다고 해보자. 4,000만 명 전부 조사하는 대신 2,000명을 잘 뽑아서 조사하고, 그 결과로 전체를 추정할 수 있어.

이때 관계는 이렇게 잡으면 돼.

> **모집단 → 표본추출 → 표본 → 통계량 → 모집단의 특성 추정**

| 개념                 | 의미                | 예                |
| ------------------ | ----------------- | ---------------- |
| **모집단 Population** | 알고 싶은 전체 대상       | 전국 성인            |
| **표본 Sample**      | 모집단에서 실제로 조사한 일부  | 선택된 2,000명       |
| **모수 Parameter**   | 모집단의 특성을 나타내는 값   | 모집단 평균 μ         |
| **통계량 Statistic**  | 표본에서 계산한 값        | 표본평균 \(\bar{x}\) |
| **표본추출 Sampling**  | 모집단에서 표본을 선택하는 과정 | 2,000명 선정        |

### 대표성이 핵심이야

표본이 크기만 하면 되는 게 아니야.

**모집단의 특징을 제대로 반영하는 표본**, 즉 **대표성 있는 표본**을 뽑아야 해.

극단적으로 전국 성인의 평균 소득을 조사하면서 서울 강남구 주민 10만 명만 조사한다면 표본 수는 많아도 전국을 잘 대표한다고 보기 어렵겠지.

그래서 표본추출에서는 항상 두 가지를 같이 봐.

**표본 크기 + 표본을 뽑는 방법**

## 🎲 2. 표본추출 방법의 가장 큰 구분

표본추출 방법은 먼저 이것부터 나눠.

### 확률표본추출 Probability Sampling

모집단의 각 구성원이 **표본으로 선택될 확률을 알 수 있는 방법**이야.

무작위성이 들어가므로 모집단을 통계적으로 추론하기에 유리해.

대표적인 방법은:

**단순랜덤추출 → 계통추출 → 층화추출 → 군집추출**

### 비확률표본추출 Non-probability Sampling

각 구성원이 선택될 확률을 알 수 없거나 무작위 선택을 하지 않는 방법이야.

조사하기 쉽지만 **선택편향**이 발생할 가능성이 커.

대표적으로:

**편의추출 · 판단추출 · 할당추출 · 눈덩이추출**

시험에서는 우선 **확률표본추출 4개**를 확실하게 구분하는 게 중요해.

---

## 🎯 3. 단순랜덤추출

### Simple Random Sampling

모집단의 각 개체가 **동일한 확률로 선택되도록 무작위로 추출**하는 가장 기본적인 방법이야.

예를 들어 학생 1,000명에게 1~1,000번 번호를 부여하고 난수로 100명을 선택하는 방식이지.

#### 핵심

> **모두에게 같은 선택 기회**

장점은 이해하기 쉽고 통계적 추론이 간단하다는 것.

하지만 모집단이 아주 크면 모든 사람의 명단을 확보해야 하기 때문에 현실적으로 어려울 수 있어.

---

## 🔢 4. 계통추출

### Systematic Sampling

모집단을 일정한 순서로 나열한 다음 **일정한 간격 \(k\)**마다 하나씩 뽑는 방식이야.

모집단 크기가 \(N\), 원하는 표본 크기가 \(n\)이면 대략

$$
k=\frac{N}{n}
$$

으로 추출 간격을 정해.

예를 들어 1,000명 중 100명을 뽑으면

$$
k=\frac{1000}{100}=10
$$

이야.

처음 시작점을 무작위로 7번으로 선택했다면

**7 → 17 → 27 → 37 → …**

처럼 추출할 수 있어.

#### 핵심

> **랜덤 시작 + 일정 간격**

단, 모집단의 배열 자체에 어떤 **주기성**이 있다면 표본이 왜곡될 수 있어.

---

## 🧩 5. 층화추출

### Stratified Sampling

여기부터 시험에서 중요해져.

모집단을 서로 비슷한 특징을 가진 여러 **층(stratum)**으로 나눈 다음, **각 층에서 표본을 추출**하는 방법이야.

예를 들어 회사 직원이

* 개발직 50%
* 영업직 30%
* 관리직 20%

라면 직군별로 층을 만들고 각 층에서 사람을 뽑는 거야.

### 왜 층을 나눌까?

모집단에 서로 성격이 다른 하위집단이 존재하면 단순랜덤추출만으로는 어떤 집단이 지나치게 적게 뽑힐 수 있어.

층화추출은 이런 문제를 막아줘.

#### 구조를 기억해

**층 내부는 서로 비슷하고, 층과 층은 서로 다르다.**

즉,

> **층 내 동질 / 층 간 이질**

그리고 **모든 층에서 표본을 뽑는다.**

---

## 🏘️ 6. 군집추출

### Cluster Sampling

이번에는 모집단을 여러 **군집(cluster)**으로 나눈 다음, 군집 일부를 무작위로 선택해 조사하는 방법이야.

예를 들어 전국 고등학생을 조사한다고 해보자.

학생 개인을 전국에서 하나씩 뽑기 힘드니까 학교를 군집으로 보고

**전국 학교 중 30개 학교를 선택 → 선택된 학교의 학생 조사**

처럼 할 수 있어.

### 군집의 이상적인 구조

각 군집 자체가 모집단을 어느 정도 닮아 있어야 해.

그래서 보통 개념적으로

> **군집 내 이질 / 군집 간 동질**

이라고 기억해.

---

## ⚔️ 7. 층화추출과 군집추출 — 가장 중요한 구분

이 둘은 정말 자주 헷갈려.

| 구분    | 층화추출              | 군집추출             |
| ----- | ----------------- | ---------------- |
| 목적    | 모집단의 각 특성을 골고루 반영 | 조사 비용·편의성 향상     |
| 집단 내부 | **동질적**           | **이질적**          |
| 집단 사이 | **이질적**           | **동질적**          |
| 조사 방식 | **모든 층에서** 표본 추출  | **일부 군집을 선택**    |
| 예     | 성별별로 사람 추출        | 여러 학교 중 일부 학교 선택 |

한 문장으로 압축하면:

> **층화는 “각 종류에서 조금씩”, 군집은 “몇 덩어리를 통째로”.**

이 문장이 두 방법을 구분하는 가장 좋은 기준이야.

### 예를 하나 연결해볼게

대학교 학생 10,000명의 만족도를 조사한다고 하자.

**학년을 1·2·3·4학년으로 나누고 각 학년에서 학생을 뽑는다.**

→ **층화추출**

반면

**전국 대학 200개 중 15개 대학을 선택해 해당 대학 학생들을 조사한다.**

→ **군집추출**

차이는 **집단을 만든다는 것**이 아니야. 둘 다 집단을 만들 수 있어.

진짜 차이는

**모든 집단에서 뽑느냐 vs 일부 집단을 선택하느냐**

에 있어.

## 🪆 8. 다단계추출

### Multistage Sampling

대규모 조사에서는 한 번의 추출만으로 끝내지 않고 여러 단계를 거치는 경우도 많아.

예를 들어 전국 가구조사라면:

**지역 선택 → 동 선택 → 가구 선택 → 가구원 선택**

처럼 단계적으로 표본을 좁혀 갈 수 있어.

이런 방식을 **다단계추출**이라고 해.

군집추출과 결합해서 사용하는 경우가 많아.

## 👥 9. 비확률표본추출

확률표본추출과 달리 선택 확률을 정확히 알 수 없는 방식이야.

### 편의추출 Convenience Sampling

쉽게 만날 수 있는 사람을 조사해.

예: 학교 앞에서 만나는 학생에게 설문.

빠르고 싸지만 대표성이 약할 수 있어.

### 판단추출 Purposive/Judgment Sampling

조사자가 목적에 적합하다고 판단하는 대상을 선택해.

예: 특정 기술 전문가를 선정해 인터뷰.

### 할당추출 Quota Sampling

특정 구성비를 맞춰 조사하지만 각 집단 내부에서는 무작위로 뽑지 않아.

예:

남성 50명 / 여성 50명은 맞추되 조사원이 접근하기 쉬운 사람에게 질문.

겉모습은 층화추출과 비슷하지?

하지만 차이는 명확해.

> **층화추출 = 층 내부에서도 확률적으로 추출**
> **할당추출 = 할당량만 맞추고 비확률적으로 추출**

### 눈덩이추출 Snowball Sampling

한 조사 대상자가 다른 조사 대상자를 소개하는 식으로 표본이 점점 늘어나는 방식이야.

접근하기 어려운 집단을 조사할 때 쓰여.

## 🎯 10. 표본오차란?

우리가 모집단 전체가 아니라 **일부 표본만 조사했기 때문에 발생하는 우연한 차이**야.

예를 들어 실제 모집단 평균이

$$
\mu=70
$$

인데 어떤 표본의 평균이

$$
\bar{x}=72
$$

가 나왔다고 해보자.

표본을 우연히 다르게 뽑았기 때문에 이런 차이가 생길 수 있어.

이런 변동이 **표본오차(sampling error)**야.

### 표본크기가 커지면?

일반적으로 표본크기 \(n\)이 커질수록 표본통계량이 안정돼.

대표적으로 평균의 표준오차는

$$
SE(\bar{x})=\frac{\sigma}{\sqrt n}
$$

이므로 \(n\)이 커질수록 작아져.

여기서 아주 중요한 특징이 나와.

> **표본오차는 표본크기를 증가시키면 일반적으로 감소한다.**

다만 \(n\)을 2배로 만든다고 오차가 절반이 되는 건 아니야.

$$
SE \propto \frac{1}{\sqrt n}
$$

이니까 표준오차를 절반으로 만들려면 표본 크기를 대략 **4배**로 늘려야 해.

## 🚨 11. 편향이란?

### Bias

편향은 추정 결과가 모집단의 실제 값에서 **특정 방향으로 체계적으로 벗어나는 현상**이야.

표본오차가 우연한 흔들림이라면,

편향은 **조사 방법 자체가 한쪽으로 기울어진 것**이라고 보면 돼.

예를 들어 전국 평균 소득을 조사하면서 고소득자 밀집 지역 주민만 조사한다면 평균이 계속 높게 나올 가능성이 있지.

이건 우연한 표본오차라기보다 **선택 과정의 편향**이야.

### 가장 중요한 차이

표본 수를 크게 늘리면 표본오차는 줄어들지만,

> **편향된 방법으로 표본을 뽑았다면 표본 수를 아무리 늘려도 편향은 사라지지 않는다.**

전국 여론을 조사하면서 특정 대학 학생만 조사한다고 생각해봐.

100명을 조사하는 것보다 10만 명을 조사하면 숫자는 훨씬 정밀해 보이겠지만, 여전히 **특정 대학 학생이라는 편향된 표본**이야.

즉,

> **큰 표본 ≠ 좋은 표본**

이게 표본추출 단원의 중요한 메시지야.

## 🧨 12. 주요 편향 유형

### 선택편향 Selection Bias

특정 종류의 대상이 표본에 들어갈 가능성이 체계적으로 높거나 낮아지는 경우야.

예: 온라인 설문만 실시해서 인터넷 사용이 어려운 집단이 빠지는 경우.

### 비응답편향 Nonresponse Bias

표본으로 선정됐지만 응답하지 않은 사람들의 특징이 응답한 사람들과 다를 때 발생해.

예를 들어 소득조사에서 고소득자가 응답을 특히 많이 거부한다면 결과가 실제보다 낮아질 수 있어.

### 응답편향 Response Bias

응답자가 사실과 다르게 답하거나 질문 방식 때문에 특정 답을 하게 되는 경우야.

민감한 질문이나 유도질문에서 발생하기 쉬워.

### 커버리지 편향 Coverage Bias

애초에 모집단의 일부가 **표본추출틀**에 포함되지 않는 경우야.

예를 들어 전화번호부에 있는 사람만 대상으로 조사하면 전화번호부에 등록되지 않은 사람은 선택될 기회 자체가 없어.

## 🧠 13. 표본오차와 편향을 한 번에 정리하자

| 구분      | 표본오차          | 편향              |
| ------- | ------------- | --------------- |
| 성격      | 우연적 변동        | 체계적 왜곡          |
| 주요 원인   | 모집단 일부만 조사    | 잘못된 표본선정·조사방법   |
| 표본크기 증가 | 일반적으로 감소      | 반드시 감소하지 않음     |
| 방향      | 표본마다 달라질 수 있음 | 일정 방향으로 치우치는 경향 |
| 해결 핵심   | 표본크기·효율적인 설계  | 조사 설계 자체 개선     |

시험장에서 가장 먼저 떠올릴 문장은 이거야.

> **표본오차는 “우연”, 편향은 “체계적”.**

그리고 하나 더:

> **표본크기를 늘리면 표본오차는 감소하지만 편향이 해결된다는 보장은 없다.**

**모집단의 특성을 알고 싶다**

↓
전수조사는 어렵다

↓

## 📝 15. 빅데이터분석기사용 초압축 암기판

| 키워드    | 바로 떠올릴 말                   |
| ------ | -------------------------- |
| 단순랜덤추출 | 동일 확률, 무작위                 |
| 계통추출   | 랜덤 시작 + 일정 간격              |
| 층화추출   | **모든 층에서 추출**              |
| 군집추출   | **일부 군집 선택**               |
| 층화 구조  | 층 내 동질, 층 간 이질             |
| 군집 구조  | 군집 내 이질, 군집 간 동질           |
| 할당추출   | 비율은 맞춤, 무작위 X              |
| 표본오차   | 우연적, \(n↑ \Rightarrow\) 감소 |
| 편향     | 체계적 왜곡                     |
| 선택편향   | 특정 대상이 과소·과대 포함            |
| 비응답편향  | 응답자와 미응답자의 특성 차이           |

### 특히 이 세 쌍은 묶어서 기억해

**① 층화 ↔ 군집**

> 층화 = 모든 층
> 군집 = 일부 군집

**② 표본오차 ↔ 편향**

> 표본오차 = 우연
> 편향 = 체계적

**③ 층화 ↔ 할당**

> 층화 = 확률추출
> 할당 = 비확률추출

이 세 구분이 안정되면 표본추출 문제의 상당 부분이 정리돼.
