숫자로 불확실성을 다루는 법

#빅데이터분석기사#통계기법이해#기술통계#확률분포

이 단원은 사실 하나의 흐름이야. 어떤 실험의 결과를 숫자로 바꾸는 게 확률변수이고, 그 숫자가 각각 얼마나 자주 나타나는지를 나타내는 게 확률분포야. 그리고 그 분포를 대표하는 중심과 퍼짐이 기댓값과 분산이고.

시험 핵심: 관계로 기억

🎯 확률변수

사건의 결과를 숫자로 바꾼다.

정의
X = 앞면이 나온 횟수

동전을 두 번 던지면 결과는 앞앞, 앞뒤, 뒤앞, 뒤뒤처럼 생겨. 통계에서는 이런 결과 자체보다 숫자로 계산할 수 있는 형태가 편하지.

결과확률변수 X
뒤뒤0
앞뒤1
뒤앞1
앞앞2

확률변수는 확률 자체가 아니라, 확률실험의 결과에 숫자를 대응시키는 변수야.

이산형과 연속형

이산확률변수

값을 하나씩 셀 수 있어. 고객 수, 불량품 개수, 주사위 눈 등이 대표적이야.

X = 0, 1, 2, 3, …
연속확률변수

구간 안에서 연속적인 값을 가질 수 있어. 키, 몸무게, 시간, 온도 등이 대표적이야.

170.1, 170.12, 170.123, …

시험 감각: “불량품의 개수” → 이산형 / “제품의 수명” → 연속형

📊 확률분포 — 어떤 값이 얼마나 가능한가

아까 X가 앞면의 개수였다면 각 값에 확률을 붙일 수 있어. 이 관계 전체가 확률분포야.

P(X=0)=1/4
P(X=1)=1/2
P(X=2)=1/4

이산확률분포

특정 값의 확률을 직접 말할 수 있고 모든 가능한 값의 확률을 더하면 반드시 1이 돼.

Σ P(X=x) = 1

연속확률분포

특정한 한 점의 확률은 0으로 보고, 구간의 확률을 곡선 아래 면적으로 구해.

P(a<X<b) = ∫ₐᵇ f(x) dx

함정: 확률밀도 f(x) 자체와 확률은 같은 게 아니야.

🧩 주요 확률분포 — 상황을 보고 고른다

분포유형핵심 상황
베르누이이산성공/실패 한 번
이항이산독립적인 성공/실패를 n번 반복
포아송이산일정 구간에서 사건 발생 횟수
균일연속구간 내 값들이 균등한 밀도
정규연속평균 주변에 대칭적으로 모임
지수연속사건이 발생할 때까지의 대기시간

베르누이 → 이항

베르누이는 성공/실패 한 번. 이 시행을 독립적으로 n번 반복해서 성공 횟수를 세면 이항분포가 돼.

X ~ B(n,p)

고객 한 명이 구매하는가? → 베르누이
고객 100명 중 몇 명이 구매하는가? → 이항

포아송

시간·공간 등의 일정한 구간에서 사건이 몇 번 발생하는지를 모델링해.

X ~ Poisson(λ)

λ는 평균 발생 횟수.

정규분포

X ~ N(μ, σ²)

평균을 중심으로 좌우대칭이며 평균 = 중앙값 = 최빈값.

Z = (X − μ) / σ

표준화하면 평균 0, 분산 1인 표준정규분포로 바꿀 수 있어.

지수분포

포아송과 연결해서 기억하면 좋아.

일정 시간 동안 전화가 몇 통 오는가? → 포아송
다음 전화까지 얼마나 기다리는가? → 지수

⚖️ 기댓값

기댓값 E(X)는 가장 자주 나오는 값이 아니라, 확률을 가중치로 사용한 확률적 평균이야.

E(X) = Σ xP(X=x)
E(X) = 0×1/4 + 1×1/2 + 2×1/4 = 1

동전을 두 번 던지는 실험을 아주 많이 반복하면 앞면 개수의 평균은 1에 가까워진다는 뜻이야.

연속형: E(X) = ∫₋∞∞ xf(x) dx

중요한 성질

E(aX+b) = aE(X)+b
E(X+Y) = E(X)+E(Y)

마지막 식 자체에는 독립이라는 조건이 필요하지 않아.

📐 분산

평균만 같다고 두 분포가 같은 건 아니야. 분산은 평균으로부터 떨어진 거리의 제곱을 평균낸 것이라고 보면 돼.

Var(X) = E[(X−E(X))²]
Var(X) = E(X²) − [E(X)]²

표준편차는 σ = √Var(X). 분산은 단위가 제곱되지만 표준편차는 원래 자료와 같은 단위를 가져.

🔍 기댓값과 분산에서 특히 헷갈리는 차이

위치를 b만큼 이동
E(X+b) = E(X)+b
Var(X+b) = Var(X)

중심은 움직이지만 값 사이의 간격은 그대로야.

크기를 a배 확대
Var(aX) = a²Var(X)
Var(aX+b) = a²Var(X)

시험 포인트: 기댓값에는 a, 분산에는 a².
