🎯 1. 통계량의 표본분포 — 무엇이 분포한다는 걸까?

모집단에서 무작위로 30명을 뽑아 평균을 계산했더니 x̄ = 171.2가 나왔다고 하자. 다시 30명을 뽑으면 169.8, 또 뽑으면 170.5가 나올 수 있어.

171.2, 169.8, 170.5, 171.0, …

이렇게 반복해서 생긴 표본평균 x̄들의 분포가 바로 표본평균의 표본분포야.

구분무엇이 분포하나?
모집단의 분포개별 관측값 X
하나의 표본실제로 뽑힌 관측값들
표본분포표본에서 계산한 통계량

표본분포는 표본 안의 데이터 분포가 아니다. 평균, 비율, 분산 같은 통계량을 반복 표집했을 때 나타나는 분포야.

🔬 2. 표본평균의 표본분포 — 중심은 어디일까?

모집단 평균을 μ, 분산을 σ²라고 하자. 크기가 n인 확률표본의 표본평균은

x̄ = (X₁ + ··· + Xₙ) / n

이고, 표본추출을 반복하면 x̄ 자체가 확률변수가 돼. 이때 중요한 성질은

E(x̄) = μ

즉, 표본평균의 표본분포는 모평균 μ를 중심으로 형성돼. 어떤 표본에서는 실제보다 높고 다른 표본에서는 낮지만, 반복 표집에서 표본평균의 평균은 모집단 평균에 맞춰진다는 뜻이야.

📐 3. 표준오차 — 표본평균은 얼마나 흔들릴까?

표본평균들이 μ 주변에 모인다는 걸 알았다면 다음 질문은 얼마나 넓게 퍼져 있느냐야. 그 퍼짐을 나타내는 것이 표준오차(Standard Error, SE)야.

표본평균의 분산
Var(x̄) = σ² / n
표준오차
SE(x̄) = σ / √n
개념의미
σ개별 관측값들이 얼마나 퍼져 있는가
σ / √n표본평균들이 얼마나 퍼져 있는가

표준편차(SD) = 데이터의 흔들림, 표준오차(SE) = 통계량의 흔들림이라고 잡으면 좋아. 모표준편차를 모르는 실제 상황에서는 SE(x̄) ≈ s / √n으로 추정하기도 해.

🔍 4. n이 커지면 왜 추정이 정밀해질까?

SE = σ / √n

모집단의 σ가 같다면 n이 커질수록 분모가 커지니까 표준오차가 작아져.

σ=20, n=25
SE = 4
σ=20, n=100
SE = 2

표본크기를 4배로 늘렸더니 표준오차는 절반이 됐지. SE는 n이 아니라 √n에 반비례하기 때문이야.

🧠 5. 중심극한정리와 표본분포

모집단이 정규분포라면 표본평균도 정규분포를 따르고,

x̄ ~ N(μ, σ²/n)

더 중요한 건 모집단 자체가 정규분포가 아니더라도 적절한 조건에서 표본크기가 충분히 커지면 표본평균의 분포가 근사적으로 정규분포에 가까워진다는 거야. 이게 중심극한정리의 핵심 역할이야.

Z = (x̄ − μ) / (σ / √n)

이렇게 표준화해서 확률을 계산할 수 있게 돼. 다만 “n ≥ 30이면 무조건 된다”고 기계적으로 이해하면 안 돼. 실제 근사 정도는 모집단 분포의 형태와 표본추출 조건에도 영향을 받아.

🛠️ 6. 표본분포는 어디에 쓰일까?

표본마다 결과가 달라지는 표집에 따른 불확실성을 표본분포가 수량화해줘.

모집단
표본
x̄, p̂, S²
표본분포
표준오차 SE
신뢰구간 · 가설검정

즉 표본분포는 기술통계에서 추론통계로 넘어가는 다리라고 보면 돼.

⚠️ 7. 필기시험에서 잘 낚이는 구별

표본분포 ≠ 표본의 분포
표본분포에서 분포하는 대상은 통계량이야.
표준오차 ≠ 표준편차
표준오차는 통계량의 표집변동을 나타낸다.
표본크기 증가 → 표준오차 감소
SE ∝ 1/√n
E(x̄) = μ
Var(x̄) = σ²/n
SE(x̄) = σ/√n

🧩 한 문장으로 연결하기

같은 모집단에서 같은 크기의 표본을 반복 추출하면 통계량도 표본마다 달라지고, 그 통계량들의 분포가 표본분포이며, 그 분포의 표준편차가 표준오차다. 표본크기가 커질수록 표준오차가 작아져 모집단 모수에 대한 추정이 더 정밀해진다.

이 관계가 잡혀 있으면 표본분포 문제 대부분의 뼈대가 보여.
