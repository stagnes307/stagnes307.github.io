🧭 먼저 큰 그림: 우리는 왜 ‘추정’할까?

모집단 전체를 조사할 수 있다면 추론통계가 크게 필요하지 않아. 하지만 대한민국 성인 전체의 평균 키처럼 모집단 전체를 직접 조사하는 일은 현실적으로 비용과 시간이 너무 많이 들지.

그래서 일부만 표본(sample)으로 뽑고, 표본에서 얻은 정보를 이용해 알 수 없는 모집단의 값을 추측해.

모수

알고 싶은 모집단의 특성
예: 모집단 평균 μ

통계량

표본으로 계산한 값
예: 표본평균 X̄

추정량

모수를 추정하는 통계량·규칙
예: X̄

추정값

관측 후 나온 구체적 숫자
예: 172.4cm

🎯 추정량과 점추정: ‘방법’과 ‘결과’를 분리하자

점추정(point estimation)은 미지의 모수를 하나의 값으로 추정하는 것이야.

예를 들어 표본 5명의 값이 170, 175, 168, 172, 175라면 표본평균은 172야.

X̄ = (170 + 175 + 168 + 172 + 175) / 5 = 172

여기서 172라는 숫자 자체가 추정량은 아니야. 표본평균을 계산하는 규칙 X̄가 추정량이고, 실제 관측자료를 넣어 얻은 172가 추정값이야.

추정량

모수를 추정하는 규칙

추정값

실제로 나온 숫자

점추정

하나의 숫자로 추정하는 행위

⚖️ 좋은 추정량을 가르는 네 가지 성질

같은 모수를 추정하는 방법이 여러 개라면 어떤 추정량이 더 좋은지를 판단해야 해. 필기에서는 특히 불편성, 효율성, 일치성, 충분성을 구별할 수 있어야 해.

불편성 — 평균적으로 과녁 중앙을 맞히는가?

E(θ̂) = θ

한 번의 추정이 정확하다는 뜻은 아니야. 표본을 계속 새로 뽑았을 때 추정량의 기댓값이 실제 모수와 같음을 뜻해.

Bias(θ̂) = E(θ̂) − θ

효율성 — 둘 다 중앙을 겨냥한다면 누가 덜 흔들리는가?

Var(θ̂₁) < Var(θ̂₂)

두 추정량이 모두 불편하다면 분산이 작은 추정량이 더 효율적이야. 같은 과녁을 겨냥하더라도 결과가 더 촘촘하게 모이는 쪽이지.

일치성 — 표본이 커지면 진짜 값에 가까워지는가?

n ↑ ⇒ θ̂ → θ

표본크기가 증가할수록 추정량이 실제 모수에 가까워지는 성질이야. 불편성과 달리 n이 커지는 과정이 핵심이야.

충분성 — 표본의 정보를 제대로 담고 있는가?

표본 → 모수 관련 정보 → 충분통계량

충분통계량은 모수에 관한 표본의 정보를 충분히 담고 있는 통계량이야.

성질질문핵심 기준
불편성평균적으로 맞는가?E(θ̂)=θ
효율성얼마나 덜 흔들리는가?분산이 작음
일치성표본을 늘리면 맞아지는가?θ̂→θ
충분성정보를 충분히 쓰는가?모수 관련 정보 보존

🔬 과녁으로 보는 불편성과 효율성

두 사수가 모두 중앙을 중심으로 쏜다면 둘 다 불편성이 좋아. 그런데 한쪽의 탄착점이 훨씬 좁게 모이면 그쪽 추정량이 더 효율적이야.

불편 + 높은 효율성

중앙 주변에 촘촘

불편 + 낮은 효율성

평균 중심은 같지만 넓게 퍼짐

🧮 대표 사례: 모집단 평균의 점추정

모집단 평균이 μ이고 표본이 X₁, …, Xₙ이라면 표본평균으로 모집단 평균을 추정할 수 있어.

μ̂ = X̄ = (1/n) Σ Xᵢ

표본평균의 기댓값은 모집단 평균과 같아.

E(X̄) = μ

따라서 표본평균은 모집단 평균의 불편추정량이야. 독립 표본이고 모집단 분산이 σ²라면

Var(X̄) = σ² / n

즉 n이 증가하면 표본평균의 분산은 감소해. 이 관계는 뒤의 표준오차와 구간추정으로 그대로 연결돼.

🧩 대표 함정: 모집단 분산을 추정할 때 왜 n−1인가?

표본평균을 이용해 편차를 계산하면서 분모를 n으로 두면 모집단 분산을 평균적으로 작게 추정하는 편향이 생겨.

S² = [1 / (n−1)] Σ(Xᵢ − X̄)²

이렇게 n−1로 자유도를 보정하면 E(S²)=σ²가 되어 모집단 분산의 불편추정량이 돼.

시험 연결: n−1 → 자유도 보정 → 모집단 분산의 불편추정량

📊 점추정 결과는 어떻게 해석해야 할까?

어떤 조사에서 모집단 평균의 점추정 결과가 μ̂=52.3이라고 해보자.

올바른 해석

표본자료에 근거하여 모집단 평균을 52.3으로 추정한다.

피해야 할 해석

모집단 평균이 정확히 52.3이다.

다른 표본을 뽑으면 다른 추정값이 나올 수 있기 때문이야. 그래서 점추정에는 본질적인 한계가 있어.

점추정은 하나의 값을 주지만 추정의 불확실성을 직접 보여주지는 않는다.

이 한계를 보완하는 다음 개념이 구간추정이야. 하나의 숫자 대신 일정한 신뢰수준에서 모수가 위치할 것으로 보는 구간을 제시하는 거지.
