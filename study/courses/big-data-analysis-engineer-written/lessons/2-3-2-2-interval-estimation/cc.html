오늘의 중심식

신뢰구간 = 점추정량 ± 임계값 × 표준오차

🎯 1. 구간추정은 왜 필요한가?

모집단 전체를 조사하기 어렵기 때문에 표본으로 모수(parameter)를 추정해.

예를 들어 전국 직장인의 평균 수면시간 μ를 알고 싶은데 100명을 조사해서 표본평균이 6.8시간 나왔다고 하자.

점추정

μ̂ = X̄ = 6.8

구간추정

6.5 ≤ μ ≤ 7.1

표본을 다시 뽑으면 6.7, 6.9처럼 값이 달라질 수 있지. 그래서 구간추정은 하나의 값 대신 모수가 있을 것으로 추정되는 범위를 제시해.

점추정량 ± 임계값 × 표준오차

즉, 신뢰구간 = 추정값 ± 오차한계

🧠 2. 신뢰구간 원리 — 95%가 정확히 무슨 뜻일까?

같은 모집단에서 같은 방법으로 표본을 계속 뽑아 95% 신뢰구간을 반복해서 만든다고 생각해 보자. 이 절차를 아주 많이 반복하면 만들어진 구간 중 약 95%가 실제 모수 μ를 포함하게 돼.

신뢰수준과 유의수준

신뢰수준 = 1 − α

신뢰수준α양쪽 꼬리 각각
90%0.100.05
95%0.050.025
99%0.010.005

95% 신뢰구간에서 익숙한 1.96이 나오는 이유도 여기에 있어.

zα/2 = z0.025 = 1.96

90% → 1.645 95% → 1.96 99% → 2.576

📐 3. 신뢰구간의 폭을 결정하는 세 가지

X̄ ± zα/2 · σ/√n

신뢰수준이 높아지면?

95% → 99%로 높이면 임계값이 1.96 → 2.576으로 커져.

신뢰수준 ↑ → 신뢰구간 폭 ↑

더 확실하게 모수를 잡으려면 더 넓게 그물을 쳐야 한다고 생각하면 돼.

표본크기가 커지면?

SE = σ/√n

n ↑ → SE ↓ → 신뢰구간 폭 ↓

표본이 많아질수록 추정이 정밀해지는 거야.

표준편차가 커지면?

σ ↑ → SE ↑ → 신뢰구간 폭 ↑

변화신뢰구간
신뢰수준 ↑넓어진다
표본크기 n ↑좁아진다
표준편차 ↑넓어진다

🔬 4. 모수별 구간추정

공식을 무작정 외우기보다 추정 대상 → 조건 → 분포 순서로 판단하면 덜 헷갈려.

모평균 μ — 모분산을 아는 경우

모표준편차 σ를 알고 있다면 Z 분포를 사용해.

X̄ ± zα/2 · σ/√n

예시

표본평균 50, 모표준편차 10, 표본크기 100, 95% 신뢰구간이라면

50 ± 1.96 × 10/√100 = 50 ± 1.96

48.04 ≤ μ ≤ 51.96

모평균 μ — 모분산을 모르는 경우

현실에서는 σ를 모르는 경우가 많아. 이때 표본표준편차 s로 대신 추정하고 t 분포를 사용해.

X̄ ± tα/2,n−1 · s/√n

자유도 df = n − 1

모분산을 안다 → Z

모분산을 모른다 → t

특히 표본이 작을수록 t분포는 정규분포보다 꼬리가 두꺼워서 신뢰구간이 더 넓어져.

모비율 p

성공/실패처럼 비율을 추정한다면 표본비율 p̂ = x/n을 사용해.

p̂ ± zα/2 √[p̂(1−p̂)/n]

추정 대상점추정량표준오차대표 분포
모평균, σ 앎X̄σ/√nZ
모평균, σ 모름X̄s/√nt
모비율p̂√[p̂(1−p̂)/n]Z 근사

⚠️ 5. 신뢰구간 해석 — 가장 잘 낚이는 부분

95% CI = [48.04, 51.96]

흔히 “모평균 μ가 이 구간 안에 있을 확률이 95%다”라고 말하고 싶어져.

고전적 빈도주의 신뢰구간에서는 엄밀한 해석이 아니야.

모수 μ는 이미 고정된 값이고, 표본을 어떻게 뽑느냐에 따라 구간 자체가 변하는 것이기 때문이야.

BAILEY

“95% 신뢰구간이니까 이번 구간에 모수가 들어 있을 확률이 95%?”

…그럼 모수가 표본 뽑을 때마다 어디로 도망다니기라도 하냐.

고정된 것은 모수, 변하는 것은 신뢰구간.

🔗 6. 구간추정과 가설검정은 연결돼 있다

어떤 모평균에 대해 H₀: μ = μ₀를 양측검정한다고 해보자.

95% 신뢰구간에 μ₀가 없음

→ 유의수준 5% 양측검정에서 H₀ 기각

95% 신뢰구간에 μ₀가 포함

→ 해당 양측검정에서 H₀를 기각할 수 없음

구간추정과 가설검정은 별개의 암기 단원이 아니라 같은 추론을 다른 방식으로 표현한 것이라고 이해하면 다음 단원이 쉬워져.

📝 7. 시험 직전 압축 정리

신뢰구간 = 점추정량 ± 임계값 × SE

① 모평균 + σ 앎

X̄ ± zα/2 σ/√n

② 모평균 + σ 모름

X̄ ± tα/2,n−1 s/√n

③ 모비율

p̂ ± zα/2√[p̂(1−p̂)/n]

④ 폭의 방향

신뢰수준 ↑ → 폭 ↑
n ↑ → 폭 ↓
σ ↑ → 폭 ↑

고정 = 모수 · 변동 = 신뢰구간
