🔄 1. 입력·출력 정의 — 무엇으로 무엇을 알아낼 것인가?

분석모형을 만들 때 가장 먼저 명확해야 하는 건 입력 데이터와 출력 결과의 관계야. 온라인 쇼핑몰에서 고객의 구매 여부를 예측한다고 해보자.

입력 X

모형이 판단에 사용하는 정보야.

  • 고객 나이
  • 최근 방문 횟수
  • 장바구니 금액
  • 이전 구매 횟수

설명변수 · 독립변수 · 예측변수 · 특성(feature)

→

출력 Y

모형이 최종적으로 만들어내려는 결과야.

이번 주 구매 여부 → 구매 / 미구매

목표변수 · 종속변수

X → f(X) → Y

중요한 건 데이터를 많이 넣는 게 아니야. 분석 목적과 연결되는 입력과 출력이어야 해. 목적이 고객 이탈 예측인데 출력변수를 매출액으로 잡으면 모형 정의 자체가 어긋난 거지.

🧩 2. 분석 유형에 따라 입력과 출력도 달라진다

지도학습

입력과 정답에 해당하는 출력이 존재해.

분류 · 정상/불량, 구매/미구매, 스팸/정상메일
회귀 · 매출액, 가격, 온도, 수요량

비지도학습

미리 정해진 목표변수 없이 데이터 자체의 구조를 찾을 수 있어. 고객 군집분석이라면 비슷한 고객들을 몇 개의 집단으로 나누는 결과가 만들어지지.

따라서 “모든 분석모형에는 사전에 정의된 종속변수가 반드시 존재한다”는 표현은 조심.

⚙️ 모형 가정 — 모형이 작동하기 위한 전제

모형은 현실 전체를 그대로 복제하지 않아. 현실을 단순화해서 일정한 규칙으로 표현하기 때문에 “이런 조건이 성립한다고 보고 분석하겠다”라는 전제가 필요해.

Y = β₀ + β₁X + ε

선형회귀라면 X와 Y의 관계를 선형적으로 표현할 수 있다는 생각이 들어가. 실제 관계가 완전히 다른 구조라면 선형모형이 부적절할 수 있겠지. 그래서 분석자는 “이 모형이 요구하는 조건이 데이터에 적합한가?”를 확인해야 해.

선형성

X와 Y의 관계가 적절하게 선형적으로 표현될 수 있는가?

독립성

관측값이나 오차가 서로 지나치게 영향을 주지 않는가?

등분산성

예측값에 따라 오차의 퍼짐이 지나치게 달라지지 않는가?

정규성

특정 통계모형에서 오차 등이 필요한 분포 특성을 갖는가?

중요: 모든 분석모형이 똑같은 가정을 요구하는 것은 아니야.

🗺️ 분석 범위 정의 — 분석의 경계를 긋는다

분석 범위는 이번 분석에서 어디까지 포함하고 어디부터 제외할지를 정하는 것이야.

ANALYSIS BOUNDARY

분석 대상

전체 고객? 신규 고객? 온라인 고객? 특정 지역 고객?

시간 범위

최근 1개월? 최근 1년? 특정 시점 이후?

데이터 범위

구매 기록? 접속 기록? 문의 기록? 광고 반응?

변수 범위

나이? 구매 빈도? 방문 횟수? 이용 기간?

분석 목적↔ 데이터 가용성↔ 시간·비용↔ 분석 가능성

분석 범위

온라인몰 회원 · 최근 12개월 · 구매·방문·문의 기록 · 다음 달 이탈 예측.

결국 분석모형 정의는 단순히 알고리즘을 고르는 일이 아니야. 알고리즘을 고르기 전에 문제 자체를 분석 가능한 형태로 구체화하는 과정이야.
