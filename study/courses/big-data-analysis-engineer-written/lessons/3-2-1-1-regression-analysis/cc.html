회귀분석

#빅데이터분석기사 #회귀모형 #추정 #진단 #결과해석

회귀분석에서 필기시험이 계속 묻는 건 크게 세 가지야. 모형이 어떻게 생겼는가 → 계수를 어떻게 추정하고 진단하는가 → 나온 숫자를 어떻게 해석하는가. 이 세 축을 연결하면 공식 암기량이 꽤 줄어들어.

🧭 1. 회귀분석은 무엇을 하려는가?

회귀분석은 한 변수의 변화가 다른 변수와 어떤 관계를 가지는지 수식으로 표현하고, 그 관계를 이용해 설명하거나 예측하는 방법이야.

아파트 가격 Y를 면적 X로 설명한다면 가장 기본적인 형태는 다음과 같아.

Y = β₀ + β₁X + ε

여기서 핵심은 실제값을 두 부분으로 나누는 거야.

설명되는 것과 설명하는 것

종속변수 Y
설명하거나 예측하려는 값
독립변수 X
Y를 설명하는 변수
회귀계수 β
X와 Y의 관계를 나타내는 숫자
오차항 ε
회귀식으로 설명되지 않는 부분

🏗️ 2. 회귀모형 구조

단순선형회귀

Yᵢ = β₀ + β₁Xᵢ + εᵢ

β₀는 절편, β₁은 회귀계수 또는 기울기야. 예를 들어 Ŷ = 100 + 5X라면 X가 1 증가할 때 예측된 Y는 평균적으로 5 증가한다고 해석해.

오차항

이론적·모집단 수준

εᵢ = Yᵢ − (β₀ + β₁Xᵢ)

관측할 수 없는 값

잔차

표본·계산 수준

eᵢ = Yᵢ − Ŷᵢ

관측자료로 계산할 수 있는 값

다중선형회귀

Yᵢ = β₀ + β₁X₁ᵢ + β₂X₂ᵢ + ··· + βₚXₚᵢ + εᵢ

다중회귀의 회귀계수는 다른 독립변수들의 값이 일정할 때 해당 변수가 1만큼 변할 때 Y가 얼마나 달라지는지를 나타내.

🎯 3. 회귀계수는 어떻게 추정하는가?

최소제곱법 OLS

잔차를 그대로 더하면 양수와 음수가 상쇄될 수 있어. 그래서 잔차를 제곱한 뒤 합하고, 그 값이 가장 작아지는 회귀계수를 선택해.

SSE = Σ(Yᵢ − Ŷᵢ)²

OLS = 잔차제곱합을 최소화하는 회귀선을 찾는 방법

단순회귀 계수의 구조

β̂₁ = Σ(Xᵢ−X̄)(Yᵢ−Ȳ) / Σ(Xᵢ−X̄)²

β̂₀ = Ȳ − β̂₁X̄

β̂₁은 대략 X와 Y가 함께 움직이는 정도 ÷ X가 변하는 정도로 이해할 수 있어.

🔍 4. 추정만 했다고 끝이 아니다: 회귀모형의 기본 가정

선형성

독립변수와 종속변수의 관계가 선형적으로 표현될 수 있어야 해.

독립성

오차들이 서로 독립적이어야 해. 자기상관은 Durbin-Watson으로 진단하며 2에 가까울수록 자기상관이 없는 상태로 해석하는 게 기본이야.

등분산성

오차의 분산이 일정해야 해. 잔차가 깔때기처럼 퍼지면 이분산성을 의심해.

정규성

오차가 정규분포를 따른다고 가정해. 특히 회귀계수의 가설검정과 신뢰구간에서 중요해.

다중공선성

다중회귀에서는 독립변수끼리 지나치게 강한 상관관계를 가지면 각 변수의 고유한 영향을 구분하기 어려워져.

VIFⱼ = 1 / (1 − Rⱼ²)

시험에서는 흔히 VIF가 10 이상이면 다중공선성을 의심하는 기준을 접해. 실제 분석에서는 5 같은 더 보수적인 기준도 쓰여.

🧪 5. F검정과 t검정

모형 전체

F검정

H₀: β₁ = β₂ = ··· = βₚ = 0

모든 독립변수가 Y를 설명하는 데 도움이 되지 않는다는 귀무가설을 검정해.

개별 계수

t검정

H₀: βⱼ = 0

특정 독립변수의 회귀계수가 통계적으로 유의한지 확인해.

F검정 = 회귀모형 전체 · t검정 = 개별 회귀계수

📐 6. 모형은 얼마나 잘 설명하는가: R²

SST = SSR + SSE

SST는 총변동, SSR은 회귀모형이 설명한 변동, SSE는 설명하지 못한 오차 변동이야.

R² = SSR / SST = 1 − SSE / SST

R² = 0.80이라면 종속변수 전체 변동의 약 80%를 회귀모형이 설명한다고 해석해.

독립변수를 추가하면 R²는 일반적으로 감소하지 않아. 그래서 변수 수까지 고려한 수정된 결정계수 Adjusted R²를 함께 봐.

Adjusted R² = 1 − (1 − R²)(n − 1)/(n − p − 1)

🩺 7. 잔차진단: 모형의 문제는 어디서 드러나는가?

잔차는 단순히 계산하고 버리는 숫자가 아니야. 모형이 놓친 구조가 잔차에 남아 있어.

  • 곡선 패턴 → 선형성 위반 가능성
  • 깔때기 모양 → 이분산성
  • 시간에 따른 반복 패턴 → 자기상관
  • 극단적으로 떨어진 점 → 이상치 가능성

이상적 잔차: 0을 중심으로 일정한 폭에서 무작위 분포

🔬 8. 이상치와 영향력 있는 관측치

이상치

종속변수 관점에서 크게 벗어난 관측치. 잔차가 지나치게 큰 경우가 대표적이야.

레버리지

독립변수 공간에서 다른 관측치와 멀리 떨어져 있는 정도.

영향력

관측치 하나를 포함하거나 제거할 때 회귀식이 얼마나 크게 바뀌는가. 대표 지표는 Cook's distance야.

📖 9. 회귀분석 결과표를 실제로 읽어보자

Ŷ = 10 + 2X₁ − 4X₂
변수 계수 p-value
절편100.030
X₁20.001
X₂-40.220

X₁

다른 변수가 일정할 때 X₁이 1 증가하면 Y의 예측값은 평균적으로 2 증가. p=0.001이므로 통계적으로 유의해.

X₂

계수 방향은 음(-)이지만 p=0.220이므로 유의수준 5%에서는 통계적으로 유의하다고 보기 어려워.

모형 전체

F검정 p=0.002라면 모형 전체는 통계적으로 유의해.

설명력

R²=0.75, Adjusted R²=0.72라면 전체 변동의 약 75%를 설명하고 변수 수를 고려한 설명력은 약 72% 수준이야.

🧠 11. 결과 해석에서 가장 중요한 세 가지 구분

관계의 방향과 크기는?

회귀계수 β̂ⱼ를 본다. 양수면 양의 관계, 음수면 음의 관계이며 절댓값은 X 한 단위 변화와 연결된 Y 변화량을 나타내.

그 관계를 통계적으로 믿을 수 있는가?

t검정의 p-value를 본다. 예를 들어 p<0.05이면 유의수준 5%에서 해당 회귀계수를 통계적으로 유의하다고 판단해.

모형 전체의 설명력과 적합성은?

F검정은 전체 유의성, R²와 Adjusted R²는 설명력, 잔차분석은 가정과 적합성을 점검해.
