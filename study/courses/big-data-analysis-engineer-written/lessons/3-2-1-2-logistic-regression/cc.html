🎯 먼저 잡을 한 문장 — 로지스틱 회귀는 무엇을 예측할까?

로지스틱 회귀분석은 결과가 두 범주로 나뉘는 문제에서 특정 사건이 발생할 확률을 예측하는 회귀모형이야.

예를 들어 고객 이탈 여부, 대출 연체 여부, 질병 유무, 구매 여부처럼 목표값이 보통 0 또는 1인 문제에 사용해.

시험의 흐름은 사실 세 단계뿐이야.

확률 p → 오즈 p/(1-p) → 로그오즈 log[p/(1-p)]

🔢 1. 확률과 오즈 — 왜 확률을 그대로 쓰지 않을까?

확률 p

어떤 사건이 일어날 가능성을 p라고 하면 범위는 0에서 1 사이야.

0 ≤ p ≤ 1

예를 들어 고객 이탈확률이 0.8이라면 p = 0.8이야.

선형회귀식을 그대로 쓰면?

p = β₀ + β₁X

X의 값에 따라 예측값이 -0.3이나 1.4가 될 수 있어. 하지만 확률은 0과 1 사이여야 하니 범위를 벗어나 버리지.

⚖️ 오즈 Odds

Odds = p / (1-p)

사건이 발생할 확률을 사건이 발생하지 않을 확률과 비교한 비율이야.

p = 0.2
Odds = 0.25
비발생 가능성이 더 큼
p = 0.5
Odds = 1
발생과 비발생이 같음
p = 0.8
Odds = 4
발생 가능성이 비발생의 4배

🔄 2. 로그오즈와 로짓 — 선형식과 연결하는 다리

오즈의 범위는 0보다 크고 무한대까지라 여전히 제한돼 있어. 그래서 오즈에 자연로그를 취해.

log(p / (1-p))
로그오즈 또는 로짓(logit)

로그를 취하면 값의 범위가 음의 무한대부터 양의 무한대까지 열리기 때문에 선형결합과 연결할 수 있어.

log(p / (1-p)) = β₀ + β₁X₁ + β₂X₂ + ··· + βₖXₖ

즉 로지스틱 회귀는 확률 자체를 선형모형으로 만드는 것이 아니라 로그오즈를 선형모형으로 만든다는 게 핵심이야.

🧮 3. 모형 구축 — 실제 확률은 어떻게 구할까?

설명변수가 하나라면 로짓식은 다음과 같아.

log(p / (1-p)) = β₀ + β₁X
오른쪽을 z = β₀ + β₁X라고 두면
p = 1 / (1 + e-z)

시그모이드가 하는 일

z가 매우 작으면 p는 0에 가까워져.
z = 0이면 p = 0.5야.
z가 매우 크면 p는 1에 가까워져.

🧠 4. 모형 구축 과정 — 시험에서는 무엇을 묻나?

설명변수 → 로짓 계산 → 확률 계산 → 범주 결정
Worked Example
log(p / (1-p)) = -3 + 0.8X

X = 5라면 z = -3 + 0.8(5) = 1

p = 1 / (1 + e-1) ≈ 0.731

즉 사건 발생확률은 약 73.1%야.

분류 기준이 0.5라면 0.731 > 0.5이므로 1인 집단으로 분류해.

단, 0.5는 자주 쓰는 기준일 뿐 분석 목적에 따라 임계값을 바꿀 수 있어.

📊 5. 계수 해석 — 여기서 시험 문제가 많이 갈린다

모형이 log(p/(1-p)) = β₀ + β₁X일 때 β₁은 X가 1 증가할 때 로그오즈가 β₁만큼 변한다는 뜻이야.

핵심 변환
eβ₁
이 값이 오즈비 Odds Ratio야.

계수가 양수인 경우

β₁ = 0.7 → e0.7 ≈ 2.01

다른 조건이 동일할 때 X가 1 증가하면 사건 발생 오즈가 약 2.01배가 돼.

계수가 음수인 경우

β₁ = -0.7 → e-0.7 ≈ 0.497

오즈가 약 0.497배가 되므로 약 50.3% 감소한 것으로 볼 수 있어.

시험 핵심: eβ는 확률비가 아니라 오즈비야.

🚦 6. 오즈비 해석 공식 — 세 가지만 기억해

오즈비 계수 해석
OR > 1β > 0사건 발생 오즈 증가
OR = 1β = 0변화 없음
OR < 1β < 0사건 발생 오즈 감소
증가율
(OR - 1) × 100%

OR = 1.3이면 오즈가 30% 증가.

감소율
(1 - OR) × 100%

OR = 0.7이면 오즈가 30% 감소.

🧩 7. 절편 β₀은 어떻게 해석할까?

모든 설명변수가 0일 때의 로그오즈가 β₀야.

오즈로 변환
Odds = eβ₀
확률로 변환
p = eβ₀ / (1 + eβ₀)

실제 데이터에서는 설명변수 0이 현실적으로 의미 없는 경우도 있어 절편 자체를 실질적으로 해석하지 않기도 해.

🔬 8. 다중 로지스틱 회귀에서는 무엇이 달라질까?

log(p / (1-p)) = β₀ + β₁X₁ + β₂X₂ + ··· + βₖXₖ
고객 이탈 예시
log(p / (1-p)) = -4 + 0.05(불만횟수) - 0.03(가입기간)
e0.05 ≈ 1.051

불만횟수가 1회 증가하면 이탈 오즈가 약 5.1% 증가.

e-0.03 ≈ 0.970

가입기간이 1단위 증가하면 이탈 오즈가 약 3.0% 감소.

중요: 다중회귀에서는 항상 “다른 설명변수가 동일할 때”라는 조건을 붙여 해석해.

⚠️ 10. 가장 자주 틀리는 세 가지

첫 번째 함정 — 계수를 확률 변화량으로 해석한다

β = 0.5라고 해서 X가 1 증가하면 확률이 0.5 증가하는 게 아니야.

β는 로그오즈의 변화량이야.

두 번째 함정 — eβ를 확률비로 해석한다

eβ = 2는 확률이 2배라는 뜻이 아니라 오즈가 2배라는 뜻이야.

p = 0.5 → Odds = 1 → Odds = 2 → p = 2/3 ≈ 0.667

세 번째 함정 — 음의 계수의 감소율을 잘못 계산한다

eβ = 0.8이면 80% 감소가 아니라 기존 오즈의 0.8배가 된 것이므로 20% 감소야.

Bailey: “0.8배가 됐는데 왜 80%가 사라졌다고 생각했지?”

🗺️ 11. 세 개의 표현을 서로 변환할 수 있어야 한다

확률 → 오즈
Odds = p / (1-p)
오즈 → 확률
p = O / (1+O)
오즈 → 로그오즈
logit(p) = ln(O)
로그오즈 → 오즈
O = eL

🧭 12. 빅데이터분석기사 필기용 압축 정리

  1. 로지스틱 회귀는 주로 이항 종속변수를 분석한다.
  2. 확률을 그대로 선형모형에 넣지 않고 로짓 변환을 한다.
  3. 로짓은 log[p/(1-p)]이다.
  4. 회귀계수 β는 설명변수가 1 증가할 때의 로그오즈 변화량이다.
  5. eβ는 오즈비 Odds Ratio다.
  6. eβ > 1이면 오즈 증가, eβ < 1이면 오즈 감소다.
