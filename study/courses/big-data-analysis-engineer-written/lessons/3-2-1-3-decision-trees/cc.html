🎯 2. 분할 기준 — 어떤 질문이 가장 잘 나누는가?

좋은 분할은 자식 노드가 더 순수해지는 분할이야. 뒤죽박죽 섞인 상태를 같은 종류끼리 모으는 방향으로 바꾸는 거지.

분할 전 · 불순도 높음
O X O X O X
→
좋은 분할 후 · 불순도 낮음
O O O
X X X

엔트로피와 정보이득 — ID3

엔트로피는 클래스가 얼마나 섞여 있는지를 나타내는 불순도 지표야. 노드가 완전히 한 종류라면 엔트로피는 0이고, 여러 클래스가 비슷한 비율로 섞일수록 커진다.

Entropy = −Σ pᵢ log₂ pᵢ

분할 전 엔트로피에서 분할 후 자식 노드의 가중 엔트로피를 빼면 정보이득 Information Gain이 된다. 정보이득이 클수록 좋은 분할이야.

ID3 → 정보이득

정보이득비 — C4.5

정보이득은 범주가 아주 많은 변수를 지나치게 선호할 수 있어. 고객번호처럼 각 값이 거의 고유하면 데이터를 쉽게 순수하게 나눌 수 있지만 예측 규칙으로서는 별 의미가 없지.

C4.5는 이런 편향을 보정하기 위해 정보이득비 Gain Ratio를 사용한다.

Gain Ratio = Information Gain / Split Information
C4.5 → 정보이득비

지니지수 — CART

지니지수도 불순도를 측정해. 하나의 클래스만 남으면 0이고, 클래스가 섞일수록 커진다. CART는 분할 뒤 지니 불순도가 작아지는 방향을 선택한다.

Gini = 1 − Σ pᵢ²
CART → 지니지수 기본적으로 이진 분할

카이제곱 — CHAID

CHAID는 범주형 변수 사이의 관계를 통계적으로 판단하며 대표적으로 카이제곱 검정을 이용한다. CART와 달리 한 노드가 두 갈래보다 많이 나뉘는 다지 분할도 가능하다.

CHAID → 카이제곱 → 다지 분할 가능
알고리즘 대표 분할 기준 시험 핵심
ID3정보이득엔트로피 감소
C4.5정보이득비정보이득의 편향 보완
CART지니지수이진 분할
CHAID카이제곱 검정다지 분할 가능

🌱 3. 나무 생성 — 어떻게 자라나는가?

전체 데이터에서 가장 좋은 분할을 고르고, 만들어진 각 자식 노드에서도 다시 최적 분할을 찾는다. 이 과정을 반복하는 것이 재귀적 분할 Recursive Partitioning이야.

01
전체 데이터
02
최적 변수 탐색
03
데이터 분할
04
하위 노드 반복
05
종료 조건

언제 멈출까?

계속 분할하면 훈련 데이터 하나하나에 맞춘 거대한 나무가 될 수 있어. 훈련 데이터에는 아주 잘 맞지만 새로운 데이터에는 약해지는 과적합 Overfitting이 생긴다.

대표적인 종료 조건
  • 노드의 데이터가 너무 적음
  • 최대 깊이에 도달
  • 분할로 얻는 개선이 너무 작음
  • 노드가 이미 충분히 순수함
숨은 위험
나무가 깊다고 무조건 좋은 건 아니다.

복잡도가 지나치면 데이터의 일반적 구조가 아니라 잡음까지 학습한다.

✂️ 4. 가지치기 — 왜 잘 만든 가지를 다시 자를까?

훈련 데이터를 정확히 설명하는 것과 새로운 데이터까지 잘 예측하는 것은 달라. 가지치기의 목적은 모델 복잡도를 줄여 과적합을 억제하고 일반화 성능을 높이는 것이야.

Pre-pruning

사전 가지치기

나무가 만들어지는 도중 성장을 제한한다. 최대 깊이, 최소 노드 크기, 최소 개선량 등을 기준으로 더 이상 분할하지 않는다.

성장 → 정지
Post-pruning

사후 가지치기

우선 나무를 충분히 성장시킨 다음, 성능에 도움이 되지 않는 가지를 제거한다.

큰 나무 생성 → 불필요한 가지 제거
시험 핵심
가지치기 → 과적합 방지 → 일반화 성능 향상

🔍 5. 결과 해석 — 완성된 나무를 어떻게 읽을까?

의사결정나무의 강점은 결과가 규칙 형태로 보인다는 거야. 루트에서 리프까지의 한 경로를 그대로 IF–THEN 규칙으로 번역할 수 있다.

트리 경로
방문횟수 ≥ 5 ?
↓ Yes
소득 = 높음 ?
↓ Yes
구매 = O
IF–THEN 규칙
IF 방문횟수 ≥ 5
AND 소득 = 높음
THEN 구매 = O

상위 노드와 변수 중요도

루트나 상위 노드에 등장한 변수는 많은 데이터를 먼저 나누므로 중요성을 직관적으로 파악하는 단서가 된다. 다만 트리 위쪽에 있다는 사실만으로 정확한 변수 중요도 수치가 결정되는 것은 아니다.

리프 노드의 의미

분류에서는 구매·비구매, 정상·이상 같은 클래스를 예측하고, 회귀에서는 집값처럼 연속형 수치를 예측할 수 있다.

CART = Classification And Regression Tree

🎓 8. 합격선 개념

분할 기준은 좋은 질문을 고르는 기준이다. 자식 노드의 불순도가 줄어드는 방향으로 나눈다.
ID3–정보이득, C4.5–정보이득비, CART–지니지수, CHAID–카이제곱의 대응을 구별한다.
나무가 지나치게 성장하면 과적합될 수 있으며, 사전·사후 가지치기로 복잡도를 조절한다.
완성된 트리는 루트에서 리프까지의 경로를 IF–THEN 규칙으로 읽을 수 있다.
최종 연결
분할 → 성장 → 과적합 가능성 → 가지치기 → 결과 해석
