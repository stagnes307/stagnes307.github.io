3-2-1-4. 인공신경망

#빅데이터분석기사 #필기 #분석기법적용 #인공신경망 #ANN

인공신경망(Artificial Neural Network, ANN)은 입력값을 여러 층의 뉴런이 가중치와 활성화 함수를 이용해 변환하면서 출력값을 만드는 모형이야. 필기에서는 수학적 계산보다 신경망 구조 → 학습 과정 → 모형 적용을 하나의 과정으로 연결하는 게 핵심이야.

STRUCTURE

🧩 1. 신경망 구조

가장 먼저 뉴런 하나부터 보면 전체 신경망이 쉬워져. 뉴런은 여러 입력값을 받아 각각에 중요도를 부여하고, 하나의 값을 만들어 다음 층으로 넘겨.

입력값→ 가중합→ 활성화→ 출력
z = w₁x₁ + w₂x₂ + ··· + wₙxₙ + b    →    y = f(z)

가중치(weight)는 각 입력이 결과에 얼마나 큰 영향을 주는지를 나타내고, 편향(bias)은 입력값과 별개로 뉴런의 활성화 기준을 이동시키는 값이야.

가중치 = 입력의 영향력 조절
편향 = 판단 기준의 위치 조절

🏗️ 2. 세 개의 층

입력층

분석에 사용할 데이터를 신경망에 전달해. 고객 이탈 예측이라면 가입기간, 이용금액, 문의횟수 같은 변수가 들어갈 수 있어.

은닉층

가중치와 활성화 함수로 입력을 반복 변환하며 복잡한 패턴을 학습해. 은닉층이 여러 개인 신경망을 심층신경망(DNN)이라고 해.

출력층

최종 예측값을 만들어. 회귀라면 연속값, 이진 분류라면 두 범주, 다중 분류라면 여러 범주의 결과가 나와.

Deep Learning의 ‘Deep’은 은닉층이 깊다는 의미로 연결해서 기억하면 좋아.

⚡ 3. 활성화 함수

가중합만 반복하면 여러 층을 쌓아도 결국 선형적인 변환에 머물러. 현실 데이터의 복잡한 관계를 표현하기 위해 뉴런에 비선형성을 넣는 것이 활성화 함수야.

함수범위 / 형태시험 연결
Sigmoid0 ~ 1확률 표현, 이진 분류 출력층과 연결
Tanh-1 ~ 10을 중심으로 한 출력
ReLUmax(0, x)음수는 0, 양수는 그대로 · 은닉층에서 널리 사용

Sigmoid는 값이 매우 크거나 작을 때 기울기가 거의 0이 되면서 기울기 소실(vanishing gradient) 문제가 생길 수 있어.

LEARNING LOOP

🎯 4. 학습 과정 — 신경망이 ‘배운다’는 것

본질은 예측값과 실제값의 차이가 작아지도록 가중치와 편향을 수정하는 과정이야.

순전파

입력층에서 출력층 방향으로 현재 가중치를 이용해 예측값을 계산해.

손실 함수

예측값과 실제값의 차이를 수치화해. 신경망 학습의 목표는 결국 손실 최소화야.

역전파

출력의 오차를 이전 층으로 거꾸로 전달하면서 각 가중치가 오차에 얼마나 영향을 줬는지 계산해.

🧭 5. 경사하강법

역전파로 손실 함수의 기울기를 계산하면 손실이 감소하는 방향으로 가중치를 조금씩 이동시킬 수 있어. 대표적인 방법이 경사하강법(Gradient Descent)이야.

wnew = wold − η · ∂L/∂w

학습률 η는 한 번에 얼마나 큰 폭으로 가중치를 갱신할지를 결정해. 너무 크면 최솟값을 지나쳐 불안정할 수 있고, 너무 작으면 학습이 지나치게 느려질 수 있어.

🔄 6. Epoch와 Batch

Epoch

전체 학습 데이터를 한 번 모두 사용하여 학습한 것. 전체 데이터를 다시 학습하면 다음 epoch가 돼.

Batch

전체 데이터를 한꺼번에 처리하지 않고 일정 크기로 나눈 한 번의 데이터 묶음.

Epoch = 전체 데이터 학습 횟수
Batch = 한 번에 처리하는 데이터 묶음

⚠️ 7. 과적합

훈련 데이터를 지나치게 학습하면 훈련 성능은 좋아도 새로운 데이터의 성능이 떨어지는 과적합(Overfitting)이 발생할 수 있어.

Dropout

일부 뉴런을 무작위로 제외하여 특정 뉴런에 대한 과도한 의존을 줄여.

Early Stopping

검증 성능이 더 좋아지지 않을 때 적절한 시점에서 학습을 중단해.

Regularization

가중치가 지나치게 커지는 것을 억제해 모형의 복잡도를 제한해.

APPLICATION

🔧 8. 모형 적용

인공신경망은 특정 분석 문제 하나만을 위한 알고리즘이 아니야. 출력층과 손실 함수 등을 목적에 맞게 구성해 분류와 회귀 모두에 사용할 수 있어.

분류

고객 이탈 여부, 카드 부정거래, 질병 여부, 이미지 분류처럼 범주를 예측해.

회귀

매출, 주택가격, 수요량처럼 연속적인 숫자를 예측해.

복잡한 비선형 관계를 학습할 수 있고 대규모 데이터에서 높은 예측력을 보일 수 있지만, 많은 데이터와 계산량을 요구할 수 있고 내부 구조의 해석이 어려워 블랙박스 모형과 연결해서 설명하기도 해.

🔗 9. 세 덩어리를 하나로 연결하기

01

신경망 구조

입력층 → 은닉층의 가중치·편향·활성화 함수 → 출력층에서 예측값 생성

02

학습 과정

손실 계산 → 역전파 → 경사하강법 등의 최적화 → 가중치 수정 → 여러 epoch 반복

03

모형 적용

학습된 가중치로 새로운 데이터에 대해 분류 또는 회귀 예측 수행

인공신경망은 여러 층의 뉴런이 가중치와 활성화 함수를 이용해 입력을 출력으로 변환하고, 손실을 역전파하여 가중치를 반복적으로 조정함으로써 분류나 회귀에 사용할 수 있는 모형이다.
