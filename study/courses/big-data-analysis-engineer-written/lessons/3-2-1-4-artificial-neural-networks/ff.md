🧠 [가중치가 답을 만드는 과정] 3-2-1-4. 인공신경망

#빅데이터분석기사 #필기 #분석기법적용 #인공신경망 #ANN

인공신경망(Artificial Neural Network, ANN)은 입력값을 여러 층의 뉴런이 가중치와 활성화 함수를 이용해 변환하면서 출력값을 만드는 모형이야.

빅데이터분석기사 필기에서는 수학적으로 깊게 계산하기보다는,

① 신경망이 어떻게 생겼는지 → ② 어떻게 학습하는지 → ③ 실제 분석에 어떻게 적용하는지

이 세 축을 연결해서 이해하는 게 핵심이야.

이번 범위는 정확히 이렇게 잡을게.

3-2. 분석기법 적용 → 3-2-1. 분석기법 → 3-2-1-4. 인공신경망

신경망 구조 → 학습 과정 → 모형 적용

참고로 지금 학습 상태는 나중에 **저장**이라고 입력하면 이어서 공부할 수 있게 보존할 수 있어.

가중치 = 입력의 영향력 조절
편향 = 판단 기준의 위치 조절

🏗️ 2. 신경망의 층 — 입력층, 은닉층, 출력층

인공신경망은 뉴런을 하나만 쓰지 않고 여러 개를 층(layer)으로 연결해.

기본 구조는 다음과 같아.

입력층(Input Layer)
↓
은닉층(Hidden Layer)
↓
출력층(Output Layer)

입력층

분석에 사용할 데이터를 받아들이는 층이야.

예를 들어 고객 이탈 예측이라면

가입기간, 이용금액, 문의횟수, 사용빈도

같은 변수들이 입력될 수 있어.

입력층은 주로 데이터를 신경망에 전달하는 역할을 해.

은닉층

인공신경망의 핵심이야.

입력값을 가중치와 활성화 함수를 통해 반복적으로 변환하면서 데이터 안의 복잡한 패턴을 학습해.

은닉층이 여러 개 있는 신경망을 일반적으로 심층신경망(DNN, Deep Neural Network)이라고 해.

즉,

Deep Learning의 'Deep'은 은닉층이 깊다는 의미

라고 잡으면 좋아.

출력층

최종 예측값을 만드는 층이야.

문제 종류에 따라 출력 형태가 달라져.

분석 목적	출력 예
회귀	주택가격 5.2억 원
이진 분류	정상 / 부도
다중 분류	A / B / C 등급

여기서 중요한 점 하나.

출력층의 구성과 활성화 함수는 분석 문제의 형태에 따라 달라진다.

이건 뒤의 모형 적용에서 다시 연결할게.

⚡ 3. 활성화 함수 — 왜 그냥 가중합만 사용하지 않을까?

🎯 4. 학습 과정 — 신경망이 '배운다'는 것은 무엇인가?

신경망 학습을 어렵게 생각할 필요 없어.

본질은 하나야.

예측값과 실제값의 차이가 작아지도록 가중치와 편향을 수정하는 과정

흐름을 먼저 잡자.

① 가중치 초기화

⬅️ 7. 역전파 — 어디를 얼마나 고칠지 알아내기

순전파가

입력 → 출력

방향이었다면, 역전파(Backpropagation)는 이름 그대로 반대 방향이야.

출력 오차 → 이전 층 → 더 이전 층

으로 전파하면서 각 가중치가 오차에 얼마나 영향을 주었는지 계산해.

쉽게 말해서 시험에서 틀렸을 때 단순히

"20점 틀렸네."

에서 끝나는 게 아니라,

"어떤 문제에서, 어떤 판단 때문에 점수를 잃었지?"

를 거꾸로 추적하는 것과 비슷해.

신경망도 손실값만 아는 것으로는 부족해.

각 가중치를 어느 방향으로 얼마나 수정해야 손실이 줄어드는지 알아야 해.

그 정보를 계산하는 핵심 과정이 역전파야.

🔄 9. Epoch와 Batch — 몇 번, 얼마나 나눠 학습할까?

이 용어들도 같이 정리해 두는 게 좋아.

Epoch

전체 학습 데이터를 한 번 모두 사용하여 학습한 것을 1 epoch라고 해.

예를 들어 학습 데이터가 10,000개라면 10,000개 전체를 한 번 학습하면 1 epoch.

이를 다시 전체 반복하면 2 epoch야.

Batch

전체 데이터를 한꺼번에 처리하지 않고 일정 크기로 나눈 단위야.

예를 들어 데이터 10,000개를 batch size 100으로 설정하면 100개씩 나눠 처리하게 돼.

따라서 둘의 관계는:

Epoch = 전체 데이터 학습 횟수
Batch = 한 번에 처리하는 데이터 묶음

⚠️ 10. 과적합 — 학습을 오래 하면 무조건 좋아질까?

그렇지 않아.

훈련 데이터를 지나치게 학습하면 과적합(Overfitting)이 발생할 수 있어.

훈련 데이터에서는 성능이 매우 좋지만 새로운 데이터에서는 성능이 떨어지는 상태야.

즉,

훈련 성능 ↑

인데

일반화 성능 ↓

가 될 수 있어.

신경망은 파라미터가 많기 때문에 특히 과적합에 주의해야 해.

대표적인 대응 방법으로는 다음이 있어.

Dropout

학습 과정에서 일부 뉴런을 무작위로 제외시키는 방법이야.

특정 뉴런에 지나치게 의존하는 것을 줄여 과적합을 완화할 수 있어.

Early Stopping

검증 데이터의 성능이 더 이상 좋아지지 않으면 학습을 중단해.

즉,

더 오래 학습하는 것이 아니라 적절한 시점에서 멈추는 것

이 핵심이야.

Regularization

가중치가 지나치게 커지는 것을 억제해 모형의 복잡도를 제한하는 방식이야.

출력층과 손실 함수 등을 목적에 맞게 구성해서 여러 문제에 적용할 수 있어.

🧠 12. 신경망은 왜 강력한가?

전통적인 통계 모형은 분석자가 변수 사이 관계를 어느 정도 명시적으로 설정하는 경우가 많아.

반면 신경망은 여러 층을 거치면서 데이터에서 복잡한 관계와 표현을 학습할 수 있어.

그래서 특히

이미지

음성

자연어

복잡한 비선형 데이터

처럼 관계가 복잡한 문제에서 강력할 수 있어.

다만 장점만 있는 건 아니야.

장점

복잡한 비선형 관계를 학습할 수 있고, 대규모 데이터에서 높은 예측력을 보일 수 있어.

단점

많은 데이터와 계산량을 요구할 수 있고, 하이퍼파라미터 조정도 필요해.

또한 내부에 많은 가중치와 뉴런이 있기 때문에 단순한 모형보다 결과의 해석이 어렵다는 단점이 있어.

이 때문에 신경망을 흔히 블랙박스 모형과 연결해서 설명하기도 해.

🔗 13. 세 덩어리를 하나의 흐름으로 연결하기

이제 시험에서 가장 중요한 연결을 만들어 보자.

신경망 구조

입력층에서 데이터를 받고
→ 은닉층에서 가중치 + 편향 + 활성화 함수로 변환하고
→ 출력층에서 예측값을 만들어.

학습 과정

예측값을 실제값과 비교해서
→ 손실 함수로 오류를 계산하고
→ 역전파로 각 가중치의 책임을 계산한 뒤
→ 경사하강법 등의 최적화 방법으로 가중치를 수정해.

이 과정을 여러 epoch 동안 반복해.

모형 적용

학습된 가중치를 이용해 새로운 데이터에 대해

→ 분류
또는
→ 회귀

예측을 수행해.

즉 전체를 한 문장으로 표현하면:

인공신경망은 여러 층의 뉴런이 가중치와 활성화 함수를 이용해 입력을 출력으로 변환하고, 손실을 역전파하여 가중치를 반복적으로 조정함으로써 분류나 회귀에 사용할 수 있는 모형이다.

이 문장이 이해되면 이번 범위의 뼈대는 잡힌 거야.

🎯 필기시험에서 갈라야 할 핵심 구분

시험에서는 비슷한 용어를 붙여놓고 구분시키는 경우가 많아.

개념	무엇을 뜻하나
가중치	입력의 영향력
편향	활성화 기준 조정
활성화 함수	비선형성 부여
순전파	입력 → 출력 계산
손실 함수	예측 오류 측정
역전파	출력 오차를 뒤로 전달하여 기울기 계산
경사하강법	손실을 줄이는 방향으로 파라미터 갱신
학습률	한 번에 갱신하는 크기
Epoch	전체 학습 데이터를 모두 학습한 횟수
Batch	한 번에 학습하는 데이터 묶음
Dropout	일부 뉴런을 무작위 제외하여 과적합 완화
Early Stopping	검증 성능 악화 전에 학습 중단

특히 다음 세 쌍은 꼭 분리해 둬.

순전파 ≠ 역전파

손실 함수 ≠ 최적화 알고리즘

Epoch ≠ Batch

이 구분만 단단해도 객관식에서 꽤 많은 함정을 피할 수 있어.
