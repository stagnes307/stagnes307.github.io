MAXIMUM MARGIN

📏 1. 최대 마진 — 왜 경계에서 멀어져야 할까?

두 종류의 데이터를 나누는 선은 여러 개 그을 수 있어. 그런데 SVM은 아무 선이나 선택하지 않아. 양쪽 집단에서 가장 가까운 데이터까지의 거리가 가장 큰 선을 고른다.

마진(Margin)

결정경계와 가장 가까운 데이터 사이의 여유 공간이 마진이야. SVM의 목표는 이 마진을 최대화하는 것. 훈련 데이터에 아슬아슬하게 붙은 경계보다 여유 있는 경계가 새로운 데이터에도 안정적으로 작동할 가능성이 높아.

서포트 벡터(Support Vector)

결정경계에 가장 가까이 위치하여 마진을 결정하는 데이터 포인트야. 모든 데이터가 경계를 똑같이 결정하는 게 아니라 경계 근처의 핵심 관측값이 경계를 지탱한다.

SVM → 마진 최대화 → 마진을 결정하는 점 = 서포트 벡터

경계 선택의 핵심

KERNEL TRICK

🌀 2. 커널 — 직선으로 나눌 수 없다면?

데이터가 항상 직선 하나로 예쁘게 나뉘지는 않아. 현재 공간에서 선형 분리가 어렵다면 데이터를 더 높은 차원의 공간에서 분리할 수 있도록 다룬다.

원래 공간

직선 하나로는 분리하기 어렵다.

→

고차원 특징 공간

새 공간에서는 선형 경계로 분리 가능.

커널 트릭(Kernel Trick)

실제로 모든 데이터를 고차원 좌표로 하나하나 변환할 필요는 없어. 커널 함수로 고차원 공간에서의 내적을 효율적으로 계산하는 것이 커널 트릭이야.

MODEL CONTROL

⚙️ 4. 모형 설정 — C가 하는 일

실제 데이터에는 이상치나 겹치는 관측값이 있어. 모든 점을 완벽하게 맞추려 하면 경계가 지나치게 복잡해질 수 있지. 그래서 SVM은 마진을 크게 만드는 것과 훈련 데이터의 오분류를 줄이는 것 사이에서 타협한다. 그 대표적인 조절값이 C야.

C ↑

오분류에 엄격

오분류에 대한 벌점을 크게 준다. 훈련 데이터를 최대한 정확하게 분류하려 한다.

오분류 허용 ↓ → 마진이 좁아질 수 있음 → 과적합 위험 ↑

C ↓

오분류에 관대

몇 개의 데이터를 틀리더라도 상대적으로 넓은 마진을 허용할 수 있다.

오분류 허용 ↑ → 넓은 마진 가능 → 일반화 중시

RBF PARAMETER

🎛️ 5. γ도 같이 보자

RBF 커널에서 γ는 개별 데이터 포인트의 영향이 얼마나 가까운 영역에 집중되는지와 연결하면 편해.

γ ↑

영향 범위 ↓ → 데이터에 민감 → 복잡한 결정경계 → 과적합 위험 증가

γ ↓

영향 범위 ↑ → 부드러운 결정경계 → 지나치면 과소적합 가능

C와 γ를 한 장면으로

C
오분류 허용훈련오차에 엄격
γ
넓은 영향국소적 영향
RBF-SVM에서는 보통 C와 γ를 함께 튜닝해. 둘 다 지나치게 공격적인 방향으로 가면 훈련자료에 지나치게 민감한 경계가 만들어질 수 있다는 그림을 잡아두면 좋아.

INTERPRETATION

🔍 6. 모형 해석 — 무엇을 보고 해석할까?

선형 SVM

wᵀx + b = 0

w는 경계의 방향을 결정하고, b는 위치와 관련돼.

서포트 벡터의 의미

모형의 결정경계를 형성하는 데 중요한 것은 경계 근처의 서포트 벡터야. 그래서 어떤 관측값이 경계를 결정하는 핵심 관측값인가?라는 관점이 중요해.

특히 비선형 커널 SVM은 회귀계수처럼 변수 효과를 직접 읽는 방식의 해석은 상대적으로 어렵다.

EXAM MEMORY PATH

🧠 시험용으로 한 번에 연결하기

① 데이터를 분류해야 한다.
② 가장 여유 있는 결정경계를 찾는다.
③ 그 여유 공간이 마진이다.
④ 마진을 결정하는 가까운 관측값이 서포트 벡터다.
⑤ 선형으로 안 나뉘면 커널을 이용한다.
⑥ C로 오분류 벌점과 마진 사이의 균형을 조절한다.
⑦ RBF에서는 γ도 결정경계의 복잡도에 영향을 준다.
