🧭 먼저 큰 그림

연관성분석(Association Analysis)은 여러 항목 가운데 함께 발생하는 경향을 찾아내는 분석기법이야. 가장 유명한 예가 장바구니 분석이지. “빵을 산 고객이 우유도 같이 사는가?”라는 질문에서 출발해.

🧩 연관규칙: X → Y는 무슨 뜻일까?

연관규칙은 보통 다음처럼 표현해.

X → Y
  • X: 조건부, 선행항(antecedent)
  • Y: 결과부, 후행항(consequent)

예를 들어 {빵} → {우유}는 “빵을 구매한 거래에서는 우유도 함께 구매되는 경향이 있다”는 규칙이야.

방향이 있다고 해서 인과관계는 아니야.
빵 → 우유라고 썼다고 해서 “빵을 샀기 때문에 우유를 샀다”는 뜻은 아니야. 연관분석은 기본적으로 동시발생 관계를 찾는 분석이지, 원인과 결과를 증명하는 분석은 아니야.

MARKET BASKET SCENE

📦 하나의 예제로 세 지표를 한 번에 잡자

거래가 총 100건 있다고 해보자. 빵 구매 40건, 우유 구매 50건, 빵과 우유 동시 구매 30건이야. 우리가 볼 규칙은 빵 → 우유.

전체 거래

100

빵 구매 X

40

빵 ∩ 우유

30

SUPPORT

📊 지지도

전체 거래 가운데 X와 Y가 동시에 나타난 비율이야.

Support = P(X ∩ Y)
30 / 100 = 0.30

즉 30%. 해당 규칙이 데이터 전체에서 얼마나 자주 등장하는지를 보여줘. 지지도가 너무 낮으면 흥미로워 보여도 실제 발생 사례가 거의 없을 수 있어.

CONFIDENCE

🎯 신뢰도

X가 발생한 거래만 놓고 그중 Y도 발생한 비율을 봐.

Confidence = P(Y | X)
30 / 40 = 0.75

즉 빵을 구매한 거래의 75%에서 우유도 구매했다는 뜻이야. 분모가 전체가 아니라 X라는 게 핵심.

LIFT

⚖️ 향상도

X가 있을 때 Y가 평소보다 정말 더 잘 나타나는지 비교해.

Lift = Confidence / Support(Y)
0.75 / 0.50 = 1.5

빵 구매자는 일반적인 우유 구매율보다 우유를 더 구매하는 경향을 보인다고 해석할 수 있어.

🚦 향상도 해석은 반드시 1을 기준으로 해

Lift > 1

양의 연관

X가 나타날 때 Y가 평소보다 더 잘 나타남.

Lift = 1

독립

X와 Y 사이에 특별한 연관이 없음.

Lift < 1

음의 연관

X가 나타날 때 Y가 평소보다 덜 나타남.

시험에서는 “향상도 1 = 독립”을 바로 떠올릴 수 있어야 해.

🔍 세 지표를 하나의 질문으로 구분하기

📊
지지도

전체 중 X와 Y가 같이 나온 비율은?

Support = (X ∩ Y) / 전체

🎯
신뢰도

X가 나온 것 중 Y도 나온 비율은?

Confidence = (X ∩ Y) / X

⚖️
향상도

X가 있을 때 Y가 평소보다 얼마나 더 잘 나타나는가?

Lift = Confidence(X → Y) / Support(Y)

🔄 방향을 바꾸면 무엇이 달라질까?

X → Y와 Y → X에서 지지도는 둘 다 X와 Y의 동시 등장 비율이므로 같아. 하지만 신뢰도는 각각 P(X)와 P(Y)가 분모가 되기 때문에 달라질 수 있어.

Confidence(빵 → 우유)

30 / 40 = 0.75

Confidence(우유 → 빵)

30 / 50 = 0.60

지표방향을 바꾸면
지지도동일
신뢰도달라질 수 있음
향상도동일

🧠 규칙 해석: 숫자가 높다고 무조건 좋은 규칙은 아니다

A → B의 신뢰도가 90%라고 해보자. 언뜻 좋은 규칙처럼 보이지? 하지만 B 자체가 전체 거래의 95%에서 발생한다면,

Lift = 0.90 / 0.95 ≈ 0.947

향상도가 1보다 작아. 즉 A가 발생한 경우 B의 발생 가능성이 평소보다 오히려 조금 낮은 셈이야. 그래서 하나의 지표만 보고 규칙을 판단하면 안 돼.

STEP 01

지지도로 빈도를 본다

실제 데이터에서 충분히 자주 발생하는가?

STEP 02

신뢰도로 조건을 본다

X가 발생했을 때 Y가 얼마나 자주 발생하는가?

STEP 03

향상도로 비교한다

그 발생률이 Y의 평소 발생률보다 정말 높은가?

🧮 공식은 따로 외우기보다 분모를 이해해

Support(X → Y) = (X ∩ Y) / 전체
↓
Confidence(X → Y) = (X ∩ Y) / X
↓
Lift(X → Y) = Confidence(X → Y) / Support(Y)

앞의 두 식은 분자 X ∩ Y가 같아. 달라지는 건 비교 기준인 분모야. 전체와 비교하면 지지도, X와 비교하면 신뢰도, Y의 기본 발생률과 비교하면 향상도.

🛒 최소 지지도·최소 신뢰도와 Apriori

항목이 많아지면 만들 수 있는 규칙의 수가 폭발적으로 늘어나. 그래서 최소 지지도와 최소 신뢰도 같은 기준으로 의미가 약한 규칙을 제거해.

APRIORI CORE IDEA

어떤 항목집합이 빈번하지 않다면, 그 항목집합을 포함하는 더 큰 집합도 빈번할 수 없다.

{A, B} 최소 지지도 미달 → {A, B, C} 탐색 불필요

필기에서 연관분석과 Apriori가 연결되면 빈발항목집합(frequent itemset)과 최소 지지도를 함께 떠올리면 돼.

⚠️ 시험에서 잘 걸리는 함정

신뢰도 = 전체 거래 기준?

아니야. 신뢰도는 P(Y|X)이므로 X가 발생한 거래가 분모야.

지지도가 높으면 연관성이 강하다?

반드시 그렇지 않아. 두 항목 자체가 흔하면 함께 많이 나타날 수도 있어.

신뢰도가 높으면 좋은 규칙?

후행항 Y 자체가 흔하면 신뢰도도 자연스럽게 높아질 수 있어. 향상도를 함께 봐야 해.

향상도 0 = 독립?

아니야. 향상도 1이 독립이야.

X → Y는 인과관계?

아니야. 연관규칙은 연관성을 보여주지 인과관계를 증명하지 않아.
