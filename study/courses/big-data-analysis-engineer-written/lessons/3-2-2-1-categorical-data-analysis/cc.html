01 / DATA STRUCTURE

🧩 범주형 자료 구조

범주형 자료는 관측값이 어떤 범주(category)에 속하는지를 나타내는 자료야. 숫자의 크기 자체보다 “어느 집단에 속했는가”가 핵심이지.

고객성별구매 여부만족도
A남구매만족
B여미구매보통
C여구매만족

명목형 — 순서가 없다

성별, 혈액형, 지역, 구매 여부처럼 범주 사이에 크고 작음의 순서가 없는 자료야.

순서형 — 순서는 있다

불만족 → 보통 → 만족, 하 → 중 → 상처럼 순서는 있지만 범주 사이의 간격이 동일하다고 볼 수는 없어.

순서가 있다는 것과 간격까지 동일하다는 것은 다른 이야기야.

03 / OBSERVED VS EXPECTED

🧮 관측도수와 기대도수

OBSERVED

관측도수 O

실제 데이터에서 관측된 빈도. 남성·구매 칸은 40명.

EXPECTED

기대도수 E

두 변수가 서로 독립이라고 가정했을 때 기대되는 빈도.

FORMULA

E = (행 합계 × 열 합계) ÷ 전체 합계
100 × 110 ÷ 200 = 55

실제 관측

40

O

↔

독립이라면 기대

55

E

O와 E가 비슷하면 독립이라는 설명과 잘 맞고,
O와 E의 차이가 커질수록 독립이라는 가정이 흔들린다.

χ² = Σ (O − E)² / E

04 / HYPOTHESIS TEST

🔍 분할표 분석 — 독립인지 검정한다

귀무가설 H₀

두 범주형 변수는 서로 독립이다.

예: 성별과 구매 여부에는 관련성이 없다.

대립가설 H₁

두 범주형 변수는 서로 독립이 아니다.

예: 성별과 구매 여부에는 관련성이 있다.

O−E 차이 증가
→
χ² 증가
→
p-value 감소
→
H₀ 기각

06 / INTERPRETATION

🧠 p-value 결과 해석

p = 0.012p < 0.05

H₀ 기각 → 통계적으로 유의한 관련성이 있다.

p = 0.31p ≥ 0.05

H₀를 기각하지 못함 → 관련성이 있다고 볼 충분한 근거가 없다.

“귀무가설을 기각하지 못했다”와 “귀무가설이 참임을 증명했다”는 같은 말이 아니야.

07 / EXAM TRAPS

⚠️ 시험에서 자주 걸리는 함정

범주 코딩 ≠ 수치적 크기

혈액형을 1, 2, 3, 4로 코딩해도 그 평균에 혈액형 자체의 수치적 의미가 생기는 건 아니야.

기대도수 ≠ 실제 관측값

O는 실제 빈도, E는 독립이라는 귀무가설 아래 계산한 빈도야.

유의함 ≠ 관계가 강함

통계적으로 유의한 관련성이 존재한다고 해서 효과의 크기까지 반드시 크다는 뜻은 아니야.
