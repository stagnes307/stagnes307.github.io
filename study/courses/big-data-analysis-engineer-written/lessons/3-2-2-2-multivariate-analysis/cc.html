1. 다변량 구조 — 왜 변수 하나씩 보면 부족할까?

핵심은 변수 사이의 관계야. 공부시간, 출석률, 시험점수가 서로 따로 움직이지 않고 같은 방향으로 움직이는 경향이 있다면, 각각의 값뿐 아니라 이들의 공동 움직임 자체가 중요한 정보가 돼.

2. 주요 분석 접근 — 목적이 다르면 기법도 달라진다

기법 이름을 줄줄 외우면 금방 섞여. 대신 “나는 데이터에서 무엇을 알고 싶은가?”로 분류하면 훨씬 안정적이야.

차원을 줄이고 싶다 → 주성분분석(PCA)

변수가 너무 많고 서로 상관되어 있다면 정보를 최대한 유지하면서 더 적은 수의 새로운 변수로 압축할 수 있어.

X₁, X₂, X₃, …, Xₚ → PC₁, PC₂, …

주성분은 원래 변수들의 선형결합이야. 첫 번째 주성분은 데이터의 변동을 가장 많이 설명하는 방향이고, 두 번째 주성분은 첫 번째와 직교하면서 남은 변동을 최대한 설명하는 방향이 돼.

핵심 목적: 정보 손실을 가능한 줄이면서 차원을 축소한다.

PCA는 변수 중 몇 개를 그냥 골라내는 방법이 아니야. 기존 변수들을 조합해서 새로운 축을 만드는 거야.

숨어 있는 공통 원인을 찾고 싶다 → 요인분석

가격 만족, 품질 만족, 재구매 의향, 추천 의향처럼 관측되는 변수들이 사실 몇 개의 숨은 특성에 의해 영향을 받을 수 있어. 요인분석은 이런 관측변수들의 상관관계를 설명하는 잠재요인을 찾으려 해.

구분PCA요인분석
중심 목적차원 축소잠재요인 탐색
관심전체 변동의 효율적 표현변수 간 공통 관계 설명
결과주성분공통요인

“정보를 압축한다”면 PCA, “잠재적인 공통요인을 찾는다”면 요인분석 쪽으로 먼저 생각하면 돼.

비슷한 관측치를 묶는다 → 군집분석

사전에 정답 집단을 주지 않고 데이터의 유사성 또는 거리를 이용해 비슷한 관측치를 그룹화해.

계층적 군집K-means

집단을 구별한다 → 판별분석

이미 알려진 집단을 잘 구별하는 규칙을 찾는 데 관심이 있어.

군집분석 → 집단을 발견

판별분석 → 알려진 집단을 구별
