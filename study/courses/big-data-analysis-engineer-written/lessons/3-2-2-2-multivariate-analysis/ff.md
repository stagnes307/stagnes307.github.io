#빅데이터분석기사 #필기 #분석기법적용 #고급분석기법 #다변량분석

🧭 먼저 큰 그림부터 잡자

다변량 분석(multivariate analysis)은 여러 변수를 동시에 살펴서 변수들 사이의 관계와 데이터의 전체 구조를 파악하는 분석이야.

예를 들어 사람을 키 하나만 보고 분석하면 단변량 분석이지만,

키 + 몸무게 + 나이 + 소득 + 소비액

을 함께 보면서 어떤 변수들이 같이 움직이는지, 사람들이 어떤 집단으로 나뉘는지, 많은 변수를 몇 개의 핵심 축으로 줄일 수 있는지를 보는 순간 다변량 분석의 영역으로 들어가.

시험에서는 개별 기법의 계산보다 먼저 이 세 층을 구분하면 좋아.

① 다변량 구조 → ② 목적에 맞는 분석 접근 → ③ 결과 해석

🔗 1. 다변량 구조 — 왜 변수 하나씩 보면 부족할까?

핵심은 변수 사이의 관계야.

학생 세 명의 데이터를 생각해보자.

학생	공부시간	출석률	시험점수
A	높음	높음	높음
B	중간	중간	중간
C	낮음	낮음	낮음

세 변수가 서로 따로 움직이지 않고 같은 방향으로 움직이는 경향이 보이지?

변수 간 관계의 출발점

대표적으로 공분산(covariance)과 상관계수(correlation coefficient)를 사용해.

공분산의 부호는 두 변수가 움직이는 방향을 보여줘.

양수 → 대체로 같은 방향

음수 → 대체로 반대 방향

0에 가까움 → 선형적인 공동 움직임이 약함

하지만 공분산은 변수의 측정 단위와 크기에 영향을 받는다는 문제가 있어. 그래서 서로 단위가 다른 변수의 관계 강도를 비교할 때는 표준화된 상관계수가 더 편리해.

상관계수는 보통 -1 ≤ r ≤ 1 범위에서 해석해.

이 행렬이 중요한 이유는 PCA 같은 여러 다변량 기법이 바로 이런 변수들의 공동 구조를 이용하기 때문이야.

⚠️ 시험에서 자주 생기는 오해

상관관계가 강하다 = 인과관계가 있다는 뜻은 아니야.

예를 들어 아이스크림 판매량과 냉방기 사용량이 함께 증가해도 아이스크림이 냉방기 사용을 증가시켰다고 결론 내릴 수 없어. 둘 모두 기온의 영향을 받았을 수 있으니까.

상관은 함께 움직이는 관계를 보여주지만, 그 자체로 원인과 결과를 증명하지 않는다.

이건 꼭 기억해둬.

🧰 2. 주요 분석 접근 — 목적이 다르면 기법도 달라진다

다변량 분석을 외울 때 기법 이름을 줄줄 외우면 금방 섞여.

대신 “나는 데이터에서 무엇을 알고 싶은가?”로 분류하면 훨씬 안정적이야.

차원을 줄이고 싶다 → 주성분분석(PCA)

변수가 너무 많고 서로 상관되어 있다면 정보를 최대한 유지하면서 더 적은 수의 새로운 변수로 압축할 수 있어.

따라서 PCA의 핵심 목적은:

정보 손실을 가능한 줄이면서 차원을 축소한다.

여기서 시험 포인트 하나.

PCA는 변수 중 몇 개를 그냥 골라내는 방법이 아니야. 기존 변수들을 조합해서 새로운 축을 만드는 거야.

숨어 있는 공통 원인을 찾고 싶다 → 요인분석

설문 문항을 생각해보자.

가격 만족, 품질 만족, 재구매 의향, 추천 의향처럼 관측되는 변수들이 사실 몇 개의 숨은 특성에 의해 영향을 받을 수 있겠지.

요인분석은 이런 관측변수들의 상관관계를 설명하는 잠재요인(latent factor)을 찾으려 해.

즉,

관측된 여러 변수 → 그 배후의 공통 요인

을 추론하는 접근이야.

PCA와 요인분석의 경계

둘 다 여러 변수를 적은 수의 요소로 표현해서 헷갈리기 쉬워.

구분	PCA	요인분석
중심 목적	차원 축소	잠재요인 탐색
관심	전체 변동을 효율적으로 표현	변수 간 공통된 관계 설명
결과	주성분	공통요인

시험에서 “정보를 압축한다”면 PCA 쪽, “잠재적인 공통요인을 찾는다”면 요인분석 쪽으로 먼저 생각하면 돼.

비슷한 관측치를 묶고 싶다 → 군집분석

이번에는 변수 자체가 아니라 관측 대상을 묶는 문제야.

고객들의 구매 행동을 바탕으로

고객들→A군, B군, C군

처럼 유사한 고객끼리 그룹화할 수 있어.

핵심은 사전에 정답 집단을 주지 않고 데이터의 유사성 또는 거리를 이용한다는 점이야.

대표적인 접근에는 계층적 군집분석과 K-means 등이 있어.

집단을 구별하고 싶다 → 판별분석

군집분석과 비교해서 기억하면 좋아.

군집분석에서는 원래 집단을 모르는 상태에서 비슷한 대상을 묶지만, 판별분석에서는 이미 알려진 집단을 잘 구별하는 규칙을 찾는 데 관심이 있어.

군집분석: 집단을 발견

판별분석: 알려진 집단을 구별

이 대비는 필기 문제에서 꽤 유용해.

🔍 3. 결과 해석 — 숫자보다 먼저 질문을 찾아라

다변량 분석 결과가 나오면 모든 숫자를 똑같이 볼 필요는 없어.

먼저 그 기법이 무엇을 찾으려 했는가를 되돌아가면 돼.

PCA라면 → 설명된 분산

각 주성분이 원래 데이터의 변동을 얼마나 설명하는지 본다.

예를 들어,

주성분	설명된 분산 비율
PC1	55%
PC2	25%
PC3	12%
PC4	8%

라면 PC1과 PC2만으로 전체 변동의

55%+25%=80%

를 설명한다고 해석할 수 있어.

그리고 각 주성분에 원래 변수들이 얼마나 관련되는지를 살펴보면 그 주성분이 어떤 의미의 축인지 해석할 수 있지.

요인분석이라면 → 요인적재량

요인적재량(factor loading)은 관측변수와 요인의 관련성을 해석하는 중요한 값이야.

예를 들어 어떤 요인에서

서비스 친절도: 높음

직원 전문성: 높음

응대 속도: 높음

의 적재량이 나타난다면, 연구자는 그 공통요인을 서비스 품질 같은 의미로 해석할 수 있겠지.

즉 숫자가 자동으로 요인의 이름을 알려주는 것은 아니고, 높게 적재된 변수들의 공통 의미를 보고 해석하는 거야.

군집분석이라면 → 군집의 특성

단순히 “3개 군집이 나왔다”에서 끝나면 부족해.

각 군집이 어떤 특징을 갖는지 비교해야 해.

예를 들어:

군집 1 → 구매 빈도 높음 + 구매액 높음
군집 2 → 구매 빈도 높음 + 구매액 낮음
군집 3 → 구매 빈도 낮음 + 구매액 낮음

이런 식으로 군집별 프로파일을 읽는 게 결과 해석의 핵심이야.

🧠 시험장에서 기법을 고르는 가장 빠른 기준

문제의 목적어를 잡아.

문제에서 원하는 것	먼저 떠올릴 기법
여러 변수를 소수의 축으로 축소	PCA
관측변수 뒤의 잠재요인 발견	요인분석
비슷한 관측치를 집단화	군집분석
이미 알려진 집단을 구별	판별분석
여러 변수의 공동 움직임 파악	상관·공분산 구조

한 줄로 압축하면,

PCA는 압축, 요인분석은 잠재구조, 군집분석은 발견, 판별분석은 구별.

이 네 단어를 기준축으로 잡아두면 세부 개념이 붙기 시작해.
