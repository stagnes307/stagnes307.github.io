3-2-2-3. 시계열 분석

시계열 분석은 시간 순서가 있는 데이터에서 패턴을 찾아 미래를 예측하는 방법이야. 빅데이터분석기사 필기에서는 복잡한 계산보다 구성요소를 구분하고, 정상성과 모형을 연결하고, ACF·PACF와 잔차 진단의 의미를 해석하는 것이 핵심이야.

전체 흐름
시계열 분해 → 정상성 확인 → 모형 선택 → 추정·예측 → 잔차 진단

🧭 1. 먼저 잡을 핵심 지도

시계열 데이터는 일반적인 회귀 데이터와 중요한 차이가 하나 있어. 관측값의 순서를 마음대로 바꾸면 안 된다.

예를 들어 월별 매출이 100 → 120 → 140 → 130 → 160이라면 이 순서 자체가 정보야. 오늘의 값이 어제의 값과 관계를 가질 수 있기 때문이지. 이런 관계를 자기상관이라고 해.

모형화·예측
어떤 규칙으로 예측하는가?
정상성 · AR · MA · ARMA · ARIMA
결과 진단

🧩 2. 시계열 구성요소

장기적으로 움직이는 방향 — 추세 Trend

시간의 흐름에 따라 전체 수준이 지속적으로 증가하거나 감소하는 현상이야. 예를 들어 연간 가입자가 10만 → 13만 → 17만 → 21만처럼 증가한다면 상승 추세가 있어.

일정한 주기로 반복 — 계절 Seasonality

고정된 주기를 가지고 반복되는 패턴이야. 여름마다 에어컨 판매 증가, 매년 12월 쇼핑 매출 증가, 매주 금요일 배달 주문 증가가 대표적이야.

장기간 오르내리는 변화 — 순환 Cycle

경기 확장과 침체처럼 긴 기간에 걸쳐 나타나는 상승·하락이야. 계절변동과 달리 주기가 일정하지 않을 수 있어.

설명하기 어려운 우연한 움직임 — 불규칙 Irregular

추세·계절·순환으로 설명되지 않는 우발적 변화야. 자연재해, 갑작스러운 파업, 예상 밖 사건 등이 포함될 수 있어.

계절변동 순환변동
주기가 비교적 일정 주기가 일정하지 않을 수 있음
1년·분기·월·요일 등과 연계 경기 등 장기적 요인과 연계
반복 시점을 예상하기 쉬움 반복 시점이 불규칙할 수 있음
시계열 = 추세 + 계절 + 순환 + 불규칙 변동

➕ 3. 가법모형과 승법모형

변동폭이 일정하면 — 가법모형

Yt = Tt + St + It

추세 수준이 높아져도 계절변동의 절대적인 크기가 비슷할 때 잘 맞아.

수준이 커질수록 변동폭도 커지면 — 승법모형

Yt = Tt × St × It

시계열 수준이 커질수록 계절변동의 크기도 비례해서 커질 때 적합해.

시험 판단: 시간이 갈수록 계절 진폭이 커진다면 승법모형, 진폭이 거의 일정하다면 가법모형.

🔬 4. 모형화의 출발점: 정상성

정상성은 시간이 지나도 시계열의 통계적 성질이 크게 변하지 않는 상태라고 보면 돼.

E(Yt) = μ
Var(Yt) = σ²
공분산은 시간 자체보다 시차에 의존

AR, MA, ARMA 같은 전통적인 시계열 모형은 시계열 구조가 시간에 따라 계속 바뀌지 않는다는 전제 위에서 움직여. 그래서 비정상 시계열을 정상 시계열로 바꾸는 작업이 중요해져.

🔧 5. 비정상 시계열을 정상화하는 방법

추세가 있다 → 차분 Differencing

∇Yt = Yt − Yt−1

100, 110, 120, 130을 1차 차분하면 10, 10, 10이 돼. ARIMA의 I는 Integrated이며, 차분을 통해 정상화하는 과정과 연결돼.

분산이 증가한다 → 변환

Zt = log(Yt)

값이 커질수록 변동폭까지 커지는 경우 로그 변환 등으로 분산을 안정화할 수 있어.

계절성이 있다 → 계절 차분

Yt − Yt−s

월별 데이터에서 1년 주기라면 s = 12로 볼 수 있어.

🧠 6. 자기상관과 ACF

자기상관은 현재 값 Yt와 과거 값 Yt−k 사이의 상관관계야. 여기서 k를 시차 lag라고 해.

lag 1
한 시점 전
lag 2
두 시점 전
lag 12
열두 시점 전
ACF: 현재 값과 여러 시점 전 값 사이의 전체적인 자기상관을 보여줘.

🧠 7. PACF는 무엇이 다른가?

PACF는 중간 시차의 영향을 제거하고 두 시점 사이의 직접적인 관계를 보려는 함수야.

ACF

전체적인 상관

PACF

중간 시차 효과를 제거한 직접적인 상관

⚙️ 8. AR 모형

AR은 Autoregressive, 자기회귀야. 현재 값은 과거 자신의 값으로 설명한다.

Yt = c + φ1Yt−1 + εt
AR(p)의 전형적 식별: ACF는 서서히 감소, PACF는 p시차 이후 절단.
기억법: AR → PACF가 칼로 잘린다.

⚙️ 9. MA 모형

MA는 Moving Average지만, 여기서는 단순 이동평균 평활법과 구분해야 해. 시계열 모형의 MA는 현재 값이 과거의 오차항에 의해 설명되는 모형이야.

Yt = μ + εt + θ1εt−1
MA(q)의 전형적 식별: ACF는 q시차 이후 절단, PACF는 서서히 감소.
기억법: MA → ACF가 칼로 잘린다.

🔗 10. ARMA와 ARIMA

ARMA(p,q)

AR과 MA를 결합한 모형. 기본적으로 정상 시계열에 적용해.

ARIMA(p,d,q)

AR + I + MA. 차분을 포함해서 비정상 시계열에 대응해.

파라미터 뜻
pAR 차수
d차분 차수
qMA 차수
ARIMA(2,1,1) = AR 2차 + 1회 차분 + MA 1차.

🗺️ 11. ARIMA 모형 구축 절차

식별 → 추정 → 진단 → 예측

🩺 12. 결과 진단의 핵심: 잔차

et = 실제값 − 예측값

모형이 데이터의 규칙적인 패턴을 잘 설명했다면 잔차에는 더 이상 설명할 구조가 거의 없어야 해. 이상적인 잔차는 백색잡음에 가까워야 해.

평균이 0에 가까움
분산이 일정함
시점 간 자기상관이 없음

🔬 13. 잔차 ACF와 Ljung-Box 검정

잔차에 자기상관이 남아 있는지 ACF로 확인할 수 있어. 이를 통계적으로 검정하는 대표적인 방법이 Ljung-Box 검정이야.

H0: 잔차에 자기상관이 없다
p > 0.05

귀무가설을 기각하기 어려움 → 자기상관 증거가 뚜렷하지 않음.

p < 0.05

귀무가설 기각 → 잔차 자기상관 존재 가능성 → 모형 개선 필요.

p-value가 크다고 모형이 무조건 완벽하다는 뜻은 아니야. 해당 검정에서 잔차 자기상관 문제가 뚜렷하게 발견되지 않았다는 뜻이야.

📐 14. 모형 비교: AIC와 BIC

AIC와 BIC는 적합도만 보는 것이 아니라 모형의 복잡성에도 페널티를 부여해. 후보 모형 비교에서는 일반적으로 AIC/BIC가 작은 모형을 선호해. BIC는 일반적으로 AIC보다 복잡도에 더 강한 벌점을 부과하는 경향이 있어.

🔮 15. 예측 결과를 읽는 법

시계열 예측에서는 하나의 숫자뿐 아니라 예측구간도 함께 볼 수 있어. 미래로 멀리 예측할수록 불확실성이 커져서 예측구간이 넓어지는 경향이 있어.

🧠 16. 시험에서 가장 중요한 연결 관계

정상성 계열

추세 존재 → 비정상 가능성 → 차분 → 정상화

ARMA → 정상 시계열 / ARIMA → 차분을 포함하여 비정상 시계열 대응

ACF·PACF 계열

모형 ACF PACF
AR(p) 점진적 감소 p 이후 절단
MA(q) q 이후 절단 점진적 감소
ARMA(p,q) 점진적 감소 점진적 감소

잔차 계열

좋은 모형 → 패턴을 충분히 설명 → 잔차에는 구조가 없어야 함 → 잔차 ≈ 백색잡음 → 잔차 자기상관 없음 → Ljung-Box에서 일반적으로 유의하지 않은 결과가 바람직

🚨 17. 자주 헷갈리는 함정 정리

계절성 ≠ 순환성

계절성은 일정한 주기, 순환성은 주기가 일정하지 않을 수 있어.

ARIMA의 I ≠ Independent

I는 Integrated. 차분과 연결해야 해.

AR → PACF

AR의 차수는 PACF 절단과 연결.

MA → ACF

MA의 차수는 ACF 절단과 연결.

잔차 자기상관이 크면 좋은 게 아님

모형이 설명하지 못한 시간적 패턴이 남아 있다는 뜻.

AIC/BIC는 작을수록 선호

후보 모형 비교에서 일반적인 판단 기준.

🎯 19. 시험장에서 바로 쓰는 판별 규칙

장기적 증가·감소 → 추세
