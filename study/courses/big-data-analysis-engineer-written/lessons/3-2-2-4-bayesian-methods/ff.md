🧭 먼저 전체 그림부터 잡자

베이지안 기법의 핵심은 사실 한 문장이야.

“데이터를 보기 전에 가지고 있던 믿음을, 데이터를 관측한 뒤 수정한다.”

시험에서는 이 흐름을 잡으면 돼.

사전분포(Prior) → 데이터 관측 → 베이즈 갱신 → 사후분포(Posterior) → 추론

조금 더 정확히 쓰면,

p(θ∣x)=
p(x)
p(x∣θ)p(θ)
	​


여기서 θ는 우리가 알고 싶은 모수, x는 관측 데이터야.

구성	의미	직관
p(θ)	사전분포	데이터를 보기 전의 믿음
p(x∣θ)	가능도	그 모수라면 현재 데이터가 얼마나 그럴듯한가
p(θ∣x)	사후분포	데이터를 본 뒤 수정된 믿음
p(x)	주변가능도	전체 확률을 맞추는 정규화 역할

시험용으로는 먼저 이것만 강하게 기억해.

사후분포 ∝ 가능도 × 사전분포

분모 p(x)는 θ에 관한 분포가 전체적으로 1이 되도록 맞춰주는 역할이라, 모수에 관한 계산에서는 위처럼 비례식으로 자주 표현해.

🧠 1. 사전분포와 사후분포 — 무엇이 ‘전’이고 무엇이 ‘후’일까?
사전분포는 데이터를 보기 전의 정보다

동전을 하나 받았다고 해보자.

우리가 알고 싶은 것은 앞면이 나올 확률

θ

야.

아직 이 동전을 던져보지는 않았지만, 일반적인 동전이라면 θ가 0.5 근처일 거라고 생각할 수 있지.

이처럼 현재 데이터를 관측하기 전에 모수 θ에 대해 가지고 있는 확률분포가 사전분포(prior distribution)야.

중요한 점은 사전분포가 단순히 하나의 숫자가 아니라는 거야.

“앞면 확률은 정확히 0.5다”가 아니라,

“0.5 근처일 가능성이 높지만 다른 값일 수도 있다.”

처럼 모수 자체의 불확실성을 확률분포로 표현하는 거지.

사후분포는 데이터를 본 뒤의 정보다

이제 동전을 실제로 10번 던졌더니 앞면이 8번 나왔다고 해보자.

처음에는 0.5 근처라고 생각했지만, 실제 데이터는 “이 동전의 앞면 확률이 좀 높은 것 아닐까?”라는 정보를 줘.

그러면 기존의 사전분포를 그대로 유지하는 게 아니라 관측된 데이터의 정보를 반영해 수정해야겠지.

그 결과가

p(θ∣x)

즉 사후분포(posterior distribution)야.

따라서 둘의 차이를 이렇게 잡으면 가장 안정적이야.

사전분포
→ 데이터 관측 전 모수에 대한 불확실성

사후분포
→ 데이터 관측 후 모수에 대한 불확실성

🔄 2. 베이즈 갱신 — 데이터가 들어오면 무엇이 변할까?

베이즈 갱신은 새로운 데이터가 들어올 때 기존 믿음을 수정하는 과정이야.

Posterior∝Likelihood×Prior

여기서 흔히 헷갈리는 게 하나 있어.

가능도는 ‘모수가 참일 확률’이 아니다
p(x∣θ)

는 θ가 주어졌을 때 지금 같은 데이터 x가 관측될 가능성을 나타내.

예를 들어,

“앞면 확률이 0.8인 동전이라면 10번 중 8번 앞면이 나오는 데이터는 얼마나 그럴듯한가?”

를 보는 거야.

반대로 우리가 궁극적으로 궁금한 건

p(θ∣x)

즉,

“10번 중 8번 앞면이 관측됐을 때, 앞면 확률 θ는 어떤 값일 가능성이 높은가?”

야.

조건의 방향이 바뀌었지.

p(x∣θ)와 p(θ∣x)를 같은 것으로 생각하면 안 돼.

이 차이가 베이지안 문제에서 굉장히 중요한 경계선이야.

🧪 3. 숫자로 보면 베이즈 갱신이 훨씬 쉽다

동전의 앞면 확률을 θ라고 하자.

사전분포를

θ∼Beta(2,2)

라고 가정해보자.

그리고 실제로 동전을 10번 던져

앞면 8번

뒷면 2번

을 관측했다고 하자.

베르누이 시행의 성공 횟수를 s, 실패 횟수를 f라고 하면 Beta 사전분포에서는

Beta(α,β)→Beta(α+s,β+f)

로 갱신할 수 있어.

따라서

Beta(2,2)→Beta(2+8,2+2)

즉,

θ∣x∼Beta(10,4)
	​


가 돼.

여기서 중요한 의미

처음에는 Beta(2,2)였어.

그런데 성공 8번이라는 증거가 들어오면서 성공 쪽 모수가 증가했고, 실패 2번도 함께 반영됐지.

그래서 사후분포가 Beta(10,4)로 바뀐 거야.

즉 베이즈 갱신은 막연하게 “생각을 수정한다”가 아니라,

기존 정보 + 새로운 데이터 → 갱신된 확률분포

라는 구조를 가진다는 걸 볼 수 있어.

📊 4. 추론 결과 해석 — 베이지안에서는 무엇을 말할 수 있을까?

여기가 필기에서 개념적으로 꽤 중요해.

베이지안 추론에서는 모수 자체를 확률분포로 다룬다.

따라서 사후분포를 얻고 나면

P(a<θ<b∣x)

처럼 모수가 특정 범위에 들어갈 사후확률을 직접 이야기할 수 있어.

신뢰구간과 신용구간을 구분하자

베이지안에서는 보통 신용구간(credible interval)을 사용해.

예를 들어 사후분포를 바탕으로

θ가 0.6~0.9 사이에 있을 사후확률이 95%다.

처럼 해석할 수 있어.

반면 빈도주의의 95% 신뢰구간(confidence interval)은 엄밀하게 같은 뜻이 아니야.

빈도주의에서는 모수는 고정된 값이고 표본을 반복해서 뽑을 때 만들어지는 구간의 장기적 포함률을 이야기해.

따라서 시험에서

“모수가 이 구간 안에 존재할 확률이 95%이다.”

라는 식의 직접적인 확률 해석은 베이지안 신용구간에 더 잘 맞는 표현이야.

⚖️ 6. 사전분포의 영향은 언제 커질까?

사전분포와 데이터가 항상 똑같은 힘을 가지는 건 아니야.

데이터가 적을 때

관측 데이터가 별로 없다면 데이터가 제공하는 정보가 제한적이므로 사전분포의 영향력이 상대적으로 커질 수 있어.

데이터가 많아질 때

데이터가 충분히 축적되면 가능도가 제공하는 정보가 강해져 사후분포가 데이터의 영향을 더 크게 받는 경우가 일반적이야.

그래서 다음 관계를 기억하면 좋아.

적은 데이터 → 사전정보 영향 상대적으로 큼
	​

많은 데이터 → 데이터의 영향 상대적으로 커짐
	​


다만 “데이터가 많으면 사전분포가 무조건 아무 영향도 없다”라고 단정하면 너무 강한 표현이야. 사전분포의 형태와 모델에 따라 달라질 수 있으니까.

🧩 7. 켤레사전분포는 왜 등장할까?

아까 아무렇지 않게

Beta(2,2)→Beta(10,4)

라고 계산했지?

이렇게 계산이 깔끔했던 이유가 있어.

사전분포와 사후분포가 같은 분포족에 속하도록 사전분포를 선택하는 경우가 있는데, 이를 켤레사전분포(conjugate prior)라고 해.

예를 들어

Binomial likelihood+Beta prior

를 사용하면 사후분포도

Beta posterior

가 돼.

즉,

Beta(α,β)+(s successes,f failures)

이면

Beta(α+s,β+f)

가 되는 거야.

계산의 편리성 때문에 전통적인 베이지안 분석에서 중요하게 사용돼.

💡 한 단계 더: 베이지안 추론의 철학

빈도주의와 베이지안의 차이를 너무 복잡하게 외울 필요는 없어.

가장 중요한 출발점은 모수를 어떻게 바라보느냐야.

빈도주의에서는 일반적으로

모수는 고정되어 있지만 알려지지 않은 값

으로 본다.

베이지안에서는

모수에 대한 불확실성을 확률분포로 표현

한다.

그래서 데이터가 들어올 때마다 그 분포를 갱신할 수 있는 거야.

이 관점이 잡히면 사전분포 → 사후분포 → 신용구간이 서로 따로 외울 내용이 아니라 하나의 논리로 연결돼.

🧠 마지막으로 머릿속에 남길 구조

베이지안 기법을 세 문장으로 압축하면 이거야.

① 사전분포
데이터를 보기 전 모수에 대한 불확실성을 나타낸다.

② 베이즈 갱신
사전분포와 데이터의 가능도를 결합하여 사후분포를 얻는다.

p(θ∣x)∝p(x∣θ)p(θ)

③ 사후분포 해석
데이터를 관측한 후 모수에 대해 우리가 알고 있는 불확실성을 나타내며, 추정·신용구간·예측 등의 베이지안 추론에 활용한다.

이 세 문장이 하나의 시간 순서라는 걸 기억하면 암기량이 확 줄어.

참고로 이번 학습 상태는 저장이라고 보내면 그대로 이어갈 수 있게 저장할 수 있어.
