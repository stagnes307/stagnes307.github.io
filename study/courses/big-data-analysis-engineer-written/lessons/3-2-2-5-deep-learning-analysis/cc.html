01
Structure

🧠 심층 신경망 구조 — 왜 굳이 층을 깊게 쌓을까?

신경망의 기본 단위인 뉴런은 입력값 x를 받아 각각 가중치 w를 곱하고 편향 b를 더한 뒤, 활성화 함수를 통과시켜 출력을 만든다.

z = Σ wᵢxᵢ + b
a = f(z)
입력값 x
신경망에 들어오는 데이터
가중치 w
각 입력의 영향력
편향 b
판단 기준을 이동시키는 값
활성화 함수 f
비선형성을 부여
출력 a
다음 층으로 전달되는 값

층이 하나가 아니라 여러 개라면?

전형적인 심층 신경망은 입력층 → 여러 은닉층 → 출력층으로 구성된다. Deep Learning의 ‘Deep’은 이런 다수의 은닉층에서 온다.

깊이가 만드는 것: 계층적 특징 학습

이미지라면 초기 층은 선·경계 같은 단순 특징을, 더 깊은 층은 그것을 조합한 형태·부분, 나아가 더 복잡한 객체 수준의 표현을 학습할 수 있다.

단순한 특징 → 특징의 조합 → 복잡한 표현

활성화 함수가 없다면?

층을 많이 쌓아도 각 층이 선형변환만 수행하면 전체 역시 하나의 선형변환으로 합쳐질 수 있다. 그래서 ReLU 같은 비선형 활성화 함수가 중요하다.

ReLU(x) = max(0, x)

활성화 함수 → 비선형성 부여 → 복잡한 관계 표현 가능

순전파 Forward Propagation

현재 가중치를 사용해 입력으로부터 예측값을 계산한다. 입력 → 은닉층 → 출력의 방향이다.

손실 함수 Loss Function

예측과 실제값 사이의 차이를 수치화한다.

Loss = L(y, ŷ)

학습의 목표 = Loss를 최소화하는 파라미터 찾기

역전파 Backpropagation

각 가중치가 손실에 얼마나 영향을 주었는지 출력층에서 입력층 방향으로 계산한다. 이 과정에서 미분과 연쇄법칙이 사용된다.

w ← w − η ∂L/∂w

η는 학습률(learning rate).

Epoch

전체 학습 데이터를 한 번 학습하는 단위

Batch

한 번의 파라미터 갱신에 사용하는 데이터 묶음

Learning Rate

너무 크면 불안정, 너무 작으면 학습이 느릴 수 있음

03
Generalization

🎯 일반화 — 학습 데이터에서 잘 맞으면 끝일까?

모델의 목적은 학습 데이터를 외우는 것이 아니라 보지 못한 새로운 데이터에서도 좋은 성능을 내는 것이다. 이것이 일반화다.

상태훈련 데이터새로운 데이터
과소적합성능 낮음성능 낮음
적절한 학습성능 높음성능 높음
과적합성능 매우 높음상대적으로 성능 저하
훈련 성능이 가장 높은 모델 = 반드시 가장 좋은 모델은 아니다.
04
Defense

🛡️ 일반화를 높이는 대표적인 방법

Dropout

학습 중 일부 뉴런을 확률적으로 비활성화하여 특정 결합에 대한 지나친 의존을 줄인다.

Dropout ↔ 과적합 완화

Regularization

Losstotal = Loss + λΣw²

모델이 지나치게 복잡한 파라미터를 갖지 않도록 손실 함수에 제약을 추가한다.

Early Stopping

검증 데이터 성능이 더 이상 개선되지 않거나 악화되기 시작하면 학습을 중단한다.

훈련 데이터

검증 데이터
모델 선택·튜닝
테스트 데이터
최종 일반화 성능 평가

Application

시험에서는 모델 구조 ↔ 데이터 특성 ↔ 적용 분야의 연결이 중요하다.

Spatial

CNN

이미지처럼 공간적 구조가 중요한 데이터 처리에 대표적으로 활용된다.

CNN → 이미지 · 영상

이미지 분류 · 객체 인식 · 영상 분석

Sequential

RNN / LSTM

이전 시점의 정보를 활용해 순서가 중요한 데이터를 처리한다. LSTM은 기본 RNN의 장기 정보 학습 어려움을 완화하도록 설계됐다.

RNN → 순차 데이터

시계열 · 자연어 · 음성

딥러닝은 자연어 처리, 음성 인식, 추천, 이상 탐지, 예측 등에도 넓게 활용된다. 시험에서는 기술 이름 자체보다 데이터의 특징 → 적합한 신경망 구조 → 적용 문제 순서로 연결하는 편이 안전하다.

🔑 마지막으로 구분해야 할 3쌍

역전파 vs 경사하강법

역전파는 기울기를 효율적으로 계산하고, 경사하강법은 그 기울기를 이용해 파라미터를 갱신한다.

학습 vs 일반화

학습은 훈련 데이터에서 패턴을 획득하는 것이고, 일반화는 새로운 데이터에도 그 패턴을 유효하게 적용하는 능력이다.

깊음 vs 무조건 좋음

층이 깊어지면 복잡한 표현을 학습할 능력은 커질 수 있지만 무조건 성능이 좋아지는 것은 아니다. 학습 난이도와 과적합도 함께 고려해야 한다.

Exam Anchor

구조 → 학습 → 일반화 → 적용

이 네 관계가 섞이지 않으면 기본 선지를 판별할 수 있고, 마지막 세 구분까지 잡으면 단순 암기를 넘어 함정 선지를 걸러낼 수 있다.
