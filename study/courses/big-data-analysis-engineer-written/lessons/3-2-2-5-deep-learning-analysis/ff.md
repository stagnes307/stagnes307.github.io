깊이가 만드는 것: 계층적 특징 학습

이미지를 예로 들어보자.

초기 층에서는 비교적 단순한 선·경계 같은 특징을 포착하고, 더 깊은 층으로 갈수록 그것들을 조합해 형태·부분, 나아가 더 복잡한 객체 수준의 표현을 학습할 수 있어.

즉,

단순한 특징→특징의 조합→복잡한 표현

이런 계층적 표현 학습이 심층 신경망의 중요한 강점이야.

활성화 함수가 없다면?

여기가 시험 함정이야.

층을 아무리 많이 쌓아도 각 층이 선형변환만 수행하면 전체 역시 결국 하나의 선형변환으로 합쳐질 수 있어.

그래서 ReLU 같은 비선형 활성화 함수가 중요해.

대표적으로

ReLU(x)=max(0,x)

가 있어.

활성화 함수 → 비선형성 부여 → 복잡한 관계 표현 가능

이 연결을 기억해.

⚙️ 2. 학습 — 신경망은 무엇을 '배운다'는 걸까?

신경망 학습의 핵심은 신비한 지능을 집어넣는 게 아니라 가중치와 편향을 조정하는 것이야.

전체 과정을 한 줄로 만들면:

순전파 → 손실 계산 → 역전파 → 가중치 갱신 → 반복

🎯 3. 일반화 — 학습 데이터에서 잘 맞으면 끝일까?

아니야. 여기서 딥러닝 시험의 핵심 구분이 하나 나온다.

모델의 진짜 목적은 학습 데이터를 외우는 게 아니라 보지 못한 새로운 데이터에서도 좋은 성능을 내는 것이야.

이 능력이 일반화(generalization)야.

과적합과 과소적합

과적합(Overfitting)은 훈련 데이터에는 지나치게 잘 맞지만 새로운 데이터에서는 성능이 떨어지는 상태야.

반대로 과소적합(Underfitting)은 모델이 데이터의 구조를 충분히 학습하지 못한 상태야.

상태	훈련 데이터	새로운 데이터
과소적합	성능 낮음	성능 낮음
적절한 학습	성능 높음	성능 높음
과적합	성능 매우 높음	상대적으로 성능 저하

그래서 훈련 성능이 가장 높은 모델 = 반드시 가장 좋은 모델은 아니야.

이 문장은 꼭 기억해둬.

조기 종료 Early Stopping

검증 데이터의 성능을 관찰하다가 더 이상 개선되지 않거나 악화되기 시작하면 학습을 멈추는 방식이야.

중요한 구분:

훈련 데이터 → 파라미터 학습
검증 데이터 → 모델 선택·튜닝 및 학습 중 성능 확인
테스트 데이터 → 최종 일반화 성능 평가

테스트 데이터를 계속 들여다보며 모델을 조정하면 공정한 최종 평가가 어려워져.

🌐 5. 적용 영역 — 어떤 딥러닝을 어디에 쓰나?

시험에서는 모델 구조 ↔ 데이터 특성 ↔ 적용 분야 연결이 중요해.

CNN — 이미지의 공간적 특징

합성곱 신경망(CNN)은 이미지처럼 공간적 구조가 중요한 데이터 처리에 대표적으로 활용돼.

대표 적용:

이미지 분류 · 객체 인식 · 영상 분석

핵심 연결은:

CNN → 이미지/영상

RNN — 순서가 있는 데이터

순환 신경망(RNN)은 이전 시점의 정보를 활용하는 구조를 통해 순차 데이터를 처리하는 데 사용돼.

대표 적용:

시계열 · 자연어 · 음성 등 순서가 중요한 데이터

따라서 시험에서는

RNN → 순차 데이터

로 먼저 연결하면 돼.

LSTM은 기본 RNN에서 장기적인 정보 학습이 어려운 문제를 완화하도록 설계된 대표적인 구조야.

딥러닝의 넓은 적용

현대 딥러닝은 이미지와 시계열에만 한정되지 않아.

자연어 처리, 음성 인식, 추천, 이상 탐지, 예측 등 다양한 분야에서 활용돼.

다만 필기에서는 기술 이름을 무작정 외우기보다 이렇게 구조화하는 게 안전해.

데이터의 특징→적합한 신경망 구조→적용 문제

여기서 출제자가 관계를 뒤집어 놓으면 잡아낼 수 있어야 해.

역전파는 손실에 대한 기울기를 계산하는 학습 메커니즘이고,
드롭아웃은 과적합을 완화해 일반화를 돕는 방법이며,

이 네 관계가 섞이지 않으면 기본 문제 상당수가 정리돼.

🔑 마지막으로 구분해야 할 3쌍
역전파 vs 경사하강법

둘을 같은 것으로 보면 안 돼.

역전파 → 기울기를 효율적으로 계산
경사하강법 → 그 기울기를 이용해 파라미터를 갱신

학습 vs 일반화

학습 → 주어진 훈련 데이터에서 패턴을 획득
일반화 → 새로운 데이터에서도 그 패턴을 유효하게 적용

깊은 신경망 vs 무조건 좋은 신경망

층이 깊어지면 더 복잡한 표현을 학습할 능력은 커질 수 있지만, 무조건 성능이 좋아진다는 뜻은 아니야.

모델 복잡도가 커질수록 학습 난이도와 과적합 문제도 함께 고려해야 해.

이 차이까지 잡으면 단순 암기를 넘어서 선지를 판별할 수 있는 수준이야.
