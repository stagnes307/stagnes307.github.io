3-2-2-6. 비정형 데이터 분석

이번 범위는 “형태가 일정하지 않은 데이터를 어떻게 분석 가능한 형태로 바꾸고, 어떤 절차로 분석하며, 결과를 어떻게 읽는가”가 핵심이야.

시험에서는 세부 알고리즘 계산보다 비정형 데이터 → 표현 → 전처리·분석 → 결과 해석 흐름과 용어 구분을 묻는 경우가 많아.

정형 데이터는 행과 열이 이미 정해져 있지만, 비정형 데이터는 문장·이미지·음성처럼 구조가 일정하지 않아 그대로는 통계적·수학적 계산에 넣기 어려워.

Unstructured Sample

“배송은 빨랐는데 제품 품질은 기대보다 별로였어요.”

이 문장에는 행·열 구조가 없어. 컴퓨터가 분석하려면 결국 문장을 수치적 표현으로 바꿔야 해.

🧱 1. 비정형 데이터 표현

비정형 데이터에는 텍스트·이미지·음성·영상 등이 있지만, 필기에서는 특히 텍스트 데이터를 어떻게 표현하는지 중심으로 잡으면 좋아.

✂️

토큰화와 형태소 분석

문장을 분석 가능한 단위로 나눠. 예를 들어 “데이터를 분석했다”를 “데이터 / 분석” 같은 핵심 의미 단위로 추출할 수 있어.

🧹

불용어 제거

분석 목적에 도움을 거의 주지 않는 조사·관용적 표현 등을 제거해 핵심 단어를 더 선명하게 남기는 과정이야.

🧬

표준 형태로 통일

어간 추출과 표제어 추출을 통해 형태가 다른 단어들을 가능한 한 일정한 기본 형태로 맞춰.

🔢 Bag of Words와 DTM

BoW는 문장에서 단어가 등장했는지, 혹은 몇 번 등장했는지를 숫자로 표현하는 방식이야.

문서빅데이터분석재미중요
문서 11110
문서 21101

행 = 문서 · 열 = 단어 · 값 = 단어 출현 정보 → 문서-단어 행렬(DTM)

약점은 단어의 순서와 문맥을 충분히 반영하지 못한다는 점이야.

⚖️ TF-IDF

특정 문서에서 자주 등장하면서도 전체 문서에서는 흔하지 않은 단어에 높은 가중치를 주는 방식이야.

TF

해당 문서에서 얼마나 자주 등장하는가

IDF

전체 문서에서는 얼마나 드문가

TF-IDF가 높다 → 특정 문서를 잘 대표할 가능성이 크다.

🧠 워드 임베딩

BoW와 TF-IDF가 출현 정보를 중심으로 본다면, 임베딩은 단어의 의미적 관계를 실수 벡터로 표현하려는 방식이야.

왕 − 남자 + 여자 ≈ 여왕

대표적으로 Word2Vec, GloVe, FastText를 알아두면 돼.

빈도 기반 표현 ↔ 의미 기반 표현

방식핵심장점한계
BoW단어 출현 빈도단순하고 이해하기 쉬움순서·문맥 반영 어려움
TF-IDF문서별 단어 중요도문서 특징 단어 파악의미 관계 표현 제한
임베딩의미적 벡터유사성·의미 관계 반영모델과 학습 과정 필요

🔄 2. 비정형 데이터 분석 절차

순서를 하나의 파이프라인으로 이해하면 돼.

① 데이터 수집

뉴스 기사, SNS 게시물, 고객 리뷰, 상담 기록, 웹 문서, 이미지·영상·음성 등 목적과 관련 있는 데이터를 확보해.

② 전처리

결측·중복 처리, 특수문자 제거, 토큰화, 형태소 분석, 불용어 제거, 어간 추출, 표제어 추출 등을 수행해.

③ 표현 및 특징 추출

전처리한 텍스트를 BoW, DTM, TF-IDF, Word Embedding 등 수치 특징으로 변환해.

④ 분석기법 적용

분류, 감성 분석, 군집 분석, 토픽 모델링처럼 목적에 맞는 기법을 선택해.

🧭 3. 결과 해석

숫자가 나왔다고 해서 그 숫자가 곧바로 현실의 의미가 되는 건 아니야. 결과는 반드시 분석 목적과 데이터의 맥락 속에서 해석해야 해.

단어 빈도 해석

“배송”이 가장 많이 등장했다고 해서 고객이 배송에 만족했다는 뜻은 아니야. “배송이 너무 느리다” 때문에 빈도가 높아졌을 수도 있어.

빈도는 관심의 크기를 보여줄 수 있지만 긍정·부정의 방향까지 자동으로 설명하지 않는다.

TF-IDF 결과 해석

어떤 문서에서 “환불”의 TF-IDF가 높다면, 그 문서에서는 자주 등장하면서 다른 문서에서는 상대적으로 흔하지 않다는 뜻이야.

문서를 특징짓는 핵심 단어일 가능성이 높지만, 현실의 인과관계를 자동으로 증명하지는 않아.

군집 분석 결과 해석

군집 번호 자체에는 의미가 없어. 각 군집의 대표 단어와 특징을 보고 분석자가 의미를 붙여야 해.

토픽 모델링 결과 해석

“금리, 은행, 대출, 기준금리, 인상”이 한 토픽에서 높은 확률로 나온다면, 분석자가 이를 “금리 및 금융정책”처럼 해석할 수 있어.

모델은 토픽 번호를 만들고, 토픽의 의미와 이름은 분석자가 해석한다.

⚠️ 시험에서 헷갈리는 경계 세 가지

빈도와 중요도는 같은가?

아니야.

단어 빈도가 높아도 모든 문서에서 흔하면 문서를 구별하는 힘이 약할 수 있어.

TF → 문서 내 빈도
TF-IDF → 빈도 + 전체 문서 희소성

분류와 군집은 같은가?

아니야.

분류는 미리 정해진 범주를 예측하고, 군집은 정답 없이 유사한 데이터를 묶어.

분류 = 지도학습
군집 = 비지도학습

토픽 모델링과 빈도 분석은 같은가?

아니야.

토픽 모델링은 단순 빈도보다 더 나아가 여러 단어의 공동 출현과 확률적 구조로 숨은 주제를 찾는 데 가깝다.

LDA → 잠재 토픽 + 문서·단어의 확률적 관계
