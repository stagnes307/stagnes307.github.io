왜 더 강해질까?

앙상블 분석 · 배깅 · 부스팅 · 앙상블 비교

앙상블은 여러 개의 모델을 결합해서 하나의 더 안정적이고 강한 모델을 만드는 방법이야.

Bagging
배깅 = 여러 모델을 독립적으로 만들어 모은다.
Boosting
부스팅 = 앞 모델의 실수를 뒤 모델이 이어받아 보완한다.

🧩 1. 앙상블은 왜 필요한가?

머신러닝 모델 하나가 항상 정확한 판단을 내리기는 어려워. 예를 들어 100명의 고객이 대출을 갚을지 예측한다고 해보자. 의사결정나무 하나를 만들었는데, 학습 데이터가 조금만 달라져도 나무 구조가 크게 달라질 수 있어. 이런 모델은 변동성이 크다, 즉 분산(variance)이 크다고 표현해.

이때 서로 조금씩 다른 여러 모델의 판단을 모으면 특정 모델의 우연한 실수가 상쇄될 수 있어. 한 사람에게만 물어보는 것보다 여러 사람이 독립적으로 판단한 뒤 다수결을 하는 쪽이 한 사람의 우연한 실수를 줄일 가능성이 커지는 것과 비슷해.

분류 Classification
투표 Voting
회귀 Regression
평균 Average

👜 2. 배깅 Bagging — 따로 배우고 마지막에 합친다

Bagging은 Bootstrap Aggregating의 줄임말이야. 이 이름 자체가 작동 원리를 거의 그대로 설명해.

Bootstrap — 데이터를 여러 번 다시 뽑는다

원래 학습 데이터가 A B C D E라면, 복원추출을 통해 A A C D E, B B C D E처럼 서로 다른 표본을 만들 수 있어. 같은 데이터가 여러 번 뽑힐 수도 있고 어떤 데이터는 빠질 수도 있어. 각각의 데이터셋으로 별도의 모델을 학습해.

Aggregating — 결과를 합친다

각 모델은 서로 독립적으로 예측한 뒤 결과를 합쳐. 핵심은 모델 1의 결과가 모델 2의 학습에 영향을 주지 않는다는 점이야. 그래서 배깅은 기본적으로 병렬적(parallel) 구조라고 볼 수 있어.

배깅이 해결하려는 문제

배깅의 대표적인 목적은 분산(Variance)을 감소시키는 것이야. 특히 의사결정나무처럼 데이터가 조금만 바뀌어도 결과가 크게 달라지는 모델에서 효과적이야.

Parallel Forest Scene

Random Forest와 배깅의 관계

랜덤 포레스트는 여러 의사결정나무를 만들고 결과를 결합해. 단순히 데이터만 무작위로 만드는 게 아니라 각 트리를 만들 때 사용할 변수(feature)도 무작위로 일부 선택해서 나무들이 지나치게 비슷해지는 것을 막아.

Bootstrap 표본 → 여러 Decision Tree → 일부 변수 무작위 선택 → 결과 결합
Sequential Correction Scene

🚀 3. 부스팅 Boosting — 앞에서 틀린 것을 뒤에서 고친다

부스팅에서는 이전 모델의 결과가 다음 모델 학습에 영향을 준다. 앞 모델이 틀린 부분을 확인하고, 다음 모델이 그 부분을 더 신경 써서 학습하고, 남은 오류를 다시 다음 모델이 보완해.

그래서 부스팅은 보통 순차적(sequential) 학습이라고 설명해. 각 모델 하나하나는 아주 뛰어나지 않아도 되고, 이런 약한 학습기(weak learner)를 이어 붙여 전체 성능을 높이는 방식이야.

🔥 AdaBoost

첫 모델이 어떤 데이터를 틀렸다면 그 데이터의 가중치(weight)를 높여. 그러면 다음 모델은 이전 모델이 틀린 관측치를 더 중요하게 보게 돼.

시험 신호어: “오분류된 관측치의 가중치를 증가시킨다.”

⚙️ Gradient Boosting

앞 모델이 제대로 설명하지 못한 오차 또는 잔차(residual)를 다음 모델이 학습하는 방식으로 이해하면 좋아.

실제값 100 − 첫 예측 70 = 잔차 30 → 다음 모델이 이 부족한 부분을 보완

대표 발전형으로 GBM, XGBoost, LightGBM 등이 있어.

⚔️ 4. 배깅 vs 부스팅 — 시험에서 갈리는 결정적 차이

🧠 5. 편향과 분산으로 한 단계 더 정확하게 보기

분산이 크다는 건

학습 데이터가 조금 달라졌을 뿐인데 모델 결과가 크게 변하는 거야. 의사결정나무가 대표적으로 이런 성질을 보일 수 있어. 여러 나무의 결과를 평균내면 개별 나무의 우연한 흔들림이 서로 상쇄될 수 있어.

배깅 → 분산 감소

편향이 크다는 건

모델 자체가 너무 단순해서 실제 관계를 충분히 잡아내지 못하는 상황이라고 볼 수 있어. 부스팅은 약한 학습기를 하나씩 추가하면서 이전 모델이 설명하지 못한 부분을 계속 보완해.

부스팅 → 편향 감소

실제 머신러닝에서는 두 효과가 완전히 분리되는 것은 아니고 알고리즘과 설정에 따라 달라져. 필기에서는 대표적인 효과를 묻는 문맥으로 이해하면 좋아.

📝 8. 필기 직전 압축 정리

앙상블 = 여러 학습모델을 결합해 예측 성능과 안정성을 높이는 방법.

배깅 = Bootstrap + Aggregating · 복원추출한 여러 표본으로 모델을 독립적으로 학습 · 분류는 투표, 회귀는 평균 · 병렬적 · 주로 분산 감소 · 대표: Random Forest

부스팅 = 약한 학습기를 순차적으로 결합 · 이전 모델의 오류를 다음 모델이 보완 · 주로 편향을 낮추고 예측력 강화 · 대표: AdaBoost, Gradient Boosting

AdaBoost = 잘못 분류된 데이터의 가중치를 증가

Gradient Boosting = 이전 모델이 남긴 오차·잔차를 다음 모델이 보완

최종 암기축
배깅 = 따로 배우고 합친다.
부스팅 = 틀린 걸 이어서 고친다.
