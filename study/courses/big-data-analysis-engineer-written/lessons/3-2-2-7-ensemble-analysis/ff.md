#빅데이터분석기사 #필기 #앙상블 #배깅 #부스팅 #RandomForest #AdaBoost

앙상블(Ensemble)은 여러 개의 모델을 결합해서 하나의 더 안정적이고 강한 모델을 만드는 방법이야.

이 단원에서 제일 중요한 건 알고리즘 이름을 외우는 게 아니라, 먼저 이 차이를 잡는 거야.

배깅 = 여러 모델을 독립적으로 만들어 모은다.
부스팅 = 앞 모델의 실수를 뒤 모델이 이어받아 보완한다.

이 한 줄에서 시험에 나오는 대부분의 비교가 파생돼.

처음 학습한 내용과 진행 상태는 저장이라고 입력하면 저장할 수 있어.
원하면 .cc를 붙여서 같은 내용을 HTML 학습 화면 형태로 볼 수도 있어.

🧩 1. 앙상블은 왜 필요한가?

머신러닝 모델 하나가 항상 정확한 판단을 내리기는 어려워.

예를 들어 100명의 고객이 대출을 갚을지 예측한다고 해보자. 의사결정나무 하나를 만들었는데, 학습 데이터가 조금만 달라져도 나무 구조가 크게 달라질 수 있어. 이런 모델은 변동성이 크다, 즉 분산(variance)이 크다고 표현해.

이때 서로 조금씩 다른 여러 모델의 판단을 모으면 특정 모델의 우연한 실수가 상쇄될 수 있어.

여러 사람에게 물어보는 것과 비슷해

한 사람에게만 물어보면 그 사람이 틀릴 위험이 커.

하지만 서로 독립적으로 판단한 여러 사람에게 물어보고 다수결을 하면 한 사람의 우연한 실수가 전체 판단을 망칠 가능성이 줄어들지.

이게 앙상블의 기본 아이디어야.

분류와 회귀에서는 어떻게 합칠까?

분류(Classification)에서는 여러 모델의 결과를 다수결(voting)로 합치는 경우가 많고,

회귀(Regression)에서는 여러 예측값의 평균(average)을 사용하는 경우가 많아.

즉,

분류 → 투표

회귀 → 평균

이라는 대응을 우선 기억하면 돼.

👜 2. 배깅 Bagging — 따로 배우고 마지막에 합친다

Bagging은 Bootstrap Aggregating의 줄임말이야.

이 이름 자체가 작동 원리를 거의 그대로 설명해.

Bootstrap → 데이터를 여러 번 다시 뽑는다

원래 학습 데이터가 있다고 하자.

A B C D E

여기에서 복원추출로 새로운 학습 데이터들을 만든다.

예를 들면,

A A C D E
B B C D E
A C C D E

처럼 같은 데이터가 여러 번 뽑힐 수도 있고, 어떤 데이터는 빠질 수도 있어.

이 각각의 데이터셋으로 별도의 모델을 학습시켜.

Aggregating → 결과를 합친다

각 모델이 서로 독립적으로 예측한 뒤 결과를 합쳐.

구조로 보면 이래.

                 ┌─ 모델 1 ─┐
원본 데이터 ─────┼─ 모델 2 ─┼──→ 투표 / 평균 ─→ 최종 예측
                 ├─ 모델 3 ─┤
                 └─ 모델 4 ─┘

핵심은 모델 1의 학습 결과가 모델 2의 학습에 영향을 주지 않는다는 것이야.

그래서 배깅은 기본적으로 병렬적(parallel) 구조라고 볼 수 있어.

🎯 배깅이 해결하려는 문제

배깅의 대표적인 목적은 분산(Variance)을 감소시키는 것이야.

특히 의사결정나무처럼 데이터가 조금만 바뀌어도 결과가 크게 달라지는 모델에서 효과적이야.

그래서 아주 대표적인 배깅 계열 알고리즘이 바로 랜덤 포레스트(Random Forest)야.

랜덤 포레스트와 배깅의 관계

랜덤 포레스트는 여러 개의 의사결정나무를 만들어 결과를 결합해.

그런데 단순히 데이터만 무작위로 만드는 게 아니라, 각 트리를 만들 때 사용할 변수(feature)도 무작위로 일부 선택해.

이렇게 하는 이유는 나무들이 너무 비슷해지는 것을 막기 위해서야.

나무끼리 다양해야 여러 모델을 모으는 효과가 커지니까.

따라서 기억해.

Random Forest

→ Bootstrap 표본
→ 여러 Decision Tree
→ 일부 변수 무작위 선택
→ 결과 결합

🚀 3. 부스팅 Boosting — 앞에서 틀린 것을 뒤에서 고친다

부스팅은 배깅과 출발부터 달라.

배깅에서는 여러 모델이 서로 독립적이었지.

부스팅에서는 이전 모델의 결과가 다음 모델 학습에 영향을 준다.

모델 1
  ↓
틀린 부분 확인
  ↓
모델 2가 그 부분을 더 신경 써서 학습
  ↓
남은 오류 확인
  ↓
모델 3이 다시 보완
  ↓
여러 모델 결합

그래서 부스팅은 보통 순차적(sequential) 학습이라고 설명해.

약한 모델을 연결해 강한 모델을 만든다

부스팅에서 자주 등장하는 개념이 약한 학습기(weak learner)야.

각 모델 하나하나는 아주 뛰어나지 않아도 돼.

예를 들어 간단한 의사결정나무를 여러 번 이어서,

첫 번째 모델이 놓친 부분 → 두 번째 모델이 보완
두 번째 모델도 놓친 부분 → 세 번째 모델이 보완

하는 방식으로 전체 성능을 높이는 거야.

🔥 4. AdaBoost — 틀린 데이터에 더 큰 관심을 준다

대표적인 부스팅 알고리즘 중 하나가 AdaBoost(Adaptive Boosting)야.

여기서 포인트는 가중치(weight)야.

처음에는 모든 관측치가 비슷한 중요도를 가져.

그런데 첫 모델이 어떤 데이터를 틀렸다면,

“이 데이터는 어려운 사례구나.”

하고 그 데이터의 가중치를 높여.

그러면 다음 모델은 이전 모델이 틀린 관측치를 더 중요하게 보게 돼.

흐름은 이렇게 이해하면 돼.

전체 데이터
   ↓
모델 1 학습
   ↓
오분류 데이터의 가중치 ↑
   ↓
모델 2 학습
   ↓
다시 오분류 데이터에 집중
   ↓
모델 3 학습
   ↓
모델들의 결과를 가중 결합

그래서 시험에서

“오분류된 관측치의 가중치를 증가시킨다.”

라는 표현을 보면 AdaBoost를 강하게 떠올리면 돼.

⚙️ 5. Gradient Boosting — 다음 모델이 잔차를 줄인다

또 중요한 부스팅 계열이 Gradient Boosting이야.

여기서는 앞 모델이 제대로 설명하지 못한 오차 또는 잔차(residual)를 다음 모델이 학습하는 방식으로 이해하면 좋아.

예를 들어 실제 값이 100인데 첫 모델이 70이라고 예측했다면,

남은 오차는

100 − 70 = 30

이야.

다음 모델은 이 부족한 부분을 보완하도록 학습하고, 다시 남은 오차를 다음 모델이 보완해.

개념적으로는

현재 예측 + 오류를 보완하는 새 모델

을 반복한다고 생각하면 돼.

대표적인 발전형

Gradient Boosting 계열에서 자주 등장하는 알고리즘으로는

GBM

XGBoost

LightGBM

등이 있어.

필기에서는 세부 구현보다 먼저 “순차적으로 오류를 보완하는 부스팅 계열”이라는 큰 구조를 정확히 잡는 게 중요해.

⚔️ 6. 배깅 vs 부스팅 — 시험에서 갈리는 결정적 차이

이제 두 방식을 같은 기준으로 비교해보자.

구분	배깅 Bagging	부스팅 Boosting
모델 관계	서로 독립적	이전 모델과 연관
학습 방식	병렬적	순차적
데이터 처리	Bootstrap 표본 생성	오류를 다음 학습에 반영
핵심 목적	주로 분산 감소	주로 편향 감소 및 예측력 향상
이전 모델의 오류	직접적으로 이어받지 않음	다음 모델이 보완
대표 알고리즘	Random Forest	AdaBoost, Gradient Boosting
주요 특징	안정성 향상	어려운 사례에 점점 집중

이 표에서 특히 세 쌍을 확실하게 연결해.

첫 번째 경계

배깅 → 독립 / 병렬

부스팅 → 의존 / 순차

두 번째 경계

배깅 → Bootstrap

부스팅 → 이전 오류를 보완

세 번째 경계

Random Forest → 배깅

AdaBoost → 부스팅

이 세 개를 놓치지 않으면 기본 비교 문제는 상당히 안정적으로 풀 수 있어.

🧠 7. 편향과 분산으로 한 단계 더 정확하게 보기

시험에서는 Bias와 Variance가 앙상블과 연결될 수 있어.

분산이 크다는 건

학습 데이터가 조금 달라졌을 뿐인데 모델 결과가 크게 변하는 거야.

의사결정나무가 대표적으로 이런 성질을 보일 수 있어.

여러 나무의 결과를 평균내면 개별 나무의 우연한 흔들림이 서로 상쇄돼.

그래서

배깅 → 분산 감소

라는 연결이 중요해.

편향이 크다는 건

모델 자체가 너무 단순해서 실제 관계를 충분히 잡아내지 못하는 상황이라고 볼 수 있어.

부스팅은 약한 학습기를 하나씩 추가하면서 이전 모델이 설명하지 못한 부분을 계속 보완해.

따라서 시험 수준에서는

부스팅 → 편향 감소

로 많이 연결해.

다만 실제 머신러닝에서는 이렇게 기계적으로 하나의 효과만 존재하는 건 아니야. 부스팅 역시 분산과 과적합에 영향을 받고, 구체적인 결과는 알고리즘과 설정에 따라 달라져.

필기에서는 대표적인 효과를 묻는 문맥으로 받아들이는 게 좋아.

🧪 8. 시험 문장에서 신호어를 잡는 법

문장을 읽었는데 알고리즘 이름이 직접 나오지 않을 때는 동사를 봐.

“복원추출한다”

→ Bootstrap
→ Bagging

“여러 학습기를 독립적으로 생성한다”

→ Bagging

“여러 의사결정나무의 결과를 결합한다”

→ Random Forest 가능성 높음

“이전 학습기가 잘못 분류한 관측치에 더 큰 가중치를 준다”

→ AdaBoost

“이전 모델의 오차를 다음 모델이 보완한다”

→ Boosting

“순차적으로 약한 학습기를 결합한다”

→ Boosting

즉, 시험장에서 알고리즘 이름부터 찾으려고 하지 말고,

독립인가 → 연결되어 있는가

를 먼저 판단하면 훨씬 쉬워져.

🌲 9. 한 장면으로 묶어서 기억하기

배깅은 회의와 비슷해.

여러 사람이 각자 독립적으로 판단한 뒤 마지막에 투표한다.

각자 판단 → 모아서 결정

부스팅은 릴레이 첨삭과 비슷해.

첫 번째 사람이 답안을 보고 놓친 점을 남기면, 다음 사람이 그 부족한 부분을 고치고, 또 다음 사람이 남은 문제를 고쳐.

이전 실수 → 다음 사람이 보완

따라서 머릿속 그림은 이렇게 두 개면 충분해.

BAGGING
        ┌→ 모델 A ─┐
데이터 ─┼→ 모델 B ─┼→ 결합
        └→ 모델 C ─┘
          독립 / 병렬


BOOSTING
데이터 → 모델 A → 오류 → 모델 B → 오류 → 모델 C → 결합
                        순차 / 보완
📝 10. 필기 직전 압축 정리

앙상블
= 여러 학습모델을 결합해 예측 성능과 안정성을 높이는 방법.

배깅
= Bootstrap + Aggregating
= 복원추출한 여러 표본으로 모델을 독립적으로 학습
= 분류는 투표, 회귀는 평균
= 병렬적
= 주로 분산 감소
= 대표: Random Forest

부스팅
= 약한 학습기를 순차적으로 결합
= 이전 모델의 오류를 다음 모델이 보완
= 주로 편향을 낮추고 예측력을 강화
= 대표: AdaBoost, Gradient Boosting

AdaBoost
= 잘못 분류된 데이터의 가중치를 증가

Gradient Boosting
= 이전 모델이 남긴 오차·잔차를 다음 모델이 보완

그리고 최종 암기축은 이것만 가져가도 돼.

배깅 = 따로 배우고 합친다.
부스팅 = 틀린 걸 이어서 고친다.
