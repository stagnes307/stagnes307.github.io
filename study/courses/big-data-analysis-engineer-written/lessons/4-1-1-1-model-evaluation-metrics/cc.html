🧭 먼저 큰 그림: 회귀와 분류의 평가는 무엇이 다른가?

회귀는 “얼마나 멀리 틀렸나?”

집값의 실제값이 5억인데 예측값이 4억 8천이라면, 틀렸다는 사실뿐 아니라 얼마나 차이가 났는지가 중요해.

Error = y − ŷ

즉 회귀는 기본적으로 오차(error)를 어떻게 측정하느냐가 평가의 출발점이야.

분류는 “어떤 방식으로 틀렸나?”

암 여부를 예측한다면 단순 정답률만으로는 부족해. 암 환자를 정상이라고 놓친 경우와 정상인을 암이라고 잘못 판단한 경우는 결과의 의미가 다르니까.

맞음 → 틀림 → 틀린 유형 구분

📏 회귀 평가 지표

오차를 어떻게 모을 것인가?

MAE — 오차의 절댓값 평균

MAE = (1/n) Σ |yᵢ − ŷᵢ|

각 오차의 절댓값을 평균내. 오차가 −2, 3, −1이면 절댓값은 2, 3, 1이고 MAE는 2야.

MAE → 절댓값 → 이상치에 상대적으로 덜 민감

MSE — 큰 오차를 더 강하게 벌점

MSE = (1/n) Σ (yᵢ − ŷᵢ)²

오차를 제곱한 뒤 평균내. 오차가 2이면 4지만 오차가 10이면 100이 되니까, 큰 오차가 훨씬 강하게 반영돼.

MSE → 제곱 → 큰 오차에 민감 → 이상치 영향 큼

RMSE — MSE를 원래 단위로 되돌리기

RMSE = √MSE

MSE는 단위까지 제곱되지만 RMSE는 다시 제곱근을 취하므로 종속변수와 같은 단위로 해석할 수 있어. 큰 오차에 민감한 성질은 그대로 유지돼.

지표 오차 처리 특징 좋은 값
MAE절댓값이상치 영향 상대적으로 작음작을수록
MSE제곱큰 오차에 큰 패널티작을수록
RMSEMSE의 제곱근원래 단위로 해석작을수록

🎯 결정계수 R²

R²는 단순히 오차의 크기를 보는 대신 모형이 종속변수의 변동을 얼마나 설명하는가를 나타내.

R² = 1 − Σ(yᵢ − ŷᵢ)² / Σ(yᵢ − ȳ)²

모형이 잘 맞으면 남은 오차가 작아지고 R²는 1에 가까워져. 그래서 일반적으로 R²는 클수록 좋다.

MAE · MSE · RMSE → ↓ 작을수록 좋음
R² → ↑ 클수록 좋음

🧩 분류 평가의 출발점: 혼동행렬

공식을 각각 외우기 전에 TP·FP·FN·TN의 구조를 먼저 잡자.

실제 Positive 실제 Negative
예측 Positive TP FP
예측 Negative FN TN

🎛️ 분류 지표는 “분모가 누구냐”로 읽는다

✅ 정확도 Accuracy

Accuracy = (TP + TN) / (TP + TN + FP + FN)

전체 예측 중 맞힌 비율이야. 하지만 100명 중 정상 99명, 환자 1명인 상황에서 모두 정상이라고 예측해도 정확도는 99%가 돼. 따라서 클래스 불균형이 심하면 정확도만 믿기 위험해.

🎯 정밀도 Precision

“내가 Positive라고 예측한 것 중 실제 Positive는 얼마나 되는가?”

Precision = TP / (TP + FP)

분모는 예측 Positive 전체. 따라서 FP를 줄이는 것이 중요할 때 정밀도를 본다.

FAULT LINE
FP ↓
Precision ↑

🔎 재현율 Recall

“실제 Positive 중에서 얼마나 찾아냈는가?”

Recall = TP / (TP + FN)

분모는 실제 Positive 전체. Recall은 민감도(Sensitivity)라고도 부르며, 실제 양성을 놓치는 FN이 위험할 때 중요해.

FAULT LINE
FN ↓
Recall ↑

⚖️ F1-score

F1 = 2 × (Precision × Recall) / (Precision + Recall)

Precision과 Recall의 조화평균이야. 둘 중 하나가 매우 낮으면 F1도 낮아지므로 두 지표의 균형을 볼 때 유용해. 특히 불균형 데이터에서도 자주 고려돼.

📈 ROC와 AUC — 임계값을 움직여 본다

모델이 환자일 확률을 0.72라고 예측했다고 하자. 임계값이 0.5라면 Positive지만 0.8이라면 Negative가 될 수 있어.

즉 임계값에 따라 TP, FP, FN, TN이 변한다. ROC 곡선은 여러 임계값에서 TPR과 FPR의 관계를 나타내.

TPR = Recall = TP / (TP + FN)
FPR = FP / (FP + TN)

AUC는 ROC 곡선 아래 면적이며 일반적으로 클수록 분류 성능이 좋아.

🧠 지표 선택: 시험에서 진짜 중요한 부분

🚨 FN이 위험하다
실제 Positive를 놓치면 큰 문제
→ Recall 중요
🚫 FP가 위험하다
Positive라고 잘못 판단하면 큰 문제
→ Precision 중요
⚖️ 둘의 균형이 필요하다
Precision과 Recall을 함께 평가
→ F1-score
🧩 클래스가 불균형하다
Accuracy가 높아도 중요한 클래스를 놓칠 수 있음
→ Accuracy만 믿지 않기

회귀

MAE → 절댓값 → 이상치 영향 상대적으로 작음
MSE → 제곱 → 큰 오차 강조 → 이상치 민감

R² → 설명력 → 1에 가까울수록 좋음

분류

Accuracy → 전체 중 맞힌 비율
Precision → 예측 Positive 기준 → FP
Recall → 실제 Positive 기준 → FN
F1 → Precision + Recall의 균형
AUC → ROC 아래 면적 → 클수록 좋음

🪤 필기에서 잘 걸리는 함정

TRAP 01

Precision과 Recall의 분모 뒤집기

Precision은 예측 양성, Recall은 실제 양성 기준.

TRAP 02

Accuracy가 항상 좋은 지표다?

아니야. 클래스 불균형에서는 높은 정확도가 중요한 실패를 숨길 수 있어.

TRAP 03

MSE는 이상치에 강하다?

반대. 제곱 때문에 MSE와 RMSE는 큰 오차에 민감해.

TRAP 04

회귀 지표는 모두 클수록 좋다?

MAE·MSE·RMSE는 ↓, R²는 ↑.

TRAP 05

F1은 산술평균?

아니야. Precision과 Recall의 조화평균.
