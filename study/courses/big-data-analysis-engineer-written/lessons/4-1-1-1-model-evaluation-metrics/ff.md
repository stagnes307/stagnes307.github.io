🧩 분류 평가의 출발점: 혼동행렬

분류 지표는 공식을 각각 따로 외우면 금방 섞여.

먼저 혼동행렬(Confusion Matrix) 하나를 완전히 이해하는 게 훨씬 좋아.

이진 분류에서는 예측 결과가 네 가지로 나뉘어.

	실제 Positive	실제 Negative
예측 Positive	TP	FP
예측 Negative	FN	TN

이제 영어를 해석해보자.

첫 글자:

T = True → 맞음

F = False → 틀림

두 번째 글자:

P = Positive라고 예측

N = Negative라고 예측

TP

실제 Positive이고 예측도 Positive.

양성을 양성으로 맞힘.

TN

실제 Negative이고 예측도 Negative.

음성을 음성으로 맞힘.

FP

실제 Negative인데 Positive라고 예측.

실제 음성을 양성이라고 잘못 판단.

FN

실제 Positive인데 Negative라고 예측.

실제 양성을 놓침.

이 구분만 단단하면 정확도·정밀도·재현율은 거의 자동으로 따라와.

⚖️ F1-score

이제 문제가 하나 생겨.

정밀도만 높이는 모델과 재현율만 높이는 모델 중 어느 게 더 좋은 걸까?

상황에 따라 다르지만 둘을 하나의 숫자로 함께 보고 싶을 수 있어.

그래서 사용하는 것이 F1-score야.

분류	ROC-AUC	임계값 전반의 분류 성능

그리고 지표 선택의 중심축은 이것만 기억해.

FP가 문제 → Precision
FN이 문제 → Recall
둘의 균형 → F1
불균형 데이터 → Accuracy만 믿지 않기
