🔍 1. 잔차와 오류부터 구분하자

모집단에서 존재하는 실제 오차는 직접 보기 어렵지만, 데이터를 적합한 뒤에는 관측값과 예측값의 차이를 계산할 수 있어. 그 계산 가능한 차이가 잔차야.

오차 error

εᵢ

모집단의 실제값과 이론적 모형 사이의 차이. 직접 관찰하기 어렵다.

잔차 residual

eᵢ = yᵢ − ŷᵢ

관측값과 적합된 모형의 예측값 사이의 차이. 직접 계산할 수 있다.

시험에서는 알 수 없는 오차를 잔차를 통해 추정하고 진단한다고 잡으면 돼.

Diagnostic Loop

1

2

선형성·독립성·등분산성·정규성.

3

원인별 조치

데이터나 모형을 적절히 수정한다.

🧭 2. 좋은 잔차는 ‘무작위’처럼 보여야 한다

잔차가 특별한 규칙 없이 0을 중심으로 흩어져 있다면 모형이 설명해야 할 구조가 비교적 잘 반영된 거야. 반대로 모양이 보이면 그 모양이 진단 신호가 된다.

곡선이 보인다

실제 관계가 비선형인데 선형모형을 사용했을 가능성 → 선형성 문제.

폭이 점점 커진다

예측값에 따라 오차 분산이 달라지는 이분산성을 의심한다.

하나만 크게 튄다

이상치 가능성을 본다. 단, 발견 즉시 삭제하는 건 틀린 접근이야.

🧪 3. 가정 진단의 핵심 네 축

선형성

독립변수와 종속변수의 관계를 선형모형으로 적절히 표현할 수 있어야 해.

잔차도에 곡선이나 체계적인 패턴이 남으면 선형성 위반을 의심한다.

독립성

오차들이 서로 의존하지 않아야 한다. 특히 시계열에서 중요해.

대표 진단 도구는 Durbin-Watson. 통계량이 대략 2 근처면 자기상관이 크지 않은 상태로 해석한다.

등분산성

오차 분산이 관측값에 따라 달라지지 않고 일정해야 한다.

잔차가 부채꼴로 퍼진다면 이분산성 가능성. Breusch-Pagan 검정 등을 연결해 기억하면 좋아.

정규성

통계적 추론을 위해 오차가 정규분포를 따른다고 가정하는 경우가 많다.

히스토그램, Q-Q plot, Shapiro-Wilk 등을 활용한다.

시험 함정: 독립변수 X 자체가 정규분포여야 하는 것이 아니다. 정규성 가정의 핵심 대상은 일반적으로 오차항이다.

⚠️ 4. 다중공선성: 독립변수끼리 너무 닮았다

독립변수 사이 상관관계가 지나치게 높으면 회귀계수 추정이 불안정해질 수 있어. 대표 지표가 VIF야.

VIFj = 1 / (1 − Rj2)

다른 독립변수들만으로 특정 독립변수를 매우 잘 설명할 수 있을수록 R²가 커지고, 따라서 VIF도 커진다. 방향은 간단해: VIF ↑ → 다중공선성 ↑.

📍 5. 이상치와 영향점은 다르다

표준화·학생화 잔차

유난히 큰 잔차를 찾는다.

Leverage

독립변수 공간에서 특이한 관측치를 본다.

Cook's Distance

그 관측치 하나가 회귀모형 전체를 얼마나 흔드는지 본다.

🔧 6. 진단 결과는 원인에 맞게 조치한다

진단 문제는 흔히 신호 → 원인 → 조치 연결을 묻는다. 이상을 발견했다는 이유만으로 데이터를 지우는 게 아니라, 무엇이 잘못됐는지를 먼저 해석해야 해.

진단 신호 의심할 문제 대표 조치
잔차에 곡선 패턴선형성 위반변수 변환, 다항항·비선형항 추가
잔차가 부채꼴이분산성로그·제곱근 변환, 가중회귀 등
시간 순서의 연속 패턴자기상관시계열 구조 반영, 자기회귀항 고려
극단적으로 큰 잔차이상치원인 확인 후 수정·제거 여부 판단
Cook's Distance가 큼영향점해당 관측치가 계수·적합에 미치는 영향 분석
VIF가 큼다중공선성변수 제거·선택·결합, PCA·규제 고려
Q-Q plot에서 큰 이탈정규성 문제변환 또는 모형 가정 재검토

🧠 7. 분류모형에서는 ‘오류의 위치’를 본다

Actual + / Predicted +

TP

Actual − / Predicted +

FP

Actual + / Predicted −

FN

Actual − / Predicted −

TN

분류에서는 회귀 잔차도보다 어느 클래스에서 어떤 오분류가 발생하는지를 살펴보는 게 중요해. 그래서 혼동행렬을 통해 FP와 FN의 구조를 본다.

예를 들어 질병 탐지에서 FN은 실제 환자를 정상으로 판단한 경우이므로 비용이 매우 클 수 있어.

진단 결과에 따라 임계값 조정, 특성 개선, 클래스 불균형 처리, 다른 평가 지표 선택, 재학습 등을 고려한다.
