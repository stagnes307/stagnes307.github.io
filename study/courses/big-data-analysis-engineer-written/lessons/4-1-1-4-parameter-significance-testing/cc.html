📊 회귀계수,
숫자 하나로 끝내지 않는다

모수 유의성 검정은 결국 하나를 묻는다. “이 계수가 우연히 0과 달라 보이는 것인가, 실제로 의미가 있다고 볼 근거가 있는가?”

필기 판정 순서
가설 → 통계량 → p-value → α → 결론

🎯 먼저 잡을 핵심

선형회귀식 Y = β₀ + β₁X + ε에서 관심 모수가 β₁이라면, β₁ = 0은 X가 변해도 Y에 선형적인 영향이 없다는 기준점이 된다. 따라서 모수 유의성 검정은 추정된 계수가 통계적으로 0과 구별되는가를 판단하는 절차다.

🧩 1. 모수 가설 — 무엇을 검정하는가?

NULL HYPOTHESIS

H₀: βⱼ = 0

해당 설명변수의 효과가 없다고 본다.

ALTERNATIVE HYPOTHESIS

H₁: βⱼ ≠ 0

해당 설명변수의 효과가 있다고 본다.

왜 하필 0인가?

회귀계수는 X가 1만큼 변할 때 Y가 얼마나 변하는지를 나타낸다. 따라서 βⱼ = 0이면 X가 변해도 Y의 평균적인 변화량은 0이다. 즉 설명변수의 기여가 없다는 기준점이 된다.

🧪 2. 검정통계량 — 0에서 얼마나 떨어져 있는가?

t TEST STATISTIC

t = (β̂ⱼ − βⱼ,₀) / SE(β̂ⱼ)
H₀: βⱼ = 0  ⇒  t = β̂ⱼ / SE(β̂ⱼ)

검정통계량은 계수가 0으로부터 표준오차 몇 배만큼 떨어져 있는지 보여준다. 그래서 회귀계수의 크기만 보고 유의성을 판단하면 안 된다.

β̂ = 2, SE = 0.5

t = 4

β̂ = 2, SE = 2

t = 1

같은 계수 2라도 표준오차가 다르면 증거의 강도가 달라진다.

🔍 3. 유의확률 p-value — 얼마나 드문 결과인가?

p-value는 귀무가설이 참이라고 가정했을 때, 지금 관측한 것만큼 또는 그보다 더 극단적인 결과가 나타날 확률이다.

❌ 잘못된 해석

p = 0.03 → H₀가 참일 확률이 3%

⭕ 올바른 방향

P(현재만큼 극단적인 데이터 | H₀)

즉 p-value는 P(H₀ | 데이터)가 아니다.

⚖️ 4. 유의수준 α와 비교한다

p < α

귀무가설 기각

모수가 통계적으로 유의하다고 볼 근거가 있다.

p ≥ α

귀무가설을 기각하지 못함

모수가 0과 다르다고 말할 충분한 근거가 없다.

보통 α = 0.05를 많이 사용한다. 통계적으로 더 정확한 표현은 “귀무가설을 채택한다”보다 “귀무가설을 기각하지 못한다”이다.

🔄 전체 흐름을 하나로 연결하기

가설 설정 검정통계량 p-value α와 비교 결론
H₀: βⱼ = 0
↓
t = β̂ⱼ / SE(β̂ⱼ)
↓
p < α → H₀ 기각

🧠 결과 해석 — 시험에서 가장 중요한 문장

변수 회귀계수 t값 p-value
X₁1.253.200.002
X₂−0.40−0.830.410

X₁: 0.002 < 0.05이므로 H₀를 기각한다. 따라서 X₁의 회귀계수는 통계적으로 유의하다. 계수가 양수이므로 다른 조건이 같다면 X₁이 증가할수록 Y가 증가하는 방향이다.

X₂: 0.410 > 0.05이므로 H₀를 기각하지 못한다. 따라서 X₂의 회귀계수가 0과 다르다고 볼 충분한 근거가 없다. 추정계수가 −0.40이라고 해서 곧바로 “X₂가 Y를 감소시킨다”고 확정하면 안 된다.

🚨 필기에서 자주 걸리는 함정

유의함 ≠ 영향력이 큼

p-value가 작다는 것은 0과 구별할 통계적 근거가 강하다는 뜻이지, 효과가 실질적으로 크다는 뜻은 아니다.

p-value가 크다 ≠ 귀무가설이 참임을 증명

p > 0.05는 “효과가 없다”의 증명이 아니라 “효과가 있다고 말할 충분한 증거를 얻지 못했다”에 가깝다.

부호와 유의성은 따로 본다

계수의 부호는 관계의 방향을, p-value는 통계적 유의성을 판단한다.

🧭 t값과 p-value의 관계

|t| ↑
p-value ↓

다른 조건이 같다면 검정통계량의 절댓값이 클수록 귀무가설 아래에서 더 극단적인 결과가 되고, p-value는 작아지는 경향이 있다.

💡 필기 암기 포인트

0인가? → 통계량 → p값 → α 비교 → 기각 여부

  1. H₀: β = 0은 해당 모수의 효과가 없다는 가설이다.
  2. 검정통계량은 추정치가 귀무가설의 값에서 얼마나 떨어져 있는지를 표준화한 값이다.
  3. p < α이면 귀무가설을 기각한다.
  4. 유의하지 않다는 것은 효과가 없음을 증명한 것이 아니라 효과가 있다고 판단할 근거가 부족함을 의미한다.
