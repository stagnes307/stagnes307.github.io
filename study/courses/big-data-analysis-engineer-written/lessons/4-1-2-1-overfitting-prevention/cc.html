🔎 1. 과대적합 진단 — 무엇을 비교해야 할까?

가장 중요한 신호는 훈련 성능과 검증·테스트 성능의 간격이다. 훈련 데이터에서는 매우 높은 성능을 보이는데 검증이나 테스트 데이터에서는 성능이 크게 떨어진다면, 모델이 일반적인 규칙뿐 아니라 훈련 데이터의 잡음과 우연한 패턴까지 학습했을 가능성이 크다.

TRAIN
성능 ↑↑

이미 본 데이터에는 매우 잘 맞는다.

VALIDATION / TEST
성능 ↓

새로운 데이터에서는 성능이 유지되지 않는다.

시험 판단선

훈련 오류는 계속 감소하는데 검증 오류가 다시 증가한다면 과대적합을 의심한다.

과대적합을 부르는 조건

  • 데이터에 비해 모델이 지나치게 복잡함
  • 학습 데이터가 너무 적음
  • 변수가 지나치게 많거나 불필요한 변수가 포함됨
  • 의사결정나무의 깊이가 지나치게 깊음
  • 신경망을 지나치게 오래 학습함

⚖️ 2. 편향과 분산 — 복잡도에는 대가가 있다

모델이 너무 단순하면 실제 관계를 충분히 표현하지 못해 편향이 커지고 과소적합이 생긴다. 반대로 지나치게 복잡하면 훈련 표본의 작은 변화에도 모델이 크게 흔들려 분산이 커지고 과대적합이 나타날 수 있다. 목표는 가장 복잡한 모델이 아니라 일반화 성능이 가장 좋은 복잡도를 찾는 것이다.

🛠️ 3. 규제·단순화 — 복잡함에 비용을 매긴다

목적함수 = 예측 오차 + 복잡도 패널티

잘 맞추되, 지나치게 복잡하면 벌점을 준다.

L1 · LASSO

일부 계수를 0으로

λ Σ |βj|

회귀계수의 절댓값에 패널티를 부여한다. 일부 계수를 정확히 0으로 만들 수 있어서 변수 선택 효과가 나타날 수 있다.

L2 · RIDGE

계수를 전반적으로 축소

λ Σ βj2

회귀계수의 제곱에 패널티를 부여한다. 계수를 완전히 제거하기보다 전반적으로 작게 만들어 특정 변수의 과도한 영향을 억제한다.

구분L1L2
대표 방법LassoRidge
패널티계수 절댓값계수 제곱
효과일부 계수 0 가능계수 전반 축소
기억변수 선택계수 안정화

λ가 커지면 무조건 좋을까?

아니야. λ가 작으면 규제가 약해서 모델 복잡도가 높아질 수 있고, λ가 커지면 규제가 강해져 모델이 단순해진다. 하지만 지나치게 큰 λ는 오히려 과소적합을 일으킬 수 있다. 따라서 적절한 규제 강도를 검증 데이터나 교차검증으로 선택해야 한다.

✂️ 4. 알고리즘별 단순화 — 같은 목적, 다른 장치

의사결정나무

깊은 나무는 훈련 데이터의 세부 특징까지 분리하기 쉬워 과대적합 위험이 커진다.

  • 최대 깊이 제한
  • 최소 노드 크기 설정
  • 최소 분할 데이터 수 설정
  • 가지치기(Pruning)

신경망

  • Dropout — 일부 뉴런을 임의로 제외하여 특정 경로 의존을 억제
  • Weight Regularization — 가중치의 과도한 크기를 제한
  • Early Stopping — 검증 성능이 악화되기 전에 학습 중단

📉 5. 일반화 성능 확인 — 데이터를 역할별로 분리한다

TRAINING SET

학습

모델의 파라미터를 학습한다.

VALIDATION SET

선택·조정

λ, 트리 깊이, 구조, 학습 횟수 등 하이퍼파라미터를 결정한다.

TEST SET

최종 평가

최종 모델의 일반화 성능을 확인한다.

중요: 테스트 데이터를 반복적으로 보면서 모델이나 λ를 조정하면 테스트 데이터에도 간접적으로 과대적합할 수 있다.

🔁 6. K-Fold 교차검증 — 한 번의 분할에 기대지 않는다

데이터가 제한적이면 한 번의 train/validation 분할 결과가 우연에 크게 좌우될 수 있다. K-Fold 교차검증은 데이터를 K개 부분으로 나누고 검증 역할을 번갈아 맡긴 뒤 성능을 평균하여 일반화 성능을 더 안정적으로 추정한다.

🎯 시험에서 헷갈리는 경계

성능이 높으면 과대적합이 아니다?

아니야. 훈련 성능만 높을 수 있다. 검증·테스트 성능과 함께 봐야 한다.

모델이 복잡할수록 좋은가?

훈련 성능은 좋아질 수 있지만 일반화 성능은 어느 지점부터 오히려 떨어질 수 있다.

규제는 강할수록 좋은가?

아니야. 너무 강한 규제는 과소적합을 일으킬 수 있다.

테스트 데이터로 λ를 고르면 되는가?

아니야. λ 같은 하이퍼파라미터는 검증 데이터나 교차검증으로 정하고 테스트 데이터는 최종 평가에 남겨둔다.

필기용 압축 기억

과대적합 진단

훈련 성능 ↑ / 검증·테스트 성능 ↓ → 잡음까지 학습했을 가능성

과대적합 방지

규제 · 변수 축소 · 가지치기 · Dropout · Early Stopping

L1 / L2

L1 = Lasso = 일부 계수 0 가능 · L2 = Ridge = 계수 전반 축소

일반화 확인

검증·교차검증으로 선택 → 최종 테스트 데이터로 평가

과대적합 방지는 훈련 데이터에 대한 지나친 적합을 줄이고, 규제·단순화와 검증을 통해 새로운 데이터에 대한 일반화 성능을 높이는 과정이다.
