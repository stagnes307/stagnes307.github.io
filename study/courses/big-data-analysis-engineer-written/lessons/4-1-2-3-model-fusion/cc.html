🧭 먼저 잡을 큰 그림

분석모형 융합은 여러 개의 분석모형을 함께 사용해서 하나의 모형보다 더 안정적이고 높은 예측 성능을 얻는 방법이야. 시험에서는 왜 결합하는가 → 어떻게 결합하는가 → 결합했을 때 성능이 왜 달라지는가의 흐름을 잡으면 돼.

🔗 모형 결합 원리 — 같은 실수를 하지 않는 모델들을 모은다

앙상블의 핵심은 단순히 모델 수를 늘리는 것이 아니야.

중요한 건 여러 모델이 서로 다른 방식으로 오류를 내는 것이야.

세 모델이 항상 똑같이 틀리면 셋을 모아도 별 효과가 없어. 반대로 오류가 서로 다르면 다수결이나 평균 과정에서 개별 오류가 상쇄될 수 있어.

좋은 앙상블 = 개별 모형의 성능 + 모형 사이의 다양성

분산을 줄이는 경우

훈련 데이터가 조금 바뀌었을 뿐인데 예측이 크게 변한다면 분산이 큰 모델이야. 여러 모델의 결과를 평균하면 우연한 변동이 상쇄될 수 있어.

Bagging → 분산 감소

편향을 줄이는 경우

모델이 반복적으로 같은 방향으로 틀린다면 Boosting은 이전 모델이 틀린 부분을 다음 모델이 보완하도록 학습해.

Boosting → 편향 감소에 강점

🧱 결합 방법 ① Voting — 여러 모델의 의견을 모은다

Voting은 여러 개의 서로 다른 모델이 예측한 결과를 모아서 최종 예측을 결정하는 가장 직관적인 앙상블 방식이야.

Hard Voting

각 모델이 직접 예측한 클래스를 투표해.

A · A · B → A

Hard Voting = 클래스

Soft Voting

각 모델이 예측한 확률을 평균해서 결정해.

(0.7 + 0.8 + 0.4) / 3 ≈ 0.633

Soft Voting = 확률

🎒 결합 방법 ② Bagging — 데이터를 여러 번 뽑아 병렬로 학습한다

Bagging은 Bootstrap Aggregating의 줄임말이야.

Bootstrap

원래 학습 데이터에서 복원추출을 통해 여러 개의 학습 데이터셋을 만들어. 이미 뽑힌 데이터가 다시 뽑힐 수도 있어.

Aggregating

각 모델의 결과를 마지막에 합쳐. 분류라면 흔히 다수결, 회귀라면 평균을 사용할 수 있어.

시험 연결: Bagging = Bootstrap + 병렬 + 분산 감소

Random Forest는 대표적인 Bagging 계열 방법이야. 부트스트랩 표본뿐 아니라 노드 분할 시 일부 변수도 무작위로 선택해 나무 사이의 상관관계를 낮추고 다양성을 확보해.

🚀 결합 방법 ③ Boosting — 앞 모델의 실수를 뒤 모델이 보완한다

Bagging과 달리 앞 모델의 결과가 뒤 모델 학습에 영향을 줘.

추가 보완

AdaBoost

잘못 분류된 데이터에 더 큰 관심을 주자. 앞의 모델이 틀린 관측치에 더 높은 가중치를 부여하고 다음 모델이 그 관측치를 더 잘 분류하도록 학습해.

오분류 발견 → 가중치 증가 → 다음 모델 학습

Gradient Boosting

앞 모델이 남긴 잔차 또는 오류를 다음 모델이 학습하면서 점진적으로 예측을 개선해.

GBM · XGBoost · LightGBM · CatBoost

🏗️ 결합 방법 ④ Stacking — 모델의 예측을 다시 하나의 모델이 학습한다

여러 모델의 예측 결과를 단순히 평균하거나 투표하는 대신, 그 예측 결과들을 새로운 데이터처럼 사용해서 또 다른 모델을 학습해.

Base Learner

아래 단계에서 실제 예측을 수행하는 여러 모델.

Meta Learner

Base Learner의 예측값을 받아 최종 결과를 학습하는 모델.

시험 단서: “기초 학습기의 예측 결과를 새로운 입력변수로 사용한다” → Stacking

⚖️ Bagging과 Boosting — 시험에서 가장 많이 섞이는 비교

아니야. 시험은 바로 그 생각을 노려. 가장 중요한 차이는 모델 간 관계야.

📊 성능 비교 — 앙상블이라고 무조건 좋은 것은 아니다

여러 모델을 합치면 일반화 성능을 개선할 가능성이 있지만 언제나 성능이 좋아지는 것은 아니야. 모델들이 모두 비슷하게 틀리면 결합 효과가 작아.

Bagging이 유리한 상황

데이터 변화에 민감한, 즉 분산이 큰 모델에서 효과가 좋아. 의사결정나무가 대표적이야.

Boosting이 유리한 상황

약한 모델의 오류를 계속 수정할 때 강력해. 다만 노이즈나 이상치까지 지나치게 추적할 위험이 있어.

Stacking이 유리한 상황

서로 다른 모델의 장점을 Meta Learner가 조합할 수 있지만 구조와 검증 과정이 더 복잡해져.

🧠 시험에서는 단서에서 알고리즘으로 역추적해

복원추출→Bootstrap → Bagging
여러 모델을 독립적으로 학습→Bagging
틀린 데이터에 가중치→AdaBoost
앞 학습기의 오류를 다음 학습기가 보완→Boosting
기초 모델의 예측값을 새로운 입력변수로 사용→Stacking
클래스의 다수결→Hard Voting
예측 확률의 평균→Soft Voting
