#빅데이터분석기사 #필기 #분석모형평가및개선 #분석모형개선 #앙상블 #모형결합

🧭 먼저 잡을 큰 그림

분석모형 융합은 여러 개의 분석모형을 함께 사용해서 하나의 모형보다 더 안정적이고 높은 예측 성능을 얻는 방법이야.

여기서 시험에 가장 중요한 흐름은 딱 세 단계야.

왜 결합하는가 → 어떻게 결합하는가 → 결합했을 때 성능이 왜 달라지는가

특히 다음 세 가지는 분리해서 기억해야 해.

핵심	질문	대표 개념
모형 결합 원리	왜 여러 모형을 합치나?	오류 감소, 다양성, 일반화 성능
결합 방법	어떤 방식으로 합치나?	Voting, Bagging, Boosting, Stacking
성능 비교	어떤 방법이 언제 유리한가?	분산 감소, 편향 감소, 과적합
🔗 모형 결합 원리 — 같은 실수를 하지 않는 모델들을 모은다

앙상블의 핵심은 단순히 모델 수를 늘리는 것이 아니야.

중요한 건 여러 모델이 서로 다른 방식으로 오류를 내는 것이야.

예를 들어 세 명이 어떤 문제를 푼다고 해보자.

A는 계산 실수를 자주 하고

B는 문제를 잘못 읽는 실수를 하고

C는 계산과 해석은 잘하지만 가끔 암산을 틀려.

세 사람이 서로 다른 실수를 한다면 다수결을 했을 때 정답률이 높아질 수 있겠지.

반대로 세 사람이 항상 똑같은 방식으로 생각하고 똑같이 틀린다면 세 명을 모아도 별 효과가 없어.

즉,

좋은 앙상블 = 개별 모형의 성능 + 모형 사이의 다양성

이라고 보면 돼.

왜 성능이 좋아질까?

머신러닝 모델의 예측 오차를 아주 크게 보면 다음처럼 생각할 수 있어.

오차 = 편향(Bias) + 분산(Variance) + 제거하기 어려운 잡음

앙상블은 여러 모델을 결합하면서 주로 편향 또는 분산을 줄이는 방향으로 작동해.

분산을 줄이는 경우

훈련 데이터가 조금 바뀌었을 뿐인데 모델의 예측이 크게 바뀐다면 분산이 큰 모델이야.

대표적인 예가 의사결정나무야.

나무 하나는 데이터 변화에 상당히 민감하지만, 여러 나무의 결과를 평균하면 개별 나무의 우연한 변동이 상쇄될 수 있어.

이 생각이 바로 Bagging → Random Forest로 이어져.

편향을 줄이는 경우

반대로 모델이 너무 단순해서 반복적으로 같은 방향으로 틀리는 경우에는 편향이 크다고 볼 수 있어.

Boosting은 이전 모델이 틀린 부분을 다음 모델이 계속 보완하면서 이러한 오류를 줄여 나가.

그래서 시험에서는 보통 다음 연결이 중요해.

Bagging → 분산 감소

Boosting → 편향 감소에 강점

다만 실제 모델 성능에서는 편향과 분산이 완전히 독립적으로 움직이는 건 아니야. 시험에서는 위 연결을 중심으로 잡으면 충분해.

🧱 결합 방법 ① Voting — 여러 모델의 의견을 모은다

Voting은 가장 직관적인 앙상블 방식이야.

여러 개의 서로 다른 모델이 예측한 결과를 모아서 최종 예측을 결정해.

예를 들어

로지스틱 회귀 → A

의사결정나무 → A

SVM → B

라고 예측했다면 다수결로 A를 선택할 수 있지.

Hard Voting

각 모델이 직접 예측한 클래스를 투표해.

예를 들어

A / A / B

라면 최종 예측은 A.

핵심은:

클래스 결과 자체를 투표

Soft Voting

각 모델이 예측한 확률을 평균해서 결정해.

예를 들어 어떤 데이터가 A일 확률을

모델 1 → 0.7

모델 2 → 0.8

모델 3 → 0.4

라고 예측했다면,

평균 확률은

3
0.7+0.8+0.4
	​

≈0.633

이야.

그래서 최종적으로 A를 선택할 수 있어.

시험에서 가장 빠른 구별법은 이거야.

Hard Voting = 클래스

Soft Voting = 확률

🎒 결합 방법 ② Bagging — 데이터를 여러 번 뽑아 병렬로 학습한다

Bagging은 Bootstrap Aggregating의 줄임말이야.

여기서는 두 단어를 분리해서 보면 이해가 쉬워.

Bootstrap

원래 학습 데이터에서 복원추출을 통해 여러 개의 학습 데이터셋을 만드는 방법이야.

복원추출이니까 이미 뽑힌 데이터가 다시 뽑힐 수도 있어.

원본 데이터가

A, B, C, D

라면 한 부트스트랩 표본은

A, A, C, D

가 될 수도 있어.

다른 표본은

B, C, C, D

가 될 수도 있고.

각 표본으로 별도의 모델을 훈련해.

Aggregating

각 모델의 결과를 마지막에 합쳐.

분류라면 흔히 다수결, 회귀라면 평균을 사용할 수 있어.

구조를 보면

원본 데이터

↓ Bootstrap

표본 1 → 모델 1

표본 2 → 모델 2

표본 3 → 모델 3

↓

예측 결과 결합

이야.

핵심 특징

각 모델은 병렬적으로 학습할 수 있어.

모델 2가 모델 1의 결과를 기다릴 필요가 없기 때문이야.

그래서 시험에서는

Bagging = 병렬

이라는 연결도 굉장히 중요해.

Random Forest와 연결

Random Forest는 대표적인 Bagging 계열 방법이야.

여러 개의 의사결정나무를 만들되,

서로 다른 부트스트랩 표본을 사용하고

노드를 분할할 때 전체 변수가 아니라 일부 변수를 무작위로 선택해.

이렇게 나무 사이의 상관관계를 더 낮춰서 다양성을 확보하는 거야.

그래서 Random Forest의 핵심 목적 중 하나는

여러 나무의 오류가 지나치게 비슷해지는 것을 막는 것

이라고 이해하면 좋아.

🚀 결합 방법 ③ Boosting — 앞 모델의 실수를 뒤 모델이 보완한다

Boosting은 Bagging과 구조가 꽤 달라.

Bagging에서는 여러 모델을 독립적으로 학습했지.

Boosting에서는 앞 모델의 결과가 뒤 모델 학습에 영향을 줘.

즉,

모델 1 → 오류 확인 → 모델 2 → 오류 보완 → 모델 3 → 추가 보완

처럼 순차적으로 진행돼.

그래서

Boosting = 순차

라고 기억하면 돼.

AdaBoost

대표적인 Boosting 알고리즘이야.

기본 아이디어는

잘못 분류된 데이터에 더 큰 관심을 주자

야.

앞의 모델이 틀린 관측치에 더 높은 가중치를 부여하고, 다음 모델은 그 관측치를 더 잘 분류하도록 학습해.

따라서 흐름은

오분류 발견 → 오분류 데이터 가중치 증가 → 다음 모델 학습

이야.

Gradient Boosting

Gradient Boosting은 조금 다른 관점에서 접근해.

앞 모델이 남긴 잔차 또는 오류를 다음 모델이 학습하면서 점진적으로 예측을 개선해.

이를 기반으로 발전한 알고리즘들이

GBM

XGBoost

LightGBM

CatBoost

같은 계열이야.

필기에서는 세부 수식보다

Boosting은 순차적으로 약한 학습기를 결합하여 이전 학습기의 오류를 보완한다

를 정확하게 잡는 게 우선이야.

🏗️ 결합 방법 ④ Stacking — 모델의 예측을 다시 하나의 모델이 학습한다

Stacking은 한 단계 더 올라간 구조야.

여러 모델의 예측 결과를 단순히 평균하거나 투표하는 대신,

그 예측 결과들을 새로운 데이터처럼 사용해서 또 다른 모델을 학습해.

예를 들어

원래 데이터로

Random Forest

SVM

Logistic Regression

을 학습했다고 해보자.

각 모델의 예측 결과가

P
1
	​

,P
2
	​

,P
3
	​


이라면,

이 값을 새로운 입력변수로 사용하는 Meta Model을 만들 수 있어.

구조는

원본 데이터

↓

Base Model 1

Base Model 2

Base Model 3

↓

각 모델의 예측값

↓

Meta Model

↓

최종 예측

이야.

여기서 용어도 알아두자.

Base Learner

아래 단계에서 실제 예측을 수행하는 여러 모델.

Meta Learner

Base Learner의 예측값을 받아 최종 결과를 학습하는 모델.

그래서 Stacking 문제에서

“기초 학습기의 예측 결과를 새로운 입력변수로 사용한다”

같은 표현이 나오면 거의 바로 Stacking을 떠올리면 돼.

⚖️ Bagging과 Boosting — 시험에서 가장 많이 섞이는 비교

여기서 Bailey가 한 번 끼어들 만하다.

Bailey: “둘 다 모델 여러 개 쓰니까 같은 거 아니냐?”

아니야. 시험은 바로 그 생각을 노려.

가장 중요한 차이는 모델 간 관계야.

구분	Bagging	Boosting
학습 방식	병렬	순차
데이터 처리	Bootstrap 표본	이전 오류를 반영
모델 관계	비교적 독립적	앞 모델에 의존
주요 효과	분산 감소	편향 감소 및 오류 보완
대표 알고리즘	Random Forest	AdaBoost, GBM
이상치 영향	상대적으로 덜 민감	상대적으로 민감할 수 있음
병렬화	쉬움	상대적으로 어려움

시험에서 특히

Bagging = Bootstrap + 병렬 + 분산

Boosting = 오류 보완 + 순차 + 가중치

이 두 묶음을 통째로 기억하면 구별하기 쉬워.

📊 성능 비교 — 앙상블이라고 무조건 좋은 것은 아니다

여러 모델을 합치면 대체로 일반화 성능을 개선할 가능성이 있지만, 언제나 성능이 좋아지는 것은 아니야.

모델들이 모두 비슷하게 틀리면 결합 효과가 작아.

예를 들어 매우 비슷한 세 개의 의사결정나무가 항상 같은 데이터를 똑같이 틀린다면 투표를 해도 결과는 그대로겠지.

그래서 모형 결합에서는

개별 모델의 정확도뿐 아니라 모델 간 오류의 상관관계도 중요해.

Bagging이 유리한 상황

모델이 데이터 변화에 민감할 때 유리해.

즉 분산이 큰 모델에서 효과가 좋아.

대표적으로 의사결정나무가 그래서 Bagging과 궁합이 좋아.

Boosting이 유리한 상황

약한 모델들을 순차적으로 학습하면서 오류를 계속 수정할 때 강력해.

다만 앞 단계의 오류에 계속 집중하기 때문에 노이즈나 이상치까지 지나치게 추적할 위험이 있을 수 있어.

Stacking이 유리한 상황

서로 다른 특성을 가진 여러 모델의 장점을 Meta Learner가 학습해서 조합할 수 있다는 장점이 있어.

하지만 구조가 복잡해지고 계산 비용과 검증 과정도 늘어나.

🧠 시험에서 용어를 이렇게 역으로 찾아가면 돼

문장에서 이런 표현이 나오면 연결해.

“복원추출”

→ Bootstrap

→ Bagging

“여러 모델을 독립적으로 학습”

→ Bagging

“이전 모델이 틀린 데이터에 가중치”

→ AdaBoost

“앞 학습기의 오류를 다음 학습기가 보완”

→ Boosting

“기초 모델의 예측값을 새로운 입력변수로 사용”

→ Stacking

“클래스의 다수결”

→ Hard Voting

“예측 확률의 평균”

→ Soft Voting

이렇게 문장 속 단서 → 알고리즘으로 역방향 연결을 만들어 두면 필기에서 꽤 강해져.

🧬 하나의 구조로 합쳐보기

앙상블을 전체적으로 보면 이렇게 정리할 수 있어.

모형 결합

→ 단순 결합
→ Voting

→ 데이터 변형 후 여러 모델
→ Bagging

→ 이전 오류를 다음 모델이 보완
→ Boosting

→ 여러 모델의 예측을 다시 학습
→ Stacking

그리고 성능 관점에서는

Bagging → 불안정한 모델들을 평균 → 분산 감소

Boosting → 반복되는 오류를 보완 → 편향 감소에 강점

Stacking → 서로 다른 모델의 예측 패턴을 Meta Learner가 조합

이라고 연결하면 돼.

🎯 필기 직전 압축 암기

시험장에서 기억이 흐릿할 때는 이 네 줄부터 복원해.

Voting = 투표
Bagging = 복원추출·병렬·분산 감소
Boosting = 순차·오류 보완·가중치
Stacking = 예측값을 다시 학습

그리고 대표 알고리즘까지 붙여.

Random Forest → Bagging
AdaBoost / Gradient Boosting → Boosting

이 정도가 뼈대고, 문제에서는 여기에 Hard/Soft Voting이나 Bootstrap 등의 특징을 붙여서 흔들어.
