성능·복잡도 판단

03
최종 선정

성능과 실제 활용 목적을 종합해 최종모형을 결정한다.

🔍 1. 후보 모형 비교 — 무엇을 같은 기준으로 비교할까?

모형을 개선하다 보면 로지스틱 회귀, 의사결정나무, 랜덤포레스트, 부스팅처럼 여러 후보가 생길 수 있어. 먼저 해야 할 일은 동일한 평가 기준으로 후보 모형을 비교하는 것이야.

훈련 성능보다 일반화 성능

훈련 데이터에 얼마나 잘 맞았는지보다 새로운 데이터에서도 잘 작동하는지가 중요해.

후보훈련 정확도검증 정확도판단
모형 A99%81%과적합 의심
모형 B92%89%일반화 우수

훈련 정확도만 보면 A지만, 검증 성능을 보면 B가 더 적절해.

분류모형

Accuracy · Precision · Recall · F1-score · ROC-AUC

문제 목적에 따라 중요한 지표가 달라져. 실제 양성을 놓치면 큰 손실이 생기는 문제라면 재현율이 더 중요할 수 있어.

회귀모형

MSE · RMSE · MAE · R²

MSE·RMSE·MAE 같은 오차는 작을수록, R²는 보통 클수록 좋은 방향으로 해석해.

⚖️ 2. 성능·복잡도 판단 — 1등을 그대로 뽑으면 왜 안 될까?

최종모형 선정의 핵심은 trade-off, 상충관계야. 성능이 조금 더 높아졌더라도 계산량, 해석 난이도, 운영 비용이 크게 증가한다면 그 개선이 실제로 가치 있는지 따져야 해.

모형 A
91.0%
복잡도 낮음
모형 B
91.2%
복잡도 매우 높음

0.2%p 향상을 위해 큰 복잡성을 감수할 가치가 있는가?

복잡도와 일반화의 관계

너무 단순함
균형 지점
너무 복잡함

계산 복잡도

학습·예측 시간과 필요한 컴퓨팅 자원

구조적 복잡도

변수·파라미터 수, 트리 깊이, 앙상블 규모 등

해석 가능성

예측 결과가 나온 이유를 설명하기 쉬운가

시험용 핵심 구분

성능 차이가 크지 않다면 더 단순하고 해석 가능한 모형이 유리할 수 있다.

단, “무조건 단순한 모형”이 아니라 필요한 성능을 먼저 확보해야 해.

🎯 3. 최종 선정 — 결국 어떤 모형을 남길까?

최종모형은 검증 성능 + 일반화 가능성 + 복잡도 + 해석 가능성 + 실제 활용 가능성을 종합해서 선택해. 결국 분석 목적에 가장 적합한 모형을 찾는 단계야.

검증 성능 일반화 복잡도 해석성 활용 가능성

목적이 달라지면 선택도 달라진다

모형 A · 정확도 90%

해석이 쉬움 → 설명 책임이 중요한 금융·의료 같은 상황에서 선택 근거가 될 수 있어.

모형 B · 정확도 92%

해석이 어려움 → 예측 성능 자체가 더 중요한 상황에서는 선택될 수 있어.

최적 모형은 절대적이지 않아. 분석 목적과 제약조건에 따라 달라져.

🧠 시험에서 헷갈리는 세 가지

훈련 성능 1위 = 최종모형?
X. 과적합일 수 있어. 검증 또는 교차검증을 통한 일반화 성능이 중요해.
검증 성능 1위 = 무조건 선정?
X. 복잡도, 해석 가능성, 운영 가능성까지 함께 봐야 해.
단순한 모형 = 항상 좋은 모형?
X. 지나치게 단순하면 과소적합될 수 있어. 필요한 성능과 적절한 복잡도의 균형이 핵심이야.

🧭 최종 선정의 7단계

  1. 1여러 후보 모형 생성
  2. 2동일한 평가 기준으로 성능 비교
  3. 3검증·교차검증으로 일반화 성능 확인
  4. 4과적합 여부 확인
  5. 5성능과 모형 복잡도의 균형 판단
  6. 6해석성·계산비용·활용 목적 고려
  7. 7최종모형 선정

Final Memory Line

최종모형은 검증 성능을 중심으로 후보를 비교하되, 성능과 복잡도의 균형 및 분석 목적을 종합적으로 고려하여 선정한다.

특히 기억해: “성능이 조금 더 높다”와 “최종모형으로 더 적절하다”는 같은 말이 아니다.
