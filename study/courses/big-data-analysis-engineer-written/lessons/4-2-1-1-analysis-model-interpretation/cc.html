1. 모형 출력 해석: 숫자는 무엇을 말하는가?

회귀모형이라면

Y = 10 + 3X₁ − 2X₂

여기서 10은 절편, 3과 −2는 회귀계수야. 다른 조건이 같다면 X₁이 1 증가할 때 Y는 3 증가하고, X₂가 1 증가할 때 Y는 2 감소한다고 해석할 수 있어.

계수에서는 먼저 부호와 크기를 읽는다.

분류모형이라면

예측 클래스, 클래스 확률, 실제값과 예측값을 비교하는 혼동행렬 등이 핵심 출력이 돼.

정확도
전체 중 얼마나 맞혔나?
정밀도
양성 예측 중 진짜 양성은?
재현율
실제 양성을 얼마나 찾았나?
F1-score
정밀도와 재현율을 함께 보면?
중요: 어떤 지표가 항상 최고인 건 아니야. 예를 들어 실제 양성을 놓치는 비용이 큰 상황에서는 단순 정확도보다 재현율이 더 중요할 수 있어.

2. 변수 영향 해석: 어떤 변수가 결과를 움직이는가?

시험 함정: 변수 영향력 ≠ 단순히 계수의 절댓값

변수 X₁
5
계수
≠
변수 X₂
0.1
계수

Y = 5X₁ + 0.1X₂라고 해서 X₁이 X₂보다 무조건 50배 중요하다고 할 수는 없어. X₁과 X₂의 단위와 척도가 서로 다를 수 있기 때문이야. 이런 경우 표준화된 계수 등을 활용하면 비교가 쉬워져.

선형회귀

회귀계수로 변수 변화와 예측값 변화의 방향·크기를 해석.

트리 기반 모형

변수 중요도를 통해 예측 과정에서 상대적으로 중요한 변수를 파악.

복잡한 모형

PDP, SHAP 등의 방법으로 변수와 예측 결과의 관계를 해석.

회귀계수

변수 변화와 예측값 변화의 관계

변수 중요도

예측 과정에서 변수의 상대적 중요성

3. 해석상 한계: 모형이 보여준 관계가 현실의 원인인가?

상관관계 → 인과관계?

광고비와 매출이 함께 증가해도 계절, 할인행사, 시장 성장처럼 두 변수에 동시에 영향을 미친 다른 요인이 있을 수 있어.

데이터 편향과 대표성

특정 집단에 편향된 데이터나 모집단을 제대로 대표하지 못하는 표본으로 학습하면 결과의 일반화에도 제약이 생겨.

편향된 데이터 → 편향된 학습 → 해석·활용 제약

과적합

훈련 데이터에서 성능이 매우 높아도 새로운 데이터에서 같은 성능을 보장하지 않아. 그래서 훈련 성능만 보지 말고 검증·테스트 데이터에서의 일반화 성능을 확인해야 해.

적용 범위와 모형 가정

결과를 해석할 때는 모형이 전제하는 가정과 데이터가 대표하는 범위도 함께 봐야 해.

🧠

시험용으로 세 문장에 압축

  1. 1

    모형 출력 해석은 계수·예측값·확률·평가지표 등이 무엇을 의미하는지 파악하는 것.

  2. 2

    변수 영향 해석은 계수나 변수 중요도 등을 이용해 각 변수가 예측 결과에 미치는 방향과 상대적 영향을 파악하는 것.

  3. 3

    해석상 한계에서는 상관관계를 인과관계로 단정하지 않고 데이터 편향·표본 대표성·과적합·모형 가정과 적용 범위를 고려하는 것.

FALSE JUMP 01

계수가 크다 → 무조건 더 중요하다

FALSE JUMP 02

관계가 발견됐다 → 원인이다

FALSE JUMP 03

훈련 정확도가 높다 → 좋은 모형이다
