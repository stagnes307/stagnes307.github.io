설비 목록화 유해·위험요인 위험성평가 안전보건관리규정 업무 절차 분야별 매뉴얼 비상조치 기록관리

🔍 사업장 내 설비와 유해·위험요인을 파악할 수 있다.

정의와 조사 관점

설비 파악은 사업장에 존재하는 기계·기구, 전기설비, 운반설비, 압력설비, 화학설비, 구조물과 안전장치의 종류·위치·상태·사용 조건을 확인하는 일이야. 유해요인은 소음, 진동, 분진, 유해가스와 고온처럼 건강장해를 일으킬 수 있는 원인이고, 위험요인은 끼임, 추락, 충돌, 감전과 화재·폭발처럼 급성 사고를 일으킬 수 있는 원인이야.

설비 명칭만 조사해서는 부족해. 같은 기계도 정상 운전보다 청소·점검·정비·막힘 제거 과정에서 신체가 위험점에 들어가거나 방호장치가 해제될 가능성이 커져. 따라서 설비–작업–사람–환경–관리 상태를 묶어서 확인해야 해.

파악 절차

  1. 조사 범위 설정: 공정, 작업구역, 교대조, 협력업체와 비정상 작업을 포함할지 정해.
  2. 기초자료 수집: 공정도, 배치도, 설비대장, 물질안전보건자료, 사고와 아차사고 기록을 확인해.
  3. 현장 순회점검: 설비 상태, 위험점, 작업자 행동, 통로와 작업환경을 관찰해.
  4. 작업 분해: 준비, 운전, 정지, 청소, 보수와 비상조치로 나누어 살펴봐.
  5. 위험요인 도출: 위험원, 노출 대상, 사고 형태와 기존 안전조치를 기록해.
  6. 위험성 판단: 발생 가능성과 결과의 중대성 등을 고려해 우선순위를 정해.
  7. 개선과 재확인: 대책을 실행한 뒤 잔여 위험성을 다시 평가하고 결과를 기록해.

위험요인을 사고 시나리오로 쓰는 법

좋은 표현은 위험원 + 노출 상황 + 사고 형태 + 결과를 포함해. “컨베이어가 위험하다”라고만 쓰면 대책을 선정하기 어려워. “가동 중인 컨베이어 하부의 낙하물을 손으로 제거하다가 벨트와 풀리 사이에 손이 말려 들어가 손가락이 절단될 수 있다”라고 쓰면 위험점, 행동, 사고 과정과 결과가 명확해져.

위험성 감소대책의 우선순위

  1. 제거: 위험한 작업이나 물질 자체를 없애.
  2. 대체: 더 안전한 설비·공정·물질로 바꿔.
  3. 공학적 조치: 방호장치, 격리, 환기와 자동화로 사람과 위험원을 분리해.
  4. 관리적 조치: 작업허가, 절차, 교육, 점검과 표지로 노출을 줄여.
  5. 개인보호구: 앞선 조치 후에도 남은 위험으로부터 개인을 보호해.

시험 함정은 보호구부터 답하는 거야. 보호구도 중요하지만 착용 행동에 의존하므로 가능한 경우 제거·대체·공학적 조치를 먼저 검토해야 해.

구체적인 예시와 경계

절단기에 소재가 걸렸을 때 작업자가 정지 버튼만 누르고 덮개 안으로 손을 넣는 상황을 생각해봐. 위험요인은 “잔류에너지나 오조작으로 칼날이 움직여 손이 절단될 위험”이야. 대책에는 전원 차단, 개인별 잠금과 표지, 잔류에너지 해소, 무동작 확인이 포함되어야 해. 정지 버튼은 제어 신호만 멈출 수 있으므로 에너지 격리와 같지 않아.

위험원은 해를 일으킬 잠재적 원천이고, 위험성은 그 해가 발생할 가능성과 결과의 중대성을 고려한 정도야. 순회점검은 상태를 찾아내는 활동이고, 위험성평가는 발견한 요인의 수준과 대책 우선순위를 판단하는 과정이야.

규정의 기능과 절차의 연결구조

안전보건관리규정은 안전보건 업무를 누가, 언제, 어떤 기준과 순서로 수행할지 정한 사업장 내부 운영 기준이야. 법령의 공통 요구를 해당 사업장의 조직·설비·공정에 맞는 실행 언어로 옮긴다고 이해하면 돼. 실효성 있는 체계는 책임과 권한 → 업무 절차 → 판단 기준 → 사용 서식 → 기록과 보존 → 점검과 개선으로 연결돼야 해.

필요 절차를 파악하는 순서

  1. 적용 기준 확인: 관계 법령, 안전보건관리규정, 사내 기준과 설비 제조사 지침을 확인해.
  2. 조직과 책임 확인: 사업주, 안전보건관리책임자, 관리감독자, 안전·보건관리자, 작업책임자, 근로자와 협력업체의 역할을 구분해.
  3. 필수 업무 선정: 교육, 위험성평가, 점검, 작업허가, 에너지 차단, 보호구, 화학물질, 사고조사와 비상대응 절차를 검토해.
  4. 절차 흐름 설계: 개시 조건, 담당자, 실행 단계, 확인 기준, 승인, 기록과 사후조치를 배열해.
  5. 서식 연결: 작업허가서, 점검표, 교육일지, 위험성평가표와 개선조치서를 연결해.
  6. 이행성 검토: 근로자가 실제로 수행할 수 있는지 시험하고 변경이나 사고 발생 시 개정해.

화기작업 허가 절차의 예시

화기작업은 장소·시간·내용을 신청한 뒤 주변 가연물과 인화성 물질을 확인하고 제거하거나 격리해야 해. 필요한 경우 가스 농도와 환기 상태를 확인하고, 소화설비와 화재감시자를 배치한 다음 권한 있는 사람이 승인해. 작업 조건이 바뀌면 즉시 중지하고, 종료 후에는 잔불과 지연 발화 가능성을 확인해야 해. 허가서 서명만으로 안전이 보장되는 것이 아니라 현장 조건 확인, 작업 중 감시, 종료 후 확인이 모두 작동해야 해.

개발 원칙

안전관리 매뉴얼은 규정과 절차를 작업자가 현장에서 실행할 수 있도록 구체화한 문서야. 좋은 매뉴얼은 현장 적합성, 명확성, 실행 가능성, 일관성을 갖추고, 교육·훈련과 점검으로 검증할 수 있어야 해. “적절히 주의한다” 같은 모호한 표현보다 작업중지 조건, 차단 위치, 확인 기준과 보고 대상을 분명히 써야 해.

분야별 핵심 내용

  • 기계안전: 위험점, 방호장치, 시동 전 점검, 막힘 제거와 에너지 차단
  • 전기안전: 정전작업, 검전, 접지, 충전부 접근 통제와 감전 구조
  • 화공안전: 화학물질 반입·저장·취급, 누출 대응과 혼재 금지
  • 운반·양중: 지게차 동선, 크레인 신호, 줄걸이, 적재와 출입 통제
  • 화재·폭발: 화기작업, 가연물 관리, 점화원 통제, 초기소화와 대피
  • 밀폐공간: 출입허가, 농도 측정, 환기, 감시와 구조
  • 비상대응: 경보, 신고, 지휘, 대피, 응급조치와 인원 확인
  • 사고조사: 현장 보존, 보고, 사실 수집, 원인분석과 재발방지

매뉴얼 개발 절차

  1. 대상과 사용자 설정: 공정과 위험, 신규 근로자·숙련자·관리감독자·협력업체 중 사용자를 정해.
  2. 자료 수집: 규정, 위험성평가, 공정도, 설명서, 물질안전보건자료와 사고사례를 모아.
  3. 작업 분해: 작업 전·중·후, 이상 발생 시와 비상 시로 나눠.
  4. 본문 작성: 목적, 범위, 책임, 위험요인, 안전조치, 작업중지, 비상조치와 기록을 구성해.
  5. 현장 검증: 실제 사용자가 모의 작업을 수행하며 불가능한 순서와 누락을 찾아.
  6. 승인·배포·교육: 최신본을 승인하고 구본을 회수한 뒤 사용자에게 교육해.
  7. 평가·개정: 설비·원료·작업방법·조직·법령 변경과 사고·훈련 결과를 반영해.

필수 문서 구조

목적, 적용 범위, 용어 정의, 관련 근거, 책임과 권한, 설비·작업 개요, 유해·위험요인, 작업 전·중·후 조치, 작업중지와 보고, 비상조치, 보호구, 교육·훈련, 점검표·기록, 문서번호와 개정 이력을 포함하는 것이 기본 골격이야.

컨베이어 청소·막힘 제거 매뉴얼 예시

작업 전에는 작업책임자에게 알리고 설비를 정상 정지한 뒤, 주전원을 차단하고 개인별 잠금장치와 표지를 부착해. 유압·공압·중력과 장력의 잔류에너지를 해소하고 조작부를 시험해 무동작 상태를 확인해야 해.

작업 중에는 손 대신 지정 도구를 사용하고, 관계자 외 출입을 통제해. 차단되지 않은 에너지나 잠금장치 훼손이 발견되면 즉시 중지하고 보고하며 다른 사람의 잠금장치를 임의로 해제하면 안 돼.

작업 후에는 공구·자재·작업자가 위험구역에서 빠져나왔는지 확인하고 방호장치를 원상 복구해. 각 작업자가 자신의 잠금장치를 해제한 뒤 책임자가 재가동 조건을 확인하고 주변 사람에게 알린 다음 시험 운전해.

비교와 경계

매뉴얼은 교육과 위험성평가를 대체하지 않아. 문서를 배포해도 작업자가 이해하고 수행하도록 교육·훈련해야 하고, 새로운 위험이 발견되면 위험성평가와 매뉴얼을 함께 갱신해야 해. 상세할수록 무조건 좋은 것도 아니야. 현장 행동과 무관한 설명이 너무 많으면 긴급한 순간에 필요한 정보를 찾기 어려우므로 실행 정보는 본문에, 복잡한 기술자료는 부록에 두는 것이 좋아.

시험 함정

  • 목적과 일반 수칙만 쓰고 작업 순서를 누락하는 경우
  • 책임자를 정하고도 작업중지 권한을 명시하지 않는 경우
  • 정상 절차만 작성하고 이상·비상 상황을 빠뜨리는 경우
  • 위험성평가 결과와 매뉴얼을 연결하지 않는 경우
  • 현장 검증과 교육 없이 배포만 하는 경우
  • 개정번호와 개정 이력이 없어 최신본을 구별하지 못하는 경우

🔗 세 학습목표의 통합 흐름

설비와 유해·위험요인 파악에서 현장의 위험과 사고 시나리오를 찾아. 이어서 안전보건관리규정에 따른 절차 파악을 통해 책임, 승인, 작업중지, 보고와 기록체계에 연결해. 마지막으로 분야별 매뉴얼 개발에서 이를 작업 전·중·후와 비상 시 행동으로 바꾸고 점검표, 교육, 훈련과 개정체계를 붙여.

기억할 흐름은 찾기 → 평가하기 → 절차로 연결하기 → 행동 가능한 매뉴얼로 만들기 → 현장에서 검증하기야. 위험조사 없이 만든 매뉴얼은 현장 위험을 놓치고, 규정과 연결하지 않은 매뉴얼은 책임과 권한이 사라지며, 교육과 검증이 없는 매뉴얼은 실행되지 않아.

✍️ 실기형 작성 틀

설비와 위험요인 파악: 자료 검토 → 현장조사 → 작업단계 분해 → 위험요인 도출 → 위험성 판단 → 개선 → 재평가와 기록

안전관리 절차 파악: 적용 기준 → 적용 범위 → 책임과 권한 → 개시 조건 → 수행 순서 → 이상 시 조치 → 승인과 기록 → 교육과 개정

매뉴얼 개발: 목적·범위 → 위험성평가 → 역할 → 작업 전·중·후 조치 → 작업중지 조건 → 비상조치 → 점검표 → 현장 검증 → 교육·배포 → 개정관리

답안에서는 “개정 이력을 관리한다”로 끝내기보다 “현장에 구본과 최신본이 혼재해 잘못된 절차가 사용되는 것을 방지하기 위해 개정 이력을 관리한다”처럼 조치의 목적까지 연결하면 좋아.

❓ 확인 문제

  1. 컨베이어의 정상 운전 외에 확인해야 할 작업 상태 세 가지와 그 이유를 설명해봐.
  2. “프레스가 위험하다”를 구체적인 사고 시나리오로 고쳐봐.
  3. 위험성 감소대책의 일반적인 우선순위 다섯 단계를 써봐.
  4. 안전보건관리규정에 따른 절차의 핵심 요소를 여섯 가지 이상 써봐.
  5. 규정, 절차서, 매뉴얼과 기록의 차이를 설명해봐.
  6. 매뉴얼에 포함해야 할 두 가지 비정상 상황 관련 항목을 써봐.
  7. 정비 전에 정지 버튼만 누르는 조치가 충분하지 않은 이유를 설명해봐.
  8. 매뉴얼 제정 후 현장 검증을 해야 하는 이유와 방법을 써봐.

✅ 정답 및 해설

  1. 청소, 점검·정비, 막힘 제거를 들 수 있어. 비정상 작업에서는 위험점 접근, 방호장치 해제와 불시 기동 가능성이 커져.
  2. “프레스 금형 사이의 불량품을 손으로 제거하던 중 슬라이드가 불시에 하강하여 손이 협착·절단될 수 있다.” 위험원, 노출 상황, 사고 형태와 결과가 모두 드러나.
  3. 제거 → 대체 → 공학적 조치 → 관리적 조치 → 개인보호구야.
  4. 목적, 적용 범위, 책임과 권한, 개시 조건, 수행 순서, 판단 기준, 이상 시 조치, 승인, 기록, 교육과 개정관리 가운데 여섯 가지 이상을 쓰면 돼.
  5. 규정은 원칙과 책임, 절차서는 처리 순서, 매뉴얼은 구체적인 현장 행동, 기록은 이행 증거를 담당해.
  6. 이상 발견 시 작업중지·보고와 비상 시 대응·대피야.
  7. 자동 신호, 타인의 조작과 잔류에너지로 설비가 움직일 수 있으므로 에너지원을 격리하고 잠금·표지, 잔류에너지 해소와 무동작 확인을 해야 해.
  8. 절차가 실제 작업에서 가능한지와 표현이 명확한지 확인하기 위해 필요해. 실제 사용자가 모의 작업을 하고 관찰·면담·점검표로 문제를 찾아 수정해.

✨ 요약

  • 조사 범위: 설비뿐 아니라 작업자, 작업방법, 환경과 관리 상태를 함께 살펴야 해.
  • 비정상 작업: 청소, 정비, 막힘 제거, 시운전과 재가동을 반드시 확인해.
  • 사고 시나리오: 위험원, 노출 상황, 사고 형태와 결과가 드러나게 작성해.
  • 대책 우선순위: 제거, 대체, 공학적 조치, 관리적 조치, 개인보호구 순으로 검토해.
  • 절차의 골격: 책임과 권한, 개시 조건, 수행 순서, 판단 기준, 이상 시 조치, 승인, 기록과 개정체계가 필요해.
  • 문서 구분: 규정은 원칙, 절차서는 순서, 매뉴얼은 행동, 기록은 증거야.
  • 매뉴얼 완성: 현장 검증, 승인, 배포, 교육·훈련, 최신본 관리와 지속적인 개정까지 수행해야 해.
