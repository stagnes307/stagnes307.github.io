산업안전기사 실기 · LESSON 1-10-1-2

공정도면에서 폭발위험까지 읽는 법

유해·위험 설비의 공정도면을 확인하여 유해·위험 설비의 운전방법에 의한 위험 요인을 파악할 수 있다. · 유해·위험 설비, 폭발 위험이 있는 장소를 사전에 파악하여 사고 예방활동용의 필요점을 파악할 수 있다.

도면 확인운전 이탈누출·축적점화·사고

READ THE SYSTEM

공정도면은 사고가 이동하는 지도야

도면의 선 하나는 단순한 배관이 아니라 물질과 에너지의 이동 통로야. 설비가 어떻게 연결됐는지 읽은 다음 압력·온도·유량·액위가 정상범위를 벗어날 때 어떤 사고가 이어지는지 추적해야 해.

좋은 위험요인 문장은 결과만 말하지 않아. 원인 → 공정 이탈 → 누출 또는 설비 손상 → 점화 → 사고 결과를 연결해. 예를 들면 “반응기 냉각수 공급 중단으로 온도와 압력이 상승하여 설비가 파열되고 가연성 물질이 누출될 위험”이라고 써야 해.

DRAWING SET

도면마다 찾아야 할 단서가 달라

01PFD주요 설비, 물질 흐름, 공정조건의 큰 변화를 읽어. 고온·고압 구간을 찾는 출발점이야.
02P&ID배관, 밸브, 계측기, 경보, 인터록, 안전밸브와 방출계통을 구체적으로 확인해.
03배치도설비 간 거리, 확산 방향, 방유제, 대피로와 인접 설비의 연쇄영향을 살펴봐.
04위험장소 구분도폭발성 분위기 형성 범위와 방폭 전기기기 적용의 적정성을 판단해.

PFD로 큰 흐름을 잡고 → P&ID에서 사고 원인과 보호장치를 찾고 → 배치도와 위험장소 구분도로 공간적 결과를 검증해.

INSPECTION ROUTE

도면 검토는 여섯 단계로 진행해

위험물질 표시

가연성·독성·부식성·반응성 물질의 이동경로를 표시하고 인화점, 폭발범위, 증기밀도와 자연발화온도를 확인해.

정상범위와 설계한계 비교

압력·온도·유량·액위의 정상값이 설계한계와 얼마나 떨어져 있는지 확인해. 여유가 작으면 작은 변동도 위험해져.

운전 이탈 가정

유량 없음·과다·역류, 고온·고압, 냉각수 상실, 밸브 오조작, 펌프 정지와 계측기 오지시를 적용해 봐.

보호장치 추적

감지기, 경보, 인터록, 긴급차단밸브와 안전밸브가 적절한 순서와 설정값으로 작동하는지 확인해.

방출 목적지 확인

안전밸브나 벤트의 방출물이 작업장으로 나오지 않고 플레어·스크러버 등 안전한 처리계통으로 이동하는지 살펴봐.

현장 일치 검증

도면의 개정번호를 확인하고 실제 밸브, 임시배관, 맹판과 우회배관이 최신 도면과 일치하는지 확인해.

OPERATING MODES

정상운전 밖에서 위험은 더 선명해져

시동설비 내부 공기와 가연성 물질이 함께 존재할 수 있어. 불활성가스 치환과 밸브 정렬이 불충분하면 폭발성 혼합물이 생겨.
정지·비상정지원료와 열원을 차단하더라도 압력이 갇히면 안 돼. 냉각·교반·안전한 감압 중 무엇을 유지할지 절차로 정해야 해.
정비·재가동차단, 잠금, 잔압 제거, 세정, 치환과 가스농도 측정이 필요해. 재가동 전에는 열린 드레인과 임시 맹판도 확인해.
시험 포인트: 비상정지는 모든 밸브를 무조건 닫는 조작이 아니야. 위험물질 공급은 차단하되 압력의 안전한 배출경로와 필수 냉각기능은 확보해야 해.

HAZARDOUS AREA

폭발 위험장소는 누출·축적·점화의 교차점이야

누출과 축적을 결정하는 요소

  • 펌프 축봉, 플랜지, 밸브 스템, 통기관과 시료채취구
  • 누출 빈도·지속시간·압력과 개구부 크기
  • 증기밀도, 폭발범위와 물질의 온도
  • 환기 성능, 장애물, 피트·배수구와 지형

점화를 결정하는 요소

  • 비방폭 전기기기의 스파크와 고온 표면
  • 정전기 방전과 기계적 마찰·충격
  • 용접·절단·흡연 등 화기작업
  • 차량, 휴대용 전기기기와 낙뢰

공기보다 무거운 가연성 증기는 낮은 피트와 배수구에 체류하기 쉬워. 가벼운 가스도 상부 환기가 불량하면 축적될 수 있으므로 “가스는 위, 증기는 아래”처럼 단순 암기하지 말고 물질 특성과 실제 공기 흐름을 함께 판단해야 해.

BARRIER SYSTEM

사고 경로를 끊는 장벽은 여러 겹이어야 해

예방위험물질 대체, 밀폐, 내식재료, 예방정비로 누출 확률을 낮춰.
감지계측기와 경보, 가스검지기로 이상을 조기에 알려.
제어인터록, 긴급차단과 안전밸브로 공정 이탈을 제한해.
완화소화설비, 방유제, 살수와 대피체계로 사고 결과를 줄여.

방폭기기는 누출을 막는 장벽이 아니라 점화 가능성을 낮추는 장벽이야. 설비 밀폐와 예방정비, 환기, 가스검지, 점화원 통제가 함께 작동해야 해.

FIELD CASE

용제 이송공정에 적용해 보자

인화성 용제를 저장탱크에서 펌프로 보내 반응기에 공급한다고 가정해. 반응기 입구밸브가 닫힌 채 펌프를 운전하면 토출측이 막히고 압력이 올라가. 플랜지나 호스가 손상되면 용제가 누출·증발하고, 증기가 피트에 축적된 뒤 비방폭 모터나 정전기와 만나 화재·폭발이 발생할 수 있어.

  1. 도면 단서: 토출압력계, 고압경보, 재순환배관, 긴급차단밸브와 안전한 방출경로
  2. 운전 대책: 가동 전 밸브 정렬 확인, 펌프 기동 순서 준수와 이상압력 시 즉시 정지
  3. 장소 대책: 환기, 가스검지기, 방폭 전기기기, 접지·본딩과 화기작업 통제
  4. 피해완화: 비상차단, 방유제, 소화설비, 대피로와 비상연락체계

EXAM BOUNDARIES

비교와 시험 함정

잘못된 판단

“PFD에 주요 설비가 있으니 모든 밸브와 인터록도 확인할 수 있다.”

바른 판단

세부 배관·밸브·계장·인터록은 P&ID에서 추적해야 해.

잘못된 판단

“안전밸브가 표시되어 있으므로 과압 대책은 충분하다.”

바른 판단

설정압력, 용량, 차단 가능성, 배출 목적지와 처리계통까지 확인해야 해.

잘못된 판단

“정상 운전조건만 설계범위에 있으면 안전하다.”

바른 판단

시동·정지·비상·정비 중 발생하는 조성 변화, 잔압과 오조작도 검토해야 해.

SELF CHECK

확인 문제

문제 1. P&ID에서 과압 위험을 검토할 때 확인해야 할 사항을 네 가지 쓰시오.
문제 2. 반응기 냉각수 공급이 중단될 때 예상되는 사고 진행 경로와 필요한 보호장치를 설명하시오.
문제 3. 폭발 위험장소를 판단할 때 고려할 요소를 다섯 가지 쓰시오.
문제 4. “방폭형 전동기를 설치했으므로 누출 위험도 제거되었다”라는 판단이 틀린 이유를 쓰시오.

MODEL ANSWER

정답과 해설

1. 막힌 구간의 형성 가능성, 압력계와 고압경보, 자동차단 인터록, 안전밸브 또는 파열판, 전후단 차단밸브 상태, 방출배관의 최종 목적지 가운데 네 가지를 구체적으로 쓰면 돼.
2. 냉각수 상실 → 온도 상승 → 반응속도와 발열 증가 → 압력 상승 → 누출 또는 파열 → 화재·폭발로 이어져. 온도·압력 감지, 고온·고압 경보, 원료 자동차단, 비상냉각, 안전밸브와 안전한 방출계통이 필요해.
3. 누출원, 누출 빈도와 지속시간, 물질의 폭발범위·증기밀도, 환기상태, 피트와 장애물 같은 지형, 점화원, 방폭기기 적합성을 고려해야 해.
4. 방폭형 전동기는 폭발성 분위기의 점화를 억제할 뿐 누출 자체를 제거하지 않아. 밀폐, 설비 건전성, 예방정비, 환기, 가스검지와 긴급차단이 별도로 필요해.

RECALL MAP

회상 요약

  • PFD로 큰 흐름을 읽고 P&ID로 사고 원인과 보호장치를 찾아.
  • 위험요인은 원인 → 운전 이탈 → 누출 → 점화 → 결과로 연결해 표현해.
  • 정상뿐 아니라 시동, 정지, 비상정지, 정비와 재가동을 모두 검토해.
  • 폭발 위험장소는 누출원, 물질 특성, 환기, 지형과 점화원을 함께 판단해.
  • 예방·감지·제어·피해완화 장벽을 여러 겹으로 구성해.
  • 최신 도면과 실제 현장이 일치하는지 반드시 검증해.

흐름을 읽고 → 이탈을 찾고 → 결과를 연결하고 → 장벽으로 끊는다
