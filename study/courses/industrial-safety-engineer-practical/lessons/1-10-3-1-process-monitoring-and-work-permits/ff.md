이번 수업의 핵심은 두 가지야. 첫째, 정해 둔 안전지침이 실제 현장에서 지켜지는지를 **증거에 근거해 확인하는 능력**이야. 둘째, 위험한 작업을 시작하기 전에 조건을 검토하고 승인하며, 작업 중 조건이 달라지면 허가를 중지하거나 다시 발급하는 **안전작업허가 통제 능력**이야.

원문에는 ‘안적작업허가’라고 적혀 있지만, 수업에서는 통상적인 용어인 **안전작업허가**로 설명할게. 다만 아래에는 요구된 topic 원문도 그대로 보존했어.

## 1. 전체 작업 흐름: 지침이 종이라면 모니터링과 작업허가는 현장의 방어선이야

안전지침은 작업자가 따라야 할 기준을 정하고, 모니터링은 실제 행동과 현장 상태가 그 기준에 일치하는지 확인해. 작업허가는 특히 위험도가 높은 비정상 작업에 대해 “지금 이 장소에서, 이 인원이, 이 방법으로 작업해도 되는가?”를 작업 시작 전에 판단하는 절차야.

두 제도는 다음과 같이 연결돼.

| 단계 | 핵심 활동 | 확인할 증거 | 조건 미충족 시 조치 |
|---|---|---|---|
| 작업 계획 | 작업 범위와 위험요인 파악 | 작업계획서, 절차서, 물질 정보 | 계획 보완 |
| 작업 전 | 설비·물질·환경 조건 확인 | 점검표, 격리 상태, 측정 결과 | 작업 시작 금지 |
| 허가 승인 | 예방조치의 적정성 검토 | 작업허가서, 서명, 유효시간 | 승인 보류 |
| 작업 중 | 지침 준수와 조건 변화 감시 | 현장 관찰, 계측값, 기록 | 작업중지 또는 재허가 |
| 작업 종료 | 인원·공구·설비 상태 확인 | 종료 점검과 인계 기록 | 정상운전 복귀 금지 |
| 사후 개선 | 이탈 원인과 재발방지 검토 | 시정조치 기록, 교육 자료 | 절차 및 계획 개정 |

중요한 원칙은 **서류가 있다는 사실과 안전하게 작업한다는 사실은 다르다**는 거야. 허가서에 서명이 모두 있어도 격리가 풀렸거나 가스 농도가 변했다면 작업은 안전하지 않아. 반대로 작업자가 숙련됐더라도 필요한 허가를 생략하면 위험요인이 조직적으로 통제되지 않아.

## 2. Topic 1

### 유해·위험 설비 및 유해·위험물질의 취급시 개발된 안전지침 및 계획에 따라 작업이 이루어지는지 모니터링 할 수 있다.

### 2-1. 정의와 목적

**모니터링**은 작업 전·중·후의 상태와 행동을 관찰하고 측정하여, 실제 작업이 승인된 안전지침과 계획에 부합하는지 판단하는 활동이야. 단순히 현장을 둘러보는 순찰이 아니라 다음 네 요소를 연결하는 통제 과정이지.

1. **기준 설정**: 무엇을 준수해야 하는가  
2. **현장 확인**: 실제 상태와 행동은 어떠한가  
3. **차이 판정**: 기준에서 이탈했는가  
4. **조치와 검증**: 이탈을 바로잡았으며 효과가 있는가  

모니터링의 최종 목적은 위반자를 찾는 데 있지 않아. 화재·폭발·누출로 이어질 수 있는 **작은 이탈을 사고 전에 발견하고 제거하는 것**이야. 자동차 계기판이 고장 난 뒤 책임자를 찾는 장치가 아니라 운전 중 이상을 조기에 알리는 장치인 것과 같아.

### 2-2. 모니터링 기준의 준비

현장 확인 전에 먼저 적용 기준을 분명히 해야 해. 기준이 모호하면 관찰자의 경험에 따라 판정이 달라지기 때문이야.

반드시 확인할 자료는 다음과 같아.

1. 설비의 안전운전지침과 작업절차서  
2. 해당 작업의 작업계획서와 위험성평가 결과  
3. 취급 물질의 유해성·위험성 정보와 저장·취급 조건  
4. 배관계장도, 설비 배치도, 차단 및 격리 계획  
5. 비상조치 계획과 누출·화재 시 연락체계  
6. 필요한 작업허가서와 부속 점검표  
7. 작업자의 교육·훈련 및 자격 확인 자료  
8. 보호구 선정 기준과 착용 방법  
9. 점검·검사·정비 주기 및 계측기 교정 상태  
10. 과거 사고, 아차사고, 자체감사 및 시정조치 기록  

이때 기준은 “조심해서 취급한다”처럼 추상적이면 안 돼. “밸브를 잠근다”, “압력을 제거한다”, “가스 농도를 측정한다”, “감시인을 배치한다”처럼 **관찰하거나 측정할 수 있는 문장**으로 바꿔야 해.

### 2-3. 작업 전 모니터링

작업 전에는 사람, 설비, 물질, 환경, 절차를 함께 확인해야 해.

| 구분 | 핵심 확인사항 |
|---|---|
| 사람 | 작업 책임자와 작업자 지정, 교육·자격, 역할 이해, 건강 상태 |
| 설비 | 정지 여부, 압력·온도 제거, 밸브 차단, 맹판 설치, 잠금·표지 |
| 물질 | 물질명, 인화성·독성·부식성, 혼합금지 물질, 잔류물 |
| 환경 | 환기, 점화원, 출입 통제, 주변 동시작업, 대피로 |
| 절차 | 최신 절차서 사용, 작업 순서, 비상조치, 변경사항 반영 |
| 보호 | 보호구, 소화설비, 누출 대응 장비, 구조 장비 |
| 측정 | 산소, 가연성가스, 유해가스, 계측기 기능 및 교정 상태 |

작업자는 절차를 받았다는 이유만으로 이해했다고 볼 수 없어. 작업 시작 전에 작업자에게 “누출되면 무엇을 먼저 해야 하는가?”, “어느 밸브가 격리 경계인가?”처럼 질문해 **이해도를 교차 확인**해야 해.

### 2-4. 작업 중 모니터링

작업 중에는 초기 조건이 계속 유지되는지를 확인해야 해. 위험은 고정되어 있지 않고 작업 진행에 따라 변하기 때문이야.

예를 들어 배관을 개방하기 전에는 가스가 검출되지 않았어도, 내부 잔류물이 이동하거나 인접 설비에서 유입되면 농도가 상승할 수 있어. 따라서 최초 측정값 하나만 믿지 말고 위험 특성에 따라 연속 측정 또는 주기적 재측정을 해야 해.

중점적으로 관찰할 항목은 다음과 같아.

1. 승인된 작업 범위와 방법을 지키는가  
2. 격리·잠금·표지 상태가 유지되는가  
3. 보호구를 올바르게 착용하는가  
4. 환기와 가스 측정이 지속되는가  
5. 불티·열·정전기 등 점화원이 통제되는가  
6. 감시인이 자리를 지키고 다른 업무를 하지 않는가  
7. 허가받지 않은 인원이나 장비가 들어오지 않는가  
8. 누출, 냄새, 소음, 진동, 압력 변화가 발생하지 않는가  
9. 인접 작업이 새로운 위험을 만들지 않는가  
10. 작업 범위·시간·인원·공법이 임의로 변경되지 않는가  

### 2-5. 이탈 발견과 조치 원칙

이탈을 발견하면 그 심각도에 따라 대응해야 해.

**즉시 작업중지 대상**은 화재·폭발·중독·질식 등 급박한 위험이 있거나, 핵심 방호조치가 상실된 경우야. 가스 농도 상승, 격리 해제, 환기 정지, 감시인 부재, 허가 범위 밖의 작업, 비상대피로 차단이 대표적이야.

조치 순서는 다음과 같아.

1. 위험 작업을 즉시 중지한다.  
2. 작업자를 안전한 장소로 대피시킨다.  
3. 점화원과 에너지원을 통제한다.  
4. 작업책임자와 관련 부서에 알린다.  
5. 누출 확산 방지 등 비상조치를 시행한다.  
6. 이탈 원인과 영향 범위를 확인한다.  
7. 필요한 시정조치를 완료한다.  
8. 안전조건을 다시 점검하고 측정한다.  
9. 기존 허가의 유효성을 검토한다.  
10. 조건이 변경됐다면 재위험성평가와 재허가 후 작업을 재개한다.  

**작업중지 → 원인 확인 → 시정 → 재검증 → 재승인**의 연결을 기억하면 좋아. 위험조건이 사라졌다는 확인 없이 “이제 괜찮아 보인다”는 판단만으로 재개하면 안 돼.

### 2-6. 구체적인 예시

인화성 용제가 남아 있을 수 있는 저장탱크의 배관 교체 작업을 생각해 보자.

작업 전에는 탱크와 배관의 연결을 차단하고, 내부 압력을 제거하며, 필요하면 세정·치환·환기를 실시해야 해. 잠금장치와 표지를 부착한 뒤 산소와 가연성가스 농도를 적합한 계측기로 측정해. 작업자는 물질의 위험성과 비상대피 방법을 알아야 하고, 주변의 점화원과 동시작업도 확인해야 해.

작업 중 감시자가 배관에서 용제 냄새를 감지하고 가연성가스 측정값의 상승을 확인했다면 작업을 즉시 중지해야 해. “아직 폭발범위에 들어가지 않았다”는 이유로 계속 진행하면 안 돼. 농도 상승 자체가 격리나 세정이 충분하지 않을 가능성을 보여 주기 때문이야.

작업자는 안전지역으로 이동하고, 점화원을 제거한 뒤 격리 상태와 잔류물 유입 경로를 다시 확인해야 해. 추가 환기와 재측정 후에도 작업 조건이 최초 허가와 달라졌다면 기존 허가를 그대로 사용하지 않고 위험성을 재검토하여 허가를 다시 받아야 해.

### 2-7. 비교와 경계

| 올바른 모니터링 | 잘못된 모니터링 |
|---|---|
| 절차서와 현장을 대조한다 | 서류 보유 여부만 본다 |
| 직접 관찰하고 측정한다 | 작업자의 말만 듣는다 |
| 정상 상태와 이상징후를 함께 확인한다 | 명백한 위반만 찾는다 |
| 작업 조건의 변화를 추적한다 | 작업 전 점검 한 번으로 끝낸다 |
| 즉시조치와 근본조치를 구분한다 | 현장에서 임시로 고치고 종결한다 |
| 시정조치의 효과를 재확인한다 | 조치 지시만 기록한다 |

모니터링은 작업자를 감시해 처벌하는 활동과도 구분해야 해. 처벌 중심의 분위기에서는 작업자가 누출이나 절차 이탈을 숨길 수 있어. 작은 이상을 자유롭게 보고하고 즉시 멈출 수 있어야 예방 기능이 살아나.

### 2-8. 시험 함정

1. **순찰과 모니터링을 동일시하는 함정**  
   모니터링에는 기준 비교, 측정, 이탈 판정, 시정조치, 효과 확인이 포함돼.

2. **작업 전 점검으로 끝내는 함정**  
   작업 조건은 변하므로 작업 중 감시와 필요 시 재측정이 중요해.

3. **개인보호구만 강조하는 함정**  
   위험원 제거, 설비 격리, 환기 같은 공학적·관리적 통제가 우선 검토돼야 해.

4. **이탈 발견 후 구두주의만 하는 함정**  
   급박한 위험이면 즉시 작업을 중지하고 안전조건을 회복한 뒤 재승인해야 해.

5. **기록을 사후에 한꺼번에 작성하는 함정**  
   측정값, 시간, 장소, 조치 결과는 추적 가능하도록 사실에 근거해 기록해야 해.

## 3. Topic 2

### 작업허가가 필요한 작업에 대하여 안적작업허가 기준에 부합된 절차에 따라 작업허가를 할 수 있다.

### 3-1. 안전작업허가의 정의

**안전작업허가제도**는 화재·폭발·누출·질식·감전과 같은 중대위험이 있는 작업을 시작하기 전에 작업 조건과 예방조치를 검토하고, 권한이 있는 사람이 일정한 범위와 시간에 한해 작업을 승인하는 제도야.

작업허가서는 단순한 서명이 아니라 다음 내용이 합쳐진 통제 장치야.

1. 어떤 작업을 하는가  
2. 어디에서 하는가  
3. 어떤 위험이 있는가  
4. 위험을 어떻게 제거하거나 통제했는가  
5. 누가 확인하고 승인했는가  
6. 언제까지 허가가 유효한가  
7. 어떤 조건에서 작업을 중지해야 하는가  
8. 종료 후 설비를 어떻게 인계할 것인가  

허가의 본질은 책임 전가가 아니라 **관련 부서 간의 위험정보 공유와 교차 확인**이야.

### 3-2. 작업허가가 필요한 대표 작업

사업장의 설비와 절차에 따라 구체적인 명칭과 범위는 달라질 수 있지만, 일반적으로 다음과 같은 고위험 작업을 관리해.

| 작업 유형 | 대표 위험 | 핵심 통제 |
|---|---|---|
| 화기작업 | 불티·열에 의한 화재와 폭발 | 가연물 제거, 가스 측정, 소화기, 화재감시 |
| 밀폐공간작업 | 산소결핍, 유해가스, 구조 곤란 | 환기, 가스 측정, 감시인, 구조계획 |
| 전기작업 | 감전, 아크, 화재 | 전원 차단, 검전, 잠금·표지, 방호구 |
| 굴착작업 | 붕괴, 매설물 파손, 추락 | 지하설비 확인, 흙막이, 출입 통제 |
| 고소작업 | 추락, 낙하물 | 작업발판, 안전대, 하부 통제 |
| 중량물 인양작업 | 낙하, 충돌, 전도 | 중량·중심 확인, 장비 점검, 신호수 |
| 배관·용기 개방 | 잔압, 유해물질 분출, 누출 | 격리, 압력 제거, 배출·세정 |
| 방사선·유해물질 작업 | 피폭, 중독, 오염 | 구역 통제, 측정, 전용 보호구 |

하나의 작업에 여러 허가가 동시에 필요할 수도 있어. 예를 들어 탱크 내부에서 용접한다면 밀폐공간작업과 화기작업의 위험을 통합해서 검토해야 해.

### 3-3. 작업허가 절차

#### 1단계: 작업 신청과 범위 확정

작업명, 장소, 설비번호, 작업 내용, 예정시간, 참여인원, 사용 장비와 공구를 명확히 적어야 해. “배관 정비”처럼 넓게 쓰면 허가 범위가 불분명해지므로 “반응기 공급배관의 특정 밸브 교체”처럼 대상을 식별할 수 있게 작성해야 해.

#### 2단계: 현장 위험성 확인

작업 대상 설비만 보지 말고 주변 설비, 상하부 작업, 물질 이동, 차량 통행, 점화원, 기상 조건까지 확인해. 정비부서와 운전부서가 함께 현장을 확인하면 작업 특성과 공정 특성을 교차 검증할 수 있어.

#### 3단계: 에너지와 유해물질의 격리

전기, 압력, 열, 중력, 회전력, 유압, 공압, 화학에너지 등 예상하지 못한 작동이나 방출을 일으킬 에너지를 확인해. 단순히 스위치를 끄는 것에 그치지 않고 차단, 잠금, 표지, 잔류에너지 제거와 영점 확인을 실시해야 해.

화학설비에서는 밸브 폐쇄만으로 충분한지 검토하고, 위험도가 높으면 맹판 설치나 배관 분리 같은 신뢰도 높은 격리 방법을 적용해야 해.

#### 4단계: 예방조치와 비상조치 확인

환기, 가스 측정, 가연물 제거, 소화기 배치, 감시인 지정, 출입 통제, 보호구, 구조장비, 통신수단과 비상대피 경로를 확인해. 각 조치는 실제로 준비됐는지 현장에서 확인해야지 허가서의 ‘적합’ 칸만 표시하면 안 돼.

#### 5단계: 측정과 판정

가스 측정이 필요하다면 예상 위험에 맞는 계측기를 선정하고 기능과 교정 상태를 확인해야 해. 측정 장소, 시간, 측정자, 산소·가연성가스·유해가스 결과를 기록하고, 작업 중 재측정 주기도 정해야 해.

한 지점의 결과만으로 공간 전체가 안전하다고 단정하면 안 돼. 기체의 특성, 공간 구조, 환기 상태를 고려하여 상부·중부·하부와 작업지점 등 대표 위치를 확인해야 해.

#### 6단계: 허가 승인과 전달

허가권자는 작업 조건과 예방조치가 기준에 부합하는지 확인한 뒤 서명해. 신청자가 작성했다는 이유만으로 자동 승인해서는 안 돼. 작업 책임자는 허가 조건을 작업자에게 설명하고, 작업자들은 자신의 역할과 작업중지 조건을 이해해야 해.

#### 7단계: 작업 중 감시

허가서와 부속 점검표는 작업 현장에서 확인할 수 있어야 해. 감시자는 허가 범위, 격리 상태, 측정값, 인원, 보호구와 주변 조건을 확인해. 조건이 변하면 작업을 중지하고 허가의 유효성을 다시 판단해야 해.

#### 8단계: 종료 확인과 인계

작업이 끝나면 인원과 공구가 모두 철수했는지, 방호장치가 복구됐는지, 설비 내부에 이물질이 남지 않았는지 확인해. 운전부서와 정비부서가 설비 상태를 함께 확인하고, 잠금장치 해제와 정상운전 복귀 절차를 거쳐야 해.

### 3-4. 작업허가의 유효성 상실 조건

다음과 같은 경우에는 기존 허가를 그대로 유지하기 어려워.

1. 허가된 작업시간이 끝난 경우  
2. 작업 장소나 범위가 변경된 경우  
3. 작업 방법이나 사용 장비가 변경된 경우  
4. 작업 책임자나 주요 작업자가 교체된 경우  
5. 가스 농도나 공정 조건이 변한 경우  
6. 경보 발생이나 누출 등 비상상황이 생긴 경우  
7. 교대 후 인계가 적절히 이루어지지 않은 경우  
8. 격리·환기·감시 등 핵심 안전조치가 상실된 경우  
9. 인접 작업이 새로운 위험을 만든 경우  
10. 작업이 장시간 중단된 뒤 재개되는 경우  

이런 변화가 생기면 먼저 작업을 멈추고 위험성을 다시 평가해야 해. 변경의 영향에 따라 허가 연장, 재승인 또는 신규 허가가 필요해. 허가서의 시간만 임의로 고치는 행위는 허가 절차가 아니야.

### 3-5. 구체적인 예시

가연성 물질을 취급하던 배관 근처에서 그라인딩 작업을 한다고 해보자.

작업 책임자는 작업 장소와 범위를 특정하고 화기작업 허가를 신청해. 운전부서는 해당 배관의 물질과 운전 상태를 확인하고, 누출 가능성과 인접 공정의 영향을 검토해. 주변 가연물을 제거하거나 방호하고, 배수구와 개구부를 통한 증기 유입 가능성도 확인해야 해.

가스 측정 결과가 허용된 작업 조건에 부합하는지 판정하고, 소화기와 화재감시인을 배치해. 작업자에게 불티의 비산 방향, 중지 기준, 비상연락 방법을 설명한 후 권한 있는 허가자가 승인해.

작업 도중 인접 공정에서 배관 세정이 시작되어 용제 증기가 유입될 가능성이 생겼다면 기존 허가의 전제가 달라진 거야. 실제 불꽃이 물질에 닿지 않았더라도 즉시 작업을 중지하고 인접 작업과의 간섭 위험을 다시 평가해야 해. 안전조건을 재확인하고 필요한 조치를 마친 다음 재승인해야 해.

### 3-6. 작업허가와 관련 제도의 비교

| 구분 | 작업허가 | 위험성평가 | 작업계획서 | 작업절차서 |
|---|---|---|---|---|
| 중심 질문 | 지금 이 작업을 시작해도 되는가 | 무엇이 얼마나 위험한가 | 작업을 어떻게 준비·수행할 것인가 | 반복 작업을 어떤 순서로 할 것인가 |
| 적용 시점 | 특정 작업 직전과 수행 중 | 작업 전 및 변경 시 | 작업 준비 단계 | 표준 절차 수립 시 |
| 주요 결과 | 제한된 범위·시간의 승인 | 위험도와 감소대책 | 인원·장비·순서·안전조치 | 표준 수행 방법 |
| 상호관계 | 다른 자료의 적정성을 최종 확인 | 허가 조건의 근거 제공 | 허가 신청의 세부 근거 | 작업자의 행동 기준 제공 |

이 네 제도는 서로 대체하지 않아. 위험성평가를 했다고 작업허가가 자동으로 발급되는 것도 아니고, 허가서를 받았다고 작업절차를 생략할 수도 없어.

### 3-7. 시험 함정

1. **허가서를 면책 서류로 보는 함정**  
   서명이 있어도 현장 조건이 부적합하면 작업을 시작하거나 계속하면 안 돼.

2. **신청자와 허가자의 역할을 혼동하는 함정**  
   작업을 요청하고 준비한 사람과 독립적으로 조건을 검토해 승인하는 권한의 구분이 중요해.

3. **밸브 폐쇄만으로 완전 격리됐다고 판단하는 함정**  
   밸브 누설과 오조작 가능성을 고려해 위험도에 맞는 격리 방법을 선택해야 해.

4. **최초 가스 측정값을 계속 유효하다고 보는 함정**  
   환기 중단, 잔류물 이동, 외부 유입으로 조건이 달라질 수 있어.

5. **작업 종료와 설비 인계를 같은 것으로 보는 함정**  
   작업이 끝났어도 인원·공구 확인, 방호 복구, 격리 해제와 운전부서 인계가 남아 있어.

6. **허가 범위를 작업자가 임의로 확대하는 함정**  
   범위·공법·장비가 변경되면 작업을 멈추고 재검토해야 해.

## 4. 두 Topic의 통합 실무 절차

### 4-1. 작업 전

1. 작업 대상과 범위를 특정한다.  
2. 최신 안전지침과 작업계획서를 확보한다.  
3. 설비·물질·주변 환경의 위험요인을 확인한다.  
4. 필요한 작업허가 유형을 결정한다.  
5. 위험성평가 결과에 따라 예방조치를 정한다.  
6. 에너지와 유해물질을 차단·격리한다.  
7. 환기, 측정, 보호구, 감시인, 비상장비를 준비한다.  
8. 현장에서 조치의 완료 여부를 교차 확인한다.  
9. 작업자에게 허가 조건과 중지 기준을 설명한다.  
10. 권한 있는 사람이 허가하고 유효시간을 명시한다.  

### 4-2. 작업 중

1. 허가된 범위와 방법을 준수하는지 관찰한다.  
2. 격리·환기·출입 통제 상태를 확인한다.  
3. 필요한 가스 농도와 설비 상태를 재측정한다.  
4. 인접 작업과 공정조건의 변화를 감시한다.  
5. 이탈이나 이상징후가 나타나면 즉시 작업을 중지한다.  
6. 원인과 영향 범위를 확인한 뒤 시정한다.  
7. 최초 조건이 달라졌으면 위험성을 재평가하고 재허가한다.  

### 4-3. 작업 후

1. 작업 종료와 잔여 위험을 확인한다.  
2. 인원, 공구, 자재의 철수를 확인한다.  
3. 임시 방호물과 작업 장비를 안전하게 제거한다.  
4. 설비의 방호장치와 정상 상태를 복구한다.  
5. 운전부서와 정비부서가 상태를 공동 확인한다.  
6. 정해진 절차에 따라 격리와 잠금을 해제한다.  
7. 허가서를 종결하고 작업 결과와 이탈사항을 기록한다.  
8. 반복되는 이탈은 원인을 분석해 지침·교육·설비를 개선한다.  

***

## 5. 실기 답안 구성법

서술형 문제에서는 **대상 → 위험 확인 → 예방조치 → 승인 → 감시 → 이상 시 조치 → 종료 확인** 순서로 쓰면 답안의 구조가 안정돼.

예를 들어 “안전작업허가 절차를 쓰시오”라는 문제가 나오면 다음 뼈대를 활용할 수 있어.

1. 작업 내용·장소·시간·인원을 명확히 하여 허가를 신청한다.  
2. 현장 위험성평가를 실시하고 필요한 안전조치를 결정한다.  
3. 설비와 에너지원을 차단·격리하고 잔류에너지를 제거한다.  
4. 환기, 가스 측정, 감시인, 보호구와 비상조치를 확인한다.  
5. 권한 있는 허가자가 현장 조건을 확인한 후 허가한다.  
6. 작업 중 허가 조건의 유지 여부를 감시한다.  
7. 조건이 변경되거나 이상이 발생하면 작업을 중지하고 재평가·재허가한다.  
8. 작업 종료 후 인원·공구·설비 상태를 확인하고 허가를 종결한다.  

문제가 요구한 개수를 먼저 확인해야 해. “4가지를 쓰시오”라고 했는데 8개를 장황하게 쓰기보다, 채점 가능한 핵심 항목을 서로 겹치지 않게 제시하는 편이 좋아.

## 6. 확인 문제

안전지침 준수 여부를 모니터링하는 활동과 가장 거리가 먼 것은 무엇일까?

1. 작업절차와 실제 작업을 대조한다.  
2. 설비 상태와 가스 농도를 확인한다.  
3. 이탈 발견 후 시정조치의 효과를 확인한다.  
4. 허가서에 서명이 있으므로 현장 확인을 생략한다.  

### 문제 2

작업 중 환기설비가 정지하고 가스 측정값이 상승했다. 가장 적절한 조치를 순서대로 서술해 봐.

### 문제 3

안전작업허가서에 포함하거나 확인해야 할 핵심사항을 다섯 가지 써 봐.

### 문제 4

다음 문장이 옳으면 O, 틀리면 X로 판단해 봐.

## 8. 요약

1. **모니터링**은 기준 설정, 현장 확인, 이탈 판정, 시정조치와 효과 검증을 연결하는 예방 활동이야.

2. 작업 전에는 사람·설비·물질·환경·절차·보호조치·측정 조건을 확인하고, 작업 중에는 그 조건이 계속 유지되는지 감시해야 해.

3. 급박한 위험이나 핵심 안전조치의 상실을 발견하면 **작업중지 → 대피와 위험 통제 → 원인 확인 → 시정 → 재검증 → 재승인** 순서로 대응해.

4. **안전작업허가**는 특정한 작업을 일정한 장소·범위·시간·조건 아래에서만 승인하는 제도야.

5. 허가 전에는 위험성 확인, 에너지 격리, 가스 측정, 환기, 보호구, 감시인, 비상조치와 작업자 교육을 실제 현장에서 확인해야 해.

6. 작업 범위, 방법, 인원, 시간 또는 주변 조건이 달라지면 기존 허가가 계속 유효하다고 단정할 수 없어. 먼저 작업을 중지하고 재평가와 재허가 여부를 판단해야 해.

7. 작업 종료는 공구를 내려놓는 순간이 아니야. 인원·공구 확인, 방호 복구, 격리 해제, 설비 인계와 허가 종결까지 완료해야 해.
