## 1. 안전시설 관리의 핵심 원리

### 1.1 안전시설은 설치보다 유지가 중요해

안전난간, 작업발판, 개구부 덮개, 추락방호망, 낙하물 방지망과 같은 시설은 설치한 순간부터 끝나는 설비가 아니야. 공정 진행, 자재 이동, 장비 충돌, 진동, 강풍, 부식, 임의 해체 때문에 성능이 계속 변할 수 있어.

예를 들어 안전난간이 외형상 멀쩡해 보여도 고정 볼트가 풀려 있다면 작업자가 기대는 순간 전도될 수 있어. 개구부 덮개도 덮여 있다는 사실만으로는 충분하지 않아. 이동하거나 뒤집히지 않도록 고정되어야 하고, 예상되는 하중을 견뎌야 하며, 작업자가 위험을 알아볼 수 있도록 표시되어야 해.

따라서 점검의 본질은 다음과 같아.

**현재 모습이 아니라 현재 방호성능을 확인한다.**

### 1.2 점검은 기준과 실제 상태를 비교하는 과정이야

점검자는 개인적인 감각으로 양호와 불량을 결정하면 안 돼. 먼저 적용 기준을 확인하고, 현장 상태를 조사한 다음, 두 값을 비교해서 적합 여부를 판정해야 해.

**적용 기준 확인 → 현장 관찰 → 치수·성능 측정 → 기준과 비교 → 적합성 판정 → 조치 → 재확인 → 기록**

이 순서는 체온계로 몸 상태를 판단하는 과정과 비슷해. 숫자를 측정하는 것만으로는 진단이 끝나지 않아. 정상 범위와 비교하고, 이상 원인을 찾고, 조치 후 다시 측정해야 비로소 관리가 완성돼.

### 1.3 법령·기준·지침의 관계

| 구분 | 역할 | 현장 확인 내용 |
|---|---|---|
| 관련 법령 | 사업주의 안전보건조치 의무와 관리 책임의 근거가 돼 | 필요한 방호조치가 시행됐는지 확인해 |
| 안전보건기준 | 시설별 설치·사용·관리 요건을 구체화해 | 구조, 설치 위치, 방호 상태와 작업방법을 확인해 |
| 기술지침 | 점검 방법과 판단 방법을 실무적으로 보완해 | 측정 위치, 점검 항목, 개선 방법을 정하는 데 활용해 |
| 제조자 기준 | 제품별 사용 한계와 유지관리 조건을 제시해 | 허용하중, 체결 방법, 교체 기준과 검사 주기를 확인해 |
| 현장 관리기준 | 공정과 위험성평가 결과를 현장에 적용해 | 책임자, 점검 주기, 통제 절차와 기록 방법을 확인해 |

법령은 개정될 수 있으므로 시험과 현장에서는 **점검 시점에 시행 중인 산업안전보건법령과 산업안전보건기준에 관한 규칙의 최신 조문**을 확인해야 해. 사내 기준이 법정 기준보다 느슨하다면 법정 기준을 따라야 하고, 사내 기준이 더 엄격하다면 더 엄격한 기준을 적용하는 게 원칙이야.

## 2. 기 설치된 안전시설의 점검 절차

### 2.1 사전 준비

점검 전에는 다음 자료를 확보해야 해.

1. 안전시설 배치도와 설치계획서
2. 설계도서와 구조 검토 자료
3. 제품 설명서와 성능 관련 자료
4. 위험성평가 결과
5. 이전 점검표와 보수 이력
6. 공정 변경 및 시설 이동 기록
7. 적용 법령, 기준, 기술지침
8. 측정 장비의 교정 또는 검증 상태

이전 기록과 현재 상태를 비교하면 반복되는 결함을 찾을 수 있어. 같은 장소에서 체결부 풀림이 계속 발생한다면 단순히 볼트를 다시 조이는 데서 끝내면 안 돼. 진동, 충돌, 설치 방식 또는 체결 구조 자체를 원인으로 의심해야 해.

### 2.2 현장 통제

점검 때문에 오히려 사고가 발생해서는 안 돼. 고소부, 개구부 주변 또는 중장비 이동구간을 점검한다면 작업구역을 구획하고 관계자 외 출입을 통제해야 해. 점검자가 방호시설을 흔들거나 일부를 해체해야 한다면 먼저 대체 방호조치를 마련해야 해.

중대한 결함이 발견되면 다음 순서로 대응해.

**작업 중지 또는 접근 통제 → 위험구역 표시 → 책임자 보고 → 보수·교체 → 재점검 → 사용 재개 승인**

### 2.3 육안·촉진 점검

눈으로 형상과 손상 상태를 확인하고, 허용되는 범위에서 손으로 체결 상태나 흔들림을 점검해. 다음 항목이 핵심이야.

1. 부재의 누락, 파손, 변형 또는 처짐
2. 볼트, 클램프, 용접부와 고정부의 이완
3. 부식, 균열, 마모 또는 절단
4. 시설의 임의 해체와 원상복구 누락
5. 통로와 작업공간을 방해하는 돌출부
6. 표시, 경고, 식별표지의 훼손
7. 자재 적치나 토사로 인한 기능 방해
8. 낙하물 방지시설 위의 잔해 축적
9. 작업발판의 들뜸, 이동, 틈 또는 미끄럼 위험
10. 주변 공정 변화로 새롭게 발생한 사각지대

### 2.4 측정 점검

육안점검으로 이상이 없어 보여도 치수와 성능을 측정해야 할 때가 있어. 설계값, 법정 기준, 제품 기준 또는 현장 승인값과 측정 결과를 비교해 적합 여부를 판단해.

측정 결과는 숫자 하나만 기록하면 부족해. **측정 위치, 측정값, 허용 기준, 장비 식별정보, 측정 일시, 측정자, 판정과 조치 내용**을 함께 남겨야 재현성과 책임성이 생겨.

### 2.5 개선 및 재확인

결함 조치에는 단계가 있어.

1. **즉시조치:** 출입통제, 작업중지, 임시 지지, 위험표지처럼 노출을 먼저 줄여.
2. **복구조치:** 조임, 재고정, 부재 추가, 위치 수정 또는 잔해 제거를 수행해.
3. **교체조치:** 균열, 심한 변형, 부식, 수명 초과처럼 복구로 성능을 신뢰하기 어려우면 교체해.
4. **근본개선:** 반복 결함이면 설치 방식, 자재, 배치, 점검 주기 또는 작업절차를 바꿔.
5. **재점검:** 조치가 끝난 뒤 같은 기준과 적절한 측정 방법으로 적합성을 다시 확인해.

수리했다는 보고만 받고 종결하면 안 돼. **개선 완료와 적합 판정은 서로 다른 단계**이기 때문이야.

## 3. 시설별 핵심 점검 포인트

| 안전시설 | 육안 확인 | 측정·기능 확인 | 대표적인 개선 |
|---|---|---|---|
| 안전난간 | 부재 누락, 휨, 부식, 고정 불량 | 높이, 부재 간격, 흔들림과 체결 상태 | 재고정, 부재 보강, 손상 부재 교체 |
| 작업발판 | 파손, 들뜸, 미끄럼, 과다 적재 | 폭, 틈, 처짐, 고정 상태 | 고정 보완, 적재물 제거, 발판 교체 |
| 개구부 덮개 | 덮개 누락, 변형, 경고표시 훼손 | 개구부 완전 차폐, 이동 방지, 지지 상태 | 재고정, 표지 복구, 강도 확보된 덮개로 교체 |
| 추락방호망 | 절단, 마모, 처짐, 접속부 이탈 | 설치 위치, 장력 상태, 결속 상태 | 결속 보완, 이물질 제거, 망 교체 |
| 낙하물 방지망 | 찢김, 처짐, 잔해 축적 | 지지부와 연결부 상태, 방호범위 | 잔해 제거, 지지부 보강, 손상부 교체 |
| 방호울·출입통제시설 | 틈, 전도, 문 개방, 표지 누락 | 출입문 잠금과 통제 기능 | 배치 수정, 고정 강화, 잠금장치 교체 |
| 계단·통로 | 장애물, 미끄럼, 파손, 조도 불량 | 경사, 폭, 단차, 조도와 난간 상태 | 장애물 제거, 미끄럼 방지, 조명 보완 |
| 가설구조물 접속부 | 풀림, 변형, 부식, 부재 누락 | 수직·수평 상태, 변위, 체결 상태 | 재체결, 지지 보강, 구조 검토 후 교체 |

### 안전난간 예시

안전난간을 확인할 때 높이만 재면 된다고 생각하기 쉬워. 하지만 난간의 목적은 사람의 추락을 막는 것이므로 상부난간대, 중간난간대, 발끝막이판, 기둥과 고정부가 함께 기능해야 해. 치수가 맞아도 기둥이 바닥에서 빠지거나 클램프가 풀려 있다면 부적합이야.

반대로 도면과 조금 달라 보인다는 이유만으로 곧바로 철거해서도 안 돼. 승인된 설계변경이나 동등 이상의 방호성능이 있는지 확인해야 해. 중요한 것은 외형의 동일성보다 **법적·기술적 요구사항을 충족하는 방호성능**이야.

### 개구부 덮개 예시

개구부 위에 합판 한 장을 놓았다고 해서 덮개가 설치된 것은 아니야. 밟거나 장비가 지나갈 때 파괴되지 않아야 하고, 밀리거나 뒤집히지 않도록 고정되어야 하며, 개구부임을 식별할 수 있어야 해.

덮개가 반복해서 이동한다면 작업자에게 “건드리지 말라”고 교육하는 것만으로는 약해. 고정 구조를 바꾸거나 작업 동선을 조정하는 공학적 개선이 우선이야.

## 4. 측정 장비의 선정과 사용

### 4.1 장비별 용도

| 측정 장비 | 주요 측정 대상 | 사용 시 주의점 |
|---|---|---|
| 줄자·레이저 거리측정기 | 높이, 폭, 간격, 방호범위 | 기준점과 측정 방향을 명확히 해 |
| 버니어캘리퍼스 | 부재 두께, 마모량, 틈새 | 영점과 측정면의 이물질을 확인해 |
| 수평기·레이저 레벨 | 수평, 수직, 경사, 처짐 | 안정된 기준면을 확보해 |
| 토크렌치 | 규정된 체결 토크 확인 | 장비 범위와 체결 규격을 맞추고 교정 상태를 확인해 |
| 조도계 | 통로와 작업장 조도 | 센서 방향, 측정 높이와 주변광 영향을 통제해 |
| 절연저항계·접지 관련 측정기 | 전기 안전시설의 절연·접지 상태 | 적정 자격과 안전절차에 따라 사용해 |
| 초음파 두께측정기 | 금속 부재의 부식·감육 | 재질과 표면 상태에 맞게 보정해 |
| 하중·인장 관련 시험기 | 체결부, 앵커 또는 부재의 성능 | 승인된 시험방법과 구조 안전성을 먼저 검토해 |
| 균열게이지 | 균열 폭과 변화 | 위치를 표시하고 시간에 따른 변화를 비교해 |

### 4.2 올바른 측정 절차

**첫째, 무엇을 판단할 것인지 정해.**  
난간 높이, 발판 폭, 체결 토크처럼 판정 항목을 먼저 정해야 해.

**둘째, 비교할 기준값을 확인해.**  
법령, 설계도서, 제품 설명서 또는 승인된 작업계획에서 허용범위를 찾아.

**셋째, 적합한 장비를 선택해.**  
예상 측정범위와 필요한 분해능을 만족하는 장비여야 해.

**넷째, 장비 상태를 확인해.**  
외관 손상, 배터리, 영점, 교정 유효상태와 작동 여부를 확인해.

**다섯째, 측정 조건을 통제해.**  
측정 위치와 방향을 일정하게 하고, 진동·온도·표면 오염처럼 결과를 왜곡하는 요인을 관리해.

**여섯째, 반복 측정해.**  
중요한 값은 한 번만 측정하지 말고 여러 지점 또는 동일 지점에서 반복해서 이상값을 확인해.

**일곱째, 즉시 판정하고 기록해.**  
측정값을 기준과 비교하고 적합, 조건부 적합 또는 부적합으로 구분해.

### 4.3 측정값을 그대로 믿으면 안 되는 이유

측정값은 장비 자체의 오차뿐 아니라 측정자의 자세, 기준점 선택, 표면 상태와 환경조건의 영향을 받아. 레이저 거리측정기를 비스듬히 사용하면 실제 수직높이보다 긴 값이 나올 수 있고, 토크렌치의 사용 범위를 벗어나면 신뢰할 수 없는 결과가 나올 수 있어.

그러므로 경계값에 가까운 결과가 나오면 다음을 확인해야 해.

1. 장비 영점과 교정 상태
2. 측정 위치와 기준점
3. 측정 방향과 자세
4. 반복 측정값의 일관성
5. 다른 장비나 방법을 이용한 교차확인
6. 적용 기준의 최신성과 정확성

측정값이 기준을 간신히 충족했더라도 손상이 빠르게 진행되고 있다면 예방적으로 보강하거나 교체할 수 있어. 안전관리는 “오늘 숫자가 통과했는가?”뿐 아니라 “다음 점검 전까지 성능이 유지될 것인가?”도 판단해야 해.

## 5. 개선과 교체의 판단 기준

### 5.1 보수 가능한 상태

다음과 같은 결함은 제조자 지침과 승인된 절차에 따라 보수할 수 있어.

1. 규격 부재가 건전하지만 체결부가 느슨한 경우
2. 안전표지나 식별표시만 훼손된 경우
3. 방호망 위에 잔해가 쌓였지만 망 자체는 손상되지 않은 경우
4. 배치가 잘못됐지만 부재 성능은 건전한 경우
5. 허용범위 안에서 조정할 수 있는 경미한 위치 이탈

### 5.2 교체를 우선해야 하는 상태

다음 상황에서는 임의 수리보다 교체를 우선 검토해야 해.

1. 균열, 파단 또는 영구변형이 발생한 경우
2. 심한 부식이나 마모로 단면이 감소한 경우
3. 방호망의 섬유가 절단되거나 광범위하게 열화된 경우
4. 제품 수명 또는 제조자가 정한 교체 조건에 도달한 경우
5. 충격이나 낙하물을 받아 잔존 성능을 확신하기 어려운 경우
6. 반복 보수에도 동일 결함이 재발하는 경우
7. 규격과 출처를 확인할 수 없는 임의 제작 부품이 사용된 경우
8. 보수 후 성능을 객관적으로 검증할 수 없는 경우

### 5.3 교체만으로 끝나지 않는 경우

같은 위치의 방호망이 계속 찢어진다면 망만 교체해서는 사고가 반복될 수 있어. 자재 인양 경로가 망과 충돌하는지, 용접 불티가 떨어지는지, 모서리에 마찰되는지까지 조사해야 해.

즉, **결함 부품 교체는 현상 제거이고, 발생 원인 제거는 근본개선**이야. 둘을 구분해야 해.

## 6. 수시점검이 필요한 시점

정기점검만으로는 공정 변화가 빠른 건설현장을 관리하기 어려워. 다음 상황에서는 수시점검을 실시해야 해.

1. 강풍, 폭우, 폭설, 지진과 같은 기상·자연현상 이후
2. 중장비 또는 운반물과 안전시설이 충돌한 이후
3. 시설을 해체·이동·변경하거나 다시 설치한 이후
4. 공정, 작업방법 또는 작업구역이 변경된 이후
5. 추락물이나 큰 하중이 방호시설에 작용한 이후
6. 작업자가 흔들림, 소음, 변형 또는 손상을 신고한 경우
7. 사고나 아차사고가 발생한 이후
8. 장기간 사용하지 않던 시설을 다시 사용하는 경우
9. 반복 결함이 관찰되는 경우
10. 감독자가 방호성능 저하를 의심할 합리적인 사유가 있는 경우

수시점검은 정기점검을 대신하는 것이 아니야. 정기점검 사이에서 발생하는 변화와 돌발 손상을 잡아내는 보완 장치야.

## 7. 기록과 보고

### 7.1 점검기록의 필수 요소

| 기록 항목 | 작성 내용 |
|---|---|
| 시설 식별 | 시설명, 관리번호, 설치 위치 |
| 점검 정보 | 점검 일시, 점검자, 입회자 |
| 적용 기준 | 법령, 설계도서, 제품 기준, 현장 기준 |
| 점검 결과 | 육안 상태, 측정 위치와 측정값 |
| 장비 정보 | 장비명, 관리번호, 교정 또는 검증 상태 |
| 판정 | 적합, 조건부 적합, 부적합 |
| 즉시조치 | 통제, 작업중지, 임시 보강 |
| 개선조치 | 보수, 보강, 위치 변경, 교체 |
| 책임과 기한 | 조치 담당자와 완료 예정일 |
| 종결 확인 | 재점검 결과, 확인자, 사용 재개 여부 |

“이상 없음”만 반복해서 적은 점검표는 결함이 발생했을 때 무엇을 어떻게 확인했는지 증명하기 어려워. 핵심 부위의 상태와 주요 측정값을 구체적으로 기록해야 해.

### 7.2 부적합 표시 방법

부적합 시설은 누구나 즉시 알아볼 수 있도록 표시하고 접근을 통제해야 해. 점검표에만 부적합이라고 적고 현장 시설은 그대로 사용하게 두면 통제가 이루어진 것이 아니야.

표시에는 다음 내용이 포함되면 좋아.

1. 사용금지 또는 접근금지 여부
2. 결함 내용
3. 발견 일시
4. 조치 책임자
5. 재사용 승인 조건

## 8. 구체적인 현장 사례

### 사례: 외곽 안전난간의 반복적인 흔들림

점검자가 건물 외곽 안전난간의 상부난간대를 손으로 확인했더니 일부 구간에서 흔들림이 느껴졌어. 외관상 부재는 파손되지 않았지만, 기둥 하부 클램프가 느슨해져 있었어.

먼저 해당 구간의 접근을 통제하고 추락위험 작업을 중지해. 다음으로 도면, 설치계획과 제조자 체결기준을 확인한 뒤 적합한 토크렌치를 준비해. 토크렌치의 식별번호와 교정 상태를 확인하고 여러 체결부를 측정해 보니 특정 구간에서 반복적으로 체결상태가 저하된 사실이 확인됐어.

단순히 다시 조이는 것만으로 끝내지 않고 원인을 조사했더니, 인접 자재 운반 과정에서 난간에 반복적으로 충격이 가해지고 있었어. 그래서 체결부를 적정하게 복구한 뒤 난간을 재점검하고, 자재 운반 동선을 변경하며, 충돌 가능 구간에 추가 방호조치를 설치했어.

이 사례의 핵심은 다음과 같아.

**육안 확인 → 기능 이상 발견 → 장비 측정 → 기준 비교 → 즉시 통제 → 복구 → 원인 제거 → 재측정 → 기록**

만약 클램프나 기둥이 영구변형되었다면 재체결만 해서는 안 되고 해당 부재를 교체해야 해.

## 9. 비교와 경계

| 혼동하기 쉬운 판단 | 올바른 판단 |
|---|---|
| 설치되어 있으므로 적합하다 | 설치 상태와 현재 방호성능이 모두 적합해야 해 |
| 눈으로 이상이 없으면 측정할 필요가 없다 | 치수·체결·변위처럼 눈으로 판정하기 어려운 항목은 측정해야 해 |
| 측정값 하나가 기준 안이면 적합하다 | 측정 위치, 반복성, 장비 상태와 전체 구조 상태를 함께 봐야 해 |
| 수리했으므로 사용해도 된다 | 재점검을 통해 적합 판정을 받은 뒤 사용해야 해 |
| 정기점검만 하면 충분하다 | 공정 변경, 충격, 악천후 이후에는 수시점검이 필요해 |
| 손상된 부품만 교체하면 끝난다 | 손상의 근본 원인과 주변 공정도 개선해야 해 |
| 측정 장비에 숫자가 표시되면 믿을 수 있다 | 영점, 교정, 측정범위와 사용방법이 적절해야 해 |
| 사내 기준만 따르면 된다 | 최신 법령과 강제 기준을 우선 확인해야 해 |

## 10. 산업안전기사 실기 시험 함정

### 함정 1: 점검과 조치를 분리해서 쓰는 경우

“안전난간의 상태를 점검한다”만 쓰면 부족할 수 있어. 문제에서 관리 절차나 조치까지 요구한다면 **기준 확인, 상태 점검, 부적합 판정, 출입통제, 보수·교체, 재점검과 기록**을 연결해야 해.

### 함정 2: 측정 장비 이름만 나열하는 경우

줄자, 토크렌치, 조도계를 적는 것만으로는 장비 사용 능력이 드러나지 않아. 무엇을 측정하고 어떤 기준과 비교하는지 함께 써야 해.

예를 들면 “토크렌치로 체결부의 상태를 확인한다”보다 “교정 상태가 확인된 적합한 토크렌치로 체결값을 측정하고 설계 또는 제조자 기준과 비교한다”가 더 완전해.

### 함정 3: 보수 후 재점검을 빠뜨리는 경우

보수는 작업이고 재점검은 검증이야. 답안에서는 **조치 후 성능을 다시 확인하고 결과를 기록한다**는 문장을 빠뜨리지 않는 게 좋아.

### 함정 4: 육안점검만 강조하는 경우

시설의 높이, 간격, 처짐, 조도, 두께와 체결상태는 측정 장비가 필요할 수 있어. 육안점검과 측정점검을 구분해서 제시해야 해.

### 함정 5: 모든 결함을 현장 수리로 처리하는 경우

균열, 영구변형, 심한 부식 또는 성능 확인이 불가능한 부재는 임의 수리하면 안 돼. 사용을 중지하고 승인된 절차에 따라 교체한 뒤 재확인해야 해.

### 함정 6: 숫자만 암기하는 경우

시설별 세부 수치는 적용 시설, 구조와 최신 기준에 따라 확인해야 해. 숫자를 답안에 쓸 때는 대상 시설과 측정 위치를 정확히 연결해야 해. 서로 다른 시설의 기준값을 섞으면 안 돼.

## 11. 실무형 표준 절차

현장에서 바로 기억할 수 있도록 여덟 단계로 정리해볼게.

1. **기준 확인:** 최신 법령, 설계도서, 기술지침과 제조자 기준을 찾는다.
2. **위험 통제:** 점검구역을 구획하고 필요한 경우 작업과 출입을 제한한다.
3. **육안 점검:** 누락, 파손, 변형, 부식, 이완과 임의 해체를 확인한다.
4. **장비 측정:** 치수, 수평·수직, 체결, 조도 또는 두께를 적합한 장비로 측정한다.
5. **적합 판정:** 측정 결과와 관찰 결과를 기준값과 비교한다.
6. **개선·교체:** 결함의 위험도에 따라 즉시조치, 보수, 보강 또는 교체한다.
7. **재확인:** 동일한 판단 기준으로 방호성능 회복 여부를 확인한다.
8. **기록·공유:** 결과, 사진, 측정값, 조치자와 종결 확인을 기록하고 관계자에게 알린다.

앞글자보다 흐름으로 기억하는 게 좋아.

**기준을 찾고 → 위험을 막고 → 눈으로 보고 → 장비로 재고 → 기준과 비교하고 → 고친 뒤 → 다시 확인하고 → 기록한다.**

중대한 결함이 의심되면 사람의 노출을 먼저 차단해야 해. 작업과 접근을 통제한 뒤 보고, 보수·교체, 재점검 순서로 진행해.

### 문제 3 예시 답안

1. 장비 외관의 손상 여부
2. 영점과 정상 작동 여부

장비 이름보다 **그 장비가 신뢰할 만한 값을 낼 수 있는 상태인지 확인하는 것**이 핵심이야.

**틀림**

### 문제 8 예시 답안

동일 결함이 반복된다는 것은 진동, 충돌, 잘못된 배치, 부적절한 자재 또는 작업방법과 같은 근본 원인이 남아 있을 가능성을 의미해. 부품만 교체하면 원인이 제거되지 않아 다시 손상될 수 있으므로 원인조사와 공학적 개선을 함께 실시해야 해.

## 14. 요약

1. **기 설치된 안전시설에 대해 관련법령, 기준, 지침에 따라 확인하고, 수시로 개선할 수 있다.** 이를 위해서는 적용 기준을 먼저 확인하고 육안·촉진·측정 점검으로 현재 방호성능을 판정해야 해.
2. **측정 장비를 이용하여 안전시설이 제대로 유지되고 있는지 확인하고, 필요한 경우 교체할 수 있다.** 장비의 영점, 교정 상태, 측정범위와 사용조건을 확인한 뒤 측정값을 기준과 비교해야 해.
3. 안전시설의 존재와 안전시설의 성능은 같은 말이 아니야. 설치되어 있어도 파손, 이완, 변형 또는 부적절한 배치가 있으면 부적합할 수 있어.
4. 결함을 발견하면 작업과 접근을 먼저 통제하고, 보수·보강 또는 교체한 뒤 반드시 재점검해야 해.
5. 반복되는 결함은 부품만 바꾸지 말고 충돌, 진동, 공정과 배치 같은 근본 원인을 제거해야 해.
6. 점검 결과에는 측정 위치, 기준값, 측정값, 장비 정보, 판정, 조치와 종결 확인을 남겨야 해.
7. 시험에서는 **기준 확인 → 점검·측정 → 판정 → 통제 → 개선·교체 → 재확인 → 기록**의 완전한 흐름을 쓰는 게 핵심이야.

안전시설 점검은 체크표에 표시하는 행정작업이 아니라, 현장의 방호성능이 살아 있는지 확인하는 건강검진이야. 숫자를 재는 데서 멈추지 않고 그 숫자가 무엇을 뜻하는지 판정하고, 위험이 사라질 때까지 조치를 닫아야 해. 조금 복잡해 보여도 이 흐름만 잡으면 실기 답안과 현장 실무가 한 줄로 연결될 거야. 잘하고 있어! 😊
