# 1-15-4-1. 위험성평가 기록과 보존의 실무 지도

산업안전기사 실기  
관련법령, 기준, 지침에 따라 위험성평가를 실시한 내용과 결과를 기록할 수 있다. · 위험성평가와 관련한 위험성평가 기록물을 관련법령, 기준, 지침에서 정한 기간 동안 보존할 수 있다.

## 1. 기록은 위험성평가를 증명하는 마지막 공정이야

위험성평가는 위험요인을 찾아 점수를 매기는 것으로 끝나지 않아. 누가 어떤 작업을 검토했고, 무엇을 위험요인으로 판단했으며, 어떤 감소대책을 언제까지 실행하기로 했는지를 기록해야 비로소 관리 활동으로 완성돼.

기록은 현장의 기억을 문서로 고정하는 안전장치야. 사고가 발생하거나 감독·점검을 받을 때 말로만 “평가했다”고 주장해서는 실시 사실과 조치 내용을 객관적으로 증명하기 어려워. 반대로 평가 과정과 후속 조치가 연결된 기록은 사업장이 위험을 인식하고 통제한 과정을 보여 주는 증거가 돼.

관련법령, 기준, 지침에 따라 위험성평가를 실시한 내용과 결과를 기록할 수 있다.

위험성평가와 관련한 위험성평가 기록물을 관련법령, 기준, 지침에서 정한 기간 동안 보존할 수 있다.

핵심 흐름은 다음과 같이 기억하면 돼.

**유해·위험요인 파악 → 위험성 결정 → 감소대책 수립 → 실행 → 잔여 위험성 확인 → 기록 → 보존 → 재평가에 활용**

## 2. 기록해야 할 핵심 내용

산업안전보건법령에 따른 위험성평가 기록에서는 최소한 다음 내용을 확인해야 해.

1. **위험성평가의 대상과 실시 개요**
   - 사업장, 공사명, 공종, 작업 장소
   - 대상 작업과 작업 단계
   - 평가일과 평가자
   - 근로자 참여자와 관련 부서
   - 평가 방법과 적용 기준

2. **유해·위험요인의 파악 내용**
   - 위험요인이 존재하는 설비, 물질, 작업 또는 환경
   - 예상되는 사고·질병의 형태
   - 위험에 노출되는 근로자와 노출 상황
   - 기존 안전조치와 현재의 관리 상태

3. **위험성 결정의 내용**
   - 가능성과 중대성의 판단
   - 사용한 위험성 수준 또는 점수
   - 사업장이 정한 허용 가능 위험성 기준
   - 허용 여부와 우선순위

4. **위험성 감소대책과 실행 결과**
   - 추가로 필요한 감소대책
   - 담당자와 완료 예정일
   - 실제 조치일과 조치 결과
   - 조치 후 잔여 위험성
   - 추가 개선 또는 재평가 필요 여부

5. **그 밖에 필요한 사항**
   - 근로자 의견과 협의 내용
   - 관련 도면, 사진, 측정 결과
   - 변경 사유와 개정 이력
   - 승인자 또는 확인자의 확인

시험에서는 세부 서식의 모양보다 **유해·위험요인, 위험성 결정, 감소대책과 실행 결과**가 하나의 추적 가능한 흐름으로 연결되는지가 중요해.

## 3. 건설현장에서는 작업 단위로 연결해야 해

건설공사는 장소와 작업 조건이 계속 변해. 따라서 보고서를 한 번 작성한 뒤 그대로 보관하는 것만으로는 충분하지 않아. 공정표, 작업계획서, 작업 전 안전점검, 협력업체 작업 내용과 위험성평가 기록이 서로 연결되어야 해.

예를 들어 외부비계 조립 작업을 평가한다고 해보자.

**작업 단계:** 비계 부재 인양 및 조립  
**유해·위험요인:** 작업발판 설치 전 단부에서 작업하여 추락할 위험  
**기존 조치:** 안전모와 안전대 지급  
**초기 판단:** 중대성이 크고 노출 가능성도 있어 허용 불가  
**감소대책:** 선행 안전난간 설치, 수직구명줄 설치, 안전대 걸이시설 확보, 작업지휘자 배치  
**담당자:** 비계 작업반장  
**완료 기한:** 조립 작업 시작 전  
**확인 결과:** 난간과 구명줄 설치 상태를 확인한 뒤 작업 승인  
**잔여 위험성:** 허용 가능한 수준이나 안전대 체결 여부를 계속 감독

좋은 기록은 “안전대 착용”처럼 결과만 적지 않아. **위험요인과 조치가 왜 연결되는지**, **조치가 실제로 완료되었는지**, **조치 후 위험성이 허용 가능한지**까지 보여 줘야 해.

## 4. 기록 작성 절차

### 1단계: 평가 단위를 명확히 정해

공종 전체를 한 줄로 뭉뚱그리지 말고 작업 장소와 세부 단계를 구분해. “철근 작업”보다 “지상 5층 슬래브 단부에서 철근 배근”처럼 적어야 위험 상황이 구체적으로 보이게 돼.

### 2단계: 관찰 가능한 표현으로 위험요인을 써

“추락 위험 있음”만 쓰면 원인과 상황이 빠져 있어. “개구부 덮개가 고정되지 않아 이동 중 덮개가 이탈하면서 근로자가 아래층으로 추락할 위험”처럼 **원인·상황·결과**를 연결하면 대책을 고르기 쉬워져.

### 3단계: 위험성 판단 근거를 남겨

점수만 쓰지 말고 가능성과 중대성을 어떻게 판단했는지 확인할 수 있어야 해. 사업장이 사용하는 평가 기준표, 허용 가능 기준, 우선순위와 일치하도록 기록해.

### 4단계: 감소대책을 우선순위에 따라 정해

대책은 원칙적으로 다음 순서로 검토해.

**위험 작업의 제거·대체 → 공학적 대책 → 관리적 대책 → 개인용 보호구**

추락 위험이 큰 개구부를 그대로 둔 채 “주의 교육”만 적는 것은 약한 대책이야. 개구부를 없애거나 견고한 덮개와 안전난간을 설치하는 조치를 먼저 검토해야 해.

### 5단계: 실행 책임과 기한을 지정해

“즉시 개선”이라는 표현만으로는 책임 추적이 어려워. 담당자, 완료 예정일, 확인자와 완료 상태를 구체적으로 적어야 해.

### 6단계: 조치 후 위험성을 다시 판단해

감소대책을 적었다고 위험성이 자동으로 낮아지는 것은 아니야. 실제 설치·변경 상태를 확인하고 잔여 위험성을 다시 결정해야 해. 허용 기준을 초과한다면 작업을 시작하거나 계속해서는 안 돼.

## 5. 기록의 보존과 관리

산업안전보건법령상 사업주는 위험성평가 결과와 조치 사항을 기록하여 **3년간 보존**해야 해. 실기시험에서는 보존기간을 묻는 경우가 많으니 **위험성평가 기록은 3년**이라고 분명하게 기억해 둬.

보존기간만 맞춘다고 기록관리가 끝나는 것은 아니야. 문서는 필요할 때 즉시 찾을 수 있어야 하고, 원본성과 변경 이력을 확인할 수 있어야 해.

**종이 기록**은 공사명, 공종, 평가일을 기준으로 분류하고 습기·화재·분실로부터 보호해야 해. 서명이나 승인란을 포함한 원본은 임의로 덧쓰지 않고, 수정할 때 수정자와 수정일을 남기는 편이 좋아.

**전자 기록**은 파일명 규칙, 접근권한, 백업, 버전관리가 필요해. 최종본과 작성 중 문서를 구분하고, 파일을 교체했을 때 이전 버전과 변경 사유를 추적할 수 있어야 해.

권장 파일명은 다음처럼 구성할 수 있어.

**공사명_공종_작업명_평가일_개정번호**

예를 들면 **A현장_비계공사_외부비계조립_20260830_R02**처럼 적을 수 있어. 이렇게 하면 현장과 작업, 작성 시점, 최신 개정 여부를 빠르게 확인할 수 있어.

## 6. 최초·수시·정기평가 기록의 경계

평가 기록은 실시 시점과 사유가 드러나야 해.

**최초평가** 기록은 사업장의 작업과 공정 전반을 처음 체계적으로 검토한 기준점이 돼. 이후 기록과 비교할 수 있도록 평가 범위와 기준을 명확히 남겨야 해.

**수시평가** 기록은 설비·원재료·작업방법의 변경, 건설물의 설치·이전·변경, 산업재해 발생과 같은 새로운 위험 상황을 반영해. 무엇이 바뀌었기 때문에 다시 평가했는지를 반드시 적어야 해.

**정기평가** 기록은 기존 평가의 타당성과 현장 변화 여부를 주기적으로 재검토한 결과야. 기존 문서를 단순 복사하는 것이 아니라 설비 성능, 작업방법, 근로자 구성, 사고·아차사고, 감소대책의 유효성을 다시 확인해야 해.

작업 전 안전점검표나 TBM 기록은 위험성평가의 실행을 뒷받침하는 자료가 될 수 있지만, 그것만으로 위험성평가 전체 기록을 항상 대체하는 것은 아니야. 평가 기준, 위험성 결정, 감소대책과 조치 결과가 빠져 있다면 별도의 기록 보완이 필요해.

## 7. 비교와 시험 함정

| 구분 | 올바른 판단 | 자주 틀리는 판단 |
|---|---|---|
| 기록 시점 | 평가와 조치 과정에서 지속적으로 작성 | 공사 종료 후 한꺼번에 작성 |
| 위험요인 표현 | 원인·상황·예상 결과를 구체화 | “위험함”, “주의 필요”로만 작성 |
| 위험성 결정 | 사업장 기준과 판단 근거를 함께 기록 | 숫자만 기입 |
| 감소대책 | 담당자·기한·실행 결과까지 연결 | 대책명만 나열 |
| 조치 후 확인 | 잔여 위험성을 다시 판단 | 대책을 적은 순간 완료로 처리 |
| 보존기간 | 3년간 보존 | 공사 종료와 동시에 폐기 |
| 전자문서 | 접근권한·백업·버전관리 실시 | 파일 한 개만 저장 |
| 근로자 참여 | 의견, 참여자, 반영 결과를 확인 | 관리자가 독단적으로 작성 |

특히 다음 함정을 조심해야 해.

1. **위험성평가표만 작성하면 모든 절차가 끝난다**는 생각은 틀려. 감소대책의 실행과 확인 결과도 연결해야 해.
2. **모든 위험을 보호구로 해결한다**는 답은 적절하지 않아. 제거·대체와 공학적 대책을 먼저 검토해야 해.
3. **문서를 3년간 창고에 두기만 하면 된다**는 생각도 부족해. 검색 가능성, 훼손 방지, 접근권한, 개정 이력이 관리되어야 해.
4. **점수가 낮으면 무조건 안전하다**고 판단하면 안 돼. 중대재해 가능성이 있거나 법령상 필요한 조치가 누락되었다면 별도로 통제해야 해.
5. **과거 평가표를 날짜만 바꾸어 재사용**하면 현장 변화와 실제 위험요인을 반영하지 못해.

## 8. 실기 답안 구성법

서술형 답안에서는 질문이 요구하는 범위를 먼저 구분해.

기록사항을 묻는다면 다음 구조로 답할 수 있어.

1. 위험성평가 대상과 실시 개요  
2. 유해·위험요인의 파악 내용  
3. 위험성 결정의 내용  
4. 위험성 감소대책의 수립 및 실행 내용  
5. 감소대책 실행 후 확인 결과와 그 밖에 필요한 사항

보존기간을 묻는다면 불필요하게 길게 쓰지 말고 다음과 같이 답하면 돼.

**사업주는 위험성평가 결과와 조치 사항을 기록하여 3년간 보존해야 한다.**

사례형 문제라면 **발견된 위험요인 → 위험성 판단 → 감소대책 → 담당자와 기한 → 실행 확인 → 잔여 위험성 → 기록 보존**의 순서로 쓰면 논리가 안정적이야.

## 10. 정답과 해설

### 정답 1

**3년간 보존한다.**

위험성평가의 결과와 그에 따른 조치 사항은 평가 이후에도 감독, 재평가, 사고조사와 개선 활동에 활용할 수 있도록 정해진 기간 동안 유지해야 해.

### 정답 2

예시 답안은 다음과 같아.

1. 위험성평가 대상과 실시 개요  
2. 유해·위험요인의 파악 내용  
3. 위험성 결정의 내용  
4. 위험성 감소대책의 수립 및 실행 결과

담당자, 완료 기한, 근로자 참여 내용, 잔여 위험성과 관련 자료를 함께 기록하면 추적성이 더 높아져.

### 정답 3

첫째, 교육은 관리적 대책이므로 위험원 자체를 제거하거나 차단하는 공학적 대책보다 우선할 수 없어. 개구부 덮개, 안전난간, 추락방호망과 같은 조치를 먼저 검토해야 해.

둘째, 담당자·완료 기한·실행 확인·조치 후 잔여 위험성이 기록되지 않았어. 따라서 대책이 실제로 이행되었는지 확인하기 어려워.

### 정답 4

**접근권한 관리, 정기적인 백업, 버전 및 개정 이력 관리**를 들 수 있어. 파일명 체계, 무결성 확보, 복구 가능성도 중요한 관리요소야.

### 정답 5

예시 보완 기록은 다음과 같아.

**위험요인:** 3층 계단실 개구부에 덮개와 안전난간이 없어 자재 운반 중 근로자가 아래층으로 추락할 위험  
**초기 위험성:** 허용 불가  
**감소대책:** 견고하게 고정된 개구부 덮개와 안전난간을 설치하고 경고표지를 부착  
**담당자와 기한:** 안전시설 담당자, 자재 운반 작업 시작 전  
**조치 결과:** 덮개 고정 상태와 난간 치수를 현장 확인하고 사진으로 기록  
**잔여 위험성:** 허용 가능, 일일 작업 전 고정 상태 재점검

## 11. 회상 요약

**기록의 세 축**은 유해·위험요인, 위험성 결정, 감소대책과 실행 결과야.

**좋은 기록의 조건**은 구체성, 추적성, 실행 확인, 개정 이력, 검색 가능성이야.

**건설현장의 핵심**은 공정과 작업 조건이 바뀔 때 기록도 함께 갱신하는 것이야.

**감소대책의 흐름**은 제거·대체, 공학적 대책, 관리적 대책, 개인용 보호구 순서로 검토해.

**시험의 핵심 숫자**는 위험성평가 결과와 조치 사항을 **3년간 보존**한다는 것이야.

한 문장으로 압축하면 이렇게 기억할 수 있어.

**무엇이 위험했는지, 어떻게 판단했는지, 누가 언제 무엇을 고쳤는지, 조치 후 안전한지를 기록하고 3년간 보존한다.**
