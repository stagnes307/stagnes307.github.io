건설공사 위험성평가 보고서가 안전관리의 지도라면, 유해·위험요인 목록은 지도에 표시하는 위험 표지판이야. 표지판을 빠뜨리거나 위치를 모호하게 적으면 평가와 감소대책도 엉뚱한 방향으로 흘러가. 따라서 단순히 위험한 것을 나열하는 데서 멈추지 않고, 누가 어떤 작업에서 무엇에 노출되어 어떤 결과를 입을 수 있는지까지 구조적으로 기록해야 해.

## 1. 유해·위험요인을 목록화 할 수 있다.

### 1.1 유해·위험요인의 의미

유해·위험요인은 근로자에게 부상이나 질병을 일으킬 잠재력이 있는 기계·기구, 설비, 물질, 에너지, 작업방법, 작업행동, 작업환경 등의 근원이야. 아직 사고가 발생하지 않았더라도 손상을 일으킬 가능성이 존재한다면 목록에 포함해야 해.

다음 세 개념을 분리하면 목록이 훨씬 명확해져.

| 구분 | 의미 | 건설현장 예시 |
|---|---|---|
| 유해·위험요인 | 손상을 일으킬 잠재력을 가진 근원 | 개구부, 이동식 크레인, 전선 충전부 |
| 위험상황 | 사람이 유해·위험요인에 노출된 상태 | 안전난간 없는 개구부 가장자리에서 작업함 |
| 예상 결과 | 노출로 발생할 수 있는 재해나 건강장해 | 추락에 의한 골절·사망 |

예를 들어 “개구부”만 적으면 위험원의 이름만 기록한 거야. “안전난간이 설치되지 않은 바닥 개구부 주변에서 자재 운반 중 근로자가 중심을 잃고 추락하여 중상을 입을 수 있음”이라고 작성하면 위험원, 노출 상황, 사고 경로, 결과가 연결돼.

### 1.2 목록화의 목적

목록화는 현장의 위험을 빠짐없이 수집하고, 같은 기준으로 분류하며, 평가와 개선이력을 추적하기 위한 절차야.

목록이 제대로 작성되면 다음 흐름이 만들어져.

**공정 파악 → 작업 분해 → 유해·위험요인 파악 → 위험성 결정 → 감소대책 수립 → 담당자 지정 → 조치 확인 → 잔여 위험 재평가**

목록은 한 번 작성하고 보관하는 문서가 아니야. 공정 진행, 설계 변경, 장비 반입, 작업방법 변경, 사고·아차사고 발생처럼 위험 조건이 바뀔 때 갱신되는 살아 있는 관리대장이야.

### 1.3 목록화 대상의 범위

건설현장에서는 정상작업뿐 아니라 비정상·비정기 작업까지 살펴야 해.

| 조사 영역 | 확인할 내용 |
|---|---|
| 공정 | 굴착, 골조, 거푸집, 철근, 콘크리트, 마감, 해체 |
| 작업자 | 직영근로자, 수급인 근로자, 신규자, 고령자, 방문자 |
| 기계·설비 | 양중기, 차량계 건설기계, 전동공구, 가설설비 |
| 물질 | 유기용제, 도료, 용접흄, 분진, 산소결핍 유발 물질 |
| 에너지 | 전기, 중량물의 위치에너지, 압력, 회전체의 운동에너지 |
| 작업환경 | 소음, 진동, 고온·한랭, 조도, 환기, 협소공간 |
| 작업행동 | 임의 운전, 안전장치 해제, 불안전한 통행과 자세 |
| 비정상 상태 | 정비, 청소, 고장조치, 자재 걸림 제거, 시운전 |
| 외부 조건 | 강풍, 폭우, 낙뢰, 인접 교통, 인접 구조물과 매설물 |
| 과거 정보 | 산업재해, 아차사고, 근로자 제안, 점검 지적사항 |

“사고가 자주 발생한 작업만 조사한다”는 접근은 위험해. 발생 이력이 없더라도 결과의 중대성이 큰 붕괴, 질식, 감전, 화재·폭발 위험을 놓쳐서는 안 돼.

## 2. 유해·위험요인을 목록화하는 절차

### 2.1 1단계: 평가 단위를 정해

평가 범위를 너무 크게 잡으면 위험이 추상적으로 표현돼. “골조공사” 하나로 묶기보다 실제 작업 순서와 장소를 기준으로 나누는 게 좋아.

**공정 → 작업 → 세부 작업 → 작업 단계** 순서로 분해해.

예시는 다음과 같아.

**골조공사 → 거푸집 작업 → 벽체 거푸집 설치 → 자재 인양, 위치 조정, 임시 고정, 체결, 검측**

이렇게 분해하면 자재 인양 중 낙하, 위치 조정 중 끼임, 임시 고정 불량에 따른 전도처럼 단계별 위험을 찾을 수 있어.

### 2.2 2단계: 자료조사와 현장조사를 병행해

문서만 보면 실제 작업자의 우회 동선이나 불편 때문에 생기는 불안전한 행동을 놓칠 수 있어. 반대로 현장만 보면 과거 재해이력이나 설비 사양 같은 배경정보를 놓칠 수 있지.

확인할 자료는 다음과 같아.

1. 공사계획서와 설계도서
2. 공정표와 작업계획서
3. 기계·기구의 설명서와 점검기록
4. 물질안전보건자료
5. 산업재해와 아차사고 기록
6. 순회점검 및 안전보건점검 결과
7. 근로자 건의사항과 작업 전 안전점검회의 내용
8. 관련 법령, 기준 및 안전보건 지침
9. 이전 위험성평가 결과와 감소조치 이력

현장에서는 작업을 직접 관찰하고, 근로자에게 “평소 가장 불안한 순간이 언제인지”, “설비가 막히거나 고장 났을 때 어떻게 조치하는지”를 물어봐야 해. 실제 작업을 수행하는 근로자의 참여는 서류에서 드러나지 않는 위험을 찾는 핵심 장치야.

### 2.3 3단계: 위험의 발생 시나리오를 문장으로 작성해

목록의 기본 문장은 다음 구조로 만들 수 있어.

**작업·장소 + 유해·위험요인 + 노출 또는 발생 과정 + 예상 재해**

예를 들어 볼게.

| 불완전한 표현 | 개선한 표현 |
|---|---|
| 추락 위험 | 외부비계 작업발판 단부의 안전난간이 누락되어 이동 중 근로자가 지상으로 추락할 위험 |
| 충돌 위험 | 굴착기 작업반경에 근로자가 출입하여 선회하는 후미와 충돌할 위험 |
| 감전 위험 | 피복이 손상된 이동전선을 습윤한 장소에서 사용하여 충전부 접촉으로 감전될 위험 |
| 낙하 위험 | 타워크레인으로 철근 묶음을 인양하는 중 결속이 풀려 하부 근로자에게 낙하할 위험 |
| 붕괴 위험 | 흙막이 지보공의 부재 손상과 변형을 방치하여 굴착면이 붕괴할 위험 |

좋은 문장은 원인과 결과 사이의 경로가 보여. 이 경로가 보여야 차단지점을 찾아 감소대책을 세울 수 있어.

### 2.4 4단계: 일정한 분류체계를 적용해

분류는 누락을 줄이는 검색 틀이야. 건설현장에서는 다음과 같이 분류할 수 있어.

| 분류 | 대표 유해·위험요인 |
|---|---|
| 추락 | 작업발판 단부, 개구부, 사다리, 지붕, 철골 |
| 낙하·비래 | 인양물, 공구, 해체물, 비산 파편 |
| 붕괴·도괴 | 굴착면, 흙막이, 거푸집동바리, 비계, 적재물 |
| 끼임·말림 | 회전체, 이동부, 장비와 구조물 사이 |
| 부딪힘·충돌 | 차량계 건설기계, 양중장비, 이동 자재 |
| 감전 | 충전부, 누전, 손상 전선, 부적합 임시배선 |
| 화재·폭발 | 용접 불티, 가연물, 인화성 물질, 가스 누출 |
| 질식·중독 | 밀폐공간, 산소결핍, 유해가스, 도료 증기 |
| 물리적 유해인자 | 소음, 진동, 고온, 한랭, 방사선 |
| 화학적 유해인자 | 분진, 흄, 미스트, 증기, 유기용제 |
| 인간공학적 요인 | 중량물 취급, 반복작업, 부자연스러운 자세 |
| 심리·조직적 요인 | 과도한 작업속도, 의사소통 부족, 장시간 작업 |

분류명만 적어서는 안 돼. “추락”은 재해 형태이고, “난간이 없는 개구부”는 위험원이야. 시험에서는 위험요인과 재해 결과를 뒤섞어 쓰지 않는 것이 중요해.

### 2.5 5단계: 중복을 정리하되 위험 시나리오는 함부로 합치지 마

동일한 위험원이 여러 장소에 존재하더라도 노출인원, 작업빈도, 높이, 주변 조건이 다르면 별도 항목으로 관리할 필요가 있어.

예를 들어 1층과 15층의 개구부는 모두 추락 위험이 있지만 예상 피해의 중대성과 구조 가능성, 낙하물에 의한 2차 피해가 다를 수 있어. “현장 내 모든 개구부 추락 위험”이라는 한 줄로 통합하면 담당자와 조치기한을 구체적으로 지정하기 어려워져.

### 2.6 6단계: 식별번호와 관리정보를 부여해

유해·위험요인 목록은 위험성평가표 및 개선조치표와 연결되어야 해.

| 필수 관리항목 | 작성 내용 |
|---|---|
| 식별번호 | 공종·구역·순번을 조합한 고유번호 |
| 공정·작업 | 평가 대상 공정과 세부 작업 |
| 장소·시점 | 위험이 존재하는 위치와 작업 단계 |
| 유해·위험요인 | 위험원과 위험상황 |
| 예상 결과 | 부상, 질병, 설비손상 등의 결과 |
| 노출 대상 | 작업자, 주변 근로자, 방문자 |
| 기존 조치 | 현재 적용 중인 방호조치 |
| 위험성 수준 | 현장이 정한 방법에 따른 평가 결과 |
| 추가 대책 | 제거·대체·공학적·관리적 대책 |
| 책임자·기한 | 조치 담당자와 완료 예정일 |
| 확인 결과 | 완료 여부, 확인자, 확인일 |
| 잔여 위험 | 조치 후에도 남아 있는 위험 |

식별번호가 있으면 위험성평가표, 사진, 시정조치 기록, 교육자료를 같은 위험 항목에 연결할 수 있어.

## 3. 건설현장 목록화 실무 예시

### 3.1 거푸집동바리 작업

| 식별번호 | 세부 작업 | 유해·위험요인 및 발생 시나리오 | 예상 결과 | 확인해야 할 기존 조치 |
|---|---|---|---|---|
| FORM-01 | 동바리 조립 | 구조검토와 조립도에 맞지 않게 부재를 설치하여 콘크리트 타설 중 동바리가 붕괴할 위험 | 매몰, 골절, 사망 | 구조검토, 조립도, 부재 규격, 연결 상태 |
| FORM-02 | 상부 작업 | 단부에 작업발판과 안전난간이 없어 이동 중 추락할 위험 | 추락 부상 | 작업발판, 안전난간, 추락방호망 |
| FORM-03 | 해체 | 상하 동시작업 중 해체 부재가 하부 근로자에게 낙하할 위험 | 두부 손상, 골절 | 출입통제, 작업순서, 신호체계 |

| 식별번호 | 세부 작업 | 유해·위험요인 및 발생 시나리오 | 예상 결과 | 확인해야 할 기존 조치 |
|---|---|---|---|---|
| EXC-01 | 굴착 | 지반상태를 고려한 기울기나 흙막이를 확보하지 않아 굴착면이 붕괴할 위험 | 매몰, 질식, 사망 | 지반조사, 굴착계획, 흙막이 상태 |
| EXC-02 | 굴착기 선회 | 유도자 없이 작업반경에 근로자가 접근하여 굴착기 후미와 충돌할 위험 | 협착, 골절 | 출입통제, 유도자, 경보장치 |
| EXC-03 | 덤프트럭 후진 | 운전자의 사각지대에 근로자가 들어가 차량에 부딪히거나 깔릴 위험 | 중상, 사망 | 이동경로 분리, 유도자, 후방카메라 |

### 3.3 용접 및 밀폐공간 작업

| 식별번호 | 세부 작업 | 유해·위험요인 및 발생 시나리오 | 예상 결과 | 확인해야 할 기존 조치 |
|---|---|---|---|---|
| HOT-01 | 용접 | 용접 불티가 주변 가연물에 비산하여 화재가 발생할 위험 | 화상, 화재 | 가연물 제거, 불티받이, 소화기 |
| HOT-02 | 탱크 내부 용접 | 환기 부족으로 유해가스가 축적되고 산소농도가 저하될 위험 | 중독, 질식 | 농도 측정, 환기, 감시인, 구조계획 |
| HOT-03 | 임시전원 사용 | 손상된 용접선이나 부적절한 접지로 누전되어 감전될 위험 | 감전, 화상 | 절연상태, 접지, 누전차단기 |

***

## 4. 목록의 검토와 갱신

유해·위험요인 목록은 다음 상황에서 다시 검토해야 해.

1. 새로운 기계·기구, 설비 또는 물질을 도입했을 때
2. 작업방법이나 작업절차를 변경했을 때
3. 설계, 공법, 공정 또는 작업장소가 변경되었을 때
4. 산업재해나 아차사고가 발생했을 때
5. 안전보건 점검에서 새로운 위험이 발견되었을 때
6. 근로자가 새로운 유해·위험요인을 제안했을 때
7. 기존 감소대책의 효과가 부족하다고 판단되었을 때
8. 장기간 중단했던 작업을 재개하거나 비정상 작업을 수행할 때
9. 날씨, 지반, 인접 공사와 같은 외부 조건이 변했을 때

변경 전 목록을 단순히 삭제하면 안 돼. 발견일, 변경 사유, 조치내용, 확인일이 이어지도록 개정이력을 관리해야 개선 과정의 추적성이 확보돼.

***

## 5. 위험성평가 인정제도의 구조

### 5.1 인정제도의 의미

“위험성평가와 관련해서 위험성평가 인정신청, 심사, 사후관리 등 필요한 위험성평가 인정제도에 참여할 수 있다.”는 목표는 신청서만 제출할 수 있다는 뜻이 아니야. 사업장이 위험성평가 체계를 실제로 구축하고, 인정심사에서 그 실행 증거를 제시하며, 인정 후에도 체계를 유지·개선할 수 있어야 한다는 뜻이야.

인정은 단순한 서류 인증으로 이해하면 안 돼. 사업주의 의지, 근로자 참여, 유해·위험요인 파악, 위험성 결정, 감소대책 실행, 기록과 지속적 개선이 현장에서 작동하는지를 확인하는 과정이야.

구체적인 신청 대상, 제출서류, 심사방법, 인정기간과 혜택은 시행 시점의 관계 법령과 담당기관 공고에 따라 달라질 수 있으므로 실제 업무에서는 최신 기준을 확인해야 해. 시험에서는 일반적인 절차와 관리 논리를 중심으로 답안을 구성하면 좋아.

### 5.2 전체 절차

**참여 가능 여부 확인 → 자체 위험성평가 실시 → 신청자료 준비 → 인정신청 → 서류 및 현장심사 → 보완 → 인정 여부 결정 → 사후관리 → 갱신 또는 재신청**

이 절차에서 가장 중요한 원칙은 “신청을 위해 문서를 만드는 것”이 아니라 “실행한 위험성평가를 문서로 입증하는 것”이야.

***

## 6. 인정신청 준비

### 6.1 참여 조건과 최신 기준 확인

먼저 사업장의 업종, 규모, 대상 여부, 신청 시기, 관할기관, 신청방법을 확인해. 과거에 사용했던 기준이나 다른 사업장의 서식을 그대로 적용하면 현재 기준이나 현장 특성과 맞지 않을 수 있어.

건설현장은 공정과 참여업체가 계속 바뀌므로 원청과 수급인의 역할, 평가 대상 작업, 근로자 참여방법, 공정별 책임자를 명확히 정하는 게 중요해.

### 6.2 자체 위험성평가 체계 구축

인정신청 전에 다음 요소가 실제로 운영되어야 해.

1. 위험성평가 실시방침과 절차
2. 평가 책임자와 참여자의 역할
3. 공정 및 작업별 유해·위험요인 목록
4. 현장에서 채택한 위험성 결정기준
5. 허용할 수 없는 위험에 대한 감소대책
6. 담당자와 완료기한
7. 조치 완료 및 효과 확인
8. 근로자 참여와 결과 공유
9. 변경 및 정기 검토 절차
10. 기록 보존과 개정이력 관리

### 6.3 신청자료의 정합성 확인

심사자는 문서 사이의 연결을 확인할 수 있어. 예를 들어 유해·위험요인 목록에는 “굴착기 충돌”이 있는데 평가표와 개선조치표에 해당 항목이 없다면 체계가 끊긴 거야.

다음 연결관계를 점검해.

**유해·위험요인 목록의 식별번호 = 위험성평가표의 항목번호 = 감소조치표의 번호 = 완료사진 및 확인기록의 번호**

근로자 참여 기록도 형식적인 서명만으로 끝내지 말고, 누가 어떤 위험을 제안했고 그 의견이 평가나 대책에 어떻게 반영되었는지 보여주는 게 좋아.

***

## 7. 인정심사에 참여하는 방법

### 7.1 서류심사에서 확인되는 내용

일반적으로 서류심사에서는 다음과 같은 사항을 확인해.

| 심사 영역 | 준비할 증거 |
|---|---|
| 추진체계 | 방침, 조직도, 역할과 책임 |
| 평가절차 | 실시규정, 평가방법, 결정기준 |
| 위험 파악 | 공정별 목록, 점검표, 근로자 의견 |
| 감소대책 | 개선계획, 책임자, 기한, 완료기록 |
| 교육·공유 | 교육일지, 회의기록, 게시·전달 자료 |
| 기록관리 | 평가표, 개정이력, 보존체계 |
| 지속적 개선 | 재평가 결과, 사고 후 개선, 변경관리 |

문서의 양보다 일관성과 실행성이 중요해. 날짜가 서로 맞지 않거나, 존재하지 않는 설비가 평가표에 들어 있거나, 모든 위험을 같은 점수로 평가했다면 형식적으로 작성했다는 의심을 받을 수 있어.

### 7.2 현장심사에서 확인되는 내용

현장심사는 “서류에 적힌 대책이 실제 현장에 존재하는가”를 검증하는 단계야.

심사 대응 시에는 다음 사항을 준비해.

1. 현장 책임자와 평가 참여자가 절차를 설명할 수 있도록 해.
2. 평가표의 위험 항목이 있는 장소와 설비를 추적할 수 있게 해.
3. 감소대책의 설치·실행 상태를 확인해.
4. 근로자가 주요 위험과 작업방법을 알고 있는지 확인해.
5. 신규·변경 작업이 목록에 반영되었는지 확인해.
6. 완료 처리된 조치가 실제로 유지되고 있는지 확인해.
7. 잔여 위험과 임시조치가 구분되어 있는지 확인해.

심사 질문에 “서류 담당자가 알고 있다”고 답하는 건 좋지 않아. 위험성평가는 일부 관리자의 문서업무가 아니라 현장 구성원이 참여하는 실행체계이기 때문이야.

### 7.3 보완요구에 대응하는 방법

보완요구를 받으면 지적 문구만 고치는 데 그치지 말고 원인을 확인해야 해.

**지적사항 분석 → 관련 위험 항목 확인 → 현장조치 → 문서 수정 → 근로자 공유 → 효과 확인 → 증빙 제출**

예를 들어 “근로자 참여 증거 부족”이라는 지적에 서명지만 새로 만들면 본질적인 개선이 아니야. 공정별 작업자 면담이나 작업 전 회의에서 위험요인을 제안받고, 제안 내용이 목록과 감소대책에 반영되도록 절차를 바꿔야 해.

***

## 8. 인정 후 사후관리

### 8.1 사후관리의 목적

사후관리는 인정 당시의 상태가 계속 유지되는지, 사업장이 변화된 위험을 스스로 찾아 개선하는지를 확인하는 과정이야. 인정서를 받았다고 위험성평가가 종료되는 것은 아니야.

### 8.2 지속적으로 수행할 사항

1. 공정·설비·인원·작업방법의 변경사항을 확인해.
2. 새로운 유해·위험요인을 목록에 추가해.
3. 기존 감소대책의 이행상태와 효과를 점검해.
4. 산업재해와 아차사고의 원인을 평가에 반영해.
5. 근로자 참여 및 결과 공유를 계속해.
6. 평가표, 조치기록, 교육기록의 개정이력을 유지해.
7. 심사에서 지적된 사항의 재발 여부를 점검해.
8. 필요한 경우 재평가하고 추가 감소대책을 수립해.
9. 인정 유지·갱신에 필요한 최신 절차를 확인해.

### 8.3 인정 유지에 불리한 대표 상황

| 문제 상황 | 왜 문제가 되는가 |
|---|---|
| 평가표를 복사하고 현장 확인을 하지 않음 | 실제 유해·위험요인이 반영되지 않음 |
| 개선조치를 완료로 표시했지만 현장에 반영되지 않음 | 기록과 실행이 불일치함 |
| 신규 공정과 장비를 평가하지 않음 | 변경관리가 작동하지 않음 |
| 근로자 참여가 서명에만 그침 | 실질적 참여 증거가 부족함 |
| 사고 후에도 목록과 대책을 수정하지 않음 | 학습과 재발방지 기능이 없음 |
| 인정 당시 자료만 보관하고 이후 기록이 없음 | 지속적 운영을 입증할 수 없음 |

***

## 9. 두 학습목표의 연결

유해·위험요인 목록화와 위험성평가 인정제도는 별개의 업무가 아니야.

| 목록화 결과 | 인정 과정에서의 활용 |
|---|---|
| 공정별 위험 목록 | 위험 파악의 충실성을 입증 |
| 근로자 제안 기록 | 근로자 참여를 입증 |
| 식별번호 | 평가·대책·증빙의 추적성 확보 |
| 변경이력 | 지속적 개선과 변경관리 입증 |
| 조치 전후 기록 | 감소대책의 실행과 효과 입증 |
| 잔여 위험 기록 | 재평가 및 후속관리 입증 |

목록이 부실하면 인정심사에서도 위험 파악의 적정성과 개선활동의 실효성을 설명하기 어려워져. 반대로 목록이 구체적이고 평가·조치·확인 기록과 연결되어 있으면 심사와 사후관리의 핵심 증거가 돼.

***

## 10. 비교와 경계

### 위험요인 목록과 단순 점검표

점검표는 미리 정한 항목의 적합 여부를 확인하는 도구야. 위험요인 목록은 해당 현장의 공정과 작업을 분석해 실제 위험 시나리오를 기록하는 결과물이야. 점검표에 없는 위험도 근로자 면담과 현장 관찰을 통해 찾아야 해.

### 위험요인 파악과 위험성 결정

위험요인 파악은 무엇이 어떻게 사람을 다치게 할 수 있는지 찾는 단계야. 위험성 결정은 그 위험의 가능성과 중대성 등을 판단하여 허용 가능 여부와 개선 우선순위를 정하는 단계야. 파악 전에 점수를 먼저 매기면 평가 대상 자체가 누락될 수 있어.

### 인정심사와 일회성 서류검사

인정심사는 서식이 존재하는지만 보는 절차가 아니야. 실제 현장과 문서가 일치하고, 근로자가 참여하며, 감소대책과 사후관리가 작동하는지를 확인하는 과정으로 이해해야 해.

### 사후관리와 정기점검

정기점검은 사후관리의 한 수단일 뿐이야. 사후관리에는 변경사항 반영, 사고·아차사고의 환류, 조치효과 확인, 기록 갱신, 근로자 공유가 함께 포함돼.

***

## 11. 산업안전기사 실기 시험 함정

### 함정 1: 재해 형태만 쓰기

“추락, 감전, 붕괴”만 나열하면 유해·위험요인을 구체적으로 파악했다고 보기 어려워.

**개선 답안:** 안전난간이 없는 개구부 주변에서 자재 운반 중 근로자가 추락할 위험.

### 함정 2: 위험원과 결과를 혼동하기

“골절”은 위험원이 아니라 예상 결과야. 위험원은 개구부, 회전체, 충전부처럼 손상을 일으킬 잠재적 근원이야.

### 함정 3: 정상작업만 조사하기

정비, 청소, 고장조치, 해체, 시운전 같은 비정상 작업은 방호장치가 해제되거나 작업자가 위험구역에 접근하기 쉬워 반드시 포함해야 해.

### 함정 4: 보호구를 첫 번째 대책으로 쓰기

위험성 감소는 위험원의 제거·대체 가능성을 먼저 검토하고, 공학적 대책과 관리적 대책을 거쳐 필요한 개인용 보호구를 적용하는 방향으로 접근해야 해. 보호구만 제시하면 위험원 자체는 그대로 남아.

### 함정 5: 인정신청을 위험성평가의 시작으로 보기

인정신청 전에 사업장의 자체 위험성평가 체계가 운영되어야 해. 신청은 실행한 체계를 심사받는 절차이지 평가를 대신하는 절차가 아니야.

### 함정 6: 인정 후 관리가 끝난다고 보기

인정 후에도 변경관리, 재평가, 조치 확인, 기록 유지와 같은 사후관리가 필요해.

### 함정 7: 제도 세부수치를 단정하기

대상 범위, 신청서류, 인정 유효기간, 혜택 등은 적용 시점의 최신 기준을 확인해야 해. 불확실한 수치를 임의로 쓰기보다 출제기준과 문제에서 요구한 범위에 맞춰 절차와 원칙을 정확히 작성해.

## 12. 실무 수행 예제

외부비계에서 석재 설치작업을 시작한다고 가정해보자.

### 12.1 목록 작성

1. 작업발판 단부의 안전난간 누락으로 이동 중 추락할 위험
2. 작업발판의 틈 또는 고정 불량으로 발이 빠지거나 발판이 이탈할 위험
3. 석재 인양 중 줄걸이 불량으로 인양물이 낙하할 위험
4. 비계 허용하중을 고려하지 않은 석재 적재로 비계가 변형·붕괴할 위험
5. 상하 동시작업으로 공구와 자재가 하부 근로자에게 떨어질 위험
6. 강풍 중 석재가 흔들려 작업자 또는 구조물과 충돌할 위험

### 12.2 평가와 조치 연결

위험마다 현재 조치, 위험성 수준, 추가 대책, 책임자, 기한을 정해. 추락 위험에 대해서는 안전난간 설치나 작업발판 개선처럼 집단적·공학적인 방호조치를 우선 검토하고, 필요한 경우 개인용 추락보호조치를 보완적으로 적용해.

### 12.3 인정심사 증빙 연결

식별번호를 기준으로 위험성평가표, 작업 전 점검기록, 근로자 의견, 조치 전후 사진, 완료 확인기록을 연결해. 심사 시에는 현장 상태와 문서가 일치해야 하고 작업자도 주요 위험과 통제방법을 설명할 수 있어야 해.

### 12.4 사후관리

강풍 예보, 작업발판 변경, 인양장비 교체, 신규 근로자 투입처럼 조건이 달라지면 목록을 재검토해. 조치가 완료되었다고 표시한 뒤에도 난간이 임의로 해체되지 않았는지 확인해야 해.

## 14. 정답 및 해설

### 문제 1 정답 예시

“안전난간이 설치되지 않은 작업발판 단부에서 이동 중 근로자가 지상으로 추락할 위험”이라고 작성할 수 있어.

**해설:** 작업장소, 위험원, 노출 상황, 예상 재해가 연결되어야 구체적인 감소대책을 세울 수 있어.

### 문제 2 정답

**4번**

**해설:** 담당자의 기억에만 의존하면 누락과 편향이 생겨. 정상·비정상 작업, 사고·아차사고, 변경 작업, 근로자 의견과 현장 관찰을 종합해야 해.

### 문제 3 정답

**라 → 나 → 마 → 가 → 다**

**해설:** 평가 대상을 구체적으로 나눈 뒤 위험을 찾고, 그 위험성을 판단해 감소대책을 실행하며, 마지막으로 효과와 잔여 위험을 확인해야 해.

### 문제 4 정답 예시

1. 사업장 특성에 맞는 위험성평가 절차와 책임체계를 구축해야 해.
2. 근로자가 참여한 유해·위험요인 파악, 위험성 결정 및 감소대책 실행 기록을 갖춰야 해.

**해설:** 인정신청은 미실시 상태를 대신해 주는 절차가 아니라 이미 운영 중인 위험성평가 체계를 확인받는 과정이야.

### 문제 5 정답 예시

문서에 기록된 유해·위험요인과 감소대책이 실제 현장에 반영되어 있는지, 위험성평가가 형식적인 서류 작성에 그치지 않고 작동하는지를 검증하기 위해서야.

3. 재해·아차사고 발생 시 재평가
4. 근로자 참여와 결과 공유
