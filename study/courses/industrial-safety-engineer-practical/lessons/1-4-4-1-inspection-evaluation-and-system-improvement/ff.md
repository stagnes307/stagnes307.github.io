## 1. 전체 업무 흐름

안전점검 평가 업무는 다음과 같은 순환구조로 이해하면 쉬워.

| 단계 | 핵심 질문 | 주요 산출물 |
|---|---|---|
| 1. 기준 확인 | 무엇을 만족해야 하는가? | 법령, 사내 기준, 작업표준, 점검표 |
| 2. 사실 확인 | 현장의 실제 상태는 어떠한가? | 관찰·측정·면담·기록 결과 |
| 3. 비교 평가 | 기준과 실제 상태 사이에 차이가 있는가? | 적합, 부적합, 관찰사항 |
| 4. 위험요인 도출 | 무엇이 누구에게 어떤 손상을 일으킬 수 있는가? | 구체적인 위험요인 |
| 5. 위험성 판단 | 얼마나 중대하고 시급한가? | 위험도와 개선 우선순위 |
| 6. 개선방안 수립 | 위험을 가장 효과적으로 줄이는 방법은 무엇인가? | 제거·대체·공학적·관리적 대책 |
| 7. 실행 및 확인 | 조치가 실제로 완료되고 효과를 냈는가? | 담당자, 기한, 완료 증거, 재점검 |
| 8. 시스템 개선 | 같은 문제가 다시 생기지 않도록 무엇을 바꿀 것인가? | 절차서·교육·점검표·책임체계 개선 |

중요한 경계가 하나 있어. **불량한 상태를 발견하는 것**과 **위험요인을 도출하는 것**은 같지 않아.

“통로에 자재가 있음”은 관찰된 사실이야. 반면 “통로 적치물에 발이 걸려 작업자가 넘어질 위험”은 사고 발생 과정까지 표현한 위험요인이야. 답안을 작성할 때는 단순한 상태 나열을 넘어 **위험원–노출 상황–예상 재해**가 연결되도록 써야 해.

## 2. 안전기준에 따라 점검내용을 평가하여 위험요인을 도출할 수 있다.

### 2.1 안전기준의 의미와 우선순위

안전기준은 현장의 상태가 허용 가능한지를 판단하는 잣대야. 대표적인 근거는 다음과 같이 구분할 수 있어.

1. 산업안전보건 관계 법령과 기술기준
2. 인허가 조건과 관계기관의 명령
3. 사업장 안전보건관리규정
4. 표준작업절차서와 설비 운전·정비 기준
5. 제조자가 제시한 사용설명서와 허용조건
6. 위험성평가 결과와 과거 재해방지대책
7. 해당 설비·공정에 적용되는 국가표준 또는 사내 기술기준

여러 기준이 동시에 적용될 때는 상위 법령을 위반할 수 없어. 사내 기준이 법적 최소기준보다 엄격하다면, 사업장이 스스로 정한 엄격한 기준을 실제 관리기준으로 적용하는 것이 원칙이야.

시험에서는 숫자를 억지로 외워 쓰기보다 **무슨 기준을 적용했고 현장이 그 기준을 어떻게 벗어났는지** 명확히 쓰는 게 중요해. 세부 수치나 법조문은 적용 시점의 현행 기준과 대상 설비의 조건을 확인해야 해.

### 2.2 점검내용의 평가 절차

#### ① 평가대상과 범위를 확정해

설비, 작업구역, 작업방법, 작업시간, 협력업체 작업, 비정상작업을 구분해야 해. 정상 생산만 보고 청소·정비·고장조치·교대·작업 준비를 빼면 중대한 위험이 누락될 수 있어.

#### ② 적용 기준을 연결해

각 점검항목마다 판정 근거가 있어야 해. “위험해 보인다”가 아니라 “회전체에 작업자가 접촉할 수 있으나 방호장치가 설치되지 않았다”처럼 기준과 사실을 연결해야 해.

#### ③ 객관적인 증거를 수집해

현장 관찰, 사진, 측정값, 작업자 면담, 설비 이력, 교육기록, 점검기록을 서로 대조해. 사진 한 장만으로 작업 빈도와 노출시간까지 단정해서는 안 돼.

#### ④ 적합 여부를 판정해

판정은 보통 다음처럼 구분할 수 있어.

| 판정 | 의미 | 후속조치 |
|---|---|---|
| 적합 | 적용 기준을 충족함 | 상태 유지와 정기 확인 |
| 부적합 | 기준을 충족하지 못함 | 시정조치와 위험성 판단 |
| 관찰사항 | 즉시 부적합으로 단정하기 어렵지만 악화 가능성이 있음 | 추가 확인 또는 예방조치 |
| 즉시조치 대상 | 급박하거나 중대한 위험이 존재함 | 작업 통제 후 안전 확보 |

여기서 “점검하지 못함”을 “적합”으로 처리하면 안 돼. 확인할 수 없었던 항목은 미확인 사유와 추가 확인계획을 남겨야 해.

### 2.3 위험요인을 구체화하는 방법

좋은 위험요인 문장은 다음 구조를 가져.

**위험원 + 노출 상황 + 사고 과정 + 예상 결과**

예를 들어 볼게.

| 불충분한 표현 | 구체적인 위험요인 |
|---|---|
| 방호덮개 불량 | 운전 중인 회전체의 방호덮개가 제거되어 작업자의 손이 말려 들어갈 위험 |
| 바닥 불량 | 바닥에 누출된 기름으로 이동 중인 작업자가 미끄러져 넘어질 위험 |
| 전기 위험 | 피복이 손상된 전선의 충전부에 접촉하여 감전될 위험 |
| 적재 불량 | 불안정하게 적재된 자재가 무너져 인접 작업자를 가격할 위험 |
| 환기 불량 | 밀폐된 장소에 유해가스가 축적되어 작업자가 중독되거나 질식할 위험 |

위험요인은 사람의 불안전한 행동만으로 설명하지 않는 게 좋아. 작업자가 방호장치를 해제했다면 “작업자 부주의”로 끝낼 것이 아니라, 방호장치를 해제해야만 작업할 수 있었던 설비구조, 생산압박, 감독 부재, 표준작업절차의 결함까지 살펴야 해.

### 2.4 위험성을 판단하는 원리

위험성은 일반적으로 **사고가 발생할 가능성**과 **발생했을 때의 중대성**을 결합해 판단해. 사업장에 따라 노출빈도, 노출인원, 기존 대책의 신뢰성을 추가할 수도 있어.

가령 동일한 날카로운 모서리라도 사람이 거의 접근하지 않는 격리구역에 있는 경우와 작업자가 매시간 손을 넣는 위치에 있는 경우는 가능성이 달라. 반대로 발생 가능성이 낮아도 사망이나 다수 피해로 이어질 수 있는 위험은 높은 우선순위를 부여해야 해.

위험성 등급을 기계적으로 계산하는 것만으로는 부족해. 다음 상황은 수치와 무관하게 우선적인 통제가 필요할 수 있어.

1. 급박한 위험이 있는 경우
2. 중대재해로 이어질 수 있는 경우
3. 법정 안전조치가 누락된 경우
4. 다수의 작업자가 동시에 노출되는 경우
5. 과거 동일하거나 유사한 재해가 발생한 경우
6. 기존 대책이 사실상 작동하지 않는 경우

### 2.5 구체적인 평가 예시

프레스 작업구역을 점검했는데 작업자가 재료 위치를 바로잡기 위해 금형 사이에 손을 넣고 있었고, 방호장치는 반복적으로 무력화된 상태였다고 해보자.

관찰된 사실은 “방호장치 무력화”와 “금형 사이로 손이 진입함”이야. 적용 기준과 비교하면 위험점에 대한 접근 방지가 유지되지 않은 부적합 상태야. 도출되는 위험요인은 “프레스가 예기치 않게 작동하거나 슬라이드가 하강할 때 작업자의 손이 금형 사이에 끼어 절단·협착될 위험”이야.

여기서 “작업자에게 주의교육을 한다”만 제안하면 부족해. 설비가 작동하는 동안 위험점에 손이 들어갈 수 있다는 구조적 조건이 남기 때문이야.

### 2.6 비교와 경계

| 구분 | 핵심 의미 |
|---|---|
| 위험원 | 손상을 일으킬 잠재력을 가진 근원이나 상태 |
| 위험요인 | 위험원과 사람이 접촉하여 사고로 이어질 수 있는 구체적 조건 |
| 유해요인 | 건강장해를 일으킬 수 있는 물리적·화학적·생물학적 요인 |
| 위험성 | 사고 또는 건강장해가 발생할 가능성과 결과의 중대성을 고려한 정도 |
| 부적합 | 정해진 요구사항을 충족하지 못한 상태 |
| 재해 | 위험이 현실화되어 인적·물적 손실이 발생한 결과 |

**시험 함정:** “위험요인”을 묻는데 개선대책만 쓰거나, “평가 절차”를 묻는데 위험 종류만 나열하면 요구사항을 벗어난 답이 돼. 무엇을 묻는지 먼저 구분해야 해.

## 3. 안전점검결과 발생한 위험요소를 감소하기 위한 개선방안을 도출할 수 있다.

### 3.1 개선방안의 기본 원리

개선방안은 단순히 가능한 조치를 늘어놓는 작업이 아니야. **위험을 근원적으로 제거할 수 있는 대책부터 검토하고, 현실적으로 남는 위험을 여러 방어층으로 통제하는 과정**이야.

일반적인 우선순위는 다음과 같아.

1. **제거:** 위험한 작업, 물질, 설비 또는 노출 자체를 없앰
2. **대체:** 더 안전한 물질·공정·설비로 바꿈
3. **공학적 대책:** 격리, 방호, 밀폐, 환기, 자동화처럼 사람과 위험원을 구조적으로 분리함
4. **관리적 대책:** 작업절차, 허가제도, 교육, 감독, 점검주기, 작업시간을 개선함
5. **개인보호구:** 남아 있는 위험으로부터 개인을 보호함

개인보호구가 중요하지 않다는 뜻은 아니야. 다만 보호구는 사람이 정확히 선택하고, 착용하고, 관리해야 효과가 나므로 위험원을 제거하거나 격리하는 대책보다 실패 가능성이 커.

### 3.2 개선방안을 도출하는 절차

#### ① 원인을 분석해

직접원인과 근본원인을 분리해야 해. 예를 들어 바닥에 기름이 흘러 미끄럼 위험이 발생했다면 직접원인은 기름이 묻은 바닥이지만, 근본원인은 배관 열화, 예방정비 누락, 누출감지 부재, 청소 책임 불명확일 수 있어.

#### ② 가능한 대책을 폭넓게 검토해

하나의 위험요인에 대하여 제거, 대체, 공학적 대책, 관리적 대책, 보호구를 차례로 검토해. 처음 떠오른 “교육 실시”에 멈추지 않는 게 핵심이야.

#### ③ 적정성을 평가해

다음 질문으로 후보 대책을 평가할 수 있어.

1. 위험의 발생 가능성과 중대성을 실제로 낮추는가?
2. 법적·기술적 요구사항을 충족하는가?
3. 새로운 위험을 만들지 않는가?
4. 정상작업뿐 아니라 정비·청소·비상상황에도 작동하는가?
5. 작업자가 우회하거나 무력화하기 쉬운 대책은 아닌가?
6. 유지관리와 성능 확인이 가능한가?

#### ④ 우선순위와 실행계획을 정해

개선조치는 위험도가 높은 항목, 중대재해 가능 항목, 법적 미준수 항목부터 우선해야 해. 조치계획에는 적어도 **조치내용, 책임자, 완료기한, 필요한 자원, 임시조치, 완료 확인방법**이 들어가야 해.

#### ⑤ 잔여위험을 재평가해

대책을 설치했다고 위험이 자동으로 허용 가능한 수준까지 낮아지는 것은 아니야. 개선 후 현장을 다시 확인하고 위험성을 재평가해야 해. 잔여위험이 크다면 추가 대책을 적용해야 해.

### 3.3 위험요인별 개선대책 예시

| 점검결과 | 근본원인 예시 | 우선 개선방안 | 보완 대책 | 효과 확인 |
|---|---|---|---|---|
| 회전체 방호덮개 제거 | 청소 시 덮개 해체가 필요함 | 개방하지 않고 청소할 수 있도록 설비구조 변경 | 인터록, 잠금표지 절차, 교육 | 덮개 개방 시 가동 불가 시험 |
| 통로 적치물 | 보관공간과 물류동선 부족 | 적치 원인을 제거하고 전용 보관구역 확보 | 통로 표시, 순회점검 | 통로 폭과 장애물 재확인 |
| 배관 누출 | 예방정비 주기 부적절 | 손상 배관 교체와 누출원 제거 | 누출감지, 방유턱, 청소절차 | 누출 여부와 바닥 상태 확인 |
| 국소배기 성능 저하 | 필터 막힘과 점검 누락 | 후드·덕트·집진설비 정비 | 성능점검 주기와 책임자 지정 | 설계된 제어성능 유지 확인 |
| 전기설비 임시배선 | 전원 인출구 부족 | 적정 용량의 고정배선 설치 | 손상방지, 차단장치, 정기점검 | 절연·접지·차단기능 확인 |

### 3.4 프레스 사례의 개선안

앞의 프레스 사례에 적용해보자.

첫째, 작업자가 금형 사이에 손을 넣어야 하는 공정 자체를 제거할 수 있는지 검토해. 자동공급장치나 전용 수공구로 재료 위치 조정 작업을 바꾸는 방법이 있어.

둘째, 위험점 접근 시 작동을 차단하는 방호장치와 인터록을 적용해. 방호장치가 쉽게 무력화되지 않도록 설계하고, 고장 시 안전한 상태로 정지하도록 해야 해.

셋째, 금형교체·청소·고장조치 때 에너지를 차단하고 재가동을 방지하는 절차를 마련해. 권한, 확인방법, 표지와 잠금의 관리가 함께 있어야 해.

넷째, 작업표준을 변경하고 작업자와 감독자에게 교육해. 그러나 교육은 공학적 대책을 대신하는 것이 아니라 보완하는 방어층이야.

다섯째, 조치 후 실제 작업을 관찰해 손이 위험점에 들어가지 않는지, 방호장치가 생산과정에서 계속 유지되는지 확인해야 해.

### 3.5 임시조치와 영구조치

즉시 영구개선을 끝낼 수 없는 경우에는 위험구역 출입통제, 작업중지, 설비 사용금지, 감시인 배치 같은 임시조치를 먼저 시행할 수 있어. 그러나 임시조치는 영구조치의 대체물이 아니야.

| 임시조치 | 영구조치 |
|---|---|
| 단기간 노출을 통제함 | 위험의 원인이나 구조를 지속적으로 개선함 |
| 신속하게 적용할 수 있음 | 설계·예산·공사기간이 필요할 수 있음 |
| 관리가 풀리면 효과가 사라질 수 있음 | 유지되는 한 비교적 안정적인 효과를 기대할 수 있음 |
| 종료조건과 후속기한이 필요함 | 성능 검증과 유지관리 기준이 필요함 |

**시험 함정:** “교육 실시, 보호구 착용, 주의표지 부착”만 반복하면 관리적 대책에 편중돼. 가능하면 제거와 공학적 대책을 먼저 제시하고, 관리적 대책과 보호구를 보완수단으로 연결해야 해.

## 4. 안전점검결과를 바탕으로 사업장내 안전관리 시스템을 개선할 수 있다.

### 4.1 개별 시정과 시스템 개선의 차이

개별 시정은 발견된 한 건의 문제를 바로잡는 일이야. 시스템 개선은 같은 종류의 문제가 다른 설비·부서·시간대에서 반복되지 않도록 관리방식을 바꾸는 일이야.

예를 들어 소화기 앞의 적치물을 치운 것은 개별 시정이야. 반면 소방시설 접근구역을 표준화하고, 점검표에 접근성 항목을 추가하며, 물류배치 기준과 담당자 책임을 고친 것은 시스템 개선이야.

시스템 개선은 **계획–실행–확인–개선**의 순환으로 이해할 수 있어.

| 순환 단계 | 안전점검결과의 활용 |
|---|---|
| 계획 | 위험요인, 목표, 대책, 책임자, 자원과 기한 설정 |
| 실행 | 공학적 개선, 절차 개정, 교육과 의사소통 |
| 확인 | 점검, 성과측정, 내부검토, 조치완료 검증 |
| 개선 | 원인분석, 표준 개정, 수평전개, 경영검토 |

### 4.2 시스템 개선 절차

#### ① 점검결과를 분류하고 추세를 분석해

부서, 공정, 설비, 위험유형, 원인, 위험등급, 반복 여부로 분류해. 단일 점검결과만 보면 우연처럼 보이던 문제가 여러 기록을 묶으면 구조적인 결함으로 드러날 수 있어.

예를 들어 여러 부서에서 방호장치 해제가 반복된다면 특정 작업자의 태도보다 생산방식, 설비설계, 정비절차 또는 감독체계의 문제일 가능성이 커.

#### ② 반복되는 근본원인을 찾아

“왜 발생했는가?”를 연속해서 물어 원인을 추적할 수 있어. 다만 횟수를 채우는 데 집착하기보다, 조직이 통제할 수 있는 원인에 도달하는 것이 중요해.

예시는 다음과 같아.

방호덮개가 제거됐다 → 청소하기 불편했다 → 가동 상태에서만 이물질을 제거할 수 있었다 → 설비 구매 시 청소·정비 안전성을 검토하지 않았다 → 구매검토 절차에 안전부서 참여 기준이 없었다.

이렇게 분석하면 대책도 “작업자 재교육”에서 “설비 구매·변경관리 절차 개선”으로 깊어져.

#### ③ 관리요소를 개정해

점검결과에 따라 다음 요소를 개선할 수 있어.

1. 안전보건 방침과 목표
2. 조직별 책임과 권한
3. 위험성평가 절차
4. 작업표준과 작업허가 절차
5. 설비 구매·변경·정비관리
6. 교육훈련과 자격관리
7. 협력업체 선정·조정·감독
8. 비상조치계획
9. 점검표, 점검주기와 점검자 역량
10. 시정조치 추적과 완료 검증
11. 경영층 보고와 성과검토
12. 근로자 참여와 위험신고 체계

#### ④ 수평전개를 실시해

한 설비에서 발견된 위험이 같은 형식의 설비에도 존재할 수 있어. 동일·유사 설비, 다른 교대조, 협력업체 구역까지 범위를 확장해 확인하는 것을 수평전개라고 이해하면 돼.

#### ⑤ 효과성을 검증해

“조치 완료”와 “조치 효과 있음”은 다르다. 방호장치를 설치한 사진이 있더라도 현장에서 계속 우회되고 있다면 효과적인 개선이 아니야.

효과성 검증에는 다음이 포함될 수 있어.

1. 현장 재점검
2. 작업자 행동과 작업방법 관찰
3. 설비 기능시험과 측정
4. 유사 부적합의 재발 여부 확인
5. 아차사고·재해·고장지표의 변화 확인
6. 작업자 의견 확인
7. 추가 위험 또는 부작용 확인

### 4.3 안전관리 시스템 개선 사례

사업장 여러 구역에서 지게차와 보행자의 동선이 겹친다는 점검결과가 반복됐다고 해보자.

개별 시정만 한다면 바닥선을 다시 칠하거나 작업자에게 주의를 줄 수 있어. 하지만 시스템 개선은 더 넓게 접근해.

먼저 물류량과 이동경로를 분석해 차량과 보행자의 동선을 물리적으로 분리해. 교차가 불가피한 지점에는 출입통제, 시야확보, 경보와 우선통행 기준을 적용해. 이어서 신규 설비 배치와 공정변경 전에 물류동선 위험을 검토하도록 변경관리 절차를 고쳐. 지게차 운전자뿐 아니라 보행자, 방문자, 협력업체에 대한 교육기준도 정비해. 마지막으로 충돌·근접사고, 동선 침범, 시설 훼손 상태를 정기적으로 확인해 개선 효과를 검증해.

이처럼 시스템 개선은 **현장 한 지점의 표시를 고치는 것에서 끝나지 않고, 설계·변경관리·교육·점검·성과평가를 연결하는 것**이야.

### 4.4 선행지표와 후행지표

| 구분 | 의미 | 예시 |
|---|---|---|
| 선행지표 | 사고가 발생하기 전에 예방활동의 작동상태를 보여주는 지표 | 고위험 개선조치 완료율, 기한 준수율, 재점검 실시율, 작업허가 준수율 |
| 후행지표 | 이미 발생한 결과를 보여주는 지표 | 재해건수, 손실일수, 설비손상, 누출사고 건수 |

재해건수가 줄었다고 관리체계가 반드시 좋아졌다고 단정할 수 없어. 우연히 사고가 발생하지 않았을 수도 있기 때문이야. 반대로 위험신고 건수가 증가한 것은 위험이 늘어난 결과일 수도 있지만, 신고문화가 활성화된 신호일 수도 있어. 따라서 여러 지표를 함께 해석해야 해.

### 4.5 비교와 경계

| 잘못된 접근 | 개선된 접근 |
|---|---|
| 부적합 건수를 줄이기 위해 점검기준을 느슨하게 함 | 부적합의 근본원인과 반복 양상을 줄임 |
| 조치완료 사진만 받음 | 현장 기능과 재발 여부까지 검증함 |
| 사고가 난 부서만 개선함 | 유사 설비와 전 부서로 수평전개함 |
| 작업자 부주의로 종결함 | 설계·절차·교육·감독·자원 요인을 함께 분석함 |
| 점검표를 매년 그대로 사용함 | 사고, 변경, 점검결과에 따라 항목과 주기를 개정함 |

**시험 함정:** 안전관리 시스템 개선을 “교육 강화” 한 줄로 끝내면 부족해. 점검결과의 분석, 근본원인 규명, 절차와 책임체계의 개정, 수평전개, 효과성 검증까지 연결해야 완성도 높은 답이 돼.

## 5. 실기 답안 작성 틀

서술형에서는 다음 순서로 쓰면 논리가 안정돼.

### 위험요인 도출형

1. 적용 안전기준을 확인한다.
2. 현장의 설비·작업방법·작업환경을 관찰하거나 측정한다.
3. 기준과 실제 상태를 비교하여 부적합을 판정한다.
4. 위험원, 노출 상황, 예상 재해를 구체화한다.
5. 발생 가능성과 결과의 중대성을 고려하여 위험성을 평가한다.
6. 중대하고 시급한 위험부터 우선순위를 정한다.

### 개선방안 도출형

1. 부적합의 직접원인과 근본원인을 분석한다.
2. 제거와 대체 가능성을 우선 검토한다.
3. 공학적 대책을 적용한다.
4. 관리적 대책과 개인보호구를 보완한다.
5. 책임자, 기한과 확인방법을 정한다.
6. 개선 후 잔여위험을 재평가한다.

### 시스템 개선형

1. 점검결과를 위험유형·부서·원인별로 분류한다.
2. 반복성과 추세를 분석한다.
3. 근본원인을 규명한다.
4. 절차, 조직, 교육, 점검과 자원배분을 개선한다.
5. 유사 공정과 설비에 수평전개한다.
6. 재점검과 성과지표를 통해 효과성을 검증한다.

## 6. 종합 사례

한 사업장에서 혼합기 내부 청소작업 중 설비가 예기치 않게 작동할 가능성이 발견됐다고 해보자. 현장에는 주전원 차단 절차가 있었지만 작업자가 차단기를 내린 뒤 개인 잠금장치를 설치하지 않았고, 다른 사람이 전원을 복구할 수 있는 상태였어.

### 평가

적용 작업절차와 실제 작업을 비교하면 에너지 차단 후 재가동 방지조치가 유지되지 않은 부적합이야. 위험요인은 “혼합기 내부에서 청소 중인 작업자가 다른 사람의 전원 복구로 회전체에 끼이거나 충돌하여 중상을 입을 위험”으로 표현할 수 있어. 사고 결과가 매우 중대하므로 우선적인 통제가 필요해.

### 개선방안

즉시 작업을 중지하고 내부 작업자를 안전한 장소로 대피시켜. 그다음 전원과 잔류에너지를 차단하고 잠금·표지·무에너지 상태 확인 절차를 적용해. 장기적으로는 작업자가 혼합기 내부에 들어가지 않고 청소할 수 있는 설비구조를 검토하고, 불가피한 내부작업에는 개인별 잠금장치, 작업허가, 에너지 차단목록과 복구 확인절차를 마련해야 해.

### 시스템 개선

같은 형식의 혼합기뿐 아니라 컨베이어, 파쇄기, 교반기 등 예기치 않은 작동 위험이 있는 설비로 점검범위를 확대해. 정비·청소작업 절차, 도급작업 조정, 잠금장치 지급, 작업자 자격, 감독자의 확인책임을 개정해야 해. 이후 현장 관찰과 기능시험을 통해 절차가 실제로 작동하는지 확인하고, 발견된 문제를 경영검토와 다음 위험성평가에 반영해야 해.

## 8. 정답 및 해설

### 문제 1 정답

“절단기 회전날의 방호덮개가 분리되어 작업자의 손이나 의복이 회전날에 접촉·말림되어 절단 또는 중상을 입을 위험”이라고 쓸 수 있어.

**해설:** 방호덮개 분리는 관찰된 상태일 뿐이야. 작업자의 노출, 사고 과정과 예상 결과를 연결해야 완전한 위험요인 문장이 돼.

### 문제 2 정답

**다 → 라 → 나 → 마 → 가**

분진 발생 공정 제거 → 저분진 원료로 대체 → 국소배기장치 설치 → 작업시간·청소절차 관리 → 방진마스크 착용 순서야.

**해설:** 제거, 대체, 공학적 대책, 관리적 대책, 개인보호구의 순서로 검토한 거야. 실제 현장에서는 하나의 대책만 선택하기보다 여러 대책을 조합할 수 있어.

### 문제 3 정답

사진만으로는 충분하지 않아. 사진은 특정 시점에 적치물이 제거됐다는 사실만 보여줄 뿐, 통로가 지속적으로 확보되고 재적치 원인이 제거됐는지는 증명하지 못해.

추가로 보관공간 확보 여부, 물류동선 변경 여부, 통로의 필요한 상태 유지 여부, 다른 시간대의 재적치 여부, 담당자와 점검주기, 작업자 의견을 확인해야 해.

### 문제 4 정답

동일한 설계, 작업방법 또는 관리절차가 적용된 설비에는 같은 위험이 잠재할 수 있으므로 한 대만 고치면 다른 설비에서 사고가 발생할 수 있어.

동일·유사 설비 전체를 수평점검하고, 방호장치의 구조와 무력화 원인을 분석해야 해. 설비개선, 작업표준 개정, 변경관리, 교육, 감독, 정기 기능점검과 효과성 검증을 시스템에 반영해야 해.

### 문제 5 정답

점검결과 분류 → 위험성과 우선순위 평가 → 반복·추세 분석 → 직접원인과 근본원인 규명 → 개선목표와 실행계획 수립 → 절차·설비·조직·교육 개선 → 유사 공정 수평전개 → 재점검과 성과지표를 통한 효과성 검증 → 결과의 경영검토 및 지속적 개선 순서로 정리할 수 있어.

## 9. 요약

   기준과 현장의 실제 상태를 비교해 적합 여부를 판정하고, 위험원·노출 상황·사고 과정·예상 결과를 연결해 위험요인을 구체적으로 표현해야 해.

2. **안전점검결과 발생한 위험요소를 감소하기 위한 개선방안을 도출할 수 있다.**  
   직접원인과 근본원인을 분석한 뒤 제거, 대체, 공학적 대책, 관리적 대책, 개인보호구 순으로 검토하고, 조치 후 잔여위험을 재평가해야 해.
