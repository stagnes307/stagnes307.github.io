# 1-9-2-1. 무전압을 증명하는 정전작업 안전지도
산업안전기사 실기  
안전한 정전작업 수행을 위한 안전작업계획서를 수립할 수 있다. · 정전작업 중 안전사고가 우려 시 작업중지를 결정할 수 있다. · 정전작업 수행 시 필요한 보호구와 방호구, 작업용 기구와 장치, 표지를 선정하고 사용할 수 있다.

> 핵심 키워드: 정전작업, 전원 차단, 잠금·표지, 무전압 확인, 잔류전하 방전, 단락접지, 작업중지, 보호구

## 1. 정전작업의 핵심 개념

정전작업은 단순히 스위치를 끈 상태에서 하는 작업이 아니야. 작업 대상 전기설비를 모든 전원에서 분리하고, 다른 사람이 임의로 다시 투입하지 못하도록 통제하며, 검전으로 무전압을 확인한 뒤 필요한 방전·접지 조치까지 완료한 상태에서 수행하는 작업이야.

핵심은 **정전이라는 상태를 추측하지 않고 작업자가 직접 증명하는 것**이야. 표시등이 꺼졌거나 기계가 멈췄다는 사실만으로는 안전을 보장할 수 없어. 예비전원, 비상발전기, 축전지, 태양광 설비, 제어회로, 유도전압, 역송전처럼 눈에 잘 보이지 않는 에너지원이 남아 있을 수 있기 때문이야.

정전작업 안전은 다음 세 가지 장벽이 연속해서 성립해야 완성돼.

1. **에너지 제거:** 전원을 차단하고 설비를 전원으로부터 분리한다.
2. **재통전 방지:** 잠금장치와 표지를 설치해 임의 조작을 막는다.
3. **무전압 증명:** 적합한 검전기로 작업 지점의 무전압을 직접 확인한다.

여기에 잔류전하가 예상되면 방전하고, 오통전이나 유도전압의 위험이 있으면 단락접지를 실시해야 해. 하나라도 빠지면 정전작업의 안전조건은 완성되지 않아.

## 2. 안전작업계획서에 담아야 할 내용

**안전한 정전작업 수행을 위한 안전작업계획서를 수립할 수 있다.**

계획서는 “조심해서 작업한다”는 선언문이 아니라, 누가 어떤 설비를 어떤 순서로 격리하고 확인할지를 미리 결정하는 실행 문서야. 다음 내용을 구체적으로 적어야 해.

### 작업 범위와 책임

작업 대상 설비의 명칭, 위치, 회로, 작업구역과 작업시간을 특정해야 해. 작업책임자, 정전조작 담당자, 검전 담당자, 감시인과 작업자의 역할도 분명히 정해야 하지. 동일 설비에서 여러 작업조가 일한다면 각 작업조의 잠금과 해제 권한까지 구분해야 해.

### 전원과 위험요인의 조사

단선결선도와 현장 표시를 대조해 주전원뿐 아니라 보조전원, 비상전원, 축전지, 발전기, 태양광 전원, 제어전원과 역송전 가능성을 조사해야 해. 콘덴서의 잔류전하, 장거리 케이블의 유도전압, 인접 충전부, 자동복귀 기능, 원격조작 가능성도 확인 대상이야.

### 작업 순서와 안전조치

계획서에는 다음 순서가 드러나야 해.

1. 관계자에게 작업과 정전 범위를 알린다.
2. 부하를 정지하고 정해진 절차에 따라 전원을 차단한다.
3. 개폐기와 단로장치 등을 이용해 모든 전원에서 분리한다.
4. 조작부에 잠금장치와 정전작업 표지를 설치한다.
5. 검전기의 정상 작동을 확인한다.
6. 작업 대상의 모든 필요한 상과 도체를 검전한다.
7. 검전기를 다시 확인해 측정 중 고장이 없었음을 확인한다.
8. 잔류전하를 방전하고 필요한 경우 단락접지한다.
9. 인접 충전부를 방호하고 작업구역을 구획한다.
10. 작업허가 후 정전작업을 시작한다.
11. 종료 후 공구·인원·접지 상태를 확인한다.
12. 권한 있는 사람이 접지, 표지와 잠금을 정해진 순서로 해제한다.
13. 관계자에게 통보한 후 전원을 재투입한다.

검전기의 정상 여부를 **검전 전과 검전 후에 모두 확인**하는 이유는 중요해. 검전기가 처음부터 고장 났거나 측정 도중 손상되었다면 “전압이 없다”는 표시를 신뢰할 수 없기 때문이야.

## 3. 정전작업의 표준 안전절차

전체 절차는 **차단 → 분리 → 잠금·표지 → 검전 → 방전 → 접지 → 작업 → 복구**로 기억하면 좋아.

### 차단과 분리

먼저 부하를 정상적으로 정지한 뒤 전원을 차단해. 그러나 차단기 OFF만으로 충분하지 않아. 차단기의 접점 용착, 원격 재투입, 조작 착오가 있을 수 있으므로 가능한 경우 단로기 개방, 플러그 분리, 퓨즈 제거 등 눈으로 확인할 수 있는 격리점을 확보해야 해.

### 잠금과 표지

격리한 조작부에는 잠금장치를 설치하고 “정전작업 중”, “조작 금지”, 작업자와 연락처 같은 정보를 표시해. 잠금은 물리적으로 조작을 막고, 표지는 조작하면 안 되는 이유와 책임자를 알려 줘. 따라서 표지만 붙이는 것은 잠금장치를 대신하지 못해.

여러 사람이 작업한다면 개인별 잠금 또는 이에 준하는 통제체계를 사용해야 해. 작업이 끝났다는 이유로 다른 사람의 잠금을 임의로 제거하면 안 돼. 각 잠금은 원칙적으로 설치한 사람이나 정해진 권한과 확인 절차를 가진 책임자가 해제해야 해.

### 검전·방전·접지

검전은 작업할 바로 그 지점에서 실시하고, 3상 설비라면 필요한 모든 상과 대지 사이, 상호 간의 전압 가능성을 확인해야 해. 검전기는 설비의 전압등급과 환경에 적합해야 하며, 절연장갑 같은 필요한 보호구를 착용하고 사용해야 해.

콘덴서나 케이블에는 전원을 끈 뒤에도 전하가 남을 수 있으므로 충분히 방전해야 해. 단락접지는 오통전이나 유도전압이 발생했을 때 전류를 안전한 경로로 흘려 보호장치를 동작시키고 작업점의 전위 상승을 억제하는 장벽이야. 접지장치를 설치할 때는 일반적으로 **접지측을 먼저 연결하고 전로측을 나중에 연결**하며, 철거할 때는 그 반대 순서를 적용해.

## 4. 보호구·방호구·기구·표지의 선정

**정전작업 수행 시 필요한 보호구와 방호구, 작업용 기구와 장치, 표지를 선정하고 사용할 수 있다.**

선정 기준은 품목 이름을 외우는 데 있지 않아. 설비의 전압, 예상되는 아크·감전 위험, 작업 위치, 인접 충전부, 습기와 협소 공간 같은 환경을 평가한 뒤 적합한 등급과 상태의 용품을 골라야 해.

### 개인보호구

- **절연장갑:** 차단·검전·접지처럼 전기적 접촉 가능성이 있는 작업에서 사용해. 전압등급, 사용기한, 천공·균열·오염 여부를 확인해야 해.
- **안전모:** 머리의 충격과 전기적 위험에 적합한 제품을 선택해.
- **보안면과 보안경:** 개폐 조작이나 사고에 따른 아크, 비산물로부터 얼굴과 눈을 보호해.
- **난연성 작업복:** 아크열에 의한 착화와 화상 확대를 줄이는 데 사용해.
- **절연화:** 작업환경과 전압 위험에 맞게 선정하며 젖음과 손상 여부를 점검해.

### 방호구와 작업용 기구

- **절연용 방호구:** 인접한 충전부를 덮거나 격리해 우발적 접근과 접촉을 막아.
- **절연매트와 절연대:** 작업자의 대지 접촉 경로를 줄이는 보조 장벽이야.
- **검전기:** 무전압을 확인하는 핵심 측정기구로, 대상 전압에 적합해야 해.
- **방전기구:** 잔류전하를 안전하게 제거할 때 사용해.
- **단락접지기구:** 전로를 단락하고 대지에 연결해 오통전과 유도전압에 대비해.
- **절연공구:** 손잡이의 절연 성능과 손상 상태를 확인하고 용도에 맞게 사용해.
- **잠금장치:** 차단기의 임의 조작과 재통전을 물리적으로 방지해.
- **차단봉·울타리:** 작업구역과 접근금지 구역을 구분해 제3자의 진입을 막아.

### 표지

“정전작업 중”, “조작 금지”, “접근 금지”, “고압 위험”과 같은 표지는 위험의 성격과 금지행위를 명확히 전달해야 해. 잘 보이는 위치에 견고하게 설치하고, 작업 종료와 안전 확인 전에 제거하면 안 돼.

모든 보호구와 기구는 사용 전 외관, 오염, 균열, 습기, 성능과 전압등급을 점검해야 해. 보호구를 착용했다는 사실이 차단·검전·접지를 생략할 이유가 되지는 않아. 보호구는 절차 실패에 대비하는 추가 장벽이지, 정전절차의 대체물이 아니야.

## 5. 작업중지 결정과 보고

**정전작업 중 안전사고가 우려 시 작업중지를 결정할 수 있다.**

작업중지는 사고가 발생한 뒤 내리는 조치가 아니야. 계획과 다른 상태, 에너지 통제의 불확실성 또는 보호장벽의 손상을 발견한 순간 피해가 발생하기 전에 내리는 예방 결정이야.

다음 상황에서는 즉시 작업을 멈춰야 해.

- 검전 결과 전압이 검출되거나 측정 결과가 불확실하다.
- 전원 계통이나 격리점을 확실히 식별할 수 없다.
- 잠금장치나 표지가 훼손·제거되었거나 임의 조작의 흔적이 있다.
- 비상전원, 발전기, 축전지 또는 역송전 가능성이 새로 발견되었다.
- 단락접지기구, 검전기, 절연장갑 등 필수 장비가 손상되었다.
- 인접 충전부의 방호가 불충분하거나 안전거리를 유지할 수 없다.
- 작업계획과 다른 설비 상태 또는 작업조건이 확인되었다.
- 누수, 침수, 화재, 이상음, 냄새, 발열 등 새로운 위험이 발생했다.
- 감시인이 이탈했거나 의사소통이 두절되었다.
- 작업자의 건강상태나 숙련도로 안전한 수행이 어렵다.

중지 후에는 작업자에게 즉시 알리고 위험구역에서 벗어나게 한 다음, 작업책임자에게 보고해. 그 뒤 에너지원을 다시 확인하고 위험성평가와 작업계획을 보완해야 해. 안전조치가 복구되고 책임자가 재개를 승인하기 전에는 작업을 다시 시작하면 안 돼.

## 6. 실제 적용 사례

배전반 내부의 차단기를 교체하는 작업을 생각해 보자. 담당자는 도면상 주전원만 차단하면 된다고 판단했지만, 현장에는 제어용 변압기와 비상발전기 연계회로가 존재했어.

안전작업계획 단계에서는 단선결선도와 현장을 대조해 주전원, 제어전원과 비상전원을 모두 식별해야 해. 관계자에게 정전 범위를 통보하고 각 전원을 차단·분리한 뒤 잠금장치와 표지를 설치하지. 이후 적합한 검전기의 정상 작동을 확인하고 작업점에서 모든 관련 도체를 검전한 다음 검전기를 다시 시험해.

그런데 한 단자에서 전압이 검출되었다면 “낮은 전압이니 계속하자”고 판단하면 안 돼. 즉시 작업을 중지하고 작업자를 물린 뒤 역송전 경로를 추적해야 해. 비상발전기 자동절체회로가 원인이라면 해당 전원을 추가로 격리하고 계획서를 수정해. 다시 잠금·표지와 검전을 완료하고 필요한 접지·방호 조치를 실시한 뒤에만 작업을 재개할 수 있어.

작업 종료 후에도 바로 투입하지 않아. 인원과 공구의 철수, 덮개 복구, 단락접지 제거, 잠금·표지 해제와 관계자 통보를 확인한 뒤 책임 있는 절차에 따라 전원을 복구해야 해.

## 7. 비교·경계와 시험 함정

| 혼동하기 쉬운 판단 | 올바른 판단 |
|---|---|
| 차단기를 OFF 했으니 정전이 완료되었다 | 분리, 잠금·표지, 검전과 필요한 방전·접지까지 확인한다 |
| 표시등이 꺼졌으니 무전압이다 | 적합한 검전기로 작업 지점에서 직접 확인한다 |
| 표지를 붙였으니 잠금장치가 필요 없다 | 표지는 경고, 잠금은 물리적 재통전 방지 기능을 한다 |
| 보호구를 착용했으니 검전을 생략할 수 있다 | 보호구는 보조 장벽이며 무전압 확인을 대신할 수 없다 |
| 작은 이상은 작업 후 보고하면 된다 | 사고 우려가 있으면 먼저 중지하고 보고·재평가한다 |
| 작업이 끝나면 아무나 잠금을 해제할 수 있다 | 설치자 또는 정해진 권한과 절차에 따라 해제한다 |

실기시험에서는 **차단**만 적고 끝내는 답안이 흔한 함정이야. 정전작업 순서를 묻는다면 잠금·표지, 검전, 방전, 접지와 작업구역 통제를 함께 떠올려야 해.

“검전기의 정상 여부 확인”도 한 번만 쓰기보다 **검전 전·후 확인**으로 표현하면 정확도가 높아져. 단락접지 순서에서는 설치 시 접지측을 먼저, 철거 시 전로측을 먼저 분리한다는 방향을 바꾸지 않도록 주의해.

작업중지 기준을 묻는 문제에는 막연히 “위험하면 중지한다”라고 쓰기보다 전압 검출, 잠금 훼손, 보호구 손상, 계획과 다른 상태, 인접 충전부 노출처럼 관찰 가능한 조건을 제시하는 것이 좋아.

## 8. 확인 문제

### 문제 1

정전작업을 시작하기 전의 핵심 안전절차를 순서에 맞게 서술해 봐.

### 문제 2

검전기의 정상 작동 상태를 검전 전과 검전 후에 확인해야 하는 이유는 무엇일까?

### 문제 3

작업 중 잠금장치가 훼손된 사실을 발견했다. 작업자가 취해야 할 조치를 세 단계로 써 봐.

### 문제 4

정전작업용 보호구·방호구 또는 작업용 기구를 네 가지 제시하고 각각의 역할을 설명해 봐.

### 문제 5

단락접지기구의 설치·철거 순서를 접지측과 전로측의 관계로 설명해 봐.

## 9. 정답 및 해설

### 문제 1 정답

관계자 통보 및 부하 정지 → 전원 차단 → 모든 전원으로부터 분리 → 잠금장치와 표지 설치 → 검전기 정상 확인 → 작업점 무전압 확인 → 검전기 재확인 → 잔류전하 방전 → 필요한 단락접지와 인접 충전부 방호 → 작업허가와 작업 개시의 순서야.

핵심은 차단 이후에도 재통전 방지와 무전압 증명이 이어져야 한다는 점이야.

### 문제 2 정답

검전 전 확인은 검전기가 처음부터 정상인지 확인하기 위한 것이고, 검전 후 확인은 측정 과정에서 검전기가 고장 나지 않았는지 확인하기 위한 것이야. 두 확인 사이에 실시한 무전압 판정의 신뢰성을 확보하는 절차지.

### 문제 3 정답

즉시 작업을 중지하고 작업자를 위험구역에서 철수시켜 → 작업책임자에게 잠금 훼손 사실을 보고하고 에너지 격리 상태를 재확인한 뒤 → 잠금·표지와 필요한 안전조치를 복구하고 재개 승인을 받은 후 작업을 다시 시작해야 해.

### 문제 4 정답

예를 들면 절연장갑은 전기적 접촉 위험을 줄이고, 검전기는 작업점의 무전압을 확인하며, 단락접지기구는 오통전·유도전압에 대비하고, 절연용 방호구는 인접 충전부와의 우발적 접촉을 막아. 잠금장치, 절연매트, 보안면과 절연공구도 작업조건에 따라 선정할 수 있어.

### 문제 5 정답

설치할 때는 **접지측을 먼저 연결하고 전로측을 나중에 연결**해. 철거할 때는 반대로 **전로측을 먼저 분리하고 접지측을 나중에 분리**해야 해. 작업자가 접지되지 않은 전로와 접지기구 사이에 놓일 위험을 줄이기 위한 순서야.

## 10. 회상 요약

- 정전작업은 스위치를 끄는 행위가 아니라 **격리된 무전압 상태를 확인하고 유지하는 작업체계**야.
- 계획서에는 작업범위, 책임자, 모든 에너지원, 차단·검전·접지 순서, 보호구, 비상조치와 복구절차를 담아야 해.
- 표준 순서는 **차단 → 분리 → 잠금·표지 → 검전 → 방전 → 접지 → 작업 → 복구**야.
- 표시등 소등이나 설비 정지만으로 무전압을 판단하지 말고, 적합한 검전기로 작업점에서 확인해야 해.
- 보호구와 방호구는 전압등급·작업환경·손상 여부를 확인해 선정하며 정전절차를 대신하지 못해.
- 계획과 다른 상태, 전압 검출, 잠금 훼손 또는 장비 손상이 발견되면 즉시 작업을 중지해야 해.
- 중지한 작업은 위험요인 제거, 계획 보완, 안전조치 재확인과 책임자의 승인 후에만 재개해.

**한 문장으로 기억해 보자:** 끄는 것에서 끝내지 말고, 잠그고 표시하고 검전하여 무전압을 증명한 뒤 작업한다.
