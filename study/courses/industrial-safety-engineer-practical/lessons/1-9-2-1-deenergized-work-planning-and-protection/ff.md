## 1. 정전작업의 본질

정전작업은 단순히 스위치를 끄고 전기설비를 만지는 작업이 아니야. 작업 대상 전로를 모든 전원으로부터 분리하고, 다른 사람이 임의로 다시 투입하지 못하도록 통제한 다음, 검전으로 무전압을 확인하고 필요한 방전·접지 조치를 거쳐 작업하는 체계적인 과정이야.

여기서 가장 중요한 구분은 **전원 차단**과 **무전압 상태의 확보**야. 차단기를 내렸다는 사실은 조작 행위일 뿐이고, 작업 지점에 전압이 없다는 사실을 곧바로 증명하지는 못해. 예비전원, 비상발전기, 태양광 설비, 축전지, 제어회로, 변압기 역송전, 다른 회로와의 유도결합처럼 예상하지 못한 전원이 남아 있을 수 있기 때문이야.

따라서 정전작업의 안전 원리는 다음 흐름으로 이해하면 돼.

**계획 → 식별 → 차단 → 격리 → 잠금·표시 → 무전압 확인 → 방전·접지 → 작업 → 인원·공구 확인 → 접지 해제 → 복전**

이 순서는 도미노를 역으로 세우는 것과 비슷해. 위험으로 이어질 수 있는 고리를 하나씩 끊고, 작업이 끝난 뒤에는 안전 확인을 거쳐 반대 순서로 복구하는 거야.

### 핵심 경계

| 구분 | 의미 | 안전상 판단 |
|---|---|---|
| 정지 | 기계의 운전만 멈춘 상태 | 전기적 에너지가 남을 수 있어 |
| 차단 | 차단기나 개폐기를 조작한 상태 | 오조작·역송전 가능성이 있어 |
| 격리 | 전원과 작업 설비 사이를 확실히 분리한 상태 | 잠금과 표시가 추가로 필요해 |
| 무전압 확인 | 검전기로 작업 지점의 전압 부재를 확인한 상태 | 검전기의 정상 여부도 확인해야 해 |
| 안전한 정전상태 | 격리, 잠금·표시, 검전, 방전·접지까지 필요한 조치를 완료한 상태 | 작업 개시 판단의 기준이 돼 |

**시험 함정:** “차단기를 내렸으므로 즉시 작업한다”는 표현은 안전한 절차가 아니야. 차단 뒤에는 임의 투입 방지, 검전, 잔류전하 제거와 필요한 접지가 이어져야 해.

## 2. 안전한 정전작업 수행을 위한 안전작업계획서를 수립할 수 있다.

### 2-1. 작업계획서의 목적과 구성

안전작업계획서는 사고가 난 뒤 책임을 찾는 문서가 아니야. 작업 전에 전원 경로와 위험요인을 찾아내고, 누가 어떤 순서와 권한으로 위험을 통제할지 합의하는 실행 문서야.

계획서에는 적어도 다음 사항이 구체적으로 들어가야 해.

1. 작업명, 작업 목적, 작업 장소와 예정 시간
2. 작업 대상 설비의 명칭, 관리번호와 정확한 위치
3. 단선결선도와 전원 계통
4. 주전원, 보조전원, 비상전원과 역송전 가능성
5. 작업책임자, 전기취급 작업자, 감시인과 연락 담당자
6. 정전 범위와 차단·격리 지점
7. 차단장치의 잠금 방법과 꼬리표 부착 방법
8. 검전 위치, 검전 방법과 검전기 선정
9. 잔류전하 방전 및 단락접지의 필요 여부와 설치 위치
10. 접근 금지구역, 방책과 감시 방법
11. 개인보호구, 방호구, 작업용 기구와 장치
12. 작업 순서, 작업중지 조건과 비상조치
13. 복전 전 확인 사항과 복전 승인권자
14. 관계 부서 통보, 의사소통 방법과 비상연락망
15. 작업 전 안전회의와 작업자 서명·확인 기록

“차단기 조작”처럼 추상적으로 적으면 실제 현장에서 혼동이 생겨. “배전반 A의 주차단기 QF-01을 개방하고 작업책임자가 개인 잠금장치를 설치한다”처럼 대상, 위치, 행위자와 조치를 명확하게 써야 해.

### 2-2. 위험성평가와 전원 계통 확인

계획을 세울 때에는 정상 전원만 보지 말고 **모든 에너지원**을 찾아야 해. 전기뿐 아니라 회전체의 관성, 스프링 압력, 공압, 유압, 중력, 축전기 전하와 고온부도 작업자를 다치게 할 수 있어.

특히 다음 전원은 누락하기 쉬워.

- 비상발전기와 무정전전원장치
- 태양광 발전설비와 축전지
- 제어전원과 계기용 변압기 회로
- 다른 변압기나 모선에서 들어오는 역송전
- 병렬회로와 연계된 설비
- 장거리 병행 전선에서 발생하는 유도전압
- 축전기에 저장된 잔류전하

도면과 현장이 다를 가능성도 확인해야 해. 단선결선도만 믿지 말고 설비 명판, 케이블 표찰, 차단기 번호와 실제 연결 상태를 대조해야 하지.

### 2-3. 정전·격리·확인 절차

#### ① 작업 범위 협의와 통보

정전으로 영향을 받는 생산부서, 설비 운영자와 관계 작업자에게 작업 범위와 시간을 알려야 해. 갑작스러운 정전으로 다른 위험이 생기지 않는지도 확인해.

#### ② 부하 정지

가능하면 정상적인 운전정지 절차로 부하를 먼저 멈춰. 부하가 걸린 상태에서 부적절한 개폐기를 조작하면 아크나 설비 손상이 발생할 수 있어.

#### ③ 모든 전원 차단과 격리

확인된 모든 전원을 차단하고, 필요한 경우 단로기 개방, 퓨즈 분리 또는 물리적 분리를 실시해. 조작 장치의 명칭과 실제 작업 대상을 다시 대조해야 해.

#### ④ 잠금장치와 꼬리표 설치

차단장치를 잠가 다른 사람이 임의로 투입하지 못하게 해야 해. 꼬리표에는 작업 중임을 알 수 있는 표시와 작업책임자, 연락처, 설치 시각 같은 식별 정보를 기록해.

여러 사람이 작업한다면 각 작업자가 자신의 잠금장치를 관리하는 방식이 안전해. 타인의 잠금장치를 임의로 제거해서는 안 되고, 부득이한 제거는 사전에 정한 엄격한 확인·승인 절차에 따라야 해.

#### ⑤ 무전압 확인

회로 정격과 사용 환경에 적합한 검전기를 사용해 작업 대상의 모든 필요한 도체 사이와 대지 사이를 확인해. 검전은 다음 순서로 기억하면 좋아.

**확실한 활선에서 검전기 정상 확인 → 작업 대상 검전 → 확실한 활선에서 다시 정상 확인**

이를 흔히 “활선–작업점–활선” 확인이라고 이해할 수 있어. 검전 전후로 검전기의 정상 작동을 확인하는 이유는 첫 번째 확인 뒤 검전기가 고장 날 가능성까지 통제하기 위해서야.

#### ⑥ 잔류전하 방전과 단락접지

축전기나 케이블에는 차단 뒤에도 전하가 남을 수 있으므로 충분히 방전해야 해. 역송전이나 유도전압 우려가 있는 곳에는 단락접지를 설치해 작업 지점의 전위를 안전하게 유지해야 하지.

접지기구를 설치할 때에는 일반적으로 접지측을 먼저 연결하고 전로측을 연결해. 제거할 때에는 반대로 전로측을 먼저 떼고 접지측을 나중에 제거해. 작업자는 해당 전압과 위험에 적합한 절연용 보호구와 절연용구를 사용해야 해.

#### ⑦ 작업구역 설정과 작업 개시 승인

방책과 표지를 설치하고, 필요한 감시인을 배치한 다음 작업책임자가 조치 완료 여부를 확인해. 작업자는 작업허가와 현장 상태가 일치하는지 확인한 뒤 작업을 시작해야 해.

### 2-4. 구체적인 예시

공장 배전반 내부의 차단기를 교체한다고 해보자. 계획서에는 배전반 명칭과 차단기 번호를 쓰고, 주전원뿐 아니라 비상발전기와 연계 회로도 확인해야 해. 생산설비를 정상 정지한 뒤 주전원을 차단하고 잠금장치와 꼬리표를 설치해.

그다음 정격에 적합한 검전기의 정상 작동을 확인하고, 각 상 사이와 각 상·대지 사이를 검전해. 축전기나 유도전압의 가능성을 검토하고 필요한 방전·접지를 마친 뒤 작업구역을 통제해. 작업 완료 후에는 인원, 공구, 덮개와 접지기구를 확인하고 작업책임자의 승인에 따라 복전하는 거야.

### 2-5. 비교와 시험 함정

| 불완전한 계획 | 안전한 계획 |
|---|---|
| “전원을 끈다” | 차단 대상과 위치, 조작자, 잠금 방법을 명시해 |
| “테스터로 확인한다” | 정격에 적합한 검전기와 검전 지점·순서를 명시해 |
| “작업 후 전원을 켠다” | 인원·공구·접지·덮개 확인과 복전 승인 절차를 명시해 |
| 주전원만 조사해 | 비상전원, 축전지와 역송전원까지 조사해 |
| 보호구를 일괄 지정해 | 전압, 아크 위험과 작업 자세에 맞게 선정해 |

**시험 함정:** 잠금장치와 꼬리표는 같은 기능이 아니야. 잠금장치는 실제 조작을 물리적으로 제한하고, 꼬리표는 위험과 작업 정보를 전달해. 꼬리표만 붙이고 잠글 수 있는 장치를 잠그지 않는 것은 충분한 통제가 아니야.

## 3. 정전작업 중 안전사고가 우려 시 작업중지를 결정할 수 있다.

### 3-1. 작업중지의 의미

작업중지는 실패가 아니라 위험이 사고로 변하기 전에 연결고리를 끊는 적극적인 안전조치야. 일정이 늦어진다는 이유로 이상 징후를 무시하면 작은 불확실성이 감전, 아크 화상, 화재 또는 설비 폭발로 커질 수 있어.

작업자는 사전에 정한 조건이 발생했거나 현재 상태가 계획서와 다르면 즉시 작업을 멈추고 안전한 위치로 물러나야 해. 작업책임자는 현장을 재평가하고, 위험 제거와 재승인 전에는 작업을 재개하지 않아야 하지.

### 3-2. 즉시 중지해야 하는 대표 조건

1. 작업 대상에서 전압이 검출된 경우
2. 검전기의 정상 여부를 확인할 수 없는 경우
3. 차단기, 잠금장치 또는 꼬리표가 훼손·변경된 경우
4. 도면과 실제 전원 계통이 일치하지 않는 경우
5. 알 수 없는 케이블이나 추가 전원이 발견된 경우
6. 접지기구가 이탈하거나 접속 상태가 불량한 경우
7. 아크, 불꽃, 연기, 이상음, 이상 냄새 또는 과열이 발생한 경우
8. 누전, 절연 파괴나 설비 손상이 의심되는 경우
9. 우천, 침수, 결로 또는 과도한 습기로 절연 성능이 우려되는 경우
10. 보호구나 절연용구가 손상되었거나 정격을 확인할 수 없는 경우
11. 방책이 무너지거나 관계없는 사람이 작업구역에 진입한 경우
12. 감시인 이탈 또는 작업자 간 통신 두절이 발생한 경우
13. 작업 범위나 방법이 승인된 계획에서 변경된 경우
14. 작업자가 피로, 현기증 또는 집중력 저하를 호소하는 경우
15. 복전 요청이 들어왔지만 작업자 철수 여부를 확인하지 못한 경우

### 3-3. 작업중지 후 조치 절차

**멈춤 → 접근 통제 → 보고 → 상태 보존 → 재평가 → 시정조치 → 재확인 → 재승인**

먼저 작업을 즉시 멈추고 위험부에서 안전거리를 확보해. 다른 사람이 접근하지 못하도록 통제한 뒤 작업책임자와 설비 운영자에게 이상 상태를 알려야 해.

그다음 임의로 장치를 조작하거나 잠금장치를 제거하지 말고 원인을 조사해. 전원 계통, 검전 결과, 접지 상태, 보호구와 환경 조건을 다시 확인하고 계획서의 위험성평가를 수정해야 해. 위험요인이 제거되었다는 사실을 확인하고 작업책임자가 재개를 승인한 뒤에만 작업을 다시 시작해.

### 3-4. 구체적인 예시

작업자가 차단과 잠금을 완료한 뒤 케이블 단자에서 전압을 검출했다고 해보자. 이때 “유도전압일 것”이라고 추측하며 계속 작업하면 안 돼. 즉시 작업을 중지하고 작업구역을 유지한 채 작업책임자에게 보고해야 해.

이후 비상발전기 연계, 다른 회로의 역송전, 오차단, 케이블 오식별과 유도전압 가능성을 조사해. 추가 전원을 격리하거나 필요한 단락접지를 하고, 검전기 정상 여부와 무전압 상태를 다시 확인한 다음 정식 재승인을 받아야 해.

### 3-5. 중지와 재개의 경계

| 상황 | 판단 |
|---|---|
| 작업자가 막연한 불안만 느껴 | 이유를 확인할 때까지 우선 멈추는 편이 안전해 |
| 공정 지연 압박이 있어 | 안전 확인보다 우선할 수 없어 |
| 감독자가 구두로 계속하라고 해 | 위험이 제거되지 않았다면 재개 근거가 될 수 없어 |
| 이상 원인을 찾았어 | 원인 발견만으로 부족하고 시정·재확인·승인이 필요해 |
| 보호구를 새것으로 교환했어 | 다른 위험요인까지 재평가한 후 재개해야 해 |

**시험 함정:** 작업중지 원인이 사라진 것처럼 보여도 작업자가 임의로 재개하면 안 돼. 위험요인 제거, 안전조치 재확인과 권한자의 재개 승인이 하나의 묶음이야.

## 4. 정전작업 수행 시 필요한 보호구와 방호구, 작업용 기구와 장치, 표지를 선정하고 사용할 수 있다.

### 4-1. 선정의 기본 원리

장비는 이름만 외우기보다 **위험과 기능을 대응**시켜야 해.

- 감전 위험에는 절연용 보호구와 절연용 방호구
- 아크 위험에는 아크 방호 성능을 고려한 안면·신체 보호구
- 추락 위험에는 안전대와 작업발판
- 오투입 위험에는 잠금장치와 꼬리표
- 잔류·유도전압 위험에는 검전기, 방전기구와 단락접지기구
- 제3자 접근 위험에는 방책, 감시와 출입금지 표지

보호구는 사람이 착용하는 마지막 방어선이고, 방호구는 충전부나 작업구역 같은 위험원과 사람 사이에 장벽을 만드는 수단이야. 둘은 경쟁 관계가 아니라 함께 사용하는 다중 방어층이야.

### 4-2. 개인보호구

| 보호구 | 주요 기능 | 선정·사용 시 확인 |
|---|---|---|
| 절연장갑 | 손을 통한 감전 방지 | 사용 전 균열·천공·오염 여부와 사용 전압 적합성을 확인해 |
| 절연화 | 발을 통한 전류 경로 억제 | 젖음, 밑창 손상과 오염 상태를 확인해 |
| 안전모 | 충격과 머리 부위 위험 방호 | 전기작업에 적합한 성능과 턱끈 상태를 확인해 |
| 보안경 | 비산물로부터 눈 보호 | 렌즈 손상과 시야 확보 상태를 확인해 |
| 안면보호구 | 아크와 비산물로부터 얼굴 보호 | 예상 아크 위험에 적합한 방호 성능을 선정해 |
| 난연·아크 방호복 | 열과 아크에너지로 인한 화상 저감 | 노출 위험 수준에 맞는 성능과 착용 상태를 확인해 |
| 안전대 | 고소작업 중 추락 방지 | 부착설비, 죔줄, 훅과 마모 상태를 확인해 |

절연장갑의 표면이 멀쩡해 보여도 미세한 구멍이 있을 수 있어. 사용 전 육안과 공기 누설 상태를 확인하고, 젖거나 오염된 제품은 사용하지 않아야 해. 금속 장신구는 감전과 아크 화상의 피해를 키울 수 있으므로 제거해야 하지.

### 4-3. 절연용 방호구와 작업구역 방호

- 절연덮개와 절연시트
- 절연방호관
- 절연매트와 절연발판
- 방책, 차단봉과 안전 로프
- 충전부 접근 방지 덮개
- 임시 울타리와 출입 통제 설비

정전된 작업 대상 주변에 다른 충전부가 남아 있다면 거리 확보만 믿지 말고 필요한 방호구를 설치해야 해. 방호구는 사용 전 손상, 오염, 습기와 정격 적합성을 확인하고, 움직이거나 벗겨지지 않도록 안정적으로 설치해야 해.

### 4-4. 작업용 기구와 안전장치

| 기구·장치 | 기능 | 핵심 사용 원칙 |
|---|---|---|
| 검전기 | 전압 존재 여부 확인 | 회로 전압에 적합한 기종을 사용하고 검전 전후 정상 작동을 확인해 |
| 절연공구 | 작업자와 도전부 사이 절연 보조 | 손상된 피복이나 허용 범위를 넘는 제품을 사용하지 않아 |
| 방전기구 | 축전된 전하 제거 | 설비 특성과 작업절차에 맞게 사용해 |
| 단락접지기구 | 역송전·유도전압 등에 대비해 전위를 안전하게 유지 | 용량·설치 위치를 검토하고 접지측부터 설치해 |
| 잠금장치 | 차단장치의 임의 투입 방지 | 작업자별 관리 원칙과 제거 절차를 지켜 |
| 꼬리표 | 작업 상태와 금지 사항 전달 | 식별 정보가 지워지지 않도록 명확히 표시해 |
| 절연봉 | 안전거리를 유지하며 조작 | 사용 전압과 사용 목적에 맞는지 확인해 |
| 휴대용 조명 | 어두운 작업장의 시야 확보 | 환경에 적합한 안전한 전원과 구조를 사용해 |
| 절연 사다리 | 전도 위험을 줄이며 접근 | 파손과 오염을 확인하고 안정된 바닥에 설치해 |
| 토크 공구 | 정해진 체결력으로 접속 | 교정 상태와 제조자 기준을 확인해 |

**중요:** 검전기는 일반 측정기와 같은 개념으로 대충 선택하면 안 돼. 작업 전압, 교류·직류 여부, 사용 장소와 기기의 사용 범위를 확인해야 해.

### 4-5. 표지 선정과 설치

대표적인 표지는 다음 목적에 따라 선정해.

1. **조작금지:** 차단기나 개폐기의 임의 투입을 막아.
2. **작업 중:** 현재 작업자가 설비에서 작업하고 있음을 알려.
3. **고압 위험·감전 위험:** 전기적 위험을 경고해.
4. **출입금지·접근금지:** 관계자 외 출입을 통제해.
5. **접지 중:** 임시 접지 상태를 알려 복전 오류를 막아.
6. **보호구 착용:** 해당 구역에서 요구되는 보호구를 알려.

표지는 잘 보이는 위치에 견고하게 부착하고, 실제 작업 상태와 정확히 일치해야 해. 오래된 표지나 다른 작업의 꼬리표가 남아 있으면 잘못된 판단을 유발하므로 작업 완료 뒤 승인된 절차에 따라 회수해야 해.

### 4-6. 구체적인 선정 사례

저압 배전반 내부 부품을 정전 교체하지만 옆 구획이 충전 상태라고 해보자. 작업자는 절연장갑, 안전모, 보안경과 위험성평가에 따른 안면·신체 보호구를 갖춰야 해. 인접 충전부에는 적합한 절연덮개를 설치하고 작업구역에는 방책과 접근금지 표지를 둬.

전원 차단부에는 잠금장치와 조작금지 꼬리표를 설치해. 작업 지점에서는 정격에 적합한 검전기를 검전 전후로 확인하고, 회로 특성에 따라 방전과 단락접지 여부를 판단해야 해. 이처럼 장비 선정은 “정전작업용 세트”를 기계적으로 꺼내는 것이 아니라 현장의 잔존 위험에 맞춰 구성하는 일이야.

### 4-7. 비교와 시험 함정

| 자주 하는 오판 | 올바른 판단 |
|---|---|
| 정전했으니 절연보호구가 필요 없어 | 오차단·역송전·인접 충전부 위험을 고려해야 해 |
| 고무장갑이면 모두 절연장갑이야 | 사용 전압과 성능이 확인된 절연장갑이어야 해 |
| 꼬리표만 붙이면 재투입을 막을 수 있어 | 가능한 경우 물리적 잠금이 필요해 |
| 검전기는 한 번만 시험하면 돼 | 검전 전후 정상 작동을 확인해야 해 |
| 접지는 아무 순서로 연결해도 돼 | 설치는 접지측부터, 제거는 전로측부터가 원칙이야 |
| 보호구만 착용하면 안전해 | 전원 격리와 공학적·관리적 통제가 우선이야 |

## 5. 작업 완료와 안전한 복전

복전은 단순히 차단기를 올리는 행위가 아니야. 작업 중 구축했던 안전장벽을 통제된 순서로 해제하고 설비를 정상 상태로 돌리는 별도의 위험 작업이야.

다음 순서로 확인해.

1. 작업이 계획된 범위대로 완료되었는지 확인해.
2. 모든 작업자가 위험구역에서 철수했는지 인원별로 확인해.
3. 공구, 부품, 전선 조각과 임시 자재가 남지 않았는지 점검해.
4. 덮개, 울타리와 안전장치를 원상 복구해.
5. 작업책임자의 지시에 따라 단락접지기구를 안전하게 제거해.
6. 각 작업자가 관리하는 잠금장치와 꼬리표를 승인된 절차로 제거해.
7. 관계 부서와 영향을 받는 작업자에게 복전 예정 사실을 통보해.
8. 복전 승인권자의 허가를 받아 정해진 순서로 전원을 투입해.
9. 이상음, 냄새, 진동, 과열과 계기 지시를 확인해.
10. 작업 결과와 이상 유무를 기록해.

여기서 **접지기구 제거와 인원 철수 확인의 누락**은 매우 위험한 시험 포인트야. 잠금장치를 제거했다는 이유만으로 복전 준비가 끝난 것이 아니야.

## 6. 통합 현장 시나리오

모터 제어반의 접촉기를 교체하는 작업을 생각해보자.

작업책임자는 도면과 현장을 대조해 주전원, 제어전원과 비상전원을 확인해. 생산 담당자에게 정전 범위를 알리고 모터를 정상 정지한 다음 모든 관련 전원을 차단해. 각 차단장치에는 잠금장치와 조작금지 꼬리표를 설치하지.

작업자는 검전기의 정상 작동을 먼저 확인하고, 작업 대상의 상간·대지간 전압을 검사한 뒤 다시 검전기의 정상 여부를 확인해. 인접 구획에 충전부가 있다면 절연덮개와 방책을 설치하고, 선정된 보호구를 착용한 상태에서 작업을 시작해.

작업 중 도면에 없는 제어선에서 전압이 검출되면 즉시 중지해야 해. 작업책임자가 별도 제어변압기의 역송전 경로를 찾아 추가 격리하고, 잠금·표시와 검전을 다시 완료해. 위험성평가와 계획서를 갱신하고 재승인을 받은 뒤 작업을 이어가야 하지.

교체가 끝나면 작업자와 공구를 확인하고 덮개를 복구해. 접지기구와 잠금장치는 책임과 절차에 따라 제거하고 관계자에게 복전을 통보해. 승인 후 전원을 투입하고 모터의 회전, 전류와 이상 상태를 확인하면 작업이 종료돼.

이 사례의 핵심은 **처음 세운 계획보다 실제 현장 상태가 우선**이라는 점이야. 계획과 현장이 다르면 현장을 계획에 억지로 맞추는 게 아니라 작업을 멈추고 계획을 수정해야 해.

## 정답 및 해설

### 문제 1 정답

차단·격리 상태 확인 → 임의 투입 방지를 위한 잠금장치와 꼬리표 설치 → 검전기 정상 확인 → 작업 지점 무전압 확인 → 검전기 재확인 → 필요한 잔류전하 방전과 단락접지 → 작업구역 통제와 작업 개시 승인 순서로 답하면 돼.

**해설:** 차단은 안전한 정전상태의 일부일 뿐이야. 오투입, 역송전과 잔류전하 위험을 추가로 제거해야 해.

### 문제 2 정답

확실한 활선에서 검전기 정상 작동 확인 → 작업 대상 검전 → 확실한 활선에서 검전기 정상 작동 재확인이야.

**해설:** 작업 대상에서 무반응이 나와도 검전기가 고장 난 것인지 실제 무전압인지 구분해야 해.

### 문제 3 정답

즉시 작업중지 → 안전거리 확보와 접근 통제 → 작업책임자 보고 → 전원 계통과 역송전 원인 조사 → 추가 차단·격리·잠금·표시 → 검전과 필요한 접지 재실시 → 위험성평가·계획 수정 → 재확인과 재개 승인 순서야.

**해설:** 전압의 원인을 추정한 채 작업을 계속해서는 안 돼. 위험 제거와 공식적인 재승인까지 끝나야 해.

### 문제 4 정답

설치할 때에는 **접지측을 먼저 연결하고 전로측을 연결**해. 제거할 때에는 **전로측을 먼저 분리하고 접지측을 나중에 분리**해.

**해설:** 접지 연결이 없는 상태에서 전로측을 먼저 다루는 위험을 피하기 위한 순서야.

### 문제 5 정답

잠금장치는 차단장치의 임의 조작을 물리적으로 제한하고, 꼬리표는 작업 중이라는 사실과 작업자·금지 사항을 전달해.

**해설:** 정보 전달과 물리적 억제는 서로 다른 기능이므로 가능한 경우 함께 적용해야 해.

### 문제 6 정답 예시

작업 대상과 장소, 전원 계통, 정전 범위, 차단·격리 지점, 잠금·표시 방법, 검전 방법, 방전·접지 방법, 작업책임자와 역할, 보호구·방호구, 작업 순서, 작업중지 조건, 비상조치, 복전 절차와 연락 방법을 포함하면 돼.

## 요약

1. 정전작업은 단순한 전원 차단이 아니라 **모든 전원의 격리와 안전상태 확인**을 포함해.
2. 작업계획서는 전원 계통, 역할, 차단점, 잠금·표시, 검전, 방전·접지, 보호구, 중지 조건과 복전 절차를 구체적으로 정해야 해.
3. 차단장치를 조작한 뒤에는 **잠금·꼬리표 → 검전 → 방전·접지**의 안전 고리를 완성해야 해.
4. 검전기는 회로에 적합한 제품을 사용하고 **활선–작업점–활선** 순서로 정상 작동을 확인해.
5. 전압 검출, 계통 불일치, 보호구 손상, 접지 이탈, 통신 두절이나 환경 악화가 발생하면 즉시 작업을 중지해.
6. 작업 재개는 위험요인 제거, 안전조치 재확인과 권한자의 승인 뒤에만 가능해.
7. 보호구는 작업자를 보호하고, 방호구는 위험원과 작업자를 분리하며, 잠금장치와 표지는 오조작과 접근을 통제해.
8. 접지기구는 설치할 때 접지측부터, 제거할 때 전로측부터 처리해.
9. 복전 전에는 작업자, 공구, 접지기구, 덮개와 잠금 상태를 모두 확인해야 해.
10. 시험에서는 **차단과 무전압의 차이**, **잠금과 꼬리표의 차이**, **검전 전후 확인**, **작업중지 후 재승인**을 분명히 구별하면 돼.

흥. 정전은 “전기가 없을 것”을 믿는 작업이 아니야. **전기가 없음을 확인하고, 다시 들어오지 못하게 통제하는 작업**이라는 문장만 정확히 잡아도 핵심은 놓치지 않아 😎
