## 1. 프로그램학습법

### 정의

프로그램학습법은 학습 내용을 작은 단계로 세분화하고, 학습자가 각 단계에서 능동적으로 응답한 뒤 즉시 정답 여부를 확인하면서 자기 속도에 맞게 진행하는 교육방법이야.

여기서 프로그램은 컴퓨터 프로그램만을 뜻하지 않아. 교재, 카드, 문제지, 교육기기처럼 학습 순서와 피드백이 체계적으로 설계된 모든 자료가 프로그램이 될 수 있어.

### 핵심 원리

| 원리 | 의미 | 기억할 표현 |
|---|---|---|
| 작은 단계의 원리 | 학습 내용을 짧고 쉬운 단계로 나눠 제시해 | 조금씩 전진 |
| 적극적 반응의 원리 | 학습자가 답을 쓰거나 선택하도록 해 | 수동적 관찰 금지 |
| 즉시 확인의 원리 | 응답 직후 정답과 오류를 확인해 | 즉시 피드백 |
| 자기 속도의 원리 | 학습자마다 자신의 속도로 진행해 | 개별 진도 |
| 학습자 검증의 원리 | 실제 학습자의 성취 결과로 프로그램을 수정해 | 학습자가 프로그램을 검증 |

프로그램학습은 징검다리를 하나씩 건너는 것과 비슷해. 한 번에 먼 곳으로 뛰게 하지 않고, 짧은 학습 단위인 프레임을 차례로 통과하게 만드는 방식이야.

### 기본 절차

1. 학습목표를 명확히 설정해.
2. 전체 내용을 작은 프레임으로 세분화해.
3. 각 프레임에 정보나 문제를 제시해.
4. 학습자가 능동적으로 응답해.
5. 응답 직후 결과를 확인하고 피드백을 받아.
6. 이해한 학습자는 다음 단계로 이동해.
7. 오류가 있는 학습자는 보충 설명이나 교정 경로를 거쳐.

### 대표 유형

**직선형 프로그램**은 모든 학습자가 같은 프레임을 일정한 순서로 따라가는 방식이야. 작은 단계와 반복을 강조하므로 기초 지식이나 표준작업 절차를 익히는 데 적합해.

**분지형 프로그램**은 학습자의 응답에 따라 다음 경로가 달라지는 방식이야. 정답자는 다음 내용으로 이동하고, 오답자는 오류를 교정하는 보충 프레임으로 이동할 수 있어.

### 구체적인 예시

신입 작업자에게 보호구 착용 순서를 교육한다고 생각해 보자.

먼저 안전모 상태 확인을 제시하고 학습자가 올바른 점검 항목을 선택하게 해. 정답이면 턱끈 조절 단계로 이동하고, 오답이면 균열과 충격 흔적을 다시 확인하도록 피드백을 제공해. 이후 안전화, 보안경, 방진마스크 순서로 작은 단계를 통과하게 만들 수 있어.

### 장점과 한계

| 구분 | 내용 |
|---|---|
| 장점 | 개인차를 반영하고 즉시 피드백을 제공할 수 있어 |
| 장점 | 학습자의 참여를 유도하고 학습 결과를 확인하기 쉬워 |
| 장점 | 표준화된 내용을 반복적으로 교육하기 좋아 |
| 한계 | 프로그램의 설계와 제작에 시간과 비용이 들어 |
| 한계 | 토론, 태도 변화, 복합적인 대인관계 훈련에는 제한이 있어 |
| 한계 | 지나치게 세분화하면 전체 구조를 놓칠 수 있어 |

### 비교와 경계

강의법은 교사가 다수의 학습자에게 내용을 전달하는 데 효율적이지만 학습자의 개별 속도를 충분히 반영하기 어려워. 반면 프로그램학습법은 학습자의 개별 응답과 자기 속도를 중시해.

시청각교육법은 영상과 음향을 이용해 이해와 기억을 돕지만, 매체를 보여 주는 것만으로 적극적 반응이나 즉시 피드백이 자동으로 보장되지는 않아.

### 시험 함정

**즉시 확인**을 단순한 시험 종료 후 채점으로 보면 안 돼. 핵심은 각 응답에 가까운 시점에서 바로 피드백을 주는 거야.

**자기 속도**는 학습자가 아무 목표 없이 마음대로 공부한다는 뜻이 아니야. 설계된 학습 순서는 유지하되 진행 속도를 개인에게 맞춘다는 뜻이야.

학습자의 행동을 실제 위험 상황과 비슷하게 재현한다면 프로그램학습법보다 모의법에 가까워.

## 2. 모의법

### 정의

모의법은 실제 작업이나 위험 상황을 그대로 경험하기 어렵거나 위험할 때, 그 상황의 핵심 조건을 모형·장치·가상환경·가상 시나리오로 재현하여 판단과 행동을 연습시키는 교육방법이야.

영어의 시뮬레이션과 연결하면 기억하기 쉬워. 실제 상황의 중요한 요소를 안전하게 모사하고, 학습자가 그 안에서 행동하게 만드는 방식이야.

### 핵심 원리

모의법의 중심은 **실제성**, **행동 연습**, **안전한 실패**, **결과 피드백**, **반복 훈련**이야.

단순히 사고 영상을 보는 것은 관찰 중심의 시청각교육이지만, 학습자가 가상의 사고 상황에서 경보를 판단하고 설비를 정지하며 대피 경로를 선택한다면 모의법이 돼.

### 기본 절차

1. 실제 직무에서 요구되는 행동과 판단을 분석해.
2. 교육목표에 필요한 상황과 조건을 선정해.
3. 모형, 훈련장, 가상현실 또는 시나리오로 상황을 재현해.
4. 학습자에게 역할과 조건을 부여해.
5. 학습자가 판단하고 행동하도록 해.
6. 수행 결과와 오류를 관찰하고 기록해.
7. 피드백을 제공한 뒤 동일하거나 변형된 상황을 반복해.

### 구체적인 예시

화학설비에서 유해가스 누출 경보가 발생한 상황을 모의한다고 해 보자. 학습자는 보호구를 선택하고, 풍향을 확인하며, 비상정지 절차를 수행하고, 지정된 경로로 대피해야 해.

실제 유해가스를 방출하지 않더라도 경보음, 설비 배치, 제한시간, 의사소통 조건을 재현하면 현장 대응능력을 훈련할 수 있어. 수행 후 보호구 선택 오류나 대피 방향의 문제를 즉시 교정할 수도 있지.

### 장점과 한계

| 구분 | 내용 |
|---|---|
| 장점 | 실제 사고를 일으키지 않고 위험 대응을 연습할 수 있어 |
| 장점 | 지식뿐 아니라 판단력, 숙련도, 협동능력을 함께 평가할 수 있어 |
| 장점 | 드물지만 피해가 큰 비상상황을 반복 훈련할 수 있어 |
| 한계 | 고성능 장비와 훈련환경 구축에 비용이 들 수 있어 |
| 한계 | 모의환경의 실제성이 낮으면 현장 전이가 제한될 수 있어 |
| 한계 | 학습자가 훈련임을 의식하면 실제 상황과 다르게 행동할 수 있어 |

### 비교와 경계

**실연법**에서는 숙련자가 실제 작업방법을 보여 주고 학습자가 이를 관찰하거나 따라 해. 교육의 중심은 올바른 작업동작의 시범이야.

**모의법**에서는 특정 상황과 조건을 재현하고 학습자가 그 안에서 판단하고 행동해. 교육의 중심은 상황 대응이야.

**역할연기법**은 사람 사이의 관계, 의사소통, 태도와 역할을 연기하는 데 초점을 두어. 역할연기가 모의상황 안에 포함될 수는 있지만 두 방법을 항상 같은 것으로 보면 안 돼.

**사례연구법**은 제시된 사례를 분석하고 해결책을 토의하는 데 중심이 있어. 실제처럼 행동하기보다 사고와 토론이 중심이라면 사례연구법에 가까워.

### 시험 함정

모의법은 반드시 거대한 기계식 시뮬레이터가 있어야 하는 방법이 아니야. 간단한 모형, 탁상훈련, 비상대응 시나리오도 핵심 조건을 재현하면 모의법이 될 수 있어.

현실을 완벽하게 복제해야 한다는 설명도 틀리기 쉬워. 교육목표에 필요한 핵심 조건을 충분히 재현하는 것이 중요해.

위험을 직접 체험하게 하는 것이 모의법의 목적은 아니야. 위험을 통제하면서 실제와 유사한 판단과 행동을 훈련하는 것이 목적이야.

## 3. 시청각교육법 등

### 정의

시청각교육법 등은 사진, 그림, 도표, 실물, 모형, 녹음, 방송, 동영상과 같은 교육매체를 활용해 학습 내용을 구체적으로 전달하는 방법을 말해.

시각과 청각을 함께 활용하면 말로만 설명하기 어려운 작업과정, 설비구조, 위험의 진행 순서를 더 선명하게 보여 줄 수 있어. 다만 화려한 영상 자체가 교육효과를 보장하는 것은 아니야. 매체는 목표와 내용에 맞게 선택해야 해.

### 매체의 구분

| 구분 | 주요 매체 | 적합한 내용 |
|---|---|---|
| 시각매체 | 사진, 그림, 도표, 포스터, 실물, 모형 | 구조, 형태, 위치, 비교 |
| 청각매체 | 녹음, 방송, 음성 안내 | 경보음 구별, 설명, 반복 청취 |
| 시청각매체 | 동영상, 애니메이션, 음향 포함 영상 | 작업 순서, 사고 과정, 복합 상황 |
| 상호작용 매체 | 컴퓨터 콘텐츠, 퀴즈, 가상현실 | 선택, 피드백, 반복 연습 |

### 교육매체 선정 원리

먼저 교육목표를 확인해야 해. 설비의 내부구조를 이해시키려면 단면도나 모형이 유리하고, 기계 끼임사고의 시간적 진행을 보여 주려면 동영상이나 애니메이션이 효과적이야.

학습자의 연령, 경험, 문해력도 고려해야 해. 초보자에게 지나치게 복잡한 도표를 제공하면 오히려 인지 부담이 커질 수 있어.

교육장소의 크기, 소음, 조도, 전원과 재생장비 같은 조건도 확인해야 해. 작은 글씨가 많은 슬라이드를 대형 강의실에서 보여 주는 것은 적절하지 않아.

매체를 사용한 뒤에는 질문, 토의, 실습 또는 확인 문제를 연결해야 해. 보는 것과 할 수 있는 것은 서로 다르기 때문이야.

### 구체적인 예시

프레스 작업의 끼임 위험을 교육한다고 생각해 보자.

먼저 사진으로 위험점을 표시하고, 애니메이션으로 슬라이드가 움직이는 과정과 손이 위험영역에 들어가는 순간을 보여 줄 수 있어. 이어서 실제 방호장치 모형으로 구조를 확인하고, 학습자에게 올바른 작업순서를 말하게 하면 관찰이 능동적 학습으로 이어져.

경보음 교육에서는 여러 경보음을 직접 들려주고 각각의 의미와 대응 행동을 연결할 수 있어. 이때 음원을 재생하는 것만으로 끝내지 말고, 학습자가 경보 종류를 구별하고 대응 절차를 선택하게 해야 해.

### 장점과 한계

| 구분 | 내용 |
|---|---|
| 장점 | 추상적인 내용을 구체화하고 주의를 집중시킬 수 있어 |
| 장점 | 공간적 구조와 시간적 과정을 효과적으로 전달할 수 있어 |
| 장점 | 다수의 학습자에게 동일한 자료를 반복 제시할 수 있어 |
| 한계 | 매체가 학습목표보다 앞서면 오락이나 수동적 관람이 될 수 있어 |
| 한계 | 장비 고장과 교육환경의 영향을 받을 수 있어 |
| 한계 | 실제 수행능력을 확인하려면 실습이나 평가를 추가해야 해 |

### 비교와 경계

프로그램학습법은 **작은 단계, 적극적 반응, 즉시 피드백, 자기 속도**가 중심이야.

모의법은 **실제와 유사한 상황, 판단과 행동, 안전한 반복 훈련**이 중심이야.

시청각교육법 등은 **매체를 통한 구체적 전달, 이해와 기억의 촉진**이 중심이야.

한 교육에서 세 방법을 결합할 수도 있어. 예를 들어 누출사고 영상을 본 뒤 단계별 컴퓨터 문제에 응답하고, 마지막으로 가상 누출상황에 대응한다면 시청각교육법, 프로그램학습법, 모의법이 순서대로 결합된 거야.

### 시험 함정

영상을 사용했다는 이유만으로 프로그램학습법이 되는 것은 아니야. 학습자가 단계별로 응답하고 즉시 피드백을 받는 구조가 있어야 프로그램학습의 성격이 생겨.

가상현실을 사용했다는 이유만으로 모두 모의법인 것도 아니야. 단순히 가상공간을 관람하면 시청각교육에 가까울 수 있고, 상황 속에서 판단하고 행동하면 모의법의 성격이 강해져.

교육매체는 교사를 무조건 대체하는 수단이 아니야. 매체 선택, 질문, 피드백, 실습 연결을 설계하는 교사의 역할은 여전히 중요해.

***

## 세 교육방법 한눈에 비교

| 교육방법 | 중심 원리 | 학습자의 핵심 행동 | 대표 단서 | 적합한 목표 |
|---|---|---|---|---|
| 프로그램학습법 | 단계화와 즉시 피드백 | 응답하고 결과 확인 | 프레임, 자기 속도, 분지 | 지식과 절차의 개별학습 |
| 모의법 | 상황의 안전한 재현 | 판단하고 실제처럼 행동 | 시뮬레이션, 비상상황 | 대응능력과 수행능력 |
| 시청각교육법 등 | 감각적·구체적 전달 | 보고 듣고 이해 | 영상, 사진, 도표, 음향 | 구조와 과정의 이해 |

> 문제를 풀 때는 **무엇을 사용했는가**보다 **학습자가 무엇을 했는가**를 먼저 봐. 응답과 즉시 확인이면 프로그램학습법, 재현된 상황에서 판단하고 행동하면 모의법, 매체를 보고 듣는 것이 중심이면 시청각교육법 등이야. 🤓

## 확인 문제

### 문제 1

학습 내용을 작은 단계로 나누고, 학습자가 각 단계에서 응답한 직후 결과를 확인하며 자신의 속도로 진행하는 방법은 무엇일까?

1. 강의법
2. 토의법
3. 프로그램학습법
4. 모의법

### 문제 2

프로그램학습법의 원리로 가장 거리가 먼 것은 무엇일까?

1. 작은 단계의 원리
2. 적극적 반응의 원리
3. 즉시 확인의 원리
4. 모든 학습자의 동일한 학습속도 원리

### 문제 3

실제 유해가스를 방출하지 않고 가상 누출경보와 대피상황을 재현하여 대응행동을 훈련했다. 가장 적절한 교육방법은 무엇일까?

1. 모의법
2. 강의법
3. 문답법
4. 사례연구법

### 문제 4

작업자가 사고 영상을 시청한 뒤 별도의 응답이나 실습 없이 사고 진행과정을 이해했다. 중심이 된 교육방법은 무엇일까?

1. 프로그램학습법
2. 모의법
3. 시청각교육법
4. 역할연기법

### 문제 5

다음 설명 중 옳은 것은 무엇일까?

1. 영상을 사용하면 언제나 프로그램학습법이다.
2. 모의법은 실제 위험을 직접 발생시켜야 한다.
3. 시청각교육법만으로 실제 수행능력이 항상 보장된다.
4. 여러 교육방법은 하나의 교육과정에서 결합될 수 있다.

### 문제 6

가상현실 속 화재현장에서 학습자가 소화기를 선택하고 대피경로를 결정했다. 이 사례를 모의법으로 판단하는 가장 중요한 근거는 무엇일까?

1. 화면의 색상이 선명하기 때문
2. 고가의 장비를 사용했기 때문
3. 재현된 상황에서 학습자가 판단하고 행동했기 때문
4. 교육자가 설명하지 않았기 때문

## 정답 및 해설

| 문제 | 정답 | 해설 |
|---|---:|---|
| 1 | 3 | 작은 단계, 적극적 응답, 즉시 확인, 자기 속도는 프로그램학습법의 대표 단서야. |
| 2 | 4 | 프로그램학습법은 모든 학습자의 속도를 통일하지 않고 개인별 자기 속도를 인정해. |
| 3 | 1 | 위험한 실제 상황을 안전한 조건으로 재현하고 대응행동을 연습했으므로 모의법이야. |
| 4 | 3 | 영상 매체를 이용한 관찰과 이해가 중심이므로 시청각교육법이야. |
| 5 | 4 | 영상, 단계별 문항, 모의훈련을 연계하는 것처럼 여러 방법을 결합할 수 있어. |
| 6 | 3 | 장비의 종류나 가격이 아니라 재현된 상황에서 판단과 행동을 수행했다는 점이 핵심이야. |

## 요약

1. **프로그램학습법**은 작은 단계, 적극적 반응, 즉시 확인, 자기 속도, 학습자 검증을 중심으로 해.

2. **모의법**은 실제로 시행하기 어렵거나 위험한 상황을 안전하게 재현하여 판단과 행동을 반복 훈련해.

3. **시청각교육법 등**은 사진, 도표, 실물, 음향, 동영상 같은 매체로 추상적인 내용을 구체화해.

4. 세 방법의 구별 기준은 장비의 외형이 아니라 학습활동의 중심이야. **응답과 피드백**, **상황 속 행동**, **보고 듣는 이해**를 각각 찾아내면 돼.

5. 시청각자료를 보고, 프로그램식 문항에 답하고, 모의상황에서 행동하는 방식처럼 여러 교육방법을 결합할 수 있어.
