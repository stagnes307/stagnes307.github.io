## 1. 인간-기계 시스템의 정의 및 유형

### 1.1 인간-기계 시스템의 정의

인간-기계 시스템은 인간과 기계가 일정한 환경 안에서 상호작용하여 공동의 목표를 달성하는 체계야. 여기서 기계는 단순한 장비뿐 아니라 공구, 차량, 생산설비, 컴퓨터, 제어장치와 같은 기술적 요소를 포함해.

인간이 기계를 사용하는 장면만으로는 충분하지 않아. 인간과 기계 사이에 정보의 전달과 제어의 순환이 형성되어야 하나의 시스템으로 볼 수 있어.

대표적인 작동 순서는 다음과 같아.

1. 기계의 표시장치가 인간에게 현재 상태를 알려줘.
2. 인간은 표시된 정보를 감각기관으로 받아들여.
3. 인간은 정보를 해석하고 필요한 행동을 판단해.
4. 인간이 조종장치를 움직여 기계에 명령을 전달해.
5. 기계가 명령에 따라 작업을 수행해.
6. 수행 결과가 다시 표시장치를 통해 인간에게 전달돼.

이처럼 출력 결과가 다시 입력 정보로 돌아오는 구조를 피드백이라고 해. 자동차 운전을 떠올리면 쉬워. 운전자는 속도계를 보고 속도를 판단한 뒤 가속페달이나 브레이크를 조작하고, 달라진 속도를 다시 속도계와 주변 풍경으로 확인하지. 인간과 기계가 공을 주고받는 것처럼 계속 정보를 교환하는 셈이야.

### 1.2 구성요소와 정보 흐름

| 구성요소 | 주요 기능 | 산업현장 예시 |
|---|---|---|
| 인간 | 감지, 판단, 기억, 의사결정, 조작 | 운전자, 크레인 운전원, 중앙제어실 작업자 |
| 표시장치 | 기계 상태를 인간에게 전달 | 계기판, 경보등, 압력계, 모니터 |
| 조종장치 | 인간의 명령을 기계에 전달 | 버튼, 레버, 페달, 핸들, 터치패널 |
| 기계 | 동력 변환, 계산, 반복 작업, 작업 수행 | 프레스, 굴착기, 산업용 로봇 |
| 작업환경 | 인간과 기계의 성능에 영향을 줌 | 조명, 소음, 진동, 온도, 작업공간 |
| 피드백 | 수행 결과를 다시 입력으로 환류 | 속도 표시, 완료 신호, 이상 경보 |

표시장치와 조종장치가 만나는 접점을 인간-기계 인터페이스라고 해. 인터페이스가 잘못 설계되면 작업자가 정확한 지식을 갖고 있어도 실수할 수 있어. 예를 들어 비상정지 버튼이 다른 버튼과 같은 색과 크기로 배치되면 긴급한 순간에 찾기 어려워져. 따라서 사고를 개인의 부주의로만 설명해서는 안 되고, 정보가 정확히 지각되고 올바른 행동으로 이어지도록 시스템이 설계되었는지도 살펴야 해.

### 1.3 인간과 기계의 기능 비교

| 비교 항목 | 인간에게 유리한 기능 | 기계에게 유리한 기능 |
|---|---|---|
| 정보 처리 | 불완전한 상황의 종합 판단, 맥락 이해 | 빠른 계산, 대량 자료의 정형 처리 |
| 감지 | 미묘한 패턴과 예상 밖의 변화 인식 | 설정된 범위의 정밀하고 지속적인 측정 |
| 작업 | 융통성 있는 대응, 새로운 문제 해결 | 반복 작업, 큰 힘, 고속 작업 |
| 학습 | 경험을 통한 전략 수정과 창의적 추론 | 프로그램과 학습 자료에 따른 일관된 처리 |
| 신뢰성 | 새로운 상황에 적응 가능 | 피로 없이 규정된 동작을 반복 |
| 취약점 | 피로, 주의 저하, 감정, 기억 한계 | 고장, 전원 상실, 미규정 상황 대응 한계 |

여기서 중요한 원칙은 인간과 기계 중 어느 쪽이 항상 우월한지를 판단하는 게 아니야. 과업의 성질에 맞게 기능을 배분해야 해. 이를 기능 할당이라고 해.

기계는 반복 계산이나 일정한 힘의 작업에 강하지만, 설계자가 예상하지 못한 상황에서는 융통성이 부족할 수 있어. 인간은 맥락을 해석하고 예외에 대응하는 능력이 뛰어나지만 피로와 주의 저하의 영향을 받아. 좋은 시스템은 양쪽의 강점을 결합하고 약점을 서로 보완하도록 설계돼.

## 2. 인간-기계 시스템의 유형

자동화 수준과 인간이 담당하는 기능을 기준으로 인간-기계 시스템은 일반적으로 수동 시스템, 기계화 시스템, 자동화 시스템으로 구분해.

### 2.1 수동 시스템

수동 시스템에서는 인간이 동력원이 되어 작업을 직접 수행하고, 도구나 기계는 인간의 힘과 기능을 보조해. 망치질, 삽질, 손톱을 이용한 절단처럼 사람이 감각과 판단뿐 아니라 물리적 에너지까지 제공하는 형태야.

수동 시스템의 기본 흐름은 인간의 감각과 판단, 근육 활동, 도구 작용, 작업 결과 확인으로 이어져. 구조가 단순하고 상황 변화에 유연하게 대응할 수 있지만 인간의 근력과 숙련도에 크게 의존해. 반복 작업에서는 피로와 근골격계 부담이 증가하고, 작업자별 성능 편차도 커질 수 있어.

구체적인 예로 작업자가 토크렌치를 사용해 볼트를 조이는 장면을 생각해 보자. 작업자는 볼트 위치를 확인하고 렌치를 잡아 힘을 가하며 설정 토크에 도달했는지를 감지해. 이때 공구는 인간의 힘을 전달하거나 증폭하지만 판단과 동력의 중심은 인간에게 있어.

수동 시스템을 단순히 전기가 없는 시스템이라고 판단하면 안 돼. 전동 표시장치가 일부 포함되어도 인간이 주된 동력을 공급하고 작업을 직접 수행한다면 수동적 성격이 강할 수 있어. 분류 기준은 전기의 존재가 아니라 인간과 기계 사이의 기능 및 동력 분담이야.

### 2.2 기계화 시스템

기계화 시스템에서는 기계가 주된 동력을 제공하고, 인간은 기계를 조종하고 제어해. 자동차, 굴착기, 선반, 지게차가 대표적인 예야.

운전자가 지게차를 운전하는 경우 엔진이나 전동기가 이동과 인양에 필요한 힘을 제공해. 운전자는 주변 상황과 계기판을 관찰하고, 핸들·페달·레버를 조작해 방향과 속도 및 포크 높이를 결정하지. 따라서 인간은 정보 처리와 의사결정을, 기계는 동력 제공과 물리적 작업을 주로 담당해.

기계화는 인간의 육체 부담을 줄이고 큰 힘을 사용할 수 있게 하지만 새로운 위험도 만들어. 기계의 출력과 속도가 커지면서 한 번의 오조작이 중대한 사고로 확대될 수 있기 때문이야. 표시장치가 복잡하거나 조종장치의 방향이 작업자의 기대와 반대라면 잘못된 조작이 발생할 가능성도 높아져.

시험에서는 기계화를 완전 자동화와 혼동하기 쉬워. 기계가 동력을 공급하더라도 인간이 계속 감시하고 직접 조종한다면 기계화 시스템이야. 자동차의 일반적인 수동 운전이 대표적인 판단 기준이야.

### 2.3 자동화 시스템

자동화 시스템에서는 기계가 감지, 정보 처리, 판단 또는 제어 기능의 상당 부분을 수행해. 인간은 시스템을 설계하거나 프로그램하고, 정상 작동을 감시하며, 이상 상황에 개입하는 역할을 맡아.

자동 생산라인에서는 센서가 제품의 위치와 상태를 측정하고, 제어기가 입력값을 처리해, 구동장치에 명령을 보내. 작업자는 제어실에서 운전 상태를 확인하고 경보가 발생하면 원인을 판단하여 개입해. 즉, 기계 내부에도 센서·제어기·작동기 사이의 폐회로가 형성될 수 있어.

자동화는 반복 작업의 일관성과 속도를 높이고 위험 구역에서 인간을 분리하는 데 유리해. 하지만 자동화 수준이 높다고 언제나 안전한 것은 아니야. 인간이 오랫동안 수동 조작을 하지 않으면 숙련이 저하될 수 있고, 정상 운전 중 주의가 떨어질 수도 있어. 자동화가 갑자기 해제되었을 때 인간이 상황을 제대로 파악하지 못하는 자동화 놀람도 발생할 수 있어.

예를 들어 자동 운전 중인 공정에서 압력 제어장치가 고장 났다고 해보자. 경보가 너무 많거나 현재 상태가 명확히 표시되지 않으면 작업자는 짧은 시간 안에 어떤 밸브를 조작해야 하는지 판단하기 어려워. 따라서 자동화 시스템은 인간을 제거하는 설계가 아니라 인간이 필요할 때 정확히 이해하고 개입할 수 있도록 만드는 설계여야 해.

### 2.4 세 유형의 핵심 비교

| 구분 | 주된 동력 제공 | 주된 제어·판단 | 대표 사례 | 핵심 위험 |
|---|---|---|---|---|
| 수동 시스템 | 인간 | 인간 | 망치, 삽, 수동 공구 | 피로, 근골격계 부담, 숙련도 편차 |
| 기계화 시스템 | 기계 | 인간 | 지게차, 굴착기, 일반 자동차 | 오조작, 과도한 출력, 표시·조종 부적합 |
| 자동화 시스템 | 기계 | 기계 중심, 인간 감시·개입 | 자동 생산라인, 자동 공정제어 | 감시 실패, 숙련 저하, 자동화 놀람 |

기억 고리는 간단해.

**수동은 사람이 힘도 내고 판단도 해. 기계화는 기계가 힘을 내고 사람이 조종해. 자동화는 기계가 힘뿐 아니라 제어 기능까지 상당 부분 담당해.**

다만 실제 산업현장의 설비는 세 유형이 완전히 분리되지 않을 수 있어. 정상 운전에서는 자동화 시스템으로 작동하다가 고장이나 정비 상황에서는 기계화 또는 수동 운전으로 전환될 수 있지. 그러므로 시스템의 명칭보다 해당 운전 단계에서 누가 감지하고, 누가 판단하며, 누가 동력을 제공하고, 누가 제어하는지를 확인해야 해.

## 3. 시스템의 특성

### 3.1 목표성

시스템은 일정한 목표를 달성하기 위해 존재해. 생산 시스템의 목표는 단순히 제품을 많이 만드는 데 그치지 않아. 품질, 생산량, 안전, 비용, 시간과 같은 복수의 목표를 함께 만족해야 해.

목표가 충돌할 수도 있어. 생산속도를 지나치게 높이면 작업자의 반응 시간이 부족해지고 사고 위험이 증가할 수 있지. 따라서 안전은 생산성과 분리된 부수 요소가 아니라 시스템의 성능을 구성하는 핵심 목표로 봐야 해.

### 3.2 구성요소의 상호관련성

시스템의 구성요소는 독립적으로 존재하지 않고 서로 영향을 줘. 작업자의 피로가 증가하면 판단 속도가 느려지고, 조종장치의 배치가 부적절하면 오조작 가능성이 커지며, 경보가 너무 자주 울리면 작업자가 중요한 경보까지 무시할 수 있어.

사고 원인을 특정 작업자 하나에서만 찾으면 상호관련성을 놓치게 돼. 작업자, 작업절차, 설비, 표시장치, 조직의 생산압력과 환경조건이 어떻게 연결되었는지를 함께 분석해야 해. 인간공학적 사고는 바로 이 연결 고리를 보는 데서 시작해.

### 3.3 통합성 또는 전체성

시스템 전체의 성능은 개별 구성요소의 성능을 단순히 더한 것과 같지 않아. 성능이 좋은 부품과 숙련된 작업자를 모아도 인터페이스가 나쁘거나 작업절차가 서로 충돌하면 전체 시스템의 성능은 낮아질 수 있어.

예를 들어 정밀도가 높은 압력계가 설치되어 있어도 작업자의 시야에서 벗어난 위치에 있다면 필요한 정보를 제공하지 못해. 반대로 개별 장치의 성능이 평범하더라도 정보 표시와 조작 흐름이 일관되고 오류 방지 장치가 적절하면 전체 시스템은 안정적으로 작동할 수 있어.

이것이 전체 최적화와 부분 최적화의 차이야. 한 구성요소만 최고 수준으로 만드는 부분 최적화가 전체 시스템의 최적화를 보장하지는 않아.

### 3.4 계층성

시스템은 더 작은 하위 시스템으로 구성되며, 동시에 더 큰 상위 시스템의 일부가 될 수 있어. 한 명의 작업자와 프레스는 하나의 인간-기계 시스템이지만, 이 체계는 생산라인의 하위 시스템이야. 생산라인은 다시 공장과 기업 운영체계의 일부가 되지.

계층성을 이해하면 사고의 원인을 여러 수준에서 찾을 수 있어. 프레스 사고는 작업자의 순간적 행동뿐 아니라 기계의 방호장치, 생산라인의 속도, 정비계획, 교육체계와 경영방침의 영향을 받을 수 있어. 하위 수준의 오류가 상위 시스템의 조건에서 만들어졌을 가능성을 검토해야 해.

### 3.5 경계성과 환경 의존성

시스템을 분석하려면 무엇을 시스템 내부로 보고 무엇을 외부 환경으로 볼지 경계를 정해야 해. 하지만 경계 밖의 요인도 시스템에 영향을 줘. 온도, 조명, 소음, 진동, 교대근무, 법규와 생산 일정이 대표적이야.

예를 들어 같은 기계라도 충분한 조명 아래에서는 안전하게 조작될 수 있지만, 눈부심이나 그림자가 심한 장소에서는 표시값을 잘못 읽을 수 있어. 시스템의 성능은 내부 구성만으로 결정되지 않고 환경과의 상호작용에 따라 달라져.

시험에서는 시스템이 환경과 완전히 분리된 폐쇄적 존재라고 단정하는 표현을 조심해야 해. 산업현장의 인간-기계 시스템은 일반적으로 환경과 정보와 에너지를 교환하는 개방적 성격을 가져.

### 3.6 입력·변환·출력

시스템은 입력을 받아 일정한 과정을 거쳐 출력으로 변환해.

**입력 → 처리 또는 변환 → 출력**

프레스 작업을 예로 들면 재료, 작업지시와 에너지가 입력되고, 프레스의 가공과 작업자의 조작이 변환 과정이 되며, 완성된 제품과 작업 결과가 출력이 돼. 소음, 열, 불량품과 위험상태도 의도하지 않은 출력으로 볼 수 있어.

출력은 목표한 결과만을 의미하지 않아. 사고, 오염, 피로와 같은 부정적인 결과까지 확인해야 시스템을 정확히 평가할 수 있어.

### 3.7 피드백과 제어

피드백은 시스템의 출력 결과를 다시 입력 측으로 보내 목표와 실제 결과의 차이를 수정하게 하는 과정이야.

설정 온도가 100도인데 실제 온도가 110도라면 제어장치는 그 차이를 감지해 열 공급을 줄여. 인간이 계기판을 보고 밸브를 조절하는 것도 피드백 제어이며, 자동제어기가 센서값에 따라 작동하는 것도 피드백 제어야.

목표값과 실제값의 차이는 오차로 볼 수 있어. 시스템은 이 오차를 줄이도록 작동해. 피드백이 늦거나 부정확하면 진동, 과잉 조작 또는 불안정한 제어가 발생할 수 있어.

### 3.8 동적 평형과 변화성

시스템은 고정된 상태로만 존재하지 않아. 시간의 흐름에 따라 작업자의 피로, 기계의 마모, 환경조건과 작업량이 변해. 따라서 시스템은 변화를 감지하고 조정하면서 목표 상태를 유지해야 해.

정상 운전 초기에 적절했던 작업속도도 야간 교대 후반에는 작업자의 피로 때문에 과도할 수 있어. 기계 부품의 마모가 누적되면 초기 설정값이 더 이상 정확하지 않을 수도 있고. 이런 변화를 무시하고 처음 설계된 조건만을 고집하면 시스템의 안전 여유가 줄어들어.

### 3.9 창발성

창발성은 개별 구성요소만 살펴봐서는 충분히 예측하기 어려운 성질이 구성요소의 상호작용에서 나타나는 현상이야.

각 장치가 정상이고 각 작업자도 규정을 지켰지만, 여러 경보가 동시에 발생하면서 정보량이 인간의 처리 능력을 초과하면 전체 시스템에서 새로운 위험이 나타날 수 있어. 반대로 작업자 간 의사소통과 적절한 피드백이 결합되어 개별 능력보다 높은 팀 성과가 나타날 수도 있어.

창발성은 사고를 단순한 부품 고장이나 개인 실수의 합으로만 설명해서는 안 된다는 점을 알려줘.

### 3.10 신뢰성과 안전성

신뢰성은 시스템이 주어진 조건에서 정해진 기간 동안 요구 기능을 수행할 가능성과 관련돼. 안전성은 시스템이 사람과 재산에 허용할 수 없는 피해를 일으키지 않도록 위험을 통제하는 성질이야.

두 개념은 관련되지만 동일하지 않아. 매우 신뢰성 있게 작동하는 절단기가 방호장치 없이 사람을 위험에 노출한다면 신뢰성은 높아도 안전성은 낮을 수 있어. 반대로 안전장치가 고장 때마다 설비를 정지시키면 안전 측면에서는 바람직할 수 있지만 가동 신뢰성에 대한 별도 검토가 필요해.

따라서 시험에서 신뢰성이 높으면 반드시 안전하다는 표현이 나오면 의심해야 해. 시스템은 기능 수행 능력과 위해 방지 능력을 함께 평가해야 해.

## 4. 비교와 경계 정리

### 인간-기계 시스템이 아닌 것처럼 보이지만 포함되는 사례

컴퓨터 프로그램을 감시하는 작업도 인간-기계 시스템이야. 작업자가 물리적 힘을 거의 사용하지 않더라도 화면에서 정보를 받고 판단하여 명령을 입력하기 때문이야.

자동화 공정도 인간이 완전히 사라진 시스템으로 보면 안 돼. 인간은 설계, 프로그래밍, 감시, 정비와 비상개입을 담당하므로 더 넓은 시스템 경계에서는 여전히 중요한 구성요소야.

### 기계화와 자동화의 경계

기계가 큰 힘을 낸다는 사실만으로 자동화가 되는 것은 아니야. 굴착기는 강력한 기계지만 운전자가 계속 레버를 조작하여 동작을 결정하면 기계화 시스템이야.

반대로 장치가 작아도 센서가 상태를 측정하고 제어기가 판단하여 스스로 출력을 조절한다면 자동화 요소를 가진다고 볼 수 있어.

### 개별 오류와 시스템 오류의 경계

작업자가 잘못된 버튼을 눌렀다면 인간 오류가 관찰된 것은 맞아. 그러나 같은 모양의 버튼들이 혼란스럽게 배치되어 있었거나 표시와 조종 방향이 불일치했다면 설계 오류도 함께 존재해.

인간공학에서는 마지막 행동만 보는 대신 그 행동이 발생하도록 만든 조건을 추적해야 해. 흥, 모든 사고를 작업자 부주의 한마디로 끝내면 시스템 분석이라고 할 수 없지 😎

## 5. 시험 함정

### 함정 1: 수동 시스템은 기계를 사용하지 않는다

틀린 설명이야. 수동 시스템도 공구나 기계를 사용할 수 있어. 다만 인간이 주된 동력을 제공하고 작업을 직접 제어해.

### 함정 2: 기계가 동력을 제공하면 자동화 시스템이다

틀렸어. 기계가 동력을 제공하더라도 인간이 계속 판단하고 조종하면 기계화 시스템이야.

### 함정 3: 자동화 수준이 높을수록 인간의 역할은 완전히 사라진다

틀린 설명이야. 인간의 역할이 직접 조작에서 감시, 계획, 정비와 비상개입으로 이동할 뿐이야.

### 함정 4: 개별 구성요소의 성능을 높이면 전체 시스템이 항상 최적화된다

틀렸어. 구성요소 간 인터페이스와 상호작용이 나쁘면 부분 최적화가 전체 성능을 오히려 떨어뜨릴 수 있어.

### 함정 5: 신뢰성이 높은 시스템은 반드시 안전하다

틀린 설명이야. 신뢰성은 요구 기능을 지속적으로 수행하는 성질이고, 안전성은 허용할 수 없는 피해를 방지하는 성질이야.

### 함정 6: 피드백은 자동화 시스템에만 존재한다

틀렸어. 작업자가 계기판을 보고 조종장치를 수정하는 과정도 피드백이야.

### 함정 7: 인간-기계 시스템의 출력은 완성된 제품만 의미한다

틀린 설명이야. 불량품, 소음, 열, 작업자 피로와 위험상태 같은 의도하지 않은 결과도 출력에 포함해 분석할 수 있어.

## 8. 요약

1. **인간-기계 시스템의 정의 및 유형**에서 핵심은 인간과 기계가 환경 속에서 정보와 에너지를 교환하며 공동 목표를 달성한다는 점이야.

2. 인간은 감지, 판단, 융통성 있는 대응에 강하고, 기계는 반복 작업, 큰 힘, 빠른 계산과 정밀 측정에 강해. 기능은 과업 특성에 맞게 할당해야 해.

3. 수동 시스템에서는 인간이 주된 동력을 제공하고, 기계화 시스템에서는 기계가 동력을 제공하면서 인간이 조종해. 자동화 시스템에서는 기계가 감지·판단·제어 기능까지 상당 부분 담당해.

4. **시스템의 특성**에는 목표성, 상호관련성, 전체성, 계층성, 경계성과 환경 의존성, 입력·변환·출력, 피드백, 동적 평형, 창발성, 신뢰성과 안전성이 포함돼.

5. 시스템 사고는 사고를 개인의 부주의 하나로 축소하지 않아. 인간, 기계, 인터페이스, 절차, 조직과 환경의 연결 구조를 함께 살펴봐.

6. 시험에서는 기계화와 자동화, 부분 최적화와 전체 최적화, 신뢰성과 안전성을 구별하는 문제가 특히 중요해.
