# 2-1-3-1. 요구에서 접점까지 잇는 체계설계

산업안전기사 필기  
목표 및 성능명세의 결정 · 기본설계 · 계면설계

체계설계는 장비의 모양부터 그리는 일이 아니야. 먼저 **무엇을 달성해야 하는지** 정하고, 그 목표를 **측정 가능한 성능**으로 바꾼 다음, 인간과 기계가 맡을 기능을 배분하고, 마지막으로 둘이 만나는 접점을 구체화하는 과정이야.

이번 학습의 흐름은 다음과 같아.

**요구 확인 → 목표 설정 → 성능명세 작성 → 기능 배분 → 기본 구조 결정 → 인간·기계 계면 구체화 → 시험과 수정**

***

## 1. 세 단계가 하나의 설계 사슬을 이루는 이유

### 목표 및 성능명세의 결정

체계가 달성해야 할 목적을 정하고, 그 목적이 달성되었는지 판단할 수 있도록 **성능 수준과 조건을 수치 또는 관찰 가능한 기준으로 표현하는 단계**야. 목표가 방향이라면 성능명세는 그 방향에 도달했는지 확인하는 눈금이라고 보면 돼.

예를 들어 “작업자가 위험을 빨리 알아차리게 한다”는 문장은 목표에 가까워. 이를 “위험 발생 후 2초 이내에 경보가 제시되고, 정상 시력을 가진 작업자의 95% 이상이 식별할 수 있어야 한다”라고 쓰면 시험 가능한 성능명세가 돼.

### 기본설계

성능명세를 만족하도록 체계의 전체 구조와 기능 배분을 정하는 단계야. 어떤 기능을 사람에게 맡길지, 어떤 기능을 기계에 맡길지, 표시장치·조종장치·경보장치가 어떤 관계로 작동할지를 큰 틀에서 결정해.

이 단계에서는 세부 버튼의 색을 정하기보다 **기능 구조, 작업 흐름, 인간과 기계의 역할, 주요 하위체계의 연결 관계**를 먼저 확정해. 건물을 짓기 전에 방의 배치와 동선을 정하는 것과 비슷해.

### 계면설계

사람과 기계, 하위체계와 하위체계가 실제로 정보를 주고받거나 작용을 전달하는 접점을 설계하는 단계야. 표시장치, 조종장치, 경보, 작업공간, 절차서, 소프트웨어 화면이 대표적인 인간–기계 계면이야.

계면은 체계의 내부 성능을 작업자의 실제 행동으로 바꾸는 번역기야. 기계가 정확한 정보를 만들더라도 표시가 알아보기 어렵거나 조작 방향이 직관과 반대라면 전체 체계는 안전하게 작동하지 못해.

***

## 2. 목표를 시험 가능한 성능명세로 바꾸기

좋은 목표는 체계가 존재하는 이유를 분명하게 나타내야 해. 하지만 “안전하게”, “신속하게”, “편리하게”처럼 추상적인 표현만으로는 설계 결과를 평가하기 어려워. 그래서 목표를 다음 요소로 분해해야 해.

1. **대상:** 누가 또는 무엇이 수행하는가  
2. **행동:** 어떤 기능을 수행해야 하는가  
3. **조건:** 어떤 환경과 운전 상태에서 수행하는가  
4. **기준:** 어느 정도의 정확도·속도·신뢰도를 요구하는가  
5. **제약:** 시간, 비용, 공간, 법규, 인간 능력의 한계는 무엇인가

예를 들어 “비상정지를 쉽게 한다”는 목표를 성능명세로 바꿔보자.

“보호장갑을 착용한 작업자가 정상 작업 위치에서 비상정지 조작부를 식별하고 1초 이내에 작동시킬 수 있어야 하며, 작동 후 설비의 위험 운동은 허용 정지시간 이내에 종료되어야 한다.”

이 문장에는 사용자, 작업 조건, 조작 행동, 시간 기준, 설비 반응이 함께 들어 있어. 이처럼 성능명세는 **구체성, 측정 가능성, 시험 가능성, 현실성, 일관성**을 갖춰야 해.

특히 시험에서 기억할 점은 목표와 수단을 혼동하지 않는 거야. “적색 램프를 설치한다”는 것은 해결 수단이지 목표가 아니야. 목표는 “위험 상태를 작업자가 빠르고 정확하게 식별하도록 한다”이고, 적색 램프는 그 목표를 달성하기 위한 여러 대안 중 하나야.

## 3. 성능명세에 인간요소를 넣는 방법

체계의 성능을 기계의 출력만으로 정의하면 현장에서 실패하기 쉬워. 실제 산업 체계에서는 작업자의 탐지, 판단, 조작, 기억, 의사소통이 전체 성능을 구성하기 때문이야.

인간요소 성능명세에는 다음과 같은 변수를 고려해.

- **탐지성:** 신호의 존재를 알아차릴 수 있는가  
- **식별성:** 여러 신호 가운데 의미를 구별할 수 있는가  
- **양립성:** 표시와 조작 결과가 인간의 기대와 일치하는가  
- **반응시간:** 위험을 인지하고 조작하는 데 얼마나 걸리는가  
- **오류율:** 잘못 읽거나 잘못 조작할 가능성이 어느 정도인가  
- **작업부하:** 주의·기억·판단 요구가 지나치게 크지 않은가  
- **신체 적합성:** 도달범위, 힘, 자세, 시야가 사용자 특성에 맞는가  
- **환경 내성:** 소음, 진동, 조도, 온도 속에서도 성능이 유지되는가

예를 들어 소음이 큰 공장에서 청각경보만 사용하면 기계 자체는 정상 작동해도 작업자는 신호를 놓칠 수 있어. 따라서 “경보음은 배경소음과 구별되어야 한다”는 조건과 함께 시각경보 또는 진동경보를 병행하도록 정할 수 있어.

여기서 중요한 원리는 **평균적인 작업자만 기준으로 설계하지 않는 것**이야. 체격, 경험, 연령, 보호구 착용 상태, 피로 수준이 다른 사용자도 고려해야 해. 인간의 한계를 작업자 개인의 부주의로 돌리기 전에 체계가 그 한계를 흡수하도록 설계하는 게 인간공학적 접근이야.

## 4. 기본설계의 핵심인 기능 분석과 기능 배분

기본설계에서는 먼저 체계가 수행해야 할 상위 기능을 하위 기능으로 나눠. 이를 **기능 분석**이라고 해. 예를 들어 화학설비의 안전운전은 다음과 같이 분해할 수 있어.

**상태 감시 → 이상 탐지 → 위험도 판단 → 경보 제시 → 대응 선택 → 조작 실행 → 결과 확인**

기능을 나눈 뒤에는 각 기능을 인간, 기계 또는 인간–기계 협동 중 어디에 맡길지 결정해야 해. 이것이 **기능 배분**이야.

기계는 반복 계산, 고속 처리, 정밀 측정, 지속 감시, 큰 힘을 요구하는 작업에 강해. 인간은 불완전한 정보의 해석, 새로운 상황에서의 판단, 유연한 문제 해결, 가치가 충돌하는 상황의 선택에 상대적으로 강해.

그러나 “기계가 빠르니 모두 자동화한다”는 결론은 위험해. 자동화 수준이 높아질수록 작업자는 정상 운전에서 수동적으로 변하고, 드문 비상상황에서 갑자기 복잡한 판단을 요구받을 수 있어. 이를 **자동화의 역설**이라고 이해할 수 있어.

따라서 기능 배분은 능력 비교만으로 끝나지 않아. 고장 시 대체 가능성, 작업자의 상황인식, 교육 수준, 유지보수성, 책임 소재, 자동화 실패의 결과까지 함께 검토해야 해.

좋은 기본설계는 인간을 체계 밖의 감시자로 밀어내지 않고, 자동화가 무엇을 하고 있는지 이해하며 필요할 때 안전하게 개입할 수 있게 만들어.

## 5. 기본설계에서 계면설계로 구체화되는 과정

기본설계와 계면설계는 서로 분리된 절차가 아니라 확대 수준이 다른 설계야.

| 구분 | 기본설계가 답하는 질문 | 계면설계가 답하는 질문 |
|---|---|---|
| 설계 초점 | 체계가 어떤 구조로 작동하는가 | 사용자가 체계와 어떻게 상호작용하는가 |
| 주요 결정 | 기능 분해, 역할 배분, 정보 흐름 | 표시, 조종, 경보, 배치, 피드백 |
| 대표 결과 | 기능 블록도, 작업 흐름, 하위체계 구조 | 화면 구성, 조작부 형태, 경보 방식 |
| 오류 위험 | 기능 누락, 부적절한 자동화 | 오독, 오조작, 피드백 부족 |

예를 들어 기본설계에서 “작업자는 이상 상태를 확인하고 운전을 정지한다”고 정했다고 해보자. 그러면 계면설계에서는 이상 상태를 어떤 표시로 알릴지, 경보의 우선순위를 어떻게 구별할지, 정지 조작부를 어디에 배치할지, 조작이 접수되었음을 어떻게 피드백할지 결정해야 해.

기본설계가 역할을 정한다면 계면설계는 그 역할을 **실제로 수행할 수 있는 조건**을 만드는 셈이야.

## 6. 안전한 계면을 만드는 네 가지 원리

### 정보의 가시성과 구별성

중요한 정보는 필요한 순간에 쉽게 보여야 하고, 다른 정보와 혼동되지 않아야 해. 색만으로 상태를 구별하면 색각 특성이 다른 사용자가 어려움을 겪을 수 있으므로 색상과 함께 문자, 형상, 위치, 점멸 같은 중복 단서를 사용해야 해.

### 표시–조종 양립성

조작 방향과 결과가 사용자의 자연스러운 기대와 일치해야 해. 오른쪽으로 돌리면 증가하고, 위로 움직이면 상승하는 것처럼 공간적·운동적 관계가 자연스러워야 오조작이 줄어들어.

### 즉각적이고 명확한 피드백

사용자가 조작했을 때 체계가 입력을 받았는지, 어떤 상태로 변했는지 알려줘야 해. 버튼을 눌렀는데 아무 반응이 보이지 않으면 사용자는 반복 조작하거나 잘못된 판단을 할 수 있어.

### 오류 예방과 복구 가능성

좋은 계면은 오류가 발생한 뒤 경고하는 데 그치지 않고, 처음부터 오류가 발생하기 어렵게 만들어. 위험한 두 조작부를 멀리 배치하거나 형태를 다르게 하고, 중요한 조작에는 확인 절차를 두며, 가능한 경우 취소나 복구 수단을 제공해야 해.

다만 모든 조작에 확인 단계를 넣으면 작업 흐름이 느려지고 경고를 습관적으로 무시할 수 있어. 그러므로 오류 결과가 중대하고 되돌리기 어려운 조작에 확인 절차를 집중해야 해.

## 7. 실제 사례로 연결하기: 프레스 설비 비상정지 체계

프레스 설비의 비상정지 체계를 설계한다고 생각해보자.

먼저 목표는 “위험 상황에서 작업자가 설비의 위험 운동을 신속하게 정지시켜 상해를 방지한다”가 될 수 있어. 이 목표를 바탕으로 비상정지 조작시간, 정지 반응시간, 접근 가능 거리, 오조작 방지, 고장 시 안전 상태 같은 성능명세를 정해.

기본설계에서는 위험 감지, 비상정지 명령, 동력 차단, 제동, 정지 상태 확인 기능을 분해해. 작업자는 위험 인지와 수동 정지 명령을 담당하고, 제어계통은 명령 검출과 동력 차단을 담당하도록 배분할 수 있어. 필요하다면 광전자식 방호장치가 위험구역 침입을 자동 감지하도록 설계해.

계면설계에서는 비상정지 버튼을 눈에 잘 띄고 도달하기 쉬운 위치에 배치해. 일반 조작부와 형태·색·크기를 구별하고, 보호장갑을 낀 상태에서도 누를 수 있게 해야 해. 버튼이 작동하면 설비가 정지했음을 표시하고, 원인이 제거되기 전에는 단순 복귀만으로 자동 재가동되지 않도록 해야 해.

이 사례에서 버튼 자체만 잘 만들었다고 안전한 것은 아니야. 목표가 불명확하거나, 정지 기능의 역할 배분이 잘못되었거나, 제동 성능이 부족하면 계면만 개선해도 사고를 막기 어려워. 세 단계가 반드시 이어져야 하는 이유가 바로 여기에 있어.

## 8. 시험에서 자주 나오는 경계와 함정

**첫 번째 함정은 목표와 성능명세를 같은 것으로 보는 것**이야. 목표는 달성하려는 방향이고, 성능명세는 달성 여부를 판단하는 구체적 기준이야.

**두 번째 함정은 기본설계를 외형 설계로만 이해하는 것**이야. 기본설계의 핵심은 기능 분석, 기능 배분, 체계 구조, 정보 흐름을 결정하는 데 있어.

**세 번째 함정은 계면을 장비 표면이나 화면으로만 한정하는 것**이야. 계면에는 표시장치와 조종장치뿐 아니라 경보, 작업공간, 절차, 소프트웨어 상호작용도 포함될 수 있어.

**네 번째 함정은 인간에게 맡기면 항상 유연하고 안전하다고 판단하는 것**이야. 인간은 피로, 주의 분산, 기억 한계, 개인차의 영향을 받아. 반대로 기계도 새로운 상황과 예상하지 못한 고장에 취약할 수 있으므로 상호 보완적으로 배분해야 해.

**다섯 번째 함정은 자동화를 인간의 완전한 제거로 보는 것**이야. 자동화 이후에도 작업자는 감시, 예외 처리, 복구를 맡을 수 있어. 따라서 상황인식과 수동 개입 가능성을 보존해야 해.

**여섯 번째 함정은 계면설계를 마지막 장식 단계로 보는 것**이야. 계면 문제는 기능 배분과 작업 절차에 영향을 주므로 설계 초기부터 반복적으로 검토해야 해.

## 10. 정답 및 해설

**문제 1 정답: 2번**

“2초 이내”처럼 성능을 측정하고 시험할 수 있는 기준이 들어 있으므로 성능명세에 해당해. 단순히 “위험을 신속하게 알린다”라고 했다면 목표에 더 가까워.

**문제 2 정답: 3번**

기본설계는 세부 외형보다 먼저 기능 구조, 작업 흐름, 인간–기계 기능 배분을 결정하는 단계야. 버튼 색이나 글꼴은 이후의 구체적인 계면설계에서 다뤄.

**문제 3 정답: 2번**

형상과 위치를 구별하면 작업자가 잘못된 조작부를 선택할 가능성이 줄어들어. 이는 오류가 일어난 뒤 처벌하는 방식이 아니라 설계로 오류를 예방하는 접근이야.

**문제 4 예시 답안**

자동화가 실패하거나 예상하지 못한 상황이 발생했을 때 작업자가 현재 상태를 이해하고 적절하게 개입해야 하기 때문이야.

핵심은 자동화가 정상일 때의 편리함만 보는 것이 아니라, **비정상 상태에서 인간이 통제권을 회복할 수 있는지**까지 살피는 거야.

## 11. 회상 요약

**목표**는 체계가 달성해야 할 방향이야.

**성능명세**는 목표를 조건, 수준, 시간, 정확도처럼 측정하고 시험할 수 있는 기준으로 바꾼 것이야.

**기본설계**는 기능을 분해하고 인간과 기계의 역할을 배분하며 체계의 전체 구조와 정보 흐름을 정하는 단계야.

**계면설계**는 표시, 조종, 경보, 작업공간, 피드백을 통해 인간과 기계가 안전하게 상호작용하도록 접점을 구체화하는 단계야.

세 개념의 순서를 짧게 기억하면 돼.

**무엇을 달성할지 정한다 → 누가 어떤 기능을 맡을지 정한다 → 실제로 어떻게 보고 조작할지 정한다**

결국 좋은 체계설계는 사람에게 “조심하라”고 요구하는 데서 끝나지 않아. 인간의 능력과 한계를 처음부터 성능 기준, 기능 구조, 접점 설계 안에 넣어 오류가 사고로 이어지지 않도록 만드는 과정이야.
