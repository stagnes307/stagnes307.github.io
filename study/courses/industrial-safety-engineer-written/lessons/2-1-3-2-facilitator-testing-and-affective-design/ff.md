## 1. 촉진물 설계

### 1.1 정의와 목적

**촉진물 설계**는 작업자가 어떤 조작을 해야 하는지 빠르게 알아차리고, 여러 조종장치를 혼동하지 않으며, 장갑을 끼거나 시야가 제한된 상황에서도 정확히 식별할 수 있도록 조종장치의 형태와 배치를 설계하는 일이야.

여기서 촉진물은 보통 손으로 잡거나 돌리고 누르는 **손잡이, 노브, 레버, 스위치 같은 조종장치의 식별 단서**를 뜻해. 촉진물의 목적은 장식을 더하는 것이 아니라 작업자의 탐색시간, 판단시간, 오조작 확률을 줄이는 데 있어.

촉진물 설계를 잘하면 작업자는 조종장치를 매번 자세히 읽지 않아도 돼. 자동차에서 방향지시등과 와이퍼 조작부의 위치와 움직임이 구분되는 것처럼, 촉진물은 사람의 감각과 기억을 보조하는 작은 표지판 역할을 해.

### 1.2 설계에 사용되는 식별 단서

| 식별 단서 | 설계 원리 | 장점 | 주의할 점 |
|---|---|---|---|
| 형상 | 원형, 별형, 막대형처럼 형태를 다르게 함 | 촉각만으로도 구분 가능 | 지나치게 유사한 형상은 혼동을 유발함 |
| 크기 | 지름, 길이, 높이 또는 두께에 차이를 둠 | 시각적 식별이 쉬움 | 손의 크기와 장갑 착용을 고려해야 함 |
| 표면 촉감 | 매끈함, 요철, 홈, 거친 정도를 달리함 | 어두운 곳에서도 촉각 식별 가능 | 피부 자극과 미끄럼을 방지해야 함 |
| 위치 | 기능별로 일정한 장소에 배치함 | 탐색시간이 감소함 | 자주 쓰는 장치는 정상 작업영역에 둬야 함 |
| 색채 | 기능이나 위험 수준에 따라 색을 구별함 | 빠른 시각적 판단에 유리함 | 색각 이상과 낮은 조도를 고려해야 함 |
| 표시 | 문자, 숫자, 기호를 부착함 | 기능을 명시할 수 있음 | 작은 글씨와 모호한 기호를 피해야 함 |
| 조작 방향 | 기능 변화와 조작 방향을 대응시킴 | 결과를 예측하기 쉬움 | 집단 고정관념과 일치시켜야 함 |

중요한 원리는 **하나의 단서에만 의존하지 않는 것**이야. 예를 들어 비상정지장치를 빨간색으로만 구별하면 어두운 환경이나 색각 이상이 있는 작업자에게 불리할 수 있어. 따라서 색채뿐 아니라 큰 버섯형 머리, 돌출된 위치, 명확한 표시를 함께 사용해야 해.

### 1.3 양립성과 집단 고정관념

촉진물의 움직임은 사용자가 예상하는 결과와 일치해야 해. 이를 **운동 양립성** 또는 조작과 반응의 양립성이라고 해.

일반적으로 조종장치를 오른쪽이나 시계 방향으로 움직이면 표시값, 속도 또는 출력이 증가할 것이라고 기대해. 반대로 왼쪽이나 반시계 방향은 감소로 받아들이는 경우가 많아. 이런 사회적으로 공유된 기대를 **집단 고정관념**이라고 해.

하지만 이 규칙을 기계적으로 적용하면 안 돼. 조종장치와 표시장치가 어떤 공간적 관계에 놓였는지, 작업자가 장치를 어느 방향에서 보는지, 실제 산업 관행은 무엇인지 함께 검토해야 해.

### 1.4 구체적인 예시

화학설비 제어반에 모양과 크기가 같은 검은색 노브가 열 개 있다고 생각해보자. 작업자가 긴급 상황에서 압력 조절 노브를 찾으려면 명칭을 하나씩 읽어야 하므로 반응이 늦어져.

압력 조절 노브를 큰 별형으로 만들고, 온도 조절 노브는 둥근 홈이 있는 형상으로 만들며, 비상 차단장치는 돌출된 적색 버섯형으로 만들면 탐색시간과 오조작 가능성이 줄어들어. 장갑을 착용한 작업자도 촉각으로 구분할 수 있다는 점이 핵심이야.

### 1.5 비교와 적용 경계

**표시장치**는 기계의 상태를 사람에게 전달하는 입력 통로이고, **조종장치**는 사람의 의도를 기계에 전달하는 출력 통로야. 촉진물 설계는 주로 조종장치를 쉽게 찾고 구분하도록 만드는 문제에 해당해.

색채는 멀리서도 빠르게 구별할 수 있지만 조명과 색각에 영향을 받아. 형상과 촉감은 시선이 다른 곳을 향하거나 어두운 환경에서도 사용할 수 있지만, 너무 많은 종류를 쓰면 오히려 기억 부담이 커져. 따라서 작업의 빈도, 중요도, 긴급성, 환경조건을 기준으로 단서를 조합해야 해.

### 1.6 시험 함정

1. 촉진물은 미적 장식이 아니라 **조종장치의 식별과 정확한 조작을 돕는 인간공학적 단서**야.

2. 색채만으로 충분하다는 문장은 위험해. 중요한 기능은 형상, 위치, 표시 같은 단서를 중복해서 제공하는 것이 좋아.

3. 모든 조종장치를 서로 다르게 만들면 무조건 좋다는 주장도 틀릴 수 있어. 기능적으로 같은 장치는 일관성을 유지하고, 혼동하면 위험한 장치끼리는 명확히 구별해야 해.

4. 조작 방향은 설계자의 임의적 취향보다 사용자의 기대, 공간 관계, 집단 고정관념과 양립해야 해.

## 2. 시험 및 평가

### 2.1 정의와 역할

**시험 및 평가**는 설계된 인간·기계체계가 정해진 성능명세를 충족하는지 자료를 통해 확인하는 과정이야. 시험은 관찰과 측정을 수행하는 활동이고, 평가는 그 결과를 기준과 비교하여 적합성이나 개선 필요성을 판단하는 활동이라고 구분할 수 있어.

좋은 평가에서는 단순히 기계가 작동하는지만 보지 않아. 작업자가 얼마나 정확하고 빠르게 과업을 수행하는지, 피로와 불편은 어느 정도인지, 실수 후 회복이 가능한지, 비상상황에서도 안전한지를 함께 확인해야 해.

### 2.2 평가 절차

1. **평가 목표 설정**  
무엇을 검증할지 명확하게 정해. 조작시간 감소, 오류율 저하, 경보 식별성 향상처럼 측정 가능한 목표가 필요해.

2. **평가기준과 지표 선정**  
목표를 수치로 나타낼 지표를 정해. 수행시간, 오류 횟수, 성공률, 반응시간, 작업부하, 만족도, 생리적 부담을 사용할 수 있어.

3. **시험 조건과 참가자 구성**  
실제 사용자를 대표하는 참가자를 선정하고 조도, 소음, 보호구, 작업속도 같은 현장조건을 반영해.

4. **시험 실시와 자료 수집**  
객관적 수행자료와 사용자의 주관적 평가를 함께 수집해. 관찰, 면담, 설문, 영상기록, 생리측정도 활용할 수 있어.

5. **기준과 비교 및 원인 분석**  
성능명세나 기존 설계와 결과를 비교하고, 평균값뿐 아니라 오류가 발생한 조건과 사용자 집단도 분석해.

6. **설계 수정과 재시험**  
평가는 판정으로 끝나지 않아. 발견된 문제를 수정하고 다시 시험하는 반복 과정이 필요해.

### 2.3 평가 지표의 구조

| 평가 차원 | 대표 지표 | 의미 |
|---|---|---|
| 효과성 | 성공률, 정확도, 오류율 | 사용자가 목표를 올바르게 달성했는가 |
| 효율성 | 수행시간, 조작 횟수, 학습시간 | 목표 달성에 자원이 얼마나 들었는가 |
| 안전성 | 위험행동, 사고 가능성, 회복 가능성 | 오류가 재해로 확대되지 않는가 |
| 신체 부담 | 근활성도, 자세, 피로도 | 신체에 과도한 부담이 발생하는가 |
| 정신 부담 | 주관적 작업부하, 주의 요구량 | 인지자원이 지나치게 소모되는가 |
| 만족도 | 선호도, 편안함, 수용성 | 사용자가 설계를 긍정적으로 받아들이는가 |

**객관적 지표**는 수행시간이나 오류율처럼 관찰하고 측정할 수 있는 자료야. **주관적 지표**는 편안함이나 만족도처럼 사용자가 보고한 자료야. 객관적 성능이 좋아도 사용자가 지나친 긴장과 피로를 느낄 수 있으므로 두 종류를 함께 봐야 해.

### 2.4 신뢰도와 타당도

**신뢰도**는 같은 대상을 같은 조건에서 반복해서 측정했을 때 비슷한 결과가 나오는 정도야. 체중계가 실제보다 항상 2kg 크게 표시하더라도 반복 측정값이 일정하다면 신뢰도는 높을 수 있어.

**타당도**는 측정하려는 대상을 실제로 제대로 측정했는지를 뜻해. 작업자의 안전성을 평가한다면서 버튼을 누르는 속도만 측정했다면 중요한 오류율과 위험행동을 놓칠 수 있으므로 타당도가 낮아.

따라서 신뢰도가 높다고 타당도까지 자동으로 높아지는 것은 아니야. 이 구별은 시험에서 자주 물어보는 핵심이야.

### 2.5 형성평가와 총괄평가

**형성평가**는 설계가 진행되는 동안 문제를 찾아 수정하기 위한 평가야. 초기 모형이나 시제품을 사용해 조기에 문제를 발견하므로 수정비용을 줄일 수 있어.

**총괄평가**는 완성된 체계가 최종 요구사항과 성능명세를 충족하는지 종합적으로 판단하는 평가야. 개발 완료나 도입 결정에 가까운 단계에서 수행돼.

| 구분 | 형성평가 | 총괄평가 |
|---|---|---|
| 주요 시점 | 설계 및 개발 중 | 개발 후반 또는 완료 후 |
| 주요 목적 | 문제 발견과 개선 | 최종 성능과 적합성 판단 |
| 핵심 질문 | 무엇을 고쳐야 하는가 | 요구사항을 충족했는가 |
| 변경 가능성 | 상대적으로 큼 | 상대적으로 제한됨 |

### 2.6 구체적인 예시

새로운 비상정지장치를 평가한다고 해보자. 참가자에게 정상 운전 중 경보가 발생하는 시나리오를 제시하고, 경보 발생부터 비상정지장치 조작까지 걸린 시간과 잘못 누른 버튼의 수를 측정해.

동시에 장치를 쉽게 찾았는지, 힘은 적절했는지, 표시가 명확했는지를 설문과 면담으로 확인해. 조명이 밝은 조건에서만 시험하지 말고 저조도, 소음, 보호장갑 착용 조건도 포함해야 현장 타당성을 높일 수 있어.

평균 반응시간이 짧더라도 일부 작업자가 비상정지장치와 운전시작 버튼을 혼동했다면 안전한 설계라고 결론 내리면 안 돼. 안전 평가에서는 평균 성능뿐 아니라 치명적인 오류와 극단조건을 중요하게 봐야 해.

### 2.7 시험 함정

1. 시험은 자료를 얻는 활동이고 평가는 자료를 기준과 비교하여 의미를 판단하는 활동이야.

2. 신뢰도는 **일관성**, 타당도는 **측정 목적에 대한 적합성**이야.

3. 평균 수행시간만으로 인간공학적 적합성을 판단하면 안 돼. 오류율, 작업부하, 만족도와 안전성도 확인해야 해.

4. 실제 사용자를 대표하지 않는 참가자와 지나치게 이상적인 실험환경은 현장 적용 가능성을 떨어뜨려.

5. 형성평가는 개선 중심, 총괄평가는 최종 판정 중심이라고 기억하면 쉬워.

## 3. 감성공학

### 3.1 정의와 핵심 원리

**감성공학**은 사용자가 제품이나 환경에서 느끼는 편안함, 안정감, 고급스러움, 역동성 같은 감성적 요구를 조사하고, 이를 형상·색채·재질·소리·조작감과 같은 구체적인 설계요소로 변환하는 접근이야.

핵심 흐름은 다음과 같아.

**사용자의 감성 → 감성어휘와 평가척도 → 제품 특성과의 관계 분석 → 설계요소 결정 → 시제품 검증**

즉, 감성공학은 설계자의 직관만으로 예쁜 제품을 만드는 일이 아니야. 주관적인 감성을 가능한 한 체계적으로 측정하고 설계변수와 연결하는 과정이야.

### 3.2 감성공학의 절차

1. **대상 사용자와 제품영역을 설정해**  
누가 어떤 상황에서 사용할 제품인지 결정해. 작업자용 보호구와 일반 소비자용 전자제품은 필요한 감성이 달라.

2. **감성어휘를 수집해**  
편안한, 견고한, 신뢰감 있는, 가벼운, 세련된 같은 표현을 사용자 조사와 문헌에서 모아.

3. **대표 감성어휘를 정리해**  
유사한 단어를 묶고 평가 목적에 맞는 핵심 어휘를 선정해.

4. **제품 표본과 설계요소를 분해해**  
색상, 곡률, 표면질감, 버튼 압력, 경보음의 높낮이처럼 조절 가능한 속성을 정리해.

5. **사용자 평가자료를 수집해**  
사용자가 각 제품을 보고 만지고 조작한 뒤 감성어휘별로 점수를 부여하도록 해.

6. **감성과 설계요소의 관계를 분석해**  
어떤 형상과 재질이 안정감이나 신뢰감을 높이는지 통계적 또는 실험적으로 확인해.

7. **설계안을 구현하고 검증해**  
예측된 설계가 실제로 원하는 감성을 유발하는지 다시 시험해.

### 3.3 의미분별법

감성평가에는 **의미분별법**이 자주 활용돼. 서로 반대되는 형용사 쌍을 척도의 양 끝에 두고 사용자의 느낌을 평가하는 방식이야.

예를 들면 다음과 같아.

| 감성 척도 | 왼쪽 의미 | 오른쪽 의미 |
|---|---|---|
| 가벼운 ↔ 무거운 | 가볍고 민첩한 인상 | 묵직하고 안정적인 인상 |
| 단순한 ↔ 복잡한 | 직관적이고 정돈된 인상 | 정보가 많고 정교한 인상 |
| 부드러운 ↔ 딱딱한 | 친근하고 편안한 인상 | 견고하고 엄격한 인상 |
| 불안한 ↔ 신뢰감 있는 | 취약하고 불확실한 인상 | 안전하고 믿을 만한 인상 |

여기서 중요한 점은 감성어휘의 어느 한쪽이 항상 좋은 것은 아니라는 거야. 휴대용 장비에는 가벼운 느낌이 적합할 수 있지만, 비상정지장치에는 묵직하고 확실한 조작감이 더 신뢰를 줄 수 있어.

### 3.4 구체적인 예시

산업용 안전모를 설계한다고 생각해보자. 사용자는 안전모에 대해 가벼움, 견고함, 안정감, 시원함 같은 감성을 기대할 수 있어.

설계자는 색상, 표면의 광택, 외피의 곡률, 내부 완충재의 촉감, 통풍구의 형태를 설계변수로 정해. 사용자가 여러 시제품을 착용한 뒤 감성어휘별 점수를 매기게 하면 어떤 속성이 원하는 인상과 관련되는지 파악할 수 있어.

다만 사용자가 견고해 보인다고 평가했다는 이유만으로 실제 충격보호 성능이 확보되는 것은 아니야. 감성적 신뢰와 공학적 안전성은 서로 보완해야 하지만 동일한 개념은 아니야.

### 3.5 비교와 적용 경계

| 관점 | 전통적 인간공학 | 감성공학 |
|---|---|---|
| 주요 관심 | 안전, 효율, 오류 감소, 신체 적합성 | 느낌, 인상, 선호, 정서적 만족 |
| 대표 질문 | 사용할 수 있는가 | 사용하고 싶고 신뢰할 수 있는가 |
| 대표 자료 | 오류율, 반응시간, 작업부하 | 감성어휘, 선호도, 의미분별 척도 |
| 공통점 | 사용자 특성과 사용환경을 설계에 반영함 | 사용자 특성과 사용환경을 설계에 반영함 |

전통적 인간공학과 감성공학을 대립 관계로 외우면 안 돼. 전자는 사용의 안전성과 효율성을 확보하고, 후자는 사용자가 느끼는 정서적 품질을 구체화해. 산업안전 분야에서는 **객관적 안전성이라는 바닥 위에 감성적 수용성을 쌓아야 해**.

### 3.6 시험 함정

1. 감성공학은 감성을 제거하는 학문이 아니라 감성을 **설계요소로 번역하는 접근**이야.

2. 감성은 주관적이지만 조사, 척도, 실험과 분석을 통해 체계적으로 다룰 수 있어.

3. 감성적 안전감과 실제 안전성은 같지 않아. 안전해 보이는 제품이라도 성능시험을 통과하지 못하면 안전한 제품이 아니야.

4. 감성어휘를 바로 설계자의 취향으로 해석하면 안 돼. 목표 사용자의 평가자료가 필요해.

5. 의미분별법에서는 보통 서로 반대되는 형용사 쌍을 이용해 대상의 의미와 인상을 측정해.

## 4. 세 주제의 통합 관계

세 주제를 하나의 제어반 개발과정에 연결해볼게.

먼저 **촉진물 설계**를 통해 비상정지장치의 형상, 크기, 촉감, 색채와 위치를 결정해. 다음으로 **시험 및 평가**를 통해 작업자의 반응시간, 오조작률, 조작력, 작업부하와 만족도를 측정해. 마지막으로 **감성공학**을 이용해 작업자가 장치를 얼마나 견고하고 신뢰감 있게 느끼는지 조사하고 그 감성을 재질과 조작감에 반영해.

그러나 감성평가에서 높은 점수를 받은 설계라도 실제 오류율이나 위험이 증가하면 채택하면 안 돼. 산업안전 설계의 우선순위는 다음처럼 이해하면 좋아.

1. 법적·기술적 안전요건을 충족해.

2. 사용자가 정확하고 효율적으로 조작할 수 있게 해.

3. 시험 및 평가로 성능을 검증해.

4. 감성적 수용성과 신뢰감을 개선해.

5. 수정한 설계를 다시 시험해.

핵심은 **느낌이 성능을 대신하지 않고, 성능도 사용자의 느낌을 무시하지 않는 것**이야.
