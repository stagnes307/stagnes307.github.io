🧠 인간실수를 어떻게 이해해야 할까?

인간실수는 작업자가 의도한 목표와 실제 행동 또는 결과 사이에 차이가 생긴 상태야. 사고가 발생했을 때만 인간실수라고 부르는 것은 아니야. 잘못된 버튼을 눌렀지만 안전장치가 작동해 사고가 나지 않은 경우에도 인간실수는 이미 발생한 거야.

인간실수를 단순히 “작업자가 부주의했다”라고 설명하면 원인을 제대로 찾을 수 없어. 같은 실수가 반복된다면 개인의 주의력보다 표시장치, 조작장치, 절차서, 작업시간, 교육 또는 작업환경에 반복을 유도하는 조건이 있을 가능성이 커. 인간실수의 분류는 사람을 비난하기 위한 명칭표가 아니라 오류가 발생한 위치와 원인을 찾아 적절한 방어책을 선택하기 위한 분석 도구야.

작업자가 밸브를 잠그지 않았다면 “필요한 행동을 빠뜨렸는가?”, “다른 밸브를 조작했는가?”, “조작은 맞았지만 너무 늦었는가?”, “작업 순서를 바꾸었는가?”를 구별해야 해. 겉으로는 모두 밸브 조작 실패처럼 보여도 오류의 구조와 예방대책은 서로 달라지기 때문이야.

📚 인간실수의 분류

생략오류: Omission Error

생략오류는 해야 할 행동이나 절차를 수행하지 않은 오류야. 기억하지 못했거나 확인하지 않았거나 작업 단계 자체를 건너뛴 경우가 여기에 해당해. 정상 절차가 A → B → C라면 A → C처럼 B가 사라진 모습이야. 행동의 내용이 잘못된 것이 아니라 필요한 행동이 존재하지 않는다는 점이 핵심이야.

  • 설비 정비 후 방호덮개를 다시 설치하지 않은 경우
  • 작업 시작 전 가스농도 측정을 누락한 경우
  • 전원을 차단했지만 잠금장치를 설치하지 않은 경우
  • 운전 전 점검표의 한 항목을 확인하지 않은 경우

생략오류를 줄이려면 기억력에만 의존하지 말고 체크리스트, 단계별 확인표, 인터록, 경보와 작업완료 표시를 사용해야 해. 시험에서는 “해야 할 조작을 하지 않았다”는 표현을 찾으면 돼. 잘못된 조작을 실제로 수행한 작위오류와 구별해야 해.

작위오류: Commission Error

작위오류는 필요한 행동을 하지 않은 것이 아니라 행동을 했지만 내용이나 대상이 잘못된 오류야. B 밸브를 열어야 하는데 C 밸브를 열었다면 행동은 존재하지만 대상이 틀렸어. 따라서 생략오류가 아니라 작위오류야.

  • 정지 버튼 대신 기동 버튼을 누른 경우
  • 차단해야 할 전원이 아닌 인접 회로의 전원을 차단한 경우
  • 원료 A 대신 외관이 비슷한 원료 B를 투입한 경우
  • 압력 설정값 20을 200으로 입력한 경우

예방하려면 조작장치의 식별성, 색상과 형상의 차별화, 라벨의 가독성, 중요 조작의 재확인과 물리적 오조작 방지 구조가 필요해. 밸브를 전혀 잠그지 않았다면 생략오류이고 다른 밸브를 잠갔다면 작위오류야.

불필요행동오류: Extraneous Error

불필요행동오류는 작업 목적을 달성하는 데 요구되지 않은 행동을 추가로 수행하는 오류야. 정상 절차가 A → B → C인데 A → B → X → C를 수행했다면 X가 불필요행동에 해당해.

  • 점검과 관계없는 스위치를 추가로 조작한 경우
  • 정상 운전 중 필요하지 않은 우회회로를 활성화한 경우
  • 승인되지 않은 시험 조작을 임의로 수행한 경우
  • 절차에 없는 밸브를 추가로 개방한 경우

호기심, 습관, 절차의 모호성 또는 조작부의 과도한 노출이 원인이 될 수 있어. 접근권한 제한, 불필요한 조작부 제거, 명확한 절차 표시와 중요 조작부 보호커버가 효과적이야. 새로운 행동을 끼워 넣으면 불필요행동오류이고 기존 행동들의 순서만 바꾸면 순서오류야.

시간오류: Time Error

시간오류는 행동의 내용과 대상은 맞지만 요구된 시점이나 허용시간을 지키지 못한 오류야. 너무 일찍 수행하거나 너무 늦게 수행하는 경우가 모두 포함돼.

  • 압력이 충분히 낮아지기 전에 설비를 개방한 경우
  • 이상 신호가 나타난 뒤 비상정지를 지나치게 늦게 수행한 경우
  • 규정된 냉각시간이 끝나기 전에 다음 공정을 시작한 경우
  • 정해진 시간보다 늦게 환기장치를 가동한 경우

시간오류는 작업자의 반응속도만으로 설명할 수 없어. 경보가 늦거나 정보가 복잡하거나 허용시간이 비현실적으로 짧아도 발생해. 명확한 타이머, 단계 전환 신호, 자동정지, 충분한 반응시간과 경보 우선순위 설계가 필요해. 행동을 하지 않았다면 생략오류이고 결국 수행했지만 시점이 부적절했다면 시간오류야.

순서오류: Sequential Error

순서오류는 필요한 작업들을 모두 수행했더라도 규정된 순서를 지키지 않은 오류야. 정상 절차가 A → B → C인데 A → C → B로 수행하면 순서오류가 돼. 각 행동을 개별적으로 보면 맞지만 행동의 배열이 잘못됐다는 점이 핵심이야.

  • 전원을 차단하기 전에 설비 덮개를 연 경우
  • 배관의 압력을 제거하기 전에 연결부를 분리한 경우
  • 접지를 확인하기 전에 전기작업을 시작한 경우
  • 원료 투입 순서를 반대로 적용한 경우

절차 단계가 많거나 단계 간 구별이 약할 때 발생 가능성이 커져. 순차 인터록, 단계별 작업허가, 번호가 표시된 조작부와 한 단계 완료 후 다음 단계가 활성화되는 구조가 효과적이야.

🔍 인지 단계에 따른 분류

결과 형태에 따른 분류가 “무엇이 잘못되었는가?”를 보여준다면, 인지 단계에 따른 분류는 “사람의 정보처리 과정 어디에서 잘못되었는가?”를 보여줘.

인지 단계에 따른 인간실수 분류
분류 핵심 의미 대표 사례 주요 대책
인지오류 정보를 발견하거나 식별하지 못함 경고등을 보지 못함 가시성, 대비, 경보 개선
판단오류 정보를 보았지만 의미를 잘못 해석함 압력상승을 정상변동으로 오판 기준 명확화, 교육, 진단 지원
행동오류 판단은 맞지만 실행을 잘못함 올바른 밸브 대신 옆 밸브 조작 조작부 구별과 배치 개선

인지오류

인지오류는 필요한 신호나 정보를 감지하지 못하거나 다른 정보로 잘못 알아보는 오류야. 신호가 너무 작고 흐리거나 배경 소음이 크거나 여러 경보가 동시에 제시되면 가능성이 높아져. 작업자가 경고등을 보지 못했다면 주의력만 탓하지 말고 경고등의 밝기, 위치, 색 대비와 시야각을 함께 살펴야 해.

판단오류

판단오류는 정보를 인지했지만 그 의미를 잘못 해석하거나 부적절한 결정을 내리는 오류야. 지식 부족, 잘못된 정신모형, 경험에 대한 과신 또는 불완전한 절차서가 원인이 될 수 있어. 압력 상승을 확인했지만 일시적인 정상현상으로 오판해 운전을 계속한 사례가 해당해.

행동오류

행동오류는 상황과 필요한 조치를 올바르게 이해했지만 실제 동작을 잘못 수행한 경우야. 비슷하게 생긴 스위치, 불편한 조작 방향, 좁은 간격, 피로와 긴장 때문에 발생할 수 있어. 정지해야 한다는 판단은 맞았지만 인접한 기동 버튼을 누른 경우가 대표적이야.

🧩 의도와 행동의 관계에 따른 분류

Slip

Slip은 목표와 계획은 올바르지만 실행 과정에서 행동이 빗나간 오류야. 숙련된 작업자가 익숙한 작업을 자동적으로 수행하다가 유사한 조작부를 잘못 건드리는 경우가 대표적이야. 펌프 A를 정지하려고 정확히 판단했지만 펌프 B의 정지 버튼을 눌렀다면 의도는 맞고 실행이 틀렸으므로 slip이야.

Lapse

Lapse는 기억 과정의 실패야. 해야 할 일을 잠시 잊거나 작업 중단 후 어느 단계까지 했는지 기억하지 못하는 경우가 포함돼. 전화 때문에 점검이 중단된 뒤 복귀하면서 마지막 점검 항목을 수행했다고 착각한 사례가 해당해. 체크리스트와 중단지점 표시가 중요한 이유야.

Mistake

Mistake는 행동을 실행하기 전에 세운 판단이나 계획 자체가 잘못된 경우야. 작업자는 자신이 세운 계획대로 정확히 행동했지만 그 계획이 상황에 적합하지 않았던 거야. 설비의 이상 원인을 잘못 진단해 정상적으로 작동하는 냉각장치를 정지한 사례가 해당해.

Violation

Violation은 규칙이나 절차를 알고도 의도적으로 따르지 않는 행위야. 따라서 비의도적인 인간실수와 엄밀히 구별해야 해. 다만 개인의 도덕성만으로 설명해서도 안 돼. 규정을 지키면 작업을 완료할 수 없는 생산압력, 현장과 맞지 않는 절차 또는 조직적으로 묵인된 우회 관행이 위반을 정상화할 수 있기 때문이야.

Slip, Lapse, Mistake, Violation 비교
구분 의도·계획 실행 판별 질문
Slip 올바름 잘못됨 하려던 행동과 다른 행동을 했는가?
Lapse 대체로 올바름 기억 누락 해야 할 일을 잊었는가?
Mistake 잘못됨 계획대로 수행 판단이나 계획부터 틀렸는가?
Violation 규칙 이탈을 의도함 의도대로 수행 규칙을 알면서 따르지 않았는가?

핵심 비교는 간단해. Slip과 lapse는 실행·기억 단계의 문제이고 mistake는 계획·판단 단계의 문제야. Violation은 비의도적 오류가 아니라 의도적인 규칙 이탈이라는 차이가 있어.

🧭 형태적 특성

형태적 특성은 인간실수가 작업의 외형상 어떤 모습으로 나타났는지를 구별하는 관점이야. 마음속에서 왜 그런 판단을 했는가보다 관찰 가능한 행동이 정상 절차와 어떻게 달라졌는지를 분석해.

인간실수의 형태적 특성 비교
형태 오류 구조 핵심 질문
생략 A → C 필요한 행동이 빠졌는가?
작위 A → X → C 해야 할 행동 대신 잘못된 행동을 했는가?
불필요행동 A → B → X → C 요구되지 않은 행동을 추가했는가?
시간 A → B → C, 단 시점 부적절 너무 빠르거나 늦었는가?
순서 A → C → B 필요한 행동의 배열이 바뀌었는가?

이 구분의 장점은 사고기록을 “작업자 부주의”로 끝내지 않고 구체적인 설계대책과 연결할 수 있다는 데 있어. 생략이 반복되면 체크리스트나 인터록을 검토하고, 작위가 반복되면 조작부의 모양과 라벨 및 배치를 살펴야 해. 시간오류가 많다면 경보부터 조치까지 주어진 시간이 충분한지 확인하고, 순서오류가 많다면 절차와 순차제어 구조를 개선해야 해.

형태적 특성과 원인은 같은 개념이 아니야

형태적 특성은 오류가 나타난 모양이고 원인은 그 모양을 발생시킨 조건이야. 하나의 형태가 언제나 하나의 원인과 대응하는 것은 아니야. 생략오류도 기억 실패, 경보의 가시성 부족, 절차서의 모호함, 작업 중단, 과도한 업무량, 피로, 시간압박 또는 교육 부족에서 발생할 수 있어.

반대로 하나의 원인이 여러 형태의 오류를 만들 수도 있어. 피로는 점검 누락이라는 생략오류, 잘못된 버튼 조작이라는 작위오류 또는 반응 지연이라는 시간오류를 만들 수 있어. 따라서 사고조사에서는 오류 형태를 분류한 다음 왜 발생했는지, 어떤 설계와 조직 조건이 영향을 주었는지, 같은 오류가 사고로 발전하지 않도록 어떤 방어층이 필요한지까지 확인해야 해.

🏭 통합 사례: 화학설비 정비 후 재가동

정상 절차는 작업 완료 확인, 공구와 잔류물 제거, 방호덮개 설치, 밸브 정렬 확인, 경보계통 시험, 운전책임자 승인, 설비 재가동의 순서라고 해보자.

사례 A: 방호덮개 설치 누락

생략오류야. 필요한 행동이 빠졌기 때문이야. 체크리스트, 덮개 설치 감지장치 또는 미설치 시 기동 불가 인터록으로 예방할 수 있어.

사례 B: 인접한 다른 밸브 개방

외형상 작위오류이고 실행 수준에서는 slip일 수 있어. 행동은 수행했지만 대상이 틀렸고 올바른 의도가 실행 과정에서 빗나갔기 때문이야. 밸브 태그, 색상, 형상과 배치를 차별화하고 지시와 복창 절차를 적용할 수 있어.

사례 C: 승인 전 설비 재가동

순서오류야. 승인과 재가동이라는 단계는 모두 존재하지만 규정된 배열이 바뀌었기 때문이야. 승인 신호가 없으면 기동되지 않는 순차 인터록이 효과적이야.

사례 D: 안정화 시간 전 다음 단계 수행

시간오류야. 행동 내용은 맞지만 시점이 너무 빨랐기 때문이야. 자동 타이머, 대기시간 표시 또는 조건 충족 전 다음 단계 잠금으로 예방할 수 있어.

사례 E: 절차에 없는 우회스위치 조작

불필요행동오류야. 정상 절차에 요구되지 않은 행동을 추가했기 때문이야. 우회조작 권한 제한, 보호커버와 승인 절차가 필요해.

같은 사건에도 서로 다른 분류축을 동시에 적용할 수 있어. “다른 밸브를 열었다”는 것은 외형상 작위오류이고, 라벨을 잘못 읽었다면 인지오류이며, 의도는 맞았지만 손이 잘못 움직였다면 slip일 수 있어. 따라서 형태, 인지 단계, 의도성을 각각 기록해야 해.

🛡️ 예방설계와 연결하기

인간실수 유형별 예방설계
오류 유형 취약 지점 우선적인 예방 방법
생략오류 기억, 확인, 작업중단 체크리스트, 완료표시, 인터록
작위오류 식별, 선택, 조작 라벨 개선, 형상 차별화, 오조작 방지
불필요행동오류 접근통제, 절차 이해 보호커버, 권한 제한, 불필요 기능 제거
시간오류 경보, 반응시간, 단계 전환 타이머, 조기경보, 자동정지
순서오류 절차 구조, 단계 의존성 순차 인터록, 번호 표시, 단계별 승인
Slip 자동화된 행동의 미끄러짐 조작부 구별, 피드백, 확인 단계
Lapse 기억 유지 체크리스트, 중단지점 표시, 알림
Mistake 지식과 판단 교육, 진단지원, 명확한 의사결정 기준
Violation 규정과 현장의 불일치 실행 가능한 절차, 감독, 조직문화 개선

좋은 대책은 “주의하라”는 구호보다 실수를 어렵게 만들고, 실수가 발생해도 즉시 발견하며, 발견하지 못해도 사고로 확대되지 않도록 해야 해. 오류 예방, 오류 검출, 결과 완화라는 여러 방어층을 겹치는 방식이 중요해.

⚠️ 산업안전기사 시험 함정

생략과 작위

“조작하지 않았다”는 생략오류이고 “잘못 조작했다”는 작위오류야.

시간과 순서

시간오류는 행동 시점이 너무 빠르거나 늦은 것이고, 순서오류는 여러 행동의 배열이 바뀐 것이야.

불필요행동과 작위

작위오류는 요구된 행동을 잘못 수행한 것이고, 불필요행동오류는 요구되지 않은 행동을 추가한 것이야.

Slip과 Mistake

계획은 맞고 실행이 틀리면 slip이야. 계획이나 판단부터 틀리면 mistake야.

Error와 Violation

Error는 기본적으로 비의도적 실패이고, violation은 규칙에서 벗어나려는 의도가 있다는 차이가 있어.

암기 연결: 안 함은 생략, 잘못 함은 작위, 더 함은 불필요, 때가 틀리면 시간, 차례가 틀리면 순서라고 기억하면 안정적으로 구분할 수 있어.

    1. 순서오류
    2. 생략오류
    3. 불필요행동오류
    4. 인지오류

  4. 작업자가 설비 이상을 정확히 인식했지만 잘못된 대응계획을 세우고 그 계획대로 행동했다. 가장 적절한 분류는 무엇일까?

    1. Slip
    2. Lapse
    3. Mistake
    4. Omission

  5. 다음 중 시간오류에 해당하는 사례는 무엇일까?

    1. 점검항목 하나를 빠뜨렸다.
    2. 다른 밸브를 열었다.
    3. 요구되지 않은 스위치를 추가로 눌렀다.
    4. 압력이 충분히 낮아지기 전에 배관을 열었다.

  6. 다음 설명 중 옳지 않은 것은 무엇일까?

    1. 형태적 특성은 오류가 외부에 나타난 모습을 분류한다.
    2. 동일한 생략오류도 서로 다른 원인에서 발생할 수 있다.
    3. Violation은 언제나 비의도적인 기억 실패를 의미한다.
    4. Slip은 올바른 의도가 실행 단계에서 빗나간 경우다.

✨ 요약

  • 인간실수의 분류: 사람을 비난하는 절차가 아니라 오류의 구조와 적절한 예방책을 찾는 분석 과정이야.
  • 생략오류: 해야 할 행동을 하지 않은 경우야.
  • 작위오류: 행동했지만 내용이나 대상이 잘못된 경우야.
  • 불필요행동오류: 요구되지 않은 행동을 추가한 경우야.
  • 시간오류: 수행 시점이 너무 빠르거나 늦은 경우야.
  • 순서오류: 필요한 작업 단계의 배열이 바뀐 경우야.
  • Slip: 올바른 의도가 실행 단계에서 빗나간 오류야.
  • Lapse: 해야 할 행동을 잊는 기억 실패야.
  • Mistake: 판단이나 계획 자체가 잘못된 오류야.
  • Violation: 규칙에서 의도적으로 이탈한 행위야.
  • 형태적 특성: 오류가 나타난 모습이지 원인 그 자체는 아니야.
  • 시험 암기: 안 함은 생략, 잘못 함은 작위, 더 함은 불필요, 때가 틀리면 시간, 차례가 틀리면 순서야.
