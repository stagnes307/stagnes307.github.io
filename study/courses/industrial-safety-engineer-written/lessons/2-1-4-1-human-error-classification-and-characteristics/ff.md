## 1. 인간실수를 어떻게 이해해야 할까?

인간실수는 **작업자가 의도한 목표와 실제 행동 또는 결과 사이에 차이가 생긴 상태**야. 여기서 중요한 점은 사고가 발생했을 때만 인간실수라고 부르는 게 아니라는 거야. 잘못된 버튼을 눌렀지만 안전장치가 작동해 사고가 나지 않은 경우에도 인간실수는 이미 발생했어.

인간실수를 단순히 “작업자가 부주의했다”라고 설명하면 원인을 제대로 찾을 수 없어. 같은 사람이 같은 실수를 반복한다면 개인의 주의력보다 **표시장치, 조작장치, 절차서, 작업시간, 교육, 작업환경**에 반복을 유도하는 조건이 있을 가능성이 커. 인간실수의 분류는 사람을 비난하기 위한 명칭표가 아니라, 오류가 발생한 위치와 원인을 찾아 적절한 방어책을 선택하기 위한 분석 도구야.

예를 들어 작업자가 밸브를 잠그지 않았다면 먼저 “필요한 행동을 빠뜨렸는가?”, “다른 밸브를 조작했는가?”, “조작은 맞았지만 너무 늦었는가?”, “작업 순서를 바꾸었는가?”를 구별해야 해. 겉으로는 모두 밸브 조작 실패처럼 보이지만 예방책은 서로 달라지거든.

# 2. 인간실수의 분류

## 2.1 결과의 형태에 따른 기본 분류

### 2.1.1 생략오류: Omission Error

**생략오류**는 해야 할 행동이나 절차를 수행하지 않은 오류야. 기억하지 못했거나, 확인하지 않았거나, 작업 단계 자체를 건너뛴 경우가 여기에 해당해.

정상 절차가 A → B → C라면 생략오류는 A → C처럼 B가 사라진 모습이야. 행동의 내용이 잘못된 것이 아니라 **필요한 행동이 존재하지 않는다**는 점이 핵심이야.

구체적인 예시는 다음과 같아.

1. 설비 정비 후 방호덮개를 다시 설치하지 않은 경우
2. 작업 시작 전 가스농도 측정을 누락한 경우
3. 전원을 차단했지만 잠금장치를 설치하지 않은 경우
4. 운전 전 점검표의 한 항목을 확인하지 않은 경우

생략오류를 줄이려면 기억력에만 의존하지 말고 **체크리스트, 단계별 확인표, 인터록, 경보, 작업완료 표시**를 사용해야 해.

**시험 함정:** 해야 할 조작을 하지 않은 것은 생략오류야. 잘못된 조작을 한 작위오류와 구별해야 해.

---

### 2.1.2 작위오류: Commission Error

**작위오류**는 필요한 행동을 하지 않은 것이 아니라, 행동을 했지만 그 행동의 내용이나 대상이 잘못된 오류야. 흔히 “잘못 수행한 오류”라고 이해하면 돼.

정상 절차에서 B 밸브를 열어야 하는데 C 밸브를 열었다면 행동 자체는 존재하지만 대상이 틀렸어. 따라서 생략오류가 아니라 작위오류야.

구체적인 예시는 다음과 같아.

1. 정지 버튼 대신 기동 버튼을 누른 경우
2. 차단해야 할 전원이 아닌 인접 회로의 전원을 차단한 경우
3. 원료 A 대신 외관이 비슷한 원료 B를 투입한 경우
4. 압력 설정값을 20으로 입력해야 하는데 200으로 입력한 경우

예방하려면 **조작장치의 식별성, 색상과 형상의 차별화, 라벨의 가독성, 중요 조작의 재확인, 물리적 오조작 방지 구조**가 필요해.

**비교와 경계:** 밸브를 전혀 잠그지 않았다면 생략오류이고, 다른 밸브를 잠갔다면 작위오류야.

---

### 2.1.3 불필요행동오류: Extraneous Error

**불필요행동오류**는 작업 목적을 달성하는 데 요구되지 않은 행동을 추가로 수행하는 오류야. 필요한 행동이 빠진 것도 아니고, 지정된 행동을 틀리게 한 것도 아니라는 점이 특징이야.

정상 절차가 A → B → C인데 작업자가 A → B → X → C를 수행했다면 X가 불필요행동에 해당해.

구체적인 예시는 다음과 같아.

1. 점검과 관계없는 스위치를 추가로 조작한 경우
2. 정상 운전 중 필요하지 않은 우회회로를 활성화한 경우
3. 승인되지 않은 시험 조작을 임의로 수행한 경우
4. 절차에 없는 밸브를 추가로 개방한 경우

불필요행동은 호기심, 습관, 절차의 모호성, 조작부의 과도한 노출에서 발생할 수 있어. 따라서 **접근권한 제한, 불필요한 조작부 제거, 명확한 절차 표시, 중요 조작의 보호커버**가 효과적이야.

**시험 함정:** 작업 순서를 바꾸는 오류와 혼동하면 안 돼. 새로운 행동을 끼워 넣으면 불필요행동오류이고, 기존 행동들의 순서만 바꾸면 순서오류야.

---

### 2.1.4 시간오류: Time Error

**시간오류**는 행동의 내용과 대상은 맞지만, 요구된 시점이나 허용시간을 지키지 못한 오류야. 너무 일찍 수행하거나 너무 늦게 수행하는 경우가 모두 포함돼.

구체적인 예시는 다음과 같아.

1. 압력이 충분히 낮아지기 전에 설비를 개방한 경우
2. 이상 신호가 나타난 뒤 비상정지를 지나치게 늦게 수행한 경우
3. 규정된 냉각시간이 끝나기 전에 다음 공정을 시작한 경우
4. 정해진 시간보다 늦게 환기장치를 가동한 경우

시간오류는 작업자의 반응속도만으로 설명할 수 없어. 경보가 늦게 나타나거나, 정보가 복잡하거나, 허용시간이 현실적으로 너무 짧아도 발생해. 예방을 위해서는 **명확한 타이머, 단계 전환 신호, 자동정지, 충분한 반응시간, 경보 우선순위 설계**가 필요해.

**비교와 경계:** 행동을 하지 않았다면 생략오류이고, 결국 수행했지만 시점이 부적절했다면 시간오류야.

---

### 2.1.5 순서오류: Sequential Error

**순서오류**는 필요한 작업들을 모두 수행했더라도 규정된 순서를 지키지 않은 오류야. 각 행동을 개별적으로 보면 맞지만 배열이 잘못됐다는 점이 핵심이야.

정상 절차가 A → B → C인데 A → C → B로 수행하면 순서오류가 돼.

구체적인 예시는 다음과 같아.

1. 전원을 차단하기 전에 설비 덮개를 연 경우
2. 배관의 압력을 제거하기 전에 연결부를 분리한 경우
3. 접지를 확인하기 전에 전기작업을 시작한 경우
4. 원료 투입 순서를 반대로 적용한 경우

순서오류는 절차의 단계가 많거나 단계 간 구별이 약할 때 증가해. **순차 인터록, 단계별 작업허가, 번호가 표시된 조작부, 한 단계 완료 후 다음 단계가 활성화되는 구조**가 예방에 효과적이야.

**시험 함정:** 모든 행동을 했다는 이유만으로 정상 작업이라고 판단하면 안 돼. 산업설비에서는 동일한 행동도 순서가 바뀌면 폭발, 감전, 누출로 연결될 수 있어.

***

## 2.2 인지 단계에 따른 분류

결과 형태에 따른 분류가 “무엇이 잘못되었는가?”를 보여준다면, 인지 단계에 따른 분류는 “사람의 정보처리 과정 어디에서 잘못되었는가?”를 보여줘.

| 분류 | 핵심 의미 | 대표 사례 | 주요 대책 |
|---|---|---|---|
| **인지오류** | 정보를 발견하거나 식별하지 못함 | 경고등을 보지 못함 | 가시성, 대비, 경보 개선 |
| **판단오류** | 정보를 보았지만 의미를 잘못 해석함 | 압력상승을 정상변동으로 오판 | 기준 명확화, 교육, 진단 지원 |
| **행동오류** | 판단은 맞지만 실행을 잘못함 | 올바른 밸브 대신 옆 밸브 조작 | 조작부 구별, 배치 개선 |

### 2.2.1 인지오류

인지오류는 필요한 신호나 정보를 감지하지 못하거나 다른 정보로 잘못 알아보는 오류야. 신호가 너무 작고 흐리거나, 배경 소음이 크거나, 여러 경보가 동시에 제시되면 발생 가능성이 높아져.

예를 들어 작업자가 경고등을 보지 못했다면 “주의하지 않았다”라고만 결론 내리지 말고 경고등의 밝기, 위치, 색 대비, 시야각, 다른 표시와의 경쟁을 함께 살펴야 해.

### 2.2.2 판단오류

판단오류는 정보를 인지했지만 그 의미를 잘못 해석하거나 부적절한 결정을 내리는 오류야. 지식 부족, 잘못된 정신모형, 경험에 대한 과신, 불완전한 절차서가 원인이 될 수 있어.

예를 들어 압력 상승을 확인했지만 일시적인 정상현상이라고 판단해 운전을 계속했다면 판단오류에 가까워.

### 2.2.3 행동오류

행동오류는 상황과 필요한 조치를 올바르게 이해했지만 실제 동작을 잘못 수행한 경우야. 비슷하게 생긴 스위치, 불편한 조작 방향, 좁은 간격, 피로와 긴장 때문에 발생할 수 있어.

예를 들어 정지해야 한다는 판단은 맞았지만 인접한 기동 버튼을 누른 경우가 행동오류야.

***

## 2.3 의도와 행동의 관계에 따른 분류

### 2.3.1 Slip

**Slip**은 목표와 계획은 올바르지만 실행 과정에서 행동이 빗나간 오류야. 숙련된 작업자가 익숙한 작업을 자동적으로 수행하다가 유사한 조작부를 잘못 건드리는 경우가 대표적이야.

예를 들어 작업자는 펌프 A를 정지하려고 정확히 판단했지만 펌프 B의 정지 버튼을 눌렀어. 의도는 맞았지만 실행이 틀렸으므로 slip이야.

### 2.3.2 Lapse

**Lapse**는 기억 과정의 실패야. 해야 할 일을 잠시 잊거나, 작업 중단 후 어느 단계까지 했는지 기억하지 못하는 경우가 포함돼.

예를 들어 전화 때문에 점검이 중단된 뒤 복귀하면서 마지막 점검 항목을 수행했다고 착각했다면 lapse로 볼 수 있어. 체크리스트와 중단지점 표시가 중요한 이유야.

### 2.3.3 Mistake

**Mistake**는 행동을 실행하기 전에 세운 판단이나 계획 자체가 잘못된 경우야. 작업자는 자신이 세운 계획대로 정확히 행동했지만, 그 계획이 상황에 적합하지 않았던 거야.

예를 들어 설비의 이상 원인을 잘못 진단해 정상적으로 작동하는 냉각장치를 정지했다면 mistake야.

### 2.3.4 Violation

**Violation**은 규칙이나 절차를 알고도 의도적으로 따르지 않는 행위야. 따라서 비의도적인 인간실수와 엄밀히 구별할 필요가 있어.

그러나 violation도 무조건 개인의 도덕성 문제로만 보면 안 돼. 규정을 지키면 작업을 완료할 수 없는 생산압력, 현장과 맞지 않는 절차, 조직적으로 묵인된 우회 관행이 위반을 정상화할 수 있기 때문이야.

| 구분 | 의도·계획 | 실행 | 대표 질문 |
|---|---|---|---|
| **Slip** | 올바름 | 잘못됨 | 하려던 행동과 다른 행동을 했는가? |
| **Lapse** | 대체로 올바름 | 기억 누락 | 해야 할 일을 잊었는가? |
| **Mistake** | 잘못됨 | 계획대로 수행 | 판단이나 계획부터 틀렸는가? |
| **Violation** | 규칙 이탈을 의도함 | 의도대로 수행 | 규칙을 알면서 따르지 않았는가? |

**핵심 비교:** Slip과 lapse는 실행·기억 단계의 문제이고, mistake는 계획·판단 단계의 문제야. Violation은 비의도적 오류가 아니라 의도적인 규칙 이탈이라는 차이가 있어.

# 3. 형태적 특성

## 3.1 형태적 특성이란?

**형태적 특성**은 인간실수가 작업의 외형상 어떤 모습으로 나타났는지를 구별하는 관점이야. 마음속에서 왜 그런 판단을 했는가보다, 관찰 가능한 행동이 정상 절차와 어떻게 달라졌는지를 분석해.

정상 절차를 A → B → C라고 놓으면 형태적 특성은 다음처럼 기억할 수 있어.

| 형태 | 오류 구조 | 핵심 질문 |
|---|---|---|
| 생략 | A → C | 필요한 행동이 빠졌는가? |
| 작위 | A → X → C | 해야 할 행동 대신 잘못된 행동을 했는가? |
| 불필요행동 | A → B → X → C | 요구되지 않은 행동을 추가했는가? |
| 시간 | A → B → C, 단 시점 부적절 | 너무 빠르거나 늦었는가? |
| 순서 | A → C → B | 필요한 행동의 배열이 바뀌었는가? |

이 구분의 장점은 사고기록을 “작업자 부주의”로 끝내지 않고 구체적인 설계대책과 연결할 수 있다는 데 있어.

생략이 반복되면 체크리스트나 인터록을 검토해야 해. 작위가 반복되면 조작부의 모양, 라벨, 배치를 살펴야 하지. 시간오류가 많다면 경보부터 조치까지 주어진 시간이 충분한지 확인해야 하고, 순서오류가 많다면 절차와 순차제어 구조를 개선해야 해.

***

## 3.2 형태적 특성과 원인은 같은 개념이 아니야

형태적 특성은 **오류가 나타난 모양**이고, 원인은 **그 모양을 발생시킨 조건**이야. 하나의 형태가 언제나 하나의 원인과 대응하는 건 아니야.

예를 들어 생략오류는 다음과 같은 여러 원인으로 발생할 수 있어.

1. 기억 실패
2. 경보나 표시의 가시성 부족
3. 절차서의 모호함
4. 작업 중단과 재개
5. 과도한 업무량
6. 피로와 시간압박
7. 교육 부족

반대로 하나의 원인이 여러 형태의 오류를 만들 수도 있어. 피로는 점검 누락이라는 생략오류를 만들 수 있고, 잘못된 버튼 조작이라는 작위오류나 반응 지연이라는 시간오류도 만들 수 있어.

따라서 사고조사에서는 “생략오류가 발생했다”는 분류만으로 분석을 끝내면 안 돼. 그 다음에는 **왜 생략되었는지**, **어떤 설계와 조직 조건이 영향을 주었는지**, **같은 오류가 사고로 발전하지 않도록 어떤 방어층이 필요한지**까지 확인해야 해.

***

# 4. 통합 사례로 분류하기

## 사례: 화학설비 정비 후 재가동

정상 절차는 다음과 같다고 해보자.

1. 작업 완료 확인
2. 공구와 잔류물 제거
3. 방호덮개 설치
4. 밸브 정렬 확인
5. 경보계통 시험
6. 운전책임자 승인
7. 설비 재가동

### 사례 A

작업자가 방호덮개 설치를 건너뛰고 다음 단계로 이동했어.

**판정:** 생략오류  
**이유:** 필요한 행동이 빠졌기 때문이야.  
**예방:** 체크리스트, 덮개 설치 감지장치, 미설치 시 기동 불가 인터록

### 사례 B

작업자가 개방해야 할 밸브와 인접한 다른 밸브를 개방했어.

**판정:** 작위오류이면서 실행 수준에서는 slip  
**이유:** 행동은 수행했지만 대상이 틀렸고, 올바른 의도가 실행 과정에서 빗나갔기 때문이야.  
**예방:** 밸브 태그 개선, 색상과 형상 차별화, 배치 분리, 지시와 복창

### 사례 C

작업자가 승인 전에 설비를 먼저 재가동했어.

**판정:** 순서오류  
**이유:** 승인과 재가동이라는 단계가 존재하지만 규정된 배열이 바뀌었기 때문이야.  
**예방:** 승인 신호가 없으면 기동되지 않는 순차 인터록

### 사례 D

작업자가 경보계통 시험을 완료했지만 규정된 안정화 시간을 기다리지 않았어.

**판정:** 시간오류  
**이유:** 행동 내용은 맞지만 시점이 너무 빨랐기 때문이야.  
**예방:** 자동 타이머, 대기시간 표시, 조건 충족 전 다음 단계 잠금

### 사례 E

작업자가 절차에 없는 우회스위치를 추가로 작동했어.

**판정:** 불필요행동오류  
**이유:** 정상 절차에 요구되지 않은 행동을 추가했기 때문이야.  
**예방:** 우회조작 권한 제한, 보호커버, 승인 절차

같은 사건도 서로 다른 분류축을 동시에 적용할 수 있어. “다른 밸브를 열었다”는 것은 외형상 작위오류이고, 인지 과정까지 조사하면 밸브 라벨을 잘못 읽은 인지오류일 수도 있으며, 의도는 맞았지만 손이 잘못 움직였다면 slip일 수도 있어. 분류축을 섞지 않고 **형태, 인지 단계, 의도성**을 각각 기록하는 것이 중요해.

# 5. 예방설계와 연결하기

| 오류 유형 | 취약 지점 | 우선적인 예방 방법 |
|---|---|---|
| 생략오류 | 기억, 확인, 작업중단 | 체크리스트, 완료표시, 인터록 |
| 작위오류 | 식별, 선택, 조작 | 라벨 개선, 형상 차별화, 오조작 방지 |
| 불필요행동오류 | 접근통제, 절차 이해 | 보호커버, 권한 제한, 불필요 기능 제거 |
| 시간오류 | 경보, 반응시간, 단계 전환 | 타이머, 조기경보, 자동정지 |
| 순서오류 | 절차 구조, 단계 의존성 | 순차 인터록, 번호 표시, 단계별 승인 |
| Slip | 자동화된 행동의 미끄러짐 | 조작부 구별, 피드백, 확인 단계 |
| Lapse | 기억 유지 | 체크리스트, 중단지점 표시, 알림 |
| Mistake | 지식과 판단 | 교육, 진단지원, 명확한 의사결정 기준 |
| Violation | 규정과 현장의 불일치 | 실행 가능한 절차, 감독, 조직문화 개선 |

좋은 대책은 “주의하라”는 구호보다 실수를 어렵게 만들고, 실수가 발생해도 즉시 발견하며, 발견하지 못해도 사고로 확대되지 않도록 해야 해. 여러 방어층을 겹치는 방식이 중요한 이유야.

# 6. 산업안전기사 시험 함정

## 함정 1: 생략과 작위의 혼동

“조작하지 않았다”는 생략이고, “잘못 조작했다”는 작위야.

## 함정 2: 시간과 순서의 혼동

시간오류는 행동 시점이 너무 빠르거나 늦은 것이고, 순서오류는 여러 행동의 배열이 바뀐 것이야.

## 함정 3: 불필요행동과 작위의 혼동

작위오류는 요구된 행동을 잘못 수행한 것이고, 불필요행동오류는 요구되지 않은 행동을 추가한 것이야.

## 함정 4: Slip과 Mistake의 혼동

계획은 맞고 실행이 틀리면 slip이야. 계획이나 판단부터 틀리면 mistake야.

## 함정 5: Error와 Violation의 혼동

Error는 기본적으로 비의도적 실패이고, violation은 규칙에서 벗어나려는 의도가 있다는 차이가 있어.

## 암기 연결

**안 함은 생략, 잘못 함은 작위, 더 함은 불필요, 때가 틀리면 시간, 차례가 틀리면 순서**라고 연결하면 안정적으로 구분할 수 있어. 😊

# 9. 요약

1. **인간실수의 분류**는 사람을 비난하기 위한 것이 아니라 오류의 구조와 적절한 예방책을 찾기 위한 분석 과정이야.

2. **생략오류**는 해야 할 행동을 하지 않은 것이고, **작위오류**는 행동했지만 내용이나 대상이 잘못된 것이야.

3. **불필요행동오류**는 요구되지 않은 행동을 추가한 것이고, **시간오류**는 수행 시점이 부적절한 것이며, **순서오류**는 작업 단계의 배열이 바뀐 것이야.

4. 인지 과정에서는 인지오류, 판단오류, 행동오류를 구별할 수 있어.

5. **Slip**은 올바른 의도가 실행에서 빗나간 것이고, **lapse**는 기억 실패이며, **mistake**는 판단이나 계획 자체의 오류야.

6. **Violation**은 비의도적인 error와 달리 규칙 이탈에 의도가 존재해.

7. **형태적 특성**은 오류가 나타난 모습이지 원인 그 자체가 아니야. 같은 형태도 설계, 피로, 절차, 교육, 조직문화처럼 서로 다른 원인에서 발생할 수 있어.

8. 시험에서는 “안 함, 잘못 함, 더 함, 때가 틀림, 차례가 틀림”을 각각 생략, 작위, 불필요행동, 시간, 순서와 연결하면 좋아.
