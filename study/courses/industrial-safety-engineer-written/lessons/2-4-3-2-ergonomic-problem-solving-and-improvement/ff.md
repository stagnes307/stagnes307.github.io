## 1. 문제해결절차

근골격계질환 예방에서 **문제해결절차**는 작업자가 아프다고 호소한 뒤 임시로 휴식을 주는 데서 끝나는 과정이 아니야. 작업과 작업환경에서 부담을 만드는 원인을 체계적으로 찾아내고, 적합한 개선안을 시행한 다음, 실제로 부담이 감소했는지 확인하는 순환 과정이야.

핵심 흐름은 다음처럼 잡으면 돼.

**문제 인식 → 유해요인 파악 → 원인 분석 → 개선안 도출 → 대안 평가와 선정 → 개선안 실행 → 효과 평가 → 지속적 관리**

이 흐름은 일방통행이 아니라 **피드백이 있는 순환 구조**야. 효과 평가에서 문제가 남아 있으면 원인 분석이나 개선안 도출 단계로 돌아가야 해. 한 번 개선했다고 끝내면 새로운 자세 부담이나 생산상의 문제가 생겨도 발견하기 어렵거든.

### 1.1 문제 인식과 범위 설정

문제해결의 출발점은 “작업이 힘들다”는 막연한 느낌을 **관찰하고 측정할 수 있는 문제**로 바꾸는 거야.

문제는 다음과 같은 단서에서 발견할 수 있어.

- 작업자의 통증, 저림, 뻣뻣함과 피로 호소
- 동일 부서에서 반복되는 근골격계 증상
- 결근, 치료, 작업 전환 또는 산업재해의 증가
- 불편한 자세나 과도한 힘이 반복되는 작업
- 작업속도 저하, 불량 증가, 잦은 실수
- 작업자의 개선 제안과 현장 관리자의 관찰 결과

예를 들어 “포장작업이 힘들다”만으로는 개선 대상을 정하기 어려워. 이를 “허리 아래에 있는 상자에서 제품을 꺼내 어깨 높이의 컨베이어로 분당 8회 옮길 때 허리 굽힘과 어깨 들림이 반복된다”처럼 구체화해야 해.

이 단계에서 **누가, 어디에서, 어떤 작업을, 얼마나 자주, 얼마나 오래 수행하는가**를 명확히 설정하는 것이 중요해. 조사 범위가 지나치게 넓으면 원인을 놓치기 쉽고, 지나치게 좁으면 공정 전체의 상호작용을 보지 못할 수 있어.

### 1.2 유해요인 파악과 자료 수집

근골격계 부담을 만드는 대표적 유해요인은 다음과 같아.

| 유해요인 | 판단의 초점 | 현장 사례 |
|---|---|---|
| 반복동작 | 같은 관절과 근육을 짧은 주기로 반복 사용하는가 | 조립, 포장, 키보드 입력 |
| 부자연스러운 자세 | 허리 굽힘, 몸통 비틀림, 팔 들기, 손목 꺾임이 있는가 | 낮은 작업대, 머리 위 배선 |
| 과도한 힘 | 들기, 밀기, 당기기, 쥐기에 큰 힘이 필요한가 | 중량물 운반, 뻑뻑한 손공구 |
| 정적 자세 | 움직임 없이 같은 자세를 오래 유지하는가 | 현미경 검사, 장시간 서기 |
| 접촉 스트레스 | 신체 일부가 단단하거나 날카로운 면에 눌리는가 | 책상 모서리에 손목을 댐 |
| 진동 | 손·팔 또는 전신에 진동이 전달되는가 | 그라인더, 착암기, 지게차 |
| 환경·조직 요인 | 추위, 빠른 작업속도, 부족한 휴식이 부담을 키우는가 | 저온창고, 촉박한 생산주기 |

자료를 모을 때는 **작업자 면담**, **현장 관찰**, **사진과 동영상 분석**, **작업시간 측정**, **중량·거리·높이 측정**, **증상조사**, **기존 재해기록 검토**를 함께 사용해야 해. 하나의 방법에만 의존하면 실제 원인을 잘못 판단할 수 있어.

작업자 면담은 특히 중요해. 작업자는 정상운전뿐 아니라 고장 처리, 청소, 자재 부족, 물량 급증처럼 관찰자가 놓치기 쉬운 비정상 상황도 알고 있기 때문이야. 다만 주관적 호소만으로 결론을 내리지 말고 객관적 관찰과 측정으로 교차 확인해야 해.

### 1.3 원인 분석

유해요인을 찾았다고 해서 곧바로 해결책을 고르면 안 돼. 눈앞에 보이는 현상과 그 현상을 만든 **근본 원인**을 구분해야 해.

예를 들어 작업자의 허리 굽힘이 발견됐다고 해보자.

1. 직접 원인: 자재를 바닥 가까이에서 집는다.
2. 설비 원인: 자재 용기의 높이를 조절할 수 없다.
3. 공정 원인: 자재 공급 방향과 완제품 배출 방향이 반대다.
4. 관리 원인: 작업대 선정 시 작업자의 신체 치수를 고려하지 않았다.
5. 조직 원인: 설비 구매 과정에 작업자가 참여하지 않았다.

단순히 “허리를 펴고 작업하라”고 교육하면 직접 원인은 그대로 남아 있어. 반면 자재 높이와 공급 위치를 바꾸면 작업자가 의식적으로 자세를 교정하지 않아도 부담이 감소하지. 이것이 **원인 중심 개선**의 핵심이야.

원인 분석에는 다음과 같은 질문을 활용할 수 있어.

- 왜 이 자세가 필요한가?
- 왜 이 정도의 힘을 사용해야 하는가?
- 왜 같은 동작을 반복해야 하는가?
- 작업자마다 부담이 다른 이유는 무엇인가?
- 정상작업과 비정상작업의 조건은 어떻게 다른가?
- 설비, 공구, 배치, 작업방법, 작업시간 중 무엇이 부담을 만드는가?

원인과 결과를 정리할 때는 특성요인도, 공정 흐름도, 작업분석표, 연속적인 “왜?” 질문을 사용할 수 있어. 중요한 것은 분석 도구의 이름을 암기하는 데 그치지 않고 **사람·설비·재료·방법·환경·관리 조건을 함께 살피는 것**이야.

### 1.4 개선목표 설정

개선목표는 “작업을 편하게 만든다”처럼 모호하면 안 돼. 가능한 범위에서 구체적으로 정해야 해.

좋은 목표의 예시는 다음과 같아.

- 허리 굽힘이 발생하는 자재 취급 횟수를 줄인다.
- 어깨 높이보다 위에서 수행하는 작업을 제거한다.
- 1회 취급 중량을 낮춘다.
- 손목이 중립자세를 유지하도록 공구 손잡이를 변경한다.
- 장시간의 정적 자세를 줄이도록 작업과 휴식의 구성을 조정한다.
- 작업자의 불편도와 피로도를 개선 전보다 낮춘다.

목표에는 안전성뿐 아니라 **실행 가능성, 품질, 생산성, 유지관리성**도 반영해야 해. 그러나 생산성이 향상된다는 이유로 근골격계 부담을 다른 신체 부위나 다른 작업자에게 전가하면 올바른 개선이 아니야.

### 1.5 개선안 도출과 대안 선정

개선안은 처음부터 하나만 정하지 말고 여러 대안을 만든 뒤 비교해야 해. 일반적인 대안의 범주는 다음과 같아.

- **제거**: 불필요한 동작이나 중량물 취급 자체를 없앤다.
- **공학적 개선**: 설비, 공구, 작업대, 운반수단과 배치를 변경한다.
- **관리적 개선**: 작업시간, 휴식, 작업순환, 인원과 작업속도를 조정한다.
- **작업방법 개선**: 동작의 순서, 자재의 방향, 손의 사용방법을 바꾼다.
- **교육·훈련**: 개선된 설비와 작업방법을 올바르게 사용하도록 지원한다.
- **보조수단 적용**: 필요하면 적절한 보조기구나 보호수단을 사용한다.

대안을 비교할 때는 다음 기준을 사용해.

| 평가 기준 | 핵심 질문 |
|---|---|
| 위험 감소 효과 | 원인을 제거하거나 충분히 낮추는가 |
| 기술적 타당성 | 현장 조건에서 구현할 수 있는가 |
| 작업자 적합성 | 다양한 신체 치수와 능력을 수용하는가 |
| 부작용 | 다른 신체 부위나 공정에 새 위험을 만들지 않는가 |
| 품질·생산성 | 품질과 작업 흐름을 해치지 않는가 |
| 비용과 기간 | 비용 대비 효과가 적절하고 적시에 시행 가능한가 |
| 유지관리성 | 고장, 청소, 점검과 조절이 쉬운가 |
| 수용성 | 작업자가 실제로 지속해서 사용할 수 있는가 |

원칙적으로는 사람에게 주의를 요구하는 대책보다 **위험의 발생원과 작업조건을 바꾸는 공학적 개선**을 우선 검토해야 해. 교육은 필요하지만, 구조적으로 나쁜 작업을 교육만으로 해결하려 해서는 안 돼.

### 1.6 실행과 효과 평가

개선안이 선정되면 담당자, 일정, 예산, 적용 대상과 평가방법을 정해 실행해야 해. 가능하면 전면 적용 전에 시제품이나 일부 공정에서 시험해 보는 것이 좋아.

효과 평가는 반드시 **개선 전과 개선 후를 같은 기준으로 비교**해야 해.

- 자세의 각도와 지속시간이 감소했는가?
- 반복횟수와 힘의 요구량이 줄었는가?
- 작업자의 불편도와 피로도가 낮아졌는가?
- 작업시간, 품질, 불량과 사고 위험은 어떻게 변했는가?
- 새로운 끼임, 충돌, 미끄러짐 위험이 생기지 않았는가?
- 작업자가 개선안을 우회하거나 사용하지 않는 이유는 없는가?

개선 후 부담이 감소하지 않았다면 작업자의 탓으로 돌리기보다 **원인 분석과 대안 선정이 적절했는지** 다시 확인해야 해. 설비 변경으로 허리 부담은 줄었지만 손목 반복이 늘었다면 개선은 부분적으로 실패한 거야.

### 문제해결절차의 구체적 예시

한 작업자가 바닥의 15kg 상자를 허리 높이의 팔레트에 반복 적재한다고 해보자.

| 절차 | 적용 내용 |
|---|---|
| 문제 인식 | 작업자가 허리 통증을 호소하고 몸통 굽힘이 반복됨 |
| 유해요인 파악 | 중량물, 낮은 취급 높이, 반복동작, 몸통 비틀림 확인 |
| 원인 분석 | 상자가 바닥에 공급되고 팔레트 위치가 작업자 측면에 있음 |
| 개선안 도출 | 높이조절 리프트, 롤러 컨베이어, 팔레트 위치 변경, 상자 중량 분할 |
| 대안 선정 | 리프트와 팔레트 회전대를 조합하여 굽힘과 비틀림을 함께 감소 |
| 실행 | 시험 설치 후 작업자 교육과 높이 조절 기준 마련 |
| 효과 평가 | 허리 굽힘 빈도, 취급시간, 불편도와 새 위험을 전후 비교 |
| 지속 관리 | 설비 점검, 작업자 의견 수렴, 물량 변화 시 재평가 |

여기서 단순히 “두 사람이 함께 들어라”라고 지시하는 것은 관리적 대책이야. 도움이 될 수는 있지만 인원 확보와 협동 타이밍에 의존하지. 높이조절 리프트로 낮은 취급 위치를 없애는 방식은 원인에 직접 작용하는 공학적 개선이므로 일반적으로 더 안정적이야.

### 비교와 경계

**위험성평가**와 문제해결절차는 연결되지만 완전히 같은 말은 아니야. 위험성평가는 유해·위험요인을 파악하고 위험성을 추정·결정하여 감소대책을 수립·실행하는 넓은 관리 체계야. 근골격계 문제해결절차는 그 체계를 작업 자세, 힘, 반복성, 진동과 같은 인간공학적 부담에 적용한 과정으로 이해하면 좋아.

또한 **증상자 관리**와 **작업개선**도 구별해야 해. 증상자에게 치료나 작업 전환을 제공하는 것은 필요하지만, 유해한 작업조건을 그대로 두면 다른 작업자에게 같은 문제가 생길 수 있어. 예방의 중심은 개인의 치료만이 아니라 작업의 원인을 개선하는 데 있어.

### 시험 함정

1. **효과 평가는 마지막에 한 번만 한다?**  
   아니야. 시험 적용 중에도 확인하고, 정식 적용 후에도 추적 평가해야 해.

2. **교육은 가장 우선적인 근본 대책이다?**  
   아니야. 교육은 보완적 수단이며, 가능하면 유해요인의 제거와 공학적 개선을 먼저 검토해.

3. **작업자가 불편하지 않다고 하면 유해요인이 없다?**  
   아니야. 증상 호소와 별도로 자세, 힘, 반복성, 지속시간을 객관적으로 살펴야 해.

4. **개선 후 생산성이 높아졌다면 성공이다?**  
   반드시 그렇지는 않아. 근골격계 부담과 새로 발생한 안전·보건 위험까지 평가해야 해.

5. **원인 분석 없이 익숙한 대책을 바로 적용해도 된다?**  
   위험해. 같은 증상이라도 작업조건에 따라 원인이 다르므로 조사와 분석이 선행돼야 해.

## 2. 작업개선안의 원리 및 도출방법

**작업개선안의 원리 및 도출방법**은 작업자를 정해진 설비에 억지로 맞추는 것이 아니라, 작업을 사람의 신체적·인지적 특성에 맞도록 재설계하는 방법이야. 핵심은 “작업자가 조심하도록 만든다”가 아니라 **보통의 작업행동만으로도 안전하고 편안하게 수행할 수 있도록 조건을 바꾸는 것**이야.

### 2.1 작업개선안의 핵심 원리

#### 원리 1: 유해요인의 제거를 먼저 검토한다

가장 좋은 개선은 부담을 견디는 방법을 가르치는 것이 아니라 부담을 만드는 작업 자체를 없애는 거야.

예를 들어 무거운 부품을 작업자가 들어 검사대로 옮기는 대신, 생산라인에서 자동으로 검사 위치까지 이동하도록 만들 수 있어. 제거가 어렵다면 중량을 낮추거나 기계적 보조장치를 사용해 노출 수준을 줄여야 해.

#### 원리 2: 작업을 사람에게 맞춘다

작업대 높이, 조작 위치와 도달거리를 설비의 편의만으로 결정하면 안 돼. 작업자의 신체 치수, 근력, 관절 가동범위와 시야를 고려해야 해.

다양한 체격의 작업자가 사용하는 설비에는 **조절 가능성**이 중요해. 높이조절 작업대, 위치를 바꿀 수 있는 발판, 각도 조절식 부품함은 한 가지 고정 치수보다 다양한 작업자를 수용하기 쉬워.

#### 원리 3: 중립자세를 유지하게 한다

중립자세는 관절이 지나치게 굽거나 펴지거나 비틀리지 않은 자연스러운 상태야. 손목이 곧고, 팔꿈치가 몸 가까이에 있으며, 몸통의 과도한 굽힘과 비틀림이 없는 자세가 대표적이야.

중립자세는 근육과 관절에 걸리는 부담을 줄여. 손잡이 각도를 바꾸거나 작업물의 방향을 회전시키는 작은 변화만으로도 손목 꺾임과 몸통 비틀림을 줄일 수 있어.

#### 원리 4: 힘의 요구량을 줄인다

중량을 분할하고, 운반거리를 줄이며, 마찰을 낮추고, 적절한 손잡이를 제공하면 필요한 힘을 줄일 수 있어.

예를 들어 바퀴가 작은 운반대는 바닥 요철에서 큰 미는 힘을 요구할 수 있어. 적합한 직경의 바퀴를 선택하고 정비하면 단순히 “올바르게 밀라”고 교육하는 것보다 직접적인 효과가 있어.

#### 원리 5: 반복과 지속시간을 줄이고 회복기회를 준다

반복동작의 위험은 동작 횟수만으로 결정되지 않아. 사용하는 힘, 자세, 작업 지속시간과 회복시간이 함께 작용해.

자동화, 공구 개선, 양손 작업의 균형, 작업순환과 적절한 휴식으로 동일 조직의 누적부담을 줄일 수 있어. 다만 작업순환은 서로 다른 이름의 작업을 번갈아 수행하는 것만으로 충분하지 않아. 두 작업이 같은 근육과 관절을 사용한다면 실질적인 회복이 일어나지 않기 때문이야.

#### 원리 6: 발생원에서 개선한다

위험원과 작업조건에 직접 작용하는 대책은 작업자의 기억이나 주의에 덜 의존해.

예를 들어 높은 선반에서 물건을 꺼내지 말라고 교육하는 것보다 사용 빈도가 높은 물품을 허리와 어깨 사이 높이에 배치하는 편이 안정적이야. 작업자가 바뀌거나 바쁜 상황에서도 효과가 유지되기 때문이야.

#### 원리 7: 한 부담을 다른 부담으로 옮기지 않는다

자동화나 보조기구가 언제나 완전한 해결책은 아니야. 중량물 취급을 자동화했지만 작은 버튼 조작을 매우 빠르게 반복하게 되면 새로운 상지 부담이 생길 수 있어.

따라서 개선안은 국소 작업만 보지 말고 투입부터 산출까지 전체 흐름과 정상·비정상 상황을 함께 평가해야 해.

#### 원리 8: 작업자의 참여를 보장한다

작업자는 실제 작업의 변동과 어려움을 가장 잘 알고 있어. 설계 단계에서 작업자가 참여하면 실행 가능성이 높아지고, 책상 위에서는 보이지 않던 문제를 발견할 수 있어.

다만 참여란 개선 책임을 작업자에게 떠넘기는 것이 아니야. 사업장과 관리자는 필요한 자원과 기술적 지원을 제공하고, 작업자의 경험을 설계 정보로 활용해야 해.

### 2.2 개선안의 유형

| 유형 | 개선 대상 | 예시 | 특징 |
|---|---|---|---|
| 공학적 개선 | 설비·공구·작업대·배치 | 높이조절대, 리프트, 공구 손잡이 변경 | 발생원과 작업조건에 직접 작용 |
| 관리적 개선 | 시간·인원·작업조직 | 휴식, 작업순환, 작업속도 조정 | 비교적 신속하지만 운영 준수에 의존 |
| 작업방법 개선 | 동작·순서·공정 흐름 | 물품 위치 변경, 불필요한 동작 제거 | 공정 분석과 표준화가 중요 |
| 교육·훈련 | 지식·사용방법 | 보조장치 사용법, 개선 작업방법 훈련 | 다른 개선책을 보완 |
| 개인별 조치 | 증상과 능력 차이 | 업무 적합성 검토, 작업 전환 | 집단적 예방대책을 대체할 수 없음 |

여기서 시험에 자주 나오는 경계는 **공학적 개선과 관리적 개선의 구별**이야.

작업대 높이를 조절하는 것은 설비 조건을 바꾸므로 공학적 개선이야. 작업시간을 줄이거나 작업자를 교대하는 것은 작업조직을 바꾸므로 관리적 개선이야. 둘을 병행할 수 있지만, 관리적 개선만으로 구조적인 부담을 장기간 방치해서는 안 돼.

### 2.3 개선안 도출방법

#### 1단계: 작업을 요소별로 분해한다

작업을 준비, 이동, 집기, 운반, 위치 맞춤, 조립, 검사, 배출과 정리 같은 요소로 나눠. 각 요소에서 자세, 힘, 반복성, 접촉, 진동과 지속시간을 확인하면 개선 지점을 명확히 볼 수 있어.

#### 2단계: 목적과 수단을 구분한다

현재의 작업방법을 반드시 유지해야 하는 것으로 가정하지 말고 다음 질문을 던져야 해.

- 이 작업요소는 왜 필요한가?
- 삭제하거나 다른 공정과 결합할 수 있는가?
- 순서를 바꿀 수 있는가?
- 작업장소나 자재 방향을 바꿀 수 있는가?
- 사람 대신 기계가 수행할 수 있는가?
- 더 적은 힘과 더 자연스러운 자세로 같은 목적을 달성할 수 있는가?

이 과정은 **제거, 결합, 재배열, 단순화**라는 관점으로 정리할 수 있어.

#### 3단계: 유해요인별 아이디어를 만든다

| 발견된 문제 | 도출 방향 |
|---|---|
| 바닥의 물품을 반복해서 집음 | 물품 높이 상승, 경사식 용기, 자동 공급장치 |
| 어깨 위 작업 | 작업물 높이 하강, 작업자 발판, 공구 연장장치 |
| 몸통 비틀림 | 물품을 정면에 배치, 회전대 설치, 흐름 방향 변경 |
| 과도한 중량 | 중량 분할, 리프트·호이스트 사용, 운반거리 단축 |
| 손목 꺾임 | 공구 손잡이 각도 변경, 작업물 고정 방향 조절 |
| 높은 반복성 | 공정 자동화, 동작 삭제, 작업속도 조정, 실질적 작업순환 |
| 접촉 스트레스 | 모서리 완화, 패드 적용, 지지면 확대 |
| 진동 | 저진동 공구, 정비, 방진 구조, 노출시간 관리 |

#### 4단계: 여러 대안을 조합한다

하나의 대책만으로 복합 유해요인을 해결하기 어려울 수 있어. 예를 들어 중량물 취급에서는 중량 감소, 높이 조절, 수평거리 단축, 운반보조기구와 작업방법 개선을 조합할 수 있어.

단, 대책을 많이 적용한다고 무조건 좋은 것은 아니야. 서로 방해하거나 작업을 복잡하게 만들어 사용률을 낮출 수 있으므로 시제품과 현장 시험이 필요해.

#### 5단계: 우선순위를 정한다

우선순위는 단순히 가장 싼 개선안부터 선택하는 것이 아니야. 일반적으로 다음 요소를 종합해 판단해.

**위험의 크기와 노출빈도 → 피해의 심각성 → 개선 효과 → 실행 가능성 → 필요한 시간과 비용 → 작업자 수용성 → 새 위험의 발생 가능성**

즉시 제거할 수 있는 중대한 위험은 신속히 조치해야 해. 장기 설비개선에 시간이 필요하다면 임시 관리대책을 함께 시행하되, 임시조치가 영구대책으로 굳어지지 않도록 일정과 책임자를 정해야 해.

#### 6단계: 현장 검증과 표준화를 실시한다

개선안은 도면이나 회의만으로 완성되지 않아. 실제 작업자가 시험해 보고, 다양한 체격과 작업조건에서도 사용할 수 있는지 확인해야 해.

검증이 끝나면 조절방법, 점검주기, 안전한 사용절차와 비정상 상황의 대응방법을 표준화해야 해. 표준화하지 않으면 시간이 지나면서 장치가 사용되지 않거나 원래 작업방법으로 되돌아갈 수 있어.

### 작업개선안 도출의 구체적 예시

조립공정에서 작업자가 오른쪽 뒤편의 부품함에서 부품을 꺼내 정면 작업물에 끼우는 동작을 분당 12회 반복한다고 해보자.

**문제 분석**

- 오른팔을 뒤로 뻗는 동작이 반복된다.
- 몸통을 오른쪽으로 비튼다.
- 부품함이 깊어질수록 도달거리가 증가한다.
- 작업속도가 빨라 회복시간이 부족하다.

**도출 가능한 개선안**

1. 부품함을 작업자 정면의 정상 작업영역에 배치한다.
2. 부품이 앞쪽으로 자연스럽게 이동하는 경사식 용기를 사용한다.
3. 용기의 깊이를 줄이거나 분할 용기를 사용한다.
4. 양손의 작업량을 균형 있게 재배치한다.
5. 공급장치를 이용해 필요한 수량을 가까운 위치로 보낸다.
6. 작업속도와 회복시간을 함께 검토한다.

**선정 논리**

단순 작업순환보다 부품함 위치와 구조를 변경하는 대안이 우선이야. 작업순환은 노출시간을 나눌 뿐 비틀림과 과도한 도달이라는 원인을 제거하지 못하기 때문이야. 부품함을 정면 가까이에 두고 경사식 구조로 바꾸면 도달거리와 몸통 비틀림을 동시에 줄일 수 있어.

**효과 확인**

개선 전후의 팔 도달거리, 몸통 비틀림 빈도, 작업자 불편도, 조립시간과 부품 누락을 비교해. 부품함이 너무 가까워 무릎 공간을 침범하거나 통로를 막는 새 문제가 생기지 않았는지도 확인해야 해.

### 시험 함정

1. **작업순환은 언제나 근골격계 부담을 감소시킨다?**  
   아니야. 순환하는 작업들이 같은 신체 부위를 사용하면 누적부담이 계속될 수 있어.

2. **개인보호구를 사용하면 인간공학적 개선이 완료된다?**  
   아니야. 개인보호구나 보조수단은 발생원 제거와 공학적 개선을 대체하지 못해.

3. **평균 신체 치수에 맞추면 모든 작업자에게 적합하다?**  
   아니야. 다양한 체격을 고려하고 필요하면 조절 가능한 설계를 사용해야 해.

4. **중량을 줄이면 자세와 반복성은 평가하지 않아도 된다?**  
   아니야. 가벼운 물체도 불량한 자세와 높은 반복성이 결합되면 부담을 만들 수 있어.

5. **교육 후에도 작업자가 불편한 자세를 취하면 개인의 부주의다?**  
   단정하면 안 돼. 설비 배치나 작업속도가 그 자세를 강제하는지 먼저 분석해야 해.

6. **개선안은 비용이 가장 낮은 대안을 우선 선정한다?**  
   아니야. 위험 감소 효과와 새 위험, 실행 가능성, 유지관리성을 함께 평가해야 해.

## 3. 두 주제의 연결 구조

**문제해결절차**가 전체 항로라면 **작업개선안의 원리 및 도출방법**은 그 항로에서 실제 대책을 설계하는 엔진이라고 볼 수 있어 😊

| 문제해결절차의 단계 | 작업개선안과의 연결 |
|---|---|
| 문제 인식 | 증상과 작업상 부담의 존재를 확인 |
| 유해요인 파악 | 자세, 힘, 반복성, 진동과 지속시간을 조사 |
| 원인 분석 | 부담을 만드는 설비·배치·방법·관리 조건을 분해 |
| 개선안 도출 | 제거, 공학적 개선, 관리적 개선과 작업방법 개선을 구상 |
| 평가·선정 | 효과, 타당성, 부작용, 비용과 수용성을 비교 |
| 실행 | 담당자와 일정을 정하고 시험 적용 |
| 효과 평가 | 개선 전후의 부담, 증상, 품질과 새 위험을 비교 |
| 지속 관리 | 표준화, 점검, 작업자 의견과 변화 조건을 재검토 |

암기할 때는 **찾고 → 분석하고 → 여러 대안을 만들고 → 우선순위를 정해 실행하고 → 검증한다**는 흐름을 중심에 두면 돼.

## 6. 요약

- **문제해결절차**는 문제 인식, 유해요인 파악, 원인 분석, 개선안 도출, 대안 선정, 실행, 효과 평가와 지속적 관리로 이어지는 순환 과정이야.
- 증상만 처리하지 말고 작업 자세, 힘, 반복성, 지속시간, 진동, 설비 배치와 작업조직의 원인을 함께 분석해야 해.
- **작업개선안의 원리 및 도출방법**에서는 작업을 사람에게 맞추고, 중립자세를 유지하며, 힘·반복·지속시간과 과도한 도달을 줄이는 것이 핵심이야.
- 교육과 작업순환은 유용하지만 구조적인 유해요인을 없애는 공학적 개선을 대신할 수 없어.
- 개선안은 제거, 결합, 재배열, 단순화의 질문을 활용해 여러 개를 도출한 뒤 위험 감소 효과, 실행 가능성, 부작용, 비용과 작업자 수용성을 비교해 선정해야 해.
- 개선 후에는 반드시 전후 조건을 비교하고, 새로운 위험이나 다른 신체 부위로의 부담 전가가 없는지 확인해야 해.
- 시험에서는 **공학적 개선과 관리적 개선의 구별**, **작업순환의 한계**, **효과 평가의 필요성**, **발생원 중심 개선**을 특히 조심하면 돼. 조금 복잡해 보여도 “사람을 억지로 맞추지 말고 작업의 원인을 바꾼다”는 중심축을 잡으면 흔들리지 않아 😊
