## 1. 설계도에 따른 안전지침

### 1.1 정의와 목적

**설계도에 따른 안전지침**은 설비 도면, 배치도, 조립도, 전기·유압·공압 회로도, 장비사양서와 제조자의 사용설명서를 검토하여 위험요인을 찾고, 이를 방호장치·안전거리·작업방법·점검기준으로 구체화한 지침이야.

핵심은 도면을 단순히 읽는 데 있지 않아. 도면에 표현된 구조와 에너지의 흐름을 보고 사람이 어디에서 끼이거나, 절단되거나, 감전되거나, 예상하지 못한 작동에 노출될 수 있는지 판단해야 해.

설계단계에서 위험을 제거하면 운전단계에서 작업자의 주의력에 덜 의존하게 돼. 그래서 안전대책의 우선순위는 일반적으로 다음과 같이 이해하면 좋아.

1. 위험요인의 제거 또는 대체
2. 구조와 설계를 통한 위험 감소
3. 방호장치와 안전장치 적용
4. 경고표지와 안전작업절차 마련
5. 교육 및 개인보호구 적용

위쪽 조치일수록 사람의 행동에 덜 의존하고, 아래쪽 조치일수록 작업자가 매번 정확하게 행동해야 한다는 한계가 있어.

### 1.2 설계도에서 확인할 안전정보

| 검토 자료 | 확인할 내용 | 대표 위험 |
|---|---|---|
| 설비 배치도 | 기계 간 간격, 통로, 비상대피 경로, 작업공간, 정비공간 | 충돌, 협착, 대피 지연 |
| 조립도와 상세도 | 회전체, 왕복부, 절단부, 금형부, 돌출부의 위치 | 말림, 끼임, 절단 |
| 전기 회로도 | 전원 차단점, 접지, 인터록, 비상정지 회로 | 감전, 오작동, 불시 기동 |
| 유압·공압 회로도 | 잔류압력, 축압기, 실린더 낙하, 차단밸브 | 분출, 낙하, 협착 |
| 배관계장도 | 물질 종류, 흐름 방향, 압력, 온도, 차단 위치 | 누출, 화재, 폭발, 화상 |
| 장비사양서 | 허용하중, 속도, 압력, 온도, 사용환경 | 과부하, 파손, 기능 상실 |
| 제조자 설명서 | 설치·운전·점검·정비·폐기 조건 | 오사용, 부적절한 정비 |

도면 하나만 보면 위험을 놓칠 수 있어. 예를 들어 기계 배치도에는 작업공간이 충분해 보여도 전기 회로도를 확인하면 주전원 차단기가 정비자가 접근하기 어려운 위치에 있을 수 있어. 따라서 **구조, 배치, 에너지, 작업행동을 서로 겹쳐서 검토**해야 해.

### 1.3 안전지침을 만드는 기본 원리

#### ① 위험영역을 식별해

위험영역은 근로자가 기계의 운동부, 가공점, 동력전달부 또는 방출되는 물질과 접촉하여 다칠 수 있는 공간이야.

도면에서 다음 위치를 우선적으로 표시해야 해.

1. 회전체와 고정부 사이
2. 두 회전체가 맞물리는 부분
3. 왕복운동부와 고정 구조물 사이
4. 프레스의 금형 사이
5. 벨트와 풀리가 접하는 부분
6. 절삭공구와 가공물이 접촉하는 부분
7. 고온·고압 물질이 누출될 수 있는 부분
8. 중량물이 이동하거나 낙하할 수 있는 부분

위험점만 표시하고 끝내면 부족해. 작업자가 재료를 공급하고, 완성품을 꺼내고, 청소하며, 막힘을 제거하는 동선까지 검토해야 해.

#### ② 정상 상태와 비정상 상태를 분리해

정상운전만 안전한 설계는 충분하지 않아. 설비는 정지, 고장, 정전, 재가동, 시운전, 청소 및 정비 상태에서도 위험할 수 있어.

특히 다음 질문이 중요해.

1. 정전 후 전원이 복구되면 자동으로 다시 움직이는가?
2. 방호문을 열었을 때 위험한 동작이 정지하는가?
3. 정지 후에도 관성으로 회전체가 계속 움직이는가?
4. 전원을 차단해도 유압·공압·중력 에너지가 남는가?
5. 센서 하나가 고장 나면 안전기능 전체가 상실되는가?
6. 비상정지를 해제하면 즉시 재기동되는가?

좋은 설계는 고장이 발생하지 않는다는 가정에 기대지 않아. 고장이 발생해도 위험한 결과로 이어지지 않도록 만드는 **고장 안전 개념**이 중요해.

#### ③ 안전기능을 도면에 대응시켜

안전기능에는 방호덮개, 방호울, 인터록, 비상정지장치, 과부하방지장치, 압력방출장치, 낙하방지장치와 접근감지장치가 포함돼.

| 위험 | 우선 검토할 안전기능 | 확인 포인트 |
|---|---|---|
| 회전체 접촉 | 고정식 방호덮개 | 쉽게 제거되거나 틈으로 접근할 수 없는가 |
| 방호문 개방 중 작동 | 인터록 | 문을 열면 위험 동작이 정지하는가 |
| 예기치 않은 기동 | 에너지 차단·잠금 | 작업자가 차단 상태를 직접 통제할 수 있는가 |
| 과압 | 안전밸브·압력방출장치 | 설정압력과 배출 방향이 적절한가 |
| 중량부 낙하 | 기계식 지지대·체크밸브 | 동력 상실 시에도 낙하를 막는가 |
| 긴급상황 | 비상정지장치 | 쉽게 접근 가능하고 명확하게 식별되는가 |

**비상정지장치는 기본 방호수단을 대신하지 않아.** 비상정지는 위험을 발견한 사람이 조작해야 하므로 반응시간과 접근성에 영향을 받아. 따라서 먼저 접촉 자체를 막고, 비상정지는 보완수단으로 두는 것이 원칙이야.

### 1.4 설계도 검토 절차

설계도에 따른 안전지침은 다음 흐름으로 작성할 수 있어.

**도면과 사양 확인 → 사용 목적 확인 → 작업 단계 분해 → 위험원 식별 → 위험성 추정 → 안전대책 선정 → 도면 반영 확인 → 현장 검증 → 변경관리**

작업 단계는 설치, 정상운전, 재료 공급, 제품 배출, 조정, 청소, 점검, 고장처리, 정비와 폐기로 나누어 살펴봐야 해.

위험성은 단순히 위험원이 존재하는지만 보는 것이 아니야. 사고가 발생할 가능성과 결과의 중대성을 함께 고려해야 해. 위험성이 허용 가능한 수준이 아니면 설계를 수정하거나 추가적인 방호조치를 적용해야 해.

마지막에는 실제 설비와 도면이 일치하는지 확인해야 해. 도면상 방호울이 설치되어 있어도 현장에서 작업 편의를 이유로 철거됐다면 안전지침은 실효성을 잃어.

### 1.5 구체적인 예시

자동 프레스 설비의 조립도에는 금형이 상하로 움직이고, 작업자가 전면에서 소재를 투입하도록 표시되어 있다고 해보자.

먼저 금형 사이는 신체가 끼일 수 있는 위험영역이야. 작업자가 손으로 소재를 넣는 방식이라면 위험점에 직접 접근하게 돼. 따라서 소재의 자동공급, 위험영역의 방호, 접근감지 또는 양수조작 방식과 같은 대책을 검토해야 해.

정비할 때는 전원만 끄는 것으로 충분하지 않을 수 있어. 슬라이드의 중량, 플라이휠의 관성, 공압계통의 잔류압력이 남아 있기 때문이야. 이때는 에너지원을 차단하고, 저장에너지를 해소하며, 움직이는 부분을 기계적으로 지지한 후 무에너지 상태를 확인해야 해.

즉, 도면 검토는 “위험한 부분이 어디인가?”에서 끝나지 않고 “누가, 언제, 어떤 이유로 그곳에 접근하는가?”까지 이어져야 해.

### 1.6 비교와 경계

| 잘못된 접근 | 올바른 접근 |
|---|---|
| 정상운전 상태만 검토한다 | 설치부터 폐기까지 전 생애주기를 검토한다 |
| 도면에 안전장치가 표시되어 있으므로 안전하다고 본다 | 안전장치의 기능, 고장 시 상태와 우회 가능성을 확인한다 |
| 전원을 끄면 모든 에너지가 사라진다고 본다 | 전기·압력·열·중력·탄성·관성 에너지를 각각 확인한다 |
| 개인보호구를 우선 선정한다 | 제거와 공학적 방호를 먼저 검토한다 |
| 설계 변경을 현장 편의로 처리한다 | 변경 전 위험성을 재평가하고 도면과 절차를 함께 개정한다 |

### 1.7 시험 함정

😠 여기서 자주 틀리는 부분이 있어.

1. **비상정지장치가 방호장치를 대체한다**는 표현은 잘못된 판단이야.
2. **주전원 차단만으로 모든 에너지가 제거된다**는 표현도 위험해. 잔류압력과 중력에너지를 별도로 확인해야 해.
3. **도면 검토는 정상운전만을 대상으로 한다**는 표현도 틀려. 청소·조정·정비·고장처리 같은 비정상 작업까지 포함해야 해.
4. 안전대책을 선택할 때는 일반적으로 **위험 제거와 공학적 대책이 교육이나 개인보호구보다 우선**해.
5. 설비가 변경되면 도면, 위험성평가와 작업절차도 함께 재검토해야 해.

## 2. 특수 작업의 조건

### 2.1 정의와 판단 기준

**특수 작업의 조건**은 정상적인 생산운전과 다른 위험한 작업을 실시하기 전에 충족해야 하는 인적·기술적·관리적 요건이야.

작업 이름만으로 특수 작업 여부를 판단하면 안 돼. 같은 청소 작업이라도 완전히 정지된 설비 외부를 닦는 것과 방호장치를 열고 내부의 회전체 가까이에서 이물질을 제거하는 것은 위험성이 전혀 달라.

다음 특징이 있으면 특수 작업으로 관리할 필요성이 커져.

1. 정상 방호기능을 해제하거나 우회해야 하는 작업
2. 위험구역 내부로 사람이 들어가는 작업
3. 설비의 저장에너지에 노출되는 작업
4. 화재·폭발·질식·중독 위험이 있는 작업
5. 고소, 굴착, 양중과 같은 중대위험 작업
6. 여러 작업팀이 동시에 영향을 주고받는 작업
7. 운전 중 조정 또는 시험처럼 정지와 가동이 반복되는 작업
8. 작업조건이 수시로 변하여 표준절차만으로 통제하기 어려운 작업

특수 작업의 본질은 “평소보다 어려운 일”이 아니라 **기존의 정상운전 통제가 약화되거나 새로운 위험이 추가되는 일**이야.

### 2.2 작업을 허용하기 위한 공통 조건

#### ① 사전 위험성 확인

작업의 범위, 장소, 설비 상태, 작업인원, 사용도구, 주변 공정과 예상되는 에너지를 먼저 확인해야 해.

위험성평가는 작업자가 실제로 수행할 순서를 기준으로 해야 해. “탱크 정비”처럼 큰 이름만 적는 대신 개방, 환기, 내부 진입, 부품 분리, 용접, 재조립과 시운전으로 나누어 위험을 확인하는 방식이 좋아.

#### ② 작업계획과 책임체계

작업계획에는 다음 사항이 명확해야 해.

1. 작업 대상과 범위
2. 작업 순서와 방법
3. 작업책임자와 작업자
4. 지휘·연락 방법
5. 위험요인과 통제조치
6. 사용 장비와 개인보호구
7. 출입통제 범위
8. 이상 발생 시 작업중지 기준
9. 비상조치와 구조 방법
10. 작업 종료 후 복구·인계 방법

책임자가 있다는 것만으로는 부족해. 누가 에너지를 차단하고, 누가 작업 시작을 승인하며, 누가 복구 전 인원을 확인하는지가 구체적으로 정해져야 해.

#### ③ 에너지 격리와 무에너지 확인

기계 내부에서 청소·점검·수리 작업을 할 때 가장 중요한 조건 중 하나가 **예기치 않은 기동의 방지**야.

기본 흐름은 다음과 같아.

**작업 대상 확인 → 정상 정지 → 에너지원 분리 → 잠금·표지 → 저장에너지 해소 → 무에너지 상태 확인 → 작업 수행 → 인원·공구 확인 → 잠금 해제 → 방호 복구 → 시험운전과 인계**

차단해야 할 에너지는 전기에 한정되지 않아.

| 에너지 종류 | 위험 예시 | 통제 예시 |
|---|---|---|
| 전기 | 감전, 모터 기동 | 차단, 잠금, 무전압 확인 |
| 유압·공압 | 실린더 이동, 유체 분출 | 밸브 차단, 잔압 제거 |
| 중력 | 상승부·중량물 낙하 | 하강, 받침대 설치 |
| 탄성 | 압축 스프링의 복원 | 장력 해제, 기계적 고정 |
| 열 | 고온 표면, 증기 | 냉각, 격리, 온도 확인 |
| 화학 | 유해물질 누출 | 배출, 세정, 환기, 농도 확인 |
| 관성 | 회전체의 계속 회전 | 완전 정지 확인, 회전 방지 |

스위치를 끈 상태와 에너지가 격리된 상태는 같지 않아. 제어용 버튼은 회로 고장이나 다른 사람의 조작으로 다시 켜질 수 있기 때문이야.

#### ④ 작업허가와 현장 확인

화기작업, 밀폐공간 작업 또는 기존 공정에 큰 영향을 미치는 정비작업은 작업허가 절차를 통해 시작 조건을 확인해야 해.

작업허가서는 단순한 서명이 아니야. 현장의 위험상태를 확인하고, 필요한 조치가 실제로 이행됐을 때 작업을 허용하는 통제수단이야. 작업 장소·범위·시간·조건이 달라지면 기존 허가가 그대로 유효하다고 가정하지 말고 재검토해야 해.

#### ⑤ 적격 작업자와 의사소통

특수 작업자는 작업방법, 설비의 위험성, 비상정지 방법과 개인보호구 사용법을 이해해야 해. 작업책임자는 작업 전에 역할과 금지사항을 공유하고, 작업 중 조건이 바뀌면 즉시 작업을 중지시켜야 해.

설비 내부 작업자와 외부 감시자, 운전실과 정비팀처럼 서로 떨어진 인원이 협력할 때는 연락수단과 신호체계를 미리 정해야 해.

### 2.3 대표적인 특수 작업별 핵심 조건

| 작업 유형 | 주요 위험 | 핵심 조건 |
|---|---|---|
| 정비·청소·막힘 제거 | 불시 기동, 잔류에너지 | 정지, 격리, 잠금·표지, 무에너지 확인 |
| 시운전·조정 | 방호 미완성, 반복 기동 | 제한된 접근, 지휘자 지정, 단계별 시험, 비상정지 확보 |
| 화기작업 | 불꽃, 복사열, 가연물 착화 | 가연물 제거·격리, 화재감시, 소화수단, 작업 후 확인 |
| 밀폐공간 작업 | 산소 결핍, 유해가스, 구조 곤란 | 출입통제, 환기, 농도 확인, 감시인, 구조계획 |
| 고소작업 | 추락, 낙하물 | 안전한 작업발판, 추락방호, 출입통제 |
| 양중작업 | 낙하, 충돌, 협착 | 하중과 장비능력 확인, 신호수, 이동경로 통제 |
| 전기작업 | 감전, 아크 | 전원 격리, 무전압 확인, 충전부 방호 |
| 동시작업 | 상호 간섭, 오조작 | 작업 간 영향 검토, 통합지휘, 일정·구역 조정 |

각 작업에는 관계 법령과 사업장 절차에 따른 세부 요건이 추가될 수 있어. 시험에서는 개별 숫자를 무리하게 암기하기 전에 **위험과 통제의 대응관계**를 정확히 잡는 게 중요해.

### 2.4 구체적인 예시

컨베이어 내부에 끼인 자재를 제거하는 작업을 생각해보자.

작업자가 정지 버튼만 누르고 내부로 들어가면 다른 작업자가 설비를 다시 가동할 수 있어. 또한 경사 구간의 자재가 중력으로 미끄러지거나, 장력이 걸린 벨트가 갑자기 움직일 수도 있어.

따라서 정상 정지 후 주전원을 격리하고 잠금·표지를 해야 해. 남아 있는 기계적 장력과 중력에너지를 해소하거나 고정한 뒤, 현장 조작부에서 기동되지 않는지 확인해야 해. 작업구역의 출입을 통제하고 내부 작업자와 외부 책임자가 연락할 방법도 정해야 해.

작업이 끝나면 내부에 사람이 남아 있지 않은지, 공구와 임시 지지물이 제거됐는지 확인해야 해. 방호장치를 복구한 다음 제한된 조건에서 시험운전하고 운전 담당자에게 인계해야 해.

이 사례에서 가장 중요한 점은 **정지 버튼을 누르는 행위가 아니라, 위험에너지가 다시 작용하지 못하도록 통제하는 상태**야.

### 2.5 작업조건 변경과 작업중지

특수 작업은 허가를 받았다는 이유로 끝까지 계속해야 하는 일이 아니야. 다음과 같은 변화가 생기면 작업을 멈추고 재평가해야 해.

1. 작업 범위나 방법이 변경된 경우
2. 새로운 설비나 화학물질이 투입된 경우
3. 환기·차단·방호 조건이 상실된 경우
4. 예상하지 못한 압력, 누출, 진동 또는 소음이 발생한 경우
5. 통신이 두절되거나 감시자가 자리를 비운 경우
6. 다른 공정의 가동으로 위험이 추가된 경우
7. 작업자가 위험을 인지하거나 절차 이행이 불가능한 경우
8. 교대나 장시간 중단으로 작업 상태를 다시 확인해야 하는 경우

작업중지는 실패가 아니야. 위험조건이 바뀌었는데도 관성적으로 작업을 계속하는 것이 실패에 가까워.

### 2.6 비교와 경계

| 혼동하기 쉬운 개념 | 구별 기준 |
|---|---|
| 정지와 격리 | 정지는 동작을 멈추는 것이고, 격리는 에너지 전달 경로를 끊는 것이야 |
| 격리와 무에너지 확인 | 격리 조치를 했더라도 실제로 에너지가 남지 않았는지 확인해야 해 |
| 작업계획과 작업허가 | 작업계획은 수행 방법을 설계하고, 작업허가는 현장조건 충족을 확인해 시작을 승인해 |
| 감시와 지휘 | 감시는 상태를 관찰하고, 지휘는 작업 순서와 행동을 통제해 |
| 개인보호구와 위험 제거 | 개인보호구는 노출 결과를 줄이는 수단이고, 위험 제거는 노출 가능성 자체를 없애는 수단이야 |
| 정상운전과 특수 작업 | 정상 방호 아래 반복 수행되는가, 방호 해제·내부 진입·에너지 노출이 수반되는가로 구별해 |

### 2.7 시험 함정

😒 다음 문장은 특히 조심해야 해.

1. **설비를 정지했으므로 즉시 정비할 수 있다**는 판단은 틀릴 수 있어. 격리와 저장에너지 해소가 필요해.
2. **작업허가서에 서명했으므로 현장 확인은 생략할 수 있다**는 판단은 잘못이야.
3. **숙련자는 별도의 작업계획이나 연락체계가 없어도 된다**는 표현도 틀려.
4. **개인보호구를 지급하면 공학적 방호를 생략할 수 있다**는 표현은 위험해.
5. **작업조건이 변경되어도 최초 허가는 계속 유효하다**고 단정하면 안 돼.
6. **작업 종료는 실제 작업이 끝난 순간**이라고만 보면 부족해. 인원·공구 확인, 방호 복구, 잠금 해제와 인계까지 포함해야 해.

## 3. 두 주제의 연결 구조

설계도에 따른 안전지침과 특수 작업의 조건은 별개처럼 보이지만 실제로는 한 흐름이야.

**설계도**는 위험한 구조와 에너지의 위치를 알려줘.  
**안전지침**은 그 위험을 정상운전 중 어떻게 통제할지 정해.  
**특수 작업 조건**은 정비나 시운전처럼 정상 방호가 약해지는 순간에 추가 통제를 제공해.

| 단계 | 핵심 질문 | 결과물 |
|---|---|---|
| 설계 검토 | 위험부와 에너지원은 어디에 있는가? | 위험영역·차단점 표시 |
| 안전대책 설계 | 위험을 제거하거나 접근을 막을 수 있는가? | 방호·인터록·안전거리 |
| 작업절차 작성 | 사람이 어떤 순서로 행동해야 하는가? | 표준 작업방법 |
| 특수 작업 판단 | 정상 방호가 해제되거나 새 위험이 생기는가? | 특별 통제 필요성 |
| 작업 전 확인 | 허가조건과 현장상태가 일치하는가? | 작업 승인 또는 중지 |
| 작업 후 복구 | 사람·공구·방호상태가 정상인가? | 시험운전과 인계 |

결국 안전은 도면 속 선에서 시작해 현장의 행동으로 완성돼. 도면과 실제 설비가 다르거나, 절차와 실제 작업이 다르면 안전의 연결고리가 끊어지는 거야.

## 4. 확인 문제

### 문제 1

설계도 검토에 따른 안전대책으로 가장 적절하지 않은 것은?

1. 위험원을 가능한 한 설계단계에서 제거한다.
2. 정상운전뿐 아니라 청소와 정비 상태도 검토한다.
3. 비상정지장치를 설치했으므로 위험점 방호를 생략한다.
4. 설계 변경 시 위험성을 다시 평가한다.

### 문제 2

기계 내부의 막힘을 제거하기 전 가장 적절한 조치는?

1. 정지 버튼만 누르고 즉시 진입한다.
2. 에너지원을 격리하고 저장에너지를 해소한 후 상태를 확인한다.
3. 동료에게 구두로 알린 뒤 방호장치를 제거한다.
4. 개인보호구를 착용했으므로 운전 중 작업한다.

### 문제 3

특수 작업의 작업허가에 관한 설명으로 옳은 것은?

1. 서류에 서명하는 행위만으로 현장점검을 대신한다.
2. 한 번 발급되면 작업 장소와 조건이 변해도 계속 유효하다.
3. 작업 시작 전 통제조치의 실제 이행 여부를 확인하는 수단이다.
4. 숙련자에게는 적용할 필요가 없다.

### 문제 4

설계도에 따른 안전지침과 특수 작업의 조건을 연결한 설명으로 가장 적절한 것은?

1. 설계도는 정상 생산량만을 확인하는 자료다.
2. 특수 작업은 작업자의 숙련도만으로 통제한다.
3. 도면에서 위험원과 차단점을 확인하고 특수 작업 절차에 반영한다.
4. 특수 작업에서는 설계상 안전기능을 모두 해제하는 것이 원칙이다.

### 문제 5

다음 설명이 맞으면 O, 틀리면 X로 판단해봐.

“기계가 멈춘 것을 눈으로 확인했다면 전기·유압·중력 에너지는 모두 제거된 것으로 볼 수 있다.”

## 6. 요약

1. **설계도에 따른 안전지침**은 도면과 사양서에서 위험원, 위험영역, 에너지 흐름과 차단점을 찾아 안전대책으로 바꾸는 과정이야.
2. 도면 검토는 정상운전뿐 아니라 설치, 조정, 청소, 점검, 고장처리, 정비와 폐기 상태까지 포함해야 해.
3. 안전대책은 위험 제거와 설계적 감소를 우선하고, 방호장치·절차·교육·개인보호구를 단계적으로 보완해야 해.
4. 비상정지장치는 기본 방호수단을 대신할 수 없어.
5. **특수 작업의 조건**은 정상 방호가 약화되거나 새로운 중대위험이 생기는 작업을 허용하기 위한 통제요건이야.
6. 특수 작업 전에는 위험성 확인, 작업계획, 책임자 지정, 에너지 격리, 작업허가, 출입통제, 의사소통과 비상조치가 필요해.
7. 정지는 동작을 멈추는 것이고, 격리는 에너지 경로를 끊는 것이며, 무에너지 확인은 실제 안전상태를 검증하는 것이야.
8. 작업조건이 변경되거나 통제조치가 상실되면 즉시 작업을 중지하고 재평가해야 해.
9. 작업 종료에는 인원·공구 확인, 방호장치 복구, 안전한 잠금 해제, 시험운전과 인계가 포함돼.
