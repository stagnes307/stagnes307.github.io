# 3-1-1-3. 작업절차와 공정도를 잇는 안전분석

산업안전기사 필기  
표준안전작업절차서 · 공정도를 활용한 공정분석 기술

> 핵심 관점: 공정도는 작업의 흐름과 위험 지점을 찾아내는 지도이고, 표준안전작업절차서는 그 위험을 통제하며 작업하는 방법을 정한 실행 규칙이야.

## 1. 두 도구의 역할과 연결 구조

**표준안전작업절차서**는 작업자가 정해진 작업을 안전하고 일관되게 수행하도록 작업 순서, 위험요인, 안전조치, 보호구, 비상조치를 문서화한 기준이야. 흔히 SOP 또는 안전작업표준이라고 부르며, 단순한 작업 설명서가 아니라 사고를 예방하기 위한 통제 문서라는 점이 핵심이야.

**공정도를 활용한 공정분석 기술**은 원재료 투입부터 가공, 운반, 검사, 정체, 저장에 이르는 전체 흐름을 기호와 순서로 나타낸 뒤, 각 단계의 필요성과 위험성을 분석하는 방법이야. 작업 현장을 한 장의 지도로 펼쳐 놓고 어디에서 위험이 생기며 어떤 조치가 필요한지 찾는 과정이라고 생각하면 쉬워.

두 도구는 따로 존재하지 않아. 먼저 공정도를 작성하여 작업의 흐름과 위험 지점을 발견하고, 분석 결과를 표준안전작업절차서의 작업 순서와 안전조치에 반영해야 해.

**현장 관찰 → 공정도 작성 → 단계별 위험 분석 → 통제대책 선정 → 절차서 작성 → 교육·실행 → 점검·개정**

공정도가 진단 도구라면 표준안전작업절차서는 처방전이야. 진단이 빠지면 절차서가 현실과 어긋나고, 처방이 빠지면 분석 결과가 실제 행동으로 이어지지 않아.

## 2. 표준안전작업절차서의 구성 원리

좋은 절차서는 작업자가 현장에서 바로 행동으로 옮길 수 있을 만큼 구체적이어야 해. “안전에 유의한다”처럼 판단 기준이 없는 표현은 충분한 안전조치가 아니야.

### 기본 구성 요소

1. **적용 범위와 목적**  
   어떤 설비와 작업에 적용하며 무엇을 예방하기 위한 절차인지 명확히 정해.

2. **작업자의 자격과 책임**  
   작업 책임자, 운전자, 보조자, 점검자의 역할과 필요한 교육·자격을 구분해.

3. **사용 설비·도구·보호구**  
   필요한 기계, 수공구, 방호장치, 개인보호구와 사용 전 확인사항을 제시해.

4. **작업 전 준비와 점검**  
   전원 상태, 방호장치, 비상정지장치, 작업 공간, 재료 고정, 주변 작업자 유무를 확인해.

5. **정상 작업 순서**  
   작업을 실제 행동 단위로 나누고 각 단계의 시작 조건, 수행 방법, 완료 기준을 정해.

6. **단계별 위험요인과 안전조치**  
   끼임, 절단, 충돌, 비래, 감전, 화재와 같은 위험을 작업 단계 옆에 대응시켜야 해.

7. **이상 발생 시 조치**  
   설비 이상, 재료 걸림, 정전, 누출, 작업자 부상 시 정지·신고·대피 절차를 규정해.

8. **작업 종료와 정리**  
   동력 차단, 잔류에너지 해소, 공구 회수, 청소, 폐기물 처리, 인계 절차를 포함해.

9. **승인·교육·개정 기록**  
   작성자와 승인자, 시행일, 개정 이력, 교육 기록을 남겨 최신성이 유지되도록 해.

### 작성 원칙

절차는 **누가, 언제, 어디서, 무엇을, 왜, 어떻게** 수행하는지 식별할 수 있어야 해. 특히 위험한 단계에서는 다음 행동으로 넘어갈 수 있는 조건을 명시해야 해.

예를 들어 “기계를 정지한 후 이물질을 제거한다”보다 “주전원을 차단하고 잠금장치와 표지판을 설치한 뒤 잔류에너지가 없음을 확인하고 지정 공구로 이물질을 제거한다”가 더 적절해. 정지는 재기동과 잔류에너지 위험까지 제거했다는 뜻이 아니기 때문이야.

## 3. 공정도를 이용한 공정분석 절차

공정분석은 작업을 큰 이름으로 묶지 않고 관찰 가능한 사건으로 분해하는 데서 시작해. “프레스 작업” 하나로 기록하면 재료 운반, 금형 투입, 가공, 제품 취출, 검사 과정의 서로 다른 위험이 가려질 수 있어.

### 1단계: 분석 범위 설정

분석 대상의 시작점과 종료점을 정해. 작업자, 설비, 재료 가운데 무엇의 흐름을 추적할지도 결정해야 해. 범위가 불명확하면 같은 이동을 빠뜨리거나 중복 기록하기 쉬워.

### 2단계: 현장 관찰과 사실 수집

문서만 보지 말고 실제 작업을 관찰해야 해. 정상 작업뿐 아니라 준비, 청소, 조정, 고장 처리, 재료 걸림 제거와 같은 비정상·비정기 작업도 포함해. 사고는 생산이 안정적으로 진행될 때보다 이런 경계 작업에서 자주 발생하기 때문이야.

### 3단계: 공정 기호로 흐름 기록

각 사건을 가공, 운반, 검사, 정체, 저장으로 분류하고 발생 순서에 따라 연결해. 필요하면 거리, 시간, 작업자 수, 설비 조건도 함께 기록해.

### 4단계: 단계별 질문

각 단계마다 다음 질문을 적용해.

- 이 단계는 반드시 필요한가?
- 다른 단계와 결합하거나 순서를 변경할 수 있는가?
- 이동 거리와 취급 횟수를 줄일 수 있는가?
- 작업자가 위험점에 접근해야만 하는가?
- 방호장치나 자동화를 통해 노출을 차단할 수 있는가?
- 이상 상태에서도 같은 방법이 안전한가?
- 사고가 발생하면 에너지와 피해가 어디로 전파되는가?

### 5단계: 개선안 설계

개선은 일반적으로 **제거 → 대체 → 공학적 대책 → 관리적 대책 → 개인보호구**의 우선순위를 고려해. 위험한 작업 자체를 없앨 수 있는데 주의표지만 추가하는 것은 약한 대책이야.

### 6단계: 절차서 반영과 검증

개선된 공정 흐름을 기준으로 절차서를 작성하고 실제 작업자가 그대로 수행할 수 있는지 시험해. 작업자가 절차를 자주 우회한다면 작업자의 태도만 탓하지 말고 절차의 현실성, 설비 배치, 생산 압박, 도구 부족을 함께 점검해야 해.

## 4. 공정 기호로 읽는 위험의 위치

| 공정 활동 | 의미 | 대표 위험 | 분석 초점 |
|---|---|---|---|
| 가공 | 대상의 형상·성질·상태가 의도적으로 변함 | 끼임, 절단, 비래, 열, 소음 | 위험점 접근과 에너지 차단 |
| 운반 | 대상이 한 장소에서 다른 장소로 이동함 | 충돌, 낙하, 전도, 협착 | 이동 경로와 사람·차량의 분리 |
| 검사 | 수량·품질·상태를 확인함 | 가동부 접근, 날카로운 면 접촉 | 검사 위치와 설비 정지 조건 |
| 정체 | 다음 단계로 진행하지 못하고 기다림 | 통로 점유, 불안정 적치, 공정 혼잡 | 병목 원인과 임시 적치 상태 |
| 저장 | 지정 장소에서 관리 상태로 보관함 | 붕괴, 화재, 누출, 혼재 | 적재 기준과 물질별 격리 |

공정분석에서 가장 흔한 실수는 가공 단계만 위험하다고 보는 거야. 운반 중의 충돌, 검사 중의 가동부 접근, 정체 중의 임시 적치, 저장 중의 붕괴도 독립된 위험원이 될 수 있어.

특히 **정체**와 **저장**을 구분해야 해. 정체는 다음 활동을 기다리는 비의도적 지연 성격이 강하고, 저장은 승인된 장소에서 관리되는 계획적 보관이야. 생산품이 통로에 임시로 쌓였다면 이름을 “보관”이라고 부르더라도 실제 공정 성격은 정체에 가까울 수 있어.

## 5. 실제 예시: 프레스 가공 공정 개선

금속판을 프레스로 성형하는 작업을 분석해 보자.

### 개선 전 흐름

1. 자재를 손수레로 프레스 옆까지 운반한다.
2. 바닥에 자재를 임시 적치한다.
3. 작업자가 손으로 금속판을 금형 안에 넣는다.
4. 페달을 밟아 프레스를 작동한다.
5. 손으로 제품을 꺼낸다.
6. 치수를 검사한다.
7. 완성품 상자에 적재한다.
8. 불량이나 걸림이 생기면 손을 넣어 조정한다.

이 공정에서는 임시 적치물에 의한 걸림, 손 투입과 취출 과정의 끼임, 페달의 오조작, 날카로운 모서리에 의한 베임, 재료 걸림 제거 중 불시 기동 위험이 나타나.

### 공정분석에 따른 개선

먼저 자재 적치대를 설치해 통로의 정체를 제거해. 다음으로 손이 위험점에 들어가는 투입·취출 방식을 전용 치구나 자동 공급장치로 대체해. 방호장치와 기동장치가 유효하지 않으면 설비가 작동하지 않도록 연동하고, 필요하면 양수조작식 기동장치를 검토해.

재료가 걸렸을 때는 정상 생산 절차를 그대로 적용할 수 없어. 설비를 정지하고 에너지원 차단, 잠금·표지, 잔류에너지 확인, 지정 공구 사용, 방호장치 복구, 주변 인원 확인의 별도 절차가 필요해.

### 절차서에 들어갈 행동 문장

- 작업 전 방호장치와 비상정지장치의 기능을 확인한다.
- 재료는 지정된 적치대에 안정적으로 놓고 통로를 침범하지 않는다.
- 금형 내부에 손을 넣지 않고 지정된 투입·취출 도구를 사용한다.
- 이상음이나 제품 걸림이 발생하면 즉시 설비를 정지한다.
- 걸림 제거 전 모든 에너지원을 차단하고 잠금·표지를 실시한다.
- 작업 종료 후 설비를 정지하고 잔류에너지를 해소한 뒤 주변을 정리한다.

이처럼 공정분석 결과가 절차서의 행동 문장으로 변환되어야 개선이 완성돼.

## 6. 비교와 적용 경계

### 공정도와 표준안전작업절차서의 차이

**공정도**는 전체 작업 흐름을 조망하고 불필요한 단계, 병목, 이동, 위험 노출 지점을 발견하는 데 강해. 반면 **표준안전작업절차서**는 발견된 위험을 작업자가 어떤 순서와 조건으로 통제할지 정하는 데 강해.

공정도에는 “무슨 일이 어떤 순서로 일어나는가”가 중심적으로 나타나고, 절차서에는 “그 일을 누가 어떤 안전조건 아래 어떻게 수행하는가”가 나타나. 따라서 공정도만으로 작업자 교육을 끝내거나, 공정분석 없이 기존 절차서를 그대로 복사해서는 안 돼.

### 정상 작업과 비정상 작업의 경계

정상 가공 절차가 잘 만들어져 있어도 청소, 점검, 수리, 조정, 걸림 제거가 누락되면 중요한 위험이 남아. 이런 작업은 방호장치가 해제되거나 작업자가 위험점 안으로 들어가는 경우가 많아 별도의 안전조건과 에너지 차단 절차가 필요해.

### 문서화와 실제 안전의 경계

절차서가 존재한다는 사실만으로 안전이 확보되는 것은 아니야. 작업자가 내용을 이해하고, 필요한 설비와 도구가 제공되며, 현장 조건이 바뀔 때 문서가 개정되어야 해. 현장과 다른 절차서는 오래된 지도처럼 오히려 잘못된 판단을 유도할 수 있어.

## 7. 산업안전기사 시험 함정

### 함정 1: 절차서를 교육자료로만 이해하기

절차서는 작업 전 교육에 쓰이지만 본질은 작업 수행의 기준이야. 작성 후에는 승인, 배포, 교육, 준수 확인, 개정 관리까지 이어져야 해.

### 함정 2: 개인보호구를 가장 먼저 선택하기

개인보호구는 위험원과 작업자의 접촉 가능성을 근본적으로 없애지 못해. 위험 제거, 대체, 격리, 방호장치와 같은 상위 통제수단을 먼저 검토하는 것이 원칙이야.

### 함정 3: 정지와 저장을 같은 상태로 보기

정체는 공정 중 기다림이나 지연이고, 저장은 계획된 보관이야. 지정되지 않은 장소에 임시 적치된 재료는 저장품처럼 보여도 공정 지연과 통로 위험을 나타내는 정체로 분석될 수 있어.

### 함정 4: 정상 생산만 관찰하기

재료 걸림 제거, 청소, 금형 교환, 시운전과 같은 작업은 빈도가 낮더라도 위험 노출이 커. 공정분석에서는 빈도와 피해 가능성을 함께 봐야 해.

### 함정 5: 모호한 표현을 안전조치로 인정하기

“조심한다”, “주의한다”, “안전하게 실시한다”는 표현에는 행동 기준과 완료 조건이 없어. 설비 정지, 에너지 차단, 잠금·표지, 지정 공구 사용처럼 확인 가능한 행동으로 바꿔야 해.

### 함정 6: 공정도 작성 자체를 분석의 끝으로 보기

기호를 배열하는 것은 현상 기록이야. 각 단계의 필요성, 위험, 개선 가능성을 질문하고 절차서와 설비에 반영해야 진정한 공정분석이 돼.

## 8. 확인 문제

### 문제 1

공정도를 활용한 안전 공정분석의 가장 적절한 흐름을 고르면?

1. 절차서 작성 → 현장 관찰 → 위험 확인 → 공정도 폐기  
2. 현장 관찰 → 공정도 작성 → 위험 분석 → 개선 → 절차서 반영  
3. 보호구 지급 → 생산량 확인 → 공정도 작성 → 교육 생략  
4. 사고 발생 → 공정도 작성 → 작업자 교체 → 절차 유지

### 문제 2

다음 중 표준안전작업절차서의 문장으로 가장 적절한 것은?

1. 작업자는 항상 안전에 주의한다.  
2. 기계가 이상하면 적절히 조치한다.  
3. 재료 걸림 제거 전 에너지원을 차단하고 잠금·표지한 뒤 잔류에너지가 없음을 확인한다.  
4. 숙련자는 필요에 따라 방호장치를 해제할 수 있다.

### 문제 3

다음 중 공정 활동과 대표 위험의 연결이 가장 부적절한 것은?

1. 가공 — 끼임과 절단  
2. 운반 — 충돌과 낙하  
3. 정체 — 통로 점유와 불안정 적치  
4. 저장 — 공정 지연만 존재하며 붕괴 위험은 없음

### 문제 4

위험한 수동 투입 작업에 대한 개선 대책으로 우선 검토할 것은?

1. 주의표지 확대  
2. 개인보호구만 추가 지급  
3. 자동 공급 또는 전용 치구를 이용한 위험점 접근 제거  
4. 작업자의 집중력 강조

## 9. 정답과 해설

**문제 1 정답: 2번**

공정분석은 실제 작업을 관찰해 흐름을 기록하고, 각 단계의 위험과 낭비를 분석한 뒤 개선안을 절차서와 현장에 반영하는 순서로 진행해. 절차서를 먼저 고정하면 현장 사실이 문서에 제대로 반영되지 않을 수 있어.

**문제 2 정답: 3번**

3번은 작업 시점, 통제 행동, 확인 조건이 구체적으로 제시돼 있어. 나머지는 모호하거나 방호장치 해제를 허용하여 위험을 증가시켜.

**문제 3 정답: 4번**

저장 단계에서도 적재물 붕괴, 화재, 누출, 위험물 혼재가 발생할 수 있어. 저장은 움직임이 없다고 해서 무위험 상태가 아니야.

**문제 4 정답: 3번**

위험점에 손이 접근하는 원인을 제거하거나 줄이는 공학적 대책이 주의표지나 개인보호구보다 우선돼. 자동 공급과 전용 치구는 작업자와 위험점 사이의 접촉 가능성을 구조적으로 낮춰.

## 10. 회상 요약

- 공정도는 작업의 **흐름과 위험 위치를 발견하는 분석 지도**야.
- 표준안전작업절차서는 발견된 위험을 통제하는 **구체적인 실행 기준**이야.
- 공정은 가공뿐 아니라 **운반, 검사, 정체, 저장**까지 모두 분석해야 해.
- 정상 작업 외에 **청소, 조정, 수리, 걸림 제거**도 별도 단계로 살펴야 해.
- 안전조치는 가능하면 **제거와 공학적 통제**를 먼저 검토하고 보호구에만 의존하지 않아야 해.
- 절차서에는 “주의한다”가 아니라 **누가 무엇을 어떤 조건에서 수행하는지**가 들어가야 해.
- 가장 중요한 연결은 **공정도 작성 → 위험 분석 → 통제대책 선정 → 절차서 반영 → 현장 검증과 개정**이야.
