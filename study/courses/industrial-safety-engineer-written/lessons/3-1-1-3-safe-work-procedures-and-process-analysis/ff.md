# 3-1-1-3. 표준안전작업절차서 · 공정도를 활용한 공정분석 기술

산업안전기사 필기에서 다루는 **3-1. 기계공정의 안전**, **3-1-1. 기계공정의 특수성 분석** 가운데 이번 학습 범위는 **3-1-1-3. 표준안전작업절차서 · 공정도를 활용한 공정분석 기술**이야.

핵심 주제는 **표준안전작업절차서**와 **공정도를 활용한 공정분석 기술**이야. 둘은 별개의 문서가 아니라, 공정을 먼저 구조적으로 분석하고 그 결과를 작업자가 실행할 수 있는 안전한 순서로 바꾸는 하나의 연결 고리라고 보면 돼. 😊

> 🔑 핵심 키워드: 표준작업, 위험성평가, 작업순서, 공정도, 공정기호, 작업분석, 위험요인, 통제조치

***

## 1. 전체 구조부터 잡기

사고는 흔히 작업자가 규칙을 지키지 않아서 발생한다고 설명되지만, 실제로는 규칙 자체가 모호하거나 공정의 위험한 접점을 빠뜨린 경우도 많아. 따라서 안전관리자는 먼저 공정 전체를 관찰하고, 작업을 작은 단계로 분해하며, 각 단계에서 발생할 수 있는 위험요인을 찾아야 해.

**공정도를 활용한 공정분석 기술**은 작업의 흐름을 눈에 보이는 지도처럼 표현하는 방법이야. 이 분석 결과를 토대로 작업 순서, 위험요인, 안전조치, 이상 발생 시 대응방법을 문서화한 것이 **표준안전작업절차서**야.

| 구분 | 중심 질문 | 대표 산출물 |
|---|---|---|
| 공정분석 | 작업은 실제로 어떤 순서와 흐름으로 진행되는가? | 공정도, 작업단계 목록, 개선안 |
| 위험분석 | 각 단계에서 무엇이 사람을 다치게 할 수 있는가? | 위험요인과 위험성평가 결과 |
| 절차서 작성 | 작업자가 어떤 순서와 조건으로 행동해야 안전한가? | 표준안전작업절차서 |
| 교육과 확인 | 작업자가 내용을 이해하고 실제로 수행할 수 있는가? | 교육 기록, 관찰 결과, 개정 이력 |

핵심 연결은 다음과 같아.

**작업 관찰 → 공정도 작성 → 단계별 위험요인 확인 → 불필요하거나 위험한 단계 개선 → 안전한 작업순서 확정 → 표준안전작업절차서 작성 → 교육과 실행 확인 → 재평가와 개정**

공정도가 **진단 지도**라면, 표준안전작업절차서는 그 지도를 토대로 만든 **안전 운전 안내서**인 셈이야.

# 2. 표준안전작업절차서

## 2-1. 정의와 목적

**표준안전작업절차서**는 특정 작업을 일관되고 안전하게 수행하기 위해 작업의 순서, 작업 조건, 단계별 위험요인, 예방조치, 금지사항 및 비상 대응방법을 구체적으로 정한 문서야.

일반적인 표준작업절차가 품질, 생산성, 작업시간의 균일화까지 폭넓게 다룬다면, 표준안전작업절차서는 특히 **근로자의 부상과 설비 사고를 방지하는 통제 조건**을 분명히 한다는 점이 중요해.

절차서의 목적은 단순히 작업자를 통제하는 데 있지 않아. 사람마다 다른 작업방식을 안전성이 검증된 방식으로 통일하고, 숙련자의 암묵적 지식을 누구나 확인할 수 있는 명시적 지식으로 바꾸는 것이 핵심이야. 교대근무, 신규 채용, 작업자 변경처럼 인적 조건이 달라져도 안전 수준을 안정적으로 유지하게 해 주지.

## 2-2. 표준안전작업절차서의 기본 원리

### 작업을 실제 행동 단위로 분해해야 해

“기계를 안전하게 운전한다”는 문장은 목표일 뿐 절차가 아니야. 작업자는 무엇을 먼저 확인하고, 어떤 조작을 하며, 어느 지점에 손을 대지 않아야 하는지 알 수 있어야 해.

예를 들어 프레스 작업을 단순히 “재료를 투입하고 가공한다”라고 쓰면 위험한 손의 위치와 기계 정지 조건을 확인할 수 없어. 다음처럼 관찰 가능한 행동으로 나눠야 해.

1. 작업 전 방호장치와 비상정지장치의 상태를 확인한다.
2. 금형과 재료의 규격이 작업지시와 일치하는지 확인한다.
3. 지정된 위치에 재료를 공급한다.
4. 손이 위험구역 밖에 있는 상태에서 기동장치를 조작한다.
5. 기계가 완전히 정지한 뒤 가공물을 꺼낸다.
6. 걸림이나 이상이 발생하면 운전을 정지하고 에너지원을 통제한 뒤 조치한다.

이렇게 분해해야 각 단계의 위험요인과 안전조치를 일대일로 연결할 수 있어.

### 작업순서뿐 아니라 안전조건을 규정해야 해

좋은 절차서는 “무엇을 한다”만 말하지 않고 “어떤 조건에서 해야 하는가”까지 알려 줘. 기계의 완전 정지 여부, 방호장치의 설치 상태, 허용 인원, 공구 사용 조건, 보호구, 에너지원 차단 여부가 여기에 해당해.

특히 청소, 점검, 수리, 조정, 막힘 제거처럼 작업자가 위험구역에 접근하는 비정상 작업은 정상 운전보다 위험해. 단순히 정지 버튼을 누르는 것만으로는 예기치 않은 재가동이나 잔류에너지의 방출을 막지 못할 수 있으므로, 절차서에는 동력 차단과 잔류에너지 확인 같은 조건이 명시되어야 해.

### 정상 작업과 비정상 상황을 함께 다뤄야 해

현장의 사고는 계획된 정상 작업보다 재료 걸림, 제품 불량, 센서 이상, 설비 청소, 급한 정비 같은 이탈 상황에서 자주 발생해. 따라서 절차서에는 다음 내용이 포함되어야 해.

1. 정상 운전 절차
2. 기동 전 확인사항
3. 정상 정지 절차
4. 이상 발견 시 정지와 보고 방법
5. 막힘 제거와 청소 시 안전조치
6. 정비 또는 점검 전 에너지원 통제
7. 화재, 누출, 끼임과 같은 비상상황의 대응방법
8. 작업 재개 전 확인사항

## 2-3. 필수 구성요소

| 구성요소 | 작성 내용 | 확인해야 할 핵심 |
|---|---|---|
| 문서 식별정보 | 절차서명, 문서번호, 작성일, 개정번호 | 최신본인지 확인할 수 있어야 해 |
| 적용 범위 | 대상 설비, 공정, 작업, 작업자 | 적용 경계가 모호하면 안 돼 |
| 책임과 권한 | 작업자, 감독자, 정비 담당자의 역할 | 정지와 승인 권한을 분명히 해야 해 |
| 준비사항 | 자격, 교육, 공구, 보호구, 작업환경 | 작업 시작 전 조건을 확인해야 해 |
| 작업순서 | 준비부터 종료까지의 단계별 행동 | 실제 수행 순서와 일치해야 해 |
| 위험요인 | 끼임, 절단, 충돌, 비산, 감전, 화재 | 각 단계에 대응해 표시해야 해 |
| 안전조치 | 방호, 차단, 확인, 접근금지, 보호구 | 위험요인과 직접 연결되어야 해 |
| 금지사항 | 우회 조작, 임의 해체, 운전 중 청소 | 모호한 표현보다 구체적 행동을 써야 해 |
| 이상·비상 대응 | 정지, 대피, 보고, 구조 요청 | 무리한 단독 조치를 막아야 해 |
| 개정관리 | 변경 사유, 승인자, 교육 기록 | 설비·공정 변경을 반영해야 해 |

## 2-4. 작성 절차

### 1단계: 대상 작업과 적용 범위를 정해

작업의 시작점과 종료점, 대상 기계, 정상 작업과 부수 작업의 포함 여부를 정해야 해. 범위가 지나치게 넓으면 내용이 추상적으로 변하고, 지나치게 좁으면 작업 간 연결 위험을 놓칠 수 있어.

### 2단계: 현장 작업을 직접 관찰해

기존 문서만 베끼면 실제 작업과 절차서가 어긋날 수 있어. 숙련 작업자, 감독자, 정비 담당자의 의견을 함께 듣고 정상 상황뿐 아니라 막힘 제거, 청소, 교체, 조정 과정도 관찰해야 해.

### 3단계: 작업을 순서대로 분해해

각 단계는 한 문장에 하나의 핵심 행동이 드러나도록 작성하는 것이 좋아. “확인 후 운전하고 이상 시 정지한다”처럼 여러 행동을 한 단계에 묶으면 누락 여부를 판단하기 어려워.

### 4단계: 단계별 위험요인을 확인해

각 단계에서 다음 질문을 던져 봐.

1. 신체가 위험점에 접근하거나 들어가는가?
2. 회전부, 왕복부, 절단부 또는 이송부와 접촉할 수 있는가?
3. 물체가 떨어지거나 튀거나 무너질 수 있는가?
4. 전기, 압력, 열, 중량물 또는 화학물질의 에너지가 방출될 수 있는가?
5. 작업자가 시야, 자세, 공간 또는 시간의 제약을 받는가?
6. 다른 작업자나 다른 설비의 행동이 영향을 주는가?
7. 이상 발생 시 무리한 개입이 예상되는가?

### 5단계: 통제조치를 결정해

위험을 줄일 때는 단순히 보호구부터 적는 것이 아니라 **위험원 제거와 공학적 통제**를 우선 검토해야 해.

| 우선순위 | 통제 방법 | 예시 |
|---|---|---|
| 1 | 제거 | 위험한 수작업 자체를 없앰 |
| 2 | 대체 | 더 안전한 재료나 공법으로 변경 |
| 3 | 공학적 통제 | 방호덮개, 인터록, 자동공급장치 설치 |
| 4 | 관리적 통제 | 절차서, 교육, 출입통제, 점검 |
| 5 | 개인보호구 | 보안경, 안전화, 방음보호구 착용 |

시험에서는 **표준안전작업절차서 자체가 위험원을 물리적으로 제거하는 공학적 대책은 아니라는 점**을 구별해야 해. 절차서와 교육은 주로 관리적 통제에 해당하며, 방호장치 같은 공학적 대책을 대신할 수 없어.

### 6단계: 현장 검증과 승인을 받아

작성된 순서를 실제로 수행해 보면서 실행 가능성, 누락된 위험, 표현의 모호성을 확인해야 해. 검증되지 않은 절차는 종이 위에서는 완벽해 보여도 작업공간이나 설비 구조 때문에 실행할 수 없을 수 있어.

### 7단계: 교육하고 이해도를 확인해

절차서를 배포한 사실만으로 교육이 완료되는 것은 아니야. 작업자가 핵심 위험요인과 정지 조건을 설명할 수 있는지, 실제 행동으로 수행할 수 있는지를 확인해야 해.

### 8단계: 변경과 사고 정보를 반영해 개정해

다음과 같은 상황에서는 절차서를 재검토해야 해.

1. 설비, 원재료, 공법 또는 작업순서가 변경된 경우
2. 방호장치나 제어방식이 변경된 경우
3. 사고나 아차사고가 발생한 경우
4. 새로운 위험요인이 확인된 경우
5. 작업자의 반복적인 우회 행동이 발견된 경우
6. 법적·기술적 기준이나 현장 조건이 바뀐 경우

## 2-5. 구체적인 예시

선반에서 회전체 주변의 칩을 제거하는 작업을 생각해 보자.

나쁜 절차는 “칩에 주의하여 청소한다”라고만 적어. 위험을 작업자의 주의력에 떠넘기기 때문에 행동 기준이 없어.

개선된 절차는 다음처럼 구성할 수 있어.

1. 선반의 운전을 정지한다.
2. 척과 가공물의 회전이 완전히 멈춘 것을 눈으로 확인한다.
3. 지정된 칩 제거용 공구를 사용한다.
4. 손으로 칩을 직접 잡거나 압축공기로 몸 쪽을 향해 불지 않는다.
5. 청소 후 공구와 장애물을 제거한다.
6. 방호 상태와 작업구역을 확인한 뒤 운전을 재개한다.

여기서 위험요인은 회전체 끼임, 날카로운 칩에 의한 베임, 칩 비산이야. 대응조치는 완전 정지 확인, 전용 공구 사용, 손의 직접 접촉 금지, 비산 방지야. **위험요인과 안전조치가 단계별로 연결**되어 있다는 점이 중요해.

## 2-6. 비교와 경계

| 구분 | 표준안전작업절차서 | 작업지시서 | 위험성평가 |
|---|---|---|---|
| 주된 목적 | 안전한 행동과 조건의 표준화 | 생산 대상과 작업 요구 전달 | 위험요인 확인과 위험성 결정 |
| 핵심 내용 | 순서, 위험, 조치, 금지, 비상 대응 | 수량, 규격, 일정, 작업 조건 | 가능성, 중대성, 감소대책 |
| 사용 시점 | 작업 전·중·후 지속 활용 | 작업 배정과 수행 시 활용 | 작업 설계·변경·점검 시 활용 |
| 관계 | 평가 결과를 실행 절차로 구체화 | 절차서의 적용 대상을 지시 | 절차서에 반영할 위험 근거 제공 |

### 시험 함정

1. 절차서가 있으면 방호장치가 없어도 된다는 진술은 틀려.
2. 숙련자는 절차서를 생략해도 된다는 진술도 틀려.
3. 작업순서만 적고 위험요인과 안전조치를 제외하면 안전절차서로서 불충분해.
4. 절차서는 한 번 작성하면 고정되는 문서가 아니라 변경과 사고 경험을 반영해 개정해야 해.
5. “주의한다”, “안전하게 한다”처럼 관찰하거나 판정할 수 없는 표현은 좋은 절차의 기준이 아니야.

# 3. 공정도를 활용한 공정분석 기술

## 3-1. 정의와 목적

**공정도를 활용한 공정분석 기술**은 작업 대상이 공정 안에서 어떻게 가공되고, 이동하고, 검사되고, 기다리고, 저장되는지를 기호와 순서로 표현하여 비효율과 위험요인을 분석하는 방법이야.

말로만 공정을 설명하면 반복, 역행, 대기, 장거리 운반 같은 문제가 숨어 버릴 수 있어. 공정도는 작업의 시간적 순서와 공간적 흐름을 시각화하므로, 작업자가 위험구역을 몇 번 통과하는지, 어느 단계에서 수작업 개입이 발생하는지, 재공품이 어디에 쌓이는지를 발견하는 데 유용해.

## 3-2. 기본 공정기호

산업공학적 공정분석에서는 일반적으로 다음과 같은 기본 활동을 구분해.

| 활동 | 일반적 의미 | 안전분석 관점 |
|---|---|---|
| 가공·작업 | 대상의 형상, 성질 또는 상태를 의도적으로 변화시킴 | 절단, 끼임, 회전부 접촉, 열·압력 노출을 확인 |
| 운반 | 사람이나 물체의 위치가 이동함 | 충돌, 낙하, 전도, 중량물 취급, 동선 교차를 확인 |
| 검사 | 수량이나 품질을 확인함 | 위험구역 접근, 불안전한 자세, 가동 중 접촉을 확인 |
| 정체·대기 | 다음 활동을 기다리며 일시적으로 멈춤 | 재공품 적치, 통로 점유, 공정 압박과 임의 개입을 확인 |
| 저장 | 승인된 장소에서 계획적으로 보관함 | 붕괴, 낙하, 화재하중, 부적절한 적재를 확인 |

**대기와 저장의 차이**는 자주 혼동돼. 대기는 다음 작업을 기다리는 일시적 정체이고, 저장은 승인된 장소에서 계획적으로 보관하는 상태야. 둘 다 멈춰 있다는 외형은 비슷하지만 관리 목적과 통제 수준이 달라.

## 3-3. 공정도의 주요 형태

### 작업공정도

작업공정도는 주로 **가공과 검사**를 중심으로 전체 생산과정을 개괄적으로 보여 줘. 원재료나 부품이 어떤 작업을 거쳐 조립되고 검사되는지를 빠르게 파악하는 데 적합해.

전체 흐름의 골격을 보는 데는 유리하지만, 운반과 대기처럼 안전에 중요한 세부 활동이 생략될 수 있다는 한계가 있어.

### 흐름공정도

흐름공정도는 가공, 운반, 검사, 대기, 저장을 포함하여 대상의 흐름을 더 상세하게 나타내. 따라서 불필요한 운반, 반복 검사, 장시간 대기, 위험한 수작업 개입을 찾는 데 효과적이야.

분석 대상에 따라 재료 흐름, 작업자 행동, 설비 이용 흐름을 구분하여 살펴볼 수 있어. 무엇을 추적하는지 명확히 하지 않으면 서로 다른 흐름을 섞어 잘못 해석할 수 있으니 주의해야 해.

### 유통선도

유통선도는 작업장의 배치도 위에 사람이나 물자의 실제 이동경로를 선으로 나타내는 방식이야. 이동거리가 길거나 동선이 교차하는 장소, 왕복 이동과 우회가 발생하는 장소를 공간적으로 확인할 수 있어.

흐름공정도가 활동의 **순서**를 강조한다면, 유통선도는 이동의 **공간적 경로**를 강조한다고 구별하면 쉬워.

## 3-4. 공정분석 절차

### 1단계: 분석 목적과 대상을 정해

분석 목적은 재해 예방, 운반 감소, 병목 제거, 작업자 노출시간 단축처럼 구체적이어야 해. 분석 대상도 재료, 작업자, 기계 중 무엇인지 분명히 해야 해.

### 2단계: 현행 공정을 관찰하고 기록해

개선안을 먼저 상상하기보다 현재의 작업을 있는 그대로 기록해야 해. 공식 절차뿐 아니라 실제 작업자가 사용하는 우회 동작, 대기, 재작업, 수동 조정도 포함해야 해.

### 3단계: 활동을 기호와 순서로 표시해

각 활동을 가공, 운반, 검사, 대기, 저장으로 분류하고 순서대로 배열해. 필요한 경우 거리, 시간, 작업자 수와 위험요인을 함께 기록해.

### 4단계: 단계별로 질문해

공정분석에서는 각 활동을 비판적으로 검토해야 해.

| 질문 관점 | 핵심 질문 |
|---|---|
| 목적 | 왜 이 활동이 필요한가? 제거할 수 없는가? |
| 장소 | 왜 이 장소에서 하는가? 더 안전한 위치는 없는가? |
| 순서 | 왜 이 순서인가? 앞뒤 단계를 결합하거나 바꿀 수 없는가? |
| 사람 | 왜 이 작업자가 하는가? 자격과 인원이 적절한가? |
| 방법 | 왜 이 방법을 사용하는가? 자동화·원격화할 수 없는가? |

이 질문은 공정을 당연한 것으로 받아들이지 않고, 위험한 접점 자체를 제거하거나 줄이는 데 목적이 있어.

### 5단계: 제거·결합·재배열·단순화를 검토해

공정 개선의 대표적인 사고방식은 다음과 같아.

1. **제거**: 불필요한 작업, 운반, 검사 또는 대기를 없앤다.
2. **결합**: 분리된 활동을 안전하게 함께 수행할 수 있는지 검토한다.
3. **재배열**: 공정 순서나 배치를 바꾸어 역행과 동선 교차를 줄인다.
4. **단순화**: 복잡한 조작이나 과도한 수작업을 줄인다.

단, 생산성 향상만을 목표로 활동을 결합하면 한 작업자에게 과도한 부하나 동시 위험이 생길 수 있어. 모든 개선안은 새로운 위험을 만드는지 다시 평가해야 해.

### 6단계: 개선 공정도를 작성하고 비교해

현행 공정도와 개선 공정도를 비교하면서 활동 수, 운반거리, 소요시간, 대기시간, 위험구역 접근 횟수와 같은 지표가 어떻게 변했는지 확인해.

### 7단계: 절차서에 반영하고 실행 결과를 확인해

개선된 공정이 확정되면 표준안전작업절차서, 교육자료, 점검표에 반영해야 해. 공정도만 변경하고 현장 절차를 그대로 두면 분석 결과가 실제 행동으로 이어지지 않아.

## 3-5. 구체적인 공정분석 예시

금속 부품의 드릴 가공 공정을 다음처럼 가정해 보자.

| 순서 | 현행 활동 | 분류 | 주요 위험 |
|---|---|---|---|
| 1 | 원재료 보관대에서 부품을 가져옴 | 운반 | 중량물 취급, 통로 충돌 |
| 2 | 드릴 작업대 옆에 임시 적치함 | 대기 | 통로 점유, 낙하 |
| 3 | 부품을 손으로 고정함 | 작업 준비 | 회전공구 접촉, 부품 회전 |
| 4 | 드릴 가공을 실시함 | 가공 | 끼임, 말림, 칩 비산 |
| 5 | 기계가 회전하는 동안 치수를 확인함 | 검사 | 회전부 접근 |
| 6 | 손으로 칩을 제거함 | 작업 | 베임, 말림 |
| 7 | 완성품 보관대로 운반함 | 운반 | 낙하, 운반 동선 교차 |
| 8 | 완성품을 적재함 | 저장 | 적재물 붕괴 |

이 공정에서는 단순히 작업자에게 “조심하라”고 교육하는 것보다 다음과 같은 구조적 개선을 검토해야 해.

1. 원재료 보관 위치를 작업대 가까이 재배치하여 운반거리와 동선 교차를 줄인다.
2. 임시 적치대를 통로 밖의 지정 위치에 설치한다.
3. 손 고정 대신 적합한 바이스나 고정구를 사용한다.
4. 회전 중 측정을 금지하고 완전 정지 후 검사하도록 순서를 변경한다.
5. 칩 제거는 완전 정지 후 전용 공구로 수행한다.
6. 비산 방호와 보안경 착용 조건을 함께 적용한다.
7. 완성품의 적재 높이와 적재 방법을 표준화한다.

개선 후에는 “운반 횟수가 줄었다”는 결과만 확인해서는 부족해. 회전부 접근 횟수, 손 고정 작업의 제거 여부, 통로 점유시간, 칩 접촉 가능성이 실제로 줄었는지도 확인해야 해.

## 3-6. 비교와 경계

| 구분 | 작업공정도 | 흐름공정도 | 유통선도 |
|---|---|---|---|
| 중심 정보 | 가공과 검사 중심의 개요 | 활동 종류와 시간적 순서 | 작업장 내 공간적 이동경로 |
| 적합한 분석 | 전체 공정의 골격 파악 | 운반·대기까지 포함한 상세 분석 | 이동거리와 동선 교차 분석 |
| 장점 | 단순하고 전체 흐름을 보기 쉬움 | 누락 활동과 비효율을 찾기 좋음 | 배치 문제를 직관적으로 확인 |
| 주의점 | 세부 운반과 대기를 놓칠 수 있음 | 분석 대상을 명확히 해야 함 | 활동 목적과 시간은 별도 분석이 필요함 |

### 시험 함정

1. 작업공정도와 흐름공정도를 같은 것으로 보면 안 돼.
2. 대기와 저장은 모두 정지 상태지만 의미와 관리 방식이 달라.
3. 공정분석은 단순한 시간 단축 기법이 아니라 위험한 동작과 접점을 찾는 데도 활용돼.
4. 운반거리가 짧아졌다고 반드시 안전해진 것은 아니야. 지게차와 보행자의 동선이 더 많이 교차하면 위험은 커질 수 있어.
5. 공정을 결합하거나 단순화한 뒤에는 새롭게 생긴 동시작업 위험과 작업부하를 재평가해야 해.

# 4. 두 기술을 하나의 안전관리 고리로 연결하기

공정분석이 먼저 “실제로 무슨 일이 일어나는지”를 보여 주면, 표준안전작업절차서는 “앞으로 어떻게 해야 하는지”를 규정해. 따라서 다음 순환구조가 중요해.

| 단계 | 공정분석의 역할 | 절차서의 역할 |
|---|---|---|
| 현행 파악 | 실제 활동과 흐름을 기록 | 기존 절차와 실제 작업의 차이를 확인 |
| 위험 발견 | 위험한 운반·대기·접근·수작업을 식별 | 단계별 위험요인을 명시 |
| 개선 설계 | 제거·결합·재배열·단순화를 검토 | 개선된 순서와 조건을 행동 문장으로 변환 |
| 현장 적용 | 개선 공정의 효과를 관찰 | 작업자가 동일한 방식으로 수행하도록 안내 |
| 사후 검증 | 시간·거리·노출·접근 횟수를 비교 | 준수 여부와 실행 가능성을 확인 |
| 재개정 | 새 위험이나 비효율을 다시 분석 | 변경된 공정과 사고 경험을 반영 |

예를 들어 공정분석에서 작업자가 매 제품마다 방호구역 안으로 손을 넣는다는 사실을 발견했다면, 가장 먼저 자동 배출이나 전용 보조도구 같은 공학적 개선을 검토해야 해. 그 뒤 절차서에는 보조도구 사용방법, 접근금지 조건, 이상 발생 시 정지 절차를 적어야 하지.

반대로 절차서에 “손을 넣지 않는다”고만 쓰고 공정 구조상 손을 넣지 않으면 제품을 꺼낼 수 없게 설계되어 있다면, 그 절차는 현실성이 없어. 이 경우 작업자의 불이행만 탓할 게 아니라 공정 자체를 다시 분석해야 해. 흥, 지킬 수 없는 절차를 만들어 놓고 작업자에게 책임을 돌리면 안전관리가 아니라 서류관리일 뿐이야. 😒

# 5. 실전 판단 기준

다음 다섯 문장으로 핵심을 점검해 보자.

1. 공정도는 작업의 **흐름과 활동**을 가시화한다.
2. 공정분석은 위험한 단계의 **제거·결합·재배열·단순화** 가능성을 검토한다.
3. 표준안전작업절차서는 분석 결과를 **실행 가능한 행동과 안전조건**으로 바꾼다.
4. 절차서와 교육은 방호장치 같은 공학적 대책을 **대체하지 않는다**.
5. 설비·공정 변경이나 사고가 발생하면 공정도와 절차서를 **함께 재검토**한다.

# 6. 확인 문제

## 문제 1

표준안전작업절차서에 관한 설명으로 가장 적절한 것은?

1. 숙련 작업자에게는 적용하지 않는다.
2. 작업의 생산량과 납기만을 기록한다.
3. 단계별 작업순서, 위험요인 및 안전조치를 구체화한다.
4. 한 번 승인되면 공정이 변경되어도 개정하지 않는다.

## 문제 2

다음 가운데 표준안전작업절차서 작성의 바람직한 원칙은?

1. “항상 주의한다”와 같이 포괄적인 표현을 사용한다.

# 8. 요약

**표준안전작업절차서**는 안전한 작업순서와 작업조건을 명확히 하여 작업방법을 표준화하는 문서야. 적용 범위, 책임, 준비사항, 단계별 행동, 위험요인, 안전조치, 금지사항, 이상·비상 대응 및 개정관리가 포함되어야 해.

**공정도를 활용한 공정분석 기술**은 가공, 운반, 검사, 대기, 저장과 같은 활동을 시각화하고, 목적·장소·순서·사람·방법을 검토하여 위험과 비효율을 찾아내는 방법이야.

두 주제의 관계를 한 문장으로 정리하면 다음과 같아.

> 공정도는 작업의 현실을 해부하고, 표준안전작업절차서는 그 분석 결과를 안전한 행동으로 고정해.

시험에서는 작업공정도·흐름공정도·유통선도의 차이, 대기와 저장의 구별, 절차서의 구성요소, 공정 변경 후 재평가와 개정의 필요성을 특히 정확하게 기억해 둬. 내용이 많아 보여도 **분석 → 개선 → 절차화 → 교육 → 검증 → 개정**이라는 순환만 잡으면 흔들리지 않아. 잘 따라왔어! 😊
