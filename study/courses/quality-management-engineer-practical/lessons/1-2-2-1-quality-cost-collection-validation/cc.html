품질코스트 수집 관제실

품질코스트 수집하기

흩어진 비용 자료가 믿을 만한 경영정보가 되려면 같은 기준으로 모으고, 증빙과 계산을 양방향으로 검증해야 해. 이번 레슨에서는 Q COST와 COPQ가 발생한 순간부터 승인된 보고값이 되기까지의 신호 경로를 따라가 볼 거야.

INPUT부문별 원천자료
CONTROL항목별 산출기준
OUTPUT검증된 품질코스트

MISSION

이번 레슨에서 확보할 능력

  • 품질코스트(Q COST) 및 COPQ 항목별 산출기준에 따라 각 부문에서 주기적으로 품질코스트를 산출하고 수집하도록 지원할 수 있다.
  • 수집된 품질코스트(Q COST) 및 COPQ를 산출기준에 따라 검증할 수 있다.

핵심은 비용을 많이 모으는 것이 아니라 동일한 비용을 누가 보더라도 같은 항목과 금액으로 판정하게 만드는 거야. 이를 위해 정의, 자료 출처, 계산식, 수집 주기, 책임자와 승인 절차가 하나의 기준으로 연결돼야 해.

SYSTEM MAP

Q COST와 COPQ의 구조

Q COST

요구 품질을 확보하기 위해 투입한 비용과 품질 실패로 발생한 손실을 함께 보는 전체 체계야. 일반적으로 예방비용 P, 평가비용 A, 내부실패비용 IF, 외부실패비용 EF로 구분해.

COPQ

나쁜 품질 때문에 발생한 비용이야. 협의로는 내부실패비용과 외부실패비용의 합을 뜻하지만, 회사 기준에 따라 생산성 저하나 기회손실 같은 숨은 비용까지 포함할 수 있어.

총품질코스트 = P + A + IF + EF　│　협의의 COPQ = IF + EF

주의할 점은 활동의 이름보다 목적과 발생 원인이야. 정상적인 정기검사는 평가비용이지만, 불량 때문에 추가한 재검사는 내부실패비용으로 판정하는 것이 일반적이야.

RULE SET

항목별 산출기준의 여섯 잠금장치

① 정의와 분류항목의 뜻과 P·A·IF·EF 또는 COPQ 분류를 명시해.
② 포함·제외 범위중복을 막도록 포함 비용과 제외 비용의 경계를 정해.
③ 원천자료전표, 작업일보, 검사기록 등 인정할 증빙을 지정해.
④ 계산식수량, 단가, 시간, 노무비율과 배부기준을 고정해.
⑤ 주기와 기준일월간·분기별 마감일과 비용 귀속기간을 일치시켜.
⑥ 책임과 승인작성자, 검증자, 승인자와 수정 이력 관리방법을 정해.

재작업비 산출 예

재작업비 = 추가 재료비 + 재작업 직접노무비 + 추가 설비가동비 + 재검사비로 설계할 수 있어. 직접노무비는 재작업시간과 시간당 노무비율을 곱해 계산하지. 단, 재검사비가 이미 노무비에 포함됐다면 다시 더하지 않아야 해.

DATA FLOW

수집에서 승인까지의 신호 경로

OWNERSHIP

부문별로 무엇을 받아야 할까?

품질부문검사·시험 실적, 측정기 교정비, 부적합보고서, 품질교육과 품질계획 자료
생산·구매부문폐기량, 재작업시간, 설비정지, 선별기록, 공급자 불량과 반품 운송자료
영업·고객서비스고객불만, 교환·반품, 보증수리, 리콜과 손해배상 자료
재무부문회계전표, 재료단가, 급여율, 제조간접비와 배부기준
인사·교육부문교육시간, 참가자, 강사료, 교재비와 교육 운영비
수집 책임자발생일, 제품, 항목, 금액, 증빙번호, 제출자와 승인상태를 표준 양식으로 통합

품질코스트는 품질부서 장부 하나에서 완성되지 않아. 여러 부문의 업무기록과 재무자료를 연결해야 하므로 공통 항목코드와 기준일을 사용하고, 제출 지연이나 미제출 상태도 관리해야 해.

수집 명세서의 금액을 전표, 작업일보, 검사기록으로 내려가며 확인해. 실제 발생 여부와 계산의 정확성을 검증하는 데 강해.

↔

업무기록 → 명세서

부적합보고서, 폐기기록, 반품기록에서 비용명세서로 올라가며 확인해. 기록되지 않은 비용의 누락을 찾는 데 강해.

합계가 맞아도 분류가 틀릴 수 있고, 전표가 있어도 기간이 틀릴 수 있어. 동일 증빙번호·날짜·제품·금액의 반복은 중복 신호야. 생산량이 비슷한데 폐기비가 급증했다면 불량수량, 단가, 분류방법과 입력오류를 순서대로 재확인해야 해.

CASE RUN

월간 품질코스트 산출 예시

수집된 원천자료
  • 품질교육비 1,200,000원
  • 수입·공정검사비 2,800,000원
  • 폐기비 2,400,000원
  • 재작업 직접노무비 1,600,000원
  • 재검사비 400,000원
  • 반품 운송비와 보증수리비 1,600,000원

P 1,200,000원

A 2,800,000원

IF 4,400,000원

EF 1,600,000원

총 Q COST 10,000,000원

협의의 COPQ 6,000,000원

그런데 재검사비 400,000원이 재작업 직접노무비에 이미 포함돼 있었다면 중복이야. 이때 내부실패비용은 4,000,000원, 총품질코스트는 9,600,000원으로 수정해야 해. 계산식을 재수행하는 것만큼 포함 범위와 중복 여부를 확인하는 일이 중요해.

ALERT PANEL

분류 경계와 실기 시험 함정

  • 예방과 평가: 불량을 막는 활동은 예방비용, 기준 충족 여부를 확인하는 활동은 평가비용이야.
  • 평가와 실패: 정상 검사는 평가비용이지만 불량 때문에 추가한 재검사는 내부실패비용이야.
  • 내부와 외부: 일반적인 경계는 고객 인도 전후야. 출하 전 재작업은 내부실패, 인도 후 보증수리는 외부실패야.
  • COPQ 범위: 문제에서 정의한 범위를 먼저 봐. 언제나 P+A+IF+EF로 계산하면 안 돼.
  • 발생일과 지급일: 돈을 지급한 날보다 비용이 어느 보고기간에 귀속되는지 확인해야 해.
  • 비율의 분모: 매출액 대비 품질코스트 비율이라면 문제에서 지정한 매출액을 분모로 사용해.

SELF CHECK

확인 문제

품질계획비 50만 원, 완성품 검사비 90만 원, 출하 전 재작업비 130만 원, 고객 보증수리비 80만 원이 발생했어. 총품질코스트와 협의의 COPQ를 계산해봐.
정상적인 공정검사비와 부적합품 재작업 후 실시한 추가 재검사비는 각각 어느 항목으로 분류해야 할까?
수집 명세서에 재작업비가 기록됐지만 작업일보와 승인 전표가 없어. 검증자는 어떻게 처리해야 할까?
명세서에서 증빙으로만 추적하면 완전성까지 충분히 확인할 수 있을까? 이유를 말해봐.

ANSWER CONSOLE

정답 및 해설

1번: P 50만 원, A 90만 원, IF 130만 원, EF 80만 원이므로 총품질코스트는 350만 원이야. 협의의 COPQ는 IF+EF이므로 210만 원이야.
2번: 정상 공정검사비는 평가비용이고, 부적합 때문에 추가한 재검사비는 내부실패비용이야. 활동 명칭이 아니라 발생 원인으로 판정해.
3번: 즉시 확정하지 말고 작업일보와 승인 전표를 요청해야 해. 재작업시간, 노무비율과 추가 재료비를 대조하고, 증빙이 확보되지 않으면 보류 또는 예외로 표시한 뒤 책임자 승인을 받아야 해.
4번: 충분하지 않아. 명세서에서 증빙으로 내려가는 검사는 기록된 금액의 실재성 확인에 유리하지만 누락은 찾기 어려워. 업무기록에서 명세서로 역추적해야 완전성을 확인할 수 있어.

MEMORY CORE

회상 요약

분류Q COST는 P·A·IF·EF로 보고, 협의의 COPQ는 IF+EF로 기억해.
수집기준 설정, 원천자료 확보, 표준화, 산출, 마감 순서로 진행해.
검증실재성·완전성·정확성·분류·기간을 양방향으로 확인해.
