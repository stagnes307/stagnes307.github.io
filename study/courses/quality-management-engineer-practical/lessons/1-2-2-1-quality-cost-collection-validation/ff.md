# 1-2-2-1. 품질코스트를 모으고 검증하는 법
과정명: 품질경영기사 실기  
공식 Lesson 제목: 품질코스트 수집하기

## 1. 학습 목표와 실무 능력

이번 레슨의 핵심은 비용 자료를 단순히 합산하는 데 있지 않아. 각 부문에서 발생한 품질 관련 비용을 **동일한 산출기준으로 분류·수집하고, 증빙과 기준에 따라 검증하여 신뢰할 수 있는 품질코스트 정보로 만드는 것**이 목표야.

- 품질코스트(Q COST) 및 COPQ 항목별 산출기준에 따라 각 부문에서 주기적으로 품질코스트를 산출하고 수집하도록 지원할 수 있다.
- 수집된 품질코스트(Q COST) 및 COPQ를 산출기준에 따라 검증할 수 있다.

전체 흐름은 다음처럼 기억하면 돼.

**산출기준 설정 → 부문별 자료 수집 → 항목 분류 → 금액 산출 → 증빙 대조 → 중복·누락 점검 → 확정·보고**

여기서 가장 중요한 원칙은 **같은 비용을 누가 분류하더라도 같은 항목과 금액으로 판단할 수 있어야 한다는 것**이야.

## 2. Q COST와 COPQ의 의미

### 품질코스트 Q COST

품질코스트는 요구되는 품질을 확보하거나 품질문제로 발생한 손실을 관리하기 위해 투입된 비용이야. 일반적으로 다음 네 범주로 분류해.

1. **예방비용 P**
   - 불량이 발생하지 않도록 사전에 투입하는 비용
   - 품질교육비, 공정능력 조사비, 협력업체 품질지도비, 품질계획비

2. **평가비용 A**
   - 제품이나 공정이 품질기준을 충족하는지 확인하는 비용
   - 수입검사비, 공정검사비, 시험비, 측정기 교정비, 완성품 검사비

3. **내부실패비용 IF**
   - 제품이 고객에게 전달되기 전에 발견된 부적합으로 발생하는 비용
   - 폐기비, 재작업비, 재검사비, 선별비, 공정중단 손실

4. **외부실패비용 EF**
   - 제품이 고객에게 전달된 뒤 발견된 부적합으로 발생하는 비용
   - 반품비, 보증수리비, 고객불만 처리비, 리콜비, 손해배상비

따라서 기본 구조는 다음과 같아.

**총품질코스트 = 예방비용 + 평가비용 + 내부실패비용 + 외부실패비용**

### COPQ

COPQ는 Cost of Poor Quality, 즉 **나쁜 품질 때문에 발생한 비용**이야. 대표적으로 내부실패비용과 외부실패비용을 중심으로 파악하지만, 기업의 산출기준에 따라 숨은 손실까지 포함할 수 있어.

**협의의 COPQ = 내부실패비용 + 외부실패비용**

숨은 COPQ에는 납기지연, 생산성 저하, 고객 신뢰 하락, 기회손실처럼 회계장부에서 직접 찾기 어려운 손실도 포함될 수 있어. 그러므로 시험이나 실무에서 COPQ를 계산할 때는 먼저 **문제 또는 회사 기준이 어느 범위까지 포함하도록 정의했는지** 확인해야 해.

## 3. 항목별 산출기준을 만드는 방법

산출기준은 비용의 이름만 정하는 표가 아니야. 각 비용을 **누가, 언제, 어떤 자료로, 어떤 계산식에 따라 산출할지 정한 업무 규칙**이야.

각 항목의 기준에는 최소한 다음 내용이 필요해.

- 항목명과 품질코스트 분류
- 비용의 정의와 포함 범위
- 제외 대상과 다른 항목과의 경계
- 자료 발생 부문과 수집 책임자
- 원천 증빙과 데이터 출처
- 계산식과 배부기준
- 수집 주기와 기준일
- 승인자와 검증 절차

예를 들어 재작업비의 산출기준을 다음과 같이 정할 수 있어.

**재작업비 = 재작업 직접노무비 + 추가 재료비 + 추가 설비가동비 + 재검사비**

직접노무비는 **재작업시간 × 시간당 노무비율**로 산출할 수 있어. 여러 제품이 공용 설비를 사용한다면 설비가동비는 작업시간, 생산수량 또는 기계시간을 기준으로 배부해야 해. 이때 배부기준을 기간마다 임의로 바꾸면 비용 추세를 비교할 수 없으므로 일관성을 유지해야 해.

## 4. 부문별 수집 절차와 책임

품질코스트는 품질부서에서만 발생하지 않아. 구매·생산·품질·영업·고객서비스·재무 부문에 흩어진 자료를 연결해야 완성돼.

### 단계 1: 수집 대상과 주기 확정

먼저 월간, 분기 또는 프로젝트 단위의 수집 주기를 정해. 마감일과 책임자를 함께 지정해야 자료가 늦게 제출되거나 기준 기간이 서로 달라지는 문제를 막을 수 있어.

### 단계 2: 부문별 원천자료 요청

- 품질부서: 검사실적, 시험기록, 교정비, 부적합보고서
- 생산부서: 폐기량, 재작업시간, 설비정지시간, 선별작업 기록
- 구매부서: 공급자 불량, 반품 운송비, 협력업체 지도비
- 고객서비스부서: 고객불만, 보증수리, 교환·반품 기록
- 인사·교육부서: 품질교육 시간과 교육비
- 재무부서: 전표, 급여율, 재료단가, 제조간접비 배부자료

### 단계 3: 표준 양식으로 변환

부문마다 사용하는 명칭이 다르면 동일한 비용이 여러 이름으로 수집될 수 있어. 따라서 발생일, 부문, 제품, 비용항목, P·A·IF·EF 분류, 수량, 단가, 금액, 증빙번호, 책임자를 포함한 표준 양식으로 통일하는 것이 좋아.

### 단계 4: 금액 산출과 1차 확인

각 부문은 승인된 산출식으로 금액을 계산하고 원천 증빙을 연결해 제출해. 품질부서는 항목의 성격과 발생 원인을 확인하고, 재무부서는 금액과 회계자료의 일치 여부를 확인하는 방식으로 역할을 나눌 수 있어.

### 단계 5: 기간 마감과 이력 보존

검증이 끝난 자료는 승인 상태로 확정하고 수정 이력을 남겨야 해. 과거 금액을 수정했다면 수정 전 금액, 수정 사유, 수정자, 승인자를 함께 기록해야 추적성이 확보돼.

## 5. 수집된 비용의 검증 원리

검증은 금액의 합계만 다시 계산하는 작업이 아니야. 다음 다섯 질문에 답하는 과정이야.

1. **실재성:** 실제로 발생한 비용인가?
2. **완전성:** 빠진 비용은 없는가?
3. **정확성:** 수량·단가·시간·비율과 계산 결과가 맞는가?
4. **분류 적정성:** P·A·IF·EF 또는 COPQ 항목에 올바르게 배치됐는가?
5. **기간 적정성:** 해당 보고기간에 귀속되는 비용인가?

검증 순서는 다음과 같이 운영할 수 있어.

**수집 명세서 확인 → 증빙 대조 → 계산식 재수행 → 분류기준 대조 → 중복·누락 탐색 → 전기 대비 변동 분석 → 부문 확인 → 승인**

중복은 동일한 증빙번호, 발생일, 제품, 금액이 반복되는지를 찾아 점검해. 누락은 부적합보고서에는 재작업이 기록됐지만 비용명세서에는 금액이 없는 경우처럼 **업무기록과 비용자료를 역방향으로 대조**하면 발견하기 쉬워.

변동 분석도 중요해. 생산량이 비슷한데 폐기비가 전월보다 크게 증가했다면 단순한 비용 증가로 확정하지 말고 불량수량, 재료단가, 분류방법 또는 입력오류가 변했는지 확인해야 해.

## 6. 실제 산출·검증 예시

A공장의 월간 자료가 다음과 같다고 해보자.

- 품질교육비: 1,200,000원
- 수입검사비: 1,800,000원
- 공정검사비: 1,000,000원
- 폐기비: 2,400,000원
- 재작업 직접노무비: 1,600,000원
- 재검사비: 400,000원
- 고객 반품 운송비: 600,000원
- 보증수리비: 1,000,000원

분류하고 합산하면 다음과 같아.

- 예방비용 P = 1,200,000원
- 평가비용 A = 1,800,000원 + 1,000,000원 = 2,800,000원
- 내부실패비용 IF = 2,400,000원 + 1,600,000원 + 400,000원 = 4,400,000원
- 외부실패비용 EF = 600,000원 + 1,000,000원 = 1,600,000원
- 총품질코스트 = 10,000,000원
- 협의의 COPQ = 4,400,000원 + 1,600,000원 = 6,000,000원

이 자료를 검증할 때는 교육비 전표와 교육실적, 검사비의 검사시간과 노무비율, 폐기수량과 재료단가, 재작업 작업일보, 반품 운송장, 보증수리 전표를 대조해야 해.

만약 재검사비 400,000원이 재작업 직접노무비 1,600,000원에 이미 포함돼 있었다면 별도로 더할 수 없어. 수정된 내부실패비용은 4,000,000원이고 총품질코스트는 9,600,000원이 돼. 이런 **중복 포함 여부**가 실기에서 자주 확인되는 지점이야.

## 7. 비교·경계와 시험 함정

### 예방비용과 평가비용

불량을 만들지 않기 위한 활동은 예방비용이고, 만들어진 결과가 기준에 맞는지 확인하는 활동은 평가비용이야. 품질교육은 예방비용이지만 검사원 인건비는 평가비용에 해당해.

### 평가비용과 실패비용

정상적인 정기검사비는 평가비용이야. 그러나 불량 때문에 추가로 실시한 재검사는 내부실패비용으로 보는 것이 일반적이야. 같은 검사라는 단어만 보고 모두 평가비용으로 분류하면 안 돼.

### 내부실패와 외부실패

판단 경계는 보통 **고객에게 인도되기 전인지 후인지**야. 출하 전에 발견한 부적합의 폐기·재작업은 내부실패이고, 인도 후 반품·보증수리·리콜로 이어지면 외부실패야.

### 자주 나오는 함정

- 품질코스트를 실패비용만으로 보는 오류
- COPQ의 범위를 확인하지 않고 무조건 P+A+IF+EF로 계산하는 오류
- 재작업비와 재검사비의 중복 포함 여부를 확인하지 않는 오류
- 매출액 대비 품질코스트 비율에서 분모를 생산원가로 바꾸는 오류
- 발생일과 지급일을 혼동해 비용을 잘못된 기간에 귀속하는 오류
- 금액 합계가 맞다는 이유로 항목 분류까지 맞다고 판단하는 오류
- 전표만 확인하고 폐기·재작업·반품 같은 업무기록과 대조하지 않는 오류

## 8. 확인 문제

### 문제 1

품질계획비 500,000원, 완성품 검사비 900,000원, 출하 전 재작업비 1,300,000원, 고객 보증수리비 800,000원이 발생했다. 총품질코스트와 협의의 COPQ를 계산해봐.

### 문제 2

정상적인 공정검사비와 부적합품 재작업 후 실시한 추가 재검사비는 각각 어느 항목으로 분류해야 할까?

### 문제 3

수집 명세서에 재작업비가 기록돼 있지만 재작업 작업일보와 승인 전표가 없다. 검증자는 어떤 조치를 해야 할까?

### 문제 4

품질코스트 자료의 완전성을 확인하려면 비용명세서에서 증빙으로만 추적하면 충분할까? 이유도 함께 설명해봐.

## 9. 정답과 해설

### 문제 1 정답

- 예방비용 = 500,000원
- 평가비용 = 900,000원
- 내부실패비용 = 1,300,000원
- 외부실패비용 = 800,000원
- 총품질코스트 = 3,500,000원
- 협의의 COPQ = 2,100,000원

COPQ는 이 문제에서 별도 범위가 제시되지 않았으므로 내부실패비용과 외부실패비용의 합으로 계산해.

### 문제 2 정답

정상적인 공정검사비는 평가비용이고, 부적합으로 인해 추가 발생한 재검사비는 내부실패비용이야. 활동의 명칭보다 **발생 원인**을 기준으로 분류해야 해.

### 문제 3 정답

곧바로 확정하면 안 돼. 작업일보와 승인 전표의 제출을 요청하고, 재작업시간·노무비율·추가 재료비를 대조해야 해. 증빙이 확보되지 않으면 보류 또는 예외 항목으로 표시하고 책임자의 확인과 승인을 받아야 해.

### 문제 4 정답

충분하지 않아. 비용명세서에서 증빙으로 추적하면 기록된 자료의 실재성은 확인할 수 있지만, 기록되지 않은 비용의 누락은 찾기 어려워. 부적합보고서, 폐기기록, 재작업일보, 고객불만 기록에서 비용명세서로 역추적해야 완전성을 확인할 수 있어.

## 10. 회상 요약

- 품질코스트는 **예방비용, 평가비용, 내부실패비용, 외부실패비용**으로 관리해.
- COPQ는 일반적으로 **내부실패비용과 외부실패비용**을 중심으로 산출하지만 조직의 정의를 먼저 확인해야 해.
- 산출기준에는 정의, 포함·제외 범위, 계산식, 자료 출처, 책임자, 주기, 승인 절차가 필요해.
- 수집은 **기준 설정 → 원천자료 확보 → 표준화 → 분류·산출 → 마감** 순서로 수행해.
- 검증은 **실재성, 완전성, 정확성, 분류 적정성, 기간 적정성**을 확인하는 과정이야.
- 명세서에서 증빙으로 추적하면 실재성을, 업무기록에서 명세서로 역추적하면 완전성을 확인하기 쉬워.
- 실기에서는 분류 명칭보다 비용의 **발생 목적, 발생 원인, 고객 인도 전후의 시점**을 먼저 판단하면 돼.
