공정의 시간적 변동을 읽고 데이터 특성에 맞는 관리도를 선정하고 작성하는 실기 학습

관리특성 계량형 데이터 계수형 데이터 합리적 부분군 중심선 관리한계선 공정 안정성

🎯 학습 목표

중점관리항목의 특성에 따라 해당되는 관리도의 종류를 선정할 수 있다.

관리계획서 또는 QC공정도의 관리방법에 따라 데이터를 수집하여 관리도를 작성할 수 있다.

관리도는 제품이 규격에 합격했는지만 판정하는 표가 아니야. 시간의 흐름에 따라 공정이 통계적 관리상태에 있는지, 즉 우연원인만 작용하는 안정된 공정인지 아니면 이상원인이 개입했는지를 살펴보는 도구야. 한 번의 측정값을 보여주는 체온계보다 시간에 따른 변화를 보여주는 심전도에 더 가까워.

📐 관리도의 본질과 구성 원리

관리도와 규격의 차이

규격한계는 개별 제품이 고객 또는 설계 요구를 만족하는지를 판단해. 반면 관리한계는 실제 공정에서 얻은 통계량이 우연변동으로 예상되는 범위 안에 있는지를 판단하지. 규격한계는 고객이나 설계자가 정하지만 관리한계는 공정 데이터로 계산해. 따라서 제품이 모두 규격 안에 있더라도 관리도에 이상 패턴이 나타날 수 있고, 공정이 통계적으로 안정되어 있어도 평균이나 산포가 규격에 적합하지 않으면 부적합품이 생길 수 있어.

관리도의 세 기준선

중심선 CL은 관리대상 통계량의 평균 수준이고, 관리상한선 UCL은 우연변동으로 예상되는 위쪽 경계이며, 관리하한선 LCL은 아래쪽 경계야. 기본 구조는 UCL = 중심선 + 3 × 표준오차, CL = 통계량의 평균, LCL = 중심선 − 3 × 표준오차로 이해할 수 있어. 관리한계를 벗어난 점은 즉시 불량이라는 뜻이 아니라 이상원인을 조사해야 할 통계적 신호야.

우연원인과 이상원인

우연원인은 미세한 온도 차이, 재료의 작은 편차, 측정기의 제한된 분해능처럼 공정에 본래 내재한 반복적 변동이야. 이상원인은 공구 파손, 잘못된 원재료 투입, 설비 설정 오류, 작업방법 변경 또는 측정기 고장처럼 특정 시점에 공정 상태를 바꾸는 식별 가능한 원인이야. 관리한계 이탈뿐 아니라 한쪽 편중, 연속 상승이나 하강, 주기적 진동과 같은 비무작위 패턴도 이상원인의 단서가 돼.

🧭 데이터 특성에 따른 관리도 선정

계량형과 계수형의 구분

계량형 데이터는 길이, 무게, 온도, 압력, 강도처럼 연속적인 수치로 측정한 값이야. 계수형 데이터는 제품을 양품과 부적합품으로 분류하거나 제품에서 발견된 흠집 수를 세어 얻은 값이지. 관리도를 선정할 때는 먼저 이 둘을 구분한 다음 부분군 크기, 표본크기의 일정성, 부적합품과 부적합의 구분, 검사기회의 일정성을 확인해야 해.

X̄-R 관리도

X̄-R 관리도는 한 부분군에서 여러 개의 계량값을 측정하고 부분군 크기가 비교적 작을 때 사용해. X̄ 관리도는 공정 중심의 변화를, R 관리도는 부분군 내부 산포의 변화를 보여줘. 각 부분군에서 X̄ᵢ = 측정값 합 ÷ n, Rᵢ = 최댓값 − 최솟값을 계산하고, 전체 자료에서 X̿ = 부분군 평균들의 평균, R̄ = 부분군 범위들의 평균을 구해.

X̄ 관리도: UCL = X̿ + A₂R̄, CL = X̿, LCL = X̿ − A₂R̄

R 관리도: UCL = D₄R̄, CL = R̄, LCL = D₃R̄

A₂, D₃, D₄는 한 부분군의 관측값 수 n에 따라 달라져. 전체 데이터 수나 부분군 수를 n으로 착각하면 안 돼.

X̄-S 관리도

부분군 크기가 커지면 범위 R보다 표준편차 S가 산포를 더 안정적으로 표현해. 이때 X̄-S 관리도를 사용하며 X̄ 관리도는 UCL = X̿ + A₃S̄, CL = X̿, LCL = X̿ − A₃S̄로 계산해. S 관리도는 UCL = B₄S̄, CL = S̄, LCL = B₃S̄를 적용해. 시험에서는 계량형 데이터와 큰 부분군이라는 조건이 핵심 단서야.

I-MR 관리도

파괴검사처럼 여러 개를 동시에 측정하기 어렵거나 생산 간격이 길어 부분군을 구성할 수 없다면 개별값 I와 이동범위 MR을 사용해. 연속된 두 값의 이동범위는 MRᵢ = |Xᵢ − Xᵢ₋₁|이야. 개별값 관리도의 기본 한계는 UCL = X̄ + 3MR̄ ÷ d₂, CL = X̄, LCL = X̄ − 3MR̄ ÷ d₂로 계산할 수 있어. 계산이 편하다는 이유만으로 합리적 부분군을 해체하고 I-MR을 선택하면 안 돼.

p 관리도와 np 관리도

제품을 양품 또는 부적합품으로 판정한다면 p 또는 np 관리도를 검토해. pᵢ = dᵢ ÷ nᵢ이고 p̄ = 전체 부적합품수 ÷ 전체 검사수야. 표본크기 n이 일정한 p 관리도의 한계는 UCL = p̄ + 3√[p̄(1 − p̄) ÷ n], CL = p̄, LCL = p̄ − 3√[p̄(1 − p̄) ÷ n]이야. 표본크기가 변하면 각 nᵢ를 이용해 부분군별 한계를 계산할 수 있어.

np 관리도는 일정한 표본에서 부적합품수 자체를 표시해. UCL = np̄ + 3√[np̄(1 − p̄)], CL = np̄, LCL = np̄ − 3√[np̄(1 − p̄)]을 적용해. 계산된 하한이 음수이면 부적합품률이나 부적합품수는 음수가 될 수 없으므로 LCL을 0으로 처리해.

c 관리도와 u 관리도

한 제품에 흠집이 여러 개 존재할 수 있다면 제품의 합격 여부가 아니라 부적합수를 세는 거야. 검사 단위의 크기와 검사기회가 일정하면 c 관리도를 사용하며 UCL = c̄ + 3√c̄, CL = c̄, LCL = c̄ − 3√c̄로 계산해. 검사 면적, 길이, 시간 또는 단위 수가 변하면 u 관리도를 사용하고 uᵢ = cᵢ ÷ nᵢ로 나타내. u 관리도의 한계는 UCLᵢ = ū + 3√(ū ÷ nᵢ), CL = ū, LCLᵢ = ū − 3√(ū ÷ nᵢ)야.

관리도 선정 절차

  1. 관리특성이 측정값인지 계수값인지 확인해.
  2. 계량형이면 합리적인 부분군의 크기를 확인해.
  3. 작은 부분군은 X̄-R, 큰 부분군은 X̄-S, 부분군 크기 1은 I-MR을 검토해.
  4. 계수형이면 부적합품과 부적합 중 무엇을 세는지 구분해.
  5. 부적합품은 표본크기에 따라 p 또는 np를 선택해.
  6. 부적합은 검사기회에 따라 c 또는 u를 선택해.
  7. 관리계획서와 QC공정도에 지정된 관리방법을 최종 확인해.

🗂️ 관리계획서와 QC공정도 해석

관리도 작성은 계산부터 시작하지 않아. 관리계획서 또는 QC공정도에서 무엇을, 어디에서, 누가, 어떤 장비로, 얼마나 자주, 몇 개씩 측정하는지 먼저 확인해야 해.

🧪 데이터 수집과 합리적 부분군

합리적 부분군의 원리

합리적 부분군은 부분군 내부에는 주로 우연원인만 반영되고 이상원인에 의한 차이는 부분군 사이에서 드러나도록 구성한 표본 묶음이야. 매시간 연속 생산된 제품 5개를 한 부분군으로 삼는 방식이 대표적이지. 오전부터 오후까지 임의로 한 개씩 골라 한 부분군을 만들면 시간에 따른 변화가 부분군 내부에 섞여 이상신호가 약해질 수 있어. 부분군 내부 변동은 단기 산포를 추정하고 부분군 사이 차이는 시간에 따른 공정 변화를 탐지하는 데 쓰여.

데이터 수집 준칙

  1. 데이터를 실제 발생 순서대로 기록해.
  2. 측정 단위와 소수점 자릿수를 일관되게 유지해.
  3. 측정기 식별번호와 교정 상태를 확인해.
  4. 설비, 금형, 작업조, 원재료 로트의 추적정보를 기록해.
  5. 이상하게 보인다는 이유만으로 값을 임의로 삭제하지 마.
  6. 재측정이나 수정이 있었다면 이유와 이력을 남겨.
  7. 정해진 표본추출 주기와 부분군 크기를 임의로 바꾸지 마.
  8. 측정시스템의 반복성과 재현성이 목적에 적절한지 확인해.

측정시스템이 불안정하면 관리도가 공정이 아니라 측정기의 흔들림을 보여줄 수 있어. 데이터의 신뢰성이 의심되면 교정 이력, 측정자별 차이, 반복성 및 재현성 결과를 확인해야 해.

🧮 X̄-R 관리도 작성 예시

어떤 절삭공정에서 매시간 제품 5개의 지름을 측정했다고 하자. 단위는 mm이고 부분군 수는 5개야.

전체 평균과 평균 범위 계산

X̿ = (20.020 + 20.016 + 20.036 + 20.004 + 20.030) ÷ 5 = 20.0212

R̄ = (0.04 + 0.03 + 0.03 + 0.03 + 0.04) ÷ 5 = 0.034

부분군 크기 n = 5일 때 A₂ = 0.577, D₃ = 0, D₄ = 2.114를 적용하자.

X̄ 관리도의 관리한계

UCL = 20.0212 + 0.577 × 0.034 = 20.0408

CL = 20.0212

LCL = 20.0212 − 0.577 × 0.034 = 20.0016

부분군 평균은 모두 계산된 관리한계 안에 있으므로 이 자료에서 X̄ 관리도의 한계 이탈은 발견되지 않아.

R 관리도의 관리한계

UCL = 2.114 × 0.034 = 0.0719

CL = 0.034

LCL = 0 × 0.034 = 0

모든 부분군 범위는 0.03 또는 0.04이므로 R 관리도의 관리한계 안에 있어.

관리도 작성 절차

  1. 시간순으로 각 부분군의 측정값을 기록해.
  2. 각 부분군의 X̄ᵢ와 Rᵢ를 계산해.
  3. X̿와 R̄을 계산해.
  4. 부분군 크기에 맞는 A₂, D₃, D₄를 찾아.
  5. X̄ 관리도와 R 관리도의 CL, UCL, LCL을 계산해.
  6. 가로축에 시간 또는 부분군 번호를 표시해.
  7. 세로축에 평균 또는 범위를 표시해.
  8. 중심선과 관리한계선을 그어.
  9. 각 통계량을 시간순으로 타점하고 연결해.
  10. 한계 이탈과 비무작위 패턴을 판정해.
  11. 이상신호가 있으면 공정조건과 추적정보로 원인을 조사해.

해석 순서

X̄-R 관리도에서는 일반적으로 R 관리도를 먼저 확인하고 X̄ 관리도를 해석해. 산포가 관리상태가 아니라면 그 산포를 이용해 설정한 평균 관리도의 한계도 신뢰하기 어렵기 때문이야. 모든 점이 관리한계 안에 있어도 한쪽 편중, 연속 상승, 연속 하강 또는 주기성이 있는지 확인해야 해.

📊 p 관리도 작성 예시

한 검사공정에서 매일 제품 100개를 검사했고 부적합품수가 4개, 6개, 5개, 3개, 7개였다고 하자.

p̄ = 25 ÷ 500 = 0.05

UCL = 0.05 + 3√[0.05 × 0.95 ÷ 100] ≈ 0.1154

CL = 0.05

계산된 LCL은 약 −0.0154이므로 실제 표시값은 LCL = 0이야. 모든 관측 부적합품률이 0과 0.1154 사이에 있으므로 한계 이탈은 발견되지 않아. 다만 부분군이 다섯 개뿐이므로 장기 안정성을 충분히 입증했다고 단정할 수는 없어.

⚖️ 비교와 경계 조건

부적합품과 부적합

도장된 판 한 장에서 긁힘 세 곳이 발견됐다고 하자. 제품 단위로 합격과 불합격을 판단하면 부적합품 1개지만 결점 발생 건수를 세면 부적합 3개야. 부적합품률을 관리하면 p를, 동일한 면적에서 긁힘 수를 관리하면 c를 검토해. 이 구분을 놓치면 관리도의 분포 전제와 관리한계식이 달라져.

표본크기와 검사기회의 일정성

p와 u 관리도는 표본크기 또는 검사기회가 변해도 사용할 수 있지만 각 부분군의 관리한계가 달라질 수 있어. 표본크기가 크면 표준오차가 작아져 한계 폭이 좁아지고, 표본크기가 작으면 한계 폭이 넓어져. np 관리도는 표본크기가 일정해야 하며 c 관리도는 검사 단위의 크기와 결점 발생 기회가 일정하다는 전제가 중요해.

관리도와 공정능력

관리도는 시간적 안정성을 평가하고 공정능력지수는 안정된 공정의 분포가 규격 안에 얼마나 잘 들어가는지를 평가해. 불안정한 공정에서 계산한 Cp와 Cpk는 미래 공정을 대표하기 어려워. 원칙적으로 관리도로 안정성을 확인한 다음 안정된 데이터로 공정능력을 평가해야 해.

🚨 품질경영기사 실기 시험 함정

  1. 규격한계를 관리한계로 사용하지 마. 관리한계는 공정의 표본통계량으로 계산해.
  2. p와 np를 뒤바꾸지 마. p는 부적합품률이고 np는 일정 표본의 부적합품수야.
  3. c와 u는 부적합수 관리도야. 부적합품수와 혼동하면 안 돼.
  4. X̄ 관리도만 작성하지 마. X̄-R은 중심과 산포를 함께 판단하는 한 쌍이야.
  5. 관리도용 계수의 n을 정확히 읽어. n은 한 부분군의 관측값 수야.
  6. 계수형 관리도의 음수 하한은 0으로 처리해.
  7. 한계 안의 점도 패턴을 확인해. 편중, 추세와 주기성은 이상원인의 단서야.
  8. 한계 이탈을 불량 확정으로 표현하지 마. 이상원인 조사 신호라는 뜻이야.
  9. 이상점을 근거 없이 삭제하지 마. 원인을 확인하고 정해진 절차에 따라 재계산해야 해.

💡 정답 및 해설

  1. 3번, X̄-R 관리도. 지름은 계량형이고 매시간 5개로 부분군을 구성하므로 평균과 범위를 함께 관리해.
  2. 1번, p 관리도. 부적합품을 판정하고 표본크기가 변하므로 부적합품률을 표시해.
  3. 2번, c 관리도. 동일한 검사 단위에서 발생한 부적합수를 관리해.
  4. 2번, u 관리도. 검사 면적이 달라지므로 단위면적당 부적합수를 관리해.
  5. n = 4. n은 전체 부분군 수가 아니라 한 부분군의 관측값 수야.
  6. 관리상태라고 결론 내리면 안 돼. 산포에 이상신호가 있으므로 먼저 원인을 조사해야 하며 X̄ 관리도의 한계도 신뢰하기 어려워.
  7. LCL = 0. 부적합품률은 음수가 될 수 없어.
  8. 3번. 안정된 공정이라도 평균 위치나 산포 때문에 규격을 만족하는 능력이 부족할 수 있어.

✨ 요약

  • 관리도의 목적: 제품 합격 여부가 아니라 공정의 시간적 안정성을 판단해.
  • 관리한계: 실제 공정 데이터에서 계산하며 규격한계와 구분해야 해.
  • 계량형 관리도: 작은 부분군은 X̄-R, 큰 부분군은 X̄-S, 개별 측정은 I-MR을 검토해.
  • 부적합품 관리도: 부적합품률은 p, 일정한 표본의 부적합품수는 np를 사용해.
  • 부적합수 관리도: 일정한 검사기회는 c, 변동하는 검사기회는 u를 사용해.
  • 데이터 수집: 관리계획서 또는 QC공정도의 관리특성, 측정방법, 표본크기와 주기를 따라야 해.
  • 부분군: 공정의 시간 구조를 반영한 합리적 부분군을 구성해야 해.
  • 해석 순서: X̄-R 관리도에서는 산포를 나타내는 R 관리도를 먼저 확인해.
  • 이상신호: 한계 이탈은 불량 확정이 아니라 이상원인을 조사하라는 신호야.
  • 학습목표 1: 중점관리항목의 특성에 따라 해당되는 관리도의 종류를 선정할 수 있다.
  • 학습목표 2: 관리계획서 또는 QC공정도의 관리방법에 따라 데이터를 수집하여 관리도를 작성할 수 있다.
