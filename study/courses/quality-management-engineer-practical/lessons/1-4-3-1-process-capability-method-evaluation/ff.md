## 1. 공정능력이란 무엇인가

### 1.1 정의와 평가 전제

**공정능력**은 공정이 안정된 상태에서 요구 규격을 만족하는 제품을 지속적으로 만들어 낼 수 있는 고유한 능력이야. 일반적으로 공정 산포의 폭과 규격폭을 비교하고, 필요하면 공정 평균이 규격 중심에서 얼마나 벗어났는지도 함께 평가해.

공정이 정규분포를 따르고 평균이 μ, 표준편차가 σ라면 자연공차는 보통 다음과 같이 표현해.

**자연공차 = μ ± 3σ**

전체 자연공차 폭은 다음과 같아.

**자연공차 폭 = 6σ**

정규분포를 가정하면 μ ± 3σ 안에는 약 99.73%가 들어가. 따라서 규격폭이 6σ보다 넓을수록 공정 산포를 수용할 여유가 커지고, 규격폭이 더 좁으면 규격 이탈 가능성이 커져.

하지만 공정능력 분석에는 중요한 전제가 있어.

1. 측정시스템이 적절해야 해.
2. 데이터가 해당 공정을 대표해야 해.
3. 관리도 등으로 공정이 통계적 관리상태인지 확인해야 해.
4. 적용하려는 분석법의 분포 가정을 검토해야 해.
5. 규격한계와 관리한계를 혼동하지 않아야 해.

**규격한계**는 고객, 설계 또는 기술 요구가 정한 허용범위야. 반면 **관리한계**는 실제 공정 데이터로 계산한 통계적 변동범위야. 규격 안에 들어간다고 해서 공정이 안정된 것은 아니고, 관리상태라고 해서 반드시 규격을 만족하는 것도 아니야.

### 1.2 공정능력과 공정성능의 경계

단기간에 수집한 군내 변동을 사용하면 설비와 조건이 비교적 일정한 순간의 **잠재적 공정능력**을 볼 수 있어. 반대로 장기간 데이터에는 교대조, 원자재 로트, 작업자, 환경, 설비 마모와 같은 시간 경과의 영향이 포함되므로 실제 고객이 경험하는 **공정성능**에 가까워져.

대표적인 구분은 다음과 같아.

| 구분 | 주로 사용하는 변동 | 대표 지수 | 해석 |
|---|---|---:|---|
| 단기 능력 | 군내 표준편차 | Cp, Cpk | 안정된 조건에서의 잠재적·단기 능력 |
| 장기 성능 | 전체 표준편차 | Pp, Ppk | 시간에 따른 변화를 포함한 실제 성능 |
| 계수형 성능 | 불량률·결점수 | 불량률, DPU, DPMO | 연속 측정값이 없을 때의 결과 성능 |

일반적으로 장기 데이터에는 더 많은 변동요인이 섞이므로 전체 표준편차가 커질 수 있어. 그래서 같은 자료 체계에서 흔히 **Ppk가 Cpk보다 작게** 나타나. 두 지수의 차이가 크다면 평균 이동, 로트 차이, 교대조 차이 같은 장기 변동요인을 의심해야 해.

# Topic 1  
## 데이터의 수집기간과 유형에 따라 공정능력 분석방법을 선정할 수 있다.

### 2. 데이터 수집기간에 따른 분석방법 선정

#### 2.1 단기 데이터

단기 데이터는 비교적 짧은 기간에 동일하거나 유사한 조건에서 수집한 자료야. 합리적 부분군을 구성했다면 부분군 내부의 변동을 이용해 σ를 추정하고, **Cp와 Cpk**로 공정능력을 평가해.

대표적인 군내 표준편차 추정식은 다음과 같아.

**σ̂within = R̄ / d₂**

또는 부분군 표준편차를 이용해 다음처럼 추정할 수 있어.

**σ̂within = S̄ / c₄**

여기서 d₂와 c₄는 부분군 크기에 따라 정해지는 관리도 계수야.

단기 분석이 적절한 상황은 다음과 같아.

1. 설비의 잠재 능력을 확인하려는 경우
2. 초기 공정 승인이나 조건 설정을 검토하는 경우
3. 합리적 부분군을 구성해 군내 변동을 추정할 수 있는 경우
4. 관리도를 통해 공정의 안정성을 확인한 경우

단기 데이터가 짧다고 해서 무조건 좋은 것은 아니야. 우연히 가장 안정적인 시간대만 골랐다면 실제 장기 변동을 숨길 수 있어.

#### 2.2 장기 데이터

장기 데이터는 여러 날짜, 교대조, 작업자, 원자재 로트와 환경조건을 포함해 수집한 자료야. 이때는 전체 관측값의 표준편차 s를 사용하여 **Pp와 Ppk**를 계산하는 것이 일반적이야.

**Pp = (USL − LSL) / 6s**

**Ppk = min[(USL − x̄) / 3s, (x̄ − LSL) / 3s]**

장기 분석은 고객에게 실제로 공급되는 제품의 성능을 더 현실적으로 보여줘. 다만 공정이 불안정하면 Ppk는 여러 원인이 섞인 결과를 요약할 뿐이므로 원인 규명에는 관리도와 층별 분석이 함께 필요해.

### 3. 데이터 유형에 따른 분석방법 선정

#### 3.1 계량형 데이터

길이, 무게, 강도, 온도처럼 연속적인 수치로 측정되는 데이터야. 계량형 자료라면 평균과 표준편차를 이용해 Cp, Cpk, Pp, Ppk를 계산할 수 있어.

선정 절차는 다음과 같아.

1. 정규성 또는 적절한 분포모형을 검토해.
2. 시계열 순서와 관리도로 안정성을 확인해.
3. 단기 군내 변동이면 Cp와 Cpk를 선택해.
4. 장기 전체 변동이면 Pp와 Ppk를 선택해.
5. 양측규격인지 단측규격인지 확인해.

비정규 계량형 데이터에 정규분포 공식을 기계적으로 적용하면 꼬리 부분의 부적합률을 잘못 추정할 수 있어. 이때는 데이터 변환, 적합분포 모형 또는 분위수 기반 능력분석을 고려해야 해.

#### 3.2 계수형 데이터

합격·불합격, 불량품 수, 표면 흠집 개수처럼 분류하거나 세어서 얻는 데이터야. 연속 측정값의 평균과 표준편차가 없으므로 Cp와 Cpk를 직접 적용하는 것은 일반적으로 적절하지 않아.

대신 다음 지표를 활용해.

**불량률 = 불량품 수 / 검사품 수**

**DPU = 총 결점 수 / 검사 단위 수**

**DPMO = 총 결점 수 / 총 결점 기회 수 × 1,000,000**

계수형 분석은 결과 성능을 쉽게 보여주지만, 규격경계까지 얼마나 여유가 있는지는 알기 어려워. 예를 들어 지금까지 모두 합격했더라도 측정값이 상한규격 바로 아래에 몰려 있을 수 있어. 가능하다면 원래의 계량값을 보존하는 편이 더 많은 정보를 제공해.

### 4. 분석방법 선정표

| 판단 조건 | 권장 분석 |
|---|---|
| 안정된 공정, 계량형, 단기 부분군 자료 | Cp와 Cpk |
| 여러 기간의 변동을 포함한 계량형 자료 | Pp와 Ppk |
| 상한과 하한이 모두 존재 | Cp와 Cpk 또는 Pp와 Ppk |
| 상한만 존재 | CPU 또는 PPU |
| 하한만 존재 | CPL 또는 PPL |
| 합격·불합격 자료 | 불량률 또는 이항모형 |
| 단위당 결점 수 자료 | DPU, DPMO 또는 포아송모형 |
| 비정규 계량형 자료 | 변환법, 적합분포법 또는 분위수법 |
| 공정이 관리상태가 아님 | 능력판정 보류 후 이상원인 제거 |

### 5. Topic 1 구체적 예시

한 축가공 공정에서 한 시간 동안 동일 원자재와 동일 설비 조건으로 5개씩 부분군을 구성해 데이터를 수집했다고 해보자. 관리도에서 이상신호가 없고 정규성도 크게 문제되지 않는다면 군내 변동으로 σ를 추정하여 Cp와 Cpk를 적용할 수 있어.

반대로 3개월 동안 주간조와 야간조, 여러 원자재 로트에서 데이터를 한꺼번에 수집했다면 전체 표준편차를 이용한 Pp와 Ppk가 실제 장기 성능을 보여주는 데 더 적절해. 이때 단기 Cpk는 높지만 장기 Ppk가 낮다면 설비 자체의 순간 능력보다 시간에 따른 조건변화가 더 큰 문제라는 뜻이야.

### 6. Topic 1 시험 함정

1. **관리상태 확인 없이 Cpk부터 계산하는 오류**  
   불안정한 공정에서는 평균과 산포가 일정하지 않으므로 계산값의 예측력이 약해져.

2. **장기 전체 표준편차로 Cpk를 계산하는 오류**  
   문제에서 군내 표준편차인지 전체 표준편차인지 구분해야 해.

3. **계수형 불량자료에 Cp 공식을 바로 적용하는 오류**  
   Cp는 연속적인 품질특성과 표준편차를 전제로 해.

4. **표본 수가 많으면 자동으로 장기 데이터라고 판단하는 오류**  
   핵심은 자료의 개수보다 시간 범위와 포함된 변동원인이야.

5. **비정규분포에 정규분포 기반 부적합률을 무조건 적용하는 오류**  
   특히 한쪽 꼬리가 긴 자료에서는 실제 위험을 과소평가할 수 있어.

# Topic 2  
## 품질특성의 규격에 따라 공정능력을 평가할 수 있다.

### 7. 양측규격에서의 평가

하한규격을 LSL, 상한규격을 USL, 공정평균을 μ, 공정표준편차를 σ라고 하자.

#### 7.1 Cp: 산포의 잠재 능력

**Cp = (USL − LSL) / 6σ**

Cp는 규격폭과 공정의 자연공차 폭을 비교해. 평균의 치우침은 반영하지 않아.

| Cp 값 | 의미 |
|---:|---|
| Cp > 1 | 공정 산포가 규격폭보다 좁음 |
| Cp = 1 | 자연공차 폭과 규격폭이 같음 |
| Cp < 1 | 공정 산포가 규격폭보다 넓음 |

Cp가 높더라도 평균이 한쪽 규격에 가까우면 실제 부적합이 발생할 수 있어. 그러므로 Cp만으로 최종판정하면 안 돼.

#### 7.2 CPU와 CPL: 규격 방향별 능력

**CPU = (USL − μ) / 3σ**

**CPL = (μ − LSL) / 3σ**

CPU는 평균에서 상한규격까지의 여유를, CPL은 하한규격까지의 여유를 나타내.

#### 7.3 Cpk: 중심 치우침을 포함한 실제 능력

**Cpk = min(CPU, CPL)**

Cpk는 두 규격 중 평균에 더 가까운 위험 방향을 선택해. 다시 말해 공정의 능력은 가장 약한 쪽이 결정한다는 뜻이야.

양측규격에서는 항상 다음 관계가 성립해.

**Cpk ≤ Cp**

평균이 정확히 규격 중심에 있으면 CPU와 CPL이 같아지고 **Cpk = Cp**가 돼. 평균이 중심에서 벗어나면 **Cpk < Cp**가 돼.

### 8. 단측규격에서의 평가

품질특성에 따라 한쪽 규격만 의미가 있을 수 있어.

상한규격만 있는 경우에는 다음을 사용해.

**CPU = (USL − μ) / 3σ**

예를 들어 유해물질 함량, 소음, 불순물처럼 작을수록 좋은 특성이 여기에 해당할 수 있어.

하한규격만 있는 경우에는 다음을 사용해.

**CPL = (μ − LSL) / 3σ**

예를 들어 인장강도, 내구수명처럼 일정 수준 이상이어야 하는 특성이 여기에 해당할 수 있어.

단측규격 문제에서 존재하지 않는 반대편 규격을 임의로 만들어 Cp를 계산하면 안 돼. 평가하려는 위험 방향의 지수만 사용해야 해.

### 9. 중심 치우침의 정량화

규격 중심 M은 다음과 같아.

**M = (USL + LSL) / 2**

규격 반폭은 다음과 같아.

**T = (USL − LSL) / 2**

평균의 상대적 치우침을 k로 나타내면 다음과 같아.

**k = |μ − M| / T**

양측규격에서 다음 관계를 이용할 수 있어.

**Cpk = Cp(1 − k)**

이 식은 Cp가 산포만, Cpk가 산포와 중심 치우침을 함께 반영한다는 사실을 명확히 보여줘.

## 10. 계산 예제 1: 양측규격

어떤 축의 규격이 **20.00 ± 0.15 mm**, 공정평균이 **20.06 mm**, 표준편차가 **0.03 mm**라고 해보자.

따라서 다음과 같아.

**USL = 20.15**

**LSL = 19.85**

### 10.1 Cp 계산

**Cp = (20.15 − 19.85) / (6 × 0.03)**

**Cp = 0.30 / 0.18 = 1.667**

산포만 보면 규격폭에 비해 공정 산포가 충분히 좁아 보여.

### 10.2 CPU 계산

**CPU = (20.15 − 20.06) / (3 × 0.03)**

**CPU = 0.09 / 0.09 = 1.000**

### 10.3 CPL 계산

**CPL = (20.06 − 19.85) / (3 × 0.03)**

**CPL = 0.21 / 0.09 = 2.333**

### 10.4 Cpk 계산과 판정

**Cpk = min(1.000, 2.333) = 1.000**

Cp는 1.667이지만 Cpk는 1.000이야. 산포 자체는 작지만 평균이 상한규격 쪽으로 치우쳐 있어. 병목은 CPU이므로 우선 평균을 목표값 쪽으로 낮춰야 해.

만약 평균만 규격 중심인 20.00 mm로 조정하고 σ가 그대로라면 다음과 같아.

**Cpk = Cp = 1.667**

이 사례는 산포 축소보다 중심 조정이 먼저인 상황을 보여줘.

***

## 11. 계산 예제 2: 상한규격만 있는 경우

어떤 오염물질 농도는 **5.0 ppm 이하**여야 해. 공정평균은 3.8 ppm이고 표준편차는 0.4 ppm이라고 하자.

상한규격만 있으므로 CPU를 계산해.

**CPU = (5.0 − 3.8) / (3 × 0.4)**

**CPU = 1.2 / 1.2 = 1.00**

현재 평균에서 상한규격까지의 거리는 정확히 3σ야. 지수가 1이므로 충분한 여유가 있다고 보기 어렵고, 평균 상승이나 산포 증가에 취약해.

여기서는 하한규격이 주어지지 않았으므로 Cp와 CPL을 억지로 계산하면 안 돼.

***

## 12. 계산 예제 3: 단기 능력과 장기 성능 비교

규격이 40 ± 4, 평균이 41이라고 하자.

**USL = 44, LSL = 36**

군내 표준편차가 0.8이고 전체 표준편차가 1.2라면 단기 Cpk는 다음과 같아.

**CPU = (44 − 41) / (3 × 0.8) = 1.25**

**CPL = (41 − 36) / (3 × 0.8) = 2.083**

**Cpk = 1.25**

장기 Ppk는 다음과 같아.

**PPU = (44 − 41) / (3 × 1.2) = 0.833**

**PPL = (41 − 36) / (3 × 1.2) = 1.389**

**Ppk = 0.833**

짧은 기간에는 어느 정도 능력이 있어 보이지만 장기적으로는 상한규격 방향의 성능이 부족해. 평균을 낮추는 조치와 함께 시간대, 작업자, 원자재 로트에 따른 변동을 줄여야 해.

## 13. Cp와 Cpk의 조합 해석

| Cp | Cpk | 진단 | 우선 개선방향 |
|---|---|---|---|
| 높음 | 높음 | 산포가 작고 중심도 양호함 | 현재 조건 유지와 지속 감시 |
| 높음 | 낮음 | 산포는 작지만 평균이 치우침 | 공정 중심 조정 |
| 낮음 | 낮음 | 산포가 규격에 비해 큼 | 변동원인 제거와 산포 축소 |
| Cpk가 음수 | 매우 불량 | 평균이 규격 밖에 위치함 | 즉시 원인조사와 공정 시정 |

Cp가 낮으면 평균을 중앙으로 옮겨도 산포 문제가 남아. 반면 Cp는 충분히 높은데 Cpk만 낮다면 중심 조정이 효과적일 수 있어.

실무에서 1.00, 1.33, 1.67 같은 기준이 자주 언급되지만, 합격기준은 고객 요구, 산업 특성, 안전성, 회사 기준에 따라 달라질 수 있어. 따라서 문제에서 별도의 판정기준이 제시되면 반드시 그 기준을 적용해야 해.

### 14.1 규격한계와 관리한계

| 규격한계 | 관리한계 |
|---|---|
| 고객·설계 요구로 결정 | 공정 데이터로 계산 |
| 제품의 합격 여부 판단 | 공정의 안정상태 판단 |
| LSL과 USL | LCL과 UCL |
| 임의로 공정 데이터에 맞춰 바꾸면 안 됨 | 공정 변화에 따라 다시 계산될 수 있음 |

### 14.2 Cp와 Cpk

| Cp | Cpk |
|---|---|
| 규격폭과 산포만 비교 | 산포와 평균 치우침을 함께 반영 |
| 공정의 잠재 능력 | 현재 중심 위치를 고려한 능력 |
| 양측규격에 적용 | 양측 또는 방향별 단측평가 가능 |
| 평균 위치를 알 수 없음 | 작은 방향지수로 위험 방향 파악 |

### 14.3 Cpk와 불량률

Cpk는 공정의 평균과 산포를 압축한 능력지수이고, 불량률은 관측된 결과 비율이야. 표본에서 불량이 0개였다고 해서 Cpk가 충분하다고 단정할 수 없어. 반대로 정규성, 안정성, 표준편차 추정방식이 부적절하면 Cpk만으로 정확한 불량률을 예측하기도 어려워.

## 15. 품질경영기사 실기 계산 절차

시험에서는 다음 순서를 습관처럼 적용해봐.

1. **규격형태를 확인해.**  
   양측규격인지, 상한만 있는지, 하한만 있는지 판단해.

2. **기호를 정리해.**  
   USL, LSL, 평균, 표준편차를 적어.

3. **표준편차의 성격을 확인해.**  
   군내 표준편차인지 전체 표준편차인지 구분해.

4. **적절한 지수를 선택해.**  
   단기이면 Cp와 Cpk, 장기이면 Pp와 Ppk를 우선 검토해.

5. **방향별 지수를 계산해.**  
   양측규격에서는 CPU와 CPL을 각각 계산해.

6. **작은 값을 선택해.**  
   Cpk는 CPU와 CPL 중 작은 값이야.

7. **수치와 원인을 함께 판정해.**  
   산포 문제인지 중심 치우침 문제인지 설명해.

8. **개선방향을 제시해.**  
   평균 조정, 산포 축소, 장기 변동원인 제거 중 무엇이 필요한지 써.

## 16. 시험 함정 총정리

1. 분모의 **6σ와 3σ**를 바꾸지 마. Cp의 분모는 6σ이고 방향별 지수의 분모는 3σ야.
2. Cpk에서 CPU와 CPL 중 큰 값을 택하면 안 돼. 반드시 **작은 값**을 선택해.
3. 규격폭은 USL − LSL이야. 목표값을 규격폭으로 착각하면 안 돼.
4. 표준편차와 분산을 혼동하지 마. 분산이 주어지면 제곱근을 구해 σ로 바꿔야 해.
5. Cp가 높다는 이유만으로 공정이 우수하다고 판정하지 마. 평균 치우침을 확인해야 해.
6. 단측규격인데 존재하지 않는 반대편 규격을 임의로 설정하지 마.
7. Cpk가 음수라면 계산 실수라고 단정하지 마. 공정평균이 규격 밖에 있으면 실제로 음수가 될 수 있어.
8. 관리한계를 규격한계 대신 공식에 넣지 마.
9. 관리상태가 아닌 공정의 능력지수를 미래 성능처럼 단정하지 마.
10. 문제에서 요구한 소수점 자리와 반올림 조건을 마지막에 확인해.

# 확인 문제

## 문제 1

어떤 부품의 규격은 50 ± 3 mm이고, 공정평균은 51 mm, 군내 표준편차는 0.5 mm야. 공정이 관리상태라고 할 때 Cp, CPU, CPL, Cpk를 구하고 개선방향을 설명해봐.

## 문제 2

어떤 유해성분의 상한규격은 12 mg 이하야. 공정평균은 9 mg, 표준편차는 1 mg일 때 적절한 공정능력지수를 구해봐.

## 문제 3

다음 상황에 가장 적절한 분석방법을 골라봐.

1. 동일 설비에서 짧은 기간 동안 합리적 부분군으로 수집한 직경 데이터
2. 6개월 동안 여러 교대조와 원자재 로트를 포함해 수집한 무게 데이터
3. 검사제품 2,000개 중 불량품 수만 기록한 데이터
4. 계량형 데이터지만 분포가 심하게 오른쪽으로 치우친 데이터
5. 관리도에서 지속적인 평균 이동이 발견된 데이터

## 문제 4

규격이 90에서 110이고 공정평균이 100, 표준편차가 2일 때 Cp와 Cpk를 구해봐.

## 문제 5

규격이 90에서 110이고 공정평균이 106, 표준편차가 2일 때 Cp와 Cpk를 구해봐. 문제 4와 비교해 무엇이 달라졌는지도 설명해봐.

# 정답 및 해설

## 문제 1 정답

**USL = 53, LSL = 47, μ = 51, σ = 0.5**

**Cp = (53 − 47) / (6 × 0.5) = 6 / 3 = 2.00**

**CPU = (53 − 51) / (3 × 0.5) = 2 / 1.5 = 1.333**

**CPL = (51 − 47) / (3 × 0.5) = 4 / 1.5 = 2.667**

**Cpk = min(1.333, 2.667) = 1.333**

Cp가 2.00이므로 산포는 충분히 작지만 평균이 상한규격 방향으로 치우쳐 Cpk가 낮아졌어. 우선 평균을 규격 중심인 50 mm 쪽으로 조정해야 해.

## 문제 2 정답

상한규격만 있으므로 CPU를 사용해.

**CPU = (12 − 9) / (3 × 1) = 1.00**

상한규격까지의 거리가 3σ이므로 여유가 크지 않아. 평균을 낮추거나 산포를 줄이는 개선이 필요해.

## 문제 3 정답

1. **Cp와 Cpk**  
   단기 계량형 자료이며 합리적 부분군의 군내 변동을 사용할 수 있어.

2. **Pp와 Ppk**  
   장기간의 전체 변동을 포함한 계량형 자료야.

3. **불량률 또는 이항모형**  
   계수형 합격·불합격 자료이므로 Cp와 Cpk를 직접 적용하지 않아.

4. **비정규 공정능력 분석**  
   변환법, 적합분포법 또는 분위수 기반 분석을 고려해야 해.

5. **능력판정 보류 후 이상원인 조사**  
   공정이 통계적 관리상태가 아니므로 먼저 평균 이동의 원인을 제거해야 해.

## 문제 4 정답

**Cp = (110 − 90) / (6 × 2) = 20 / 12 = 1.667**

공정평균이 규격 중심 100과 같아.

**CPU = CPL = 10 / 6 = 1.667**

따라서 **Cpk = 1.667**이야.

## 문제 5 정답

산포와 규격폭은 문제 4와 같으므로 다음과 같아.

**Cp = 1.667**

방향별 지수는 다음과 같아.

**CPU = (110 − 106) / (3 × 2) = 4 / 6 = 0.667**

**CPL = (106 − 90) / (3 × 2) = 16 / 6 = 2.667**

따라서 다음과 같아.

**Cpk = min(0.667, 2.667) = 0.667**

문제 4와 비교하면 산포는 변하지 않아 Cp가 같지만, 평균이 상한규격 쪽으로 이동해 Cpk가 크게 낮아졌어. 이것이 Cp와 Cpk를 함께 확인해야 하는 이유야.
