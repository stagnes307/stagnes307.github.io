# 1-4-3-2. 공정능력 결과를 개선 행동으로 바꾸는 법
품질경영기사 실기  
공정능력평가하기 (2/2)

**학습 목표**

- 공정능력 평가결과를 활용하여 개선 방향을 수립할 수 있다.
- 수립한 개선 방향에 따라 공정능력 향상 활동을 수행할 수 있다.

이번 레슨의 핵심은 공정능력지수를 계산하는 데서 멈추지 않고, **계산 결과가 알려 주는 문제 유형을 판별한 뒤 실제 개선 활동으로 연결하는 것**이야. 숫자는 진단 결과이고, 개선은 그 진단에 맞는 처방이라고 생각하면 돼. 😊

***

## 1. 공정능력평가의 전제부터 확인하기

공정능력은 공정에서 만들어지는 제품의 산포가 규격 범위 안에 얼마나 안정적으로 들어가는지를 나타내. 대표적인 지수는 다음과 같아.

- **Cp**: 공정의 산포와 규격폭을 비교한 잠재적 공정능력
- **Cpk**: 산포뿐 아니라 공정평균의 치우침까지 반영한 실제적 공정능력
- **CPU**: 상한규격을 기준으로 평가한 단측 공정능력
- **CPL**: 하한규격을 기준으로 평가한 단측 공정능력

공정능력지수는 다음과 같이 계산해.

**Cp = (USL − LSL) / 6σ**

**CPU = (USL − μ) / 3σ**

**CPL = (μ − LSL) / 3σ**

**Cpk = min(CPU, CPL)**

여기서 USL은 규격상한, LSL은 규격하한, μ는 공정평균, σ는 공정표준편차야.

하지만 계산보다 먼저 확인해야 할 조건이 있어. **공정이 통계적으로 안정된 관리상태여야 한다는 것**이야. 관리도에 이상점, 연속 상승, 한쪽 편중 같은 이상 패턴이 존재한다면 공정의 평균과 산포가 시간에 따라 변하고 있다는 뜻이야. 이런 상태에서 계산한 Cp와 Cpk는 미래의 공정능력을 대표하기 어려워.

따라서 올바른 순서는 다음과 같아.

1. 관리도로 공정의 안정상태를 확인한다.
2. 이상원인이 있으면 원인을 제거한다.
3. 안정된 데이터로 평균과 표준편차를 추정한다.
4. Cp와 Cpk를 계산한다.
5. 지수의 조합을 해석한다.
6. 문제 유형에 맞는 개선 활동을 수립한다.
7. 개선 후 같은 조건으로 다시 평가한다.

***

## 2. Cp와 Cpk의 차이로 문제 유형 판별하기

Cp는 공정평균의 위치를 고려하지 않아. 그래서 공정평균이 규격 중심에서 벗어나더라도 산포가 작으면 높은 값이 나올 수 있어. 반면 Cpk는 평균에서 가까운 규격한계까지의 거리를 이용하므로 평균의 치우침을 반영해.

두 지수의 관계를 함께 보면 개선 방향이 선명해져.

| 평가 결과 | 공정 상태 | 우선 개선 방향 |
|---|---|---|
| Cp가 높고 Cpk도 높음 | 산포가 작고 중심도 양호함 | 현재 조건의 표준화와 유지관리 |
| Cp가 높고 Cpk가 낮음 | 잠재능력은 충분하지만 평균이 치우침 | 공정 중심 조정 |
| Cp와 Cpk가 모두 낮음 | 산포가 크며 중심 치우침도 존재할 수 있음 | 산포 축소를 우선하고 중심도 함께 점검 |
| Cp와 Cpk가 거의 같음 | 평균이 대체로 규격 중심에 있음 | 산포 축소 여부를 판단 |
| Cpk가 매우 낮거나 음수 | 평균이 규격한계에 가깝거나 규격을 벗어남 | 즉시 원인 분석과 공정 조건 수정 |

항상 **Cpk ≤ Cp**가 성립해. 공정평균이 정확히 규격 중심에 위치하면 CPU와 CPL이 같아지고, 그 결과 Cp와 Cpk가 같아져.

Cp와 Cpk의 차이가 크다는 것은 산포보다 **중심 치우침**이 주요 문제라는 신호야. 반대로 두 값이 비슷하면서 모두 낮다면 중심은 비교적 맞지만 **산포 자체가 지나치게 큰 상태**라고 판단할 수 있어.

## 3. 계산 결과에서 개선 방향 도출하기

어떤 공정의 규격이 9.5 이상 10.5 이하이고, 공정평균이 10.2, 표준편차가 0.1이라고 해보자.

**Cp 계산**

Cp = (10.5 − 9.5) / (6 × 0.1)  
Cp = 1.0 / 0.6  
Cp = 1.67

**CPU 계산**

CPU = (10.5 − 10.2) / (3 × 0.1)  
CPU = 0.3 / 0.3  
CPU = 1.00

**CPL 계산**

CPL = (10.2 − 9.5) / (3 × 0.1)  
CPL = 0.7 / 0.3  
CPL = 2.33

따라서 다음과 같아.

**Cpk = min(1.00, 2.33) = 1.00**

Cp는 1.67로 충분히 높지만 Cpk는 1.00이야. 공정 산포를 줄일 잠재력보다 먼저 살펴야 할 문제는 **평균이 상한규격 쪽으로 치우쳐 있다는 것**이야.

이 경우 분산을 무작정 줄이기보다 설비 설정값, 공구 보정값, 온도 설정 또는 투입량을 조정하여 평균을 목표값 10.0에 가깝게 이동시키는 것이 효율적이야.

표준편차가 0.1로 유지되고 평균만 10.0으로 조정되면 다음과 같아.

CPU = (10.5 − 10.0) / 0.3 = 1.67  
CPL = (10.0 − 9.5) / 0.3 = 1.67  
Cpk = 1.67

산포를 전혀 줄이지 않았는데도 중심 조정만으로 Cpk가 1.00에서 1.67로 향상됐어. 이것이 **평균 개선과 산포 개선을 구분해야 하는 이유**야.

## 4. 공정능력 향상 활동의 세 가지 축

### 4.1 공정평균의 중심 조정

Cp는 양호하지만 Cpk가 낮을 때 적용하는 대표적인 활동이야.

- 설비의 기준 설정값을 목표값에 맞춘다.
- 공구 마모에 따른 보정 주기를 설정한다.
- 계량기와 센서의 영점을 교정한다.
- 원료 투입량과 가공시간을 재조정한다.
- 작업자별 설정 차이를 표준작업으로 통일한다.
- 공정평균의 이동 추세를 관리도로 감시한다.

중심 조정은 단순히 한 번 설정값을 바꾸는 활동이 아니야. 시간이 지나면서 공구 마모나 온도 변화 때문에 평균이 다시 이동할 수 있으므로 **조정 기준과 확인 주기**까지 표준화해야 해.

### 4.2 공정 산포의 축소

Cp와 Cpk가 모두 낮거나 두 값이 비슷하게 낮을 때 핵심이 되는 활동이야.

- 원재료의 로트 간 변동을 줄인다.
- 설비의 진동, 유격, 온도 변동을 개선한다.
- 치공구의 정밀도와 반복성을 높인다.
- 작업방법과 작업 순서를 표준화한다.
- 작업자 교육으로 작업자 간 차이를 줄인다.
- 측정시스템분석을 통해 측정오차를 줄인다.
- 실험계획법으로 중요 인자와 최적 조건을 찾는다.
- 예방보전으로 설비 열화를 관리한다.

산포 감소는 결과값만 조정해서는 달성되지 않아. 변동을 만드는 원인을 **사람, 설비, 재료, 방법, 측정, 환경**의 관점에서 나누어 찾아야 해.

### 4.3 공정의 안정화

관리도에서 이상원인이 발견되면 공정능력지수 개선보다 먼저 수행해야 해.

- 이상이 발생한 시간과 생산 로트를 식별한다.
- 설비 고장, 자재 변경, 작업자 교대와 연결해 본다.
- 우연원인과 이상원인을 구분한다.
- 확인된 이상원인을 제거하거나 재발방지 조치를 수립한다.
- 조치 후 관리한계를 다시 계산한다.
- 안정된 기간의 데이터로 공정능력을 재평가한다.

안정되지 않은 공정에서 평균이나 산포만 조정하면 원인이 가려지거나 오히려 변동이 커질 수 있어. **안정화가 먼저이고 능력 향상은 그다음**이라는 순서를 기억해 둬.

## 5. 개선 활동을 실행하는 실무 절차

공정능력 향상은 PDCA 구조로 정리하면 답안을 안정적으로 작성할 수 있어.

### Plan: 개선 목표와 원인 설정

현재 Cp와 Cpk, 불량률, 관리도 상태를 확인하고 목표값을 정해. 예를 들어 “Cpk를 1.00에서 1.33 이상으로 향상한다”처럼 수치화하는 것이 좋아.

그다음 산점도, 특성요인도, 파레토도, 층별, 체크시트 같은 품질도구로 원인을 좁혀. Cp와 Cpk의 차이가 크면 평균을 움직이는 원인을, 두 값이 모두 낮으면 산포를 만드는 원인을 우선 조사해.

### Do: 개선안 시험 적용

설정조건 변경, 공구 교체주기 단축, 자재 기준 강화, 작업방법 표준화 같은 개선안을 작은 범위에서 시험해. 여러 인자가 동시에 영향을 준다면 실험계획법을 활용해 어떤 인자가 평균과 산포에 유의한 영향을 주는지 확인할 수 있어.

### Check: 효과 검증

개선 전후 데이터를 같은 방법으로 수집하고 비교해야 해. 평균, 표준편차, Cp, Cpk뿐 아니라 관리도 안정상태도 함께 확인해.

Cpk가 높아졌더라도 공정이 불안정해졌다면 성공한 개선으로 볼 수 없어. 또한 표본 수, 측정기, 작업조건이 서로 다르면 개선 효과와 조건 차이를 구분하기 어려워.

### Act: 표준화와 지속관리

효과가 확인된 조건을 작업표준서, 설비조건표, 검사기준서에 반영해. 담당자, 점검 주기, 이상 시 조치기준을 정하고 관리도로 유지상태를 감시해야 해.

개선 효과가 확인되지 않았다면 원인 가설을 다시 검토하고 다음 PDCA를 진행해. 공정능력 향상은 일회성 계산이 아니라 **변동을 지속해서 줄이는 순환 활동**이야.

## 6. 개선 우선순위를 정하는 판단 지도

공정능력 결과를 받으면 다음 순서로 판단하면 돼.

**첫째, 공정이 안정되어 있는가?**

안정되지 않았다면 관리도의 이상원인을 제거해. 이 단계에서는 Cp와 Cpk만으로 장기 개선 방향을 확정하면 안 돼.

**둘째, Cp가 요구수준을 충족하는가?**

Cp가 낮다면 규격폭에 비해 공정 산포가 크다는 뜻이야. 설비, 재료, 작업방법, 측정의 변동을 줄이는 활동이 필요해.

**셋째, Cp와 Cpk의 차이가 큰가?**

차이가 크다면 평균이 규격 중심에서 벗어나 있어. 설정값과 보정값을 조정하고 평균 이동의 원인을 관리해야 해.

**넷째, 개선 효과가 지속되는가?**

개선 직후의 지수만 보지 말고 시간에 따른 안정성과 재현성을 확인해야 해. 효과가 유지되면 표준화하고, 다시 악화되면 관리항목과 점검 주기를 보완해.

공정능력지수의 일반적인 해석 기준은 회사, 고객 또는 제품 특성에 따라 달라질 수 있어. 시험에서는 별도 기준이 제시되지 않았다면 수치의 상대적 크기와 Cp·Cpk의 관계를 중심으로 판단하고, 문제에 주어진 판정기준이 있다면 그 기준을 우선 적용해야 해.

## 7. 실제 개선 사례

샤프트 직경 공정의 규격이 19.70mm 이상 20.30mm 이하라고 하자. 개선 전 평균은 20.12mm, 표준편차는 0.075mm였어.

Cp = 0.60 / (6 × 0.075) = 1.33

CPU = (20.30 − 20.12) / (3 × 0.075) = 0.80

CPL = (20.12 − 19.70) / (3 × 0.075) = 1.87

Cpk = 0.80

Cp는 1.33이지만 Cpk는 0.80이므로 평균 치우침이 핵심 문제야. 조사 결과 공구가 마모되면서 직경 평균이 점차 커졌고, 작업자가 불규칙하게 보정하고 있었어.

개선팀은 다음 활동을 수행했어.

1. 공구 사용시간별 직경 변화를 기록했다.
2. 공구 마모와 평균 이동의 관계를 분석했다.
3. 공구 교체주기와 보정시점을 표준화했다.
4. 작업자별 보정방법을 하나의 작업표준으로 통일했다.
5. 평균을 규격 중심인 20.00mm에 맞췄다.
6. 관리도로 평균 이동과 산포를 지속 감시했다.

개선 후 평균이 20.00mm, 표준편차가 0.060mm가 되었다면 다음과 같아.

Cp = 0.60 / (6 × 0.060) = 1.67

CPU = (20.30 − 20.00) / (3 × 0.060) = 1.67

CPL = (20.00 − 19.70) / (3 × 0.060) = 1.67

Cpk = 1.67

이 사례에서는 **중심 조정과 산포 축소가 동시에 이루어졌고**, 공구 관리기준까지 표준화하여 효과의 지속성을 확보했어.

## 8. 비교와 경계 조건

### 규격한계와 관리한계

규격한계는 고객이나 설계가 요구하는 제품의 허용범위야. 관리한계는 실제 공정 데이터로 계산하며 공정의 안정성을 판정하는 통계적 경계야.

규격 안에 제품이 모두 들어가더라도 관리도에 이상 패턴이 있으면 공정은 불안정할 수 있어. 반대로 공정이 안정되어 있어도 산포가 규격폭보다 크면 불량이 지속적으로 발생할 수 있어.

### 공정능력과 공정성능

단기 공정능력은 공정 내부의 비교적 짧은 기간 변동을 중심으로 평가하고, 장기 공정성능은 시간, 교대, 로트, 환경 변화까지 포함한 전체 변동을 반영해. 장기 변동이 단기 변동보다 큰 경우가 많으므로 일반적으로 장기 성능지수는 더 낮아질 수 있어.

### 지수 향상과 규격 변경

규격폭을 넓히면 Cp와 Cpk는 수학적으로 커질 수 있지만, 이것을 공정 자체가 개선되었다고 표현해서는 안 돼. 진정한 공정능력 향상은 평균의 치우침과 공정변동을 줄여 달성해야 해.

***

## 9. 시험에서 자주 나오는 함정

**함정 1: Cp가 높으면 공정이 무조건 우수하다.**

Cp는 중심 치우침을 반영하지 않아. 반드시 Cpk와 함께 확인해야 해.

**함정 2: Cpk가 낮으면 무조건 산포부터 줄인다.**

Cp가 높은데 Cpk만 낮다면 산포보다 중심 조정이 우선이야.

**함정 3: 관리상태 확인 없이 공정능력을 확정한다.**

불안정한 공정의 평균과 표준편차는 지속적으로 변할 수 있으므로 먼저 이상원인을 제거해야 해.

**함정 4: Cpk 계산에서 CPU와 CPL 중 큰 값을 선택한다.**

Cpk는 불량 위험이 더 큰 쪽을 반영해야 하므로 두 값 중 **작은 값**을 선택해.

**함정 5: 평균을 목표값으로 이동시키면 Cp도 증가한다.**

표준편차와 규격폭이 그대로라면 Cp는 변하지 않아. 중심 조정은 주로 Cpk를 높여.

**함정 6: 개선 후 지수만 다시 계산하면 충분하다.**

관리도 안정성, 표본 조건, 측정방법, 개선 효과의 지속성도 검증해야 해.

**함정 7: 규격폭 확대를 공정개선이라고 판단한다.**

지수는 상승할 수 있지만 공정의 고유한 변동이나 평균 치우침이 개선된 것은 아니야.

## 10. 확인 문제

### 문제 1

어떤 공정의 Cp가 1.67이고 Cpk가 0.92이다. 가장 먼저 검토해야 할 개선 방향을 설명해 봐.

### 문제 2

규격이 50 ± 3이고 공정평균이 51, 표준편차가 0.5일 때 Cp와 Cpk를 계산해 봐.

### 문제 3

공정능력평가 전에 관리도를 확인해야 하는 이유를 한 문장으로 설명해 봐.

### 문제 4

개선 전후 평균은 모두 100이지만 표준편차가 2.0에서 1.5로 감소했다. 규격폭이 동일하다면 Cp와 Cpk는 어떤 방향으로 변하는지 설명해 봐.

### 문제 5

공정능력 향상 활동이 끝난 뒤 표준화해야 할 항목을 세 가지 제시해 봐.

***

## 11. 정답과 해설

### 문제 1 해설

Cp는 높지만 Cpk가 낮으므로 공정의 잠재적 산포 능력은 충분하고 평균이 규격 중심에서 치우쳤을 가능성이 커. 설비 설정값, 공구 보정, 센서 영점과 같은 **공정 중심 조정 요인**을 먼저 검토해야 해.

### 문제 2 해설

USL = 53, LSL = 47, μ = 51, σ = 0.5야.

Cp = (53 − 47) / (6 × 0.5) = 6 / 3 = 2.00

CPU = (53 − 51) / (3 × 0.5) = 2 / 1.5 = 1.33

CPL = (51 − 47) / (3 × 0.5) = 4 / 1.5 = 2.67

Cpk = min(1.33, 2.67) = 1.33

Cp와 Cpk의 차이가 있으므로 평균이 상한규격 쪽으로 치우쳐 있어.

### 문제 3 해설

공정이 불안정하면 평균과 산포가 시간에 따라 변하므로 계산된 공정능력지수가 미래의 공정을 신뢰성 있게 대표할 수 없기 때문이야.

### 문제 4 해설

규격폭이 같고 표준편차가 감소하면 분모인 6σ와 3σ가 작아져 Cp와 Cpk가 모두 증가해. 평균이 규격 중심에 유지되었다면 두 지수는 같은 비율로 향상돼.

### 문제 5 해설

설비 설정조건, 공구 교체와 보정주기, 작업방법, 검사방법, 관리도 점검주기, 이상 발생 시 조치기준 가운데 세 가지를 제시하면 돼. 핵심은 개선 조건을 개인의 경험이 아니라 문서화된 관리기준으로 전환하는 것이야.

## 12. 회상 요약

- 공정능력평가는 **안정된 공정**을 대상으로 수행해야 해.
- Cp는 산포의 잠재능력, Cpk는 산포와 평균 치우침을 함께 보여 줘.
- **Cp가 높고 Cpk가 낮으면 중심 조정**이 우선이야.
- **Cp와 Cpk가 모두 낮으면 산포 축소**가 핵심이야.
- 관리도에 이상이 있으면 능력 개선보다 **이상원인 제거와 안정화**를 먼저 수행해.
- 개선은 목표 설정, 원인 분석, 시험 적용, 효과 검증, 표준화 순으로 진행해.
- 개선 전후에는 평균, 표준편차, Cp, Cpk와 관리상태를 같은 조건에서 비교해야 해.
- 규격을 넓혀 지수를 높이는 것은 공정 자체의 능력 향상과 구별해야 해.
- 개선 효과는 작업표준, 설비조건, 점검주기와 조치기준으로 고정해야 지속될 수 있어.

마지막으로 한 문장만 기억해도 좋아. **Cp는 공정이 가질 수 있는 능력이고, Cpk는 현재 실제로 발휘하고 있는 능력이야.** 두 값의 차이를 읽으면 무엇부터 개선해야 할지 보이기 시작해. 😊
