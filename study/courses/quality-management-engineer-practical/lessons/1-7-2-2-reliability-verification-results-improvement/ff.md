## 1. 신뢰성시험 결과에 근거하여 개선 방향을 설정할 수 있다.

### 1.1 개선 방향 설정의 의미

**개선 방향 설정**은 신뢰성시험에서 얻은 수명, 고장시간, 고장률, 고장모드와 시험조건을 분석하여 개선 대상을 정하고 목표 수준과 접근 방법을 결정하는 일이야.

핵심 흐름은 다음과 같아.

1. 시험 목적과 판정기준을 다시 확인한다.
2. 시험 데이터의 유효성을 검토한다.
3. 신뢰성 지표를 산출하고 목표와 비교한다.
4. 고장모드와 고장원인을 분석한다.
5. 영향도와 발생 가능성을 기준으로 우선순위를 정한다.
6. 설계·재료·공정·검사·사용조건 가운데 개선 영역을 선택한다.
7. 수치로 확인할 수 있는 개선 목표를 정한다.
8. 재시험과 효과 검증 방법을 계획한다.

즉, **결과 확인 → 원인 구조화 → 우선순위 결정 → 개선 목표 설정**의 순서로 진행해야 해.

### 1.2 시험 결과의 기본 지표

신뢰성시험 결과를 해석할 때 자주 사용하는 지표는 다음과 같아.

| 지표 | 의미 | 개선 판단에서의 활용 |
|---|---|---|
| 신뢰도 R(t) | 시간 t까지 고장 없이 작동할 확률 | 임무시간에서 목표 신뢰도 충족 여부 판단 |
| 불신뢰도 F(t) | 시간 t까지 고장날 확률 | 누적 고장 위험의 크기 판단 |
| 고장률 λ(t) | 특정 시점에서 순간적으로 고장날 정도 | 초기·우발·마모 고장 구간 구분 |
| 평균수명 MTTF | 비수리계 제품의 평균 고장시간 | 부품이나 제품의 수명 수준 비교 |
| 평균고장간격 MTBF | 수리계 시스템의 고장 간 평균 작동시간 | 설비나 시스템의 운용 신뢰성 평가 |
| B₁₀ 수명 | 모집단의 10%가 고장나는 수명 | 하위 수명 보증과 내구성 판단 |
| 형상모수 β | 와이블분포에서 고장 양상의 변화 특성 | 초기고장·우발고장·마모고장 판별 |
| 척도모수 η | 누적고장확률이 약 63.2%가 되는 특성수명 | 집단의 대표적인 수명 규모 판단 |

신뢰도와 불신뢰도의 관계는 다음과 같아.

**F(t) = 1 − R(t)**

고장률이 일정한 지수분포를 따른다면 다음 관계를 사용할 수 있어.

**R(t) = e^(−λt)**

**MTTF = 1 / λ**

와이블분포의 신뢰도는 다음과 같이 표현할 수 있어.

**R(t) = exp[−(t/η)^β]**

여기서 β는 특히 중요해.

| β의 범위 | 고장 특성 | 대표 원인 | 일반적인 개선 방향 |
|---|---|---|---|
| β < 1 | 시간이 지날수록 고장률 감소 | 초기 결함, 조립 불량, 잠재 결함 | 공정 안정화, 선별검사, 번인 |
| β = 1 | 고장률이 거의 일정 | 우발적 과부하, 외란, 무작위 고장 | 안전여유 확보, 보호회로, 중복설계 |
| β > 1 | 시간이 지날수록 고장률 증가 | 마모, 피로, 열화, 부식 | 재료·구조 개선, 예방교체, 정비주기 조정 |

**시험 함정:** β가 크면 신뢰성이 무조건 좋다고 해석하면 안 돼. β는 수명의 절대적 크기보다 **고장률이 시간에 따라 어떻게 변하는가**를 나타내는 값이야. 수명 수준은 η, B₁₀ 수명과 함께 판단해야 해.

### 1.3 결과 분석의 출발점: 데이터 유효성 확인

시험 결과가 나쁘다고 곧바로 설계를 바꾸면 안 돼. 먼저 시험 자체가 올바르게 수행됐는지 확인해야 해.

1. 시험장비의 교정 상태가 유효했는지 확인한다.
2. 온도, 습도, 진동, 전압과 하중이 계획 범위에 있었는지 확인한다.
3. 시료가 모집단을 대표하도록 선정됐는지 확인한다.
4. 시료 수와 시험시간이 판단에 충분했는지 검토한다.
5. 고장 판정기준이 시험 전후에 동일하게 적용됐는지 확인한다.
6. 중도절단 자료가 적절하게 기록됐는지 확인한다.
7. 시료 취급이나 측정 과정에서 인위적 손상이 발생하지 않았는지 확인한다.

예를 들어 시험기의 온도가 설정값보다 지나치게 높았다면 관측된 고장을 제품 설계 결함이라고 단정할 수 없어. 반대로 시험조건이 실제 사용환경보다 지나치게 약했다면 합격 결과도 현장 신뢰성을 보장하지 못해.

**비교와 경계:** 이상치는 무조건 제거하는 값이 아니야. 측정 오류나 기록 오류라면 수정하거나 제외할 수 있지만, 실제 희귀 고장이라면 오히려 중요한 개선 단서야. 이상치를 제외할 때는 기술적 근거와 처리 이력을 남겨야 해.

### 1.4 목표와 실제 결과의 차이 분석

개선 방향은 막연한 인상이 아니라 **목표값과 관측값의 차이**에서 출발해야 해.

예를 들어 요구조건이 다음과 같다고 해보자.

- 임무시간 1,000시간에서 목표 신뢰도: 0.95
- 시험 결과의 추정 신뢰도: 0.88
- 주요 고장모드: 베어링 마모
- 고장 시점: 620시간에서 900시간 사이에 집중
- 와이블 형상모수: β = 2.4

β가 1보다 크고 고장이 후기 구간에 집중됐으므로 전형적인 마모형 고장으로 볼 수 있어. 이때 단순 출하검사 강화는 근본 개선책이 되기 어려워. 개선 방향은 **베어링 재질과 정격용량 검토, 윤활 조건 개선, 축 정렬 정밀도 향상, 분진 유입 방지, 예방교체 주기 재설정** 쪽으로 잡는 게 타당해.

반대로 β가 0.6이고 조립 직후 고장이 집중된다면 방향이 달라져. 이때는 부품 수명을 늘리는 것보다 **조립조건 표준화, 작업자 오류 방지, 공급품 선별, 초기 스크리닝과 번인 조건 개선**이 먼저야.

### 1.5 고장모드 중심의 개선 방향

시험 결과는 평균값 하나보다 **어떤 고장이 얼마나 자주 발생했는지**가 더 많은 정보를 줄 수 있어.

고장모드는 현상이고 고장원인은 그 현상을 만든 이유야.

| 구분 | 예시 |
|---|---|
| 고장모드 | 누설, 단선, 균열, 출력 저하, 작동 정지 |
| 직접 원인 | 실링 손상, 납땜 균열, 베어링 마모 |
| 근본 원인 | 재료 선정 오류, 열응력 집중, 공정조건 편차, 설계 여유 부족 |

예를 들어 “모터가 정지했다”는 고장모드일 뿐이야. 분해 결과 베어링이 손상됐고, 윤활제가 고온에서 열화됐으며, 실제 사용온도가 설계 가정보다 높았다면 근본 개선 방향은 윤활제 변경과 열설계 수정이 될 수 있어.

고장모드별 발생 건수는 파레토도로 정리할 수 있어. 전체 고장의 대부분을 차지하는 핵심 고장모드를 먼저 개선하면 제한된 자원으로 큰 효과를 얻을 수 있지. 다만 발생 빈도가 낮더라도 안전사고나 법규 위반을 유발하는 고장은 최우선으로 다뤄야 해.

### 1.6 개선 우선순위 결정

개선 우선순위는 일반적으로 다음 요소를 종합해 정해.

- **심각도:** 고장이 안전, 기능, 고객, 법규에 미치는 영향
- **발생도:** 해당 고장모드의 발생 빈도나 발생 가능성
- **검출도:** 출하 전 또는 사용 중 고장을 발견하기 어려운 정도
- **목표 미달 폭:** 요구 신뢰도와 관측 신뢰도의 차이
- **개선 가능성:** 기술적 해결 가능성과 예상 효과
- **비용과 기간:** 변경에 필요한 자원과 일정
- **파급 범위:** 동일 부품이나 공정을 사용하는 다른 제품에 미치는 영향

FMEA에서는 흔히 위험우선순위수인 RPN을 참고할 수 있어.

**RPN = 심각도 × 발생도 × 검출도**

예를 들어 심각도 9, 발생도 6, 검출도 7이면 RPN은 378이야. 하지만 RPN만 기계적으로 비교하면 안 돼. 심각도가 10인 안전 고장은 발생 빈도가 낮더라도 즉시 조치할 수 있어야 해.

**시험 함정:** RPN이 가장 큰 항목만 개선한다고 쓰면 불완전한 답이 될 수 있어. 안전·법규 관련 고장은 심각도를 독립적으로 검토하고, 신뢰성시험에서 실제 확인된 고장 증거와 함께 판단해야 해.

### 1.7 개선 방향의 유형

| 개선 영역 | 적용 상황 | 대표적인 조치 |
|---|---|---|
| 설계 개선 | 응력 집중, 용량 부족, 열설계 결함 | 안전계수 확대, 구조 변경, 방열 개선 |
| 재료 개선 | 마모, 부식, 피로, 열화 | 내열·내식 재료 적용, 표면처리 변경 |
| 부품 개선 | 특정 부품의 수명 부족 | 정격 상향, 공급자 변경, 고신뢰성 부품 적용 |
| 공정 개선 | 조립 편차, 접합 불량, 오염 | 조건 최적화, 치공구 개선, 포카요케 적용 |
| 검사 개선 | 잠재 결함의 유출 | 검사 항목 추가, 검출감도 향상, 자동검사 도입 |
| 사용조건 개선 | 과부하, 오사용, 환경 초과 | 보호기능 추가, 경고 표시, 매뉴얼 수정 |
| 정비 개선 | 마모고장과 교체 지연 | 점검주기 단축, 예방교체 기준 설정 |
| 시험 개선 | 시험조건이 현장을 대표하지 못함 | 시험 프로파일 수정, 가속조건 재설계 |

### 1.8 구체적인 예시

전자제어기의 고온수명시험에서 100개 중 12개가 고장났고, 그중 8개가 전원부 납땜 균열이었다고 해보자. 고장품 단면 분석 결과 무거운 부품 주변의 열팽창 차이와 진동이 균열을 키웠어.

이때 개선 방향은 다음처럼 설정할 수 있어.

1. 전원부 부품의 지지구조를 보강한다.
2. 납땜부 형상과 패드 설계를 수정한다.
3. 리플로 온도 프로파일의 관리범위를 재설정한다.
4. 열팽창계수가 적합한 재료를 검토한다.
5. 변경품에 대해 온도사이클시험과 진동시험을 다시 수행한다.
6. 동일 설계를 사용하는 다른 모델로 수평 전개한다.

단순히 “납땜검사를 강화한다”라고만 하면 균열을 검출할 수는 있어도 균열이 생기는 구조는 남아 있어. **검출 강화는 유출 방지책이고, 설계와 공정 수정은 발생 방지책**이라는 차이를 기억해야 해.

## 2. 신뢰성 개선방향에 근거하여 개선 필요 사항을 도출하여 수정할 수 있다.

### 2.1 개선 필요 사항 도출의 의미

**신뢰성 개선방향에 근거하여 개선 필요 사항을 도출하여 수정할 수 있다.**는 목표는 분석 결과를 실제 변경 항목으로 구체화할 수 있어야 한다는 뜻이야.

“내구성을 향상한다”는 개선 방향일 뿐, 실행 가능한 수정사항은 아니야. 실행 가능한 개선 필요 사항에는 최소한 다음 내용이 포함돼야 해.

- 무엇을 변경할 것인가
- 왜 변경해야 하는가
- 어느 수준까지 변경할 것인가
- 누가 언제 수행할 것인가
- 변경에 따른 부작용은 무엇인가
- 무엇으로 효과를 검증할 것인가
- 관련 문서와 다른 제품에 어떻게 반영할 것인가

### 2.2 고장원인의 계층적 분석

개선 필요 사항을 정확히 도출하려면 고장 현상에서 근본원인까지 내려가야 해.

**고장 현상 → 고장모드 → 직접 원인 → 근본 원인 → 관리체계 원인**

예시는 다음과 같아.

| 단계 | 분석 내용 |
|---|---|
| 고장 현상 | 장시간 운전 후 제품이 정지함 |
| 고장모드 | 베어링 고착 |
| 직접 원인 | 윤활 부족과 온도 상승 |
| 근본 원인 | 실제 운전온도에 부적합한 윤활제 선정 |
| 관리체계 원인 | 설계 입력에 최고 사용온도가 누락됨 |

직접 원인만 고치면 같은 문제가 다른 형태로 재발할 수 있어. 윤활제만 바꾸는 것에 그치지 않고 설계 입력 검토 절차와 환경조건 확인표도 수정해야 재발을 막을 수 있지.

근본원인 분석에는 5 Why, 특성요인도, 결함수분석, 고장수목분석과 같은 방법을 활용할 수 있어. 중요한 건 도구의 이름을 쓰는 게 아니라 **시험 증거와 원인의 연결을 입증하는 것**이야.

### 2.3 개선 필요 사항의 구체화

개선 필요 사항은 다음처럼 측정 가능하게 작성해야 해.

좋지 않은 표현:

- 내구성을 강화한다.
- 품질관리를 철저히 한다.
- 작업자가 주의한다.

좋은 표현:

- 베어링 동정격을 기존 대비 20% 이상 상향하고 예상 L₁₀ 수명을 재계산한다.
- 리플로 최고온도를 245 ± 5℃로 관리하고 프로파일 측정 주기를 로트당 1회로 정한다.
- 실링 압축률의 설계범위를 20%에서 25%로 조정하고 누설시험 기준을 재검토한다.
- 체결 토크를 8 ± 0.5 N·m로 관리하고 토크렌치 교정상태를 작업 전에 확인한다.
- 변경 시료 30개에 대해 정해진 온도사이클을 수행하고 균열 발생 여부를 판정한다.

수정사항은 가능하면 **대상, 변경값, 허용범위, 책임자, 완료기한, 검증기준**을 포함해야 해.

### 2.4 수정안 선택과 트레이드오프

신뢰성을 높이는 변경이 언제나 제품 전체에 좋은 것은 아니야. 부품의 정격을 높이면 크기와 비용이 증가할 수 있고, 구조를 두껍게 만들면 중량과 방열 성능이 나빠질 수 있어. 실링력을 지나치게 높이면 누설은 줄지만 마찰과 마모가 커질 수도 있어.

그래서 수정안을 선택할 때는 다음을 함께 검토해야 해.

1. 신뢰성 향상 효과
2. 안전성과 법규 적합성
3. 성능 변화
4. 제조 가능성
5. 검사 가능성
6. 비용과 납기
7. 정비성과 사용 편의성
8. 새로운 고장모드의 발생 가능성

이 검토를 **변경 영향 분석**이라고 볼 수 있어. 한 고장모드를 줄이기 위한 수정이 새로운 위험을 만들지 않는지 확인하는 과정이야.

**비교와 경계:** 시정은 발견된 부적합 자체를 바로잡는 활동이고, 시정조치는 그 부적합의 원인을 제거하여 재발을 방지하는 활동이야. 고장 부품을 교환하는 것은 시정이고, 고장을 만든 설계나 공정 원인을 제거하는 것은 시정조치에 해당해.

### 2.5 수정 실행과 변경관리

신뢰성 개선은 문서에 적는 것으로 끝나지 않아. 승인된 변경사항이 설계, 공정, 구매, 검사와 현장 문서에 일관되게 반영돼야 해.

일반적인 실행 절차는 다음과 같아.

1. 개선요구서를 작성한다.
2. 기술적 타당성과 위험을 검토한다.
3. 변경 전후의 도면, 사양과 공정조건을 비교한다.
4. 변경안을 승인한다.
5. 시제품 또는 시험품을 제작한다.
6. 정해진 조건으로 확인시험을 수행한다.
7. 결과가 목표를 충족하면 변경을 확정한다.
8. 도면, 작업표준서, 검사기준서, 구매사양서를 개정한다.
9. 작업자와 검사자에게 변경 내용을 교육한다.
10. 양산 초기 데이터를 감시한다.
11. 동일 원인이 적용될 수 있는 제품과 공정으로 수평 전개한다.
12. 개선조치의 종결 근거를 기록한다.

변경 이력에는 변경 전 상태, 변경 후 상태, 변경 사유, 승인자, 적용 시점과 대상 로트가 포함돼야 해. 그래야 문제가 다시 발생했을 때 어떤 상태의 제품인지 추적할 수 있어.

### 2.6 개선 효과의 재검증

개선품이 만들어졌다고 효과가 입증된 것은 아니야. 개선 전과 동일하거나 비교 가능한 조건으로 다시 시험해야 해.

재검증에서는 다음 질문에 답해야 해.

- 주요 고장모드의 발생 빈도가 감소했는가?
- 목표 신뢰도, B₁₀ 수명 또는 MTBF를 충족했는가?
- 고장시간 분포가 유리한 방향으로 이동했는가?
- 기존 고장모드는 줄었지만 새로운 고장모드가 생기지 않았는가?
- 성능과 안전성에 부정적인 영향은 없는가?
- 결과 차이가 우연이 아니라 개선 효과라고 판단할 근거가 있는가?

예를 들어 개선 전 B₁₀ 수명이 700시간이고 개선 후 1,050시간이라면 수명은 향상됐어. 하지만 시료가 지나치게 적거나 시험조건이 달랐다면 단순 비교만으로 효과를 확정하기 어려워. 시험계획, 신뢰수준, 표본 수와 중도절단 조건도 함께 확인해야 해.

### 2.7 구체적인 개선 사례

펌프의 내구시험에서 1,500시간 목표보다 이른 800시간 부근에 누설 고장이 반복됐다고 해보자. 분해 결과 실링면 마모와 축 편심이 함께 확인됐어.

**개선 방향**

누설을 검출하는 검사 강화보다 축 정렬과 실링의 마모 원인을 줄이는 방향을 우선한다.

**도출된 개선 필요 사항**

1. 축과 하우징의 동심도 공차를 재검토한다.
2. 조립용 치공구의 위치결정 정밀도를 개선한다.
3. 실링 재질을 실제 온도와 유체 조건에 적합한 재료로 변경한다.
4. 실링 접촉압이 과도하지 않도록 설계값을 조정한다.
5. 조립 후 편심량 측정 항목을 검사기준서에 추가한다.
6. 변경품에 대해 1,500시간 내구시험과 누설량 측정을 수행한다.
7. 동일 조립공정을 사용하는 다른 펌프 모델에도 원인 존재 여부를 확인한다.

**수정 후 판정**

목표시간까지 치명적 누설이 없어야 하고, 누설량이 규격 이내이며, 실링면에 비정상 마모가 없어야 해. 동시에 마찰 증가로 소비전력이나 온도가 상승하지 않았는지도 확인해야 해.

### 2.8 시험에서 자주 나오는 함정

1. **합격률과 신뢰도를 같은 개념으로 보는 오류**

   시험 시료 10개 중 9개가 합격했다고 해서 임무시간 신뢰도가 곧바로 0.9라고 단정할 수 없어. 시험시간, 분포 가정, 중도절단과 신뢰수준을 고려해야 해.

2. **평균수명만 보고 고장 양상을 무시하는 오류**

   평균수명이 같아도 초기고장이 많은 제품과 마모고장이 집중된 제품의 개선 방향은 달라.

3. **고장모드와 고장원인을 혼동하는 오류**

   “균열”은 현상 또는 고장모드야. 재질 취성, 열응력, 형상 불연속과 공정 결함 중 무엇이 원인인지 추가 분석해야 해.

4. **검사 강화만으로 근본개선이 됐다고 보는 오류**

   검사는 불량 유출을 줄이지만 고장의 발생 원인을 반드시 제거하지는 않아.

5. **수정 후 재시험을 생략하는 오류**

   개선 효과는 의도가 아니라 데이터로 증명해야 해.

6. **개선 전후 시험조건을 다르게 설정하는 오류**

   조건이 다르면 결과 차이가 개선 때문인지 시험환경 때문인지 구별하기 어려워.

7. **새로운 고장모드의 발생 가능성을 놓치는 오류**

   한 부위를 강화하면 응력이 다른 부위로 이동할 수 있으므로 시스템 전체를 다시 검토해야 해.

8. **문서 개정을 누락하는 오류**

   시제품만 좋아지고 작업표준서와 도면이 그대로라면 양산에서 이전 문제가 재발할 수 있어.

## 실기 답안 작성 틀

서술형에서는 다음 구조로 답하면 논리가 선명해져.

**시험 결과 확인 → 목표 대비 차이 분석 → 주요 고장모드 선정 → 근본원인 분석 → 개선 우선순위 결정 → 구체적 수정 → 재시험 → 표준화와 수평 전개**

예시 답안은 이렇게 구성할 수 있어.

> 신뢰성시험 결과를 목표 신뢰도 및 수명 기준과 비교하고, 고장시간 분포와 주요 고장모드를 분석한다. 고장 영향도와 발생빈도, 검출 가능성을 고려하여 개선 우선순위를 정한 뒤 설계·재료·공정·검사조건별 개선 필요 사항을 구체화한다. 수정품에 대해 동일하거나 비교 가능한 조건으로 재시험하여 목표 신뢰도 충족 여부와 새로운 고장모드 발생 여부를 확인한다. 효과가 검증되면 도면, 작업표준서와 검사기준서를 개정하고 관련 제품에 수평 전개한다.

## 정답 및 해설

### 문제 1 정답

조립조건 표준화와 공정 오류방지 장치 적용, 초기 선별검사 또는 번인시험의 적정화가 대표적인 개선 방향이야.

**해설:** β가 1보다 작으면 시간이 지날수록 고장률이 감소하는 초기고장형 특성이야. 시험 초기에 조립 불량이 집중됐으므로 장기 마모수명을 늘리는 것보다 조립 편차와 잠재 초기결함을 제거하는 게 우선이야.

### 문제 2 정답

1. 실제 사용온도를 반영하여 실링 재료의 내열성을 상향한다.
2. 실링부의 방열구조 또는 열 차단구조를 개선한다.
3. 실링 압축률과 접촉압의 설계범위를 재검토한다.
4. 변경품에 대해 고온수명시험과 누설시험을 다시 수행한다.

**해설:** 목표와 실제 신뢰도의 차이가 크고 고장원인이 고온 열화로 특정됐으므로 재료, 열설계와 접촉조건을 수정해야 해. 수정 후에는 동일한 고장모드가 감소했는지 재시험으로 확인해야 하고 새로운 누설이나 마찰 문제가 생기지 않았는지도 살펴야 해.

### 문제 3 정답

1. 시정
2. 시정조치

**해설:** 고장난 부품을 교환하는 것은 발견된 부적합을 바로잡는 활동이야. 축 정렬 공차와 치공구를 수정하는 것은 고장의 원인을 제거하여 재발을 방지하는 활동이야.

### 문제 4 정답

1. 목표 신뢰도나 목표 수명의 충족 여부
2. 주요 고장모드의 발생 감소 여부
3. 새로운 고장모드나 부작용의 발생 여부
4. 개선 전후 시험조건의 비교 가능성과 데이터의 유효성

**해설:** 개선은 기존 고장만 줄였다고 끝나지 않아. 목표 수치를 충족하고 다른 성능이나 안전에 악영향을 주지 않았다는 점까지 입증해야 해.

### 문제 5 정답

발생 빈도가 낮더라도 안전사고, 법규 위반이나 치명적 기능 상실을 유발하는 고장모드는 우선 개선해야 하기 때문이야.

**해설:** 개선 우선순위는 빈도뿐 아니라 심각도, 검출도, 목표 미달 폭과 파급 범위를 종합해 결정해야 해. 파레토 분석은 중요한 도구지만 안전성과 법규 위험을 대신할 수는 없어.

## 요약

- **신뢰성시험 결과에 근거하여 개선 방향을 설정할 수 있다.**는 것은 시험 데이터의 유효성을 확인하고, 목표 대비 차이와 고장시간 분포 및 고장모드를 분석하여 개선 영역과 우선순위를 정하는 능력이야.
- β < 1은 초기고장, β = 1은 우발고장, β > 1은 마모고장 성격을 나타내며 각 경우의 개선 방향이 달라.
- 평균수명이나 합격률 하나만 보지 말고 신뢰도, B₁₀ 수명, 고장률, 분포모수와 고장모드를 함께 해석해야 해.
- **신뢰성 개선방향에 근거하여 개선 필요 사항을 도출하여 수정할 수 있다.**는 것은 개선 방향을 측정 가능한 설계·재료·공정·검사·사용조건 변경으로 구체화하는 능력이야.
- 수정사항에는 대상, 변경값, 허용범위, 책임, 일정과 검증기준이 들어가야 해.
- 검출 강화와 발생 방지는 구별해야 하며, 근본원인을 제거하는 조치를 우선해야 해.
- 수정 후에는 재시험을 통해 목표 달성, 기존 고장 감소, 신규 고장 부재와 부작용 여부를 확인해야 해.
- 검증된 결과는 도면, 작업표준서, 검사기준서와 구매사양서에 반영하고 관련 제품으로 수평 전개해야 해.
