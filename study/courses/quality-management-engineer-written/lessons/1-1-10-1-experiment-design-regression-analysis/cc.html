📘 회귀분석의 정의와 목적

회귀분석은 하나의 결과변수와 하나 이상의 설명변수 사이에 존재하는 평균적인 관계를 수학적 모형으로 표현하고, 그 관계를 추정·검정·예측하는 통계적 방법이야. 실험계획법에서 분산분석이 주로 인자의 효과가 존재하는지를 판정한다면, 회귀분석은 인자가 한 단위 변할 때 반응이 어느 방향으로 얼마나 변하는지를 식으로 보여줘.

단순선형회귀모형

Yᵢ = β₀ + β₁xᵢ + εᵢ

실제 자료에서는 β₀와 β₁을 알 수 없으므로 표본에서 절편 b₀와 기울기 b₁을 추정해. 추정된 회귀식은 ŷᵢ = b₀ + b₁xᵢ이고, 관측값과 예측값의 차이는 eᵢ = yᵢ − ŷᵢ로 정의되는 잔차야. 잔차는 계산의 찌꺼기가 아니라 모형이 설명하지 못한 구조를 보여주는 진단 신호야.

📐 회귀분석의 기본 원리

산점도와 관계의 형태

산점도는 설명변수 x와 반응변수 y의 관측쌍을 좌표평면에 표시한 그림이야. 회귀식을 계산하기 전에 관계가 직선에 가까운지, 증가 또는 감소 관계인지, 이상점이 존재하는지, x가 커질수록 산포가 달라지는지, 곡선이나 집단별 패턴이 숨어 있는지를 확인해야 해. 상관계수가 커도 자료가 곡선 형태라면 단순선형회귀가 적절하지 않을 수 있고, 하나의 이상점이 기울기를 과도하게 바꿀 수도 있어.

최소제곱법

최소제곱법은 잔차제곱합 SSE = Σ[yᵢ − (b₀ + b₁xᵢ)]²을 최소로 만드는 b₀와 b₁을 선택하는 방법이야. 잔차를 제곱하면 양과 음의 잔차가 상쇄되는 것을 막고 큰 오차에 더 큰 불이익을 줄 수 있어.

Sxx = Σ(xᵢ − x̄)², Sxy = Σ(xᵢ − x̄)(yᵢ − ȳ)로 두면 기울기는 b₁ = Sxy/Sxx, 절편은 b₀ = ȳ − b₁x̄이야. 이 관계 때문에 추정된 회귀직선은 반드시 표본평균점 (x̄, ȳ)을 지나.

회귀계수의 해석

기울기 b₁은 x가 한 단위 증가할 때 y의 평균적인 예측값이 얼마나 변하는지를 나타내. 예를 들어 ŷ = 52 + 3x라면 x가 한 단위 증가할 때 y의 예측값이 평균적으로 3만큼 증가해. 절편 b₀는 x = 0일 때의 예측값이지만, x = 0이 관측범위 밖이라면 현실적인 의미를 부여하기 어려울 수 있어.

🧩 회귀변동의 분해

회귀분석은 관측값의 전체 변동을 회귀식이 설명한 부분과 설명하지 못한 부분으로 나눠. 이 관계는 SST = SSR + SSE로 표현돼.

회귀분석의 제곱합 분해
변동 제곱합 의미
총변동 SST = Σ(yᵢ − ȳ)² 관측값이 전체 평균에서 벗어난 변동
회귀변동 SSR = Σ(ŷᵢ − ȳ)² 회귀식이 설명한 변동
잔차변동 SSE = Σ(yᵢ − ŷᵢ)² 회귀식이 설명하지 못한 변동

교재에 따라 회귀제곱합과 잔차제곱합에 사용하는 영문 기호가 달라질 수 있어. 시험에서는 기호만 외우지 말고 반드시 식과 의미를 함께 확인해야 해.

결정계수

결정계수 R²는 총변동 가운데 회귀식이 설명한 변동의 비율이야. R² = SSR/SST = 1 − SSE/SST로 계산해. R² = 0.80이라면 표본에서 관측된 y 변동의 80%가 회귀모형으로 설명되었다는 뜻이지, 예측이 80% 정확하거나 회귀식이 80% 확률로 참이라는 뜻은 아니야.

단순선형회귀에서는 표본상관계수와 결정계수 사이에 R² = r²가 성립해. r = −0.9라면 R² = 0.81이지만, 결정계수 자체에는 방향 정보가 없어. 방향은 기울기나 상관계수의 부호로 판단해야 해.

⚖️ 회귀식의 유의성 검정

표본의 기울기가 0이 아니어도 모집단에서 실제 관계가 존재한다고 바로 단정할 수는 없어. 그래서 H₀: β₁ = 0과 H₁: β₁ ≠ 0을 설정해 기울기의 유의성을 검정해. 귀무가설이 참이면 x가 변해도 y의 평균이 직선적으로 변하지 않는다는 뜻이야.

회귀 분산분석표

단순선형회귀의 분산분석 구조
요인 자유도 제곱합 평균제곱 검정통계량
회귀 1 SSR MSR = SSR F = MSR/MSE
잔차 n − 2 SSE MSE = SSE/(n − 2) 해당 없음
합계 n − 1 SST 해당 없음 해당 없음

단순선형회귀의 회귀 자유도는 설명변수에 대응하는 기울기 하나를 검정하므로 1이고, 잔차 자유도는 절편과 기울기 두 모수를 추정하므로 n − 2야. F₀ = MSR/MSE를 계산한 뒤 임계값 또는 p값을 사용해 귀무가설을 판정해.

검정 절차

  1. H₀: β₁ = 0을 설정해.
  2. 회귀제곱합과 잔차제곱합을 계산해.
  3. MSR과 MSE를 계산해.
  4. F₀ = MSR/MSE를 구해.
  5. F₀가 임계값보다 크거나 p값이 유의수준보다 작으면 H₀를 기각해.
  6. 회귀관계가 통계적으로 유의하다고 판단해.

t검정과 F검정의 관계

단순선형회귀에서 기울기 하나를 검정할 때 t₀ = b₁/SE(b₁)이고 F₀ = t₀²이므로 두 검정은 같은 결론을 줘. 다중회귀의 전체 F검정은 설명변수들이 집합적으로 반응을 설명하는지 묻고, 개별 t검정은 다른 설명변수를 통제했을 때 특정 계수가 유의한지 묻는다는 차이가 있어.

🧪 회귀분석의 기본 가정

선형성

반응의 평균은 E(Y｜x) = β₀ + β₁x와 같은 선형관계를 가져야 해. 모든 관측점이 정확히 직선 위에 있어야 한다는 뜻이 아니라, 각 x에서의 평균적 구조가 직선이어야 한다는 뜻이야.

독립성

오차들은 서로 독립이어야 해. 시간순으로 측정한 자료에 자기상관이 존재하면 독립성 가정이 깨질 수 있으므로 잔차를 관측 순서대로 그려봐야 해.

등분산성

모든 x 수준에서 오차의 분산은 Var(εᵢ) = σ²처럼 일정해야 해. 예측값이 커질수록 잔차 폭이 부채꼴로 넓어진다면 이분산성을 의심해야 해.

정규성

유의성 검정과 구간추론을 위해 오차가 εᵢ ∼ N(0, σ²)를 따른다고 가정해. 정규성은 잔차의 정규확률도나 히스토그램으로 확인하며 표본이 작을수록 위반의 영향이 커질 수 있어.

오차 평균이 0

오차의 기대값은 E(εᵢ) = 0이어야 해. 절편을 포함한 최소제곱회귀에서는 표본 잔차의 합이 Σeᵢ = 0이지만, 이 대수적 성질만으로 실제 모형이 올바르다고 보장되지는 않아.

🔍 잔차분석과 모형 진단

잔차분석은 회귀분석의 건강검진과 같아. 회귀계수와 결정계수가 좋아 보여도 잔차에 규칙적인 패턴이 남으면 모형이 중요한 구조를 놓친 거야.

잔차 형태에 따른 모형 진단

이상점은 y 방향으로 회귀식에서 멀리 떨어진 관측값이고, 고레버리지점은 x 값이 다른 관측값들로부터 멀리 떨어진 점이야. 자료가 불편하다는 이유만으로 점을 삭제하면 안 돼. 입력오류, 측정오류 또는 실제 공정의 특수원인인지 먼저 조사해야 해.

회귀계수 계산

x̄ = 3, ȳ = 4이고, Sxx = 10, Sxy = 9야. 따라서 기울기는 b₁ = 9/10 = 0.9이고 절편은 b₀ = 4 − 0.9×3 = 1.3이야.

추정 회귀식은 ŷ = 1.3 + 0.9x야. 이는 온도가 한 단위 증가할 때 강도의 평균 예측값이 0.9만큼 증가한다는 뜻이야.

예측값과 잔차 계산

x = 4일 때 예측값은 ŷ = 1.3 + 0.9×4 = 4.9야. 실제 관측값은 4이므로 잔차는 e = 4 − 4.9 = −0.9야. 음의 잔차는 실제 관측값이 회귀식의 예측값보다 작다는 뜻이야.

제곱합과 결정계수

SST = 10, SSR = b₁Sxy = 0.9×9 = 8.1, SSE = 10 − 8.1 = 1.9야. 따라서 R² = 8.1/10 = 0.81이고 이 표본에서 강도 변동의 81%가 온도와의 선형관계로 설명돼.

F통계량

잔차 자유도는 5 − 2 = 3이므로 MSE = 1.9/3 ≈ 0.633이야. 회귀 평균제곱은 8.1이므로 F₀ = 8.1/0.633 ≈ 12.79야. 최종 유의성 판정에는 주어진 유의수준과 자유도에 대응하는 임계값 또는 p값을 사용해야 해.

🎯 예측과 추정의 차이

평균반응의 신뢰구간

x₀에서 반복 측정할 때 나타날 평균반응을 추정하는 구간이야. 평균회귀선 자체의 불확실성을 반영해.

개별 관측값의 예측구간

x₀에서 새롭게 관측될 하나의 개별값을 예측하는 구간이야. 평균회귀선 추정의 불확실성과 새로운 개체 자체의 오차를 모두 포함하므로 같은 신뢰수준에서 평균반응의 신뢰구간보다 일반적으로 넓어.

외삽의 위험

x₀가 x̄에서 멀어질수록 신뢰구간과 예측구간이 모두 넓어져. 특히 관측된 x 범위를 벗어난 외삽은 선형관계가 확인되지 않은 영역까지 계속된다고 가정하므로 조심해야 해.

x로 y를 회귀한 식과 y로 x를 회귀한 식은 일반적으로 서로 역함수가 아니야. 어느 변수를 반응변수로 정했는지에 따라 최소화하는 오차의 방향이 달라지기 때문이야.

회귀분석과 분산분석

분산분석은 범주형 인자의 수준별 평균 차이를 검정하는 데 적합하고, 회귀분석은 연속형 설명변수의 변화에 따른 반응 추세를 표현하는 데 적합해. 하지만 두 방법 모두 일반선형모형의 틀에서 제곱합을 분해하고 오차분산과 비교해 효과를 검정해.

회귀와 인과관계

회귀계수가 유의하다고 해서 x가 y의 원인이라고 결론 내릴 수는 없어. 숨은 변수, 역인과관계, 선택편향이 존재할 수 있기 때문이야. 회귀분석은 인과성을 자동으로 만드는 도구가 아니라, 적절한 무작위화와 실험설계 위에서 효과를 정량화하는 도구야.

🚨 시험 함정

  1. 결정계수의 오해: R² = 0.9는 예측 정확도가 90%라는 뜻이 아니라 총변동 중 모형이 설명한 비율이 90%라는 뜻이야.
  2. 상관관계와 인과관계의 혼동: 강한 회귀관계가 나타나도 인과관계가 자동으로 성립하지 않아.
  3. 잔차 부호의 반대 계산: 잔차는 일반적으로 e = y − ŷ로 계산해.
  4. 자유도 오류: 단순선형회귀에서 총 자유도는 n − 1, 회귀 자유도는 1, 잔차 자유도는 n − 2야.
  5. R²와 r의 부호 혼동: r이 음수여도 R²는 음수가 되지 않아.
  6. 외삽의 무비판적 사용: 관측범위를 벗어난 예측은 검증되지 않은 관계를 전제해.
  7. 유의성과 적합성의 혼동: 회귀식이 유의해도 잔차에 곡선 패턴이 남으면 선형모형은 부적절할 수 있어.
  8. 높은 R²의 과신: 높은 R²는 잔차 가정, 이상점, 편향과 예측 타당성을 보장하지 않아.
  9. 절편의 과도한 해석: x = 0이 관측범위 밖이면 절편의 현실적 의미가 약할 수 있어.
  10. 예측구간과 신뢰구간의 혼동: 개별 관측값의 예측구간이 평균반응의 신뢰구간보다 일반적으로 넓어.

🛠️ 풀이 절차

  1. x̄와 ȳ를 구해.
  2. Sxx, Sxy, SST를 계산해.
  3. b₁ = Sxy/Sxx를 구해.
  4. b₀ = ȳ − b₁x̄를 구해.
  5. ŷ = b₀ + b₁x를 작성해.
  6. 필요한 x에서 예측값을 계산해.
  7. 잔차 e = y − ŷ를 계산해.
  8. SSR과 SSE를 구하고 SST = SSR + SSE를 확인해.
  9. R² = SSR/SST를 계산해.
  10. 자유도와 평균제곱을 구해 F검정을 수행해.
  11. 잔차분석으로 선형성, 독립성, 등분산성, 정규성을 점검해.
  12. 관측범위를 벗어난 외삽인지 확인한 뒤 결론을 작성해.

❓ 확인 문제

문제 1

회귀식이 ŷ = 15 + 2.5x일 때 x가 한 단위 증가하면 y의 평균 예측값은 어떻게 변할까?

  1. 15만큼 증가한다.
  2. 2.5만큼 증가한다.
  3. 2.5만큼 감소한다.
  4. 변하지 않는다.

문제 2

관측값이 28이고 예측값이 31일 때 잔차는 얼마일까?

문제 3

단순선형회귀에서 표본수가 12라면 잔차 자유도는 얼마일까?

문제 4

SST = 200이고 SSE = 50일 때 결정계수 R²를 구해봐.

문제 5

다음 설명 중 옳지 않은 것은 무엇일까?

  1. 단순선형회귀의 추정 회귀직선은 (x̄, ȳ)을 지난다.
  2. 결정계수는 회귀식이 설명한 변동의 비율을 나타낸다.
  3. 높은 결정계수는 두 변수 사이의 인과관계를 증명한다.
  4. 개별 관측값의 예측구간은 평균반응의 신뢰구간보다 일반적으로 넓다.

문제 6

잔차도에서 예측값이 증가할수록 잔차의 산포가 부채꼴로 넓어진다. 가장 먼저 의심해야 할 가정 위반은 무엇일까?

문제 7

단순선형회귀에서 기울기에 대한 t검정통계량이 t₀ = −3이라면 이에 대응하는 F통계량은 얼마일까?

문제 8

상관계수 r = −0.8인 단순선형회귀의 결정계수는 얼마이며, 회귀선의 기울기 방향은 어떻게 판단할까?

✅ 정답 및 해설

문제 1 정답: 2

기울기 2.5는 x가 한 단위 증가할 때 y의 평균 예측값이 2.5만큼 증가한다는 뜻이야. 15는 절편이야.

문제 2 정답: −3

e = y − ŷ = 28 − 31 = −3이야. 음의 잔차는 실제 관측값이 예측값보다 작다는 뜻이야.

문제 3 정답: 10

단순선형회귀에서는 절편과 기울기 두 개를 추정하므로 잔차 자유도는 n − 2 = 12 − 2 = 10이야.

문제 4 정답: 0.75

SSR = SST − SSE = 200 − 50 = 150이므로 R² = 150/200 = 0.75야. 총변동의 75%를 회귀식이 설명해.

문제 5 정답: 3

높은 결정계수는 표본 변동의 상당 부분이 모형으로 설명되었음을 나타낼 뿐, 인과관계를 증명하지 않아. 인과적 해석에는 무작위화와 교란변수 통제 같은 별도의 근거가 필요해.

문제 6 정답: 등분산성 위반

잔차의 폭이 예측값에 따라 달라지는 부채꼴 패턴은 오차분산이 일정하지 않은 이분산성을 시사해.

문제 7 정답: 9

단순선형회귀에서는 F₀ = t₀² = (−3)² = 9가 성립해. F통계량은 음수가 되지 않아.

문제 8 정답: R² = 0.64, 기울기는 음의 방향

R² = r² = (−0.8)² = 0.64야. 결정계수에는 방향이 없지만 r이 음수이므로 단순선형회귀의 기울기도 음수야.

✨ 요약

  • 정의: 회귀분석은 설명변수와 반응변수의 평균적인 관계를 식으로 표현하고 추정·검정·예측하는 방법이야.
  • 모형: 단순선형회귀모형은 Yᵢ = β₀ + β₁xᵢ + εᵢ로 표현해.
  • 추정: 최소제곱법은 잔차제곱합을 최소화하고 b₁ = Sxy/Sxx, b₀ = ȳ − b₁x̄를 사용해.
  • 평균점: 추정 회귀직선은 반드시 (x̄, ȳ)을 지나.
  • 변동 분해: 전체 변동은 SST = SSR + SSE로 분해돼.
  • 결정계수: R² = SSR/SST = 1 − SSE/SST이며 설명된 변동의 비율을 나타내.
  • 검정: 단순선형회귀에서는 R² = r²와 F₀ = t₀²가 성립하고 잔차 자유도는 n − 2야.
  • 진단: 잔차분석으로 선형성, 독립성, 등분산성, 정규성을 점검해야 해.
  • 경계: 높은 R²나 통계적 유의성만으로 인과관계와 모형 적합성이 보장되지는 않아.
  • 예측: 개별값의 예측구간은 평균반응의 신뢰구간보다 일반적으로 넓고 외삽은 특히 조심해야 해.

회귀분석은 흩어진 점 사이에 선을 긋는 계산이 아니라, 그 선이 자료의 구조를 얼마나 정직하게 설명하는지 검증하는 과정이야. 공식과 잔차 진단을 함께 연결하면 제대로 이해한 거야. 😊
