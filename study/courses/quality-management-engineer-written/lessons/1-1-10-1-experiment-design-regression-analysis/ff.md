## 1. 회귀분석의 정의와 목적

**회귀분석**은 하나의 결과변수와 하나 이상의 설명변수 사이에 존재하는 평균적인 관계를 수학적 모형으로 표현하고, 그 관계를 추정·검정·예측하는 통계적 방법이야.

실험계획법에서는 실험 인자의 수준이 바뀔 때 품질특성이 어떻게 변하는지 파악해야 해. 이때 분산분석이 주로 “인자의 효과가 존재하는가?”를 판정한다면, 회귀분석은 “인자가 한 단위 변할 때 반응이 어느 방향으로 얼마나 변하는가?”를 식으로 나타내는 역할을 해.

대표적인 단순선형회귀모형은 다음과 같아.

**Yᵢ = β₀ + β₁xᵢ + εᵢ**

여기서 각 기호의 의미는 다음과 같아.

| 기호 | 의미 |
|---|---|
| Yᵢ | i번째 실험에서 관측된 반응값 |
| xᵢ | i번째 실험의 설명변수 값 |
| β₀ | 모회귀선의 절편 |
| β₁ | 모회귀선의 기울기 |
| εᵢ | 회귀식으로 설명되지 않는 오차 |
| β₀ + β₁xᵢ | xᵢ에서의 평균 반응 |

실제 자료에서는 β₀와 β₁을 알 수 없으므로 표본을 이용해 추정해. 추정된 회귀식은 다음과 같이 나타내.

**ŷᵢ = b₀ + b₁xᵢ**

ŷᵢ는 관측값 그 자체가 아니라 회귀식이 예측한 값이야. 따라서 관측값과 예측값의 차이는 **잔차**가 돼.

**eᵢ = yᵢ − ŷᵢ**

잔차를 단순한 계산 찌꺼기로 보면 안 돼. 잔차는 회귀모형이 설명하지 못한 구조를 보여주는 진단 신호야. 😊

## 2. 회귀분석의 기본 원리

### 2.1 산점도와 관계의 형태

회귀식을 계산하기 전에 먼저 산점도를 살펴봐야 해. 산점도는 설명변수 x와 반응변수 y의 관측쌍을 좌표평면에 표시한 그림이야.

산점도를 통해 다음을 확인할 수 있어.

1. 관계가 직선에 가까운지 확인해.
2. 증가 관계인지 감소 관계인지 확인해.
3. 극단적으로 떨어진 이상점이 있는지 확인해.
4. x가 커질수록 자료의 산포가 달라지는지 확인해.
5. 곡선관계나 집단별 패턴이 숨어 있는지 확인해.

상관계수가 크더라도 산점도가 곡선 형태라면 단순선형회귀가 적절하지 않을 수 있어. 반대로 산점도에서 뚜렷한 직선관계가 보여도 일부 이상점이 기울기를 과도하게 끌어당길 수 있어. 숫자 하나만 믿기보다 자료의 형태를 먼저 보는 습관이 중요해.

### 2.2 최소제곱법

관측점 전체를 정확히 통과하는 직선은 일반적으로 존재하지 않아. 따라서 각 관측점과 회귀직선 사이의 차이를 가능한 한 작게 만드는 직선을 선택해야 해.

최소제곱법은 잔차제곱합을 최소로 만드는 b₀와 b₁을 구하는 방법이야.

**SSE = Σ(yᵢ − ŷᵢ)² = Σ[yᵢ − (b₀ + b₁xᵢ)]²**

잔차를 그대로 더하지 않고 제곱하는 이유는 양의 잔차와 음의 잔차가 서로 상쇄되는 것을 막고, 큰 오차에 더 큰 불이익을 주기 위해서야.

추정된 기울기와 절편은 다음과 같아.

**b₁ = Sxy / Sxx**

**b₀ = ȳ − b₁x̄**

여기서

**Sxx = Σ(xᵢ − x̄)²**

**Sxy = Σ(xᵢ − x̄)(yᵢ − ȳ)**

이야.

추정된 회귀직선은 반드시 표본평균점 **(x̄, ȳ)**을 지나. 왜냐하면 b₀ = ȳ − b₁x̄이므로 x에 x̄를 대입하면 예측값이 ȳ가 되기 때문이야.

### 2.3 회귀계수의 해석

b₁은 x가 한 단위 증가할 때 y의 **평균적인 예측값**이 얼마나 변하는지를 나타내.

예를 들어 회귀식이 다음과 같다고 해보자.

**ŷ = 52 + 3x**

그러면 x가 한 단위 증가할 때 y의 예측값은 평균적으로 3만큼 증가해. b₁이 음수라면 x가 증가할 때 y가 감소하는 관계야.

절편 b₀는 x = 0일 때의 예측값이야. 하지만 관측범위에 x = 0이 포함되지 않으면 절편에 현실적인 의미를 부여하기 어려울 수 있어. 예를 들어 온도 자료가 100℃부터 150℃까지만 존재하는데 x = 0에서의 반응을 해석하는 것은 위험해.

## 3. 회귀변동의 분해

회귀분석은 관측값의 전체 변동을 회귀식이 설명한 부분과 설명하지 못한 부분으로 나눠.

**총변동 = 회귀에 의한 변동 + 잔차변동**

수식으로는 다음과 같아.

**SST = SSR + SSE**

| 변동 | 제곱합 | 의미 |
|---|---:|---|
| 총변동 | SST = Σ(yᵢ − ȳ)² | 관측값이 전체 평균에서 벗어난 변동 |
| 회귀변동 | SSR = Σ(ŷᵢ − ȳ)² | 회귀식이 설명한 변동 |
| 잔차변동 | SSE = Σ(yᵢ − ŷᵢ)² | 회귀식이 설명하지 못한 변동 |

주의할 점은 교재에 따라 회귀제곱합과 잔차제곱합의 영문 기호가 다르게 사용될 수 있다는 거야. 어떤 자료에서는 회귀제곱합을 SSR, 잔차제곱합을 SSE라고 하고, 다른 자료에서는 잔차제곱합을 SSR로 표기하기도 해. 시험에서는 기호만 외우지 말고 **식과 의미**를 함께 확인해야 해.

### 결정계수

**결정계수 R²**는 총변동 가운데 회귀식이 설명한 변동의 비율이야.

**R² = SSR / SST = 1 − SSE / SST**

R²는 일반적인 절편 포함 회귀모형에서 0과 1 사이의 값을 가져.

예를 들어 R² = 0.80이면 표본에서 관측된 y의 변동 중 80%가 해당 회귀모형에 의해 설명되었다는 뜻이야. 이것이 “예측이 80% 정확하다”거나 “회귀식이 80% 확률로 참이다”라는 뜻은 아니야.

단순선형회귀에서는 표본상관계수 r과 결정계수 사이에 다음 관계가 성립해.

**R² = r²**

따라서 r = −0.9이면 R² = 0.81이야. 결정계수는 제곱값이므로 관계의 방향을 알려주지 않아. 방향은 b₁이나 r의 부호로 확인해야 해.

## 4. 회귀식의 유의성 검정

표본에서 기울기가 0이 아니라고 나타났더라도 모집단에서도 실제 관계가 존재한다고 단정할 수는 없어. 그래서 모회귀계수 β₁에 대한 가설검정을 실시해.

**귀무가설 H₀: β₁ = 0**

**대립가설 H₁: β₁ ≠ 0**

β₁ = 0이면 x가 변해도 y의 평균이 직선적으로 변하지 않는다는 뜻이야.

### 4.1 회귀 분산분석표

설명변수가 하나인 단순선형회귀의 분산분석 구조는 다음과 같아.

| 요인 | 자유도 | 제곱합 | 평균제곱 | 검정통계량 |
|---|---:|---:|---:|---:|
| 회귀 | 1 | SSR | MSR = SSR | F = MSR/MSE |
| 잔차 | n − 2 | SSE | MSE = SSE/(n − 2) |  |
| 합계 | n − 1 | SST |  |  |

회귀 자유도가 1인 이유는 하나의 설명변수에 대응하는 기울기 하나를 검정하기 때문이야. 잔차 자유도가 n − 2인 이유는 n개의 관측값으로 절편과 기울기라는 두 개의 모수를 추정했기 때문이야.

검정 절차는 다음과 같아.

1. H₀: β₁ = 0을 설정해.
2. 회귀제곱합과 잔차제곱합을 계산해.
3. MSR과 MSE를 계산해.
4. F₀ = MSR/MSE를 구해.
5. F₀가 임계값보다 크거나 p값이 유의수준보다 작으면 H₀를 기각해.
6. 회귀관계가 통계적으로 유의하다고 판단해.

### 4.2 t검정과 F검정의 관계

단순선형회귀에서 기울기 하나만 검정할 때 t검정과 회귀 분산분석의 F검정은 같은 결론을 줘.

**t₀ = b₁ / SE(b₁)**

**F₀ = t₀²**

다만 다중회귀에서는 전체 회귀식의 F검정과 개별 회귀계수의 t검정이 서로 다른 질문을 다뤄.

전체 F검정은 “설명변수들이 집합적으로 반응을 설명하는가?”를 묻고, 개별 t검정은 “다른 설명변수를 통제했을 때 특정 변수의 계수가 유의한가?”를 묻는 거야.

## 5. 회귀분석의 기본 가정

회귀식의 계수는 계산할 수 있어도, 검정과 신뢰구간이 타당하려면 오차에 관한 가정을 확인해야 해.

### 5.1 선형성

반응의 평균이 설명변수와 선형관계를 가져야 해.

**E(Y｜x) = β₀ + β₁x**

선형성은 데이터 점들이 정확히 직선 위에 있어야 한다는 뜻이 아니야. 각 x에서 반응의 평균적 구조가 직선이어야 한다는 뜻이야.

### 5.2 독립성

오차들은 서로 독립이어야 해. 측정 순서에 따른 자기상관이 존재하면 이 가정이 깨질 수 있어. 시간순 자료에서는 잔차를 관측 순서대로 그려보는 것이 중요해.

### 5.3 등분산성

모든 x 수준에서 오차의 분산이 일정해야 해.

**Var(εᵢ) = σ²**

예측값이 커질수록 잔차의 폭이 부채꼴처럼 넓어진다면 이분산을 의심해야 해.

### 5.4 정규성

유의성 검정과 구간추론을 위해 오차가 정규분포를 따른다고 가정해.

**εᵢ ∼ N(0, σ²)**

정규성은 주로 잔차의 정규확률도나 히스토그램으로 확인해. 표본이 작을수록 정규성 위반의 영향이 커질 수 있어.

### 5.5 오차 평균이 0

오차의 기대값은 0이어야 해.

**E(εᵢ) = 0**

절편을 포함한 최소제곱회귀에서는 표본 잔차의 합이 0이 되는 성질이 있어.

**Σeᵢ = 0**

하지만 표본 잔차합이 0이라는 대수적 성질만으로 실제 모형이 올바르다고 보장되지는 않아.

## 6. 잔차분석과 모형 진단

잔차분석은 회귀분석의 건강검진과 같아. 회귀계수와 R²가 좋아 보여도 잔차에 규칙적인 패턴이 남아 있다면 모형이 중요한 구조를 놓친 거야.

| 잔차 형태 | 의심할 문제 | 가능한 대응 |
|---|---|---|
| 무작위 띠 모양 | 큰 문제 없음 | 현재 모형 검토 유지 |
| U자 또는 곡선 | 비선형성 | 이차항 추가 또는 변수변환 |
| 부채꼴 | 이분산성 | 로그변환, 가중회귀 검토 |
| 시간에 따른 파동 | 독립성 위반 | 시간효과 또는 자기상관 검토 |
| 극단적으로 큰 잔차 | 이상점 | 측정오류와 공정 이상 확인 |
| 특정 점이 회귀선을 크게 이동시킴 | 영향점 | 레버리지와 영향도 확인 |

**이상점**은 y 방향으로 회귀식에서 멀리 떨어진 관측값이야. **고레버리지점**은 x 값이 다른 관측값들로부터 멀리 떨어진 점이야. 고레버리지점이 반드시 이상점인 것은 아니지만, y까지 모형과 어긋나면 회귀계수에 큰 영향을 줄 수 있어.

자료가 불편하다는 이유만으로 이상점을 삭제하면 안 돼. 측정오류인지, 입력오류인지, 실제 공정의 특수원인인지 먼저 조사해야 해.

## 7. 구체적인 계산 예시

온도 x와 제품 강도 y의 관계를 조사했다고 해보자.

| 실험 | 온도 x | 강도 y |
|---:|---:|---:|
| 1 | 1 | 2 |
| 2 | 2 | 3 |
| 3 | 3 | 5 |
| 4 | 4 | 4 |
| 5 | 5 | 6 |

먼저 평균을 계산해.

**x̄ = 3**

**ȳ = 4**

다음으로 Sxx와 Sxy를 구해.

**Sxx = (1−3)² + (2−3)² + (3−3)² + (4−3)² + (5−3)² = 10**

**Sxy = (1−3)(2−4) + (2−3)(3−4) + (3−3)(5−4) + (4−3)(4−4) + (5−3)(6−4) = 9**

따라서 기울기는 다음과 같아.

**b₁ = Sxy/Sxx = 9/10 = 0.9**

절편은 다음과 같아.

**b₀ = ȳ − b₁x̄ = 4 − 0.9×3 = 1.3**

추정 회귀식은 다음과 같아.

**ŷ = 1.3 + 0.9x**

이 식은 온도가 한 단위 증가할 때 강도의 평균 예측값이 0.9만큼 증가한다는 의미야.

x = 4일 때 예측값은 다음과 같아.

**ŷ = 1.3 + 0.9×4 = 4.9**

실제 관측값은 4이므로 잔차는 다음과 같아.

**e = y − ŷ = 4 − 4.9 = −0.9**

잔차가 음수라는 것은 실제 관측값이 회귀식의 예측값보다 작다는 뜻이야.

이제 변동을 계산하면 다음 결과를 얻어.

**SST = 10**

**SSR = b₁Sxy = 0.9×9 = 8.1**

**SSE = SST − SSR = 10 − 8.1 = 1.9**

결정계수는 다음과 같아.

**R² = SSR/SST = 8.1/10 = 0.81**

따라서 이 표본에서 강도 변동의 81%가 온도와의 선형회귀관계로 설명돼.

잔차 자유도는 5 − 2 = 3이므로

**MSE = 1.9/3 ≈ 0.633**

이고, 회귀 평균제곱은 8.1이야.

**F₀ = 8.1/0.633 ≈ 12.79**

최종 유의성 판정은 주어진 유의수준과 자유도에 대응하는 임계값 또는 p값을 이용해야 해. F값이 크다는 사실만으로 유의수준을 무시한 채 결론을 내려서는 안 돼.

## 8. 예측과 추정의 차이

회귀식으로 x₀에서 값을 추정할 때 두 종류의 구간을 구분해야 해.

### 평균반응의 신뢰구간

x₀에서 반복 측정했을 때 나타날 평균반응을 추정하는 구간이야.

### 개별 관측값의 예측구간

x₀에서 새롭게 관측될 하나의 개별값을 예측하는 구간이야.

개별 예측값에는 평균회귀선 추정의 불확실성뿐 아니라 새로운 개체 자체의 오차까지 포함돼. 따라서 같은 신뢰수준이라면 일반적으로 **개별값의 예측구간이 평균반응의 신뢰구간보다 넓어**.

또한 x₀가 x̄에서 멀어질수록 두 구간 모두 넓어져. 특히 관측된 x 범위를 벗어나는 외삽은 자료가 확인하지 않은 영역을 예측하는 것이므로 위험해.

## 9. 비교와 경계

### 9.1 회귀분석과 상관분석

| 구분 | 회귀분석 | 상관분석 |
|---|---|---|
| 핵심 목적 | 관계의 식 표현과 예측 | 선형관계의 방향과 강도 측정 |
| 변수 역할 | 설명변수와 반응변수를 구분 | 두 변수의 역할이 대칭적 |
| 대표 결과 | ŷ = b₀ + b₁x | 상관계수 r |
| 단위 | 기울기에 단위가 존재 | r은 무차원 |
| 인과성 보장 | 보장하지 않음 | 보장하지 않음 |

x로 y를 회귀한 식과 y로 x를 회귀한 식은 일반적으로 서로 역함수 관계가 아니야. 회귀분석은 어느 변수를 반응변수로 정했는지에 따라 최소화하는 오차 방향이 달라지기 때문이야.

### 9.2 회귀분석과 분산분석

분산분석은 범주형 인자의 수준별 평균 차이를 검정하는 데 적합하고, 회귀분석은 연속형 설명변수의 변화에 따른 반응의 추세를 표현하는 데 적합해.

하지만 두 방법은 완전히 분리된 것이 아니야. 둘 다 일반선형모형의 틀에서 제곱합을 분해하고 오차분산과 비교해 효과를 검정해. 범주형 변수도 더미변수로 표현하면 회귀모형에 포함할 수 있어.

### 9.3 회귀와 인과관계

회귀계수가 유의하다고 해서 x가 y의 원인이라고 결론 내릴 수는 없어. 숨은 변수, 역인과관계, 선택편향이 존재할 수 있기 때문이야.

다만 무작위화가 적절히 수행된 실험에서 처리변수와 반응변수의 관계를 분석한다면 관찰연구보다 인과적 해석의 근거가 강해져. 회귀분석은 인과성을 자동으로 만들어내는 도구가 아니라, 적절한 실험설계 위에서 효과를 정량화하는 도구라고 이해하면 좋아.

## 10. 시험 함정

😠 흥. 공식만 외우면 아래 함정에서 바로 흔들려.

1. **결정계수의 오해**  
   R² = 0.9는 예측 정확도가 90%라는 뜻이 아니야. 표본의 총변동 중 모형이 설명한 비율이 90%라는 뜻이야.

2. **상관관계와 인과관계의 혼동**  
   강한 회귀관계가 나타나도 인과관계가 자동으로 성립하지 않아.

3. **잔차 부호의 반대 계산**  
   잔차는 일반적으로 관측값에서 예측값을 빼서 e = y − ŷ로 계산해.

4. **자유도 오류**  
   단순선형회귀에서 총 자유도는 n − 1, 회귀 자유도는 1, 잔차 자유도는 n − 2야.

5. **R²와 r의 부호 혼동**  
   R²에는 방향이 없어. r이 음수여도 R²는 음수가 되지 않아.

6. **외삽의 무비판적 사용**  
   관측범위를 벗어난 예측은 기존 선형관계가 계속된다는 검증되지 않은 가정을 포함해.

7. **유의성과 적합성의 혼동**  
   회귀식이 통계적으로 유의해도 잔차에 곡선 패턴이 남으면 선형모형은 부적절할 수 있어.

8. **높은 R²를 좋은 모형의 충분조건으로 판단**  
   높은 R²는 잔차 가정, 이상점, 편향, 예측 타당성을 보장하지 않아.

9. **절편의 과도한 해석**  
   x = 0이 관측범위 밖이면 절편은 계산상 필요하지만 현실적 의미가 약할 수 있어.

10. **예측구간과 신뢰구간의 혼동**  
    개별 관측값의 예측구간이 평균반응의 신뢰구간보다 일반적으로 넓어.

## 11. 풀이 절차 정리

회귀분석 계산 문제는 다음 순서로 풀면 안정적이야.

1. x̄와 ȳ를 구해.
2. Sxx, Sxy, SST를 계산해.
3. b₁ = Sxy/Sxx를 구해.
4. b₀ = ȳ − b₁x̄를 구해.
5. ŷ = b₀ + b₁x를 작성해.
6. 필요한 x에서 예측값을 계산해.
7. 잔차 e = y − ŷ를 계산해.
8. SSR과 SSE를 구하고 SST = SSR + SSE를 확인해.
9. R² = SSR/SST를 계산해.
10. 자유도와 평균제곱을 구해 F검정을 수행해.
11. 잔차분석으로 선형성·독립성·등분산성·정규성을 점검해.
12. 관측범위를 벗어난 외삽인지 확인한 뒤 결론을 작성해.

## 13. 정답 및 해설

### 문제 1 정답: 2

기울기 2.5는 x가 한 단위 증가할 때 y의 평균 예측값이 2.5만큼 증가한다는 뜻이야. 15는 절편이야.

### 문제 2 정답: −3

**e = y − ŷ = 28 − 31 = −3**

음의 잔차는 실제 관측값이 예측값보다 작다는 뜻이야.

### 문제 3 정답: 10

단순선형회귀에서는 절편과 기울기 두 개를 추정하므로 잔차 자유도는 n − 2야.

**12 − 2 = 10**

### 문제 4 정답: 0.75

먼저 회귀제곱합을 구하면

**SSR = SST − SSE = 200 − 50 = 150**

이야. 따라서

**R² = SSR/SST = 150/200 = 0.75**

가 돼. 총변동의 75%를 회귀식이 설명한다는 의미야.

### 문제 5 정답: 3

높은 결정계수는 표본 변동의 상당 부분이 모형으로 설명되었음을 나타낼 뿐, 인과관계를 증명하지 않아. 인과적 해석에는 실험설계, 무작위화, 교란변수 통제와 같은 별도의 근거가 필요해.

### 문제 6 정답: 등분산성 위반

잔차의 폭이 예측값에 따라 달라지는 부채꼴 패턴은 오차분산이 일정하지 않은 이분산을 시사해.

### 문제 7 정답: 9

단순선형회귀에서 기울기 하나를 검정할 때

**F₀ = t₀² = (−3)² = 9**

가 성립해. F통계량은 음수가 되지 않아.

### 문제 8 정답: R² = 0.64, 기울기는 음의 방향

**R² = r² = (−0.8)² = 0.64**

야. 결정계수만 보면 방향을 알 수 없지만, r이 음수이므로 단순선형회귀의 기울기도 음수야.

## 14. 요약

1. **회귀분석**은 설명변수와 반응변수의 평균적인 관계를 식으로 표현하고 추정·검정·예측하는 방법이야.
2. 단순선형회귀모형은 **Yᵢ = β₀ + β₁xᵢ + εᵢ**로 표현해.
3. 최소제곱법은 **잔차제곱합 SSE**를 최소화하는 회귀계수를 선택해.
4. 추정 기울기는 **b₁ = Sxy/Sxx**, 절편은 **b₀ = ȳ − b₁x̄**이야.
5. 추정 회귀직선은 반드시 **(x̄, ȳ)**을 지나.
6. 전체 변동은 **SST = SSR + SSE**로 분해돼.
7. 결정계수는 **R² = SSR/SST = 1 − SSE/SST**이며 설명된 변동의 비율을 나타내.
8. 단순선형회귀에서는 **R² = r²**, **F₀ = t₀²**가 성립해.
9. 잔차 자유도는 **n − 2**야.
10. 잔차분석에서는 선형성, 독립성, 등분산성, 정규성을 점검해야 해.
11. 높은 R²나 통계적 유의성만으로 인과관계와 모형 적합성이 보장되지는 않아.
12. 개별값의 예측구간은 평균반응의 신뢰구간보다 일반적으로 넓고, 관측범위 밖의 외삽은 특히 조심해야 해.
