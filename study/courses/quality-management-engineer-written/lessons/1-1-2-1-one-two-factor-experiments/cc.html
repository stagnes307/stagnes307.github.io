전체 변동을 요인과 오차의 몫으로 분해하고, 평균 차이가 우연인지 판정하는 실험계획법

🔑 핵심 키워드

요인 수준 처리 반복 제곱합 자유도 평균제곱 F검정

이번 수업에서는 1요인 실험, 1요인 실험의 해석, 반복이 없는 2요인 실험을 차례로 연결해. 핵심은 관측값의 전체 흔들림을 설명 가능한 요인변동과 설명되지 않은 오차변동으로 나누는 거야.

🧪 1요인 실험

정의와 기본 구조

1요인 실험은 결과에 영향을 준다고 생각하는 요인 하나를 선정하고, 그 요인의 여러 수준에서 얻은 평균을 비교하는 실험이야. 열처리 온도를 100℃, 120℃, 140℃로 설정하고 각 온도에서 제품의 인장강도를 여러 번 측정하는 상황이 대표적이야. 온도는 요인 A, 세 온도는 수준, 인장강도는 특성값, 각 온도에서 되풀이한 측정은 반복이 돼. 요인 A에 a개 수준이 있고 각 수준에서 n회 반복하면 전체 관측수는 N = an이야.

수학적 모형과 가설

관측모형은 xᵢⱼ = μ + αᵢ + eᵢⱼ로 나타내. μ는 전체평균, αᵢ는 요인 A의 i번째 수준효과, eᵢⱼ는 개별 관측에서 발생한 우연오차야. 보통 효과를 유일하게 정하기 위해 Σαᵢ = 0이라는 제약을 둬. 하나의 측정값이 전체 중심, 해당 수준의 효과, 설명되지 않은 오차가 합쳐진 결과라고 이해하면 돼.

귀무가설 H₀는 μ₁ = μ₂ = ··· = μₐ, 즉 모든 수준의 모평균이 같다는 주장이야. 대립가설 H₁은 적어도 하나의 수준 평균이 다르다는 주장이야. 대립가설은 모든 평균이 서로 달라야 한다는 뜻이 아니므로 시험에서 이 표현을 정확히 구별해야 해.

성립 조건과 설계 원리

분산분석의 F검정을 적용하려면 관측값의 독립성, 오차의 정규성, 수준별 오차분산의 등분산성을 전제로 해. 랜덤화는 실험 순서와 외부 환경의 편중을 막고, 반복은 동일 조건에서도 생기는 순수오차를 추정하게 해. 블록화는 통제 가능한 잡음 요인을 묶어 오차를 줄이는 원리지만 단순한 1요인 완전확률화 모형과는 구분해야 해.

📊 1요인 실험의 해석

총변동의 분해

분산분석의 중심식은 SST = SSA + SSe야. 총제곱합 SST는 모든 관측값이 전체평균에서 떨어진 정도인 ΣΣ(xᵢⱼ − x̄)²이고, 요인제곱합 SSA는 수준평균이 전체평균에서 떨어진 정도인 nΣ(x̄ᵢ − x̄)²이야. 오차제곱합 SSe는 관측값이 자신이 속한 수준평균에서 떨어진 정도인 ΣΣ(xᵢⱼ − x̄ᵢ)²이야. 즉 전체 흔들림을 수준 사이의 신호와 수준 안의 잡음으로 분리하는 셈이야.

수정항을 이용한 계산

원자료 계산에서는 먼저 CT = T²/N으로 수정항을 구해. 이어서 SST = ΣΣxᵢⱼ² − CT, SSA = Σ(Tᵢ²/nᵢ) − CT, SSe = SST − SSA의 순서로 계산해. 반복수가 다르면 공통 반복수 n을 쓰지 않고 각 수준의 실제 반복수 nᵢ를 사용해야 해.

앞의 자료에서는 CT = 108²/9 = 1296이고 관측값의 제곱합은 1356이야. 따라서 SST = 60, SSA = 54, SSe = 6이 돼. 전체 변동 60 가운데 54는 재료 종류의 차이로 설명되고 6은 동일 재료 안에서 발생한 우연오차로 남아.

자유도, 평균제곱과 F검정

예시에서는 MSA = 54/2 = 27, MSe = 6/6 = 1이므로 F₀ = 27이야. 유의수준 α에서 F₀가 임계값 Fα(a−1, N−a)보다 크거나 p값이 α보다 작으면 귀무가설을 기각해. 반대로 기각하지 못한 경우는 평균이 완전히 같음을 증명한 것이 아니라 차이가 있다는 증거가 부족하다는 뜻이야.

기여율과 효과 추정

단순 기여율은 ρA = SSA/SST × 100으로 구해. 예시에서는 54/60 × 100 = 90%야. 순기여율을 요구하면 SA′ = SSA − fA·MSe로 순변동을 계산한 뒤 ρA′ = SA′/SST × 100을 사용해. 오차분산의 추정값은 MSe이고, 수준평균 μᵢ의 추정값은 x̄ᵢ, 수준효과 αᵢ의 추정값은 x̄ᵢ − x̄이야. 예시의 효과 추정값은 −3, 0, 3이 돼.

비교의 경계와 시험 함정

F검정이 유의하다는 것은 적어도 하나의 평균이 다르다는 뜻이야. 어느 수준끼리 다른지는 대비나 Tukey 방법 같은 별도의 다중비교가 필요해. 통계적으로 유의하더라도 실무적으로 중요한 차이라는 보장은 없으므로 평균차의 크기와 공정 허용범위도 함께 봐야 해.

  • 총 자유도는 N이 아니라 N − 1이야.
  • 오차 자유도는 N − a야.
  • F비는 요인 평균제곱을 오차 평균제곱으로 나눈 값이야.
  • 유의한 결과가 모든 평균이 서로 다르다는 뜻은 아니야.
  • 불균형 반복에서는 SSA 계산에 각 수준의 nᵢ를 사용해.
  • p값이 유의수준보다 작을 때 귀무가설을 기각해.

🧭 반복이 없는 2요인 실험

정의와 모형

반복이 없는 2요인 실험은 두 요인 A와 B의 각 수준 조합에서 관측값을 하나씩 얻는 실험이야. A가 a수준이고 B가 b수준이면 전체 관측수는 N = ab야. 기본 모형은 xᵢⱼ = μ + αᵢ + βⱼ + eᵢⱼ이며 αᵢ와 βⱼ는 각각 A와 B의 주효과야.

각 조합의 관측이 하나뿐이므로 A×B 교호작용과 순수오차를 따로 분리할 수 없어. 따라서 교호작용이 없거나 무시할 수 있다는 가정 아래 주효과를 해석해. 실제 교호작용이 크면 그 변동이 잔차에 섞여 검정력이 약해지거나 결론이 왜곡될 수 있어.

제곱합 계산 원리

변동은 SST = SSA + SSB + SSe로 분해해. 수정항은 CT = T²/(ab), 총제곱합은 SST = ΣΣxᵢⱼ² − CT야. A의 행합을 Tᵢ·, B의 열합을 T·ⱼ라 하면 SSA = Σ(Tᵢ·²/b) − CT, SSB = Σ(T·ⱼ²/a) − CT, SSe = SST − SSA − SSB가 돼. 한 행에는 B수준의 관측이 b개 있으므로 행합은 b로 나누고, 한 열에는 A수준의 관측이 a개 있으므로 열합은 a로 나눠.

자유도는 (a − 1) + (b − 1) + (a − 1)(b − 1) = ab − 1로 검산할 수 있어. A와 B는 각각 MSA/MSe와 MSB/MSe를 계산해 별도로 검정해야 하며, A가 유의하다고 해서 B도 유의한 것은 아니야.

시험 함정

  • 전체 관측수는 a + b가 아니라 ab야.
  • 오차 자유도는 (a − 1)(b − 1)이야.
  • SSA에서는 행합의 제곱을 b로 나누고 SSB에서는 열합의 제곱을 a로 나눠.
  • 수준 조합당 관측이 하나면 교호작용과 순수오차를 별도로 검정할 수 없어.
  • A와 B의 검정통계량은 각각 MSA/MSe와 MSB/MSe야.

⚙️ 계산 절차

1요인 실험 계산 순서

  1. 수준 수 a, 반복수 nᵢ, 전체 관측수 N을 확인해.
  2. 수준합 Tᵢ와 총합 T를 계산해.
  3. CT = T²/N을 계산해.
  4. SST = Σx² − CT를 계산해.
  5. SSA = Σ(Tᵢ²/nᵢ) − CT를 계산해.
  6. SSe = SST − SSA를 계산해.
  7. 자유도 a − 1, N − a, N − 1을 배정해.
  8. MSA와 MSe를 구한 뒤 F₀ = MSA/MSe를 계산해.
  9. 임계값 또는 p값으로 가설을 판정해.

반복이 없는 2요인 실험 계산 순서

  1. A의 수준 수 a와 B의 수준 수 b를 확인해.
  2. 행합 Tᵢ·, 열합 T·ⱼ, 총합 T를 계산해.
  3. CT = T²/(ab)를 계산해.
  4. SST, SSA, SSB를 계산해.
  5. SSe = SST − SSA − SSB를 계산해.
  6. 각 자유도를 배정하고 합이 ab − 1인지 확인해.
  7. MSA, MSB, MSe를 계산해.
  8. F₀(A)와 F₀(B)를 각각 계산해.
  9. 교호작용을 독립적으로 검정할 수 없다는 한계를 함께 해석해.

행에는 B수준이 b개 들어가므로 행합은 b로 나누고, 열에는 A수준이 a개 들어가므로 열합은 a로 나눈다고 구조로 기억해. 공식만 외우는 것보다 훨씬 안정적이야.

✍️ 확인 문제

문제

  1. 요인 A가 4수준이고 각 수준에서 5회 반복한 1요인 실험의 총 관측수, 요인 자유도, 오차 자유도, 총 자유도를 구해봐.
  2. SSA = 72, SSe = 24, a = 4, N = 16일 때 MSA, MSe, F₀를 구해봐.
  3. 1요인 F검정이 유의할 때 “모든 평균이 서로 다르다”와 “적어도 하나의 평균이 다르다” 중 올바른 설명을 골라봐.
  4. A가 3수준, B가 4수준인 반복이 없는 2요인 실험에서 전체 관측수와 A, B, 오차, 합계 자유도를 구해봐.
  5. SSA = 30, SSB = 18, SST = 60, a = 3, b = 3일 때 SSe, MSA, MSB, MSe, F₀(A), F₀(B)를 구해봐.
  6. 반복이 없는 2요인 실험에서 교호작용을 순수오차와 분리해 검정할 수 없는 이유를 설명해봐.

정답 및 해설

  1. N = 20, 요인 자유도 3, 오차 자유도 16, 총 자유도 19야. 3 + 16 = 19로 검산할 수 있어.
  2. MSA = 24, MSe = 2, F₀ = 12야.
  3. 적어도 하나의 평균이 다르다가 올바른 설명이야. 어느 평균들이 다른지는 추가 비교가 필요해.
  4. N = 12, A 자유도 2, B 자유도 3, 오차 자유도 6, 합계 자유도 11이야.
  5. SSe = 12, MSA = 15, MSB = 9, MSe = 3, F₀(A) = 5, F₀(B) = 3이야.
  6. 각 수준 조합에 관측이 하나뿐이라 동일 조합 안의 반복변동을 측정할 수 없어. 따라서 교호작용 변동과 순수오차가 잔차에 함께 들어가 분리되지 않아.

✨ 요약

  • 1요인 실험: 한 요인의 여러 수준에서 평균 차이를 검정해.
  • 변동 분해: 1요인 실험에서는 SST = SSA + SSe가 성립해.
  • F검정: F₀ = MSA/MSe로 요인 신호와 오차 잡음을 비교해.
  • 해석 경계: 유의한 F값은 적어도 하나의 평균이 다르다는 뜻이야.
  • 반복이 없는 2요인 실험: SST = SSA + SSB + SSe로 분해해.
  • 자유도: A는 a − 1, B는 b − 1, 오차는 (a − 1)(b − 1), 합계는 ab − 1이야.
  • 핵심 한계: 반복이 없으면 교호작용과 순수오차를 분리할 수 없어.
  • 계산 전략: 수정항, 제곱합, 자유도, 평균제곱, F비 순서로 풀면 실수가 줄어.

결국 분산분석은 전체 흔들림을 원인별 몫으로 나눈 뒤, 요인에서 나온 신호가 우연한 잡음보다 충분히 큰지를 판정하는 방법이야. 이 구조를 잡으면 공식도 하나의 이야기처럼 연결돼. 😊
