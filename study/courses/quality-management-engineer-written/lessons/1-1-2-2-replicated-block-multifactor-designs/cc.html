이번 학습의 중심 질문은 관측값의 변동을 어떤 원인에 배분할 것인가야. 반복이 있는 실험에서는 교호작용과 순수오차를 분리하고, 난괴법에서는 불필요한 환경 변동을 블록효과로 제거하며, 다요인실험에서는 여러 주효과와 교호작용을 동시에 분석해.

🧪 반복이 있는2요인 실험

정의와 실험 구조

반복이 있는2요인 실험은 요인 A의 각 수준과 요인 B의 각 수준을 조합한 모든 처리조건에서 관측을 두 번 이상 반복하는 실험이야. A의 수준 수를 a, B의 수준 수를 b, 각 조합의 반복 수를 r이라고 하면 전체 관측 수는 N = abr이야. 관측값 Yᵢⱼₖ에서 i는 A의 수준, j는 B의 수준, k는 동일 처리조합의 반복을 나타내. 기본 모형은 Yᵢⱼₖ = μ + αᵢ + βⱼ + (αβ)ᵢⱼ + εᵢⱼₖ로 표현해.

μ는 전체 평균, αᵢ와 βⱼ는 각 요인의 주효과, (αβ)ᵢⱼ는 A×B 교호작용, εᵢⱼₖ는 실험오차야. 동일한 A–B 조합에서 얻은 반복 관측값 사이의 차이는 처리조건이 같으므로 원칙적으로 순수오차에서 발생해. 따라서 반복은 순수오차를 직접 추정하고 주효과와 교호작용을 독립적으로 검정하게 해주는 핵심 장치야.

주효과와 교호작용

주효과는 다른 요인의 수준을 평균했을 때 한 요인이 반응값에 미치는 평균적인 영향이야. 교호작용은 한 요인의 효과가 다른 요인의 수준에 따라 달라지는 현상이야. 예를 들어 온도를 높였을 때 재료 B₁의 강도는 증가하지만 B₂의 강도는 감소한다면 온도의 효과가 재료에 의존하므로 A×B 교호작용이 존재해. 이때 “온도를 높이면 강도가 증가한다”라는 평균적 주효과만 제시하면 특정 재료에서 반대 결과가 나타나는 사실을 감출 수 있어.

교호작용 그림에서 선이 거의 평행하면 교호작용이 작고, 기울기가 뚜렷하게 다르면 교호작용 가능성이 있어. 선이 교차하면 강한 교호작용을 의심할 수 있지만, 그림은 어디까지나 보조 수단이야. 최종 판단은 교호작용 평균제곱을 오차평균제곱과 비교하는 F검정으로 해야 해.

제곱합과 자유도의 분해

총변동은 SST = SSA + SSB + SSAB + SSE로 분해해. SSA는 요인 A, SSB는 요인 B, SSAB는 A×B 교호작용, SSE는 반복 관측 내부의 오차변동이야. 각 자유도는 A가 a−1, B가 b−1, 교호작용이 (a−1)(b−1), 오차가 ab(r−1), 합계가 abr−1이야.

자유도는 (a−1)+(b−1)+(a−1)(b−1)+ab(r−1)=abr−1을 만족해. 시험에서는 이 관계가 강력한 검산 장치야. 제곱합 계산이 복잡하더라도 자유도 합이 맞지 않으면 분산분석표의 배정부터 다시 확인해야 해.

제곱합 계산 절차

전체 합계를 T, A의 i수준 합계를 Aᵢ, B의 j수준 합계를 Bⱼ, 처리조합 ij의 합계를 Tᵢⱼ라고 하자. 수정항은 CT = T² ÷ abr이고, 총제곱합은 SST = ΣYᵢⱼₖ² − CT야. 요인 A와 B의 제곱합은 각각 SSA = ΣAᵢ² ÷ br − CT, SSB = ΣBⱼ² ÷ ar − CT로 계산해.

처리조합 전체의 변동은 ΣΣTᵢⱼ² ÷ r − CT야. 여기에는 A와 B의 주효과도 들어 있으므로 순수한 교호작용은 SSAB = ΣΣTᵢⱼ² ÷ r − CT − SSA − SSB로 구해야 해. 마지막으로 SSE = SST − SSA − SSB − SSAB를 사용하면 계산 누락을 줄일 수 있어.

평균제곱과 F검정

평균제곱은 각 제곱합을 해당 자유도로 나눈 값이야. MSA = SSA ÷ (a−1), MSB = SSB ÷ (b−1), MSAB = SSAB ÷ {(a−1)(b−1)}, MSE = SSE ÷ {ab(r−1)}로 계산해. F비는 Fₐ = MSA÷MSE, Fᵦ = MSB÷MSE, Fₐᵦ = MSAB÷MSE야. 계산된 F값이 효과별 분자 자유도와 공통 분모 자유도에 대응하는 임계값보다 크면 해당 효과가 유의하다고 판단해.

구체적인 계산 예시

A가 2수준, B가 3수준이고 각 처리조합을 4회 반복하면 a=2, b=3, r=4, N=24야. 자유도는 A가 1, B가 2, A×B가 2, 오차가 18, 합계가 23이야. 계산 결과가 SSA=36, SSB=40, SSAB=20, SSE=72라면 MSA=36, MSB=20, MSAB=10, MSE=4가 돼. 따라서 Fₐ=9, Fᵦ=5, Fₐᵦ=2.5야. A에는 F(1,18), B와 A×B에는 F(2,18)의 임계값을 적용해야 한다는 점도 놓치면 안 돼.

반복 관측이 있다고 해서 언제나 올바른 반복은 아니야. 같은 시료를 여러 번 읽은 측정 반복과 서로 독립적인 실험단위를 사용한 실험 반복을 구분해야 해. 동일 시료의 반복 측정을 독립 반복처럼 처리하면 표본 수를 과장하는 의사반복 문제가 생겨.

시험 함정

  • 반복 수 r과 전체 관측 수 abr을 혼동하지 않아야 해.
  • 교호작용 자유도는 ab−1이 아니라 (a−1)(b−1)이야.
  • 오차 자유도는 r−1이 아니라 ab(r−1)이야.
  • 처리조합 제곱합에서 SSA와 SSB를 빼야 순수한 SSAB가 돼.
  • 교호작용이 유의하면 관련 주효과를 조건부로 해석해야 해.

🧱 난괴법

정의와 목적

난괴법은 반응값에 영향을 주지만 주된 연구대상은 아닌 잡음요인을 기준으로 실험단위를 동질적인 블록으로 나눈 뒤, 각 블록 안에 모든 처리를 무작위로 배치하는 방법이야. 영어 명칭은 Randomized Complete Block Design이고, Complete는 각 블록에 모든 처리가 한 번씩 포함된다는 뜻이야. 처리를 A, 블록을 B라고 하면 기본 모형은 Yᵢⱼ = μ + αᵢ + βⱼ + εᵢⱼ야.

αᵢ는 처리효과, βⱼ는 블록효과야. 기본 난괴법에서는 처리×블록 교호작용을 별도로 추정하지 않아. 따라서 처리효과와 블록효과가 더해지는 가법성이 중요한 가정이고, 실제 교호작용이 크다면 그 변동이 오차에 섞일 수 있어.

블록화의 원리

실험에서 원하지 않는 변동을 완전히 제거하기 어렵더라도 그 원인을 알고 있다면 같은 조건끼리 묶을 수 있어. 네 가지 열처리 방법을 여러 날짜에 걸쳐 비교할 때 날짜에 따라 온도나 설비 상태가 달라진다면 날짜를 블록으로 정하고, 매일 네 가지 처리를 모두 무작위 순서로 실시할 수 있어. 완전임의배치법에서는 날짜 변동이 오차에 들어가지만, 난괴법에서는 그것이 블록제곱합으로 분리돼.

블록화가 효과적이면 오차평균제곱이 작아져 처리 차이를 탐지하는 검정력이 높아질 수 있어. 다만 블록끼리 서로 동일해야 하는 것은 아니야. 오히려 블록 간 차이는 허용되며, 중요한 조건은 각 블록 내부의 실험단위가 서로 유사하다는 것이야.

배치 절차

  1. 비교할 처리와 처리 수준을 정해.
  2. 반응값에 영향을 줄 것으로 예상되는 주요 잡음요인을 찾아.
  3. 잡음 조건이 유사한 실험단위를 하나의 블록으로 묶어.
  4. 각 블록에 모든 처리를 한 번씩 포함해.
  5. 각 블록 내부에서 처리의 실시 순서를 무작위화해.
  6. 처리효과와 블록효과를 포함한 분산분석을 실시해.

제곱합과 자유도

처리 수준 수를 a, 블록 수를 b라고 하면 전체 관측 수는 ab야. 총변동은 SST = SSA + SSB + SSE로 분해해. SSA는 처리변동, SSB는 블록변동, SSE는 처리와 블록으로 설명되지 않는 오차변동이야.

전체 합계를 T, 처리별 합계를 Aᵢ, 블록별 합계를 Bⱼ라고 하면 CT=T²÷ab, SST=ΣΣYᵢⱼ²−CT, SSA=ΣAᵢ²÷b−CT, SSB=ΣBⱼ²÷a−CT야. 오차는 SSE=SST−SSA−SSB로 구해. 처리효과의 검정통계량은 F처리=MSA÷MSE이고, 필요하면 F블록=MSB÷MSE로 블록효과도 살펴볼 수 있어.

구체적인 계산 예시

세 가지 공정조건을 네 대의 설비에서 비교하고 설비를 블록으로 정했다면 a=3, b=4, 전체 관측 수는 12야. SSA=48, SSB=30, SST=90이라면 SSE=90−48−30=12야. 자유도는 처리 2, 블록 3, 오차 6, 합계 11이므로 MSA=24, MSB=10, MSE=2가 돼. 처리효과의 검정통계량은 F처리=24÷2=12야.

블록을 무시했다면 설비 간 변동 30이 오차에 포함돼 검정 분모가 더 커졌을 가능성이 있어. 난괴법은 처리효과를 인위적으로 키우는 방법이 아니라, 원래 존재하던 설비 차이를 올바른 변동원으로 분리하는 방법이야.

시험 함정

  • 각 블록에는 원칙적으로 모든 처리가 포함돼.
  • 처리는 연구대상이고 블록은 통제하려는 잡음요인이야.
  • 무작위화는 각 블록 내부에서 수행해.
  • 기본 난괴법에서는 처리×블록 교호작용을 독립적으로 추정하지 못해.
  • 오차 자유도는 (a−1)(b−1)이야.
  • 블록효과의 유의성과 처리효과의 유의성은 서로 다른 판단이야.

🧬 다요인실험의 개요

정의와 모형

다요인실험의 개요에서 핵심은 세 개 이상의 요인을 동시에 변화시켜 각 요인의 주효과와 요인 사이의 교호작용을 분석하는 데 있어. 요인이 A, B, C라면 모형에는 A, B, C의 주효과, AB, AC, BC의 2인자 교호작용, ABC의 3인자 교호작용이 포함될 수 있어. 개념적으로 Y = μ + A + B + C + AB + AC + BC + ABC + ε로 표현해.

처리조합 수와 전체 관측 수

각 요인의 수준 수가 a, b, c라면 처리조합 수는 abc야. 각 처리조합을 r회 반복하면 전체 관측 수는 abcr이 돼. 예를 들어 수준 수가 각각 2, 3, 4라면 처리조합은 24개이고, 각 조합을 2회 반복하면 전체 관측 수는 48개야.

모든 요인이 2수준인 k요인 실험은 2ᵏ 요인실험이라고 해. 처리조합은 2ᵏ개이므로 2²는 4개, 2³은 8개, 2⁴는 16개, 2⁵는 32개야. 요인이 하나 늘 때마다 처리조합이 두 배가 되므로 정보량이 풍부한 대신 실험 규모가 빠르게 커져.

효과의 계층 구조

3요인 실험에서는 A, B, C라는 세 주효과와 AB, AC, BC라는 세 개의 2인자 교호작용, ABC라는 하나의 3인자 교호작용을 분석할 수 있어. 해석은 일반적으로 가장 높은 차수의 교호작용부터 확인하는 것이 안전해. ABC가 유의하면 AB의 형태가 C의 수준에 따라 달라진다는 뜻이므로 AB를 C와 무관한 하나의 효과로 단정하기 어려워.

고차 교호작용은 저차 효과보다 해석하기 어렵고 실제로 작을 때가 많지만, 복잡하다는 이유만으로 무조건 0이라고 가정하면 안 돼. 반복자료, 공학적 지식, 효과도와 잔차분석을 함께 사용해야 해. 교호작용의 계층성을 무시하지 않는 것이 다요인실험 해석의 핵심이야.

2수준 3요인 실험에서는 각 효과의 자유도가 모두 1이야. A, B, C, AB, AC, BC, ABC의 자유도 합은 7이며 이는 2³−1과 일치해. 균형을 이룬 고정효과 기본모형에서는 각 효과의 평균제곱을 MSE로 나누어 F비를 계산해. 랜덤효과나 혼합모형에서는 적절한 검정 분모가 달라질 수 있다는 경계도 기억해.

한 요인씩 변경하는 방법과의 비교

한 요인씩 바꾸는 방법은 다른 요인을 고정하고 하나만 변화시키므로 단순하지만 교호작용을 놓칠 수 있어. 접착강도 실험에서 낮은 압력에서는 온도 상승이 유리하지만 높은 압력에서는 지나친 온도가 접착제를 손상시킨다면, 온도의 효과는 압력에 따라 달라져. 한 압력 수준만 고정하고 온도를 변화시키면 다른 압력에서 나타나는 반대 효과를 발견하지 못할 수 있어.

완전요인실험은 모든 수준 조합을 관측하므로 여러 주효과를 한 실험에서 추정하고 교호작용을 발견할 수 있어. 또한 공정의 최적조건뿐 아니라 조건 변화에 대한 강건성도 살펴볼 수 있어. 다만 요인 수가 늘면 처리조합 수가 지수적으로 증가한다는 비용을 함께 고려해야 해.

구체적인 예시

도장 공정의 불량률에 영향을 주는 건조온도 A, 도료 점도 B, 건조시간 C를 각각 2수준으로 정하면 2³=8개의 처리조합이 생겨. 각 조합을 3회 반복하면 전체 관측 수는 24개야. 분석 결과 A의 주효과와 AC 교호작용이 유의하다면 “높은 온도가 항상 좋다”라고 결론 내리면 안 돼. 온도의 효과가 건조시간에 따라 달라지므로 C의 각 수준에서 A의 단순효과를 비교해야 해.

완전요인실험과 일부실시법의 경계

2수준 요인이 7개면 완전요인실험에는 2⁷=128개 처리조합이 필요해. 실험 규모가 지나치게 크다면 일부 처리조합만 선택하는 일부실시법을 고려할 수 있어. 하지만 실험 횟수를 줄이면 서로 다른 효과를 분리하지 못하는 교락이 발생해. 일부실시법은 공짜로 실험 수를 줄이는 방법이 아니라, 적은 실험 횟수와 효과 식별력 사이의 교환관계를 관리하는 설계야.

  • 2³은 2수준 요인이 3개라는 뜻이야.
  • 2ᵏ 실험의 처리조합 수는 2k가 아니라 2ᵏ이야.
  • 3요인 실험에는 주효과 3개, 2인자 교호작용 3개, 3인자 교호작용 1개가 있어.
  • 처리조합 수와 반복을 포함한 총 관측 수를 구분해야 해.
  • 일부실시법에서는 효과 사이의 교락을 반드시 검토해야 해.

반복이 있는 2요인 실험의 풀이 순서

  1. a, b, r과 전체 관측 수 N=abr을 확인해.
  2. 수정항, 총제곱합, 두 주효과 제곱합을 계산해.
  3. 처리조합 합계로부터 교호작용 제곱합을 구해.
  4. 차감법으로 오차제곱합을 계산해.
  5. 자유도, 평균제곱, F비를 차례로 완성해.
  6. 교호작용부터 유의성을 확인하고 주효과를 해석해.

난괴법의 풀이 순서

  1. 연구대상인 처리와 통제대상인 블록을 구분해.
  2. 수정항과 총제곱합을 계산해.
  3. 처리합계로 SSA, 블록합계로 SSB를 구해.
  4. SSE=SST−SSA−SSB를 계산해.
  5. 오차 자유도 (a−1)(b−1)를 적용해.
  6. F처리=MSA÷MSE로 처리효과를 검정해.

다요인실험의 풀이 순서

  1. 요인 수와 각 요인의 수준 수를 확인해.
  2. 수준 수의 곱으로 처리조합 수를 구해.
  3. 반복 수를 곱해 총 관측 수를 구해.
  4. 주효과와 가능한 모든 교호작용을 나열해.
  5. 최고차 교호작용부터 유의성을 판단해.
  6. 유의한 교호작용에 관련된 주효과를 조건부로 해석해.

문제 1

요인 A가 3수준, 요인 B가 4수준이고 각 처리조합을 2회 반복했다. 전체 관측 수와 오차 자유도를 구해봐.

문제 2

반복이 있는 2요인 실험에서 a=2, b=3, r=4이고 SSA=30, SSB=24, SSAB=12, SSE=72이다. A, B, A×B의 F값을 각각 구해봐.

문제 3

네 가지 처리방법을 다섯 명의 작업자에게 각각 한 번씩 적용하고 작업자를 블록으로 정했다. 처리, 블록, 오차, 합계 자유도를 구해봐.

문제 4

3수준 요인 A, 2수준 요인 B, 4수준 요인 C를 모두 조합하고 각 조합을 3회 반복했다. 처리조합 수와 총 관측 수를 구해봐.

문제 5

2³ 요인실험에 존재하는 주효과와 교호작용을 모두 써봐.

문제 6

  1. 난괴법에서는 서로 다른 블록들이 가능한 한 동일해야 한다.
  2. 반복이 있는 2요인 실험에서는 순수오차와 교호작용을 분리할 수 있다.
  3. 2⁵ 요인실험의 처리조합 수는 10개이다.
  4. 교호작용이 유의하더라도 관련 주효과만 해석하면 충분하다.
  5. 난괴법에서는 각 블록 내부에서 처리 순서를 무작위화한다.

✅ 정답 및 해설

문제 1 정답

전체 관측 수는 24이고 오차 자유도는 12야. N=abr=3×4×2=24이고, dfE=ab(r−1)=3×4×1=12야.

문제 2 정답

자유도는 A가 1, B가 2, AB가 2, 오차가 18이야. 따라서 MSA=30, MSB=12, MSAB=6, MSE=4가 돼. 정답은 Fₐ=7.5, Fᵦ=3, Fₐᵦ=1.5야.

문제 3 정답

처리 수 a=4, 블록 수 b=5이므로 처리 자유도 3, 블록 자유도 4, 오차 자유도 12, 합계 자유도 19야. 검산하면 3+4+12=19로 일치해.

문제 4 정답

처리조합 수는 3×2×4=24이고, 총 관측 수는 3×2×4×3=72야. 처리조합 수에는 반복을 곱하지 않지만 전체 관측 수에는 반복 수를 곱해야 해.

문제 5 정답

주효과는 A, B, C, 2인자 교호작용은 AB, AC, BC, 3인자 교호작용은 ABC야. 전체 효과는 일곱 개야.

문제 6 정답

  1. X: 블록끼리가 아니라 각 블록 내부의 실험단위가 유사해야 해.
  2. O: 반복으로 순수오차를 추정하므로 교호작용을 별도로 검정할 수 있어.
  3. X: 2⁵는 32개야.
  4. X: 유의한 교호작용부터 해석하고 조건별 단순효과를 확인해야 해.
  5. O: 난괴법은 각 블록 내부에서 처리를 무작위 배치해.

✨ 요약

  • 반복이 있는2요인 실험: 총변동을 A, B, A×B, 오차로 분해하고 반복을 통해 순수오차를 추정해.
  • 오차 자유도: 반복이 있는 2요인 실험에서는 ab(r−1)이야.
  • 교호작용: 유의하면 한 요인의 효과가 다른 요인의 수준에 따라 달라지므로 조건부 해석이 필요해.
  • 난괴법: 알려진 잡음요인을 블록으로 분리해 처리효과 검정의 정밀도를 높여.
  • 난괴법 자유도: 오차 자유도는 (a−1)(b−1)이야.
  • 다요인실험의 개요: 세 개 이상의 요인을 동시에 다루며 주효과와 여러 차수의 교호작용을 분석해.
  • 처리조합과 관측 수: 3요인 실험은 abc개 조합이고 r회 반복하면 abcr개 관측이 생겨.
  • 시험 전략: 설계 식별, 관측 수, 제곱합, 자유도, 평균제곱, F비, 교호작용 해석 순서로 풀어.
