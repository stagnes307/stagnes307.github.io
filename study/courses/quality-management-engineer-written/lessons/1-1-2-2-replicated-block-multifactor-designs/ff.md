## 1. 반복이 있는2요인 실험

### 1.1 정의와 실험 구조

**반복이 있는2요인 실험**은 요인 A의 각 수준과 요인 B의 각 수준을 조합한 모든 처리조건에서 관측을 두 번 이상 반복하는 실험이야.

요인 A의 수준 수를 a, 요인 B의 수준 수를 b, 각 조합의 반복 수를 r이라고 하면 전체 관측 수는 다음과 같아.

**N = abr**

관측값은 Yᵢⱼₖ로 나타낼 수 있어.

1. i는 요인 A의 수준을 나타내.
2. j는 요인 B의 수준을 나타내.
3. k는 동일한 처리조합에서의 반복을 나타내.

모형은 다음과 같이 표현해.

**Yᵢⱼₖ = μ + αᵢ + βⱼ + (αβ)ᵢⱼ + εᵢⱼₖ**

여기서 μ는 전체 평균, αᵢ는 요인 A의 주효과, βⱼ는 요인 B의 주효과, (αβ)ᵢⱼ는 A와 B의 교호작용, εᵢⱼₖ는 실험오차야.

반복이 없을 때와 비교하면 가장 중요한 차이는 **순수오차를 직접 추정할 수 있다**는 점이야. 동일한 A–B 조합에서 얻은 반복 관측값 사이의 차이는 처리조건이 같으므로 원칙적으로 실험오차에서 발생해. 이 오차를 기준으로 주효과와 교호작용의 유의성을 검정할 수 있어.

### 1.2 주효과와 교호작용

**주효과**는 다른 요인의 수준을 평균했을 때 한 요인이 반응값에 미치는 평균적인 영향이야.

반면 **교호작용**은 한 요인의 효과가 다른 요인의 수준에 따라 달라지는 현상이야. 예를 들어 온도 A와 재료 B가 제품 강도에 영향을 준다고 해보자. 온도를 높였을 때 재료 B₁의 강도는 증가하지만 B₂의 강도는 감소한다면, 온도의 효과는 재료에 따라 달라져. 이때 A×B 교호작용이 존재한다고 봐.

교호작용이 유의하면 주효과만 따로 해석하면 위험해. “온도를 높이면 강도가 증가한다”라는 평균적 결론이 특정 재료에서는 정반대로 나타날 수 있기 때문이야.

교호작용 그림에서는 다음처럼 판단해.

1. 선이 거의 평행하면 교호작용이 작아.
2. 선의 기울기가 뚜렷하게 다르면 교호작용 가능성이 있어.
3. 선이 서로 교차하면 강한 교호작용을 의심할 수 있어.
4. 시각적 판단은 보조 수단이며 최종 판단은 분산분석의 F검정으로 해야 해.

### 1.3 제곱합의 분해

총변동은 다음과 같이 분해돼.

**SST = SSA + SSB + SSAB + SSE**

각 기호는 다음 변동을 뜻해.

| 변동요인 | 의미 | 자유도 |
|---|---|---:|
| 요인 A | A 수준 간 평균 차이 | a − 1 |
| 요인 B | B 수준 간 평균 차이 | b − 1 |
| A×B | 두 요인의 교호작용 | (a − 1)(b − 1) |
| 오차 | 동일 처리조합 내부의 반복 변동 | ab(r − 1) |
| 합계 | 전체 관측값의 변동 | abr − 1 |

자유도 합이 맞는지 확인해보자.

**(a−1) + (b−1) + (a−1)(b−1) + ab(r−1) = abr−1**

시험에서는 이 자유도 관계가 계산 검산 장치가 돼. 제곱합 계산이 복잡하더라도 자유도가 틀리면 분산분석표 전체가 잘못된 거야.

### 1.4 제곱합 계산식

전체 합계를 T, A의 i수준 합계를 Aᵢ, B의 j수준 합계를 Bⱼ, 처리조합 ij의 합계를 Tᵢⱼ라고 하자. 수정항은 다음과 같아.

**CT = T² ÷ abr**

총제곱합은 다음과 같아.

**SST = ΣYᵢⱼₖ² − CT**

요인 A의 제곱합은 다음과 같아.

**SSA = ΣAᵢ² ÷ br − CT**

요인 B의 제곱합은 다음과 같아.

**SSB = ΣBⱼ² ÷ ar − CT**

A와 B의 조합에 의한 제곱합은 다음과 같아.

**SSA×B 결합 = ΣΣTᵢⱼ² ÷ r − CT**

순수한 교호작용 제곱합은 결합변동에서 두 주효과를 제거해 구해.

**SSAB = ΣΣTᵢⱼ² ÷ r − CT − SSA − SSB**

오차제곱합은 다음과 같아.

**SSE = SST − SSA − SSB − SSAB**

### 1.5 평균제곱과 F검정

평균제곱은 제곱합을 해당 자유도로 나눈 값이야.

**MSA = SSA ÷ (a−1)**  
**MSB = SSB ÷ (b−1)**  
**MSAB = SSAB ÷ {(a−1)(b−1)}**  
**MSE = SSE ÷ {ab(r−1)}**

검정통계량은 모두 오차평균제곱을 분모로 사용해.

**Fₐ = MSA ÷ MSE**  
**Fᵦ = MSB ÷ MSE**  
**Fₐᵦ = MSAB ÷ MSE**

계산한 F값이 주어진 유의수준의 임계값보다 크면 해당 효과가 유의하다고 판단해.

### 1.6 구체적인 계산 예시

요인 A가 2수준, 요인 B가 3수준이고 각 처리조합을 4회 반복했다고 하자.

**a = 2, b = 3, r = 4, N = 24**

자유도는 다음과 같아.

| 변동요인 | 자유도 |
|---|---:|
| A | 1 |
| B | 2 |
| A×B | 2 |
| 오차 | 18 |
| 합계 | 23 |

가령 계산 결과가 SSA = 36, SSB = 40, SSAB = 20, SSE = 72라면 평균제곱은 다음과 같아.

**MSA = 36 ÷ 1 = 36**  
**MSB = 40 ÷ 2 = 20**  
**MSAB = 20 ÷ 2 = 10**  
**MSE = 72 ÷ 18 = 4**

따라서 F값은 다음과 같아.

**Fₐ = 36 ÷ 4 = 9**  
**Fᵦ = 20 ÷ 4 = 5**  
**Fₐᵦ = 10 ÷ 4 = 2.5**

이 값들을 각각 해당 분자·분모 자유도의 F 임계값과 비교해야 해. 같은 숫자 4를 기준으로 판단하는 것이 아니라, A는 F(1,18), B와 A×B는 F(2,18)의 임계값을 사용한다는 점을 기억해.

### 1.7 비교와 경계

| 구분 | 반복 없는 2요인 실험 | 반복이 있는 2요인 실험 |
|---|---|---|
| 처리조합당 관측 수 | 1 | 2 이상 |
| 순수오차 추정 | 원칙적으로 불가능 | 가능 |
| 교호작용의 독립적 검정 | 일반적으로 곤란 | 가능 |
| 총 자유도 | ab−1 | abr−1 |
| 오차 자유도 | 보통 교호작용과 분리 불가 | ab(r−1) |

반복 관측이 있다고 해서 언제나 올바른 반복은 아니야. 같은 시료를 여러 번 읽은 **측정 반복**과 서로 독립적인 실험단위를 사용한 **실험 반복**을 구분해야 해. 동일 시료를 반복 측정한 값을 독립 반복처럼 처리하면 표본 수를 과장하는 의사반복 문제가 생겨.

### 1.8 시험 함정

1. 반복 수 r을 전체 표본 수로 착각하지 마.
2. 교호작용 자유도는 ab−1이 아니라 **(a−1)(b−1)**이야.
3. 오차 자유도는 r−1이 아니라 **ab(r−1)**이야.
4. 조합제곱합에서 SSA와 SSB를 빼야 순수한 SSAB가 돼.
5. 교호작용이 유의한데 주효과만 독립적으로 단정하면 안 돼.
6. 모든 F비의 분모는 동일한 MSE지만 분자 자유도는 효과별로 달라.

## 2. 난괴법

### 2.1 정의와 목적

**난괴법**은 실험 결과에 영향을 주지만 주된 연구대상은 아닌 잡음요인을 기준으로 실험단위를 동질적인 블록으로 나눈 뒤, 각 블록 안에 모든 처리를 무작위로 배치하는 방법이야.

영어로는 Randomized Complete Block Design이라고 해. 여기서 Complete는 각 블록에 모든 처리가 한 번씩 포함된다는 뜻이야.

처리를 A, 블록을 B라고 하면 관측모형은 다음과 같아.

**Yᵢⱼ = μ + αᵢ + βⱼ + εᵢⱼ**

αᵢ는 처리효과이고 βⱼ는 블록효과야. 기본적인 난괴법에서는 처리와 블록의 교호작용을 별도로 추정하지 않아. 처리×블록 교호작용이 존재한다면 그것이 오차에 섞일 수 있으므로 가법성 가정이 중요해.

### 2.2 왜 블록을 만드는가

실험에서 원하지 않는 변동을 완전히 제거하기는 어려워. 하지만 그 변동의 원인을 알고 있다면 같은 조건끼리 묶을 수 있어.

예를 들어 네 가지 열처리 방법을 비교하는데 실험을 하루에 모두 완료할 수 없다고 하자. 날짜에 따라 실내 온도나 설비 상태가 달라질 수 있어. 이때 날짜를 블록으로 정하고 매일 네 가지 열처리를 모두 무작위 순서로 실시하면 날짜 간 차이를 블록효과로 분리할 수 있어.

완전임의배치법에서는 날짜 변동이 오차에 들어가지만, 난괴법에서는 날짜 변동이 블록제곱합으로 빠져나가. 그 결과 오차평균제곱이 작아지고 처리 차이를 탐지할 검정력이 높아질 수 있어. 블록은 잡음을 담아내는 별도의 서랍과 같아 🤓

### 2.3 배치 절차

난괴법은 다음 순서로 설계해.

1. 비교할 처리와 처리 수준을 정해.
2. 반응값에 영향을 줄 것으로 예상되는 주요 잡음요인을 찾어.
3. 잡음요인의 조건이 유사한 실험단위를 하나의 블록으로 묶어.
4. 각 블록에 모든 처리를 한 번씩 포함해.
5. 각 블록 내부에서 처리의 실시 순서를 무작위화해.
6. 관측값을 수집하고 처리효과와 블록효과를 분산분석해.

블록끼리 동일할 필요는 없어. 오히려 블록 간에는 차이가 있어도 괜찮아. 중요한 것은 **한 블록 내부의 실험단위가 서로 유사해야 한다**는 점이야.

### 2.4 제곱합과 자유도

처리 수준 수를 a, 블록 수를 b라고 하면 전체 관측 수는 ab야.

총변동은 다음처럼 분해해.

**SST = SSA + SSB + SSE**

여기서 SSA는 처리변동, SSB는 블록변동, SSE는 오차변동이야.

| 변동요인 | 자유도 |
|---|---:|
| 처리 A | a−1 |
| 블록 B | b−1 |
| 오차 | (a−1)(b−1) |
| 합계 | ab−1 |

전체 합계를 T, 처리별 합계를 Aᵢ, 블록별 합계를 Bⱼ라고 하면 다음 계산식을 사용해.

**CT = T² ÷ ab**

**SST = ΣΣYᵢⱼ² − CT**

**SSA = ΣAᵢ² ÷ b − CT**

**SSB = ΣBⱼ² ÷ a − CT**

**SSE = SST − SSA − SSB**

평균제곱과 처리효과 검정통계량은 다음과 같아.

**MSA = SSA ÷ (a−1)**  
**MSB = SSB ÷ (b−1)**  
**MSE = SSE ÷ {(a−1)(b−1)}**

**F처리 = MSA ÷ MSE**

필요하다면 블록효과도 **F블록 = MSB ÷ MSE**로 살펴볼 수 있어. 다만 실험의 핵심 관심은 일반적으로 처리효과야.

### 2.5 구체적인 계산 예시

세 가지 공정조건 A₁, A₂, A₃를 네 대의 설비에서 비교한다고 하자. 설비 차이를 블록으로 잡으면 a = 3, b = 4이고 총 관측 수는 12야.

가령 계산 결과가 다음과 같다고 해보자.

**SSA = 48, SSB = 30, SST = 90**

오차제곱합은 다음과 같아.

**SSE = 90 − 48 − 30 = 12**

자유도는 처리 2, 블록 3, 오차 6, 합계 11이야.

**MSA = 48 ÷ 2 = 24**  
**MSB = 30 ÷ 3 = 10**  
**MSE = 12 ÷ 6 = 2**

따라서 처리효과의 검정통계량은 다음과 같아.

**F처리 = 24 ÷ 2 = 12**

블록을 무시한 채 분석했다면 설비 간 변동 30이 오차에 포함되어 처리 검정의 분모가 더 커졌을 가능성이 있어. 난괴법은 처리효과를 인위적으로 키우는 방법이 아니라, 이미 존재하던 설비 차이를 올바른 변동원으로 분리하는 방법이야.

### 2.6 완전임의배치법과 비교

| 구분 | 완전임의배치법 | 난괴법 |
|---|---|---|
| 기본 배치 | 전체 실험단위에 처리를 무작위 배치 | 블록별로 처리를 무작위 배치 |
| 잡음요인 통제 | 주로 무작위화에 의존 | 블록화와 무작위화를 함께 사용 |
| 변동 분해 | 처리 + 오차 | 처리 + 블록 + 오차 |
| 유리한 상황 | 실험단위가 비교적 균질할 때 | 알려진 주요 잡음요인이 있을 때 |
| 위험 | 큰 잡음이 오차에 섞임 | 부적절한 블록화로 오차 자유도가 감소 |

블록요인이 반응값과 거의 관련이 없다면 블록화의 이익은 작아. 그런데도 블록을 만들면 오차 자유도만 줄어 검정력이 나빠질 수 있어. 따라서 아무 변수나 블록으로 지정하는 것이 아니라, 반응값에 실질적인 영향을 주는 잡음요인을 선택해야 해.

### 2.7 시험 함정

1. 난괴법의 각 블록에는 원칙적으로 모든 처리가 포함돼.
2. 처리는 연구대상이고 블록은 통제하려는 잡음요인이야.
3. 무작위화는 전체가 아니라 **각 블록 내부에서** 수행해.
4. 기본 난괴법에서는 처리×블록 교호작용을 독립적으로 추정하지 못해.
5. 오차 자유도는 ab−1이 아니라 **(a−1)(b−1)**이야.
6. 블록 간 동질성을 요구하는 것이 아니라 블록 내부의 동질성을 추구해.
7. 블록효과가 유의하다는 사실은 처리효과가 유의하다는 뜻이 아니야.

## 3. 다요인실험의 개요

### 3.1 정의

**다요인실험의 개요**에서 핵심은 세 개 이상의 요인을 동시에 변화시켜 각 요인의 주효과와 요인 사이의 교호작용을 분석하는 데 있어.

요인이 A, B, C 세 개라면 일반적인 완전요인실험 모형에는 다음 성분이 포함될 수 있어.

**Y = μ + A + B + C + AB + AC + BC + ABC + ε**

여기서 A, B, C는 주효과이고 AB, AC, BC는 2인자 교호작용, ABC는 3인자 교호작용이야.

### 3.2 완전요인배치의 처리조합 수

각 요인의 수준 수가 각각 a, b, c라면 처리조합 수는 다음과 같아.

**처리조합 수 = abc**

각 처리조합을 r회 반복하면 전체 관측 수는 다음과 같아.

**N = abcr**

예를 들어 A가 2수준, B가 3수준, C가 4수준이라면 처리조합은 2×3×4 = 24개야. 각 조합을 2회 반복하면 총 관측 수는 48개가 돼.

모든 요인이 2수준인 k요인 실험은 **2ᵏ 요인실험**이라고 불러. 처리조합 수는 2ᵏ개야.

| 요인 수 k | 처리조합 수 |
|---:|---:|
| 2 | 4 |
| 3 | 8 |
| 4 | 16 |
| 5 | 32 |

요인이 하나씩 늘어날 때마다 처리조합 수가 두 배가 되므로, 다요인실험은 정보량이 풍부한 대신 실험 규모가 빠르게 커져.

### 3.3 효과의 계층 구조

3요인 실험의 효과는 다음처럼 분해돼.

1. 주효과: A, B, C
2. 2인자 교호작용: AB, AC, BC
3. 3인자 교호작용: ABC

해석은 높은 차수의 교호작용부터 확인하는 것이 안전해. ABC가 유의하다면 AB의 형태가 C의 수준에 따라 달라진다는 뜻이므로, AB를 C와 무관한 하나의 효과로 단정하기 어려워.

일반적으로 고차 교호작용은 저차 효과보다 해석하기 어렵고 실제로 작을 때가 많아. 하지만 단지 복잡하다는 이유만으로 무조건 0이라고 가정하면 안 돼. 반복자료, 공학적 지식, 효과도, 잔차분석을 함께 사용해서 판단해야 해.

### 3.4 3요인 반복실험의 자유도

A, B, C의 수준 수가 각각 a, b, c이고 반복 수가 r이라면 자유도는 다음과 같아.

| 변동요인 | 자유도 |
|---|---:|
| A | a−1 |
| B | b−1 |
| C | c−1 |
| AB | (a−1)(b−1) |
| AC | (a−1)(c−1) |
| BC | (b−1)(c−1) |
| ABC | (a−1)(b−1)(c−1) |
| 오차 | abc(r−1) |
| 합계 | abcr−1 |

2수준 3요인 실험에서 각 효과의 자유도는 모두 1이야. A, B, C, AB, AC, BC, ABC의 자유도 합은 7이고, 이는 2³−1과 일치해.

각 효과의 F비는 해당 효과의 평균제곱을 MSE로 나누어 구해. 다만 고정효과모형인지 랜덤효과모형인지, 혼합모형인지에 따라 적절한 분모가 달라질 수 있어. 품질경영기사의 기본 계산에서는 먼저 고정효과와 균형자료를 전제로 한 표준 분산분석 구조를 정확히 익히는 게 좋아.

### 3.5 다요인실험이 한 요인씩 바꾸는 방법보다 나은 이유

한 요인씩 바꾸는 방법은 다른 요인을 고정하고 하나만 변화시켜. 단순하지만 요인 사이의 교호작용을 놓칠 수 있어.

예를 들어 접착강도에 온도 A와 압력 B가 영향을 준다고 하자. 낮은 압력에서는 온도를 높이는 것이 유리하지만 높은 압력에서는 지나친 온도가 접착제를 손상시킬 수 있어. A만 바꾸고 B를 한 수준에 고정하면 다른 B 수준에서 나타나는 반대 효과를 발견하지 못해.

완전요인실험은 모든 수준 조합을 관측하므로 다음 장점이 있어.

1. 여러 주효과를 한 실험에서 추정할 수 있어.
2. 교호작용을 발견할 수 있어.
3. 요인별 실험을 따로 수행하는 것보다 정보 활용이 효율적일 수 있어.
4. 공정의 최적조건뿐 아니라 조건 변화에 대한 안정성을 살펴볼 수 있어.

### 3.6 구체적인 예시

도장 공정의 불량률에 영향을 주는 세 요인을 검토한다고 해보자.

1. A: 건조온도, 낮음과 높음
2. B: 도료 점도, 낮음과 높음
3. C: 건조시간, 짧음과 김

이 실험은 2³ = 8개의 처리조합을 가져. 각 조합을 3회 반복하면 전체 관측 수는 24개야.

분석 결과 A의 주효과가 유의하고 AC 교호작용도 유의하다고 하자. 이때 “높은 온도가 항상 좋다”라고 결론 내리면 안 돼. 높은 온도의 효과가 건조시간에 따라 달라진다는 뜻이기 때문이야. 먼저 C의 각 수준에서 A의 단순효과를 비교하고, 공정적으로 적절한 조합을 찾아야 해.

### 3.7 실험 규모와 일부실시법의 경계

요인 수가 많아지면 완전요인실험의 처리조합 수가 급증해. 2수준 요인이 7개면 2⁷ = 128개의 처리조합이 필요해. 이때 일부 처리조합만 선택하는 **일부실시법**을 고려할 수 있어.

하지만 실험 횟수를 줄이면 일부 효과가 서로 분리되지 않는 **교락**이 발생해. 따라서 일부실시법은 공짜로 실험 수를 줄이는 방법이 아니야. 적은 실험 횟수와 효과 식별력 사이의 교환관계를 설계 단계에서 판단해야 해.

이번 단원에서 기억할 경계는 다음과 같아.

| 설계 | 핵심 목적 | 주요 제약 |
|---|---|---|
| 완전요인실험 | 모든 조합에서 주효과와 교호작용 추정 | 요인 수에 따라 실험 횟수가 급증 |
| 일부실시요인실험 | 적은 실험으로 중요한 효과 탐색 | 효과 사이의 교락 발생 |
| 난괴법 | 알려진 잡음요인을 블록으로 제거 | 처리×블록 교호작용 추정이 제한됨 |
| 한 요인씩 변경 | 단순한 국소 비교 | 교호작용 탐지 불가 |

### 3.8 시험 함정

1. 2³은 요인 수준이 3개라는 뜻이 아니라 **2수준 요인이 3개**라는 뜻이야.
2. 2ᵏ 실험의 처리조합 수는 2k가 아니라 **2ᵏ**이야.
3. 3요인 실험에는 주효과 3개, 2인자 교호작용 3개, 3인자 교호작용 1개가 있어.
4. 교호작용이 유의하면 관련 주효과를 평균적으로만 해석하지 마.
5. 반복 수를 늘리는 것과 요인 수준 수를 늘리는 것은 서로 다른 설계 선택이야.
6. 일부실시법은 모든 효과를 완전요인실험과 동일하게 분리하는 방법이 아니야.
7. 처리조합 수와 총 관측 수를 구분해야 해. 총 관측 수에는 반복 수가 곱해져.

## 5. 계산 문제 해결 절차

### 5.1 반복이 있는 2요인 실험

1. a, b, r을 확인해.
2. N = abr을 계산해.
3. 수정항 CT를 구해.
4. SST, SSA, SSB를 구해.
5. 처리조합 합계로부터 SSAB를 구해.
6. 차감법으로 SSE를 구해.
7. 자유도를 배정해.
8. 각 제곱합을 자유도로 나누어 평균제곱을 구해.
9. 효과별 F비를 계산해.
10. 교호작용부터 해석해.

### 5.2 난괴법

1. 무엇이 처리이고 무엇이 블록인지 먼저 구분해.
2. 처리 수준 수 a와 블록 수 b를 확인해.
3. CT와 SST를 구해.
4. 처리합계로 SSA를 구해.
5. 블록합계로 SSB를 구해.
6. SSE = SST−SSA−SSB를 계산해.
7. 오차 자유도 (a−1)(b−1)를 적용해.
8. F처리 = MSA÷MSE를 구해.
9. 블록화가 오차 감소에 기여했는지 함께 살펴봐.

### 5.3 다요인실험

1. 요인 수와 각 요인의 수준 수를 확인해.
2. 수준 수를 곱해 처리조합 수를 구해.
3. 반복 수를 곱해 총 관측 수를 구해.
4. 주효과와 가능한 교호작용을 모두 나열해.
5. 최고차 교호작용부터 유의성을 확인해.
6. 유의한 교호작용에 관련된 주효과는 조건부로 해석해.
7. 실험 수가 지나치게 크면 일부실시법의 교락 위험을 검토해.

## 7. 정답 및 해설

### 문제 1 정답

**전체 관측 수 24, 오차 자유도 12**

**N = abr = 3×4×2 = 24**

**dfE = ab(r−1) = 3×4×1 = 12**

반복이 있는 2요인 실험의 오차 자유도에는 모든 처리조합의 수 ab가 포함돼.

### 문제 2 정답

먼저 자유도와 평균제곱을 계산해.

**dfA = 1, dfB = 2, dfAB = 2, dfE = 2×3×3 = 18**

**MSA = 30÷1 = 30**  
**MSB = 24÷2 = 12**  
**MSAB = 12÷2 = 6**  
**MSE = 72÷18 = 4**

따라서 다음과 같아.

**Fₐ = 30÷4 = 7.5**  
**Fᵦ = 12÷4 = 3**  
**Fₐᵦ = 6÷4 = 1.5**

### 문제 3 정답

처리 수 a = 4, 블록 수 b = 5야.

**처리 자유도 = a−1 = 3**  
**블록 자유도 = b−1 = 4**  
**오차 자유도 = (a−1)(b−1) = 3×4 = 12**  
**합계 자유도 = ab−1 = 20−1 = 19**

검산하면 3+4+12 = 19로 일치해.

### 문제 4 정답

**처리조합 수 = abc = 3×2×4 = 24**

**총 관측 수 = abcr = 3×2×4×3 = 72**

처리조합 수에는 반복을 곱하지 않고, 총 관측 수에는 반복 수를 곱해.

### 문제 5 정답

주효과는 **A, B, C**야.

2인자 교호작용은 **AB, AC, BC**야.

3인자 교호작용은 **ABC**야.

따라서 전체 효과는 A, B, C, AB, AC, BC, ABC의 일곱 개야.

### 문제 6 정답

1. **X** — 블록끼리 같아야 하는 것이 아니라 각 블록 내부의 실험단위가 유사해야 해.
2. **O** — 반복자료로 순수오차를 추정하므로 교호작용을 별도로 검정할 수 있어.
3. **X** — 2⁵ = 32개야.
4. **X** — 유의한 교호작용을 먼저 해석하고 관련 요인의 조건부 효과를 확인해야 해.
5. **O** — 각 블록 안에서 모든 처리를 무작위로 배치하는 것이 기본이야.

## 8. 요약
