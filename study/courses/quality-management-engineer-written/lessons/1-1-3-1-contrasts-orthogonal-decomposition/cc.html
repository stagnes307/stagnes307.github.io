🔑 핵심 키워드

대비 대비계수 대비제곱합 직교대비 자유도 직교분해
대비는 묻고 싶은 차이를 수식으로 표현하고, 직교분해는 서로 중복되지 않는 질문들로 처리변동을 나눠.

🧭 대비의 정의와 출발점

대비가 표현하는 것

처리수준이 A₁, A₂, …, Aₐ이고 모평균이 μ₁, μ₂, …, μₐ라고 하자. 평균들의 선형결합 L = c₁μ₁ + c₂μ₂ + … + cₐμₐ에서 대비계수의 합이 0이면 L을 대비라고 해. 실제 표본에서는 모평균 대신 처리평균을 사용해 L̂ = c₁ȳ₁ + c₂ȳ₂ + … + cₐȳₐ로 추정하지. 대비는 평균의 절대적인 높이가 아니라 처리 사이의 상대적인 차이를 측정하는 도구야.

대비 성립 조건: Σcᵢ = 0

L = μ₁ − μ₂는 계수가 1과 −1이고 합이 0이므로 대비야. 반면 L = μ₁ + μ₂는 계수합이 2이므로 두 평균의 합일 뿐 대비가 아니야. 계수합이 0이면 모든 처리평균에 같은 상수를 더해도 대비값이 변하지 않아. 이 불변성이 처리 사이의 순수한 차이만 남겨주는 원리야.

여러 처리군을 비교하는 방법

A₁과 A₂의 평균을 A₃과 A₄의 평균과 비교하려면 L = (μ₁+μ₂)/2 − (μ₃+μ₄)/2로 나타낼 수 있어. 분모를 없앤 L = μ₁+μ₂−μ₃−μ₄도 같은 비교 방향을 표현해. 따라서 계수 (1, 1, −1, −1)과 (2, 2, −2, −2)는 크기만 다를 뿐 동일한 비교를 뜻해.

계산의 기본 절차

  1. 비교하려는 처리 또는 처리군을 확인해.
  2. 각 처리에 대비계수를 부여해.
  3. Σcᵢ = 0인지 검사해.
  4. 처리평균에 계수를 곱해 L̂ = Σcᵢȳᵢ를 계산해.
  5. 처리별 반복수가 같은지 확인해 적절한 대비제곱합 공식을 선택해.
  6. 필요하면 오차평균제곱을 이용해 F검정을 수행해.

공식보다 먼저 계수합과 반복수 구조를 확인하는 습관이 중요해. 이 두 조건을 놓치면 뒤 계산을 정확히 해도 정답이 되지 않아.

📐 대비제곱합의 원리와 계산

반복수가 모두 같은 경우

처리마다 반복수가 n으로 동일하고 처리평균을 사용하면 특정 대비가 설명하는 변동량인 대비제곱합은 다음과 같아. 하나의 독립적인 대비는 자유도 1을 가져.

SSL = L̂² ÷ Σ(cᵢ²/n) = nL̂² ÷ Σcᵢ²

처리합 Tᵢ를 사용한다면 ȳᵢ = Tᵢ/n이므로 SSL = (ΣcᵢTᵢ)² ÷ (nΣcᵢ²)로 계산할 수 있어. 평균 공식과 처리합 공식은 입력 자료의 형태만 다를 뿐 같은 원리에서 나온 식이야.

반복수가 서로 다른 경우

처리 Aᵢ의 반복수를 nᵢ라고 하면 일반식은 SSL = L̂² ÷ Σ(cᵢ²/nᵢ)야. 반복수가 다르면 하나의 공통 n을 분모 밖으로 꺼낼 수 없어. 따라서 동일 반복 공식인 nL̂²/Σcᵢ²를 기계적으로 적용하면 안 돼.

불균등 반복: SSL = L̂² ÷ Σ(cᵢ²/nᵢ)

계수의 배율이 제곱합을 바꾸지 않는 이유

모든 대비계수를 두 배로 만들면 대비값도 두 배가 되어 분자 L̂²은 네 배가 돼. 동시에 분모의 Σcᵢ²도 네 배가 되므로 비율은 변하지 않아. 그래서 대비제곱합은 계수 표현의 배율과 무관하고, 같은 비교가 설명하는 변동량을 일관되게 측정해.

계수의 배율이 바뀌어도 같은 비교의 대비제곱합은 변하지 않아.

🧮 대비제곱합 계산 예시

네 처리 A₁, A₂, A₃, A₄를 각각 3회 반복했고 처리평균이 다음과 같다고 하자.

네 처리의 처리평균
처리 A₁ A₂ A₃ A₄
처리평균 10 12 18 20

앞의 두 처리와 뒤의 두 처리 비교

대비를 L₁ = μ₁+μ₂−μ₃−μ₄로 설정하면 계수는 (1, 1, −1, −1)이고 합은 0이야. 표본 대비값은 L̂₁ = 10+12−18−20 = −16이야. 음수는 앞의 두 처리 평균이 뒤의 두 처리 평균보다 작다는 비교 방향을 나타내.

Σcᵢ² = 4, n = 3
SSL₁ = 3×(−16)²/4 = 192

대비값의 부호는 어느 처리군이 더 큰지 보여주지만, 제곱합에서는 값이 제곱되므로 변동량 자체에는 부호가 영향을 주지 않아.

⚖️ 직교대비의 판정

동일 반복에서의 직교 조건

두 대비 L₁ = Σcᵢμᵢ와 L₂ = Σdᵢμᵢ가 있고 처리별 반복수가 같다면, Σcᵢdᵢ = 0일 때 두 대비가 직교한다고 해. 대응하는 계수끼리 곱해 더한 내적이 0이면 두 비교가 설명하는 정보가 서로 겹치지 않는다는 뜻이야.

동일 반복의 직교 조건: Σcᵢdᵢ = 0

불균등 반복에서의 직교 조건

처리별 반복수가 다르면 단순 내적이 아니라 반복수로 가중한 조건을 사용해. 이때 직교 조건은 Σ(cᵢdᵢ/nᵢ) = 0이야. 불균등 반복 문제에서 Σcᵢdᵢ만 계산하면 잘못된 판정이 나올 수 있어.

불균등 반복의 직교 조건: Σ(cᵢdᵢ/nᵢ) = 0

직교와 비직교의 비교

L₁ = (1, 1, −1, −1)과 L₂ = (1, −1, 0, 0)의 내적은 1−1+0+0 = 0이므로 직교해. L₁은 앞의 두 처리군과 뒤의 두 처리군을 비교하고, L₂는 앞 처리군 내부에서 A₁과 A₂를 비교하지. 반면 L₃ = (1, 0, −1, 0)과 L₁의 내적은 2이므로 직교하지 않아. 두 비교가 A₁과 A₃의 차이에 관한 정보를 일부 공유하기 때문이야.

🧩 처리제곱합의 직교분해

자유도와 최대 대비 개수

처리수가 a개이면 처리 자유도는 a−1이야. 따라서 서로 독립인 대비도 최대 a−1개까지 만들 수 있어. 이 a−1개 대비가 서로 직교하면 처리제곱합을 겹치지 않는 성분으로 완전히 나눌 수 있어.

SSTreatment = SSL₁ + SSL₂ + … + SSLₐ₋₁

이것이 처리제곱합의 직교분해야. 각 대비는 자유도 1을 가지며 전체 자유도의 합은 a−1이 돼. 대비들이 직교하지 않으면 동일한 정보가 여러 대비제곱합에 중복될 수 있으므로 단순 합산할 수 없어.

완전한 직교대비계

네 처리에 대한 완전한 직교대비계
대비 A₁ A₂ A₃ A₄ 비교 의미
L₁ 11−1−1 앞의 두 처리와 뒤의 두 처리 비교
L₂ 1−100 A₁과 A₂ 비교
L₃ 001−1 A₃과 A₄ 비교

세 대비의 계수합은 모두 0이야. 또한 L₁·L₂ = 0, L₁·L₃ = 0, L₂·L₃ = 0이므로 서로 직교해. 처리수가 4개라 처리 자유도는 3이고, 독립적인 직교대비도 3개이므로 완전한 직교분해가 가능해.

세 대비의 제곱합 계산

L̂₁ = 10+12−18−20 = −16, SSL₁ = 3×256/4 = 192
L̂₂ = 10−12 = −2, SSL₂ = 3×4/2 = 6
L̂₃ = 18−20 = −2, SSL₃ = 3×4/2 = 6

직교대비 제곱합의 합은 192+6+6 = 204야. 전체평균은 15이므로 처리제곱합을 직접 계산하면 3[(10−15)²+(12−15)²+(18−15)²+(20−15)²] = 204가 돼. 따라서 SSTreatment = SSL₁+SSL₂+SSL₃가 정확히 성립해.

이 분해는 처리 간 변동 204 중 192가 앞쪽 두 처리와 뒤쪽 두 처리의 차이에서 발생하고, 각 처리군 내부의 차이는 6씩 기여했다는 구체적인 해석도 제공해.

🔍 분산분석과 대비검정

전체 처리효과와 특정 비교의 차이

일반적인 처리 F검정은 처리평균 전체가 동일한지 판단하지만, 유의한 차이가 어느 처리 또는 처리군 사이에서 발생했는지는 직접 알려주지 않아. 대비는 이 질문을 구체화해. 하나의 대비는 자유도 1이므로 MSL = SSL이고, 오차평균제곱을 MSE라고 하면 검정통계량은 다음과 같아.

F₀ = MSL/MSE = SSL/MSE

앞의 L₁에서 SSL₁ = 192이고 MSE = 4라면 F₀ = 48이야. 이를 자유도 (1, dfE)의 임계값과 비교해 L₁이 표현하는 처리군 차이가 유의한지 판단해. 대비제곱합은 특정 차이의 크기이고 오차평균제곱은 우연한 산포의 기준이라고 이해하면 돼.

사전대비와 사후비교의 경계

실험 전에 공정 지식이나 연구목적에 따라 정한 비교는 사전대비야. 반대로 데이터를 본 후 차이가 커 보이는 처리들을 임의로 골라 반복 검정하면 사후비교에 가까워지고 다중비교 문제가 생겨. 따라서 대비를 수학적으로 계산할 수 있다는 사실과 아무 제한 없이 검정해도 된다는 주장은 구별해야 해.

⚠️ 품질경영기사 시험 함정

조건과 공식을 혼동하는 함정

  • 대비 성립 조건은 Σcᵢ = 0이야. Σcᵢ² = 0이 아니야.
  • 두 식이 각각 대비라고 해서 서로 직교하는 것은 아니야. 상호 내적을 별도로 계산해야 해.
  • 불균등 반복에서는 SSL = L̂²/Σ(cᵢ²/nᵢ)를 사용하고 직교성도 Σ(cᵢdᵢ/nᵢ)로 판단해.
  • 모든 대비계수에 같은 수를 곱해도 대비제곱합은 변하지 않아.
  • 대비값의 부호는 비교 방향을 나타내지만 제곱합과 F값은 부호의 영향을 받지 않아.
  • 비직교 대비의 제곱합은 중복 정보를 포함할 수 있으므로 처리제곱합처럼 단순 합산하면 안 돼.
  • 처리수가 a개일 때 독립적인 대비의 최대 개수는 a−1개야.

계산형 문제 풀이 틀

  1. Σcᵢ = 0인지 확인해.
  2. L̂ = Σcᵢȳᵢ를 계산해.
  3. 동일 반복인지 불균등 반복인지 확인해.
  4. 상황에 맞는 대비제곱합 공식을 적용해.
  5. 동일 반복이면 Σcᵢdᵢ, 불균등 반복이면 Σ(cᵢdᵢ/nᵢ)로 직교성을 확인해.
  6. 각 대비의 자유도는 1이며, 완전분해라면 자유도 합이 a−1인지 확인해.
  7. 완전한 직교대비계에서는 ΣSSL = SSTreatment인지 검산해.

시험장에서는 대비 확인 → 대비값 → 반복수 → 제곱합 → 직교성 → 자유도 → 검산 순서를 지켜봐. 계산보다 조건 판독이 먼저야.

  1. (1, 1, 1, 1)

  3. (1, 1, −1, 0)

문제 2

처리평균이 (8, 10, 14, 16), 각 처리의 반복수가 2이고 대비계수가 (1, 1, −1, −1)일 때 대비값과 대비제곱합을 구해봐.

문제 3

동일 반복 실험에서 L₁ = (1, 1, −1, −1)과 L₂ = (1, −1, 1, −1)이 직교하는지 판정해봐.

문제 4

처리가 5개인 일원배치 실험에서 처리제곱합을 완전히 직교분해하려면 서로 독립인 직교대비가 몇 개 필요할까?

문제 5

처리별 반복수가 서로 다른 실험에서 두 대비의 직교 여부를 확인하는 조건을 적어봐.

✅ 정답 및 해설

문제 1 정답: 2번

계수합은 1번이 4, 2번이 0, 3번이 1, 4번이 −1이야. 따라서 (2, −1, −1, 0)만 대비가 돼.

문제 2 정답: 대비값 −12, 대비제곱합 72

L̂ = 8+10−14−16 = −12야. Σcᵢ² = 4이고 n = 2이므로 SSL = 2×(−12)²/4 = 72가 돼.

문제 3 정답: 직교한다

계수의 내적은 1−1−1+1 = 0이므로 두 대비는 직교해.

문제 4 정답: 4개

처리수가 a = 5이므로 처리 자유도는 a−1 = 4야. 완전한 직교분해에는 독립적인 직교대비 4개가 필요해.

문제 5 정답

반복수가 nᵢ로 서로 다를 때는 Σ(cᵢdᵢ/nᵢ) = 0인지 확인해야 해. 단순한 Σcᵢdᵢ = 0은 동일 반복일 때 사용하는 조건이야.

✨ 요약

  • 대비: 처리평균의 선형결합이며 Σcᵢ = 0을 만족해.
  • 대비값: L̂ = Σcᵢȳᵢ로 계산해.
  • 동일 반복 대비제곱합: SSL = nL̂²/Σcᵢ²야.
  • 불균등 반복 대비제곱합: SSL = L̂²/Σ(cᵢ²/nᵢ)야.
  • 동일 반복 직교 조건: Σcᵢdᵢ = 0이야.
  • 불균등 반복 직교 조건: Σ(cᵢdᵢ/nᵢ) = 0이야.
  • 자유도: 각 대비는 자유도 1이고, 처리수가 a개이면 독립적인 대비는 최대 a−1개야.
  • 직교분해: a−1개의 독립적인 직교대비가 있으면 처리제곱합은 각 대비제곱합의 합으로 완전히 분해돼.
  • 검정: 대비에 대한 F값은 F₀ = SSL/MSE로 구해.
  • 검산: 대비 조건, 직교 조건, 반복수, 자유도와 제곱합 합계를 차례로 확인해.
