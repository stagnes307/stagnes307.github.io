대비로 나누고 직교로 검증하기

대비와 직교분해

분산분석이 “처리 사이에 차이가 있다”고 알려 준다면, 대비는 “어느 평균 묶음이 어떻게 다른가”를 묻는 정밀한 질문이야. 직교분해는 그 질문들이 같은 변동을 중복해서 세지 않도록 처리제곱합을 서로 독립적인 비교 방향으로 나누는 방법이야.

처리 간 전체 변동처리제곱합 SSA
→
목적 있는 평균 비교계수합이 0인 대비
→
중복 없는 분해서로 직교하는 a−1개 방향
개념 조항 01

대비는 평균에 던지는 한 가지 질문이다

처리가 \(a\)개이고 모평균이 μ₁, μ₂, …, μₐ일 때, 평균들의 선형결합 L = c₁μ₁ + c₂μ₂ + … + cₐμₐ에서 계수합이 0이면 이를 대비라고 해.

대비 성립 조건: Σcᵢ = 0
왜 합이 0일까?모든 처리에 공통으로 들어 있는 전체 평균 수준을 상쇄하고 처리 사이의 상대적인 차이만 남기기 위해서야.
계수는 무엇을 뜻할까?부호는 비교할 편을, 절댓값은 비교에 부여하는 상대적 무게를 나타내. 양의 계수 묶음과 음의 계수 묶음이 서로 맞서게 돼.
성립하는 예계수 (−1, −1, 1, 1)은 합이 0이므로 앞의 두 처리와 뒤의 두 처리를 비교하는 대비야.
성립하지 않는 예계수 (1, 1, −1, 0)은 합이 1이므로 대비가 아니야. 처리 차이와 공통 평균 수준이 섞여 있어.

계수 전체에 같은 0이 아닌 상수를 곱해도 비교의 의미는 같아. (−½, −½, ½, ½)과 (−1, −1, 1, 1)은 동일한 질문을 표현해.

구조 조항 02

직교는 비교 방향의 중복을 없앤다

동일한 반복수를 가진 균형자료에서 두 대비의 계수벡터를 c와 d라고 하면, 두 벡터의 내적이 0일 때 서로 직교한다고 해.

직교 조건: Σcᵢdᵢ = 0

직교대비는 한 대비가 설명한 처리 변동을 다른 대비가 다시 세지 않는다는 뜻이야. 처리가 \(a\)개이면 처리자유도는 \(a−1\)이므로 서로 독립인 대비도 최대 \(a−1\)개까지 구성할 수 있어.

계산 조항 03

대비제곱합은 비교가 설명한 변동량이다

표본 처리평균을 ȳᵢ라고 하면 대비의 추정값은 L̂ = Σcᵢȳᵢ야. 모든 처리의 반복수가 동일하게 \(n\)인 경우 대비제곱합은 다음과 같이 계산해.

SSL = nL̂² ÷ Σcᵢ²,   dfL = 1
분자의 n처리평균으로 계산하므로 각 평균을 만든 반복수 \(n\)을 반영해야 해.
분모의 Σcᵢ²계수의 합이 아니라 각 계수를 제곱한 뒤 더한 값이야.
자유도 1하나의 대비는 평균 공간에서 하나의 비교 방향만 나타내므로 자유도는 항상 1이야.
가설검정오차평균제곱이 MSE라면 F₀ = SSL/MSE이며, 같은 양측 가설에서는 F₀ = t₀²이야.

반복수가 처리마다 \(n_i\)로 다르면 균형자료 공식을 쓰면 안 돼. 이때는 SSL = L̂² ÷ Σ(cᵢ²/nᵢ)를 사용하고, 두 대비의 직교 조건도 Σ(cᵢdᵢ/nᵢ)=0으로 가중해서 확인해야 해.

절차 조항 04

계산은 다섯 번의 판정으로 진행한다

공식을 바로 대입하기보다 조건부터 확인하면 대비와 직교분해 문제를 안정적으로 풀 수 있어. 다음 순서를 하나의 검토 장부처럼 사용해 봐.

사례 조항 05

네 처리의 변동을 세 질문으로 해체하기

처리 A₁, A₂, A₃, A₄의 평균이 각각 10, 12, 16, 18이고 각 처리의 반복수가 3회라고 하자.

A₁10
A₂12
A₃16
A₄18

세 대비를 다음처럼 설정해.

C₁ = (−1, −1, 1, 1)
앞의 두 처리와 뒤의 두 처리를 비교

C₂ = (−1, 1, 0, 0)
앞의 두 처리 내부를 비교

C₃ = (0, 0, −1, 1)
뒤의 두 처리 내부를 비교

C₁: L̂₁ = −10−12+16+18 = 12
SSL1 = 3×12²÷4 = 108

C₂: L̂₂ = −10+12 = 2
SSL2 = 3×2²÷2 = 6

C₃: L̂₃ = −16+18 = 2
SSL3 = 3×2²÷2 = 6

직교분해 합계: 108 + 6 + 6 = 120

직교성 확인

C₁·C₂ = 1−1 = 0, C₁·C₃ = −1+1 = 0, C₂·C₃ = 0이므로 세 대비는 모두 서로 직교해.

처리제곱합으로 검산

전체평균은 14이고, SSA = 3{(10−14)²+(12−14)²+(16−14)²+(18−14)²} = 120이야. 따라서 SSA = SSL1 + SSL2 + SSL3가 정확히 성립해.

경계 조항 06

대비·직교대비·사후비교를 구분하기

대비는 연구 목적에 따라 미리 구성한 특정 평균 비교야. 직교대비는 그중에서도 설명하는 변동이 서로 겹치지 않는 대비 집합이고, 사후 다중비교는 분산분석 뒤 어떤 평균쌍이 다른지 폭넓게 탐색하는 절차야.

세 비교 방법의 판정 기준
구분 핵심 목적 필수 조건 제곱합 해석
대비 특정 평균 조합 비교 Σcᵢ = 0 처리변동의 한 부분
직교대비 중복 없는 비교 방향 구성 각 대비 성립과 쌍별 내적 0 완전한 집합이면 SSA 분해
사후 다중비교 유의한 평균 차이 탐색 방법별 오류율 조정 일반적으로 직교분해 목적이 아님

모든 두 평균의 차이는 대비로 표현할 수 있지만, 모든 대비가 서로 직교하는 것은 아니야. 직교하지 않는 대비제곱합을 단순히 더하면 같은 변동을 중복 계산할 수 있어.

주의 조항 07

시험에서 틀리기 쉬운 다섯 함정

계수합과 계수제곱합 혼동대비 성립은 Σcᵢ=0으로 확인하고, Σcᵢ²은 대비제곱합의 분모에 사용해.
반복수 n 누락처리평균으로 계산하는 균형자료 공식에는 분자의 반복수 \(n\)이 반드시 들어가.
직교 판정 생략대비가 \(a−1\)개 있다는 사실만으로 완전분해가 되지 않아. 모든 대비 쌍의 내적이 0이어야 해.
계수 배율 오해계수를 모두 \(k\)배 하면 L̂²과 Σcᵢ²이 함께 \(k²\)배가 되므로 SSL은 변하지 않아.
불균형자료에 단순 공식 적용반복수가 다르면 SSL = L̂²/Σ(cᵢ²/nᵢ)와 가중 직교 조건을 사용해야 해.
자유도 중복 계산대비 하나의 자유도는 항상 1이야. 완전분해에서는 대비 자유도의 합이 처리자유도 \(a−1\)과 일치해야 해.
자가 점검

확인 문제

  1. 계수 (2, −1, −1, 0)으로 만든 선형결합은 대비인지 판정해 봐.
  2. C₁=(1, 1, −1, −1), C₂=(1, −1, 0, 0)가 동일 반복수 조건에서 직교하는지 계산해 봐.
  3. 처리평균이 8, 10, 14, 16이고 반복수가 각각 2회일 때, 계수 (−1, −1, 1, 1)의 대비값과 대비제곱합을 구해 봐.
  4. 처리가 5개인 일원배치에서 처리제곱합을 완전히 직교분해하려면 몇 개의 서로 직교하는 대비가 필요한지 설명해 봐.
판정 기록

정답 및 해설

1번: 대비다. 계수합이 2−1−1+0=0이므로 대비의 성립 조건을 만족해.
2번: 직교한다. 두 식은 각각 계수합이 0이고, 내적은 (1)(1)+(1)(−1)+(−1)(0)+(−1)(0)=0이야.
3번: L̂=12, SSL=72다. L̂=−8−10+14+16=12이고, SSL=2×12²÷4=72야.
4번: 네 개다. 처리자유도가 5−1=4이고 대비마다 자유도가 1이므로, 완전분해에는 서로 직교하는 대비 4개가 필요해.
회상 장부

요약

대비 성립처리평균의 선형결합에서 계수합은 반드시 0이야.
대비제곱합균형자료에서는 SSL=nL̂²/Σcᵢ²이고 자유도는 1이야.
직교 판정동일 반복수에서는 두 계수벡터의 내적 Σcᵢdᵢ가 0인지 확인해.
완전분해처리 \(a\)개에서 \(a−1\)개의 서로 직교하는 대비가 SSA를 중복 없이 나눠.
① 계수합→ ② 대비값→ ③ 제곱합→ ④ 직교 내적→ ⑤ 합계 검산

“합이 0이면 대비, 내적이 0이면 직교, 제곱합이 맞으면 분해 완료.”
