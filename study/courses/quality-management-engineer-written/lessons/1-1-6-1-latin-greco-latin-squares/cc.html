두 방향의 방해요인을 걷어내고 처리 효과를 선명하게 읽는 실험설계

과목: 품질경영기사 필기 · 단원: 1-1. 실험계획 분석 및 최적해 설계 · 학습 그룹: 1-1-6. 라틴방격법

🔑 핵심 키워드

라틴방격법 및 그레코 라틴 방격법 행 효과 열 효과 처리 효과 직교성 분산분석 오차자유도

🧭 라틴방격법이 필요한 이유

여러 처리의 효과를 비교할 때 실험 장소에 두 종류의 방해요인이 존재하면 처리 차이에 불필요한 변동이 섞여. 예를 들어 위아래 방향의 온도 차이와 좌우 방향의 습도 차이가 동시에 존재할 수 있지. 라틴방격법은 두 방해요인을 각각 행과 열로 배치하여 그 영향을 분리하고, 우리가 정말 알고 싶은 처리 효과를 더 정확하게 검정하는 방법이야.

라틴방격법의 기본 구성
구성 요소역할수준 수
처리비교하려는 주효과p
행첫 번째 방해요인p
열두 번째 방해요인p
관측전체 실험 횟수p²

핵심 조건: 처리 수, 행 수준 수, 열 수준 수는 모두 p로 같아야 해.

행 × 열의 격자 안에서 모든 처리가 균형 있게 한 번씩 배치돼.

🧩 배열 원리와 성립 조건

p × p 정사각형에서 p개의 처리가 각 행에 정확히 한 번, 각 열에도 정확히 한 번 나타나도록 배치한 배열이 라틴방격이야. 문자 하나만 확인하지 말고 모든 처리에 대해 행 조건과 열 조건을 함께 검사해야 해.

4 × 4 라틴방격의 예
행＼열1열2열3열4열
1행ABCD
2행BCDA
3행CDAB
4행DABC
  1. 처리, 행, 열은 각각 p개의 수준을 가져야 해.
  2. 각 처리는 모든 행과 모든 열에서 한 번씩 나타나야 해.
  3. 각 관측은 서로 독립이고 오차분산은 일정하다고 가정해.
  4. 오차는 평균 0의 정규분포를 따른다고 가정해.
  5. 행·열·처리 사이의 교호작용은 없거나 무시할 수 있어야 해.

경계: 기본 라틴방격은 한 칸에 하나의 관측을 두므로 주요 교호작용을 별도로 추정하기 어려워. 실제 교호작용이 크면 그 변동이 오차에 섞일 수 있어.

⚙️ 선형모형과 효과 분해

관측값은 전체 평균, 행 효과, 열 효과, 처리 효과, 우연오차의 합으로 분해해.

yᵢⱼ₍ₖ₎ = μ + ρᵢ + κⱼ + τₖ + εᵢⱼ₍ₖ₎

선형모형의 기호
기호의미
μ전체 평균
ρᵢi번째 행 효과
κⱼj번째 열 효과
τₖk번째 처리 효과
εᵢⱼ₍ₖ₎설명되지 않은 우연오차

식별 제약은 Σρᵢ = 0, Σκⱼ = 0, Στₖ = 0으로 둬. 행과 열은 제거하려는 변동이고, 실제 검정의 중심은 처리 효과 τₖ야.

📐 자유도 구조

총자유도 = p² − 1

행, 열, 처리는 각각 p개의 수준을 가지므로 각각의 자유도는 p − 1이야. 따라서 라틴방격법의 오차자유도는 다음처럼 얻어.

오차자유도 = (p²−1) − 3(p−1) = (p−1)(p−2)

라틴방격법의 자유도
변동요인자유도
행p−1
열p−1
처리p−1
오차(p−1)(p−2)
합계p²−1

p = 4라면 자유도는 15 = 3 + 3 + 3 + 6이야. 자유도의 합을 검산하면 계산 실수를 빠르게 찾을 수 있어.

🧮 제곱합과 F검정 절차

모든 관측값의 총합을 G, 총 관측 수를 N = p², 행합계를 Rᵢ, 열합계를 Cⱼ, 처리합계를 Tₖ라고 하자.

수정항 C = G²/N = G²/p²

총제곱합 SST = Σy² − C

행제곱합 SSR = ΣRᵢ²/p − C

열제곱합 SSC = ΣCⱼ²/p − C

처리제곱합 SSTr = ΣTₖ²/p − C

오차제곱합 SSE = SST − SSR − SSC − SSTr

라틴방격법의 분산분석표
변동요인제곱합자유도평균제곱F비
행SSRp−1SSR/(p−1)MSR/MSE
열SSCp−1SSC/(p−1)MSC/MSE
처리SSTrp−1SSTr/(p−1)MSTr/MSE
오차SSE(p−1)(p−2)SSE/[(p−1)(p−2)]해당 없음
합계SSTp²−1해당 없음해당 없음

귀무가설은 모든 처리 효과가 0이라는 것이고, 대립가설은 적어도 하나의 처리 효과가 0이 아니라는 것이야. 처리 검정통계량은 다음과 같아.

F₀ = MSTr/MSE

F₀가 임계값 Fα(p−1, (p−1)(p−2))보다 크면 귀무가설을 기각해. 처리 평균이 가장 크다는 사실만으로 유의하다고 결론 내리면 안 돼.

  1. 수정항: 134²/16 = 1122.25
  2. 총제곱합: 1208 − 1122.25 = 85.75
  3. 행제곱합: 24.75
  4. 열제곱합: 1.25
  5. 처리제곱합: 33.25
  6. 오차제곱합: 85.75 − 24.75 − 1.25 − 33.25 = 26.50

🔗 그레코 라틴 방격법과 직교성

그레코 라틴 방격법은 행과 열의 영향을 통제하면서 서로 다른 두 처리계열의 효과를 동시에 추정하는 계획이야. 첫 번째 처리계열을 A, B, C, D로, 두 번째 처리계열을 α, β, γ, δ로 표현할 수 있어.

4 × 4 그레코 라틴 방격의 예
행＼열1열2열3열4열
1행AαBβCγDδ
2행BγAδDαCβ
3행CδDγAβBα
4행DβCαBδAγ

두 문자 배열은 각각 라틴방격이어야 하고, 모든 라틴 문자와 그리스 문자의 순서쌍이 정확히 한 번씩 나타나야 해. 이 조건이 직교성이야. 각각의 배열만 검사하고 문자쌍을 확인하지 않으면 그레코 라틴 방격을 잘못 판정할 수 있어.

yᵢⱼ₍ₖₗ₎ = μ + ρᵢ + κⱼ + τₖ + γₗ + εᵢⱼ₍ₖₗ₎

그레코 라틴 방격의 오차자유도 = (p−1)(p−3)

라틴방격법과 그레코 라틴 방격법 비교
비교 항목라틴방격법그레코 라틴 방격법
처리계열1개2개
총 실험 횟수p²p²
오차자유도(p−1)(p−2)(p−1)(p−3)
추가 조건처리의 행·열 균형두 처리계열의 직교성
주요 약점교호작용 추정 곤란오차자유도가 더 작고 배열 조건이 엄격함

시험 경계: 서로 직교하는 라틴방격 한 쌍은 2차와 6차에서 존재하지 않아. “모든 차수에서 그레코 라틴 방격을 구성할 수 있다”는 문장은 틀려.

🛠️ 실험 및 분석 절차

  1. 처리와 방해요인 구분: 비교 대상과 제거할 변동 원인을 분리해.
  2. 수준 수 확인: 처리 수, 행 수준 수, 열 수준 수가 모두 p인지 확인해.
  3. 방격 선택: 각 처리가 모든 행과 열에 한 번씩 나타나는지 검사해.
  4. 직교성 확인: 그레코 라틴 방격이라면 모든 처리 순서쌍을 확인해.
  5. 랜덤화: 행 순서, 열 순서, 처리 문자 대응을 무작위화해 편향을 방지해.
  6. 합계 계산: 행합계, 열합계, 처리합계를 서로 구분해서 구해.
  7. 분산분석: 수정항과 제곱합, 자유도, 평균제곱, F비를 차례로 계산해.
  8. 유의성 판단: F비를 임계값과 비교한 뒤 처리 차이를 해석해.

🚨 시험 함정과 판별 기준

  • 블록 수: 라틴방격법의 방해요인은 행과 열, 총 두 개야.
  • 자유도 혼동: 라틴방격은 (p−1)(p−2), 그레코 라틴 방격은 (p−1)(p−3)이야.
  • 배열 오판: 각 처리의 행 조건뿐 아니라 열 조건도 확인해야 해.
  • 직교성 누락: 두 라틴방격이 존재하는 것과 두 방격이 서로 직교하는 것은 다른 조건이야.
  • 평균과 검정 혼동: 처리 평균이 크더라도 F검정 없이 유의하다고 단정할 수 없어.
  • 교호작용: 기본 설계로 모든 교호작용을 독립적으로 추정할 수 있다는 설명은 틀려.
  • 결측값: 결측 관측을 임의로 0으로 대체하면 안 되며 별도의 추정과 자유도 조정이 필요해.

문제 6. 4 × 4 라틴방격에서 총제곱합 90, 행제곱합 12, 열제곱합 8, 처리제곱합 40일 때 오차제곱합, 오차평균제곱, 처리 F비를 구해봐.

✅ 정답 및 해설

  1. 처리 수 5개, 실험 25회, 오차자유도 12: p² = 25이고 (p−1)(p−2) = 4 × 3 = 12야.
  2. 2번, 3: (4−1)(4−3) = 3이야.
  3. 2번: 각 처리는 각 행과 각 열에 정확히 한 번씩 나타나야 해.
  4. F₀ = MSTr/MSE: 처리평균제곱을 오차평균제곱으로 나눠.
  5. X: 모든 라틴 문자와 그리스 문자 순서쌍이 정확히 한 번씩 나타나는 직교성까지 확인해야 해.
  6. SSE = 30, MSE = 5, F₀ ≈ 2.667: SSE = 90−12−8−40 = 30이고 오차자유도는 6이므로 MSE = 30/6 = 5야. 처리평균제곱은 40/3이므로 F₀ = (40/3)/5 = 8/3이야.

✨ 요약

  • 정의: 라틴방격법은 두 방해요인을 행과 열로 통제하면서 하나의 처리 효과를 검정해.
  • 배열: p개의 처리는 각 행과 각 열에 정확히 한 번씩 나타나야 해.
  • 규모: 총 관측 수는 p², 총자유도는 p²−1이야.
  • 라틴방격 오차자유도: (p−1)(p−2)야.
  • 그레코 라틴 방격: 두 처리계열의 모든 순서쌍이 한 번씩 나타나는 직교성이 필요해.
  • 그레코 라틴 오차자유도: (p−1)(p−3)이야.
  • 검정: 처리 F비는 MSTr/MSE이며 단순한 처리 평균의 크기와 유의성은 구분해야 해.
