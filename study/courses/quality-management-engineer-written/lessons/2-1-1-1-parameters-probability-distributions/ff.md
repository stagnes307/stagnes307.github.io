## 1. 이번 레슨의 핵심 지도

이번 레슨은 **모수와 통계량**, **확률**, **확률분포**를 하나의 흐름으로 연결하는 과정이야.

품질관리에서는 모든 제품을 전부 조사하기 어려워. 그래서 모집단에서 표본을 뽑고, 표본으로부터 계산한 값을 이용해 모집단의 특성을 추론하지. 이때 모집단의 참값이 모수이고, 표본에서 계산한 값이 통계량이야. 표본마다 통계량이 달라지는 불확실성은 확률로 측정하며, 가능한 값과 그 확률의 전체 구조를 확률분포라고 해.

**모집단 → 표본추출 → 통계량 계산 → 확률분포 파악 → 모수 추론**

이 연결을 이해하면 다음 레슨인 검정과 추정도 훨씬 자연스럽게 배울 수 있어. 😊

## 2. 모수와 통계량

### 모집단과 표본

**모집단**은 조사하거나 관리하려는 대상 전체의 집합이야. 어느 공장에서 하루 동안 생산한 볼트 전체, 특정 공정에서 만들어지는 제품의 직경 전체가 모집단에 해당해.

**표본**은 모집단에서 실제로 관측하기 위해 선택한 일부야. 하루 생산품 10,000개 중 100개를 뽑아 직경을 측정했다면, 10,000개는 모집단이고 100개는 표본이야.

표본을 사용하는 이유는 전수검사가 비용과 시간이 많이 들거나, 수명시험처럼 검사 과정에서 제품이 파괴될 수 있기 때문이야.

### 모수

**모수(parameter)**는 모집단의 특성을 나타내는 고정된 수치야. 모집단이 정해지면 모수의 실제 값은 하나로 결정되지만, 전수조사를 하지 않는 한 정확한 값을 모를 수 있어.

대표적인 모수는 다음과 같아.

1. 모집단 평균: μ
2. 모집단 분산: σ²
3. 모집단 표준편차: σ
4. 모집단 비율: p

여기서 중요한 표현은 **고정되어 있지만 대개 알려지지 않은 값**이야.

### 통계량

**통계량(statistic)**은 표본의 관측값만으로 계산한 수치야. 어떤 표본이 선택되느냐에 따라 값이 달라지므로 표본추출 전에는 확률변수로 취급해.

대표적인 통계량은 다음과 같아.

1. 표본평균: X̄
2. 표본분산: S²
3. 표본표준편차: S
4. 표본비율: p̂

표본평균은 다음과 같이 계산해.

**X̄ = (X₁ + X₂ + ··· + Xₙ) / n**

예를 들어 제품 다섯 개의 직경이 10.1, 10.0, 9.9, 10.2, 9.8mm라면 표본평균은 10.0mm야. 이 값은 모집단 평균 μ를 추정하는 데 사용돼.

### 둘을 구별하는 기준

| 구분 | 모수 | 통계량 |
|---|---|---|
| 대상 | 모집단 | 표본 |
| 성격 | 고정된 값 | 표본에 따라 변하는 값 |
| 일반적 상태 | 알 수 없는 경우가 많음 | 관측자료로 계산 가능 |
| 평균 기호 | μ | X̄ |
| 분산 기호 | σ² | S² |
| 비율 기호 | p | p̂ |

**모수는 알고 싶은 목표이고, 통계량은 그 목표를 추정하기 위한 관측 도구**라고 기억하면 돼.

## 3. 확률의 기본 구조

### 표본공간과 사건

**확률실험**은 시행 전에 결과를 확정할 수 없지만 가능한 결과를 열거할 수 있는 실험이야.

동전을 한 번 던질 때 가능한 결과의 전체 집합은 다음과 같아.

**S = {앞면, 뒷면}**

이처럼 가능한 모든 결과의 집합을 **표본공간 S**라고 해. 표본공간의 일부 집합을 **사건 A**라고 하지.

주사위를 한 번 던질 때 짝수가 나오는 사건은 다음과 같아.

**A = {2, 4, 6}**

### 확률의 범위

모든 사건 A에 대해 확률은 다음 범위를 만족해.

**0 ≤ P(A) ≤ 1**

불가능한 사건의 확률은 0이고, 반드시 발생하는 사건의 확률은 1이야.

**P(∅) = 0, P(S) = 1**

### 여사건

사건 A가 발생하지 않는 사건을 A의 **여사건 Aᶜ**라고 해.

**P(Aᶜ) = 1 − P(A)**

불량률이 0.03이라면 양품일 확률은 1 − 0.03 = 0.97이야. 직접 계산하기 복잡한 사건은 여사건을 이용하면 간단해지는 경우가 많아.

### 덧셈법칙

두 사건 A와 B 가운데 적어도 하나가 발생할 확률은 다음과 같아.

**P(A ∪ B) = P(A) + P(B) − P(A ∩ B)**

교집합을 빼는 이유는 P(A)와 P(B)를 더할 때 두 사건이 동시에 발생하는 영역을 두 번 계산했기 때문이야.

A와 B가 동시에 발생할 수 없는 **배반사건**이면 P(A ∩ B) = 0이므로 다음과 같이 단순해져.

**P(A ∪ B) = P(A) + P(B)**

### 조건부확률과 곱셈법칙

사건 B가 발생했다는 조건에서 사건 A가 발생할 확률은 다음과 같아.

**P(A | B) = P(A ∩ B) / P(B)**

따라서 곱셈법칙은 다음과 같이 표현할 수 있어.

**P(A ∩ B) = P(B)P(A | B)**

예를 들어 야간 생산품일 확률이 0.4이고, 야간 생산품 중 불량일 확률이 0.05라면 야간에 생산되면서 불량일 확률은 0.4 × 0.05 = 0.02야.

### 독립과 배반의 차이

**독립사건**은 한 사건의 발생이 다른 사건의 확률에 영향을 주지 않는 사건이야.

**P(A | B) = P(A)**  
**P(A ∩ B) = P(A)P(B)**

반면 **배반사건**은 두 사건이 동시에 발생할 수 없는 사건이야.

**P(A ∩ B) = 0**

발생확률이 양수인 두 배반사건은 독립이 아니야. A가 발생했다는 사실을 알면 B가 발생할 가능성이 0으로 바뀌기 때문이지. 시험에서 정말 자주 혼동하는 경계야.

## 4. 확률변수와 확률분포

### 확률변수

**확률변수 X**는 확률실험의 각 결과에 실수를 대응시키는 함수야.

제품 세 개를 검사할 때 불량품의 개수를 X라고 정의하면 X가 가질 수 있는 값은 0, 1, 2, 3이야. 확률변수는 단순히 변하는 숫자가 아니라, 우연한 실험 결과를 수치로 번역하는 규칙이라는 점이 중요해.

### 이산확률변수와 연속확률변수

**이산확률변수**는 가능한 값을 하나씩 셀 수 있어. 불량품 수, 결점 수, 고장 횟수가 대표적이야.

**연속확률변수**는 일정 구간 안의 모든 실숫값을 가질 수 있어. 제품의 길이, 무게, 인장강도, 수명이 여기에 해당해.

| 구분 | 이산형 | 연속형 |
|---|---|---|
| 값의 형태 | 셀 수 있음 | 구간 내 연속적인 값 |
| 대표 함수 | 확률질량함수 | 확률밀도함수 |
| 한 점의 확률 | 양수가 될 수 있음 | 항상 0 |
| 확률 계산 | 값별 확률의 합 | 밀도곡선 아래의 면적 |
| 품질 사례 | 불량품 수 | 제품 직경 |

### 이산확률분포

이산확률변수의 각 값과 그 확률의 대응관계를 이산확률분포라고 해. 확률질량함수 f(x)는 다음 조건을 만족해야 해.

**f(x) ≥ 0**  
**Σf(x) = 1**

기댓값은 분포의 중심을 나타내.

**E(X) = Σx f(x)**

분산은 값들이 기댓값 주변에서 얼마나 퍼져 있는지를 나타내.

**Var(X) = E[(X − μ)²] = E(X²) − {E(X)}²**

표준편차는 분산의 양의 제곱근이야.

**σ = √Var(X)**

분산은 원래 단위의 제곱으로 표시되지만, 표준편차는 원래 측정값과 같은 단위를 사용해 해석하기 편리해.

### 연속확률분포

연속확률변수에서는 확률밀도함수 f(x)의 곡선 아래 면적으로 확률을 구해.

**P(a ≤ X ≤ b) = ∫ₐᵇ f(x)dx**

전체 면적은 1이고 밀도는 음수가 될 수 없어.

**f(x) ≥ 0**  
**∫₋∞∞ f(x)dx = 1**

연속형에서는 특정한 한 점이 차지하는 면적이 0이므로 다음이 성립해.

**P(X = a) = 0**

따라서 연속형 확률변수에서는 부등호에 등호를 포함하더라도 확률이 변하지 않아.

**P(a < X < b) = P(a ≤ X ≤ b)**

## 5. 품질관리에서 자주 쓰는 분포

### 이항분포

서로 독립인 n회의 시행에서 각 시행이 성공과 실패 두 결과만 가지며 성공확률 p가 일정할 때, 성공횟수 X는 이항분포를 따라.

**X ~ B(n, p)**

**P(X = x) = ₙCₓpˣ(1 − p)ⁿ⁻ˣ**

**E(X) = np**  
**Var(X) = np(1 − p)**

제품 10개를 독립적으로 검사하고 각 제품의 불량확률이 0.1이라면 불량품 수 X는 B(10, 0.1)을 따라. 불량품이 정확히 2개일 확률은 다음과 같아.

**P(X = 2) = ₁₀C₂(0.1)²(0.9)⁸**

이항분포는 **일정한 개수의 제품에서 불량품 수**를 다룰 때 적합해.

### 포아송분포

일정한 시간이나 면적, 길이 안에서 발생하는 사건의 횟수를 다룰 때 포아송분포를 사용해.

**X ~ Poisson(λ)**

**P(X = x) = e⁻λ λˣ / x!**

**E(X) = λ**  
**Var(X) = λ**

강판 1m²당 평균 결점 수가 2개라면, 1m²에서 발견되는 결점 수를 평균 λ = 2인 포아송분포로 모델링할 수 있어.

포아송분포는 **고정된 영역에서 발생하는 결점 수**를 다룬다는 점에서 이항분포와 구별돼.

### 정규분포

정규분포는 평균을 중심으로 좌우대칭인 종 모양의 연속확률분포야.

**X ~ N(μ, σ²)**

평균 μ는 분포의 위치를 결정하고, 표준편차 σ는 퍼짐의 크기를 결정해. 제품의 길이, 무게처럼 여러 작은 원인이 합쳐져 나타나는 품질특성은 정규분포로 근사되는 경우가 많아.

서로 다른 정규분포를 공통 기준으로 비교하려면 표준화해.

**Z = (X − μ) / σ**

표준화된 Z는 평균이 0이고 분산이 1인 표준정규분포를 따라.

예를 들어 제품 중량 X가 N(100, 4²)을 따를 때 108g의 표준화 값은 다음과 같아.

**Z = (108 − 100) / 4 = 2**

즉, 108g은 평균보다 표준편차 두 배만큼 큰 위치야.

## 6. 계산 문제 해결 절차

확률분포 문제는 다음 순서로 풀면 안정적이야.

1. **확률변수 정의하기**  
   무엇의 개수인지, 무엇의 측정값인지 먼저 문장으로 적어.

2. **이산형과 연속형 구분하기**  
   개수는 주로 이산형이고, 길이·무게·시간은 주로 연속형이야.

3. **분포 선택하기**  
   고정된 시행에서 불량품 수는 이항분포, 일정 영역의 결점 수는 포아송분포, 연속 측정값의 대칭적 변동은 정규분포를 우선 검토해.

4. **모수 확인하기**  
   이항분포는 n과 p, 포아송분포는 λ, 정규분포는 μ와 σ²를 확인해.

5. **사건을 수식으로 번역하기**  
   ‘정확히 2개’는 P(X = 2), ‘2개 이하’는 P(X ≤ 2), ‘2개 이상’은 P(X ≥ 2)야.

6. **공식 대입 후 범위 점검하기**  
   계산한 확률이 0과 1 사이인지 확인해. 기댓값과 분산을 서로 바꾸지 않았는지도 점검해야 해.

## 7. 시험에서 자주 나오는 함정

### 함정 1: 모수와 통계량의 기호를 뒤바꾸기

μ와 σ²는 모집단의 모수이고, X̄와 S²는 표본에서 계산한 통계량이야. 표본평균 X̄는 표본을 뽑기 전에는 확률변수지만 관측 후에는 하나의 계산값이 돼.

### 함정 2: 배반과 독립을 같은 뜻으로 보기

배반은 교집합이 없는 것이고, 독립은 한 사건이 다른 사건의 확률을 바꾸지 않는 것이야. 발생확률이 양수인 두 사건이 배반이면 서로 독립일 수 없어.

### 함정 3: 확률밀도와 확률을 혼동하기

연속확률분포에서 f(x)는 특정 점의 확률이 아니라 밀도의 높이야. 실제 확률은 구간 아래의 면적이며 P(X = x)는 0이야.

### 함정 4: 분산의 모수를 잘못 읽기

정규분포 N(μ, σ²)의 두 번째 값은 표준편차가 아니라 **분산**이야. X ~ N(100, 16)이면 σ² = 16이고 σ = 4야.

### 함정 5: ‘이하’와 ‘미만’을 잘못 처리하기

이산형에서는 P(X ≤ 2)와 P(X < 2)가 다르지만, 연속형에서는 한 점의 확률이 0이므로 P(X ≤ 2)와 P(X < 2)가 같아.

## 8. 확인 문제

### 문제 1

모집단에서 뽑은 표본 50개의 평균을 계산했다. 이 표본평균은 모수일까, 통계량일까?

### 문제 2

두 사건 A와 B에 대해 P(A) = 0.4, P(B) = 0.5, P(A ∩ B) = 0.2이다. P(A ∪ B)를 구해봐.

### 문제 3

불량확률이 0.05인 제품을 독립적으로 4개 검사한다. 불량품이 하나도 없을 확률을 식과 함께 구해봐.

### 문제 4

X ~ N(70, 25)일 때 X = 80에 대응하는 표준화 값 Z를 구해봐.

### 문제 5

연속확률변수 X에 대해 P(X = 10)의 값은 얼마일까?

### 문제 6

발생확률이 각각 양수인 두 사건 A와 B가 배반사건이다. 두 사건은 독립일까?

## 9. 정답과 해설

### 문제 1 정답

**통계량**이야. 표본평균 X̄는 표본자료로 계산하며 모집단 평균 μ를 추정하는 데 사용해.

### 문제 2 정답

**0.7**이야.

P(A ∪ B) = 0.4 + 0.5 − 0.2 = 0.7

교집합을 빼지 않으면 동시에 발생하는 영역을 중복 계산하게 돼.

### 문제 3 정답

**0.95⁴ = 0.81450625**야.

불량품이 하나도 없다는 것은 네 제품이 모두 양품이라는 뜻이야. 각 제품이 양품일 확률은 1 − 0.05 = 0.95이므로 독립성을 이용해 0.95를 네 번 곱해.

### 문제 4 정답

**Z = 2**야.

N(70, 25)에서 분산은 25이고 표준편차는 5야.

Z = (80 − 70) / 5 = 2

### 문제 5 정답

**0**이야. 연속확률변수의 확률은 구간의 면적으로 계산하므로 한 점만의 확률은 0이야.

### 문제 6 정답

**독립이 아니야.** 배반이므로 P(A ∩ B) = 0이지만, 두 사건의 확률이 각각 양수이므로 P(A)P(B) > 0이야. 따라서 독립 조건 P(A ∩ B) = P(A)P(B)를 만족하지 않아.

## 10. 회상 요약

1. **모수**는 모집단의 고정된 특성이고, **통계량**은 표본으로부터 계산되어 표본마다 달라질 수 있어.
2. 확률은 불확실성을 0과 1 사이의 수로 표현하며 여사건, 덧셈법칙, 조건부확률, 곱셈법칙이 기본 계산 도구야.
3. **배반**은 동시에 발생할 수 없다는 뜻이고, **독립**은 한 사건이 다른 사건의 확률에 영향을 주지 않는다는 뜻이야.
4. **확률분포**는 확률변수가 가질 수 있는 값과 확률의 전체 대응 구조야.
5. 이산형은 확률을 합하고 연속형은 밀도곡선 아래의 면적을 적분해.
6. 이항분포는 고정된 시행의 성공횟수, 포아송분포는 일정 영역의 사건 횟수, 정규분포는 연속적인 측정값의 변동을 다루는 데 적합해.
7. 계산 문제에서는 **확률변수 정의 → 자료 유형 판별 → 분포 선택 → 모수 확인 → 사건의 수식화 → 결과 검산** 순서로 접근하면 돼.
