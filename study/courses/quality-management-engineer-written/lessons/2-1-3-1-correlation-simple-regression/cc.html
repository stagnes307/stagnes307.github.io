산점도에서 회귀식까지 읽는 법

상관 및 단순회귀

두 품질특성이 함께 움직이는 모습을 산점도로 발견하고, 상관계수로 관계의 방향과 강도를 재고, 최소제곱 회귀식으로 평균 반응을 설명하는 흐름을 한 장의 통계 분석 보드처럼 연결해 보자.

관계의 지도

1. 상관과 회귀는 같은 자료에 다른 질문을 던져

상관분석의 질문

두 변수가 어느 방향으로 얼마나 강하게 함께 변하는가?를 묻는다. 대표 결과인 상관계수 r은 단위가 없으며 −1부터 1 사이에 놓여. X와 Y의 순서를 바꾸어도 값은 같아.

단순회귀분석의 질문

설명변수 X가 변할 때 반응변수 Y의 평균이 어떻게 달라지는가?를 묻는다. 결과는 Ŷ = b₀ + b₁X이고 X와 Y의 역할을 바꾸면 다른 회귀식이 만들어져.

① 산점도형태와 이상점 확인
② 상관계수방향과 강도 측정
③ 회귀식평균 반응 설명
④ 잔차모형의 빈틈 점검

공식부터 대입하지 말고 반드시 산점도를 먼저 봐야 해. 직선이 아닌 곡선 관계, 서로 다른 집단의 혼합, 관측 범위의 제한, 이상점 하나가 만든 가짜 상관은 숫자 하나만으로 드러나지 않거든.

첫 화면의 핵심 관계

2. 산점도에서 직선 관계를 판독하는 법

점들이 우상향 직선 주변에 모이면 양의 선형관계가 예상돼. 다만 점과 직선 사이의 세로 차이인 잔차가 무작위인지도 함께 살펴야 해.

판독 순서: 방향을 보고, 점들의 직선 밀착도를 보고, 이상점을 찾고, 마지막으로 곡률이나 부채꼴 퍼짐이 없는지 확인해. 상관계수는 이 가운데 직선 방향과 밀착도를 요약할 뿐이야.

표준화된 동행 정도

3. 공분산에서 상관계수로

공분산은 두 변수가 각자의 평균에서 같은 방향으로 벗어나는지 측정해. 두 편차의 부호가 자주 같으면 양수, 반대이면 음수가 돼.

Sxy = Σ[(xi − x̄)(yi − ȳ)] ÷ (n − 1)

공분산은 측정단위에 따라 크기가 달라져 자료 간 강도를 비교하기 어려워. 그래서 공분산을 두 변수의 표준편차로 나눈 피어슨 표본상관계수를 사용해.

r = Σ[(xi − x̄)(yi − ȳ)] ÷ √{Σ(xi − x̄)² Σ(yi − ȳ)²}

부호는 방향

r > 0이면 양의 관계, r < 0이면 음의 관계야. 음수는 약하다는 뜻이 아니라 반대 방향이라는 뜻이야.

절댓값은 강도

|r|이 1에 가까울수록 점들이 직선에 밀착해. r = 0은 선형관계가 없다는 뜻이지 모든 관계가 없다는 뜻은 아니야.

상관계수의 강함을 나누는 보편적인 절대 기준은 없어. 공정 특성, 표본크기, 측정오차와 분석 목적을 함께 판단해야 해.

최소제곱 엔진

4. 단순회귀식은 잔차제곱합을 가장 작게 만들어

모형은 Yi = β₀ + β₁Xi + εi, 표본으로 추정한 식은 Ŷ = b₀ + b₁X로 표현해. β는 알 수 없는 모집단 계수이고 b는 표본에서 계산한 추정값이야.

계산은 편차에서 시작해 교차곱, 기울기, 절편 순으로 이어져. 마지막에 예측값과 잔차를 구해 모형의 적합성을 확인해.

b₁ = Sxy ÷ Sxx　　b₀ = ȳ − b₁x̄　　잔차 ei = yi − ŷi

b₁은 X가 1단위 증가할 때 Y의 예측 평균이 변하는 양이야. b₀는 X = 0일 때의 예측값이지만, X = 0이 관측 범위 밖이거나 물리적으로 불가능하면 공학적 의미를 억지로 붙이면 안 돼. 회귀직선은 항상 표본평균점 (x̄, ȳ)을 지나.

설명된 변동과 남은 변동

5. 결정계수는 회귀식의 설명 비율이야

관측값의 전체 편차는 회귀식이 설명한 부분과 설명하지 못한 잔차로 분해돼. 제곱합으로 쓰면 SST = SSR + SSE가 성립해.

설명된 부분

SSR = Σ(ŷi − ȳ)²는 회귀직선이 평균만 사용할 때보다 추가로 설명한 Y의 변동이야.

설명되지 않은 부분

SSE = Σ(yi − ŷi)²는 관측값과 예측값 사이에 남은 오차 변동이야. 최소제곱법은 이 값을 최소화해.

R² = SSR ÷ SST = 1 − SSE ÷ SST

절편을 포함한 단순선형회귀에서는 R² = r²야. r = −0.8이면 R² = 0.64이므로 방향은 음이고 선형회귀가 Y 변동의 64%를 설명해. R²에는 방향 정보가 없으므로 반드시 r 또는 b₁의 부호를 함께 봐야 해.

한 번에 푸는 수치 예제

6. 공정 온도와 제품 강도로 계산 연결하기

공정 온도 X가 1, 2, 3, 4, 5이고 제품 강도 Y가 2, 3, 5, 4, 6이라고 하자. 평균은 x̄ = 3, ȳ = 4이며 편차 계산 결과는 Sxx = 10, Sxy = 9, Syy = 10이야.

상관계수

r = 9 ÷ √(10×10) = 0.9
강한 양의 선형관계가 관찰돼.

회귀식

b₁ = 9÷10 = 0.9
b₀ = 4−0.9×3 = 1.3
따라서 Ŷ = 1.3 + 0.9X야.

예측과 잔차

X = 4이면 Ŷ = 4.9야. 실제값이 4이므로 잔차는 4−4.9 = −0.9이고, 실제값이 예측보다 작아.

설명력

R² = 0.9² = 0.81이므로 표본 Y 변동의 81%가 X와의 선형회귀 관계로 설명돼.

모형의 사용 경계

7. 숫자가 좋아 보여도 잔차와 범위를 확인해

  • 선형성: 평균 반응이 직선 형태여야 해. 잔차도에 U자형 패턴이 나타나면 곡선 관계를 놓친 신호야.
  • 독립성: 오차가 서로 독립이어야 해. 시간 순서 자료에서 주기적 패턴이 나타나면 독립성을 의심해.
  • 등분산성: X 수준에 따른 오차분산이 일정해야 해. 부채꼴 잔차 패턴은 이분산 가능성을 뜻해.
  • 정규성: 회귀계수의 검정과 구간추정에서는 오차의 정규성을 확인해.
  • 내삽과 외삽: 관측 범위 안의 내삽보다 범위 밖 외삽이 훨씬 위험해. 공정 메커니즘이 다른 구간에서도 유지된다는 보장이 없기 때문이야.
상관은 인과가 아니야. 높은 r은 함께 움직였다는 증거이지 X가 Y를 발생시켰다는 증거가 아니야. 제3의 변수, 시간 추세, 표본 선택 또는 공통 원인이 관계를 만들 수 있어.

득점 방어선

8. 시험 함정은 부호·대칭성·인과에서 나와

r = 0이면 독립?

일반적으로 거짓이야. r = 0은 선형 상관이 없다는 뜻이야. Y = X² 같은 곡선 관계가 존재해도 r이 0에 가까울 수 있어.

−0.9는 0.7보다 약함?

거짓이야. 강도는 절댓값으로 비교하므로 |−0.9|가 더 커. 음수 부호는 반대 방향을 뜻해.

X와 Y를 바꾸어도 같음?

상관계수는 같지만 회귀식은 달라. 회귀는 설명변수와 반응변수의 역할을 구분하기 때문이야.

R²가 높으면 충분함?

아니야. 이상점 하나가 R²를 높이거나 잔차에 곡선·부채꼴 패턴이 남을 수 있어. 적합도와 모형 타당성은 별도로 점검해.

스스로 점검

9. 확인 문제

상관계수 r = −0.6일 때 관계의 방향과 결정계수 R²를 구해 봐.
x̄ = 10, ȳ = 25, Sxx = 20, Sxy = 30일 때 b₁, b₀와 회귀식을 구해 봐.
회귀식이 Ŷ = 5 + 2X이고 X = 3에서 실제 관측값이 9라면 예측값과 잔차는 얼마일까?
잔차의 퍼짐이 X가 증가할수록 넓어지는 부채꼴이라면 어떤 가정을 먼저 의심해야 할까?
“상관계수 r = 0이면 두 변수는 반드시 아무 관계가 없다”는 문장이 틀린 이유를 설명해 봐.

풀이 확인

10. 정답 및 해설

문제 1

음의 선형관계, R² = 0.36이야. 부호는 방향을, 제곱한 값은 설명 비율을 나타내.

문제 2

b₁ = 30÷20 = 1.5, b₀ = 25−1.5×10 = 10이므로 Ŷ = 10 + 1.5X야.

문제 3

예측값은 11, 잔차는 9−11 = −2야. 잔차는 실제값에서 예측값을 빼.

문제 4

등분산성을 의심해야 해. X 수준에 따라 오차분산이 달라지는 이분산 패턴이기 때문이야.

문제 5

r은 선형관계만 측정해. 곡선 관계나 집단별 관계가 존재해도 전체 r은 0에 가까울 수 있으므로 관계 자체의 부재를 단정할 수 없어.

시험 직전 회상

11. 요약

방향과 강도r의 부호는 방향, |r|은 선형관계의 강도를 나타내. 상관은 인과를 증명하지 않아.
식의 중심b₁ = Sxy/Sxx, b₀ = ȳ−b₁x̄이며 회귀직선은 반드시 (x̄, ȳ)을 지나.
설명과 검증단순회귀에서는 R² = r²야. 높은 설명력 뒤에도 잔차 패턴, 이상점과 외삽 위험을 확인해.
  • 산점도 → 상관계수 → 회귀식 → 잔차의 순서로 읽으면 공식과 해석이 끊어지지 않아.
  • 상관은 X와 Y를 대칭적으로 다루지만 회귀는 설명변수 X와 반응변수 Y를 구분해.
  • 결정계수는 설명 비율이며 방향은 알려 주지 않아. 방향은 r이나 b₁의 부호로 판단해.
  • 시험에서는 r = 0과 독립의 혼동, 음의 부호와 약한 관계의 혼동, 내삽과 외삽의 혼동을 특히 조심해.
