🧭 상관과 회귀의 출발점

상관분석과 단순회귀분석의 차이

상관분석은 두 변수 X와 Y가 어느 방향으로 얼마나 강하게 함께 움직이는지 측정하는 방법이야. 두 변수를 대등하게 취급하며 대표적인 결과는 표본상관계수 r이야. 반면 단순회귀분석은 설명변수 X를 이용해 반응변수 Y의 평균적인 변화를 식으로 나타내. 모집단 모형은 Yᵢ = β₀ + β₁Xᵢ + εᵢ이고, 표본에서 추정한 회귀식은 Ŷᵢ = b₀ + b₁Xᵢ야. 상관은 함께 움직이는 정도를 묻고 회귀는 X가 주어졌을 때 Y를 어떻게 설명하거나 예측할지를 묻는다는 차이가 핵심이야.

🔭 산점도와 관계의 형태

계산에 앞서 그림으로 진단하기

산점도는 각 관측값 (xᵢ, yᵢ)를 좌표평면에 표시한 그림이야. 점들이 오른쪽 위로 배열되면 양의 상관, 오른쪽 아래로 배열되면 음의 상관을 의심할 수 있어. 방향 없이 퍼져 있으면 선형상관이 약할 수 있지만, r = 0이라고 해서 모든 관계가 없는 것은 아니야. 예를 들어 Y = X²처럼 강한 곡선관계가 있어도 대칭적인 자료에서는 선형상관계수가 0에 가까울 수 있어. 또한 멀리 떨어진 이상점 하나가 상관계수와 회귀직선을 크게 바꿀 수 있으므로 수치만 보지 말고 산점도를 함께 확인해야 해.

🧮 편차제곱합과 편차곱합

모든 핵심 공식의 공통 재료

Sxx = Σ(xᵢ − x̄)²와 Syy = Σ(yᵢ − ȳ)²는 각 변수가 평균 주위에 얼마나 퍼져 있는지를 나타내. Sxy = Σ(xᵢ − x̄)(yᵢ − ȳ)는 두 변수의 편차가 같은 방향으로 움직이는지 반대 방향으로 움직이는지를 보여 줘. 계산에서는 Sxx = Σxᵢ² − (Σxᵢ)²/n, Syy = Σyᵢ² − (Σyᵢ)²/n, Sxy = Σxᵢyᵢ − (Σxᵢ)(Σyᵢ)/n이라는 단축식을 자주 사용해. Sxy가 양수이면 두 변수가 같은 방향으로 움직이는 경향이 있고, 음수이면 반대 방향으로 움직이는 경향이 있어.

📐 공분산과 상관계수

공분산의 방향성과 단위 의존성

표본공분산은 일반적으로 sxy = Sxy/(n − 1)로 계산해. 공분산의 부호는 관계의 방향을 보여 주지만 크기는 측정단위에 영향을 받아. 길이 단위를 m에서 cm로 바꾸면 공분산의 수도 달라지므로 서로 다른 자료의 관계 강도를 공분산만으로 비교하면 안 돼. 이 단위 문제를 제거하기 위해 공분산을 두 변수의 표준편차로 나눈 값이 상관계수야.

피어슨 표본상관계수

r = Sxy/√(SxxSyy)이며 항상 −1 ≤ r ≤ 1이야. r = 1은 완전한 양의 선형관계, r = −1은 완전한 음의 선형관계, r = 0은 표본에서 선형관계가 나타나지 않는다는 뜻이야. X와 Y를 교환하거나 각 변수에 상수를 더해도 r은 변하지 않고, 측정단위를 양의 상수배로 바꿔도 변하지 않아. 다만 한 변수에 음수를 곱하면 부호가 반대로 바뀌어. 높은 상관은 인과관계를 보장하지 않고, 이상점에도 민감하다는 경계를 반드시 기억해야 해.

⚙️ 단순선형회귀와 최소제곱법

회귀모형의 구조와 가정

단순선형회귀모형은 Yᵢ = β₀ + β₁Xᵢ + εᵢ로 표현해. β₀는 절편, β₁은 기울기, εᵢ는 직선으로 설명되지 않는 오차항이야. 전형적인 추론에서는 선형성, 오차의 평균 0, 독립성, 등분산성을 가정하며 소표본에서 정확한 t검정과 F검정을 수행할 때는 정규성도 중요해. X가 1단위 증가할 때 조건부 평균 E(Y|X)가 β₁만큼 변한다는 것이 기울기의 정확한 의미야.

최소제곱 추정량

잔차는 eᵢ = yᵢ − ŷᵢ이고 최소제곱법은 SSE = Σeᵢ²을 가장 작게 만드는 절편과 기울기를 선택해. 결과는 b₁ = Sxy/Sxx, b₀ = ȳ − b₁x̄이며 추정 회귀식은 Ŷ = b₀ + b₁X가 돼. 절편을 포함한 최소제곱 회귀직선은 반드시 평균점 (x̄, ȳ)를 지나고 잔차의 합은 0이야. 또한 Σ(xᵢ − x̄)eᵢ = 0이고 적합값의 평균은 ȳ와 같아.

상관계수와 기울기의 연결

회귀기울기와 상관계수는 b₁ = r(sy/sx)로 연결돼. 따라서 b₁과 r의 부호는 언제나 같지만 수치는 일반적으로 같지 않아. r은 무차원이고 −1과 1 사이지만 b₁은 측정단위에 따라 달라질 수 있어. 변수를 표준화하면 회귀식은 Ẑy = rZx가 되므로 상관계수를 표준화된 회귀기울기로 이해할 수 있어.

📊 변동 분해와 결정계수

설명된 변동과 남은 변동

Y의 전체 변동은 SST = Σ(yᵢ − ȳ)², 회귀식이 설명한 변동은 SSR = Σ(ŷᵢ − ȳ)², 설명하지 못한 잔차변동은 SSE = Σ(yᵢ − ŷᵢ)²이야. 절편을 포함한 최소제곱 회귀에서는 SST = SSR + SSE가 성립해. 결정계수는 R² = SSR/SST = 1 − SSE/SST이고, 단순선형회귀에서는 특별히 R² = r²이야. R² = 0.81이면 표본에서 관측된 Y의 총변동 중 81%가 적합된 선형관계로 설명된다는 뜻이지만 인과관계나 모형의 완전한 적합성을 보장하지는 않아.

🧪 회귀의 유의성 검정

분산분석과 기울기 검정

오차분산의 불편추정량은 MSE = SSE/(n − 2)이고 잔차표준오차는 s = √MSE야. 기울기 검정에서는 H₀: β₁ = 0, H₁: β₁ ≠ 0을 설정하고 t = b₁/SE(b₁), SE(b₁) = s/√Sxx를 사용해. 자유도는 n − 2야. 회귀분산분석에서는 MSR = SSR, F = MSR/MSE를 사용하며 단순회귀에서 기울기 하나를 검정할 때 F = t²이므로 두 검정은 같은 결론을 내려.

상관계수의 유의성 검정

모집단 상관계수에 대해 H₀: ρ = 0을 검정할 때는 t = r√(n − 2)/√(1 − r²)을 사용하며 자유도는 n − 2야. 단순선형회귀의 조건에서는 H₀: ρ = 0과 H₀: β₁ = 0에 관한 검정이 서로 연결돼.

🧷 구체적인 계산 예시

투입량과 인장강도 자료

어떤 공정에서 투입량 X와 인장강도 Y를 (1,2), (2,3), (3,5), (4,4), (5,6)으로 관측했다고 하자. 평균은 x̄ = 3, ȳ = 4이고 계산하면 Sxx = 10, Syy = 10, Sxy = 9가 돼. 따라서 r = 9/√(10×10) = 0.9로 강한 양의 선형관계가 나타나. 기울기는 b₁ = 9/10 = 0.9이고 절편은 b₀ = 4 − 0.9×3 = 1.3이므로 회귀식은 Ŷ = 1.3 + 0.9X야.

X = 4일 때 예측값은 Ŷ = 4.9야. 실제값이 4라면 잔차는 e = y − ŷ = 4 − 4.9 = −0.9이므로 실제값이 예측값보다 0.9 작아. 결정계수는 R² = 0.9² = 0.81이고 SST = 10이므로 SSR = 8.1, SSE = 1.9야. 즉 Y의 표본변동 중 81%가 적합된 선형회귀관계로 설명돼.

🎯 신뢰구간과 예측구간

평균반응과 개별 관측값의 구별

X = x₀에서 중심 예측값은 ŷ₀ = b₀ + b₁x₀로 같지만 구간의 의미는 달라. 평균반응 신뢰구간의 표준오차는 s√[1/n + (x₀ − x̄)²/Sxx]이고, 새로운 개별값 예측구간의 표준오차는 s√[1 + 1/n + (x₀ − x̄)²/Sxx]야. 개별값에는 새로운 오차가 추가되므로 개별값 예측구간이 더 넓어. 두 구간은 x₀가 x̄에서 멀어질수록 넓어지고, 관측된 X 범위를 벗어난 외삽은 선형관계가 계속된다는 보장이 없으므로 특히 위험해.

🔍 잔차분석과 모형 진단

잔차에서 읽는 가정 위반

잔차가 0 주위에 무작위로 흩어지면 선형성과 등분산성이 대체로 타당하다고 볼 수 있어. U자 패턴은 비선형관계, 부채꼴 패턴은 이분산성, 시간에 따른 연속적 변화는 독립성 위반을 의심하게 해. 회귀직선에서 Y 방향으로 멀리 떨어진 점은 이상점이고 X값이 다른 관측값에서 멀리 떨어진 점은 지렛점이야. 회귀계수를 크게 바꾸는 점은 영향점이므로 산점도와 잔차도를 함께 조사해야 해.

🚧 비교와 경계

해석할 수 있는 것과 없는 것

높은 상관은 두 변수가 공통 원인이나 시간추세의 영향을 함께 받은 결과일 수 있으므로 인과관계를 입증하지 않아. 반대로 낮은 상관도 곡선관계나 서로 다른 집단의 혼합을 숨길 수 있어. Y를 X에 회귀한 식과 X를 Y에 회귀한 식은 서로 다른 방향의 잔차를 최소화하므로 한 식을 단순히 대수적으로 뒤집으면 안 돼. 관측범위 안의 보간은 자료의 직접적인 지지를 받지만 범위 밖의 외삽은 훨씬 강한 가정을 요구해.

⚠️ 시험 함정

자주 뒤집어 출제되는 판단

  • r = 0: 선형상관이 없다는 뜻이지 일반적으로 독립을 뜻하지 않아.
  • 인과관계: 높은 상관이나 유의한 회귀만으로 원인과 결과를 확정할 수 없어.
  • 결정계수: 단순회귀에서는 R² = r²이지 R² = r이 아니야.
  • 기울기: b₁ = r(sy/sx)이므로 r과 부호는 같지만 값은 일반적으로 달라.
  • 평균점: 절편을 포함한 최소제곱 회귀직선은 원점이 아니라 (x̄, ȳ)를 지나.
  • 잔차: e = y − ŷ 순서이며 반대로 계산하면 부호가 바뀌어.
  • 자유도: 오차 자유도는 n − 2야.
  • 검정 관계: 단순회귀의 기울기 검정에서는 F = t²이야.
  • 구간 폭: 새로운 개별값의 예측구간이 평균반응 신뢰구간보다 넓어.
  • 외삽: 회귀식에 대입할 수 있다는 사실이 예측의 타당성을 보장하지 않아.

단순선형회귀에서는 R² = r²이므로 (−0.8)² = 0.64야. 결정계수는 상관계수의 음의 부호를 유지하지 않아.

문제 2 정답: 1

b₁ = Sxy/Sxx = 50/20 = 2.5이고 b₀ = ȳ − b₁x̄ = 30 − 2.5×10 = 5이므로 Ŷ = 5 + 2.5X야.

문제 3 정답: 3

r = 0은 선형상관이 나타나지 않는다는 뜻이야. 비선형관계가 존재할 수 있으므로 일반적으로 독립을 의미하지 않아.

문제 4 정답: 2

절편을 포함한 최소제곱 회귀직선은 반드시 표본평균점 (x̄, ȳ)를 지나. 잔차 각각이 0인 것은 아니지만 잔차의 합은 0이야.

문제 5 정답: 2

절편과 기울기라는 두 모수를 추정하므로 오차 자유도는 n − 2 = 10이야.

문제 6 정답: 2

새로운 개별 관측값에는 평균 추정의 불확실성과 새로운 오차가 함께 들어가므로 개별값 예측구간이 더 넓어.

✨ 요약

  • 상관: r = Sxy/√(SxxSyy)로 선형관계의 방향과 강도를 측정해.
  • 회귀: b₁ = Sxy/Sxx, b₀ = ȳ − b₁x̄로 Ŷ = b₀ + b₁X를 구해.
  • 연결: b₁ = r(sy/sx)이고 단순선형회귀에서는 R² = r²이야.
  • 변동: SST = SSR + SSE이고 R² = SSR/SST야.
  • 검정: 오차 자유도는 n − 2이며 기울기 하나의 검정에서는 F = t²이야.
  • 진단: 산점도와 잔차도로 비선형성, 이분산성, 이상점과 독립성 문제를 확인해야 해.
  • 경계: 상관과 회귀는 인과관계를 보장하지 않으며 외삽은 특히 조심해야 해.

상관 및 단순회귀는 Sxy에서 출발해 r과 b₁으로 갈라지고, r²이 R²로 이어지며, 잔차가 SSE와 유의성 검정으로 이어지는 하나의 연결망이야. 이 구조를 잡으면 품질경영기사 필기의 계산 문제와 개념 판단 문제를 함께 해결할 수 있어 😊
