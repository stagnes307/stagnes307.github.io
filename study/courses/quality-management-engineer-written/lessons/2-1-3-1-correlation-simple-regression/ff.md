# 2-1-3-1. 산점도에서 회귀식까지 읽는 법
품질경영기사 필기  
상관 및 단순회귀

## 1. 두 품질특성의 관계를 읽는 출발점

**상관 및 단순회귀**는 두 변수의 관계를 분석한다는 공통점이 있지만, 답하려는 질문은 서로 달라.

- **상관분석**: 두 변수가 얼마나 강하게, 어느 방향으로 함께 변하는가?
- **단순회귀분석**: 설명변수 X가 변할 때 반응변수 Y의 평균이 어떻게 변하는가?
- **산점도**: 두 변수의 관측값을 좌표평면에 표시해 관계의 형태를 먼저 확인하는 그림이야.

예를 들어 열처리 온도 X와 제품 경도 Y를 조사한다고 해보자. 온도가 높아질수록 경도가 대체로 증가한다면 양의 상관이 나타날 수 있어. 여기서 상관분석은 관계의 강도를 수치화하고, 단순회귀분석은 온도를 이용해 평균 경도를 설명하거나 예측하는 식을 만든다.

분석 순서는 보통 다음과 같아.

1. X와 Y의 산점도를 그린다.
2. 직선 관계가 적절한지 확인한다.
3. 상관계수로 방향과 강도를 파악한다.
4. 회귀직선을 추정한다.
5. 기울기와 결정계수를 해석한다.
6. 잔차와 이상점을 확인한다.
7. 필요하면 상관계수나 회귀계수를 검정한다.

산점도 확인을 생략하고 공식부터 적용하면 곡선 관계, 이상점, 집단 분리 같은 중요한 구조를 놓칠 수 있어.

## 2. 공분산과 상관계수

### 공분산

공분산은 X와 Y가 평균을 기준으로 같은 방향 또는 반대 방향으로 움직이는지를 나타내.

표본공분산은 다음과 같이 계산해.

**Sxy = Σ[(xi − x̄)(yi − ȳ)] / (n − 1)**

- xi − x̄와 yi − ȳ의 부호가 자주 같으면 Sxy > 0
- 두 편차의 부호가 자주 반대이면 Sxy < 0
- 양과 음의 곱이 서로 상쇄되면 Sxy가 0에 가까워짐

공분산은 측정단위에 영향을 받아. 온도를 ℃에서 다른 단위로 바꾸거나 길이를 mm에서 cm로 바꾸면 값의 크기도 달라지므로, 서로 다른 자료의 관계 강도를 직접 비교하기 어렵다는 한계가 있어.

### 피어슨 표본상관계수

공분산을 두 변수의 표준편차로 표준화한 값이 상관계수 r이야.

**r = Sxy / (SxSy)**

동치 형태로는 다음 식을 사용할 수 있어.

**r = Σ[(xi − x̄)(yi − ȳ)] / √{Σ(xi − x̄)²Σ(yi − ȳ)²}**

상관계수의 범위는 **−1 ≤ r ≤ 1**이야.

- r > 0: 양의 선형관계
- r < 0: 음의 선형관계
- r ≈ 0: 선형관계가 약함
- r = 1: 완전한 양의 선형관계
- r = −1: 완전한 음의 선형관계

| r의 절댓값 | 일반적인 해석 |
|---:|---|
| 0에 가까움 | 선형관계가 약함 |
| 1에 가까움 | 선형관계가 강함 |
| 정확히 0 | 선형 상관이 없음 |
| 정확히 1 | 모든 점이 양의 기울기를 가진 직선 위에 있음 |

강함과 약함을 나누는 절대적인 기준은 없어. 공정의 성격, 측정오차, 표본크기와 분석 목적을 함께 고려해야 해.

## 3. 상관계수 해석의 경계

### 상관은 인과가 아니야

X와 Y의 상관이 높더라도 X가 Y의 원인이라고 바로 결론 내릴 수 없어. 숨어 있는 제3의 변수, 시간 추세, 표본 선택 또는 우연이 관계를 만들 수 있기 때문이야.

예를 들어 생산량과 불량 건수가 함께 증가했다고 해보자. 생산량이 제품 하나하나의 불량을 직접 유발했다고 단정할 수는 없어. 가동시간, 설비 피로, 작업조 변경이 두 변수에 동시에 영향을 주었을 수 있어.

### r = 0은 모든 관계의 부재가 아니야

상관계수는 주로 **선형관계**를 측정해. Y = X²처럼 뚜렷한 곡선 관계가 있어도 X가 0을 중심으로 대칭적으로 분포하면 r이 0에 가까울 수 있어.

따라서 다음 두 문장은 구별해야 해.

- r ≈ 0: 선형관계가 거의 보이지 않는다.
- X와 Y는 아무 관계도 없다: 상관계수만으로는 단정할 수 없다.

### 이상점과 범위 제한

상관계수는 이상점 하나에 크게 영향을 받을 수 있어. 반대로 실제 관계가 있더라도 X의 관측 범위가 지나치게 좁으면 r이 작게 나타날 수 있어.

전체 공정 조건을 분석해야 하는데 안정된 좁은 구간의 자료만 사용하면 실제 관계를 과소평가할 수 있어. 산점도에서 이상점, 군집, 곡률, 관측 범위를 함께 확인해야 하는 이유야.

## 4. 최소제곱법과 단순회귀식

단순선형회귀모형은 다음과 같아.

**Yi = β₀ + β₁Xi + εi**

- β₀: 모회귀직선의 절편
- β₁: 모회귀직선의 기울기
- εi: 직선으로 설명되지 않는 오차
- Xi: 설명변수
- Yi: 반응변수

표본으로 추정한 회귀식은 다음과 같이 쓴다.

**Ŷ = b₀ + b₁X**

최소제곱법은 각 관측값과 회귀직선 사이의 세로 차이인 잔차를 제곱한 합이 최소가 되도록 b₀와 b₁을 결정해.

**잔차 ei = yi − ŷi**

**오차제곱합 SSE = Σ(yi − ŷi)²**

추정계수는 다음과 같아.

**b₁ = Sxy / Sxx**

**b₀ = ȳ − b₁x̄**

여기서 계산 편의를 위해 다음 기호를 사용해.

**Sxx = Σ(xi − x̄)²**

**Sxy = Σ(xi − x̄)(yi − ȳ)**

회귀직선은 항상 표본평균점 **(x̄, ȳ)**을 지나. X = x̄를 대입하면 Ŷ = b₀ + b₁x̄ = ȳ가 되기 때문이야.

### 기울기의 의미

b₁은 X가 1단위 증가할 때 Y의 예측 평균이 얼마나 변하는지를 나타내.

예를 들어 회귀식이 **Ŷ = 12 + 0.8X**라면 X가 1단위 증가할 때 Y의 예측 평균은 0.8단위 증가한다고 해석해. 절편 12는 X = 0일 때의 예측값이지만, X = 0이 관측 범위 밖이거나 물리적으로 불가능하면 실질적인 해석을 피해야 해.

## 5. 상관과 회귀의 연결 구조

단순선형회귀에서 기울기와 상관계수는 다음 관계를 가져.

**b₁ = r(Sy / Sx)**

따라서 b₁과 r의 부호는 항상 같아.

- r > 0이면 b₁ > 0
- r < 0이면 b₁ < 0
- r = 0이면 b₁ = 0

다만 값 자체는 같지 않아. r은 단위가 없는 −1에서 1 사이의 값이지만, b₁은 **Y의 단위/X의 단위**를 가져. 측정단위를 바꾸면 기울기는 달라질 수 있지만 상관계수는 달라지지 않아.

| 구분 | 상관분석 | 단순회귀분석 |
|---|---|---|
| 핵심 질문 | 함께 변하는 방향과 강도는? | X로 Y를 어떻게 설명·예측하는가? |
| 대표 결과 | 상관계수 r | 회귀식 Ŷ = b₀ + b₁X |
| 변수 역할 | X와 Y가 대칭적 | 설명변수와 반응변수를 구분 |
| 단위 | r은 무차원 | b₁은 Y단위/X단위 |
| 순서 교환 | rxy = ryx | Y를 X에 회귀한 식과 X를 Y에 회귀한 식은 다름 |
| 인과 판단 | 단독으로 불가능 | 단독으로 불가능 |

## 6. 변동의 분해와 결정계수

각 관측값의 총편차는 회귀식이 설명한 부분과 잔차 부분으로 나뉘어.

**yi − ȳ = (ŷi − ȳ) + (yi − ŷi)**

이를 제곱합으로 분해하면 다음 관계가 성립해.

**SST = SSR + SSE**

- **SST = Σ(yi − ȳ)²**: 총제곱합, Y의 전체 변동
- **SSR = Σ(ŷi − ȳ)²**: 회귀제곱합, 회귀식이 설명한 변동
- **SSE = Σ(yi − ŷi)²**: 오차제곱합, 회귀식이 설명하지 못한 변동

결정계수는 전체 변동 중 회귀식으로 설명되는 비율이야.

**R² = SSR / SST = 1 − SSE / SST**

절편이 포함된 단순선형회귀에서는 다음 관계가 성립해.

**R² = r²**

예를 들어 r = −0.8이면 R² = 0.64야. 방향은 음이지만 Y 변동의 64%가 X와의 선형회귀 관계로 설명된다는 뜻이야. 결정계수에는 방향 정보가 없으므로 방향은 반드시 r 또는 b₁의 부호로 확인해야 해.

R²가 높다고 모형이 반드시 적절한 것은 아니야. 곡선 관계, 이상점, 체계적인 잔차 패턴이 존재할 수 있고, 높은 설명력 역시 인과관계를 증명하지 않아.

## 7. 계산 예시: 공정 온도와 강도

다섯 번의 실험에서 공정 온도 X와 제품 강도 Y를 다음과 같이 얻었다고 하자.

- X: 1, 2, 3, 4, 5
- Y: 2, 3, 5, 4, 6

평균은 x̄ = 3, ȳ = 4야.

각 편차를 이용하면 다음 값을 얻어.

- Sxx = 4 + 1 + 0 + 1 + 4 = 10
- Sxy = 4 + 1 + 0 + 0 + 4 = 9
- Syy = 4 + 1 + 1 + 0 + 4 = 10

따라서 상관계수는 다음과 같아.

**r = 9 / √(10 × 10) = 0.9**

강한 양의 선형관계가 관찰된다고 해석할 수 있어.

회귀계수는 다음과 같아.

**b₁ = 9 / 10 = 0.9**

**b₀ = 4 − 0.9 × 3 = 1.3**

따라서 추정 회귀식은 다음과 같아.

**Ŷ = 1.3 + 0.9X**

X = 4일 때 예측값은 **Ŷ = 1.3 + 0.9 × 4 = 4.9**야. 실제 관측값이 4라면 잔차는 **e = 4 − 4.9 = −0.9**가 돼. 음의 잔차는 실제값이 회귀식의 예측값보다 작다는 뜻이야.

결정계수는 **R² = r² = 0.81**이므로, 표본에서 관측된 Y 변동의 81%가 X와의 선형회귀 관계로 설명돼.

## 8. 검정과 예측에서 주의할 조건

모상관계수 ρ가 0인지 검정할 때, 이변량 정규성과 독립 표본을 전제로 다음 통계량을 사용할 수 있어.

**t = r√(n − 2) / √(1 − r²)**

자유도는 **n − 2**야. 단순선형회귀에서 기울기 β₁ = 0을 검정하는 것과 모상관계수 ρ = 0을 검정하는 것은 같은 선형관계의 유의성을 다루므로 동일한 결론에 이르게 돼.

회귀분석의 대표적인 오차 가정은 다음과 같아.

1. 선형성: X와 Y 평균의 관계가 직선 형태다.
2. 독립성: 오차들이 서로 독립이다.
3. 등분산성: X 수준에 관계없이 오차분산이 일정하다.
4. 정규성: 추론을 수행할 때 오차가 정규분포를 따른다.
5. 오차 평균 0: 각 X 수준에서 오차의 평균이 0이다.

잔차가 0을 중심으로 무작위로 흩어지지 않고 부채꼴을 이루면 등분산성이 의심돼. U자형 패턴이 보이면 선형모형이 곡선 구조를 놓쳤을 가능성이 커.

또한 관측 범위 안의 예측인 **내삽**은 비교적 안전하지만, 관측 범위를 벗어나는 **외삽**은 관계가 계속 유지된다는 보장이 없어 위험해.

## 9. 시험 함정 정리

1. **r = 0이면 독립이다**  
   일반적으로 거짓이야. 무상관이 독립을 뜻하지는 않아. 다만 이변량 정규분포처럼 특별한 조건에서는 성립할 수 있어.

2. **상관계수가 크면 인과관계가 있다**  
   거짓이야. 상관은 인과를 보장하지 않아.

3. **r = −0.9는 r = 0.7보다 약하다**  
   거짓이야. 강도는 절댓값으로 비교하므로 −0.9가 더 강해. 음수 부호는 방향을 나타낼 뿐이야.

4. **결정계수 0.81은 상관계수 0.81을 뜻한다**  
   거짓이야. 단순회귀에서는 r = ±√0.81 = ±0.9이며, 부호는 기울기로 판단해야 해.

5. **X와 Y를 바꾸어도 회귀식은 같다**  
   거짓이야. 상관계수는 같지만 회귀식은 변수의 역할에 따라 달라져.

6. **회귀직선은 항상 원점을 지난다**  
   거짓이야. 일반적으로 평균점 (x̄, ȳ)을 지나며, 원점을 지나는 것은 별도의 제약이야.

7. **R²가 높으면 잔차를 볼 필요가 없다**  
   거짓이야. 높은 R²와 별개로 비선형성, 이상점, 이분산성이 존재할 수 있어.

8. **절편은 언제나 공학적으로 해석해야 한다**  
   거짓이야. X = 0이 의미 있는 조건이고 분석 범위와 연결될 때만 신중하게 해석해.

## 11. 정답 및 해설

### 문제 1 정답

**음의 선형관계, R² = 0.36**이야.

r의 부호 −는 방향을 나타내고, 결정계수는 r²이므로 (−0.6)² = 0.36이야. 표본 Y 변동의 36%가 X와의 선형회귀 관계로 설명된다고 해석해.

### 문제 2 정답

**b₁ = Sxy/Sxx = 30/20 = 1.5**

**b₀ = ȳ − b₁x̄ = 25 − 1.5 × 10 = 10**

따라서 회귀식은 **Ŷ = 10 + 1.5X**야.

### 문제 3 정답

**3번**이 옳아.

회귀직선은 (x̄, ȳ)을 지나. r = 0은 선형 상관이 없다는 뜻이지 일반적인 독립을 보장하지 않고, 상관계수는 측정단위 변화에 영향을 받지 않아. 결정계수는 설명 비율만 나타내므로 방향 정보도 없어.

### 문제 4 정답

예측값은 **Ŷ = 5 + 2 × 3 = 11**이야.

잔차는 **e = y − ŷ = 9 − 11 = −2**야. 실제값이 예측값보다 2만큼 작다는 의미야.

### 문제 5 정답

**등분산성 가정**을 먼저 의심해야 해.

X의 크기에 따라 잔차분산이 달라지는 모습이므로 이분산 가능성이 있어. 변수변환이나 가중회귀 같은 대응을 검토할 수 있지만, 시험에서는 우선 잔차 패턴과 위반된 가정을 연결하는 것이 핵심이야.

## 12. 회상 요약

- 산점도로 관계의 형태, 방향, 이상점을 먼저 확인해.
- 상관계수 r은 두 변수의 **선형관계 방향과 강도**를 나타내.
- r의 부호는 방향, 절댓값은 강도와 관련돼.
- 상관이 높아도 인과관계를 바로 결론 내릴 수 없어.
- 단순회귀식은 **Ŷ = b₀ + b₁X**이고, b₁ = Sxy/Sxx야.
- 회귀직선은 항상 **(x̄, ȳ)**을 지나.
- 잔차는 **실제값 − 예측값**으로 계산해.
- 변동은 **SST = SSR + SSE**로 분해돼.
- 절편을 포함한 단순선형회귀에서는 **R² = r²**가 성립해.
- 상관은 변수 순서를 바꾸어도 같지만 회귀식은 일반적으로 달라져.
- 높은 R²만 믿지 말고 선형성, 이상점, 잔차 패턴과 외삽 위험을 함께 확인해야 해.
