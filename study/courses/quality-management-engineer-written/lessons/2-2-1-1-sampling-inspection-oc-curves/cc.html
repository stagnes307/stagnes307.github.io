표본으로 로트를 판정하는 법

샘플링 검사 (1/2)

일부를 보고 전체를 결정한다. 샘플링검사는 검사비용을 줄이는 대신 판정 오류의 가능성을 받아들이는 의사결정 장치야. 이번 레슨에서는 표본 추출부터 OC곡선의 두 위험까지 하나의 흐름으로 연결해볼게.

Decision anatomy

로트 판정의 네 가지 기호

검사 대상과 판정 기준

로트는 동일한 조건에서 생산되었다고 보는 제품 집단이고, 그 크기를 N으로 나타내. 로트에서 실제로 뽑은 제품 집단은 표본이며 그 크기는 n이야. 표본에서 발견한 부적합품 수는 d, 합격을 허용하는 최대 부적합품 수는 c로 나타내.

계수형 1회 샘플링검사의 판정식은 단순해. d ≤ c이면 합격, d > c이면 불합격이야. 예를 들어 N = 1,000, n = 50, c = 1인 계획에서 d가 0 또는 1이면 로트를 받아들이고, 2 이상이면 거부해.

판정 공식 d ≤ c → 로트 합격 d > c → 로트 불합격

검사한 n개만 선별하는 것이 아니라, 표본 결과로 N개 로트 전체의 처분을 결정한다는 점이 핵심이야.

Sampling methods

대표성을 지키는 네 가지 추출법

편한 위치에서 눈에 띄는 제품만 고르면 선택편의가 생겨. 생산 순서, 설비, 작업조, 포장 위치를 고려해 모든 검사 단위에 합리적인 선택 기회를 줘야 해.

단순랜덤

모든 제품에 번호를 부여하고 난수로 선택해. 이론이 명확하고 선택편의를 줄이지만 대규모 로트의 번호화가 번거로울 수 있어.

계통

최초 위치를 무작위로 정하고 k ≈ N/n 간격으로 추출해. 빠르지만 불량 주기와 k가 일치하면 심각한 편향이 생겨.

층별

설비·작업조·시간대처럼 품질 차이가 예상되는 층으로 나눈 뒤 각 층에서 추출해. 특정 집단의 누락을 막는 데 유리해.

집락

상자나 팔레트 같은 집락 일부를 선택해 조사해. 이동비용은 줄지만 선택 집락이 전체를 대표하지 못하면 오차가 커져.

Two error channels

샘플링오차와 비샘플링오차를 분리하기

확률적 변동

샘플링오차

로트 전체가 아니라 일부만 관찰해서 표본 결과와 실제 로트 특성 사이에 생기는 차이야. 실제 부적합률이 5%여도 작은 표본에서는 부적합품이 하나도 나오거나 예상보다 많이 나올 수 있어. 일반적으로 n을 키우면 변동은 줄지만 비용과 시간이 증가해.

절차와 측정

비샘플링오차

측정기 교정 불량, 검사자의 오판, 기록 실수, 모호한 기준, 특정 위치만 고르는 편향처럼 추출량 이외의 원인으로 발생해. 잘못된 측정기를 계속 쓴다면 n을 아무리 늘려도 오류가 자동으로 사라지지 않아.

시험 경계: 우연한 표본변동과 조사 과정의 체계적 편향을 같은 것으로 보면 안 돼. 전자는 시료 크기와 확률모형의 문제이고, 후자는 검사시스템을 바로잡아야 하는 문제야.

Operating characteristic

OC곡선은 판정 장벽의 성능표야

축과 곡선의 의미

OC곡선의 가로축은 로트의 실제 부적합률 p, 세로축은 그 로트가 합격할 확률 Pₐ야. 좋은 로트는 합격할 가능성이 높고 나쁜 로트는 낮으므로 곡선은 왼쪽 위에서 오른쪽 아래로 내려가.

이항분포 모형 Pₐ = P(X ≤ c) Pₐ = Σ C(n,x)pˣ(1−p)ⁿ⁻ˣ
단, x = 0부터 c까지

c를 키우면 더 많은 부적합품을 허용하므로 같은 p에서 Pₐ가 커져. n과 c를 적절히 설계해 곡선을 가파르게 만들면 좋은 로트와 나쁜 로트를 더 뚜렷하게 구별할 수 있어.

Risk barriers

α와 β는 피해자를 따라 기억하기

α

생산자위험

좋은 로트를 불합격시키는 확률이야. AQL에서 α = 1 − Pₐ이므로 OC곡선은 AQL 지점에서 Pₐ = 1 − α를 지나.

반대 오류
β

소비자위험

나쁜 로트를 합격시키는 확률이야. LTPD에서 β = Pₐ이므로 나쁜 로트가 판정 장벽을 통과할 가능성을 뜻해.

AQL = 1%, α = 5%, LTPD = 8%, β = 10%라면 목표 OC곡선은 p = 1%에서 Pₐ = 0.95, p = 8%에서 Pₐ = 0.10인 두 지점을 통과하도록 설계해. 좋은 로트를 거부하면 생산자가, 나쁜 로트를 수용하면 소비자가 피해를 본다고 연결하면 헷갈리지 않아.

Worked example

c = 0 계획의 합격확률 계산

주어진 조건

시료 크기 n = 20
합격판정개수 c = 0
로트 부적합률 p = 0.05

표본에서 부적합품이 하나도 없어야 로트가 합격해.

확률 사건 설정
Pₐ = P(X ≤ 0) = P(X = 0)
이항확률 대입
P(X = 0) = (1 − p)ⁿ = 0.95²⁰
결과 해석
Pₐ ≈ 0.358이므로 합격확률은 약 35.8%, 불합격확률은 약 64.2%야.

Exam barriers

시험에서 자주 무너지는 판정 경계

α의 방향AQL에서의 합격확률이 아니라 불합격확률이야. 따라서 α = 1 − Pₐ이야.
β의 방향LTPD에서의 불합격확률이 아니라 나쁜 로트의 합격확률이야.
OC곡선의 가로축표본부적합률이 아니라 로트의 실제 부적합률 p를 나타내.
c의 효과c가 커지면 판정이 느슨해지고 같은 p에서 합격확률이 높아져.
검사의 역할샘플링검사는 로트를 판정할 뿐, 공정 원인을 제거하거나 제품에 품질을 만들어 넣지 않아.
분포 선택유한 로트에서 비복원 추출하면 초기하분포가 엄밀해. 로트가 충분히 크면 이항분포로 근사해.

Knowledge check

확인 문제

공식을 보기 전에 판정의 피해자와 확률 사건을 먼저 말해보면 기억이 훨씬 단단해져.

  1. 로트에서 일부만 검사해 로트 전체의 합격 여부를 결정하는 검사는 무엇일까?
  2. N = 600, n = 30인 계통샘플링의 기본 추출 간격 k는 얼마일까?
  3. 양호한 로트를 불합격시키는 위험의 명칭과 기호를 써봐.
  4. LTPD 수준의 나쁜 로트가 합격할 확률은 무엇일까?
  5. 동일한 n에서 c를 증가시키면 일반적으로 합격확률은 어떻게 변할까?
  6. n = 10, c = 0, p = 0.10일 때 로트 합격확률을 계산해봐.

Answer key

정답과 해설

각 답을 단어로만 외우지 말고 어떤 판정 사건인지 함께 확인하자.

1. 샘플링검사
표본 결과를 이용해 로트 전체를 합격 또는 불합격으로 판정해.
2. k = 20
k = N/n = 600/30이며, 최초 위치는 무작위로 정해야 해.
3. 생산자위험 α
좋은 로트가 거부되어 생산자가 손해를 보는 오류야.
4. 소비자위험 β
β = Pₐ(LTPD)이며 나쁜 로트를 받아들이는 확률이야.
5. 합격확률 증가
더 많은 부적합품을 허용하므로 판정이 느슨해져.
6. 약 0.349
Pₐ = 0.9¹⁰ ≈ 0.349이므로 합격확률은 약 34.9%야.

오류를 두 갈래로샘플링오차는 일부 관찰에 따른 확률적 변동이고, 비샘플링오차는 측정·기록·선택 절차의 문제야.
