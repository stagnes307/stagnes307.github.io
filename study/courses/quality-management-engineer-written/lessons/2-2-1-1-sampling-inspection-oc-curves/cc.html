📋 검사개요

검사의 정의와 목적

검사는 제품이나 서비스의 품질특성을 측정·시험·확인한 뒤 그 결과를 규격 또는 판정기준과 비교하여 적합 여부를 결정하는 활동이야. 품질특성을 정하고, 품질정보를 얻고, 기준과 비교하고, 제품이나 로트를 합격 또는 불합격으로 판정한 뒤 결과를 생산공정에 피드백하는 순서로 진행해.

검사는 이미 만들어진 부적합품을 찾아내는 활동이지 그 자체가 좋은 품질을 제조하는 활동은 아니야. 불량품을 선별했다고 해서 발생 원인이 제거되는 것은 아니므로 현대 품질관리에서는 공정 안정과 불량 예방을 더 근본적인 목표로 삼아.

전수검사도 검사자의 피로, 측정기 오차와 판정 착오 때문에 완전무결하지 않아. 샘플링검사는 비용과 시간을 줄이고 파괴검사를 가능하게 하지만 좋은 로트를 불합격시키거나 나쁜 로트를 합격시킬 위험이 있어.

전구 10,000개의 수명을 끝까지 시험하면 판매할 전구가 남지 않으므로 일부만 뽑는 샘플링검사가 필요해. 반면 항공기 핵심 부품의 치명적 균열처럼 불량 하나가 중대한 사고로 이어진다면 검사비용보다 안전성과 실패 결과를 우선해야 해.

비교 경계와 시험 함정

  • 샘플링검사는 로트 안의 모든 불량품을 완전히 선별하는 방법이 아니라 로트의 합격 여부를 판단하는 방법이야.
  • 전수검사도 측정오차와 판정오류에서 자유롭지 않아.
  • 관리도는 시간에 따른 공정 변화를 감시하고, 샘플링검사는 이미 형성된 로트의 수락 여부를 결정해.
  • 파괴검사에는 일반적으로 샘플링검사가 적합해.
  • 검사는 품질정보를 제공하지만 품질을 직접 제조하지는 않아.

🎲 샘플링방법과 샘플링오차

모집단, 로트와 표본

모집단은 판단하려는 전체 대상이고, 로트는 동일하거나 유사한 조건에서 생산되어 하나의 검사단위로 제출된 제품의 집합이야. 로트 크기는 보통 N, 실제로 뽑아 검사하는 표본 크기는 n, 표본에서 발견한 부적합품 수는 d로 나타내.

부품 1,000개 중 50개를 검사하는 사례
항목기호값
로트 크기N1,000
표본 크기n50
표본 부적합품 수d검사 결과에 따라 결정

단순 랜덤 샘플링과 계통 샘플링

단순 랜덤 샘플링은 로트의 모든 제품이 선택될 기회를 동등하게 갖도록 추출하는 방법이야. 창고 앞쪽 제품만 고르면 특정 생산시간대의 제품만 포함될 수 있으므로 난수표나 난수 생성기를 이용해 무작위성을 확보해야 해.

계통 샘플링은 첫 제품을 무작위로 정한 뒤 일정 간격마다 추출하는 방법이야. 기본 추출 간격은 k = N ÷ n으로 계산해. N = 1,000, n = 50이면 k = 20이고, 첫 번호가 7이라면 7번, 27번, 47번처럼 뽑을 수 있어. 다만 생산공정의 주기가 20개라면 특정 상태만 반복 선택하는 주기성 편향이 생길 수 있어.

층별 샘플링과 집락 샘플링

층별 샘플링은 모집단을 교대조, 설비, 공급자 또는 생산일자처럼 의미 있는 층으로 나눈 뒤 각 층에서 표본을 추출해. 주간조 700개와 야간조 300개가 섞인 로트에서 100개를 비례 추출한다면 각각 70개와 30개를 뽑을 수 있어.

집락 샘플링은 제품을 상자, 팔레트 또는 생산 묶음과 같은 집락으로 나눈 다음 일부 집락을 선택하여 조사해. 층별 샘플링은 모든 층을 반영하려는 반면 집락 샘플링은 여러 집락 중 일부를 고른다는 차이가 있어.

샘플링오차와 비샘플링오차

샘플링오차는 전체가 아니라 일부 표본만 관찰해서 생기는 우연한 차이야. 같은 로트에서 같은 크기의 표본을 다시 뽑아도 부적합품 수가 달라질 수 있어. 표본부적합품률은 d ÷ n이며, n = 100이고 d = 4이면 4 ÷ 100 = 0.04, 즉 4%야. 이 값은 모집단 부적합품률의 추정치이지 실제 값과 항상 같지는 않아.

비샘플링오차는 측정기 교정 불량, 검사자의 판정 착오, 기록 오류와 잘못된 추출절차 때문에 생겨. 표본 크기를 늘리면 샘플링오차는 일반적으로 줄지만 잘못 교정된 측정기를 계속 쓰면서 생기는 오류까지 자동으로 사라지지는 않아.

샘플링편의와 오류의 경계

샘플링편의는 추출방법이 특정 방향으로 치우쳐 생기는 체계적 왜곡이야. 상자 윗부분만 검사하면 아래에서 눌린 제품의 결함을 놓칠 수 있어. 표본을 10개에서 100개로 늘려도 계속 윗부분만 뽑는다면 편의는 해결되지 않아.

샘플링오차와 비샘플링오차의 비교
구분 샘플링오차 비샘플링오차·편의
주된 원인일부 표본만 관찰측정, 기록, 판정과 추출절차 문제
성격우연한 변동체계적 왜곡 포함 가능
표본 크기 증가일반적으로 감소반드시 감소하지 않음

시험 함정

  • 표본 크기를 늘리면 샘플링오차는 일반적으로 감소하지만 모든 오류가 제거되는 것은 아니야.
  • 편의가 있는 추출방법에서는 큰 표본도 잘못된 결론을 만들 수 있어.
  • 계통 샘플링에서는 생산주기와 추출간격의 일치를 점검해야 해.
  • 층별 샘플링과 집락 샘플링은 서로 다른 방법이야.
  • 표본부적합품률은 모집단 부적합품률의 추정치야.

OC곡선의 정의와 해석

OC곡선, 즉 검사특성곡선은 로트의 부적합품률 p와 로트의 합격확률 Pa의 관계를 나타내. 가로축에는 p, 세로축에는 Pa를 표시하며 p가 커질수록 Pa가 낮아지므로 일반적으로 왼쪽 위에서 오른쪽 아래로 내려가.

OC곡선은 특정 로트의 합격 여부를 확정적으로 예언하지 않아. 동일한 품질 수준의 로트에 같은 검사방식을 반복 적용했을 때 나타나는 장기적인 합격확률을 표현해.

이항분포에 의한 합격확률

로트가 충분히 크고 각 제품이 부적합일 확률을 p로 볼 수 있다면 표본의 부적합품 수 X를 이항분포로 근사할 수 있어. 합격 조건은 X ≤ c이므로 Pa = P(X ≤ c)이며, 구체적으로 Pa = Σ nCx · pˣ · (1 − p)ⁿ⁻ˣ을 x = 0부터 c까지 더해.

예시 1: n = 5, c = 0, p = 0.10이면 부적합품이 하나도 없어야 합격이므로 Pa = 0.90⁵ = 0.59049야.

예시 2: n = 5, c = 1, p = 0.10이면 Pa = P(X = 0) + P(X = 1)이야. P(X = 0) = 0.59049이고 P(X = 1) = 5 × 0.10 × 0.90⁴ = 0.32805이므로 Pa = 0.91854야. c를 0에서 1로 높이면 동일한 품질의 로트가 합격할 확률이 약 59.05%에서 91.85%로 증가해.

초기하분포와 이항분포의 경계

유한한 로트에서 표본을 비복원추출하면 정확한 확률모형은 초기하분포야. 로트 크기 N, 로트 내 부적합품 수 D, 표본 크기 n이라면 P(X = x) = [DCx × (N−D)C(n−x)] ÷ NCn으로 계산해. 로트가 표본보다 충분히 클 때는 추출별 부적합확률이 거의 일정하다고 보아 이항분포로 근사할 수 있어.

생산자위험과 소비자위험

생산자위험과 소비자위험
위험 의미 OC곡선의 관계
생산자위험 α좋은 로트를 불합격시킬 확률좋은 품질 수준에서 1 − Pa
소비자위험 β나쁜 로트를 합격시킬 확률나쁜 품질 수준에서 Pa

생산자위험 α는 좋은 품질의 로트가 불합격되는 확률이고, 소비자위험 β는 나쁜 품질의 로트가 합격되는 확률이야. 일반적으로 AQL에서 Pa = 1 − α이고, LTPD와 같은 나쁜 품질 수준에서 Pa = β로 읽어.

AQL, LTPD와 OC곡선의 판별력

AQL은 만족스러운 공정 평균으로 간주되는 좋은 품질 수준을 나타내고, LTPD는 소비자가 받아들이고 싶지 않은 나쁜 품질 수준을 나타내. 유한한 표본에는 우연성이 있으므로 좋은 로트와 나쁜 로트를 완벽하게 나누는 수직 OC곡선 대신 완만한 전이구간이 생겨.

다른 조건이 같을 때 c를 크게 하면 합격기준이 느슨해져 합격확률이 커져. 표본 크기 n을 늘리고 판정기준을 적절히 함께 설계하면 품질 차이를 더 잘 구별하여 OC곡선의 전이구간을 가파르게 만들 수 있어. 실제 설계에서는 n과 c를 함께 조정하여 원하는 α와 β를 만족시켜야 해.

비교 경계와 시험 함정

  • OC곡선의 세로축은 일반적으로 로트 합격확률 Pa야.
  • 부적합품률 p가 증가하면 Pa는 일반적으로 감소해.
  • 생산자위험은 좋은 로트의 불합격확률이야.
  • 소비자위험은 나쁜 로트의 합격확률이야.
  • AQL에서 합격확률은 일반적으로 1 − α야.
  • 나쁜 품질 수준에서 합격확률은 β야.
  • c를 크게 하면 합격판정이 느슨해져 Pa가 증가해.
  • α와 β는 서로 다른 품질 수준에서 정의되므로 한 지점에서 단순히 더해 1이라고 판단하면 안 돼.
  • 유한 로트의 비복원추출에는 초기하분포가 정확한 모형이야.

    3. 로트가 매우 작고 자동검사가 가능한 경우
    4. 모든 부적합품을 완전히 선별해야 하는 경우
  2. 로트 크기가 2,000개이고 표본 크기가 100개인 계통 샘플링의 기본 추출 간격을 구해.
  3. 표본 크기가 200이고 부적합품이 6개라면 표본부적합품률을 구해.
  4. 표본 크기를 늘려도 반드시 감소하지 않는 것을 고르면?
    1. 표본추출에 따른 우연한 변동
    2. 샘플링오차
    3. 잘못 교정된 측정기로 인한 측정오차
    4. 표본통계량의 변동성
  5. n = 80, c = 2인 검사에서 부적합품 3개가 발견되었다면 로트를 판정해.
  6. n = 4, c = 0, p = 0.20일 때 이항분포에 따른 Pa를 구해.
  7. 좋은 품질 수준에서 Pa = 0.95라면 α를 구해.
  8. 나쁜 품질 수준의 로트가 10% 확률로 합격한다면 β를 구해.
  9. 다른 조건이 같을 때 c가 증가하면 Pa가 어떻게 변하는지 설명해.
  10. 층별 샘플링과 집락 샘플링의 차이를 한 문장으로 설명해.

✅ 정답 및 해설

  1. 정답 2: 파괴검사는 검사한 제품을 정상적으로 사용할 수 없으므로 일부만 검사하는 샘플링검사가 적합해.
  2. 정답 20: k = N ÷ n = 2,000 ÷ 100 = 20이야. 생산공정에 20개 단위의 주기가 있는지도 확인해야 해.
  3. 정답 3%: 6 ÷ 200 = 0.03 = 3%야. 이는 로트 전체의 실제 비율이 아니라 표본에서 관찰된 비율이야.
  4. 정답 3: 잘못 교정된 측정기의 체계적 오류는 표본을 더 많이 측정해도 계속 발생할 수 있어.
  5. 정답 불합격: d = 3이고 c = 2이므로 d > c야.
  6. 정답 0.4096: Pa = P(X = 0) = (1 − 0.20)⁴ = 0.80⁴ = 0.4096, 즉 40.96%야.
  7. 정답 0.05: α = 1 − Pa = 1 − 0.95 = 0.05, 즉 5%야.
  8. 정답 0.10: 소비자위험은 나쁜 로트의 합격확률이므로 β = 10%야.
  9. 정답 증가: c가 커지면 더 많은 부적합품을 허용하므로 판정이 느슨해지고 Pa가 증가해.
  10. 정답: 층별 샘플링은 각 층에서 표본을 뽑아 모든 층을 반영하지만 집락 샘플링은 여러 집락 중 일부 집락을 선택해 조사해.

✨ 요약

  • 검사개요: 검사는 품질특성을 측정하여 기준과 비교하고 적합 여부를 판정하지만 품질을 직접 제조하지는 않아.
  • 전수검사와 샘플링검사: 파괴검사와 대형 로트에는 샘플링검사가 유리하지만 판정위험이 존재해.
  • 샘플링방법과 샘플링오차: 단순 랜덤, 계통, 층별, 집락 샘플링의 원리와 편의 가능성을 구별해야 해.
  • 오차의 경계: 표본을 키우면 샘플링오차는 일반적으로 감소하지만 측정오차와 체계적 편의가 자동으로 제거되지는 않아.
  • 샘플링검사와 OC곡선: OC곡선은 부적합품률 p와 합격확률 Pa의 관계를 보여 주며 p가 커지면 Pa는 일반적으로 작아져.
  • 판정규칙: 계수형 1회 검사에서는 d ≤ c일 때 합격이야.
  • 위험: α는 좋은 로트의 불합격확률이고 β는 나쁜 로트의 합격확률이야.
  • 계산: 이항분포를 적용하면 Pa = P(X ≤ c)이므로 0부터 c까지의 확률을 모두 더해야 해.

샘플링검사는 단순한 표본추출이 아니라 생산자와 소비자의 판정위험을 조절하는 확률적 의사결정이야. 계산식보다 먼저 누가 어떤 잘못된 판정으로 손해를 보는지 생각하면 구조가 훨씬 쉽게 보여 😊
