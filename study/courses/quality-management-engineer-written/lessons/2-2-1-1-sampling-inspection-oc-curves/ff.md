## 1. 검사개요

### 1.1 검사의 정의와 목적

**검사**는 제품이나 서비스의 품질특성을 측정·시험·확인한 뒤, 그 결과를 규격이나 판정기준과 비교하여 적합 여부를 결정하는 활동이야.

검사의 기본 절차는 다음과 같아.

1. 검사할 **품질특성**을 정해.
2. 측정이나 시험을 통해 **품질정보**를 얻어.
3. 결과를 **규격 또는 판정기준**과 비교해.
4. 제품이나 로트를 **합격 또는 불합격**으로 판정해.
5. 결과를 생산공정과 품질관리 활동에 피드백해.

여기서 중요한 경계가 하나 있어. 검사는 이미 만들어진 부적합품을 찾아내는 활동이지, 그 자체가 좋은 품질을 만들어 내는 생산활동은 아니야. 불량품을 선별했다고 해서 불량이 발생한 원인이 제거되는 것은 아니지. 따라서 현대 품질관리에서는 검사만 강화하기보다 **공정을 안정시키고 불량 발생을 예방하는 것**을 더 근본적인 목표로 삼아.

### 1.2 검사의 기능

| 기능 | 의미 | 구체적인 예시 |
|---|---|---|
| 판정 기능 | 개별 제품이나 로트의 적합 여부 결정 | 납품 로트의 합격·불합격 판정 |
| 선별 기능 | 양품과 부적합품 분리 | 외관 흠집이 있는 제품 제거 |
| 정보 기능 | 공정과 공급자의 품질 상태 파악 | 불량률 증가를 생산부서에 통보 |
| 예방 기능 | 검사 결과를 개선에 활용하여 재발 억제 | 반복 결함의 원인분석과 공정 개선 |
| 보증 기능 | 고객에게 요구품질 충족의 근거 제공 | 출하검사 성적서 발행 |

### 1.3 실시 단계에 따른 분류

**수입검사**는 원재료, 부품 또는 외주품을 받아들일 때 실시해. 불량 자재가 생산공정에 투입되는 것을 막는 것이 목적이야.

**공정검사**는 제조 도중에 실시해. 이상을 일찍 발견하면 뒤 공정에서 발생할 손실과 재작업을 줄일 수 있어.

**최종검사**는 완성된 제품이 규격을 충족하는지 확인해. 완성검사라고도 해.

**출하검사**는 고객에게 제품을 보내기 직전에 실시해. 포장, 수량, 표시사항이나 운송 준비까지 검사 대상에 포함될 수 있어.

### 1.4 전수검사와 샘플링검사의 비교

**전수검사**는 검사 대상 전체를 하나도 빠짐없이 검사하는 방법이야. 제품 하나의 불량이 인명이나 안전에 치명적인 영향을 주는 경우, 고가품처럼 불량 하나의 손실이 매우 큰 경우, 로트 크기가 작거나 자동검사가 매우 빠르고 저렴한 경우에 적합해.

하지만 전수검사도 완전무결하지 않아. 검사자의 피로, 측정기의 오차, 판정 착오가 존재하기 때문이야. 동일 제품을 반복해서 검사하면 오히려 손상될 수도 있어.

**샘플링검사**는 로트에서 일부 제품을 표본으로 추출해 검사하고, 표본의 결과로 로트 전체의 합격 여부를 판정하는 방법이야. 검사비용과 시간이 줄고 파괴검사를 적용할 수 있다는 장점이 있지만, 일부만 관찰하기 때문에 양질의 로트를 불합격시키거나 불량한 로트를 합격시킬 위험이 반드시 존재해.

| 구분 | 전수검사 | 샘플링검사 |
|---|---|---|
| 검사 범위 | 전체 제품 | 일부 표본 |
| 검사비용과 시간 | 일반적으로 큼 | 일반적으로 작음 |
| 파괴검사 | 적용 곤란 | 적용 가능 |
| 개별 불량품의 완전 선별 | 상대적으로 유리 | 불가능 |
| 판정위험 | 검사오류가 존재 | 검사오류와 샘플링위험이 존재 |
| 적합한 상황 | 치명적 결함, 소형 로트, 자동검사 | 대형 로트, 파괴검사, 검사비용이 큰 경우 |

### 1.5 구체적인 예시

전구 10,000개의 수명을 확인한다고 생각해 보자. 수명검사는 전구가 고장 날 때까지 작동시켜야 하므로 전수검사를 하면 판매할 전구가 남지 않아. 이런 검사를 **파괴검사**라고 하며, 일부 전구만 뽑아 수명을 시험하는 샘플링검사가 필요해.

반면 항공기 핵심 부품의 치명적 균열처럼 불량 하나가 중대한 사고로 이어질 수 있다면 샘플링검사만으로는 충분하지 않을 수 있어. 검사방법은 비용만 보고 정하는 것이 아니라, **결함의 심각도와 검사 실패의 결과**까지 고려해야 해.

### 1.6 비교와 경계

샘플링검사는 표본에 포함된 불량품을 골라내어 로트 전체를 깨끗하게 만드는 방법이 아니야. 본질적으로는 **로트의 합격 여부를 판정하는 통계적 의사결정 방법**이야.

또한 공정관리와 샘플링검사를 구별해야 해. 관리도는 시간에 따른 공정 변화를 감시하여 이상원인을 탐지하지만, 샘플링검사는 이미 형성된 로트를 받아들일지 거부할지를 결정해.

### 1.7 시험 함정

1. **샘플링검사는 불량품을 완전히 선별한다**는 설명은 틀려.
2. **전수검사는 항상 오류가 없다**는 설명도 틀려.
3. 파괴검사에는 일반적으로 전수검사보다 샘플링검사가 적합해.
4. 검사는 품질정보를 제공하지만 품질을 직접 제조하는 활동은 아니야.
5. 치명적 결함은 평균적인 검사비용보다 안전성과 위험을 우선해서 판단해야 해.

## 2. 샘플링방법과 샘플링오차

### 2.1 모집단, 로트, 표본

**모집단**은 조사하거나 판단하려는 전체 대상이야. 샘플링검사에서는 하나의 로트가 모집단 역할을 하는 경우가 많아.

**로트**는 동일하거나 유사한 조건에서 생산되어 하나의 검사단위로 제출된 제품의 집합이야. 로트의 크기는 보통 **N**으로 나타내.

**표본**은 로트에서 실제로 추출하여 검사하는 일부 제품이고, 표본의 크기는 **n**으로 나타내.

예를 들어 부품 1,000개로 이루어진 로트에서 50개를 뽑아 검사한다면 다음과 같아.

| 항목 | 값 |
|---|---:|
| 로트 크기 N | 1,000 |
| 표본 크기 n | 50 |
| 표본에서 발견된 부적합품 수 d | 실제 검사 결과에 따라 결정 |

### 2.2 단순 랜덤 샘플링

**단순 랜덤 샘플링**은 로트의 모든 제품이 표본으로 선택될 기회를 동등하게 갖도록 추출하는 방법이야. 난수표나 난수 생성기를 사용할 수 있어.

창고 앞쪽에 있는 제품만 꺼내 검사하면 편리하지만, 앞쪽 제품이 특정 생산시간대에 만들어졌다면 로트를 대표하지 못할 수 있어. 무작위성은 보기 좋은 형식이 아니라 표본의 대표성을 지키는 핵심 조건이야.

### 2.3 계통 샘플링

**계통 샘플링**은 첫 번째 제품을 무작위로 정한 다음 일정한 간격마다 제품을 추출하는 방법이야. 로트 크기가 N이고 표본 크기가 n이면 추출 간격은 대략 다음과 같아.

**추출 간격 k = N ÷ n**

예를 들어 N = 1,000이고 n = 50이면 k = 20이야. 첫 추출번호를 7로 정했다면 7번, 27번, 47번처럼 뽑을 수 있어.

주의할 점은 생산공정에 20개 단위의 주기성이 존재하면 표본이 특정 상태만 반복적으로 선택할 수 있다는 거야. 계통 샘플링은 간편하지만 **추출 간격과 공정 주기가 일치하는 주기성 편향**을 경계해야 해.

### 2.4 층별 샘플링

**층별 샘플링**은 모집단을 의미 있는 여러 층으로 나누고 각 층에서 표본을 추출하는 방법이야. 생산 교대조, 설비, 공급자, 생산일자처럼 품질에 영향을 줄 수 있는 기준을 층으로 사용할 수 있어.

주간조 제품 700개와 야간조 제품 300개가 섞인 로트에서 100개를 비례 배분한다면 주간조에서 70개, 야간조에서 30개를 뽑을 수 있어. 이렇게 하면 어느 한 집단만 과도하게 포함되는 문제를 줄일 수 있어.

### 2.5 집락 샘플링

**집락 샘플링**은 모집단을 상자, 팔레트, 생산 묶음과 같은 집락으로 구분하고 일부 집락을 선택하여 조사하는 방법이야. 넓은 장소에 제품이 분산되어 있을 때 비용을 절감하기 좋지만, 선택된 집락이 전체 모집단과 다르면 오차가 커질 수 있어.

층별 샘플링은 보통 **각 층에서 표본을 뽑아 모든 층을 반영**하려는 방법이고, 집락 샘플링은 **일부 집락을 선택하여 조사**하는 방법이라는 차이를 기억해.

### 2.6 샘플링오차와 비샘플링오차

**샘플링오차**는 모집단 전체가 아니라 일부 표본만 관찰했기 때문에 발생하는 우연한 차이야. 같은 로트에서 같은 크기의 표본을 다시 뽑아도 부적합품 수가 달라질 수 있어.

표본의 부적합품률은 다음과 같아.

**표본부적합품률 = 표본의 부적합품 수 ÷ 표본 크기**

표본 크기가 n = 100이고 부적합품이 d = 4개라면 표본부적합품률은 다음과 같아.

**4 ÷ 100 = 0.04 = 4%**

하지만 모집단의 실제 부적합품률이 반드시 4%라는 뜻은 아니야. 표본을 다시 추출하면 2%, 5% 또는 다른 값이 나올 수 있어.

**비샘플링오차**는 표본추출 이외의 원인으로 발생해. 측정기 교정 불량, 검사자의 판정 착오, 기록 오류, 불량한 표본추출 절차가 여기에 해당해. 표본 크기를 늘리면 샘플링오차는 일반적으로 줄어들지만, 측정기를 잘못 사용해서 생기는 비샘플링오차까지 자동으로 사라지지는 않아.

### 2.7 샘플링편의

**샘플링편의**는 특정 방향으로 결과가 지속해서 치우치는 체계적 오류야. 샘플링오차가 표본추출에 따른 우연한 흔들림이라면, 편의는 추출방법 자체가 잘못되어 생기는 방향성 있는 왜곡이라고 볼 수 있어.

예를 들어 상자 윗부분의 제품만 추출한다면 운송 중 아래쪽에 눌린 제품의 결함을 놓칠 수 있어. 표본 수를 10개에서 100개로 늘려도 계속 윗부분만 뽑는다면 편의는 해결되지 않아.

### 2.8 비교와 경계

| 구분 | 샘플링오차 | 비샘플링오차·편의 |
|---|---|---|
| 주된 원인 | 일부 표본만 관찰 | 측정, 기록, 판정, 추출절차의 문제 |
| 성격 | 우연한 변동 | 체계적 왜곡이 포함될 수 있음 |
| 표본 크기 증가 효과 | 일반적으로 감소 | 반드시 감소하지 않음 |
| 주요 대책 | 적절한 표본 크기와 확률표본추출 | 표준화, 교정, 교육, 절차 개선 |

### 2.9 시험 함정

1. 표본 크기를 늘리면 샘플링오차는 일반적으로 감소하지만 모든 오류가 제거되는 것은 아니야.
2. 편의가 있는 추출방법에서는 큰 표본도 잘못된 결론을 만들 수 있어.
3. 계통 샘플링에서는 생산주기와 추출간격의 일치를 점검해야 해.
4. 층별 샘플링과 집락 샘플링은 같은 방법이 아니야.
5. 표본부적합품률은 모집단 부적합품률의 추정치이지 항상 동일한 값은 아니야.

## 3. 샘플링검사와 OC곡선

### 3.1 계수형 1회 샘플링검사

계수형 1회 샘플링검사에서는 로트에서 **n개**를 한 번 추출하여 부적합품 수 **d**를 세고, 미리 정한 **합격판정개수 c**와 비교해.

판정규칙은 다음과 같아.

1. **d ≤ c이면 로트 합격**
2. **d > c이면 로트 불합격**

예를 들어 샘플링검사 방식이 n = 50, c = 1이라고 하자.

| 표본의 부적합품 수 d | 판정 |
|---:|---|
| 0 | 합격 |
| 1 | 합격 |
| 2 | 불합격 |
| 3 | 불합격 |

여기서 자주 틀리는 부분은 c의 의미야. c는 허용할 수 있는 **로트 전체의 부적합품 수**가 아니라, 표본에서 발견되어도 합격시킬 수 있는 **최대 부적합품 수**야.

### 3.2 OC곡선의 정의

**OC곡선**, 즉 검사특성곡선은 로트의 품질 수준과 그 로트가 합격할 확률의 관계를 나타내는 곡선이야.

가로축에는 보통 로트의 부적합품률 **p**, 세로축에는 로트의 합격확률 **Pa**를 표시해.

품질이 매우 좋은 로트에서는 p가 작으므로 합격확률 Pa가 높아. 품질이 나빠져 p가 커지면 표본에서 많은 부적합품이 발견될 가능성이 커지므로 Pa는 낮아져. 따라서 일반적인 OC곡선은 왼쪽 위에서 오른쪽 아래로 내려가는 형태야.

OC곡선은 특정 로트 하나의 실제 합격 여부를 예언하는 곡선이 아니야. 동일한 품질 수준의 로트에 같은 샘플링검사 방식을 반복 적용했을 때 나타나는 **장기적인 합격확률**을 표현해.

### 3.3 이항분포에 의한 합격확률

로트가 충분히 크고 각 제품이 부적합일 확률을 p로 볼 수 있다면, 표본에서 발견되는 부적합품 수 X를 이항분포로 근사할 수 있어.

**X는 표본 크기 n과 부적합품률 p를 따르는 이항확률변수**라고 생각하면 돼.

합격 조건이 X ≤ c이므로 합격확률은 다음과 같아.

**Pa = P(X ≤ c)**

이를 전개하면 다음과 같아.

**Pa = Σ [x = 0부터 c까지] nCx × pˣ × (1 − p)ⁿ⁻ˣ**

#### 예시: n = 5, c = 0, p = 0.10

c = 0이므로 표본에서 부적합품이 하나도 없어야 합격이야.

**Pa = P(X = 0)**  
**Pa = 5C0 × 0.10⁰ × 0.90⁵**  
**Pa = 0.90⁵ = 0.59049**

따라서 부적합품률이 10%인 로트가 이 검사에서 합격할 확률은 약 **59.05%**야.

#### 예시: n = 5, c = 1, p = 0.10

이번에는 부적합품이 0개 또는 1개이면 합격이야.

**Pa = P(X = 0) + P(X = 1)**

**P(X = 0) = 0.90⁵ = 0.59049**

**P(X = 1) = 5C1 × 0.10 × 0.90⁴**  
**P(X = 1) = 5 × 0.10 × 0.6561 = 0.32805**

따라서 다음과 같아.

**Pa = 0.59049 + 0.32805 = 0.91854**

즉, 합격판정개수를 0에서 1로 높이면 같은 품질의 로트가 합격할 확률이 약 59.05%에서 91.85%로 증가해.

### 3.4 초기하분포와 이항분포의 경계

유한한 로트에서 표본을 **비복원추출**하면 정확한 확률모형은 초기하분포야. 로트 크기 N, 로트 내 부적합품 수 D, 표본 크기 n일 때 표본 부적합품 수 X의 확률은 다음과 같이 표현해.

**P(X = x) = [DCx × N−D C n−x] ÷ NCn**

반면 로트가 표본보다 충분히 크면 각 추출의 부적합확률이 거의 일정하다고 보아 이항분포로 근사할 수 있어.

시험에서는 문제에 주어진 조건과 분포를 확인해야 해. 단순히 샘플링검사라는 말만 보고 항상 이항분포를 쓰는 것은 위험해.

### 3.5 생산자위험과 소비자위험

샘플링검사는 확률적인 판정이므로 두 종류의 위험이 생겨.

**생산자위험 α**는 좋은 품질의 로트가 불합격될 확률이야. 생산자 입장에서는 좋은 제품을 만들었는데 거부당하는 손실이므로 생산자위험이라고 불러.

**소비자위험 β**는 나쁜 품질의 로트가 합격될 확률이야. 소비자 입장에서는 나쁜 로트를 받아들일 위험이므로 소비자위험이라고 불러.

일반적으로 다음 관계를 기억하면 돼.

**AQL에서 Pa = 1 − α**

**LTPD 또는 나쁜 로트 품질 수준에서 Pa = β**

| 위험 | 의미 | OC곡선에서의 관계 |
|---|---|---|
| 생산자위험 α | 좋은 로트를 불합격시킬 확률 | 좋은 품질 수준에서 1 − Pa |
| 소비자위험 β | 나쁜 로트를 합격시킬 확률 | 나쁜 품질 수준에서 Pa |

### 3.6 AQL과 LTPD

**AQL**은 합격품질한계 또는 합격품질수준의 문맥에서 사용되며, 만족스러운 공정 평균으로 간주되는 좋은 품질 수준을 나타내는 기준이야. 이 품질의 로트도 항상 합격하는 것은 아니고 생산자위험 α만큼 불합격될 수 있어.

**LTPD**는 로트허용불량률로, 소비자가 받아들이고 싶지 않은 나쁜 품질 수준을 나타내. 이 품질의 로트도 소비자위험 β만큼 합격할 수 있어.

좋은 로트와 나쁜 로트를 완벽하게 구분하는 수직선 형태의 OC곡선은 현실적인 유한 표본검사에서 얻기 어려워. 표본에 우연성이 있기 때문에 두 품질 수준 사이에는 완만한 전이구간이 생겨.

### 3.7 n과 c가 OC곡선에 미치는 영향

다른 조건이 같을 때 **합격판정개수 c를 크게 하면** 합격기준이 느슨해져 모든 품질 수준에서 합격확률이 커져. 생산자에게는 유리하지만 나쁜 로트가 합격할 가능성도 커질 수 있어.

다른 조건이 같고 판정기준을 적절히 설계할 때 **표본 크기 n을 크게 하면** 로트의 품질 차이를 더 잘 구별할 수 있어. OC곡선의 전이구간이 더 가파르게 되어 좋은 로트와 나쁜 로트에 대한 판별력이 높아져.

다만 n만 단독으로 바꾸면 합격확률 전체가 이동할 수 있으므로 실제 설계에서는 n과 c를 함께 조정하여 원하는 α와 β를 만족시켜야 해.

### 3.8 비교와 경계

OC곡선이 가파르다는 것은 품질 수준의 작은 차이에 대해 합격확률이 크게 변한다는 뜻이야. 즉 **판별력이 높다**는 의미지, 모든 좋은 로트를 합격시키고 모든 나쁜 로트를 불합격시키는 완전한 검사를 의미하지는 않아.

또한 α와 β는 서로 다른 품질점에서 정의돼. 같은 한 점에서 α와 β를 단순히 더하여 1이라고 생각하면 안 돼. α는 좋은 품질 수준에서, β는 나쁜 품질 수준에서 읽어야 해.

### 3.9 시험 함정

1. OC곡선의 세로축은 일반적으로 **로트 합격확률 Pa**야.
2. 부적합품률 p가 증가하면 일반적으로 Pa는 감소해.
3. 생산자위험은 **좋은 로트의 불합격확률**이야.
4. 소비자위험은 **나쁜 로트의 합격확률**이야.
5. AQL에서 합격확률은 일반적으로 **1 − α**야.
6. 나쁜 품질 수준에서 합격확률은 **β**야.
7. c를 크게 하면 합격판정이 느슨해져 Pa가 증가해.
8. c는 로트 전체가 아니라 **표본에서 허용되는 최대 부적합품 수**야.
9. 유한 로트의 비복원추출에는 초기하분포가 정확한 모형이야.
10. OC곡선은 개별 로트의 확정적 결과가 아니라 반복검사의 장기적인 확률 특성을 나타내.

# 정답 및 해설

## 문제 1 정답: 2

파괴검사는 검사한 제품을 정상적으로 사용할 수 없게 만들기 때문에 전수검사가 곤란해. 따라서 일부 표본만 검사하는 샘플링검사가 적합해.

## 문제 2 정답: 20

**k = N ÷ n = 2,000 ÷ 100 = 20**

첫 추출번호를 무작위로 정한 뒤 대략 20개 간격으로 추출하면 돼. 다만 생산공정에 20개 단위의 주기가 있는지는 별도로 확인해야 해.

## 문제 3 정답: 3%

**표본부적합품률 = 6 ÷ 200 = 0.03 = 3%**

이 값은 표본에서 관찰된 비율이며, 로트 전체의 실제 부적합품률과 반드시 일치하지는 않아.

## 문제 4 정답: 3

표본 크기를 늘리면 우연한 샘플링오차는 일반적으로 줄어들어. 그러나 측정기가 잘못 교정되어 있다면 표본을 더 많이 측정해도 체계적인 측정오차가 계속 발생해.

## 문제 5 정답: 불합격

합격 조건은 **d ≤ c**야. 여기서는 d = 3이고 c = 2이므로 3 > 2가 되어 로트는 불합격이야.

## 문제 6 정답: 0.4096

c = 0이므로 표본 네 개가 모두 적합해야 해.

**Pa = P(X = 0) = (1 − 0.20)⁴ = 0.80⁴ = 0.4096**

따라서 합격확률은 **40.96%**야.

## 문제 7 정답: 0.05 또는 5%

좋은 품질 수준에서는 **Pa = 1 − α**이므로 다음과 같아.

**α = 1 − 0.95 = 0.05**

## 문제 8 정답: 0.10 또는 10%

소비자위험 β는 나쁜 품질 수준의 로트가 합격할 확률이야. 따라서 β = 0.10이야.

## 문제 9 정답: 증가한다

c가 커지면 표본에서 더 많은 부적합품이 발견되어도 로트를 합격시키므로 판정기준이 느슨해져. 따라서 같은 품질 수준에서 합격확률 Pa는 일반적으로 증가해.

# 요약

1. **검사개요:** 검사는 품질특성을 측정하고 기준과 비교해 적합 여부를 판정하는 활동이야. 검사는 품질정보를 제공하지만 품질을 직접 만들어 내지는 않아.

2. **전수검사와 샘플링검사:** 전수검사는 전체를 확인하고, 샘플링검사는 일부 표본으로 로트 전체의 합격 여부를 결정해. 파괴검사와 대형 로트에는 샘플링검사가 유리해.

3. **샘플링방법과 샘플링오차:** 단순 랜덤, 계통, 층별, 집락 샘플링은 서로 다른 추출 논리를 가져. 대표성을 확보하려면 편의와 공정의 주기성을 통제해야 해.

4. **오차의 구별:** 샘플링오차는 일부만 관찰해서 생기는 우연한 변동이야. 측정오차나 판정오류 같은 비샘플링오차는 표본 크기를 키운다고 자동으로 사라지지 않아.

5. **샘플링검사와 OC곡선:** OC곡선은 로트 부적합품률 p와 로트 합격확률 Pa의 관계를 보여 줘. p가 커지면 Pa는 일반적으로 작아져.

6. **판정규칙:** 계수형 1회 샘플링검사에서는 표본 부적합품 수 d가 합격판정개수 c 이하이면 합격이야.

7. **위험:** 생산자위험 α는 좋은 로트의 불합격확률이고, 소비자위험 β는 나쁜 로트의 합격확률이야.

8. **계산 핵심:** 이항분포를 적용할 때 합격확률은 **Pa = P(X ≤ c)**야. 문제를 풀 때는 0개부터 c개까지의 확률을 모두 더해야 해.

9. **가장 중요한 시험 구별:** **α는 좋은 로트를 거절할 위험, β는 나쁜 로트를 받아들일 위험**이야. 둘을 뒤집지 않도록 생산자와 소비자의 손실을 떠올리면 돼.

여기까지 이해했다면 샘플링검사를 단순한 표본추출이 아니라, 두 종류의 판단 위험을 관리하는 확률적 계약으로 볼 수 있어. 계산식보다 먼저 **누가 어떤 잘못된 판정 때문에 손해를 보는가**를 생각하면 문제의 구조가 훨씬 쉽게 보여. 어려운 부분인데도 잘 따라왔어 😊
