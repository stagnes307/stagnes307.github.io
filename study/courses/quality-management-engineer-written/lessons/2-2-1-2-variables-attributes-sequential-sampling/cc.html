🧭 샘플링검사의 공통 판정 구조

샘플링검사는 로트에서 크기 n의 표본을 무작위로 추출하고, 그 결과를 미리 정한 합격기준과 비교해 로트 전체를 판정하는 방법이야. 표본에는 우연한 변동이 있으므로 표본의 판정과 로트의 실제 상태가 언제나 일치하는 것은 아니야.

좋은 로트가 불합격되는 확률은 생산자위험 α이고, 나쁜 로트가 합격되는 확률은 소비자위험 β야. 좋은 품질수준을 p₀ 또는 AQL, 나쁜 품질수준을 p₁ 또는 LTPD로 나타내면 대표적인 설계조건은 L(p₀) = 1 − α와 L(p₁) = β가 돼.

샘플링검사의 위험과 합격확률
구분 의미 연결되는 품질수준
생산자위험 α 좋은 로트를 불합격시키는 확률 AQL 또는 p₀
소비자위험 β 나쁜 로트를 합격시키는 확률 LTPD 또는 p₁
합격확률 L(p) 불량률 p인 로트가 합격할 확률 OC곡선의 세로축

시험 함정

생산자위험은 나쁜 로트를 합격시키는 위험이 아니라 좋은 로트를 불합격시키는 위험이야. 소비자위험은 나쁜 로트를 합격시키는 위험이고, OC곡선에서는 일반적으로 불량률 p가 증가할수록 합격확률 L(p)가 감소해.

📏 계량값 샘플링검사

정의와 원리

계량값 샘플링검사는 길이, 무게, 인장강도, 순도처럼 연속적인 수치로 측정되는 품질특성을 사용해. 표본의 평균과 표준편차를 규격한계와 비교하기 때문에 단순히 불량품의 개수만 세는 방법보다 개별 관측값의 정보를 더 많이 활용할 수 있어.

예를 들어 볼트 지름의 상한규격이 10.20 mm라면 각 볼트의 지름을 측정해 표본평균과 산포를 함께 평가할 수 있어. 다만 측정기기가 필요하고 정규분포와 같은 분포 가정이 요구될 수 있다는 경계도 기억해야 해.

상한규격과 하한규격의 판정식

상한규격을 U, 공정표준편차를 σ, 합격판정계수를 k라고 하면 대표적인 상한규격형 합격조건은 x̄ ≤ U − kσ야. 같은 식을 표준화하면 (U − x̄) / σ ≥ k가 돼. k가 커질수록 U − kσ가 작아지므로 판정은 더 엄격해져.

하한규격을 L이라고 하면 대표적인 합격조건은 x̄ ≥ L + kσ이며, 표준화하면 (x̄ − L) / σ ≥ k가 돼. σ를 모르는 경우에는 표본표준편차 s를 사용하는 검사방식이 필요하지만, s에도 표본변동이 있으므로 σ를 기계적으로 s로 바꾸는 것만으로 검사계획이 완성되지는 않아.

합격확률 계산

모집단이 평균 μ, 표준편차 σ인 정규분포를 따를 때 표본크기가 n이면 표본평균은 x̄ ∼ N(μ, σ²/n)을 따라. 따라서 표본평균의 표준오차는 σ/√n이야. 상한규격형의 합격확률은 L(μ) = Φ[{U − kσ − μ}/{σ/√n}]으로 계산할 수 있어.

구체적인 예시

상한규격 U = 105, 공정표준편차 σ = 4, 합격판정계수 k = 1.5라면 합격한계는 105 − 1.5 × 4 = 99야. 표본평균이 98이면 98 ≤ 99이므로 합격이고, 표본평균이 100이면 조건을 만족하지 못하므로 불합격이야.

비교와 경계

계량값 검사와 계수값 검사의 비교
항목 계량값 샘플링검사 계수값 샘플링검사
관측자료 길이와 무게 같은 연속형 수치 불량품 수 또는 결점 수

시험 함정

표본평균이 규격 내부에 있다는 사실만으로 반드시 합격하는 것은 아니야. 평균과 규격한계 사이에 산포를 고려한 여유가 필요해. 또한 표본평균의 표준편차는 σ가 아니라 σ/√n이라는 점을 놓치지 마.

🔢 계수값 샘플링검사

정의와 자료의 종류

계수값 샘플링검사는 제품을 적합품과 부적합품으로 분류하거나 제품에서 발견된 결점의 수를 세어 로트를 판정해. 부적합품수는 제품 단위의 개수이고, 결점수는 결점 자체의 개수야. 한 제품에 결점이 세 개 있다면 부적합품은 한 개지만 결점은 세 개가 될 수 있어.

1회 계수값 검사계획

기본적인 1회 검사계획은 (n, c)로 표시해. n은 표본크기, c는 합격판정개수야. 표본에서 발견된 부적합품수를 d라고 할 때 d ≤ c이면 합격하고 d ≥ c + 1이면 불합격해.

각 제품이 독립적으로 불량일 확률이 p이고 모집단이 충분히 크면 부적합품수 X는 이항분포 B(n, p)로 모델링할 수 있어. 로트 합격확률은 L(p) = P(X ≤ c)이며, 구체적으로 x = 0부터 c까지 C(n, x)pˣ(1 − p)ⁿ⁻ˣ을 더해 구해.

구체적인 예시

검사계획이 n = 50, c = 2라면 표본에서 불량품이 0개, 1개 또는 2개 발견될 때 합격하고 3개 이상이면 불합격이야. 로트 불량률이 p = 0.02라면 L(0.02) = P(X ≤ 2)이고, 계산값은 약 0.922야.

초기하분포와 이항분포의 경계

유한한 로트에서 비복원추출을 하고 로트 크기 N과 부적합품수 D가 알려져 있다면 정확한 분포는 초기하분포야. P(X = x) = C(D, x)C(N − D, n − x)/C(N, n)이며, 로트 크기가 표본크기보다 충분히 클 때 이항분포로 근사할 수 있어.

결점수와 푸아송분포

일정한 범위에서 결점이 독립적으로 드물게 발생하고 평균 결점수가 λ라면 푸아송분포를 적용할 수 있어. P(X = x) = e−λλx/x!이며, 검사단위가 n개이고 단위당 평균 결점수가 u라면 전체 평균은 λ = nu가 될 수 있어.

검사계획 변화의 효과

시험 함정

c는 불합격판정개수가 아니라 합격판정개수야. 불합격은 일반적으로 c + 1개부터 시작해. 또한 부적합품수와 결점수를 혼동하지 말고, 추출조건에 따라 이항분포와 초기하분포를 구별해야 해.

⏩ 축차샘플링검사

정의와 핵심 아이디어

축차샘플링검사는 제품을 한 개씩 또는 작은 묶음씩 차례로 검사하고, 각 단계의 누적 결과에 따라 합격, 불합격, 검사 계속 가운데 하나를 결정해. 품질이 매우 좋거나 매우 나쁜 로트에서는 조기에 판정이 끝날 가능성이 커.

품질수준이 판정 경계에 가까우면 계속검사영역에 오래 머물 수 있어. 따라서 축차검사가 모든 품질수준에서 언제나 가장 작은 표본을 요구한다고 단정할 수는 없어. 효율은 특정 품질수준에서 필요한 표본수의 기댓값인 평균표본수 ASN으로 평가할 수 있어.

판정선의 구조

n개까지 검사한 누적불량품수를 dₙ이라고 하면 대표적인 판정식은 합격선 dₙ ≤ an + b₁과 불합격선 dₙ ≥ an + b₂야. 두 선 사이에 있으면 검사를 계속해. 일반적으로 b₁은 b₂보다 작아서 두 평행선 사이에 계속검사영역이 만들어져.

확률비의 원리

좋은 품질수준을 p₀, 나쁜 품질수준을 p₁이라고 하면 p₀ < p₁이야. 누적표본수 n과 누적불량품수 d에 대한 우도비는 Λ = [p₁d(1 − p₁)n−d]/[p₀d(1 − p₀)n−d] 형태로 계산해. Λ가 충분히 작으면 합격하고, 충분히 크면 불합격하며, 그 사이에서는 검사를 계속해.

대표적인 확률비 경계는 합격 쪽에 β/(1 − α), 불합격 쪽에 (1 − β)/α를 사용해. 로그를 취하면 곱셈 구조가 직선식으로 변환되어 누적표본수와 누적불량품수 평면에 두 개의 판정선을 그릴 수 있어.

판정 절차

  1. 제품을 무작위로 한 개 또는 정해진 묶음만큼 검사해.
  2. 누적검사개수 n과 누적불량품수 dₙ을 갱신해.
  3. dₙ이 합격영역에 들어가면 로트를 합격시켜.
  4. dₙ이 불합격영역에 들어가면 로트를 불합격시켜.
  5. 두 영역 사이에 있으면 다음 제품을 검사해.
  6. 절단점이 있는 계획은 최대 표본크기에서 지정된 절단판정을 적용해.

구체적인 예시

현재 단계의 합격선이 1.4이고 불합격선이 4.2라면 누적불량품수 1은 합격, 3은 검사 계속, 5는 불합격이야. 누적불량품수는 정수이므로 실제 판정은 1개 이하 합격, 2개부터 4개까지 계속, 5개 이상 불합격으로 해석할 수 있어.

🧩 세 검사법의 구별 기준

측정값이 10.02 mm처럼 수치로 주어지고 평균과 산포를 사용하면 계량값 샘플링검사야. 불량품이나 결점의 개수를 세고 n과 c를 사용하면 계수값 샘플링검사야. 제품을 순서대로 조사하면서 누적표본수와 누적불량품수로 매 단계 판정하면 축차샘플링검사야.

🧮 계산 문제 풀이 절차

계량값 샘플링검사

  1. 상한규격형인지 하한규격형인지 확인해.
  2. σ가 알려졌는지 s를 사용하는지 구분해.
  3. 판정계수 k를 이용해 합격한계를 계산해.
  4. 표본평균을 올바른 부등호로 비교해.
  5. 합격확률은 표준오차 σ/√n으로 표준화해.

계수값 샘플링검사

  1. 표본크기 n과 합격판정개수 c를 찾아.
  2. 관측한 부적합품수 d를 c와 비교해.
  3. 합격확률은 P(X ≤ c)로 계산해.
  4. 추출조건에 따라 이항분포와 초기하분포를 구별해.
  5. 결점수 모형에서는 λ의 검사범위를 확인해.

축차샘플링검사

  1. 누적표본수 n을 확인해.
  2. 누적불량품수 dₙ을 계산해.
  3. 현재 단계의 합격선과 불합격선을 계산해.
  4. 합격선 이하, 불합격선 이상, 두 선 사이를 구분해.
  5. 두 선 사이라면 검사를 계속해.

문제 3

n = 20, c = 0인 검사계획에서 제품의 불량확률이 p = 0.01이고 서로 독립이라면 로트 합격확률은 얼마일까?

  1. 0.0120
  2. 0.9920
  3. 1 − 0.9920
  4. 20 × 0.01

문제 4

유한한 로트에서 비복원추출을 하며 로트 크기와 부적합품수와 표본크기가 모두 주어졌어. 정확한 확률분포는 무엇일까?

  1. 정규분포
  2. 초기하분포
  3. 지수분포

문제 5

축차검사의 현재 단계에서 합격선이 2.3, 불합격선이 5.1이고 누적불량품수가 4라면 판정은 무엇일까?

  1. 합격
  2. 불합격
  3. 검사 계속
  4. 표본 전체 폐기

문제 6

다음 설명 중 옳지 않은 것을 골라봐.

  1. 계량값 검사는 측정된 수치와 산포를 활용할 수 있다.
  2. 계수값 1회 검사에서 d ≤ c이면 일반적으로 합격한다.
  3. 축차검사는 모든 품질수준에서 반드시 고정표본검사보다 적은 표본을 조사한다.
  4. 소비자위험은 나쁜 로트가 합격할 확률과 관련된다.

✅ 정답 및 해설

문제 1 정답: 1. 합격

합격한계는 50 − 1.5 × 2 = 47이야. 표본평균 46.5는 47 이하이므로 합격이야.

문제 2 정답: 2. 불합격

c = 3이므로 부적합품수가 3개 이하면 합격이야. 4개는 c + 1이므로 불합격이야.

문제 3 정답: 2. 0.99²⁰

c = 0이면 표본에 불량품이 하나도 없어야 해. 제품 하나가 양품일 확률은 0.99이므로 20개가 모두 양품일 확률은 0.9920이야.

문제 4 정답: 2. 초기하분포

유한 모집단에서 비복원추출을 할 때 표본에 포함된 부적합품수의 정확한 분포는 초기하분포야.

문제 5 정답: 3. 검사 계속

누적불량품수 4는 합격선 2.3보다 크고 불합격선 5.1보다 작아. 두 판정선 사이의 계속검사영역에 있으므로 검사를 계속해야 해.

문제 6 정답: 3

축차검사는 품질이 매우 좋거나 매우 나쁠 때 조기종료될 수 있지만, 판정 경계에 가까우면 검사량이 커질 수 있어. 언제나 더 적은 표본을 조사한다고 단정할 수 없어.

✨ 요약

  • 계량값 샘플링검사: 측정값의 평균과 표준편차를 사용하며 규격한계와 산포를 함께 비교해.
  • 계수값 샘플링검사: 검사계획 (n, c)에서 d ≤ c이면 합격하고 d ≥ c + 1이면 불합격해.
  • 분포 선택: 독립적인 부적합품수는 이항분포, 유한 로트의 비복원추출은 초기하분포, 드문 결점수는 푸아송분포와 연결돼.
  • 축차샘플링검사: 누적표본수와 누적불량품수로 합격·불합격·검사 계속을 매 단계 판정해.
  • 위험의 구별: 생산자위험은 좋은 로트의 불합격, 소비자위험은 나쁜 로트의 합격과 관련돼.
  • 시험 전략: 자료 형태, 판정기준, 부등호, 누적값, 확률분포의 순서로 확인하면 계산 실수를 줄일 수 있어.

계량값, 계수값, 축차라는 세 갈래를 자료의 형태와 판정 시점으로 먼저 나누면 공식들이 하나의 지도처럼 연결될 거야. 복잡해 보여도 여기까지 잘 따라왔어! 😊
