## 1. 샘플링검사의 공통 판정 구조

샘플링검사는 로트에서 크기 n의 표본을 무작위로 뽑아 조사한 뒤, 그 결과가 미리 정한 합격 기준을 만족하면 로트를 합격시키는 방식이야. 중요한 점은 표본의 판정과 로트 전체의 실제 상태가 완전히 일치한다고 보장할 수 없다는 거야. 표본에는 우연한 변동이 존재하기 때문이지.

좋은 로트가 표본 결과 때문에 불합격될 가능성을 생산자위험 α라고 해. 반대로 나쁜 로트가 우연히 좋은 표본을 만나 합격될 가능성을 소비자위험 β라고 해.

| 구분 | 의미 | 주로 연결되는 품질수준 |
|---|---|---|
| 생산자위험 α | 좋은 로트를 불합격시키는 확률 | AQL 또는 p₀ |
| 소비자위험 β | 나쁜 로트를 합격시키는 확률 | LTPD 또는 p₁ |
| 로트 합격확률 L(p) | 불량률이 p인 로트가 합격할 확률 | OC곡선의 세로축 |
| 로트 불합격확률 | 1 − L(p) | 합격확률의 여사건 |

AQL은 만족스러운 공정의 기준이 되는 품질수준이고, LTPD는 소비자가 받아들이기 어려운 나쁜 품질수준이야. 전형적인 설계 조건은 다음과 같아.

L(p₀) = 1 − α

L(p₁) = β

### 시험 함정

생산자위험은 나쁜 로트를 합격시키는 위험이 아니야. 좋은 로트를 불합격시키는 위험이야.

소비자위험은 좋은 로트를 불합격시키는 위험이 아니라, 나쁜 로트를 합격시키는 위험이야.

OC곡선에서 가로축 불량률 p가 증가하면 일반적으로 로트 합격확률 L(p)는 감소해.

# 2. 계량값 샘플링검사

## 2.1 정의와 원리

계량값 샘플링검사는 제품의 길이, 무게, 인장강도, 순도처럼 연속적인 수치로 측정되는 품질특성을 이용해 로트를 판정하는 방법이야. 표본평균과 표준편차가 규격한계로부터 얼마나 떨어져 있는지를 계산해 합격 여부를 결정하지.

예를 들어 볼트 지름의 상한규격이 10.20 mm라면 단순히 규격을 벗어난 볼트 수만 세는 대신, 표본의 지름을 모두 측정해 평균과 산포를 함께 평가할 수 있어. 그래서 같은 표본크기라면 계수값 검사보다 많은 정보를 얻는 경우가 많아.

다만 측정기기가 필요하고, 정규분포와 같은 분포 가정이 요구될 수 있어. 측정비용이 크거나 품질특성을 정확히 수치화하기 어려운 경우에는 계수값 검사가 더 적합할 수 있어.

## 2.2 기본 판정식

상한규격 U만 존재하고 공정표준편차 σ를 알고 있다고 해보자. 품질이 나빠질수록 평균이 상한에 가까워지는 경우에는 일반적으로 다음 형태로 판정해.

표본평균 x̄ ≤ U − kσ이면 합격

이를 표준화하면 다음과 같아.

(U − x̄) / σ ≥ k이면 합격

여기서 k는 합격판정계수야. k가 커질수록 평균이 규격한계에서 더 멀리 떨어져 있어야 하므로 판정이 엄격해져.

하한규격 L만 존재하고 평균이 너무 낮아지는 것이 문제라면 다음과 같이 판정해.

x̄ ≥ L + kσ이면 합격

(x̄ − L) / σ ≥ k이면 합격

σ를 모르는 경우에는 표본표준편차 s를 사용하도록 설계된 방식이 적용될 수 있어. 이때 σ를 단순히 s로 바꾸는 것만으로 모든 검사표가 완성되는 것은 아니야. s 자체에도 표본변동이 있기 때문에 표본크기와 검사규격에 맞는 판정절차를 사용해야 해.

## 2.3 합격확률 계산

모집단이 평균 μ, 표준편차 σ인 정규분포를 따르고, 표본크기가 n이면 표본평균의 분포는 다음과 같아.

x̄ ∼ N(μ, σ²/n)

상한규격형에서 합격조건이 x̄ ≤ U − kσ라면 로트의 합격확률은 다음과 같이 구해.

L(μ) = P(x̄ ≤ U − kσ)

표준화하면 다음과 같아.

L(μ) = Φ[{U − kσ − μ} / {σ/√n}]

Φ는 표준정규분포의 누적분포함수야.

### 구체적인 예시

상한규격 U = 105, 공정표준편차 σ = 4, 합격판정계수 k = 1.5라고 하자. 표본평균이 x̄ = 98이면 합격한계는 다음과 같아.

U − kσ = 105 − 1.5 × 4 = 99

98 ≤ 99이므로 로트는 합격이야.

표본평균이 100이라면 100 ≤ 99를 만족하지 못하므로 불합격이야.

### 비교와 경계

| 항목 | 계량값 샘플링검사 | 계수값 샘플링검사 |
|---|---|---|
| 관측자료 | 길이, 무게와 같은 연속형 수치 | 불량품 수, 결점 수 |
| 정보량 | 개별 측정값과 산포를 활용해 큼 | 분류 결과만 사용해 상대적으로 작음 |
| 표본크기 | 같은 판별력을 목표로 할 때 비교적 작을 수 있음 | 비교적 커질 수 있음 |
| 측정비용 | 측정기기와 시간이 필요함 | 합격·불합격 분류가 쉬울 수 있음 |
| 주요 가정 | 분포와 산포에 관한 가정이 중요함 | 이항분포·초기하분포·푸아송분포를 활용함 |

### 시험 함정

표본평균이 규격 안에 있다는 사실만으로 반드시 합격하는 것은 아니야. 평균과 규격한계 사이에 산포를 고려한 충분한 여유가 있어야 해.

상한규격형에서 k가 증가하면 합격조건은 더 엄격해져. U − kσ가 작아지기 때문이야.

표본평균의 표준편차는 σ가 아니라 σ/√n이야.

# 3. 계수값 샘플링검사

## 3.1 정의와 자료의 종류

계수값 샘플링검사는 제품을 적합품과 부적합품으로 분류하거나, 제품에서 발견된 결점의 수를 세어 로트를 판정하는 방법이야.

부적합품수 검사는 제품 단위의 판정이야. 한 제품에 결점이 여러 개 있어도 그 제품을 부적합품 한 개로 세어.

결점수 검사는 결점 자체를 세어. 한 제품에 세 개의 결점이 있으면 결점 세 개로 기록할 수 있어.

따라서 부적합품수와 결점수는 같은 개념이 아니야. 시험에서 둘을 섞으면 분포 선택과 계산식이 함께 틀어질 수 있어.

## 3.2 1회 계수값 샘플링검사

가장 기본적인 1회 샘플링검사 계획은 (n, c)로 표시해.

n은 표본크기이고 c는 합격판정개수야. 표본에서 발견된 부적합품수를 d라고 하면 판정은 다음과 같아.

d ≤ c이면 로트 합격

d ≥ c + 1이면 로트 불합격

모집단이 매우 크고 각 제품이 독립적으로 불량일 확률이 p라면 표본의 부적합품수 X는 보통 이항분포로 모델링해.

X ∼ B(n, p)

따라서 로트 합격확률은 다음과 같아.

L(p) = P(X ≤ c)

L(p) = Σ[x=0부터 c까지] C(n, x)pˣ(1 − p)ⁿ⁻ˣ

이 식을 p에 따라 그린 것이 OC곡선이야.

### 구체적인 예시

검사계획이 n = 50, c = 2라고 하자.

표본에서 불량품이 0개, 1개 또는 2개 발견되면 합격이야. 3개 이상이면 불합격이지.

로트 불량률이 p = 0.02라면 합격확률은 다음과 같아.

L(0.02) = P(X ≤ 2)

= P(X = 0) + P(X = 1) + P(X = 2)

= 0.98⁵⁰ + 50(0.02)(0.98⁴⁹) + C(50, 2)(0.02)²(0.98⁴⁸)

약 0.922가 돼. 즉, 불량률이 2%인 상태에서 이 검사계획을 적용하면 로트가 합격할 확률은 약 92.2%야.

## 3.3 초기하분포와 이항분포의 경계

유한한 로트에서 비복원추출을 하고 로트 크기 N과 로트 내 부적합품수 D가 알려져 있다면 정확한 부적합품수 분포는 초기하분포야.

P(X = x) = C(D, x)C(N − D, n − x) / C(N, n)

따라서 합격확률은 x = 0부터 c까지의 확률을 더해 구해.

로트 크기가 표본크기보다 충분히 크면 이항분포로 근사할 수 있어. 시험에서 모집단이 유한하고 비복원추출이라는 조건을 강조한다면 초기하분포를 먼저 떠올려야 해.

## 3.4 결점수 검사와 푸아송분포

일정한 단위당 평균 결점수가 λ이고 결점이 독립적이며 드물게 발생한다면 결점수 X를 푸아송분포로 모델링할 수 있어.

P(X = x) = e⁻λ λˣ / x!

검사단위가 n개이고 단위당 평균 결점수가 u라면 전체 평균 결점수는 nu가 될 수 있어. 따라서 어떤 λ를 사용해야 하는지 검사단위의 범위를 확인해야 해.

### 검사계획 변화의 효과

| 변화 | 합격판정의 일반적 효과 |
|---|---|
| n 증가, c 고정 | 같은 불량률에서 불량품이 더 많이 발견되기 쉬워 합격확률 감소 |
| c 증가, n 고정 | 더 많은 불량품을 허용하므로 합격확률 증가 |
| p 증가 | 일반적으로 합격확률 감소 |
| 표본 전수 양품 요구 c = 0 | 불량품 하나만 발견되어도 불합격 |

### 시험 함정

c는 불합격판정개수가 아니라 합격판정개수야. 불합격은 일반적으로 c + 1개부터 시작해.

불량률 p가 높아지면 OC곡선의 합격확률은 높아지는 것이 아니라 낮아져.

부적합품수는 이항분포와 연결되고, 결점수는 푸아송분포와 자주 연결돼. 단, 구체적인 표본추출 조건을 먼저 확인해야 해.

# 4. 축차샘플링검사

## 4.1 정의와 핵심 아이디어

축차샘플링검사는 제품을 한 개씩 또는 작은 묶음씩 차례로 검사하고, 각 단계의 누적 결과에 따라 합격, 불합격 또는 검사 계속을 결정하는 방법이야. 영어로는 Sequential Sampling Inspection이라고 해.

처음부터 표본크기를 하나로 고정하는 1회 검사와 달리, 충분한 증거가 모이면 조기에 판정을 끝낼 수 있어. 품질이 매우 좋거나 매우 나쁜 로트에서는 비교적 적은 검사량으로 결론이 날 가능성이 커.

반면 품질수준이 합격과 불합격의 경계에 가까우면 검사 계속 영역에 오래 머물 수 있어. 따라서 축차검사가 언제나 작은 표본만 요구한다고 단정하면 안 돼.

## 4.2 판정선의 구조

n개를 검사한 시점까지의 누적불량품수를 dₙ이라고 하자. 대표적인 계수형 축차검사에서는 두 개의 판정선을 사용해.

합격선: dₙ ≤ an + b₁이면 합격

불합격선: dₙ ≥ an + b₂이면 불합격

두 선 사이에 있으면 검사를 계속해.

여기서 a는 판정선의 기울기이고 b₁과 b₂는 절편이야. 일반적으로 b₁ < b₂이므로 두 선 사이에 계속검사 영역이 형성돼.

실제 문제에서는 정수인 누적불량품수와 소수로 계산되는 경계선을 비교해야 해. 합격선 이하, 불합격선 이상, 그 사이 중 어느 영역인지 부등호를 정확히 확인해야 해.

## 4.3 확률비의 원리

축차검사의 이론적 기반은 두 품질수준에 대한 우도비를 차례로 비교하는 데 있어. 좋은 품질수준을 p₀, 나쁜 품질수준을 p₁이라고 하고 p₀ < p₁이라 하자.

n개 중 누적불량품수가 d라면 이항모형에서 두 가설의 우도비는 다음과 같은 형태야.

Λ = [p₁ᵈ(1 − p₁)ⁿ⁻ᵈ] / [p₀ᵈ(1 − p₀)ⁿ⁻ᵈ]

Λ가 충분히 작으면 좋은 로트라는 증거가 강하므로 합격하고, 충분히 크면 나쁜 로트라는 증거가 강하므로 불합격해. 두 기준 사이에 있으면 아직 증거가 부족하므로 검사를 계속하지.

판정의 대표적 경계는 생산자위험 α와 소비자위험 β를 사용해 다음과 같이 설정할 수 있어.

합격 쪽 기준: β / (1 − α)

불합격 쪽 기준: (1 − β) / α

로그를 취하면 곱셈 구조가 직선식으로 바뀌어 누적표본수 n과 누적불량품수 d의 평면에서 두 개의 평행한 판정선을 얻을 수 있어.

## 4.4 판정 절차

1. 제품을 무작위로 한 개 또는 정해진 묶음만큼 추출해 검사해.
2. 지금까지 검사한 누적개수 n과 누적불량품수 dₙ을 계산해.
3. dₙ이 합격영역에 들어가면 로트를 합격시켜.
4. dₙ이 불합격영역에 들어가면 로트를 불합격시켜.
5. 두 영역 사이에 있으면 다음 제품을 검사하고 같은 절차를 반복해.
6. 절단점이 설정된 계획이라면 최대 표본크기에 도달했을 때 지정된 절단판정을 적용해.

### 구체적인 예시

어떤 단계에서 합격선이 dₙ ≤ 1.4이고 불합격선이 dₙ ≥ 4.2라고 하자.

누적불량품수 dₙ = 1이면 합격선 이하이므로 합격이야.

dₙ = 3이면 두 판정선 사이이므로 검사를 계속해.

dₙ = 5이면 불합격선 이상이므로 불합격이야.

누적불량품수는 정수이므로 이 단계에서 실제 판정은 1개 이하 합격, 5개 이상 불합격, 2개부터 4개까지 검사 계속으로 해석할 수 있어.

## 4.5 1회·2회·축차검사의 비교

| 검사방식 | 판정 시점 | 장점 | 주의점 |
|---|---|---|---|
| 1회 샘플링검사 | 한 번의 표본조사 후 판정 | 절차와 관리가 단순함 | 처음부터 정해진 표본 전체를 조사함 |
| 2회 샘플링검사 | 첫 표본이 애매하면 두 번째 표본 조사 | 1회 검사보다 평균검사량을 줄일 수 있음 | 누적판정 기준을 구분해야 함 |
| 축차샘플링검사 | 각 관측 또는 작은 묶음마다 판정 | 좋은 로트와 나쁜 로트에서 조기종료 가능 | 경계 부근에서는 검사량이 커질 수 있음 |

축차검사의 효율은 평균표본수 ASN으로 비교할 수 있어. ASN은 특정 품질수준에서 판정이 끝날 때까지 필요한 표본수의 기댓값이야. 단순히 가능한 최대 표본수가 아니라 평균적으로 몇 개를 검사하는지를 뜻해.

### 시험 함정

축차검사에는 합격과 불합격만 있는 것이 아니야. 중간에 검사 계속 영역이 있어.

누적불량품수는 이번에 발견한 불량품수만 의미하지 않아. 지금까지 발견된 불량품의 합계야.

축차검사가 모든 품질수준에서 항상 표본크기를 줄이는 것은 아니야. 경계 품질에서는 판정이 늦어질 수 있어.

# 5. 세 검사법을 한 번에 구별하는 기준

불량품이 2개, 결점이 5개처럼 개수를 센다면 계수값 샘플링검사를 생각해.

제품을 순서대로 조사하면서 누적검사개수와 누적불량품수로 매 단계 판정한다면 축차샘플링검사를 생각해.

| 질문의 단서 | 우선 판단 |
|---|---|
| 평균, 표준편차, 규격상한, 규격하한 | 계량값 샘플링검사 |
| 표본크기 n, 합격판정개수 c, 불량품수 d | 계수값 샘플링검사 |
| 누적표본수, 누적불량품수, 합격선·불합격선 | 축차샘플링검사 |
| P(X ≤ c) | 계수값 검사의 로트 합격확률 |
| σ/√n | 계량값 검사에서 표본평균의 표준오차 |
| 합격·불합격·계속의 세 영역 | 축차샘플링검사 |

# 6. 계산 문제 풀이 루틴

## 계량값 샘플링검사

1. 상한규격형인지 하한규격형인지 확인해.
2. σ가 알려졌는지 s를 사용하는지 구분해.
3. 주어진 판정계수 k로 합격한계를 계산해.
4. 표본평균과 합격한계를 올바른 부등호로 비교해.
5. 합격확률 문제라면 표본평균의 표준오차 σ/√n을 사용해 표준화해.

## 계수값 샘플링검사

1. n과 c를 찾아.
2. 실제 관측값 d와 c를 비교해.
3. 합격확률을 묻는다면 P(X ≤ c)를 계산해.
4. 복원 여부와 모집단 크기에 따라 이항분포 또는 초기하분포를 선택해.
5. 결점수 모형이라면 푸아송분포의 평균 λ가 어느 검사범위에 대한 값인지 확인해.

## 축차샘플링검사

1. 누적표본수 n을 확인해.
2. 누적불량품수 dₙ을 계산해.
3. 현재 n에서 합격선과 불합격선을 계산해.
4. 합격선 이하, 불합격선 이상, 두 선 사이를 구분해.
5. 두 선 사이라면 임의로 합격시키지 말고 검사를 계속해.

# 8. 정답 및 해설

## 문제 1 정답: 1. 합격

합격한계는 50 − 1.5 × 2 = 47이야. 표본평균 46.5는 47 이하이므로 합격이야.

## 문제 2 정답: 2. 불합격

합격판정개수 c가 3이므로 부적합품수가 3개 이하면 합격이야. 4개는 c + 1에 해당하므로 불합격이야.

## 문제 3 정답: 2. 0.99²⁰

c = 0이면 표본에 불량품이 하나도 없어야 합격해. 제품 하나가 양품일 확률은 0.99이므로 20개가 모두 양품일 확률은 0.99²⁰이야.

## 문제 4 정답: 2. 초기하분포

유한한 모집단에서 비복원추출을 할 때 표본에 포함되는 부적합품수의 정확한 분포는 초기하분포야.

## 문제 5 정답: 3. 검사 계속

누적불량품수 4는 합격선 2.3보다 크고 불합격선 5.1보다 작아. 따라서 어느 판정선에도 도달하지 않았으므로 검사를 계속해야 해.

## 문제 6 정답: 3

축차검사는 품질이 매우 좋거나 매우 나쁠 때 조기종료될 가능성이 크지만, 품질이 판정 경계에 가까우면 검사량이 커질 수 있어. 언제나 더 적은 표본을 조사한다고 단정할 수 없어.

1. **계량값 샘플링검사**는 평균과 표준편차처럼 측정값의 크기와 산포를 사용해. 상한규격형과 하한규격형의 부등호 방향을 정확히 구분해야 해.

3. 계수값 검사의 합격확률은 이항모형에서 L(p) = P(X ≤ c)로 구해. 유한 로트의 비복원추출은 초기하분포, 드문 결점수는 푸아송분포와 연결될 수 있어.

4. **축차샘플링검사**는 누적표본수와 누적불량품수를 사용해 매 단계 합격, 불합격 또는 검사 계속을 판정해.

5. 생산자위험 α는 좋은 로트를 불합격시키는 위험이고, 소비자위험 β는 나쁜 로트를 합격시키는 위험이야.
