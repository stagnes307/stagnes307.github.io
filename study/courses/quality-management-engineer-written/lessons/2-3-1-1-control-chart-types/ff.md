## 1. 공정 모니터링과 관리도 활용

### 관리도가 감시하는 것

공정에서 측정되는 품질특성은 언제나 조금씩 달라져. 같은 설비와 원료를 사용해도 온도, 진동, 작업 조건, 측정오차처럼 수많은 요인이 결과에 영향을 주기 때문이야. 이 변동 자체를 완전히 없앨 수는 없지만, 변동의 원인은 구분할 수 있어.

**우연원인**은 공정에 본래 내재된 작고 반복적인 변동이야. 여러 미세 요인이 함께 작용하므로 특정 원인 하나를 지목하기 어렵고, 공정 시스템 자체를 개선해야 줄일 수 있어.

**이상원인**은 공구 파손, 설비 설정 오류, 불량 원료, 작업방법 변경처럼 평소와 다른 사건이 만들어 낸 변동이야. 원인을 찾아 제거하면 공정을 다시 안정시킬 수 있어.

관리도는 이 둘을 구별하는 통계적 경계선이야. 관측점이 관리한계 안에서 무작위로 움직이면 우연원인만 존재하는 관리상태로 보고, 관리한계를 벗어나거나 비무작위 패턴이 나타나면 이상원인의 개입을 의심해.

### 관리도의 기본 구조

관리도에는 다음 세 기준선이 있어.

- **중심선 CL**: 공정 통계량의 기준 수준
- **상부관리한계 UCL**: 우연변동으로 예상되는 상한
- **하부관리한계 LCL**: 우연변동으로 예상되는 하한

일반적인 슈하트 관리도에서는 중심선으로부터 약 3표준편차 떨어진 곳에 관리한계를 설정해. 정규분포를 가정하면 관측값이 평균 ±3σ 안에 들어올 확률은 약 99.73%야. 따라서 점 하나가 한계를 벗어났다면 단순한 우연보다는 공정에 특별한 변화가 생겼을 가능성을 먼저 조사하는 거지.

관리한계는 **공정의 실제 변동으로 계산하는 통계적 판단선**이야. 규격한계는 설계자나 고객이 정한 **제품의 허용 범위**야. 관리한계 안에 있다고 제품이 반드시 규격을 만족하는 것도 아니고, 규격을 만족한다고 공정이 반드시 관리상태인 것도 아니야.

### 관리도의 활용 절차

1. 관리할 품질특성과 합리적 부분군을 정해.
2. 일정한 시간 간격으로 표본을 채취해.
3. 표본별 통계량을 계산하고 시간 순서대로 타점해.
4. 관리한계 이탈과 비무작위 패턴을 확인해.
5. 이상 신호가 있으면 원인을 조사하고 시정조치해.
6. 공정이 안정된 뒤 필요하면 관리한계를 다시 계산해.

여기서 **합리적 부분군**은 한 부분군 안에서는 조건을 최대한 비슷하게 하고, 부분군 사이에서는 시간에 따른 공정 변화가 드러나게 구성한 표본이야. 부분군을 잘못 묶으면 이상변동이 표본 내부에 섞여 관리도에서 보이지 않을 수 있어.

## 2. 관리상태를 판정하는 신호

관리한계를 벗어난 점은 가장 명확한 이상 신호지만, 한계 안의 점도 배열 방식에 따라 경고가 될 수 있어.

- 한 점 이상이 UCL 위나 LCL 아래에 나타남
- 여러 점이 중심선의 한쪽에 연속해서 나타남
- 값이 연속적으로 증가하거나 감소함
- 높은 값과 낮은 값이 규칙적으로 교대함
- 중심선 부근에 점이 지나치게 몰림
- 관리한계 부근에 점이 비정상적으로 집중됨
- 일정한 주기를 가진 파동이 반복됨

예를 들어 점들이 UCL을 넘지 않더라도 여러 개가 계속 중심선 위에 나타난다면 공정 평균이 상승한 것일 수 있어. 반대로 점 하나가 한계를 벗어났더라도 측정이나 기록 오류일 가능성이 있으므로 즉시 조업 조건, 측정기, 원료, 작업자 변경 여부를 확인해야 해.

관리도는 **이상 신호를 알려 주는 경보기**이지 원인을 자동으로 밝혀 주는 진단기는 아니야. 신호를 발견한 뒤에는 현장 기록과 원인분석을 연결해야 실제 개선이 이루어져.

## 3. 관리도 선택의 첫 갈림길

관리도를 고를 때 가장 먼저 물어야 할 질문은 데이터의 형태야.

### 계량값 데이터

길이, 무게, 온도, 압력, 강도처럼 연속적인 척도로 측정하는 값이야. 한 제품에서도 측정값의 크기 차이를 자세히 볼 수 있어.

대표 관리도는 다음과 같아.

- 평균과 범위를 함께 관리: **X̄-R 관리도**
- 평균과 표준편차를 함께 관리: **X̄-s 관리도**
- 개별 측정값을 관리: **X-MR 관리도**

### 계수값 데이터

합격·불합격, 결점의 개수처럼 분류하거나 세어서 얻는 값이야. 측정 정밀도는 계량값보다 낮지만 검사하기 쉽고 여러 품질특성을 한꺼번에 판정할 수 있어.

대표 관리도는 다음과 같아.

- 부적합품률: **p 관리도**
- 부적합품수: **np 관리도**
- 결점수: **c 관리도**
- 단위당 결점수: **u 관리도**

핵심은 **부적합품과 부적합을 구별하는 것**이야. 부적합품은 제품 단위로 불합격 여부를 세지만, 부적합은 한 제품 안에서 발견된 개별 결점을 세어. 하나의 제품에 흠집이 세 개 있다면 부적합품은 1개이고 부적합은 3개야.

## 4. 계량값 관리도

### X̄-R 관리도의 역할

X̄-R 관리도는 부분군 크기가 비교적 작을 때 공정의 위치와 산포를 함께 감시해.

**X̄ 관리도**는 각 부분군 평균을 타점하여 공정 평균의 변화를 감시하고, **R 관리도**는 각 부분군의 최댓값과 최솟값 차이인 범위를 타점하여 공정 산포의 변화를 감시해.

부분군이 k개이고 각 부분군 크기가 n일 때 다음 통계량을 사용해.

- 부분군 평균: X̄ᵢ = ΣXᵢⱼ ÷ n
- 부분군 범위: Rᵢ = Xmax − Xmin
- 전체 평균: X̿ = ΣX̄ᵢ ÷ k
- 평균 범위: R̄ = ΣRᵢ ÷ k

관리한계는 관리도용 계수표의 A₂, D₃, D₄를 이용해 계산해.

**X̄ 관리도**

- UCL = X̿ + A₂R̄
- CL = X̿
- LCL = X̿ − A₂R̄

**R 관리도**

- UCL = D₄R̄
- CL = R̄
- LCL = D₃R̄

X̄ 관리도의 한계는 R̄로 추정한 공정 산포에 의존해. 따라서 두 관리도를 해석할 때는 **R 관리도를 먼저 확인하고 X̄ 관리도를 나중에 확인**해야 해. 산포가 관리되지 않으면 평균 관리도의 한계도 신뢰하기 어렵기 때문이야.

### 계산 예시

부분군 크기가 5이고 X̿ = 50.0, R̄ = 4.0이라고 하자. n = 5에서 A₂ = 0.577, D₃ = 0, D₄ = 2.114를 사용하면 다음과 같아.

- X̄ 관리도 UCL = 50.0 + 0.577 × 4.0 = 52.308
- X̄ 관리도 LCL = 50.0 − 0.577 × 4.0 = 47.692
- R 관리도 UCL = 2.114 × 4.0 = 8.456
- R 관리도 LCL = 0 × 4.0 = 0

어떤 부분군에서 X̄ = 51.8, R = 9.0이 나왔다면 평균은 한계 안이지만 범위는 R 관리도의 UCL을 넘었어. 이때 공정 평균이 안정적이라고 결론 내리면 안 돼. 먼저 산포 증가의 이상원인을 조사해야 해.

### X̄-s 관리도와 X-MR 관리도

부분군 크기가 커지면 범위보다 표준편차가 산포 정보를 더 충실하게 반영하므로 **X̄-s 관리도**가 적합해. 반대로 파괴검사, 생산량 부족, 장시간 측정처럼 매번 한 개의 값만 얻는다면 **개별값 X 관리도와 이동범위 MR 관리도**를 사용해.

X-MR 관리도에서 이동범위는 보통 인접한 두 측정값 차이의 절댓값이야.

MRᵢ = |Xᵢ − Xᵢ₋₁|

개별값을 억지로 여러 개 묶어 X̄-R 관리도를 만들면 실제 시간 변화가 가려질 수 있다는 점을 기억해.

## 5. 계수값 관리도

### p 관리도와 np 관리도

**p 관리도**는 표본에서 부적합품이 차지하는 비율을 관리해. 표본크기 n이 달라져도 사용할 수 있지만, 각 표본의 관리한계가 달라질 수 있어.

표본 i의 부적합품수가 dᵢ라면 다음과 같아.

pᵢ = dᵢ ÷ nᵢ

전체 부적합품률을 p̄라고 할 때 표본크기가 일정한 경우의 한계는 다음과 같아.

- UCL = p̄ + 3√{p̄(1 − p̄) ÷ n}
- CL = p̄
- LCL = p̄ − 3√{p̄(1 − p̄) ÷ n}

계산된 LCL이 음수이면 실제 부적합품률이 음수가 될 수 없으므로 **LCL = 0**으로 둬.

**np 관리도**는 부적합품의 개수를 관리해. 표본크기 n이 일정해야 하며 현장에서 불량품 개수를 바로 표시하기 편리해.

- UCL = np̄ + 3√{np̄(1 − p̄)}
- CL = np̄
- LCL = np̄ − 3√{np̄(1 − p̄)}

즉, 표본크기가 변하면 p 관리도를 우선하고, 표본크기가 일정하면서 부적합품수 자체를 관리하고 싶으면 np 관리도를 선택해.

### c 관리도와 u 관리도

**c 관리도**는 검사단위의 크기나 기회가 일정할 때 발견된 부적합 수를 관리해. 예를 들어 크기가 같은 유리판마다 흠집 수를 세는 경우야.

- UCL = c̄ + 3√c̄
- CL = c̄
- LCL = c̄ − 3√c̄

**u 관리도**는 검사단위의 크기나 검사 기회가 달라질 때 단위당 부적합 수를 관리해.

uᵢ = cᵢ ÷ nᵢ

- UCLᵢ = ū + 3√{ū ÷ nᵢ}
- CL = ū
- LCLᵢ = ū − 3√{ū ÷ nᵢ}

c 관리도와 u 관리도의 LCL도 음수가 나오면 0으로 조정해. p·np는 제품의 합격 여부를 세는 이항분포 계열이고, c·u는 한 검사단위에서 발생한 부적합 수를 세는 포아송분포 계열이라는 차이도 중요해.

## 6. 관리도 선택 지도

| 데이터와 조건 | 적합한 관리도 | 중심선이 나타내는 것 |
|---|---|---|
| 연속 측정값, 작은 부분군 | X̄-R | 평균과 범위 |
| 연속 측정값, 큰 부분군 | X̄-s | 평균과 표준편차 |
| 연속 측정값, 표본크기 1 | X-MR | 개별값과 이동범위 |
| 부적합품률, 표본크기 변동 가능 | p | 평균 부적합품률 |
| 부적합품수, 표본크기 일정 | np | 평균 부적합품수 |
| 부적합 수, 검사단위 일정 | c | 평균 부적합 수 |
| 단위당 부적합 수, 검사단위 변동 | u | 평균 단위당 부적합 수 |

선택 순서는 이렇게 압축할 수 있어.

1. 측정값이면 계량값 관리도로 간다.
2. 합격·불합격 제품을 세면 p 또는 np를 고른다.
3. 제품 안의 결점을 세면 c 또는 u를 고른다.
4. 표본크기나 검사단위가 달라지면 p 또는 u를 고른다.
5. 일정하면 np 또는 c를 사용할 수 있다.

## 7. 비교·경계와 시험 함정

### 관리도와 규격의 혼동

관리한계는 공정 데이터에서 계산하고, 규격한계는 고객 또는 설계 요구사항에서 결정해. 규격의 상한과 하한을 관리도의 UCL과 LCL로 그대로 사용하면 안 돼.

### 관리상태와 공정능력의 혼동

공정이 관리상태라는 말은 변동이 예측 가능하다는 뜻이야. 공정능력이 충분하다는 말은 그 안정된 분포가 규격 안에 적절히 들어간다는 뜻이야. 안정적이지만 규격을 자주 벗어나는 공정도 있고, 현재 제품은 규격을 만족하지만 이상원인 때문에 불안정한 공정도 있어.

### X̄ 관리도만 먼저 보는 실수

평균이 한계 안이어도 산포가 커질 수 있어. R 또는 s 관리도가 관리상태인지 먼저 확인해야 평균 관리도를 타당하게 해석할 수 있어.

### 부적합품과 부적합의 혼동

제품 100개 중 불합격 제품이 4개라면 부적합품수는 4이고 부적합품률은 0.04야. 그 4개 제품에서 결점이 모두 9개 발견됐다면 부적합 수는 9야. 이 구별을 놓치면 p·np와 c·u를 반대로 고르게 돼.

### 표본크기 조건을 놓치는 실수

np 관리도는 일정한 표본크기를 전제로 하고, c 관리도는 일정한 검사단위를 전제로 해. 표본크기나 검사 기회가 달라질 때는 비율 또는 단위당 수로 표준화하는 p·u 관리도가 필요해.

### 음수인 하부관리한계

비율과 개수는 음수가 될 수 없어. 계산된 LCL이 0보다 작으면 0으로 두어야 해. 그렇다고 모든 관리도에서 음수 LCL을 무조건 0으로 바꾸는 것은 아니야. 길이와 온도처럼 실제 음수가 가능한 계량값은 측정척도와 맥락을 따져야 해.

## 9. 정답 및 해설

**문제 1 정답: 3**

관리도는 시간 순서에 따른 통계량의 변화를 관찰해 우연원인만 존재하는지, 조사해야 할 이상원인이 개입했는지 판단해. 관리한계와 규격한계는 목적과 결정 방식이 다르고, 한계 안에서도 런이나 추세 같은 비무작위 패턴이 나타날 수 있어.

**문제 2 정답: 2**

직경은 연속적인 계량값이고 부분군 크기가 작으므로 X̄-R 관리도가 적합해. X̄는 공정 평균, R은 부분군 내 산포를 감시해.

**문제 3 정답: 3**

부적합품의 비율을 관리하고 표본크기가 변하므로 p 관리도를 사용해. np 관리도는 표본크기가 일정할 때 부적합품수를 관리하는 방식이야.

**문제 4 정답: 1**

한 검사단위에서 발견되는 부적합의 개수를 세고 검사단위 크기가 일정하므로 c 관리도가 적합해. 원단 크기가 달라진다면 단위면적당 흠집 수를 관리하는 u 관리도를 고려해야 해.

**문제 5 정답: 3**

R 관리도가 관리상태가 아니면 공정 산포가 안정적이지 않고, 이를 이용해 설정한 X̄ 관리도의 한계도 신뢰하기 어려워. 산포의 이상원인을 먼저 조사하고 안정화한 뒤 평균 수준을 해석해야 해.

## 10. 회상 요약

- 관리도는 **시간에 따른 공정 변동**을 감시하고 우연원인과 이상원인을 구별해.
- CL은 중심선, UCL과 LCL은 공정 데이터에서 계산한 관리한계야.
- 관리한계는 통계적 판단선이고 규격한계는 제품 요구조건이야.
- 계량값 관리도에는 X̄-R, X̄-s, X-MR 관리도가 있어.
- X̄-R 관리도는 **R 관리도를 먼저**, X̄ 관리도를 나중에 판정해.
- 계수값에서는 부적합품을 세면 p·np, 부적합을 세면 c·u를 사용해.
- 표본크기 또는 검사단위가 변하면 p·u, 일정하면 np·c가 기본 선택이야.
- 계산된 계수값 관리도의 LCL이 음수이면 0으로 조정해.
- 관리상태는 변동이 예측 가능하다는 뜻이며, 규격 만족이나 충분한 공정능력을 자동으로 보장하지 않아.
