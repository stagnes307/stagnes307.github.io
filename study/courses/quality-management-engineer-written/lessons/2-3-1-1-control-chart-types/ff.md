# 2-3-1-1. 관리도 (1/2)

> 품질경영기사 필기 · 2-3. 공정품질관리 · 2-3-1. 관리도

관리도는 시간에 따라 변하는 공정 데이터를 관찰해서 공정이 **통계적 관리상태**에 있는지 판단하는 도구야. 규격에 합격했는지만 검사하는 것이 아니라, 공정의 변동 구조가 안정적인지를 계속 감시한다는 점이 핵심이지. 이번 Lesson에서는 **공정 모니터링과 관리도 활용**, **계량값 관리도**, **계수값 관리도**를 연결해서 배워볼게. 처음에는 관리도 종류가 많아 보여도, 데이터가 연속형인지 이산형인지부터 구분하면 선택 구조가 선명해져 😊

## 1. 공정 모니터링과 관리도 활용

### 1.1 관리도의 정의와 구조

관리도는 표본에서 계산한 품질특성의 통계량을 시간순으로 표시하고, 그 통계량이 관리한계 안에서 무작위로 움직이는지 판단하는 그래프야.

관리도에는 보통 다음 세 기준선이 있어.

| 기준선 | 의미 |
|---|---|
| 중심선 CL | 공정이 안정되었을 때 통계량이 위치할 것으로 기대되는 중심 |
| 상부관리한계 UCL | 우연원인만 존재한다면 통계량이 정상적으로 벗어나기 어려운 상한 |
| 하부관리한계 LCL | 우연원인만 존재한다면 통계량이 정상적으로 벗어나기 어려운 하한 |

관리한계는 일반적으로 중심값에서 표준편차의 3배만큼 떨어진 위치에 설정해.

**UCL = 중심값 + 3 × 통계량의 표준편차**

**CL = 중심값**

**LCL = 중심값 − 3 × 통계량의 표준편차**

정규분포를 가정하면 평균에서 ±3σ 범위에 약 99.73%가 포함돼. 따라서 관리한계 밖의 점은 우연한 변동만으로 나타날 가능성이 작으므로, 공정에 이상원인이 개입했다는 신호로 해석해.

다만 관리한계 안에 있다고 무조건 안정적인 것은 아니야. 점들이 한쪽에 연속해서 몰리거나 계속 상승하는 것처럼 **비무작위 패턴**이 나타나도 이상원인을 의심해야 해.

### 1.2 우연원인과 이상원인

**우연원인**은 공정에 본래 내재한 작고 불가피한 변동 원인이야. 원재료의 미세한 차이, 측정기의 작은 오차, 작업환경의 일상적 변화가 함께 작용할 수 있어. 특정 원인 하나를 제거하기 어렵고, 공정 시스템 자체를 개선해야 변동을 줄일 수 있지.

**이상원인**은 평소의 공정에는 없던 식별 가능한 변동 원인이야. 공구 파손, 잘못된 설비 설정, 부적합 원료 투입, 측정기 고장처럼 원인을 찾아 제거할 수 있는 경우가 많아.

| 구분 | 우연원인 | 이상원인 |
|---|---|---|
| 성격 | 공정에 상시 내재 | 특정 사건으로 발생 |
| 변동 양상 | 작고 무작위적 | 크거나 체계적 |
| 대응 주체 | 주로 관리자와 시스템 설계자 | 현장 작업자와 기술자도 즉시 대응 가능 |
| 개선 방법 | 공정 시스템의 근본적 개선 | 원인 탐색과 제거 |
| 관리도 신호 | 대체로 한계 내 무작위 배열 | 한계 이탈 또는 비무작위 패턴 |

관리도의 직접적인 목적은 제품을 합격과 불합격으로 나누는 것이 아니라, **이상원인을 신속하게 탐지하고 공정을 안정된 상태로 유지하는 것**이야.

### 1.3 관리상태의 판정

대표적인 이상 신호는 다음과 같아.

1. 점 하나 이상이 관리한계선을 벗어남
2. 여러 점이 중심선의 한쪽에 연속해서 나타남
3. 점들이 지속적으로 상승하거나 하락함
4. 일정한 주기가 반복됨
5. 중심선 부근 또는 관리한계 부근에 점이 비정상적으로 집중됨
6. 표본 간 변동이 갑자기 커지거나 작아짐

예를 들어 충전 공정의 평균 내용량이 UCL을 넘었다면 충전밸브 설정 변화나 압력 이상을 조사해야 해. 반대로 모든 점이 한계 안에 있어도 평균이 여덟 번 연속 중심선 위에 나타났다면 공정 평균이 위쪽으로 이동했을 가능성이 있어.

### 1.4 관리한계와 규격한계의 차이

이 구분은 시험에서 매우 자주 흔들리는 부분이야.

| 구분 | 관리한계 | 규격한계 |
|---|---|---|
| 결정 근거 | 실제 공정 데이터와 통계적 변동 | 설계조건, 고객 요구 또는 법적 기준 |
| 주요 목적 | 공정의 안정성 판단 | 제품의 적합성 판단 |
| 대표 기호 | UCL, CL, LCL | USL, 목표값, LSL |
| 의미 | 공정이 현재 어떻게 움직이는가 | 제품이 만족해야 할 범위는 무엇인가 |
| 변경 조건 | 공정 변동 구조가 달라지면 재계산 | 제품 요구조건이 바뀔 때 변경 |

공정이 관리상태여도 평균이 규격 중심에서 벗어나거나 산포가 지나치게 크면 불량품을 계속 만들 수 있어. 반대로 모든 측정값이 당장 규격 안에 있어도 데이터가 추세적으로 상승한다면 공정은 통계적으로 불안정할 수 있지.

**안정성은 관리도로 판단하고, 규격 충족 능력은 공정능력으로 판단한다**고 구분하면 돼.

### 1.5 관리도의 활용 절차

1. 관리하려는 품질특성을 명확히 정해.
2. 데이터가 계량값인지 계수값인지 구분해.
3. 합리적인 부분군과 표본크기, 채취주기를 결정해.
4. 공정이 비교적 안정된 기간의 초기 데이터를 수집해.
5. 표본별 통계량을 계산해.
6. 중심선과 관리한계선을 계산해.
7. 점을 시간순으로 타점해.
8. 한계 이탈과 비무작위 패턴을 판정해.
9. 이상원인이 발견되면 원인을 조사하고 조치해.
10. 제거 가능한 이상 데이터의 처리 근거를 기록한 뒤 관리한계를 재검토해.
11. 안정된 관리도를 지속적인 공정 감시에 사용해.

**합리적 부분군**은 부분군 내부에는 우연원인만 반영되고, 부분군 사이에서는 시간에 따른 공정 변화를 탐지할 수 있도록 표본을 구성하는 원칙이야. 같은 시점에 연속 생산된 제품들을 한 부분군으로 묶는 방식이 대표적이야.

### 1.6 구체적인 예시

한 음료 공장에서 매시간 연속 생산된 병 5개를 뽑아 내용량을 측정한다고 해보자. 각 시간대의 표본평균은 공정 중심의 변화를 보여주고, 표본범위는 병 5개 사이의 산포를 보여줘.

오후 2시의 평균이 UCL을 넘었다면 충전압력이나 밸브 설정을 확인할 수 있어. 그런데 같은 시각의 범위까지 갑자기 커졌다면 밸브의 불규칙한 작동이나 여러 충전 노즐 사이의 차이를 함께 의심해야 하지. 이처럼 중심과 산포를 함께 감시해야 원인을 더 정확히 찾을 수 있어.

### 1.7 비교와 경계

관리도는 **예측 가능한 안정된 공정**을 만드는 데 강하지만, 이상원인의 정확한 정체를 자동으로 알려주지는 않아. 관리도가 경보장치라면 원인분석은 진단 과정에 해당해. 경보가 울린 뒤에는 작업기록, 설비상태, 원료 로트, 측정시스템을 조사해야 해.

관리도를 검사표처럼 사용해서 한계를 벗어난 제품만 폐기하는 것도 잘못이야. 관리도는 제품 하나의 합격 여부보다 공정 통계량의 시간적 변화를 해석하는 도구이기 때문이야.

### 1.8 시험 함정

1. 관리한계는 규격한계와 동일하지 않아.
2. 관리한계 밖의 점은 곧바로 불량품이라는 뜻이 아니야.
3. 관리한계 안의 모든 점이 규격에 합격한다는 뜻도 아니야.
4. 한계선 안에서도 연속, 추세, 주기 같은 비무작위 패턴은 이상 신호가 될 수 있어.
5. 관리도는 이상원인의 존재를 신호하지만 그 원인을 자동으로 확정하지는 않아.
6. 공정이 불안정한 상태에서 계산한 평균과 표준편차를 장기 기준으로 고정하면 안 돼.

## 2. 계량값 관리도

### 2.1 계량값과 관리도 선택

**계량값**은 길이, 무게, 온도, 압력, 강도처럼 연속적인 척도로 측정되는 데이터야. 하나의 측정값이 단순한 합격·불합격보다 더 많은 정보를 담으므로 작은 공정 변화도 비교적 민감하게 탐지할 수 있어.

| 관리도 | 감시 대상 | 일반적인 사용 조건 |
|---|---|---|
| X̄ 관리도 | 공정 평균 | 부분군별 표본평균을 사용 |
| R 관리도 | 부분군 내 산포 | 표본크기가 비교적 작을 때 |
| s 관리도 | 부분군 내 산포 | 표본크기가 비교적 클 때 |
| X 관리도 | 개별 측정값 | 부분군을 구성하기 어렵거나 n = 1일 때 |
| MR 관리도 | 연속 개별값 사이의 변동 | X 관리도와 함께 사용 |

가장 대표적인 조합은 **X̄−R 관리도**야. X̄ 관리도로 공정 중심을, R 관리도로 공정 산포를 감시해.

### 2.2 X̄−R 관리도의 통계량

부분군의 크기를 n, 부분군 수를 k라고 하자. i번째 부분군의 측정값이 xᵢ₁부터 xᵢₙ까지라면 다음과 같이 계산해.

**부분군평균 X̄ᵢ = 부분군 측정값의 합 ÷ n**

**부분군범위 Rᵢ = 부분군 최댓값 − 부분군 최솟값**

전체 부분군평균의 평균은 다음과 같아.

**X̿ = 부분군평균들의 합 ÷ k**

평균범위는 다음과 같아.

**R̄ = 부분군범위들의 합 ÷ k**

X̄ 관리도의 관리한계는 다음과 같아.

**UCL = X̿ + A₂R̄**

**CL = X̿**

**LCL = X̿ − A₂R̄**

R 관리도의 관리한계는 다음과 같아.

**UCL = D₄R̄**

**CL = R̄**

**LCL = D₃R̄**

A₂, D₃, D₄는 표본크기 n에 따라 정해지는 관리도 계수야.

### 2.3 왜 R 관리도를 먼저 판정할까?

X̄ 관리도의 관리한계는 공정 산포를 나타내는 R̄에 의존해. 그런데 산포가 불안정하면 그 산포로 계산한 X̄ 관리도의 한계도 신뢰하기 어려워져.

그래서 보통 다음 순서로 해석해.

1. R 관리도에서 공정 산포가 관리상태인지 확인해.
2. 산포가 안정적이면 X̄ 관리도로 공정 평균을 판정해.
3. R 관리도가 불안정하면 산포의 이상원인을 먼저 조사해.
4. 필요한 조치 후 관리한계를 다시 검토해.

평균이 안정적이어도 산포가 커지면 규격 밖 제품이 증가할 수 있어. 반대로 산포가 안정적이어도 평균이 이동하면 한쪽 규격한계에 가까워질 수 있지. 두 관리도를 함께 사용하는 이유야.

### 2.4 계산 예시

어떤 가공 공정에서 한 시간마다 부품 5개를 측정했어. 초기 안정 기간의 계산 결과가 다음과 같다고 하자.

**X̿ = 20.00 mm**

**R̄ = 0.40 mm**

표본크기 n = 5일 때 A₂ = 0.577, D₃ = 0, D₄ = 2.114를 사용하면 다음과 같아.

X̄ 관리도:

**UCL = 20.00 + 0.577 × 0.40 = 20.2308 mm**

**CL = 20.00 mm**

**LCL = 20.00 − 0.577 × 0.40 = 19.7692 mm**

R 관리도:

**UCL = 2.114 × 0.40 = 0.8456 mm**

**CL = 0.40 mm**

**LCL = 0 × 0.40 = 0 mm**

새 부분군의 평균이 20.26 mm라면 X̄ 관리도의 UCL을 넘으므로 평균 이동을 의심해야 해. 새 부분군의 범위가 0.90 mm라면 R 관리도의 UCL도 넘으므로 산포 증가의 원인을 조사해야 하지.

### 2.5 X̄−s 관리도와 개별값 관리도

표본크기가 커지면 범위 R은 표본의 최댓값과 최솟값만 사용한다는 한계가 커져. 이때는 모든 관측값의 정보를 반영하는 표준편차 s를 이용한 **X̄−s 관리도**가 더 적합해.

부분군을 만들 수 없고 한 시점에 한 개의 값만 얻는다면 **X−MR 관리도**를 사용해. X 관리도는 개별값의 수준을, MR 관리도는 인접한 두 값의 이동범위를 감시해.

예를 들어 하루에 한 번만 측정할 수 있는 고가의 파괴검사나 매우 느린 화학공정에서는 n = 1이 될 수 있어. 이때 억지로 X̄−R 관리도를 선택하면 부분군 평균과 범위를 제대로 만들 수 없어.

### 2.6 비교와 경계

| 상황 | 적절한 선택 |
|---|---|
| 연속형 데이터, 작은 부분군 | X̄−R 관리도 |
| 연속형 데이터, 비교적 큰 부분군 | X̄−s 관리도 |
| 연속형 데이터, 관측값이 한 번에 하나 | X−MR 관리도 |
| 불량 여부나 결점 수 데이터 | 계수값 관리도 |

계량값 관리도는 정보량이 많고 변화 탐지력이 높지만, 측정기와 측정시간이 필요해. 측정시스템 자체가 불안정하면 관리도 신호가 제품 공정의 변화인지 측정오차의 변화인지 구분하기 어려워. 따라서 측정시스템의 신뢰성을 먼저 확보해야 해.

### 2.7 시험 함정

1. X̄ 관리도만 보고 R 관리도를 생략하면 안 돼.
2. R은 표준편차가 아니라 부분군의 최댓값과 최솟값의 차이야.
3. X̿는 모든 부분군평균의 평균이고, R̄은 모든 부분군범위의 평균이야.
4. 관리도 계수는 표본크기에 따라 달라져.
5. R 관리도는 부분군 사이 평균 차이가 아니라 부분군 내부 산포를 감시해.
6. LCL 계산값이 음수이고 관리 대상 통계량이 음수가 될 수 없다면 일반적으로 0으로 처리해.
7. n = 1에서는 같은 시점의 부분군범위를 계산할 수 없으므로 X−MR 관리도를 고려해야 해.

## 3. 계수값 관리도

### 3.1 계수값의 두 종류

**계수값**은 개수를 세거나 범주로 분류한 데이터야. 먼저 **부적합품**과 **부적합**을 분명히 나눠야 해.

**부적합품**은 검사단위가 요구조건을 충족하지 못한 경우야. 제품 하나에 결점이 여러 개 있어도 부적합품 수를 셀 때는 제품 하나로 계산해.

**부적합**은 요구조건을 충족하지 못한 개별 결점이야. 제품 하나에 긁힘 2개와 균열 1개가 있으면 부적합은 3개가 될 수 있어.

| 관리도 | 관리 대상 | 표본크기 |
|---|---|---|
| p 관리도 | 부적합품률 | 일정하거나 변동 가능 |
| np 관리도 | 부적합품 수 | 일정 |
| c 관리도 | 부적합 수 | 검사단위의 크기 또는 기회가 일정 |
| u 관리도 | 단위당 부적합 수 | 검사단위의 크기 또는 기회가 변동 가능 |

선택 요령은 간단해.

**부적합품이면 p 또는 np, 부적합이면 c 또는 u**를 먼저 골라. 그다음 표본크기나 검사기회가 변하는지 확인하면 돼.

### 3.2 p 관리도

p 관리도는 표본에서 발견된 **부적합품률**을 감시해. i번째 표본의 크기를 nᵢ, 부적합품 수를 dᵢ라고 하면 다음과 같아.

**pᵢ = dᵢ ÷ nᵢ**

전체 평균 부적합품률은 다음과 같아.

**p̄ = 전체 부적합품 수 ÷ 전체 검사품 수**

표본크기가 n으로 일정할 때 관리한계는 다음과 같아.

**UCL = p̄ + 3√{p̄(1−p̄) ÷ n}**

**CL = p̄**

**LCL = p̄ − 3√{p̄(1−p̄) ÷ n}**

표본크기가 달라지면 각 표본의 nᵢ를 사용하므로 관리한계의 폭도 달라져. 표본이 크면 통계량의 표준오차가 작아져 관리한계가 좁아지고, 표본이 작으면 넓어져.

계산된 LCL이 음수이면 부적합품률은 음수가 될 수 없으므로 0으로 둬.

### 3.3 np 관리도

np 관리도는 표본에 포함된 **부적합품 수** 자체를 감시해. 표본크기 n이 일정해야 서로 다른 시점의 부적합품 수를 직접 비교할 수 있어.

**UCL = np̄ + 3√{np̄(1−p̄)}**

**CL = np̄**

**LCL = np̄ − 3√{np̄(1−p̄)}**

예를 들어 매일 정확히 제품 100개를 검사한다면 부적합품 수를 np 관리도로 표현할 수 있어. 하지만 어떤 날은 80개, 다른 날은 150개를 검사한다면 단순 부적합품 수 비교가 왜곡되므로 p 관리도가 적절해.

### 3.4 c 관리도

c 관리도는 일정한 크기의 검사단위에서 발견된 **부적합 수**를 감시해. 포아송분포를 기초로 하며 평균과 분산이 모두 c̄인 성질을 이용해.

**UCL = c̄ + 3√c̄**

**CL = c̄**

**LCL = c̄ − 3√c̄**

LCL이 음수이면 0으로 둬.

예를 들어 매번 동일한 면적의 강판 한 장에서 표면 흠집 수를 세거나, 매번 길이가 같은 천에서 직조 결점 수를 센다면 c 관리도를 사용할 수 있어.

### 3.5 u 관리도

u 관리도는 검사단위의 크기나 검사기회가 달라질 때 **단위당 부적합 수**를 감시해.

i번째 표본의 부적합 수를 cᵢ, 검사단위 수를 nᵢ라고 하면 다음과 같아.

**uᵢ = cᵢ ÷ nᵢ**

전체 평균 단위당 부적합 수는 다음과 같아.

**ū = 전체 부적합 수 ÷ 전체 검사단위 수**

각 표본의 관리한계는 다음과 같아.

**UCLᵢ = ū + 3√{ū ÷ nᵢ}**

**CL = ū**

**LCLᵢ = ū − 3√{ū ÷ nᵢ}**

검사단위 수가 달라지면 관리한계도 표본마다 달라져. 예를 들어 어떤 날은 문서 10쪽을 검사하고 다른 날은 25쪽을 검사한다면 전체 오탈자 수를 단순 비교하기보다 쪽당 오탈자 수를 u 관리도로 관리해야 해.

### 3.6 선택 예시

1. 매일 검사하는 제품 수가 다르고 불량 제품의 비율을 관리한다면 **p 관리도**야.
2. 매일 정확히 200개를 검사하고 불량 제품 수를 관리한다면 **np 관리도**야.
3. 매번 동일한 면적의 판에서 흠집 개수를 센다면 **c 관리도**야.
4. 검사하는 판의 면적이 매번 다르고 단위면적당 흠집 수를 관리한다면 **u 관리도**야.
5. 제품 한 개에 결점이 여러 개 생길 수 있다면 p나 np가 아니라 c나 u를 먼저 검토해야 해.

### 3.7 비교와 경계

계수값 관리도는 측정이 간단하고 검사비용이 낮다는 장점이 있어. 하지만 길이 10.01 mm와 10.49 mm를 모두 합격으로만 기록하면 두 값의 차이가 사라져. 계량값을 합격·불합격으로 변환하면 정보가 손실되므로 작은 공정 변화를 발견하는 능력이 낮아질 수 있어.

또한 p와 np는 이항분포, c와 u는 포아송분포를 기본 모형으로 사용해. 실제 데이터에 과도한 군집, 검사기회 차이, 분류기준 불일치가 존재하면 이론적 관리한계가 실제 변동을 충분히 표현하지 못할 수 있어.

### 3.8 시험 함정

1. 부적합품 수와 부적합 수를 혼동하면 관리도 선택이 완전히 달라져.
2. 제품 하나에 결점이 세 개 있어도 부적합품 수는 최대 하나지만 부적합 수는 세 개가 될 수 있어.
3. np 관리도는 표본크기가 일정해야 해.
4. c 관리도는 검사단위의 크기와 부적합 발생 기회가 일정해야 해.
5. p 관리도와 u 관리도는 표본크기가 달라질 수 있으며, 이때 관리한계도 달라질 수 있어.
6. p는 부적합품률이고 u는 단위당 부적합 수야.
7. 관리한계의 계산 결과가 음수이더라도 비율이나 개수는 음수가 될 수 없으므로 LCL을 0으로 처리해.
8. 부적합품률이 높다는 사실과 공정이 통계적으로 불안정하다는 판단은 동일하지 않아. 높은 수준에서 안정된 공정도 있을 수 있어.

## 4. 세 주제를 하나의 판단 흐름으로 연결하기

관리도 선택은 다음 질문을 순서대로 적용하면 돼.

1. 품질특성을 실제 수치로 측정하는가, 개수나 범주로 세는가?
2. 수치로 측정한다면 한 시점의 부분군을 구성할 수 있는가?
3. 부분군을 구성한다면 표본크기가 작아 R을 쓸지, 비교적 커서 s를 쓸지 판단해.
4. 계수값이라면 부적합품을 세는지 부적합을 세는지 구분해.
5. 부적합품이라면 표본크기가 일정할 때 np, 달라질 때 p를 선택해.
6. 부적합이라면 검사단위가 일정할 때 c, 달라질 때 u를 선택해.
7. 관리도를 작성한 뒤 한계 이탈과 비무작위 패턴을 함께 살펴.
8. 산포와 중심을 함께 관리하는 경우 산포 관리도를 먼저 확인해.

| 데이터 상황 | 대표 관리도 | 핵심 통계량 |
|---|---|---|
| 길이·무게·온도, 작은 부분군 | X̄−R | 평균과 범위 |
| 길이·무게·온도, 큰 부분군 | X̄−s | 평균과 표준편차 |
| 개별 측정만 가능 | X−MR | 개별값과 이동범위 |
| 불량 제품 비율 | p | 부적합품률 |
| 일정 표본의 불량 제품 수 | np | 부적합품 수 |
| 일정 검사단위의 결점 수 | c | 부적합 수 |
| 변동 검사단위의 단위당 결점 수 | u | 단위당 부적합 수 |

## 7. 요약

1. **공정 모니터링과 관리도 활용**의 핵심은 공정 변동을 우연원인과 이상원인으로 구분하고, 이상원인을 조기에 찾아 제거하는 데 있어.
2. 관리한계는 공정 데이터에서 계산하며 공정 안정성을 판단해. 규격한계는 고객이나 설계 요구를 나타내며 제품 적합성을 판단해.
3. 한계 밖의 점뿐 아니라 연속, 추세, 주기, 편중 같은 비무작위 패턴도 이상 신호야.
4. **계량값 관리도**는 길이, 무게, 온도처럼 연속적으로 측정되는 데이터를 다뤄.
5. X̄−R 관리도에서는 R 관리도로 산포를 먼저 확인한 뒤 X̄ 관리도로 평균을 판정해.
6. **계수값 관리도**에서 부적합품은 p·np 관리도, 부적합은 c·u 관리도로 관리해.
7. 표본크기가 일정하면 np, 변하면 p를 선택하고, 검사단위가 일정하면 c, 변하면 u를 선택하는 것이 기본 원칙이야.
8. 관리도는 이상을 알리는 경보장치이지, 이상원인의 정체를 자동으로 밝혀주는 진단서가 아니야.
9. 안정성과 규격 적합성은 서로 다른 개념이므로 관리도와 공정능력을 구분해서 해석해야 해.

관리도 문제는 공식을 외우기 전에 **계량값인가 계수값인가 → 무엇을 세는가 → 표본크기나 검사기회가 일정한가**라는 세 갈래를 먼저 판단하면 훨씬 쉬워져. 종류가 많아 보여도 사실은 데이터의 성격에 맞는 온도계를 고르는 과정과 같아. 여기까지 따라왔다면 관리도 선택의 뼈대는 제대로 잡은 거야 😊
