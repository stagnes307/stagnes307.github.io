## 1. 신뢰도 함수

### 1.1 신뢰도의 의미

신뢰도란 제품이나 시스템이 **정해진 사용 조건에서 일정 시간 동안 요구 기능을 고장 없이 수행할 확률**이야. 단순히 “품질이 좋다”는 평가가 아니라, 시간과 사용 조건이 결합된 확률 개념이지.

수명 또는 고장시간을 확률변수 T라고 하면 신뢰도 함수는 다음과 같이 정의해.

**R(t) = P(T > t)**

즉, R(t)는 제품의 수명 T가 임무시간 t보다 길 확률이야. 제품 100개 가운데 800시간이 지난 뒤 92개가 정상 작동한다면, 경험적으로 추정한 800시간 신뢰도는 약 0.92라고 볼 수 있어.

신뢰도는 확률이므로 다음 범위에 있어.

**0 ≤ R(t) ≤ 1**

일반적인 비수리 제품에서는 시간이 흐를수록 고장하지 않은 제품의 비율이 감소하므로 R(t)는 감소함수야.

**R(0) = 1, R(∞) = 0**

다만 시작 시점부터 불량품이 포함되거나 임무 성공의 정의가 특별한 경우에는 R(0)=1이라는 이상적 가정을 그대로 적용할 수 없는 상황도 있어.

### 1.2 누적고장분포와의 관계

누적분포함수 F(t)는 제품이 시간 t 이내에 고장날 확률이야.

**F(t) = P(T ≤ t)**

고장이 t 이내에 발생하거나 t를 초과해 발생하는 사건은 서로 여사건이므로 다음 관계가 성립해.

**R(t) = 1 − F(t)**  
**F(t) = 1 − R(t)**

예를 들어 1,000시간까지의 누적고장확률이 0.08이면 신뢰도는 다음과 같아.

**R(1000) = 1 − 0.08 = 0.92**

여기서 자주 나오는 시험 함정은 F(t)를 “정확히 t에서 고장날 확률”로 해석하는 거야. 연속형 수명분포에서 F(t)는 **t 이하의 누적 고장확률**이지, 특정 순간 하나의 확률이 아니야.

### 1.3 고장밀도함수

수명 T가 연속형 확률변수이면 고장밀도함수 f(t)는 누적고장분포를 미분해 구해.

**f(t) = dF(t)/dt**

R(t)=1−F(t)이므로 다음 관계도 성립해.

**f(t) = −dR(t)/dt**

따라서 신뢰도 함수가 주어지면 음의 미분을 통해 고장밀도함수를 구할 수 있어. 반대로 고장밀도함수가 주어지면 적분을 이용해 신뢰도를 계산할 수 있지.

**R(t) = ∫ₜ∞ f(x)dx**

중요한 경계는 f(t)와 F(t), R(t)의 단위야.

| 함수 | 의미 | 일반적인 단위 |
|---|---|---:|
| R(t) | t까지 생존할 확률 | 없음 |
| F(t) | t까지 누적 고장날 확률 | 없음 |
| f(t) | 단위시간 구간의 고장확률 밀도 | 1/시간 |

f(t)는 밀도이므로 그 값 자체를 바로 확률이라고 부르면 안 돼. 구간 a부터 b까지 고장날 확률은 **f(t)의 구간 적분**으로 구해야 해.

### 1.4 고장률 함수

고장률 함수 λ(t)는 시간 t까지 살아남은 제품이 그 직후의 짧은 시간 동안 고장날 조건부 비율을 나타내.

**λ(t) = f(t) / R(t)**

이는 전체 제품을 분모로 삼는 것이 아니라, **t까지 생존한 제품을 위험집단으로 삼는다**는 점이 핵심이야. 그래서 고장밀도 f(t)와 고장률 λ(t)는 서로 다른 개념이야.

위 식에 f(t)=−R′(t)를 대입하면 다음과 같아.

**λ(t) = −R′(t) / R(t)**

이를 적분하면 일반적인 신뢰도 함수가 도출돼.

**R(t) = exp[−∫₀ᵗ λ(x)dx]**

누적고장률을 H(t)라고 정의하면 다음처럼 더 간단히 표현할 수 있어.

**H(t) = ∫₀ᵗ λ(x)dx**  
**R(t) = e^(−H(t))**

이 관계는 고장률이 시간에 따라 변하는 경우에도 적용할 수 있어.

### 1.5 지수분포와 일정 고장률

우발고장기간처럼 고장률이 일정하다고 가정하면 λ(t)=λ이고 신뢰도 함수는 다음과 같아.

**R(t) = e^(−λt)**

이에 대응하는 누적고장분포와 고장밀도함수는 다음과 같아.

**F(t) = 1 − e^(−λt)**  
**f(t) = λe^(−λt)**

예를 들어 시간당 고장률이 0.0002이고 임무시간이 1,000시간이라면 다음과 같이 계산해.

**R(1000) = e^(−0.0002×1000) = e^(−0.2) ≈ 0.8187**

따라서 1,000시간 동안 고장 없이 작동할 확률은 약 81.87%야.

반면 1,000시간 이내에 고장날 확률은 다음과 같아.

**F(1000) = 1 − 0.8187 = 0.1813**

약 18.13%인 셈이지.

### 1.6 지수분포의 무기억성

지수분포는 다음과 같은 무기억성을 가져.

**P(T > s+t | T > s) = P(T > t)**

이미 s시간 동안 작동했다는 사실이 이후 t시간의 생존확률을 바꾸지 않는다는 뜻이야. 이는 고장률이 항상 일정하기 때문에 성립해.

예를 들어 평균수명이 2,000시간인 지수분포 부품이 이미 500시간 작동했다 해도, 그 시점부터 추가로 1,000시간 작동할 확률은 새 부품이 1,000시간 작동할 확률과 같아.

하지만 마모가 누적되는 제품에는 무기억성을 그대로 적용하기 어려워. 마모고장기간에는 일반적으로 시간이 지날수록 고장률이 증가하기 때문이야.

## 2. 신뢰성 척도 계산

### 2.1 평균수명 MTTF

MTTF는 Mean Time To Failure의 약자로, 주로 **수리하지 않는 제품의 고장까지 평균시간**을 의미해.

연속형 수명분포에서는 다음과 같이 계산해.

**MTTF = E(T) = ∫₀∞ t f(t)dt**

부분적분을 이용하면 신뢰도 함수의 면적으로도 나타낼 수 있어.

**MTTF = ∫₀∞ R(t)dt**

그래프에서 보면 신뢰도 곡선 아래의 전체 면적이 평균수명이야. 이 해석은 계산 문제뿐 아니라 함수의 의미를 묻는 문제에서도 중요해.

지수분포에서는 R(t)=e^(−λt)이므로 다음과 같아.

**MTTF = ∫₀∞ e^(−λt)dt = 1/λ**

따라서 일정 고장률 모형에서는 다음 관계를 기억하면 돼.

**λ = 1/MTTF**

예를 들어 고장률이 시간당 0.0005이면 다음과 같아.

**MTTF = 1/0.0005 = 2,000시간**

주의할 점은 MTTF가 2,000시간이라고 해서 모든 제품이 정확히 2,000시간에 고장난다는 뜻은 아니라는 거야. MTTF는 수명분포의 산술평균이지 보증수명이 아니야.

### 2.2 평균고장간격 MTBF

MTBF는 Mean Time Between Failures의 약자로, **수리 가능한 시스템에서 한 고장부터 다음 고장까지의 평균 작동시간**을 뜻해.

일정 고장률을 가정하면 보통 다음과 같이 계산해.

**MTBF = 총 작동시간 / 고장횟수**

그리고 다음 관계를 사용해.

**λ = 1/MTBF**

예를 들어 동일한 장비 10대를 각각 500시간 운전했고 전체 고장횟수가 5회라면 총 작동시간은 5,000시간이야.

**MTBF = 5,000/5 = 1,000시간**  
**λ = 1/1,000 = 0.001/시간**

이 값을 지수분포 모형에 적용하면 200시간 임무 신뢰도는 다음과 같아.

**R(200) = e^(−0.001×200) = e^(−0.2) ≈ 0.8187**

시험에서는 MTTF와 MTBF를 무조건 같은 용어로 취급하면 위험해. 일정 고장률 아래에서 수치 관계가 유사할 수 있지만, MTTF는 주로 비수리 제품의 최초 고장까지 시간이고 MTBF는 수리 가능한 시스템의 고장 사이 작동시간이야.

### 2.3 평균수리시간 MTTR

MTTR은 Mean Time To Repair의 약자로, 고장난 시스템을 복구하는 데 걸리는 평균시간이야.

**MTTR = 총 수리시간 / 수리횟수**

예를 들어 4회의 수리에 각각 2시간, 3시간, 1시간, 2시간이 걸렸다면 다음과 같아.

**MTTR = (2+3+1+2)/4 = 2시간**

MTTR은 신뢰도 자체보다 보전성과 가용성을 평가할 때 직접 사용돼. 고장 간격이 길더라도 수리시간이 지나치게 길면 실제 운용 가능 시간의 비율은 낮아질 수 있어.

### 2.4 가용도와의 연결

정상상태 가용도 A는 대표적으로 다음과 같이 계산해.

**A = MTBF / (MTBF + MTTR)**

MTBF가 1,000시간이고 MTTR이 10시간이라면 다음과 같아.

**A = 1,000/(1,000+10) ≈ 0.9901**

가용도는 약 99.01%야.

신뢰도와 가용도는 구별해야 해. 신뢰도는 주어진 시간 동안 **중간 고장 없이** 임무를 완수할 확률이고, 가용도는 수리와 복구까지 고려하여 임의의 시점에 시스템이 작동 가능한 상태일 확률 또는 시간 비율이야.

한 번 고장난 뒤 매우 빠르게 복구되는 시스템은 장시간 임무 신뢰도가 낮더라도 가용도는 높을 수 있어.

### 2.5 Bₚ 수명

Bₚ 수명은 모집단의 p%가 고장나는 시점을 의미해. 이를 백분위수 수명이라고도 해.

**F(Bₚ) = p/100**  
**R(Bₚ) = 1 − p/100**

대표적으로 B₁₀ 수명은 10%가 고장하고 90%가 생존하는 시간이야.

**F(B₁₀) = 0.10**  
**R(B₁₀) = 0.90**

지수분포에서는 다음과 같이 계산해.

**R(t) = e^(−λt)**

Bₚ에서 R(Bₚ)=1−p/100이므로 다음과 같아.

**Bₚ = −ln(1−p/100)/λ**

고장률 λ=0.0005/시간일 때 B₁₀을 구하면 다음과 같아.

**B₁₀ = −ln(0.9)/0.0005 ≈ 210.72시간**

여기서 B₁₀을 10%가 생존하는 시간으로 해석하면 틀려. B₁₀은 **10% 고장, 90% 생존** 시점이야.

### 2.6 중앙수명

중앙수명은 제품의 50%가 고장하고 50%가 생존하는 시간이야.

**F(t₀.₅) = 0.5**  
**R(t₀.₅) = 0.5**

지수분포에서는 다음과 같아.

**t₀.₅ = ln 2 / λ ≈ 0.693/λ**

반면 평균수명은 1/λ이므로 지수분포에서는 다음 관계가 성립해.

**중앙수명 ≈ 0.693 × MTTF**

따라서 지수분포의 평균수명과 중앙수명은 같지 않아. 예를 들어 MTTF가 1,000시간이면 중앙수명은 약 693시간이야.

### 2.7 신뢰수명

목표 신뢰도 r을 유지하는 시간을 신뢰수명 tᵣ이라고 하면 다음 조건을 사용해.

**R(tᵣ) = r**

지수분포라면 다음과 같아.

**r = e^(−λtᵣ)**  
**tᵣ = −ln(r)/λ**

예를 들어 고장률이 0.0001/시간이고 신뢰도 0.95를 보장하는 임무시간을 구하면 다음과 같아.

**t₀.₉₅ = −ln(0.95)/0.0001 ≈ 512.93시간**

목표 신뢰도가 높아질수록 허용 임무시간은 짧아져. 95% 신뢰수명과 90% 신뢰수명을 비교하면 95% 신뢰수명이 더 짧아야 정상이지.

## 3. 신뢰성 척도 계산 절차

### 3.1 기본 풀이 순서

1. 문제에서 주어진 값의 종류를 구분해. 고장률 λ인지, 평균수명인지, 누적고장확률 F(t)인지 먼저 확인해야 해.

2. 수명분포와 가정을 확인해. “고장률이 일정하다”는 문장은 지수분포 공식을 사용할 핵심 단서야.

3. 시간 단위를 통일해. 고장률이 시간당 값인데 임무시간이 일 단위라면 반드시 시간을 같은 단위로 바꿔야 해.

4. λt가 무차원량인지 확인해. 지수함수 e^(−λt)의 지수 부분에는 단위가 남아서는 안 돼.

5. 요구값에 맞는 식을 선택해. 생존확률이면 R(t), 누적고장확률이면 F(t), 평균수명이면 1/λ를 사용해.

6. 최종값의 범위를 검산해. 확률은 반드시 0과 1 사이에 있어야 하고 시간은 음수가 될 수 없어.

### 3.2 종합 예제

어떤 전자부품의 수명이 일정 고장률을 갖는 지수분포를 따르고 MTTF가 4,000시간이라고 하자.

먼저 고장률을 구해.

**λ = 1/MTTF = 1/4,000 = 0.00025/시간**

800시간 신뢰도는 다음과 같아.

**R(800) = e^(−0.00025×800) = e^(−0.2) ≈ 0.8187**

800시간 이내의 누적고장확률은 다음과 같아.

**F(800) = 1 − 0.8187 = 0.1813**

B₁₀ 수명은 다음과 같아.

**B₁₀ = −ln(0.9)/0.00025 ≈ 421.44시간**

중앙수명은 다음과 같아.

**t₀.₅ = ln 2/0.00025 ≈ 2,772.59시간**

여기서 MTTF가 4,000시간이라고 해서 R(4000)=0.5는 아니야.

**R(4000) = e^(−1) ≈ 0.3679**

즉, 평균수명 시점까지 생존할 확률은 약 36.79%야. 이것이 평균수명과 중앙수명을 혼동하면 안 되는 대표적인 이유야.

## 4. 비교와 경계

| 구분 | 기호 또는 식 | 핵심 의미 |
|---|---|---|
| 신뢰도 | R(t) | 시간 t를 초과하여 생존할 확률 |
| 누적고장확률 | F(t) | 시간 t 이내에 고장날 확률 |
| 고장밀도 | f(t) | 수명분포의 확률밀도 |
| 고장률 | λ(t)=f(t)/R(t) | t까지 생존한 제품의 순간적인 고장 위험 |
| 평균수명 | MTTF | 비수리 제품의 고장까지 평균시간 |
| 평균고장간격 | MTBF | 수리 가능한 시스템의 고장 사이 평균 작동시간 |
| 평균수리시간 | MTTR | 고장 후 복구까지 평균시간 |
| B₁₀ 수명 | R(B₁₀)=0.9 | 모집단의 10%가 고장하는 시간 |
| 가용도 | MTBF/(MTBF+MTTR) | 시스템이 작동 가능한 상태에 있는 비율 |

신뢰도와 불신뢰도는 여사건 관계이므로 합이 1이야. 하지만 신뢰도와 가용도는 여사건 관계가 아니야.

고장밀도는 전체 모집단의 수명분포를 나타내지만, 고장률은 이미 생존한 제품을 기준으로 한 조건부 위험이야.

평균수명은 확률이 아니라 시간이고, R(t)는 시간이 아니라 확률이야. 계산 결과에 단위가 있는지 확인하면 공식 선택 오류를 상당히 줄일 수 있어.

***

## 5. 시험 함정

1. **R(t)=F(t)로 착각하기**  
   올바른 관계는 R(t)=1−F(t)야.

2. **지수분포에서 부호를 빼먹기**  
   R(t)=e^(−λt)이야. 양의 지수로 계산하면 시간이 지날수록 신뢰도가 증가하는 모순이 생겨.

3. **고장률과 고장확률을 동일하게 보기**  
   λ는 보통 단위시간당 고장 위험이고, F(t)는 일정 기간까지 누적된 확률이야.

4. **MTTF 시점의 신뢰도를 0.5로 보기**  
   지수분포에서 R(MTTF)=e^(−1)≈0.3679야. R(t)=0.5가 되는 것은 중앙수명이야.

5. **B₁₀을 생존율 10% 시점으로 보기**  
   B₁₀은 누적고장률 10%, 신뢰도 90% 시점이야.

6. **시간 단위를 통일하지 않기**  
   시간당 고장률과 분 단위 임무시간을 그대로 곱하면 안 돼.

7. **일정 고장률 조건 없이 1/λ를 기계적으로 사용하기**  
   MTTF=1/λ는 일정 고장률을 갖는 지수분포에서 성립하는 대표 공식이야.

8. **신뢰도와 가용도를 혼동하기**  
   수리가 가능한 시스템에서는 고장이 발생해도 복구 후 다시 운용할 수 있으므로 두 척도가 다르게 나타날 수 있어.

### 문제 7

다음 설명이 맞는지 판단해봐.

## 7. 정답 및 해설

### 문제 1 정답

**약 0.8187**

**R(500) = e^(−0.0004×500) = e^(−0.2) ≈ 0.8187**

500시간 동안 고장 없이 작동할 확률은 약 81.87%야.

### 문제 2 정답

**0.88**

**R(1000) = 1 − F(1000) = 1 − 0.12 = 0.88**

### 문제 3 정답

**500시간**

**MTTF = 1/λ = 1/0.002 = 500시간**

### 문제 4 정답

**MTBF=1,500시간, λ≈0.000667/시간**

**MTBF = 12,000/8 = 1,500시간**

**λ = 1/1,500 ≈ 0.000667/시간**

### 문제 5 정답

**약 210.72시간**

먼저 고장률을 구해.

**λ = 1/2,000 = 0.0005/시간**

B₁₀에서는 신뢰도가 0.9이므로 다음과 같아.

**B₁₀ = −ln(0.9)/0.0005 ≈ 210.72시간**

### 문제 6 정답

**약 0.9804, 즉 98.04%**

**A = 600/(600+12) = 600/612 ≈ 0.9804**

### 문제 7 정답

**틀림**

지수분포에서 평균수명은 1/λ이고, 이때 신뢰도는 다음과 같아.

**R(1/λ) = e^(−1) ≈ 0.3679**

생존확률이 0.5가 되는 시점은 평균수명이 아니라 중앙수명 **ln 2/λ**야.

## 8. 요약

| 핵심 항목 | 반드시 기억할 식 |
|---|---|
| 신뢰도 함수 | R(t)=P(T>t) |
| 누적고장확률과의 관계 | R(t)=1−F(t) |
| 고장밀도 | f(t)=−R′(t) |
| 고장률 | λ(t)=f(t)/R(t) |
| 일반적인 신뢰도 | R(t)=exp[−∫₀ᵗλ(x)dx] |
| 일정 고장률의 신뢰도 | R(t)=e^(−λt) |
| 지수분포 평균수명 | MTTF=1/λ |
| 평균고장간격 | MTBF=총 작동시간/고장횟수 |
| 평균수리시간 | MTTR=총 수리시간/수리횟수 |
| 정상상태 가용도 | A=MTBF/(MTBF+MTTR) |
| Bₚ 수명 | Bₚ=−ln(1−p/100)/λ |
| 지수분포 중앙수명 | ln 2/λ |

신뢰성 계산의 중심은 **R(t), F(t), f(t), λ(t)의 연결 관계**야. 특히 일정 고장률이 제시되면 지수분포를 떠올리고, 평균수명 또는 MTBF의 역수로 λ를 구한 뒤 R(t)=e^(−λt)에 연결하면 돼.
