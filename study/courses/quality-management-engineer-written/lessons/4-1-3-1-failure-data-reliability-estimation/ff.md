## 1. 고장률 곡선

### 1.1 신뢰성 척도 사이의 관계

수명확률변수 T가 있을 때 기본 척도는 다음과 같아.

| 척도 | 정의 | 의미 |
|---|---:|---|
| 누적분포함수 | F(t) = P(T ≤ t) | 시간 t까지 고장날 확률 |
| 신뢰도함수 | R(t) = P(T > t) = 1 − F(t) | 시간 t를 넘겨 작동할 확률 |
| 확률밀도함수 | f(t) = dF(t)/dt | 특정 시점 부근에 고장이 집중되는 정도 |
| 고장률함수 | λ(t) = f(t)/R(t) | t까지 생존한 제품이 직후 고장날 조건부 비율 |
| 평균수명 | MTTF = E(T) = ∫₀∞R(t)dt | 비수리계가 고장날 때까지의 평균시간 |

여기서 가장 중요한 경계는 고장률 λ(t)를 단순한 고장확률로 보면 안 된다는 거야. λ(t)는 이미 t까지 살아남았다는 조건 아래에서 순간적으로 고장할 위험을 나타내는 비율이야.

짧은 구간 Δt에서는 다음과 같이 해석할 수 있어.

P(t < T ≤ t + Δt │ T > t) ≈ λ(t)Δt

또한 고장률을 알고 있다면 신뢰도는 다음 관계로 구할 수 있어.

R(t) = exp{−∫₀ᵗλ(u)du}

즉, 순간적인 고장 위험이 시간에 따라 누적되면서 신뢰도가 감소하는 구조야.

### 1.2 욕조곡선의 세 구간

대표적인 고장률 곡선은 욕조곡선이야. 처음에는 높고, 중간에는 낮고 일정하며, 마지막에는 다시 높아지는 모양이라 욕조와 닮았어.

| 구간 | 고장률 형태 | 주된 원인 | 대표 대책 |
|---|---|---|---|
| 초기고장기 | 감소형 고장률, DFR | 제조결함, 조립불량, 잠재결함 | 번인, 스크리닝, 공정개선 |
| 우발고장기 | 일정 고장률, CFR | 우발적 충격, 예측하기 어려운 외란 | 사용조건 관리, 중복설계 |
| 마모고장기 | 증가형 고장률, IFR | 마모, 피로, 부식, 열화 | 예방보전, 정기교환, 수명설계 |

#### 초기고장기

사용 초기에 약한 제품들이 먼저 탈락하면서 고장률이 점차 낮아지는 구간이야. 제품 하나가 시간이 지나면서 저절로 강해진다는 뜻은 아니야. 취약한 개체가 먼저 제거되어 살아남은 집단의 평균적인 건전성이 높아지는 선택효과로 이해해야 해.

번인 시험은 제품을 일정 시간 작동시켜 초기결함 제품을 출하 전에 걸러내는 방법이야. 하지만 번인 시간이 지나치게 길거나 조건이 너무 가혹하면 정상 제품의 수명까지 소모할 수 있어.

#### 우발고장기

고장률이 대체로 일정한 구간이야. 이 구간에서는 과거에 얼마나 오래 사용했는지가 앞으로의 고장 위험에 큰 영향을 주지 않는다고 보는 지수분포가 자주 사용돼.

λ(t) = λ일 때,

R(t) = e^(−λt)

F(t) = 1 − e^(−λt)

f(t) = λe^(−λt)

MTTF = 1/λ

지수분포에는 무기억성이 있어.

P(T > s + t │ T > s) = P(T > t)

그러나 실제 부품이 마모되는 상황까지 지수분포로 처리하면 위험해. 일정 고장률이라는 가정이 성립하는 우발고장기에 적합한 모형이기 때문이야.

#### 마모고장기

시간이 지날수록 고장률이 증가하는 구간이야. 반복하중에 의한 피로, 윤활 성능 저하, 부식, 절연 열화가 누적되면서 고장이 집중돼. 예방교환은 바로 이 구간에 진입하기 전에 부품을 교체하여 고장을 줄이는 전략이야.

### 1.3 와이블분포와 고장률의 모양

와이블분포는 형상모수 β에 따라 고장률 형태를 다양하게 표현할 수 있어. 위치모수를 0으로 두고 척도모수를 η라고 하면,

R(t) = exp{−(t/η)^β}

λ(t) = (β/η)(t/η)^(β−1)

| 형상모수 β | 고장률 형태 | 해석 |
|---:|---|---|
| β < 1 | 감소형 | 초기고장 특성 |
| β = 1 | 일정형 | 지수분포와 동일한 우발고장 특성 |
| β > 1 | 증가형 | 마모고장 특성 |

η는 특성수명으로, t = η일 때 신뢰도는 항상 e⁻¹, 약 0.3679야. 따라서 η를 신뢰도 50%가 되는 중앙수명으로 착각하면 안 돼.

### 구체적인 예시

어떤 전자부품의 우발고장기 고장률이 시간당 0.0002라고 해보자. 1,000시간 신뢰도는 다음과 같아.

R(1000) = e^(−0.0002×1000) = e⁻⁰·² ≈ 0.8187

평균수명은 다음과 같아.

MTTF = 1/0.0002 = 5,000시간

여기서 1,000시간 신뢰도가 약 81.87%라는 말은 동일 조건의 제품 가운데 약 81.87%가 1,000시간을 초과하여 작동한다는 뜻이야. 평균수명이 5,000시간이라고 해서 모든 제품이 5,000시간에 고장난다는 뜻은 아니야.

### 시험 함정

1. 초기고장기의 고장률은 시간이 지날수록 감소해.

2. 우발고장기의 일정 고장률 모형은 지수분포와 연결돼.

3. 마모고장기에는 예방보전과 정기교환이 효과적이야.

4. 고장률과 누적고장확률은 서로 다른 척도야.

5. 와이블분포에서 β = 1이면 지수분포가 돼.

## 2. 신뢰성 데이터분석

### 2.1 데이터의 기본 유형

신뢰성 데이터는 단순히 고장시간만 모은 자료가 아니야. 시험 종료 시점까지 고장하지 않은 제품도 중요한 정보를 제공해.

| 데이터 유형 | 관측 내용 | 해석 |
|---|---|---|
| 완전자료 | 모든 시험품의 정확한 고장시간 | 각 제품의 수명이 모두 관측됨 |
| 우측중도절단자료 | 일부 고장시간과 생존시간 | 종료 시점까지 고장하지 않은 제품이 존재 |
| 제1종 중도절단 | 미리 정한 시간에 시험 종료 | 종료시간 고정, 고장 개수 변동 |
| 제2종 중도절단 | 미리 정한 고장 개수에서 종료 | 고장 개수 고정, 종료시간 변동 |
| 구간자료 | 특정 점검구간 안에서 고장 확인 | 정확한 고장시점은 알 수 없음 |

중도절단품을 고장품처럼 계산하면 수명을 과소평가하고, 반대로 분석에서 완전히 제거하면 생존정보를 버리게 돼. 중도절단은 “수명을 모른다”가 아니라 “적어도 이 시간까지는 생존했다”라는 정보야.

### 2.2 분석 절차

신뢰성 데이터분석은 다음 흐름으로 진행해.

1. 시험 목적과 관측단위를 정해.

2. 고장의 정의와 판정기준을 고정해.

3. 고장시간과 중도절단시간을 기록해.

4. 적용할 수명분포를 선정해.

5. 분포의 모수를 추정해.

6. 적합도 검정으로 모형의 타당성을 확인해.

7. 신뢰도, 고장률, 평균수명, 백분위수명을 계산해.

8. 신뢰구간을 함께 제시해 불확실성을 표현해.

고장 정의가 시험 도중 바뀌면 데이터의 동일성이 깨져. 기능 완전정지를 고장으로 볼지, 성능이 규격 하한 아래로 떨어지는 순간을 고장으로 볼지 시험 전에 결정해야 해.

### 2.3 총시험시간과 지수분포 분석

일정 고장률을 가정하는 지수분포에서는 총시험시간이 핵심이야. n개의 제품을 시험하고 관측된 고장 수를 r, 각 제품이 실제로 시험에 기여한 시간을 합한 값을 Tₜ라고 하자.

Tₜ = 모든 고장품의 고장시간 합 + 모든 중도절단품의 관측시간 합

고장률의 최우추정량은 다음과 같아.

λ̂ = r/Tₜ

평균수명의 추정량은 다음과 같아.

MTTF̂ = Tₜ/r

완전자료에서 모든 n개가 고장했다면 r = n이므로 평균수명은 단순한 고장시간의 산술평균과 같아. 중도절단자료에서는 시험품 수 n이 아니라 실제 고장 수 r로 나눠야 한다는 점이 중요해.

### 구체적인 예시

제품 5개를 시험했더니 100시간, 160시간, 240시간에 3개가 고장했고, 나머지 2개는 300시간까지 고장하지 않아 시험을 종료했다고 해보자.

총시험시간은 다음과 같아.

Tₜ = 100 + 160 + 240 + 300 + 300 = 1,100시간

고장 수는 r = 3이므로,

λ̂ = 3/1100 ≈ 0.002727/시간

MTTF̂ = 1100/3 ≈ 366.67시간

200시간 신뢰도의 점추정값은 다음과 같아.

R̂(200) = e^(−0.002727×200) ≈ 0.5796

중도절단된 두 제품은 300시간씩 총 600시간의 생존정보를 제공했어. 이 둘을 분석에서 제외해 버리면 총시험시간을 500시간으로 잘못 계산하게 되고 고장률을 지나치게 크게 추정하게 돼.

### 2.4 생명표와 Kaplan–Meier 추정

특정 분포를 강하게 가정하기 어렵다면 비모수적 생존함수 추정법을 사용할 수 있어. 대표적인 방법이 Kaplan–Meier 추정량이야.

고장시점 tᵢ 직전에 위험에 노출된 제품 수를 nᵢ, 그 시점의 고장 수를 dᵢ라고 하면,

R̂(t) = ∏(tᵢ≤t)(1 − dᵢ/nᵢ)

신뢰도는 고장이 발생한 시점에서만 계단식으로 내려가. 중도절단이 발생한 순간에는 신뢰도가 직접 감소하지 않지만, 이후 위험집단의 크기가 줄어들어 다음 계산에 반영돼.

### 비교와 경계

| 분석법 | 장점 | 주의점 |
|---|---|---|
| 지수분포 분석 | 계산이 간단하고 총시험시간 활용 가능 | 일정 고장률 가정 필요 |
| 와이블분포 분석 | 감소형·일정형·증가형 고장률 표현 가능 | 모수 추정이 더 복잡함 |
| Kaplan–Meier법 | 특정 수명분포를 가정하지 않음 | 미래 구간 외삽이 제한적 |
| 생명표법 | 구간별 자료 처리에 편리 | 구간 설정에 따라 정밀도가 달라짐 |

### 시험 함정

1. 제1종 중도절단은 종료시간을 미리 정해.

2. 제2종 중도절단은 종료할 고장 개수를 미리 정해.

3. 중도절단품의 관측시간도 총시험시간에 포함해.

4. 지수분포에서 λ̂의 분모는 시험품 수가 아니라 총시험시간이야.

5. 중도절단은 결측치와 같지 않아. 생존했다는 부분정보가 남아 있어.

## 3. 신뢰성 척도의 검정과 추정

### 3.1 점추정과 구간추정

점추정은 하나의 수치로 모집단의 특성을 나타내는 방법이야. λ̂ = 0.002처럼 결과가 간단하지만 표본변동의 크기는 보여주지 못해.

구간추정은 일정한 신뢰수준에서 모수가 포함될 것으로 기대되는 범위를 제시해. 예를 들어 평균수명의 95% 신뢰구간이 300시간에서 520시간이라고 표현하는 방식이야.

95% 신뢰구간을 “이 계산된 구간 안에 참값이 들어 있을 확률이 95%”라고 그대로 해석하면 엄밀하게는 틀려. 동일한 절차로 표본추출과 구간계산을 반복했을 때 만들어진 구간 가운데 약 95%가 참모수를 포함한다는 뜻이야.

좋은 추정량의 대표적 성질은 다음과 같아.

| 성질 | 의미 |
|---|---|
| 불편성 | 추정량의 기댓값이 참모수와 일치 |
| 일치성 | 표본이 커질수록 참모수에 가까워짐 |
| 효율성 | 불편추정량 중 분산이 상대적으로 작음 |
| 충분성 | 표본이 가진 모수 정보를 충분히 반영 |

### 3.2 가설검정의 구조

신뢰성 검정에서는 모집단의 신뢰도나 평균수명이 요구조건을 만족하는지 판단해.

예를 들어 요구 평균수명이 1,000시간 이상인지 검정한다면 보수적으로 다음처럼 설정할 수 있어.

H₀: μ ≤ 1,000시간  
H₁: μ > 1,000시간

검정 절차는 다음과 같아.

1. 귀무가설 H₀와 대립가설 H₁을 설정해.

2. 유의수준 α를 정해.

3. 수명분포와 검정통계량을 선택해.

4. 표본자료로 검정통계량을 계산해.

5. 기각역 또는 p값과 비교해.

6. H₀의 기각 여부를 결정해.

7. 품질보증 관점에서 결론을 해석해.

p값이 α보다 작으면 H₀를 기각해. p값이 크다고 해서 H₀가 참이라고 증명된 것은 아니야. 단지 현재 표본으로 H₀를 기각할 증거가 충분하지 않다는 뜻이야.

### 3.3 제1종 오류와 제2종 오류

| 실제 상태와 판단 | H₀ 기각 | H₀ 기각하지 않음 |
|---|---|---|
| H₀가 참 | 제1종 오류, 확률 α | 올바른 판단 |
| H₀가 거짓 | 올바른 판단, 검정력 1−β | 제2종 오류, 확률 β |

제1종 오류는 기준을 만족하지 못한다고 잘못 판단하는 위험과 연결될 수 있고, 제2종 오류는 실제로 불충분한 제품을 통과시키는 위험과 연결될 수 있어. 다만 생산자위험과 소비자위험의 정확한 대응은 귀무가설을 어떻게 설정했는지에 따라 달라지므로 기계적으로 외우면 안 돼.

### 3.4 지수분포 고장률의 신뢰구간

지수분포를 가정하고 총시험시간을 Tₜ, 관측 고장 수를 r이라고 할 때 고장률의 점추정량은 λ̂ = r/Tₜ야.

완전자료 또는 적용된 중도절단 방식의 조건을 만족할 때, 카이제곱분포를 이용한 양측 100(1−α)% 신뢰구간은 일반적으로 다음 형태로 표현해.

λ의 하한 = χ²(α/2, 2r) / (2Tₜ)

λ의 상한 = χ²(1−α/2, 2r+2) / (2Tₜ)

여기서 χ²(p, ν)는 자유도 ν인 카이제곱분포의 하위 p 분위수를 뜻해. 교재에 따라 분위수 표기법과 중도절단 조건이 다를 수 있으므로 자유도와 꼬리방향을 반드시 확인해야 해.

평균수명 θ = 1/λ의 구간은 고장률 구간의 역수를 취하되 순서를 뒤집어야 해.

θ의 하한 = 1/λ의 상한

θ의 상한 = 1/λ의 하한

고장률이 커질수록 평균수명은 짧아지는 역관계 때문이야.

### 3.5 신뢰도 추정과 보증수명

지수분포에서는 λ를 추정한 뒤 임의의 사용시간 t₀에서 신뢰도를 추정할 수 있어.

R̂(t₀) = exp(−λ̂t₀)

신뢰도 하한을 보수적으로 계산할 때는 고장률의 상한을 사용해야 해.

R의 하한(t₀) = exp{−λ의 상한 × t₀}

고장률이 클수록 신뢰도가 작아지기 때문이야. 반대로 신뢰도 상한에는 고장률 하한을 사용해.

목표 신뢰도 R₀를 만족하는 보증시간 t₀는 지수분포에서 다음과 같이 구해.

t₀ = −ln(R₀)/λ

예를 들어 λ = 0.0001/시간이고 목표 신뢰도가 0.90이라면,

t₀ = −ln(0.90)/0.0001 ≈ 1,053.6시간

### 3.6 적합도 검정과 모수 검정의 차이

적합도 검정은 데이터가 특정 분포를 따른다고 볼 수 있는지 판단해. 모수 검정은 해당 분포를 전제로 평균수명이나 고장률 같은 모수가 기준을 만족하는지 판단해.

| 구분 | 질문 | 대표 대상 |
|---|---|---|
| 적합도 검정 | 선택한 분포가 데이터에 적절한가? | 지수분포, 와이블분포, 정규분포 |
| 모수 검정 | 모수가 규격 또는 목표를 만족하는가? | 평균수명, 고장률, 특정 시점 신뢰도 |
| 구간추정 | 모수의 불확실한 범위는 어디인가? | λ, MTTF, R(t), 백분위수명 |

분포가 부적절한데 모수만 정밀하게 계산하면 “틀린 지도에서 좌표를 정밀하게 읽는 것”과 같아. 먼저 분포 가정의 타당성을 살펴본 다음 모수 추론을 해야 해.

### 시험 함정

1. 신뢰수준 95%와 신뢰도 R(t) = 0.95는 전혀 다른 개념이야.

2. p값이 크다고 귀무가설이 참으로 확정되는 것은 아니야.

3. 평균수명 구간은 고장률 구간의 역수를 취하면서 상·하한이 뒤바뀌어.

4. 보수적인 신뢰도 하한에는 고장률 상한을 사용해.

5. 점추정값만으로는 추정의 불확실성을 알 수 없어.

6. 적합도 검정과 모수 검정의 목적을 구분해야 해.

## 4. 세 주제를 하나로 연결하기

신뢰성 시험은 다음과 같은 하나의 학습 고리로 이해하면 편해.

1. 고장률 곡선으로 수명단계를 판단해.

2. 수명단계와 고장 메커니즘에 맞는 분포를 선택해.

3. 신뢰성 데이터분석에서 고장시간과 중도절단시간을 정리해.

4. 모수를 점추정하고 R(t), λ(t), MTTF를 계산해.

5. 적합도 검정으로 분포 가정을 확인해.

6. 신뢰구간과 가설검정으로 불확실성과 목표 충족 여부를 판단해.

예를 들어 마모고장 자료인데 지수분포를 적용하면 일정 고장률을 강제로 가정하게 돼. 계산 자체는 가능해도 시간에 따라 증가하는 위험을 놓칠 수 있어. 이때는 β > 1인 와이블분포가 더 자연스러울 가능성이 커.

## 5. 계산형 문제 해결 절차

### 지수분포 문제

1. λ, t, R(t), F(t), MTTF 중 주어진 값을 표시해.

2. 고장률이 일정하다는 조건이 있는지 확인해.

3. R(t) = e^(−λt)를 중심식으로 잡아.

4. 평균수명은 MTTF = 1/λ를 사용해.

5. 고장확률을 요구하면 F(t) = 1 − R(t)로 바꿔.

6. 시간과 고장률의 단위가 서로 맞는지 확인해.

### 중도절단 문제

1. 실제 고장 수 r을 세어.

2. 각 제품의 시험 기여시간을 모두 더해 총시험시간 Tₜ를 구해.

3. λ̂ = r/Tₜ를 계산해.

4. MTTF̂ = Tₜ/r을 계산해.

5. 필요한 시점의 신뢰도는 R̂(t) = e^(−λ̂t)로 계산해.

6. 중도절단품의 시간을 빠뜨리지 않았는지 확인해.

## 8. 요약

1. **고장률 곡선**은 초기고장기, 우발고장기, 마모고장기로 구분하며 각각 감소형, 일정형, 증가형 고장률에 대응해.

2. 지수분포는 일정 고장률을 가정하며 R(t) = e^(−λt), MTTF = 1/λ의 관계를 사용해.

3. 와이블분포에서는 β < 1이면 초기고장, β = 1이면 우발고장, β > 1이면 마모고장 특성을 나타내.

4. **신뢰성 데이터분석**에서는 고장시간뿐 아니라 중도절단품의 생존시간도 반드시 반영해야 해.

5. 지수분포의 중도절단자료에서는 λ̂ = r/Tₜ, MTTF̂ = Tₜ/r을 사용해.

6. **신뢰성 척도의 검정과 추정**은 점추정, 신뢰구간, 가설검정, 적합도 검정을 서로 구분하는 것이 핵심이야.

7. 고장률과 평균수명은 역관계이므로 신뢰구간을 변환할 때 상한과 하한이 뒤바뀌어.
