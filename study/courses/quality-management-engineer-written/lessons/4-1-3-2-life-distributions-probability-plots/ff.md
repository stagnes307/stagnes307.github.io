# 4-1-3-2. 수명 데이터를 읽는 신뢰성 추정법

품질경영기사 필기  
신뢰성 시험과 추정 (2/3)

> 핵심 목표: 정상 조건의 수명자료와 확률도를 이용해 신뢰성을 추정하고, 가속 조건의 결과를 사용 조건으로 환산하는 흐름을 이해한다.

## 1. 신뢰성 시험의 공통 언어

신뢰성 시험은 제품이나 부품을 일정 조건에서 작동시켜 고장시간을 관측하고, 그 결과로 수명분포와 신뢰도 R(t)를 추정하는 과정이야. 신뢰도는 제품이 시간 t까지 고장 없이 작동할 확률이므로 다음처럼 표현해.

**R(t) = P(T > t) = 1 − F(t)**

여기서 T는 수명, F(t)는 누적고장확률이야. 확률밀도함수 f(t)가 주어지면 고장률은 다음 관계를 가져.

**λ(t) = f(t) / R(t)**

시험자료에는 시험 중 고장난 시료의 정확한 고장시간뿐 아니라 시험 종료까지 고장나지 않은 시료도 포함돼. 후자를 **관측중단자료 또는 중도절단자료**라고 해. 고장나지 않았다는 이유로 버리면 안 돼. 적어도 해당 종료시간까지 생존했다는 중요한 정보이기 때문이야.

시험 설계에서는 시료 수, 시험시간, 시험환경, 고장판정 기준을 먼저 고정해야 해. 특히 고장판정 기준이 시험 도중 바뀌면 서로 다른 사건을 하나의 고장으로 집계하게 되어 추정 결과가 흔들릴 수 있어.

## 2. 정상수명시험

**정상수명시험**은 실제 사용조건 또는 그와 거의 같은 정격조건에서 제품을 운전하며 수명을 관측하는 시험이야. 온도, 전압, 하중과 같은 스트레스가 정상 범위에 있으므로 시험 결과를 사용현실에 직접 연결하기 쉽다는 장점이 있어.

일반적인 절차는 다음과 같아.

1. 모집단을 대표하도록 시료를 선정한다.
2. 사용조건과 고장판정 기준을 명확히 정한다.
3. 각 시료의 고장시간을 기록한다.
4. 시험 종료 시점의 미고장 시료를 중도절단자료로 표시한다.
5. 적절한 수명분포를 선정한다.
6. 분포의 모수를 추정하고 신뢰도, 평균수명, 백분위수명을 계산한다.
7. 적합도와 신뢰구간을 검토한다.

정상수명시험은 해석이 자연스럽지만 수명이 긴 제품에는 시간과 비용이 많이 들어. 예를 들어 실제 수명이 10년인 부품을 정상 조건에서 시험하면 개발 일정 안에 충분한 고장을 얻기 어렵지. 고장 수가 너무 적으면 추정치의 불확실성도 커져.

시험 종료 방식도 구별해야 해. **정수중단시험**은 미리 정한 고장개수에 도달하면 끝내고, **정시중단시험**은 미리 정한 시간이 되면 끝내. 전자는 종료시간이 변할 수 있고, 후자는 고장개수가 변할 수 있다는 차이가 있어.

## 3. 확률도를 통한 신뢰성 추정

**확률도(와이블, 정규, 지수 등)를 통한 신뢰성추정**은 수명자료를 특정 확률분포에 맞는 좌표로 변환해 점들이 직선에 가까운지 확인하고, 그 직선으로 분포 모수를 추정하는 방법이야.

자료를 작은 순서로 정렬해 t₍₁₎ ≤ t₍₂₎ ≤ … ≤ t₍ₙ₎으로 놓고 각 고장시간에 누적고장확률을 배정해. 완전자료의 대표적인 중앙순위 근사식은 다음과 같아.

**F̂ᵢ = (i − 0.3) / (n + 0.4)**

교재나 문제 조건에 따라 i/(n+1) 같은 다른 순위식을 사용할 수도 있어. 따라서 시험에서는 문제에 제시된 식을 우선 적용해야 해.

### 와이블 확률도

와이블분포의 신뢰도는 다음과 같아.

**R(t) = exp[−(t/η)ᵝ]**

η는 척도모수, β는 형상모수야. 양변을 변환하면 다음 직선식이 만들어져.

**ln{−ln[1 − F(t)]} = β ln t − β ln η**

가로축을 ln t, 세로축을 ln{−ln[1−F(t)]}로 잡으면 기울기가 β가 돼. 직선이 F = 0.632인 지점과 만나는 수명은 η야. t = η이면 R(t) = e⁻¹ ≈ 0.368이므로 누적고장확률은 약 0.632가 되기 때문이야.

β는 고장률의 형태를 알려줘.

- β < 1: 시간이 지나면서 고장률이 감소하는 초기고장형
- β = 1: 고장률이 일정한 우발고장형
- β > 1: 시간이 지나면서 고장률이 증가하는 마모고장형

### 정규 확률도

정규분포는 수명이 평균 μ를 중심으로 대칭이고 표준편차 σ로 흩어진다고 가정해.

**F(t) = Φ[(t − μ)/σ]**

정규확률도에서 자료가 직선에 가깝다면 평균수명은 누적고장확률 50%에 해당하는 시간으로 읽을 수 있어. 분포가 음의 수명까지 수학적으로 허용하므로 평균에 비해 표준편차가 지나치게 큰 수명자료에는 물리적 해석이 부자연스러울 수 있어.

### 지수 확률도

지수분포는 고장률 λ가 시간에 따라 일정하다고 가정해.

**R(t) = exp(−λt)**  
**MTTF = 1/λ**

변환식은 다음과 같아.

**−ln R(t) = λt**

지수확률도에서 직선성이 확보되면 기울기로 λ를 추정할 수 있어. 하지만 마모가 진행되는 제품에 지수분포를 무조건 적용하면 시간에 따라 증가하는 고장위험을 놓치게 돼.

## 4. 확률도 선택과 판독 경계

확률도에서 점들이 직선에 가깝다는 것은 해당 분포가 자료를 비교적 잘 설명한다는 뜻이야. 완벽히 직선이어야 한다는 의미는 아니며, 시료 수가 적을 때는 우연한 흔들림도 커져.

분포 선택은 단순히 직선의 모양만 보지 말고 고장 메커니즘과 함께 판단해야 해.

| 분포 | 핵심 가정 | 대표적인 판독값 | 주의점 |
|---|---|---|---|
| 와이블 | 고장률이 감소·일정·증가할 수 있음 | β, η | 다양한 형태를 표현하지만 모수 의미를 혼동하기 쉬움 |
| 정규 | 수명이 평균을 중심으로 대칭 | μ, σ | 강한 우측 꼬리나 양수 제약이 있는 자료에 부적절할 수 있음 |
| 지수 | 고장률이 일정 | λ, MTTF | 마모고장이나 초기고장을 설명하지 못함 |

와이블분포에서 β = 1이면 지수분포가 돼. 따라서 두 분포는 완전히 별개의 체계가 아니라 와이블분포가 지수분포를 포함하는 관계야.

또한 **평균수명**과 **B₁₀ 수명**을 구별해야 해. B₁₀은 누적고장확률이 10%인 시간, 즉 신뢰도가 90%인 시간이야. 평균수명이 길어도 수명분산이 크면 B₁₀은 짧을 수 있어.

## 5. 가속수명시험

**가속수명시험**은 정상 사용조건보다 높은 스트레스를 가해 고장을 빠르게 발생시키고, 스트레스와 수명의 관계를 이용해 정상조건의 수명을 추정하는 시험이야.

핵심 흐름은 다음과 같아.

**가속 스트레스 설정 → 고장시간 관측 → 각 조건의 수명분포 추정 → 수명·스트레스 관계식 적합 → 사용조건으로 외삽**

온도 가속에는 아레니우스 관계가 널리 사용돼.

**L = A exp[Eₐ/(kT)]**

L은 특성수명, T는 절대온도, Eₐ는 활성화에너지, k는 볼츠만상수야. 온도가 높아질수록 일반적으로 열화반응이 빨라져 수명은 짧아져.

두 온도조건 사이의 가속계수 AF는 보통 다음 형태로 계산해.

**AF = L사용 / L가속 = exp[(Eₐ/k)(1/T사용 − 1/T가속)]**

전압이나 기계적 응력에는 역거듭제곱 관계를 사용할 수 있어.

**L = K·S⁻ⁿ**

S가 스트레스이고 n이 가속민감도라면, 스트레스가 커질수록 수명은 감소해.

가속수명시험이 성립하려면 가속조건에서도 정상조건과 **동일한 고장 메커니즘**이 유지되어야 해. 스트레스를 지나치게 높여 실제 사용 중에는 발생하지 않는 용융, 절연파괴, 구조변형을 일으키면 빠른 고장은 얻지만 정상수명 추정에는 쓸 수 없어.

## 6. 정상시험·확률도·가속시험의 연결

세 요소는 서로 경쟁하는 방법이 아니라 하나의 추정 사슬을 이뤄.

1. 정상수명시험 또는 가속수명시험으로 고장시간을 얻는다.
2. 확률도로 각 조건의 수명분포가 적절한지 확인한다.
3. 분포 모수와 신뢰수명을 추정한다.
4. 가속시험이라면 스트레스별 특성수명을 가속모형에 연결한다.
5. 정상 사용조건으로 환산해 목표 신뢰도를 평가한다.

예를 들어 전자부품을 125°C, 145°C, 165°C에서 시험했다고 해보자. 각 온도의 고장시간을 와이블 확률도에 표시해 β와 η를 구해. 세 조건에서 β가 비슷하다면 동일한 고장 메커니즘이라는 가정을 어느 정도 뒷받침할 수 있어. 이후 η와 절대온도의 관계를 아레니우스식에 적합해 정상 사용온도에서의 η를 추정하고, 목표시간 t₀의 신뢰도 R(t₀)를 계산해.

반대로 온도가 높아질수록 β가 크게 달라지거나 확률도에 서로 다른 기울기의 두 직선이 나타난다면 복수 고장모드 또는 메커니즘 변화 가능성을 점검해야 해.

## 7. 계산 예시

어떤 부품의 수명이 와이블분포를 따르고 β = 2, η = 1,000시간이라고 하자. 500시간에서의 신뢰도는 다음과 같아.

**R(500) = exp[−(500/1,000)²] = exp(−0.25) ≈ 0.7788**

따라서 약 77.9%가 500시간까지 살아남는다고 추정해. 누적고장확률은 약 22.1%야.

B₁₀ 수명은 F(t) = 0.10, 즉 R(t) = 0.90을 만족하는 시간이야.

**0.90 = exp[−(t/1,000)²]**

**t = 1,000√[−ln(0.90)] ≈ 325시간**

η가 1,000시간이라고 해서 B₁₀도 1,000시간이라고 생각하면 안 돼. η에서는 이미 약 63.2%가 고장난 상태야.

지수분포에서 MTTF가 2,000시간이면 λ = 1/2,000 = 0.0005/시간이야. 1,000시간 신뢰도는 다음과 같아.

**R(1,000) = exp(−0.0005 × 1,000) = e⁻⁰·⁵ ≈ 0.6065**

## 8. 시험에서 자주 나오는 함정

### 신뢰도와 누적고장확률의 뒤바뀜

F(t) = 0.1이면 신뢰도는 0.1이 아니라 0.9야. 항상 R(t) = 1 − F(t)를 먼저 확인해.

### 와이블 모수의 의미 혼동

β는 기울기와 고장률 형태를 결정하고, η는 척도를 결정해. β와 η를 서로 바꾸어 대입하면 안 돼.

### η를 평균수명으로 단정

와이블분포의 η는 F(η) ≈ 0.632가 되는 특성수명이야. 평균수명은 일반적으로 ηΓ(1+1/β)이므로 항상 η와 같지는 않아.

### 섭씨온도를 아레니우스식에 직접 대입

아레니우스식의 T는 절대온도야. 반드시 **K = °C + 273.15**로 변환해야 해.

### 가속계수 방향 반전

일반적으로 AF = 정상조건 수명 / 가속조건 수명으로 정의하면 1보다 커. 문제에서 가속계수 정의를 반대로 제시할 수도 있으므로 식의 분자와 분모를 확인해야 해.

### 가속과 과부하 파괴의 혼동

고장을 빨리 만들었다고 모두 유효한 가속시험은 아니야. 동일한 열화 메커니즘이 유지되지 않으면 정상조건으로 외삽할 근거가 사라져.

## 9. 확인 문제

1. 와이블분포에서 β = 0.7일 때 고장률은 시간에 따라 어떤 경향을 보일까?

2. 와이블분포에서 t = η일 때 신뢰도와 누적고장확률을 각각 구해봐.

3. 지수분포의 MTTF가 4,000시간일 때 고장률 λ와 2,000시간 신뢰도를 구해봐.

4. 가속수명시험에서 스트레스를 무조건 높일 수 없는 가장 중요한 이유는 무엇일까?

5. 정규확률도에서 자료가 직선에 가깝고 누적고장확률 50%에 해당하는 시간이 800시간이라면 어떤 모수를 읽은 것일까?

## 10. 정답과 해설

1. **감소형 고장률**이야. 와이블 형상모수 β가 1보다 작으면 초기고장형으로 해석해.

2. **R(η) = e⁻¹ ≈ 0.368**, **F(η) = 1 − e⁻¹ ≈ 0.632**야. η는 평균수명이 아니라 특성수명이야.

3. **λ = 1/4,000 = 0.00025/시간**이야.  
   R(2,000) = exp(−0.00025 × 2,000) = e⁻⁰·⁵ ≈ **0.6065**야.

4. 지나친 스트레스가 **정상 사용조건과 다른 고장 메커니즘**을 만들 수 있기 때문이야. 이 경우 정상조건 수명으로의 외삽이 타당하지 않아.

5. 정규분포의 **평균 μ**를 읽은 거야. 정규분포는 평균과 중앙값이 같으므로 F(t) = 0.5인 시간이 μ에 해당해.

## 11. 회상 요약

- 정상수명시험은 정상 사용조건에서 직접 수명을 관측하므로 해석은 쉽지만 시간과 비용이 많이 들어.
- 확률도는 수명자료를 직선화해 분포 적합성과 모수를 시각적으로 추정하는 도구야.
- 와이블분포의 β는 고장률 형태, η는 누적고장확률이 약 63.2%가 되는 특성수명을 나타내.
- 지수분포는 일정한 고장률을 가정하며 MTTF = 1/λ 관계를 가져.
- 정규분포는 평균을 중심으로 대칭인 수명자료에 적합해.
- 가속수명시험은 높은 스트레스에서 얻은 수명을 정상조건으로 외삽하지만, 동일한 고장 메커니즘이 유지되어야 해.
- 계산에서는 R(t)와 F(t), 섭씨와 절대온도, 평균수명과 특성수명, 가속계수의 방향을 구별하는 것이 핵심이야.
