📦 신뢰성 샘플링기법

정의와 목적

신뢰성 샘플링기법은 모집단 전체를 시험하지 않고 일부 표본의 고장 수, 고장시간 또는 성능자료로 제품군의 신뢰성을 판정하는 방법이야. 일반적인 품질 샘플링이 현재의 불량 여부를 주로 다룬다면 신뢰성 샘플링은 일정한 임무시간 동안 기능을 유지하는지도 고려해. 신뢰성 시험은 시간과 비용이 많이 들고 파괴시험이 될 수도 있으므로, 표본 크기와 시험시간을 합리적으로 정해야 해.

1회 샘플링에서는 관측 고장 수 r이 c 이하이면 합격하고, c를 초과하면 불합격시켜. 예를 들어 n = 20, c = 1이면 고장이 0개 또는 1개일 때 합격하고 2개 이상이면 불합격이야. 여기서 c는 반드시 발생해야 하는 고장 수가 아니라 허용되는 최대 고장 수라는 점을 기억해.

이항분포에 의한 합격확률

각 제품의 고장 여부가 서로 독립이고 고장확률이 모두 p라면 고장 수 X는 이항분포를 따라. 합격확률은 Pₐ(p) = P(X ≤ c)이고, 전개하면 Pₐ(p) = Σ C(n,x)pˣ(1−p)ⁿ⁻ˣ이야. 합은 x = 0부터 c까지 계산해. 고장확률이 낮을수록 합격확률은 높아지고, 이 관계를 나타낸 것이 OC 곡선이야.

n = 10, c = 0, p = 0.05라면 무고장일 때만 합격하므로 Pₐ = 0.95¹⁰ ≈ 0.5987이야. c = 1이면 고장 0개와 1개의 확률을 더해 Pₐ ≈ 0.5987 + 0.3151 = 0.9138이 돼. c를 크게 하면 합격은 쉬워지지만 신뢰성이 낮은 제품군이 통과할 위험도 커져.

무고장 신뢰성 입증시험

n개가 시간 t까지 모두 생존해야 합격하는 계획은 c = 0 무고장 시험이야. 제품 하나의 신뢰도가 R(t)이면 독립인 n개가 모두 무고장일 확률은 [R(t)]ⁿ이야. 목표 신뢰도 R₀를 신뢰수준 1−α로 입증하려면 R₀ⁿ ≤ α가 되도록 설계하며, 필요한 표본 수는 n ≥ ln(α) ÷ ln(R₀)로 계산해.

R₀ = 0.90을 신뢰수준 95%로 입증하면 α = 0.05야. n ≥ ln(0.05) ÷ ln(0.90) ≈ 28.43이므로 최소 표본은 29개야. 표본 수는 조건을 충족해야 하므로 계산값을 버리지 않고 반드시 올림해. 실제로 0.90²⁹ ≈ 0.0471은 0.05 이하지만 0.90²⁸ ≈ 0.0523은 조건을 만족하지 못해.

생산자 위험과 소비자 위험

생산자 위험 α는 양호한 제품군이 불합격되는 확률이고, 소비자 위험 β는 신뢰성이 낮은 제품군이 합격되는 확률이야. 양호한 고장확률을 p₀, 불량한 고장확률을 p₁이라 하면 일반적으로 Pₐ(p₀) ≥ 1−α와 Pₐ(p₁) ≤ β를 요구해. 좋은 제품의 거절이 α이고 나쁜 제품의 수락이 β라는 주체 구분이 시험에서 중요해.

⚖️ 간섭이론과 안전계수

강도와 하중의 확률적 관계

간섭이론과 안전계수에서 간섭이론은 제품이 견딜 수 있는 강도 X와 제품에 작용하는 하중 S를 확률변수로 다뤄. 정상 작동 조건은 X > S이고, 고장 조건은 S ≥ X야. 따라서 신뢰도는 R = P(X > S), 고장확률은 Pf = P(S ≥ X) = 1−R이야.

간섭은 물체가 공간적으로 충돌한다는 뜻이 아니라 강도분포와 하중분포가 겹치는 현상이야. 평균강도가 평균하중보다 크더라도 두 분포의 산포가 크면 약한 제품에 큰 하중이 작용하는 경우가 생겨. 따라서 평균값의 차이만으로 안전을 확정할 수 없어.

일반적인 신뢰도 표현

강도와 하중이 독립이고 확률밀도함수를 각각 fX(x), fS(s)라고 하면 신뢰도는 R = ∫FS(x)fX(x)dx로 나타낼 수 있어. 이는 특정 강도 x가 주어졌을 때 하중이 그보다 작을 확률을 모든 강도에 대해 평균한 식이야. 같은 관계는 R = ∫[1−FX(s)]fS(s)ds로도 표현할 수 있어.

독립 정규분포의 계산

강도 X가 N(μX, σX²), 하중 S가 N(μS, σS²)을 따르고 서로 독립이라고 하자. 안전여유 M = X−S도 정규분포를 따르며 평균은 μX−μS, 분산은 σX²+σS²이야. 따라서 신뢰성 지수 z는 다음과 같아.

z = (μX−μS) ÷ √(σX²+σS²)

신뢰도는 R = Φ(z)이고 고장확률은 1−Φ(z)야. 평균강도 120 MPa, 강도 표준편차 8 MPa, 평균하중 100 MPa, 하중 표준편차 6 MPa라면 평균차는 20 MPa이고 결합 표준편차는 √(8²+6²) = 10 MPa야. 따라서 z = 2.00, R = Φ(2.00) ≈ 0.9772, 고장확률은 약 0.0228이야.

상관관계가 있을 때

강도와 하중의 상관계수가 ρ라면 안전여유의 분산은 σM² = σX²+σS²−2ρσXσS야. 따라서 z의 분모도 이 분산의 제곱근으로 바뀌어. 문제에서 독립이라고 하면 ρ = 0이므로 분산을 단순히 더해. 표준편차를 직접 더하지 않고 분산을 더한 뒤 제곱근을 취해야 해.

안전계수의 의미와 한계

안전계수는 일반적으로 대표 강도를 대표 하중으로 나눈 값이야. 평균값을 사용하면 ns = μX ÷ μS로 표현해. 평균강도가 150 MPa이고 평균하중이 100 MPa라면 안전계수는 1.5야. 이는 대표 강도가 대표 하중의 1.5배라는 뜻이지 신뢰도가 150%라는 뜻은 아니야.

같은 안전계수와 서로 다른 신뢰도

두 설계의 평균강도가 120 MPa이고 평균하중이 100 MPa라면 평균 안전계수는 모두 1.2야. 설계 A에서 σX = 4, σS = 3이면 z = 20 ÷ 5 = 4로 신뢰도는 약 0.99997이야. 설계 B에서 σX = 12, σS = 9이면 z = 20 ÷ 15 ≈ 1.33으로 신뢰도는 약 0.9082야. 평균 안전계수가 같아도 분포의 폭이 다르면 신뢰도는 크게 달라져.

신뢰도를 높이는 원리

  1. 평균강도 μX를 높인다.
  2. 평균하중 μS를 낮춘다.
  3. 공정능력 향상과 재료 균질화로 강도의 표준편차를 줄인다.
  4. 과부하 방지와 사용환경 관리로 하중의 표준편차를 줄인다.

평균강도를 높이는 것만이 유일한 해법은 아니야. 제조 산포를 줄이면 재료를 과도하게 늘리지 않고도 신뢰도를 높일 수 있어. 이 지점에서 품질관리와 신뢰성 설계가 서로 연결돼.

🔗 두 주제의 연결

신뢰성 샘플링기법은 실제 시험 결과로 제품군의 신뢰성을 판정하는 통계적 의사결정 방법이야. 간섭이론과 안전계수는 강도와 하중의 관계를 통해 제품이 왜 고장하는지 설명하는 설계 모형이야. 설계 단계에서 간섭이론으로 목표 고장확률을 정하고, 생산 후에는 신뢰성 샘플링시험으로 목표 달성 여부를 입증할 수 있어.

🚨 시험 함정

  1. 생산자 위험 α와 소비자 위험 β의 주체를 바꾸지 않아야 해.
  2. c는 정확히 발생해야 하는 고장 수가 아니라 허용 가능한 최대 고장 수야.
  3. 무고장 시험의 표본 수는 조건 충족을 위해 반드시 올림해.
  4. 신뢰도 R₀와 통계적 신뢰수준 1−α를 구분해야 해.
  5. 정상 조건은 X > S이고 고장 조건은 S ≥ X야.
  6. 독립인 강도와 하중의 차이에서는 분산을 더하고 그 결과에 제곱근을 취해.
  7. 안전계수는 확률이 아니므로 안전계수 1.5를 신뢰도 150%로 해석하면 안 돼.

📝 확인 문제

문제 1

n = 15, c = 0인 신뢰성 샘플링시험에서 제품 하나가 시험시간 동안 생존할 확률이 0.95일 때 합격확률을 구해.

문제 2

목표 신뢰도 0.90을 신뢰수준 90%로 무고장 입증하려 할 때 필요한 최소 표본 수를 구해.

문제 3

c = 2인 샘플링계획에서 관측된 고장이 2개라면 합격인지 불합격인지 판단해.

문제 4

강도 X와 하중 S가 독립이고 X ∼ N(130, 10²), S ∼ N(100, 10²)일 때 신뢰성 지수 z와 신뢰도 R을 구해.

문제 5

평균강도 180 MPa, 평균하중 120 MPa일 때 평균값 기준 안전계수를 구하고, 이 값만으로 고장확률을 확정할 수 있는지 판단해.

✅ 정답 및 해설

문제 1 정답

0.95¹⁵ ≈ 0.4633이야. c = 0이므로 15개가 모두 생존해야 합격해.

문제 2 정답

22개야. α = 0.10이고 n ≥ ln(0.10) ÷ ln(0.90) ≈ 21.85이므로 올림해.

문제 3 정답

합격이야. r ≤ c이면 합격하므로 관측 고장 수 2는 허용 범위 안에 있어.

문제 4 정답

평균차는 30이고 결합 표준편차는 √(10²+10²) ≈ 14.142야. 따라서 z ≈ 2.12이고 R = Φ(2.12) ≈ 0.9830이야.

문제 5 정답

안전계수는 180 ÷ 120 = 1.5야. 그러나 강도와 하중의 분포 및 산포가 없으므로 이 값만으로 고장확률을 확정할 수 없어.

✨ 요약

  • 신뢰성 샘플링기법: 일부 표본의 고장자료로 제품군의 신뢰성을 판정해.
  • 합격 규칙: 관측 고장 수 r이 합격판정개수 c 이하이면 합격이야.
  • 무고장 시험: 합격확률은 [R(t)]ⁿ이고 필요한 표본 수는 n ≥ ln(α) ÷ ln(R₀)이야.
  • 위험: α는 양호한 제품군을 거절할 생산자 위험이고 β는 불량한 제품군을 수락할 소비자 위험이야.
  • 간섭이론과 안전계수: 정상은 X > S이고 신뢰도는 R = P(X > S)야.
  • 정규모형: 독립일 때 z = (μX−μS) ÷ √(σX²+σS²), R = Φ(z)야.
  • 안전계수의 경계: 대표값의 비율일 뿐 산포를 직접 반영하지 않으므로 고장확률과 같지 않아.
