## 1. 신뢰성 샘플링기법

### 1.1 정의와 목적

**신뢰성 샘플링기법**은 제품 전체를 시험하지 않고 모집단에서 추출한 표본의 고장 수, 고장 시간 또는 성능 자료를 이용해 로트나 제품군의 신뢰성을 판정하는 방법이야.

일반적인 품질 샘플링이 현재의 불량품 비율을 주로 다룬다면, 신뢰성 샘플링은 일정 시간 동안 제품이 고장 없이 기능하는지까지 고려해. 따라서 시험 조건에는 표본 크기뿐 아니라 **시험시간**, **사용환경**, **허용 고장 수**가 포함될 수 있어.

신뢰성 시험은 비용과 시간이 많이 들고 때로는 파괴시험이 되기도 해. 모든 제품을 시험하면 출하할 제품이 사라질 수도 있으니, 적은 표본으로도 생산자와 소비자가 감수할 위험을 관리하도록 시험계획을 설계하는 거야.

### 1.2 기본 기호와 판정 구조

대표적인 기호는 다음과 같아.

| 기호 | 의미 |
|---|---|
| n | 시험에 투입한 표본 수 |
| c | 합격으로 인정하는 최대 고장 수, 합격판정개수 |
| r | 실제 관측된 고장 수 |
| R(t) | 제품 하나가 시간 t까지 생존할 확률 |
| F(t) | 시간 t까지 고장날 확률, F(t) = 1 − R(t) |
| p | 고장확률 또는 부적합률 |
| α | 생산자 위험 |
| β | 소비자 위험 |

가장 기본적인 **1회 샘플링 방식**에서는 n개를 시험해 관측된 고장 수 r이 c 이하이면 합격시키고, c를 초과하면 불합격시켜.

판정 규칙은 다음과 같아.

**r ≤ c이면 합격, r > c이면 불합격**

예를 들어 n = 20, c = 1인 계획은 20개를 시험하여 고장이 0개 또는 1개면 합격, 2개 이상이면 불합격이라는 뜻이야.

### 1.3 이항분포에 의한 합격확률

각 제품이 서로 독립이고 제품 하나의 고장확률이 p로 같다면, n개 가운데 고장한 제품 수 X는 이항분포를 따라.

**X ∼ Binomial(n, p)**

따라서 합격확률은 다음과 같아.

**Pₐ(p) = P(X ≤ c) = Σₓ₌₀ᶜ C(n,x)pˣ(1−p)ⁿ⁻ˣ**

여기서 Pₐ(p)는 주어진 고장확률 p를 가진 로트가 샘플링검사에서 합격할 확률이야. 고장확률이 낮으면 합격확률이 높고, 고장확률이 높아질수록 합격확률은 낮아져. 이 관계를 나타내는 곡선이 **OC 곡선**이야.

#### 구체적인 예시

표본 크기가 n = 10이고 합격판정개수가 c = 0이라고 해보자. 제품 하나가 시험 중 고장날 확률이 p = 0.05이면 무고장일 때만 합격하므로 다음과 같아.

**Pₐ(0.05) = (1−0.05)¹⁰ = 0.95¹⁰ ≈ 0.5987**

즉, 실제 고장확률이 5%인 제품군이라도 이 시험계획에서 합격할 확률은 약 59.87%야.

c = 1로 완화하면 0개 또는 1개 고장까지 합격이므로 다음과 같아.

**Pₐ(0.05) = C(10,0)(0.95)¹⁰ + C(10,1)(0.05)(0.95)⁹**

**Pₐ(0.05) ≈ 0.5987 + 0.3151 = 0.9138**

같은 n과 p에서도 c가 커지면 합격확률이 크게 상승해. 다만 불량한 로트가 합격할 위험도 함께 증가해.

### 1.4 무고장 신뢰성 입증시험

시험 대상 n개가 모두 시간 t까지 고장 없이 작동해야 합격하는 계획은 **c = 0 무고장 시험**이야.

제품 하나가 시간 t까지 생존할 확률을 R(t)라고 하면, 독립인 n개가 모두 생존할 확률은 다음과 같아.

**P(무고장) = [R(t)]ⁿ**

특정 신뢰도 R₀를 신뢰수준 1−α로 입증하고 싶다면, 경계 신뢰도 R₀에서 무고장 결과가 나타날 확률을 α 이하가 되게 설정해.

**R₀ⁿ ≤ α**

따라서 필요한 최소 표본 수는 다음 관계로 계산해.

**n ≥ ln(α) / ln(R₀)**

두 로그가 모두 음수이므로 계산 결과는 양수가 돼. 표본 수는 정수이므로 항상 **올림**해야 해.

#### 구체적인 예시

신뢰도 R₀ = 0.90을 신뢰수준 95%로 입증하려고 해. α = 0.05이고 고장은 한 건도 허용하지 않는다고 하자.

**n ≥ ln(0.05) / ln(0.90)**

**n ≥ (−2.9957) / (−0.10536) ≈ 28.43**

따라서 필요한 최소 표본 수는 **29개**야.

검산하면 다음과 같아.

**0.90²⁹ ≈ 0.0471 ≤ 0.05**

반면 28개라면 0.90²⁸ ≈ 0.0523으로 0.05보다 크기 때문에 목표 신뢰수준을 만족하지 못해.

### 1.5 생산자 위험과 소비자 위험

**생산자 위험 α**는 양호한 로트가 불합격될 확률이야. 생산자 입장에서는 좋은 제품을 만들었는데 시험의 우연한 변동 때문에 거절당하는 위험이지.

**소비자 위험 β**는 불량한 로트가 합격될 확률이야. 소비자 입장에서는 신뢰성이 낮은 제품이 시험을 통과하는 위험이야.

양호한 품질수준의 고장확률을 p₀, 불량한 품질수준의 고장확률을 p₁이라 하면 일반적으로 다음 관계를 사용해.

**Pₐ(p₀) ≥ 1−α**

**Pₐ(p₁) ≤ β**

p₀는 좋은 로트의 기준이고 p₁은 나쁜 로트의 기준이므로 보통 p₀ < p₁이야. 표본 크기 n과 합격판정개수 c는 두 조건을 가능한 한 동시에 만족하도록 정해.

### 1.6 계수형과 계량형의 비교

| 구분 | 계수형 신뢰성 샘플링 | 계량형 신뢰성 샘플링 |
|---|---|---|
| 관측값 | 고장 또는 정상, 고장 개수 | 수명, 열화량, 강도 같은 연속값 |
| 대표 모형 | 이항분포, 초기하분포 | 지수분포, 와이블분포, 정규분포 |
| 장점 | 판정이 단순하고 명확함 | 동일 표본에서 더 많은 정보를 얻음 |
| 단점 | 수명정보를 합격·불합격으로 축약함 | 분포 가정과 계산이 더 복잡함 |
| 대표 사례 | n개 중 c개 이하 고장 시 합격 | 평균수명이나 분포 모수 추정 |

계수형에서는 100시간에 고장했든 990시간에 고장했든 시험 종료 전에 고장했다면 똑같이 한 건으로 계산될 수 있어. 계량형은 실제 고장시간을 활용하므로 정보량이 많지만, 가정한 수명분포가 적절한지 확인해야 해.

### 1.7 시험에서 자주 나오는 함정

1. **α와 β의 주체를 뒤바꾸는 함정**

   α는 생산자 위험이고, β는 소비자 위험이야. 좋은 로트를 거절하는 것이 α, 나쁜 로트를 받아들이는 것이 β야.

2. **합격판정개수 c를 고정 고장 수로 해석하는 함정**

   c는 반드시 발생해야 하는 고장 수가 아니라 허용 가능한 **최대 고장 수**야. r ≤ c이면 합격이야.

3. **무고장 시험의 표본 수를 버림하는 함정**

   필요한 조건을 만족해야 하므로 계산 결과가 28.01이어도 29개가 필요해.

4. **신뢰수준과 신뢰도를 혼동하는 함정**

   R₀는 제품이 임무시간 동안 생존할 확률이고, 1−α는 그 주장을 통계적으로 뒷받침하는 확신의 정도야.

5. **복원추출과 비복원추출 모형을 혼동하는 함정**

   큰 모집단에서 독립적인 고장 여부를 다루면 이항분포를 주로 사용해. 유한 로트에서 비복원으로 추출하면 초기하분포가 더 정확할 수 있어.

## 2. 간섭이론과 안전계수

### 2.1 간섭이론의 정의

**간섭이론과 안전계수**에서 간섭이론은 제품에 작용하는 **하중 또는 응력 S**와 제품이 견딜 수 있는 **강도 X**를 각각 확률변수로 보고, 두 분포가 겹치는 영역을 통해 고장확률을 평가하는 이론이야.

제품은 일반적으로 다음 조건에서 정상 작동해.

**X > S**

반대로 하중이 강도 이상이 되면 고장한다고 정의해.

**S ≥ X**

따라서 신뢰도와 고장확률은 다음과 같아.

**R = P(X > S)**

**P_f = P(S ≥ X) = 1−R**

강도와 하중이 각각 평균값만 가진 고정된 수가 아니라는 점이 중요해. 동일한 설계로 생산해도 재료, 치수, 가공 상태가 달라 강도가 변하고, 실제 사용환경에 따라 하중도 변해. 두 변동을 함께 고려해야 현실적인 신뢰도를 구할 수 있어.

### 2.2 분포의 간섭과 고장의 의미

강도분포가 하중분포보다 오른쪽에 있으면 평균적으로 강도가 더 크다는 뜻이야. 하지만 두 분포의 꼬리가 겹치면 일부 제품이나 일부 사용조건에서는 하중이 강도를 초과할 수 있어.

여기서 말하는 **간섭**은 물체가 공간적으로 부딪친다는 뜻이 아니라 확률분포가 겹친다는 뜻이야. 평균강도가 평균하중보다 크더라도 분산이 크면 상당한 고장확률이 남을 수 있어.

예를 들어 평균강도 120 MPa, 평균하중 100 MPa인 제품을 생각해보자. 평균값만 보면 20 MPa의 여유가 있어 안전해 보여. 그러나 강도와 하중의 표준편차가 각각 15 MPa라면 약한 제품과 큰 하중이 만나는 경우가 무시할 수 없게 돼.

### 2.3 일반적인 신뢰도 적분식

강도 X와 하중 S가 서로 독립이고 각각 확률밀도함수 f_X(x), f_S(s)를 갖는다면 신뢰도는 다음과 같이 표현할 수 있어.

**R = P(X > S)**

**R = ∫ F_S(x)f_X(x)dx**

여기서 F_S(x)는 하중이 x보다 작을 누적확률이야. 어떤 강도 x가 주어졌을 때 하중이 그보다 작을 확률을 구하고, 이를 가능한 모든 강도에 대해 평균낸 식이라고 이해하면 돼.

동일한 내용을 다음과 같이 쓸 수도 있어.

**R = ∫ [1−F_X(s)]f_S(s)ds**

이번에는 하중 s가 주어졌을 때 강도가 그보다 클 확률을 전체 하중에 대해 평균낸 형태야.

### 2.4 정규분포일 때의 신뢰도

강도와 하중이 서로 독립인 정규분포를 따른다고 하자.

**X ∼ N(μ_X, σ_X²)**

**S ∼ N(μ_S, σ_S²)**

안전여유를 다음과 같이 정의해.

**M = X−S**

정규확률변수의 차도 정규분포를 따르므로 다음과 같아.

**M ∼ N(μ_X−μ_S, σ_X²+σ_S²)**

제품이 정상인 조건은 M > 0이야. 따라서 표준화된 신뢰성 지수 z는 다음과 같아.

**z = (μ_X−μ_S) / √(σ_X²+σ_S²)**

신뢰도는 표준정규분포의 누적분포함수 Φ를 이용해 계산해.

**R = Φ(z)**

고장확률은 다음과 같아.

**P_f = 1−Φ(z) = Φ(−z)**

#### 구체적인 예시

강도의 평균과 표준편차가 각각 120 MPa와 8 MPa이고, 하중의 평균과 표준편차가 각각 100 MPa와 6 MPa라고 하자.

**μ_X−μ_S = 120−100 = 20 MPa**

**√(σ_X²+σ_S²) = √(8²+6²) = √100 = 10 MPa**

따라서 신뢰성 지수는 다음과 같아.

**z = 20/10 = 2.00**

표준정규분포표에서 Φ(2.00) ≈ 0.9772이므로 다음과 같아.

**R ≈ 0.9772**

**P_f ≈ 1−0.9772 = 0.0228**

평균강도가 평균하중보다 20 MPa 크지만, 변동까지 반영하면 고장확률은 약 2.28%가 돼.

### 2.5 상관관계가 있을 때

강도 X와 하중 S가 독립이 아니고 상관계수 ρ를 갖는다면 차이 M = X−S의 분산은 다음과 같아.

**σ_M² = σ_X²+σ_S²−2ρσ_Xσ_S**

따라서 정규분포를 가정할 때 신뢰성 지수는 다음과 같아.

**z = (μ_X−μ_S) / √(σ_X²+σ_S²−2ρσ_Xσ_S)**

독립이라는 조건이 주어지면 ρ = 0으로 두어 기존 공식을 사용해. 시험에서는 독립 조건을 놓치거나, 분산을 더해야 할 곳에서 표준편차를 바로 더하는 실수가 자주 나와.

### 2.6 안전계수의 정의

전통적인 평균값 중심의 안전계수는 일반적으로 다음과 같이 정의해.

**안전계수 n_s = 허용 강도 또는 대표 강도 / 사용 하중 또는 대표 하중**

평균값을 사용하면 다음처럼 나타낼 수 있어.

**n_s = μ_X / μ_S**

예를 들어 대표 강도가 150 MPa이고 대표 하중이 100 MPa라면 안전계수는 1.5야.

**n_s = 150/100 = 1.5**

이는 대표 강도가 대표 하중의 1.5배라는 뜻이지, 고장확률이 0이라는 뜻은 아니야. 안전계수가 같더라도 강도와 하중의 산포가 다르면 신뢰도는 달라질 수 있어.

### 2.7 안전계수와 신뢰도의 차이

| 구분 | 안전계수 | 간섭이론에 의한 신뢰도 |
|---|---|---|
| 기본 관점 | 대표값의 비율 | 확률분포의 겹침 |
| 대표 표현 | 강도 ÷ 하중 | P(X > S) |
| 산포 반영 | 단순 계산에서는 반영하지 않음 | 강도와 하중의 분산을 반영함 |
| 결과 | 여유의 상대적 크기 | 성공확률 또는 고장확률 |
| 한계 | 같은 값이라도 위험이 달라질 수 있음 | 분포와 독립성 가정이 필요함 |

안전계수는 설계 여유를 빠르게 표현하는 도구이고, 간섭이론은 그 여유가 실제로 어느 정도의 성공확률을 만드는지 평가하는 도구야. 둘은 대체 관계가 아니라 보완 관계라고 보면 돼.

#### 같은 안전계수, 다른 신뢰도

두 설계 모두 평균강도 120 MPa, 평균하중 100 MPa라면 평균 안전계수는 1.2야.

설계 A의 표준편차가 σ_X = 4, σ_S = 3이면 다음과 같아.

**z_A = 20/√(4²+3²) = 20/5 = 4**

**R_A = Φ(4) ≈ 0.99997**

설계 B의 표준편차가 σ_X = 12, σ_S = 9이면 다음과 같아.

**z_B = 20/√(12²+9²) = 20/15 ≈ 1.33**

**R_B = Φ(1.33) ≈ 0.9082**

평균 안전계수는 둘 다 1.2지만 신뢰도에는 큰 차이가 나. 결국 신뢰성은 평균값 사이의 거리뿐 아니라 **분포의 폭**에도 좌우돼.

### 2.8 신뢰도를 높이는 설계 원리

간섭이론의 정규모형에서 신뢰성 지수는 다음과 같았어.

**z = (μ_X−μ_S) / √(σ_X²+σ_S²)**

따라서 신뢰도를 높이는 방법은 분자와 분모의 관점에서 정리할 수 있어.

1. **평균강도 μ_X를 높인다.**

   더 강한 재료, 적절한 열처리, 단면 확대를 활용할 수 있어.

2. **평균하중 μ_S를 낮춘다.**

   하중 분산 구조, 충격 완화, 사용조건 제한을 적용할 수 있어.

3. **강도의 표준편차 σ_X를 줄인다.**

   재료 균질화, 공정능력 향상, 치수 편차 축소가 해당해.

4. **하중의 표준편차 σ_S를 줄인다.**

   사용환경 관리, 과부하 방지, 입력조건 안정화가 해당해.

평균강도를 높이는 것만이 유일한 해법은 아니야. 제조 산포를 줄이면 재료를 과도하게 늘리지 않고도 높은 신뢰도를 얻을 수 있어. 이게 품질관리와 신뢰성 설계가 만나는 중요한 지점이야.

### 2.9 시험에서 자주 나오는 함정

1. **고장조건의 부등호를 뒤집는 함정**

   정상은 X > S이고 고장은 S ≥ X야. 강도가 하중보다 커야 버틸 수 있다고 생각하면 기억하기 쉬워.

2. **표준편차를 직접 더하는 함정**

   독립인 차이의 분산은 σ_X²+σ_S²야. 표준편차는 그 합의 제곱근이야.

3. **평균 차이를 절댓값으로 바꾸는 함정**

   분자는 μ_X−μ_S야. 평균강도가 평균하중보다 작다면 z는 음수가 될 수 있고, 이때 신뢰도는 0.5보다 작아.

4. **안전계수와 신뢰도를 동일시하는 함정**

   안전계수 1.5가 신뢰도 150%를 뜻하지 않아. 신뢰도는 0과 1 사이의 확률이야.

5. **강도와 하중의 기호를 바꾸는 함정**

   문제마다 기호는 달라질 수 있으므로 기호 자체보다 견디는 능력과 가해지는 요구라는 의미를 먼저 확인해야 해.

## 3. 두 주제를 연결해서 이해하기

**신뢰성 샘플링기법**은 시험 결과를 이용해 제품군의 신뢰성을 판정하는 통계적 의사결정 방법이야. 반면 **간섭이론과 안전계수**는 제품이 왜 고장하는지를 강도와 하중의 관계로 설명하는 설계 모형이야.

간섭이론으로 목표 고장확률을 정하고 설계한 뒤, 생산된 제품이 목표 신뢰도를 실제로 충족하는지 신뢰성 샘플링시험으로 입증할 수 있어. 설계 단계의 확률모형과 시험 단계의 통계적 판정이 연결되는 셈이지.

| 단계 | 핵심 질문 | 대표 도구 |
|---|---|---|
| 설계 | 강도가 하중을 이길 확률은 얼마인가? | 간섭이론, 신뢰성 지수 |
| 여유 설정 | 대표 강도가 대표 하중보다 얼마나 큰가? | 안전계수 |
| 입증시험 | 표본 결과가 목표 신뢰도를 지지하는가? | 신뢰성 샘플링기법 |
| 판정 | 허용 고장 수 이내인가? | n, c, r에 의한 합격판정 |

## 4. 계산 절차 정리

### 4.1 신뢰성 샘플링 문제

1. 표본 수 n과 합격판정개수 c를 찾는다.
2. 제품 하나의 고장확률 p 또는 신뢰도 R을 확인한다.
3. 고장확률이 필요하면 p = 1−R로 변환한다.
4. 이항분포로 P(X ≤ c)를 계산한다.
5. 무고장 시험이면 [R(t)]ⁿ으로 단순화한다.
6. 필요한 표본 수를 구하면 계산값을 올림한다.
7. α와 β가 누구의 위험인지 마지막에 확인한다.

### 4.2 간섭이론 문제

1. 강도와 하중을 구분한다.
2. 평균차 μ_X−μ_S를 계산한다.
3. 독립이면 분산합 σ_X²+σ_S²를 계산한다.
4. 표준편차 √(σ_X²+σ_S²)를 구한다.
5. z를 계산한다.
6. 표준정규분포표에서 Φ(z)를 찾아 신뢰도를 구한다.
7. 고장확률을 요구하면 1−R을 계산한다.

## 6. 정답 및 해설

### 문제 1 정답

**약 0.4633**

c = 0이므로 15개가 모두 생존해야 합격해.

**Pₐ = 0.95¹⁵ ≈ 0.4633**

개별 제품의 신뢰도가 95%로 높아 보여도 15개 모두 무고장일 확률은 약 46.33%야.

### 문제 2 정답

**22개**

신뢰수준이 90%이므로 α = 0.10이야.

**n ≥ ln(0.10) / ln(0.90)**

**n ≥ (−2.3026)/(−0.10536) ≈ 21.85**

표본 수는 올림하여 22개가 돼.

### 문제 3 정답

**4번**

생산자 위험은 양호한 로트의 불합격확률이고, 소비자 위험은 불량한 로트의 합격확률이야. c = 2이면 고장이 0개, 1개 또는 2개일 때 합격해.

### 문제 4 정답

**z ≈ 2.12, R ≈ 0.9830**

평균 안전여유는 다음과 같아.

**μ_X−μ_S = 130−100 = 30**

표준편차는 다음과 같아.

**√(10²+10²) = √200 ≈ 14.142**

따라서 다음과 같아.

**z = 30/14.142 ≈ 2.12**

**R = Φ(2.12) ≈ 0.9830**

고장확률은 약 0.0170이야.

### 문제 5 정답

**안전계수는 1.5이며, 이 값만으로 고장확률을 확정할 수 없어.**

**n_s = 180/120 = 1.5**

강도와 하중의 분포 형태 및 표준편차가 주어지지 않았으므로 분포의 겹침 정도를 알 수 없어. 따라서 신뢰도나 고장확률을 확정할 수 없어.

### 문제 6 정답

**신뢰도가 증가해.**

평균차가 일정한 상태에서 분모인 √(σ_X²+σ_S²)가 작아지면 z가 커져. 그러면 Φ(z)도 커지므로 신뢰도가 증가하고 고장확률은 감소해.

## 7. 요약

1. **신뢰성 샘플링기법**은 일부 표본의 고장 자료를 이용해 제품군의 신뢰성을 판정하는 방법이야.

2. n개 중 고장 수가 c 이하이면 합격하며, 계수형 합격확률은 **Pₐ(p) = P(X ≤ c)**로 계산해.

3. 무고장 시험의 합격확률은 **[R(t)]ⁿ**이고, 필요한 표본 수는 **n ≥ ln(α)/ln(R₀)**로 구한 뒤 올림해.

4. 생산자 위험 α는 양호한 로트를 불합격시키는 확률이고, 소비자 위험 β는 불량한 로트를 합격시키는 확률이야.

5. **간섭이론과 안전계수**에서 정상 조건은 강도 X가 하중 S보다 큰 경우이며, 신뢰도는 **R = P(X > S)**야.

6. 독립 정규분포라면 **z = (μ_X−μ_S)/√(σ_X²+σ_S²)**이고 신뢰도는 **R = Φ(z)**야.

7. 안전계수는 대표 강도와 대표 하중의 비율이지만, 산포를 직접 나타내지 않으므로 안전계수만으로 고장확률을 확정할 수 없어.

8. 신뢰도를 높이려면 평균강도를 높이거나 평균하중을 낮추는 방법뿐 아니라 강도와 하중의 변동을 줄이는 방법도 중요해.
