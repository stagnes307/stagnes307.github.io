고장을 미리 줄이는 신뢰성 설계

신뢰성 설계

완성품에서 고장을 찾아내는 데 그치지 않고, 요구조건을 수치화한 뒤 고장경로를 예측하고 설계 단계에서 제거하는 방법을 익혀보자.

대상 품목요구 기능사용 조건임무 시간

1. 두 학습 주제의 연결 지도

신뢰성 설계 개념주어진 조건과 기간 동안 요구 기능을 수행할 확률을 설계 목표로 바꾸는 사고방식이야.
신뢰성 설계 방법목표 배분, 예측, 고장분석, 개선, 시험을 순환시켜 그 목표를 실제 구조에 구현하는 절차야.

개념이 “무엇을 달성해야 하는가”를 정한다면 방법은 “어떻게 달성하고 입증할 것인가”를 정해. 따라서 신뢰성은 부품의 튼튼함만 뜻하지 않아. 기능, 환경, 시간, 시스템 구조를 동시에 다루는 예방적 품질특성이야.

2. 신뢰도를 읽는 수학적 기반

수명확률변수 \(T\)에 대해 신뢰도 \(R(t)\)는 시간 \(t\)를 지나서도 살아남을 확률이야. 불신뢰도 \(F(t)\)는 그때까지 고장할 확률이므로 둘의 합은 항상 1이 돼. 고장률이 일정한 우발고장기간에는 지수분포를 적용할 수 있어.

신뢰도R(t)=P(T>t)시간 t까지 기능 유지
불신뢰도F(t)=1-R(t)시간 t까지 고장
일정 고장률R(t)=e^(-λt)MTTF=1/λ

예를 들어 시간당 고장률이 0.0002인 부품을 1,000시간 사용하면 \(R(1000)=e^{-0.2}\approx0.8187\)이야. 이는 같은 조건에서 1,000시간까지 요구 기능을 유지할 확률이 약 81.87%라는 뜻이지.

3. 요구조건이 검증 결과가 되는 설계 흐름

  1. 요구 정의
    “실내환경에서 2,000시간 동안 신뢰도 0.95”처럼 고장기준과 임무조건을 수치로 정해.
  2. 신뢰도 배분
    시스템 목표를 장치와 부품의 목표로 하향 전개해. 직렬구조라면 각 부품 목표가 시스템 목표보다 높아야 해.
  3. 신뢰도 예측
    고장률, 부하, 환경, 연결구조로 설계안을 계산하고 목표와 비교해.
  4. 고장 분석과 개선
    FMEA는 고장형태에서 영향을 추적하고, FTA는 최상위 고장에서 원인을 역으로 분해해.
  5. 시험과 성장
    시험에서 찾은 원인을 제거하고 재시험해 신뢰도를 점진적으로 성장시켜.

4. 고장 가능성을 낮추는 다섯 설계 방법

단순화

같은 기능을 더 적은 부품과 접속부로 구현해 고장기회를 줄여. 필요한 보호기능까지 없애는 단순 축소와는 달라.

디레이팅

전압, 전류, 온도, 하중을 정격한계보다 낮게 운용해 스트레스와 열화를 줄여. 과도한 여유는 비용과 중량을 키울 수 있어.

중복설계

한 경로가 고장해도 다른 경로가 기능을 이어받게 해. 활성 중복, 대기 중복, 다수결 중복으로 나눌 수 있어.

고장안전

고장이 발생했을 때 위험한 상태가 아니라 안전한 상태로 이동시켜. 전원 상실 시 닫히는 차단밸브가 대표적이야.

풀프루프

잘못된 조립이나 조작 자체가 어렵도록 형상과 순서를 제한해. 방향이 맞아야 결합되는 커넥터가 좋은 예야.

5. 직렬과 병렬 구조의 계산 지도

직렬시스템은 모든 구성요소가 정상이어야 하므로 \(R_s=\prod R_i\)야. 신뢰도 0.90과 0.80인 부품을 직렬로 연결하면 시스템 신뢰도는 0.72가 돼. 병렬시스템은 모든 경로가 동시에 고장해야 실패하므로 \(R_s=1-\prod(1-R_i)\)야. 신뢰도 0.90인 동일 부품 두 개가 독립 병렬이면 시스템 신뢰도는 0.99야.

독립성 가정을 놓치면 안 돼. 두 경로가 같은 전원, 열원, 배관에 의존하면 공통원인고장 때문에 계산만큼 개선되지 않아. 대기 중복에서는 대기품뿐 아니라 고장 검출과 전환장치의 성공확률도 포함해야 해.

6. 산업용 냉각펌프 적용 사례

연속운전 설비의 냉각펌프를 설계한다고 해보자. 단일 펌프 고장이 곧 설비 정지로 이어진다면 부품 교체만으로는 충분하지 않아. 부하, 경로, 감시, 안전정지까지 시스템 수준에서 묶어야 해.

부하 여유정격보다 낮은 운전점으로 디레이팅해 열과 마모를 줄여.
대체 경로예비 펌프를 두어 주 장치 고장 시 기능을 넘겨.
상태 감시온도와 진동으로 열화를 조기에 검출해.
안전 귀결냉각 상실 시 설비를 안전하게 정지시켜.

두 펌프가 같은 전원과 흡입관을 공유하면 하나의 전원 상실이나 관로 폐색으로 동시에 멈출 수 있어. 그래서 독립 전원, 물리적 분리, 역류 방지, 전환시험까지 검토해야 중복설계가 실제 신뢰도 향상으로 이어져.

7. 개념 경계와 시험 함정

배분과 예측

신뢰도 배분은 시스템 목표를 하위 구성요소의 목표로 나누는 하향 활동이야. 신뢰도 예측은 선택한 부품과 구조로 전체 성능을 계산하는 상향 활동이야.

신뢰성·보전성·가용도

신뢰성은 고장 없이 버티는 능력, 보전성은 고장 후 빨리 복구하는 능력이야. 수리 가능한 시스템의 정상상태 가용도는 \(A=MTBF/(MTBF+MTTR)\)로 나타낼 수 있어.

혼동하기 쉬운 설계기법의 통제 대상
설계기법통제하는 대상대표 단서
디레이팅부품 스트레스정격보다 낮게 사용
중복설계기능 상실대체 경로 또는 예비품
고장안전고장 결과고장 시 안전상태
풀프루프사람의 실수오조작·오조립 방지
  • 직렬 신뢰도는 합이 아니라 곱이야.
  • 병렬 신뢰도는 모든 요소의 고장확률을 곱한 뒤 1에서 빼.
  • 번인 시험은 초기고장 제거, 예방보전은 마모고장 억제와 연결해.
  • \(MTTF=1/\lambda\)는 고장률이 일정하다는 조건에서 적용해.
  • 중복이 있어도 공통원인고장이 크면 기대한 효과를 얻지 못해.

8. 확인 문제

문제 1. 신뢰성의 정의에 반드시 포함되어야 하는 네 요소를 써봐.
문제 2. 신뢰도가 각각 0.90과 0.80인 두 부품이 직렬로 연결되어 있을 때 시스템 신뢰도를 계산해봐.
문제 3. 신뢰도 0.90인 동일 부품 두 개가 독립 병렬로 연결되어 하나 이상 작동하면 성공해. 시스템 신뢰도는 얼마일까?
문제 4. 정격보다 낮은 전압과 온도에서 부품을 사용하도록 설계하는 기법은 무엇일까?
문제 5. 고장률이 시간당 0.001로 일정한 부품을 100시간 사용할 때 신뢰도를 계산해봐.

9. 정답과 해설

1. 대상 품목, 요구 기능, 사용 조건, 임무 시간이야. 하나라도 빠지면 무엇을 어떤 기준으로 평가한 신뢰도인지 불명확해.
2. \(R_s=0.90\times0.80=0.72\)야. 직렬구조는 모든 부품이 정상이어야 해.
3. \(R_s=1-(1-0.90)^2=0.99\)야. 두 부품이 모두 고장할 확률 0.01을 1에서 빼.
4. 디레이팅 설계야. 스트레스를 정격한계 아래로 낮춰 고장률과 열화를 줄이는 방법이지.
5. \(R(100)=e^{-0.001\times100}=e^{-0.1}\approx0.9048\)이므로 약 90.48%야.

10. 회상 요약

요구 정의목표 배분신뢰도 예측고장 분석설계 개선시험·재검증

신뢰성 설계는 사후에 고장품을 선별하는 활동이 아니라, 기능·환경·시간을 기준으로 고장이 생길 구조를 개발 단계에서 줄이는 예방 활동이야. 직렬구조는 신뢰도의 곱, 병렬구조는 모든 경로의 고장확률을 1에서 뺀 값으로 계산해.

단순화와 디레이팅은 고장기회를 낮추고, 중복설계는 대체 경로를 만들며, 고장안전과 풀프루프는 각각 고장 결과와 사람의 실수를 통제해. 계산에서는 독립성, 공통원인고장, 검출·전환 실패를 반드시 점검해야 해.

기억할 한 문장: 신뢰성 설계는 고장의 길을 찾고, 그 길을 줄이거나 끊고, 남은 고장의 결과를 안전하게 만드는 일이야.
