## 1. 신뢰성 설계 개념

### 1.1 정의

**신뢰성 설계**는 제품이나 시스템이 주어진 조건에서 정해진 기간 동안 요구 기능을 고장 없이 수행하도록 구조, 부품, 운용 조건을 결정하는 활동이야.

신뢰성은 단순히 “튼튼하다”는 뜻이 아니야. 다음 네 요소가 함께 명시되어야 해.

1. **대상 기능**: 무엇을 정상적으로 수행해야 하는가
2. **사용 조건**: 온도, 습도, 진동, 하중 등의 환경은 어떠한가
3. **사용 시간**: 얼마 동안 작동해야 하는가
4. **성공 확률**: 요구 기능을 수행할 확률은 얼마인가

따라서 “이 제품은 신뢰성이 높다”보다 “정격 환경에서 1,000시간 동안 기능을 유지할 신뢰도가 0.95다”가 훨씬 정확한 표현이야.

### 1.2 신뢰도의 수학적 의미

수명확률변수를 T라고 하면 신뢰도 함수는 다음과 같아.

**R(t) = P(T > t)**

즉, 시간 t까지 고장 나지 않을 확률이야. 누적고장분포함수를 F(t)라고 하면 다음 관계가 성립해.

**R(t) = 1 − F(t)**

고장률이 일정하고 수명이 지수분포를 따른다면 다음 식을 사용해.

**R(t) = e^(−λt)**

여기서 λ는 단위시간당 고장률이야. 평균고장시간 MTBF는 일정 고장률 조건에서 다음과 연결돼.

**MTBF = 1/λ**

따라서 다음처럼 쓸 수도 있어.

**R(t) = e^(−t/MTBF)**

#### 구체적인 예시

어떤 장치의 고장률이 시간당 0.0001이고 1,000시간 동안의 신뢰도를 구한다고 해보자.

**R(1,000) = e^(−0.0001 × 1,000) = e^(−0.1) ≈ 0.9048**

그러므로 이 장치가 1,000시간 동안 고장 없이 작동할 확률은 약 90.48%야.

### 1.3 신뢰성 설계의 핵심 원리

신뢰성은 완성품을 검사해서 뒤늦게 주입하는 성질이 아니야. 설계 단계에서 고장 원인을 예측하고 제거해야 해. 이를 흔히 **신뢰성의 설계 내재화**라고 이해해.

설계 과정의 기본 흐름은 다음과 같아.

1. 요구 기능과 사용 환경을 정의한다.
2. 시스템 전체의 목표 신뢰도를 정한다.
3. 목표를 하위 시스템과 부품에 배분한다.
4. 예상 고장모드와 고장 원인을 분석한다.
5. 부품 수 감소, 디레이팅, 중복설계 등의 대책을 선택한다.
6. 예측과 시험을 통해 목표 달성 여부를 검증한다.
7. 결과가 부족하면 구조와 부품을 다시 설계한다.

이 과정은 우산을 만든 뒤 비가 새는 곳을 찾는 작업이 아니라, 빗물의 경로를 예상하면서 우산살과 천의 구조를 결정하는 작업과 비슷해.

### 1.4 신뢰성과 품질의 비교

| 구분 | 품질 | 신뢰성 |
|---|---|---|
| 중심 질문 | 출하 시점에 규격을 만족하는가 | 사용시간 동안 기능을 유지하는가 |
| 시간 요소 | 반드시 포함되지는 않음 | 반드시 포함됨 |
| 대표 지표 | 불량률, 공정능력, 규격 적합성 | 신뢰도, 고장률, MTBF |
| 주요 관리 단계 | 생산 및 검사 | 기획, 설계, 시험, 운용 |
| 전형적 문제 | 치수 규격 이탈 | 일정 시간 후 기능 상실 |

출하검사에서 합격한 제품도 사용 직후 고장 날 수 있어. 그러므로 초기 품질이 좋다는 사실만으로 장기 신뢰성이 보장되지는 않아.

### 1.5 비교와 경계

**신뢰성**은 고장 없이 기능을 수행하는 성질이고, **보전성**은 고장 후 얼마나 쉽고 빠르게 복구할 수 있는지를 나타내. **가용성**은 필요한 시점에 실제로 사용할 수 있는 확률로, 신뢰성과 보전성의 영향을 함께 받아.

신뢰성을 극단적으로 높이면 언제나 좋은 것도 아니야. 중복 부품과 안전 여유를 지나치게 늘리면 비용, 무게, 부피, 전력소모와 구조 복잡성이 증가해. 그래서 신뢰성 설계는 목표 신뢰도를 비용과 기술적 제약 속에서 달성하는 **최적화 문제**이기도 해.

### 1.6 시험 함정

1. 신뢰도는 단순한 합격률이 아니라 **시간과 사용 조건이 포함된 확률**이야.
2. 일정 고장률에서 시간 t가 증가하면 R(t)는 감소해.
3. 부품 수가 늘어나면 언제나 시스템 신뢰도가 향상되는 것은 아니야.
4. 직렬 시스템에서는 구성요소가 하나만 고장 나도 시스템이 고장 나.
5. 병렬 중복은 신뢰도를 높일 수 있지만 공통원인고장에는 취약할 수 있어.
6. MTBF가 두 배라고 해서 특정 시간의 고장확률이 정확히 절반이 되는 것은 아니야.

## 2. 신뢰성 설계 방법

### 2.1 신뢰성 목표 설정과 배분

먼저 시스템이 달성해야 할 **목표 신뢰도**를 정해. 그다음 시스템 목표를 하위 시스템과 부품에 나누어 할당하는데, 이를 **신뢰성 배분**이라고 해.

직렬 시스템의 신뢰도는 독립적인 구성요소를 가정하면 다음과 같아.

**Rₛ = R₁ × R₂ × … × Rₙ**

동일한 신뢰도 R을 가진 부품 n개가 직렬로 연결되면 다음과 같아.

**Rₛ = Rⁿ**

#### 구체적인 예시

서로 독립적인 세 부품의 신뢰도가 각각 0.98, 0.95, 0.99이고 모두 작동해야 시스템이 성공한다고 해보자.

**Rₛ = 0.98 × 0.95 × 0.99 = 0.92169**

각 부품의 신뢰도는 높아 보여도 시스템 신뢰도는 약 0.9217로 낮아져. 이것이 직렬 시스템에서 부품 수를 불필요하게 늘리지 말아야 하는 이유야.

목표 시스템 신뢰도가 0.95이고 동일한 부품 5개로 구성된 직렬 시스템이라면 각 부품에 필요한 신뢰도는 다음과 같아.

**R = 0.95^(1/5) ≈ 0.9898**

단순히 각 부품에 0.95를 할당하면 시스템 목표를 달성하지 못한다는 점이 중요해.

### 2.2 단순화와 부품 수 감소

직렬 구조에서는 부품 하나하나가 잠재적인 고장 지점이야. 따라서 불필요한 부품, 접속부, 스위치, 커넥터와 변환 단계를 줄이면 신뢰성을 높일 수 있어.

하지만 단순화와 중복설계는 서로 반대 방향으로 보일 수 있어. 단순화는 고장 지점의 수를 줄이고, 중복설계는 일부 고장이 발생해도 기능을 유지하도록 부품을 추가해. 어느 방법을 적용할지는 고장 영향, 비용, 공통원인고장 가능성을 분석해 결정해야 해.

### 2.3 디레이팅 설계

**디레이팅 설계**는 부품을 정격 한계보다 낮은 부하에서 사용하는 방법이야. 전압, 전류, 온도, 압력, 회전속도와 같은 스트레스를 낮추면 열화와 고장 가능성을 줄일 수 있어.

예를 들어 정격 전력이 100W인 부품을 항상 100W에서 운전하기보다 60W 수준에서 사용하면 열 발생과 재료 열화가 완화될 수 있어. 다만 정격의 절반으로 사용했다고 해서 수명이 반드시 두 배가 되는 것은 아니야. 스트레스와 수명의 관계는 고장 메커니즘과 재료 특성에 따라 달라지기 때문이야.

디레이팅은 다음과 구별해야 해.

1. **디레이팅**: 정상 운전 스트레스를 정격보다 낮춘다.
2. **안전계수 적용**: 최대 예상 하중보다 높은 설계 강도를 확보한다.
3. **중복설계**: 동일 기능을 수행할 대체 경로를 추가한다.

### 2.4 중복설계와 병렬 시스템

**중복설계**는 한 구성요소가 고장 나도 다른 구성요소가 기능을 이어받도록 여분을 두는 방법이야.

독립적인 두 부품이 병렬로 구성되고 둘 중 하나만 작동해도 시스템이 성공한다면 다음과 같아.

**Rₚ = 1 − (1 − R₁)(1 − R₂)**

동일한 신뢰도 R을 가진 부품 n개가 병렬이라면 다음과 같아.

**Rₚ = 1 − (1 − R)ⁿ**

#### 구체적인 예시

신뢰도가 각각 0.9인 부품 두 개를 병렬로 연결하면 두 부품이 모두 고장 날 확률은 다음과 같아.

**(1 − 0.9)² = 0.01**

따라서 병렬 시스템 신뢰도는 다음과 같아.

**Rₚ = 1 − 0.01 = 0.99**

하지만 전원, 냉각장치, 소프트웨어 또는 환경을 공유한다면 두 부품이 동시에 고장 날 수 있어. 이와 같은 **공통원인고장**이 존재하면 독립 고장을 가정한 0.99를 그대로 기대하기 어려워.

중복 방식은 다음처럼 나눌 수 있어.

| 방식 | 작동 원리 | 특징 |
|---|---|---|
| 능동 중복 | 여러 구성요소가 동시에 작동 | 전환 시간이 짧지만 부품이 계속 스트레스를 받음 |
| 대기 중복 | 주 구성요소 고장 후 예비품이 작동 | 예비품 열화를 줄일 수 있으나 감지·전환장치가 필요 |
| 다수결 중복 | 여러 출력 중 다수의 결과를 채택 | 오판 방지에 유리하지만 회로와 판단 논리가 복잡함 |

### 2.5 고장 안전 설계

**페일 세이프**는 고장이 발생했을 때 시스템이 위험한 상태가 아니라 안전한 상태로 이동하도록 하는 설계야. 철도 신호장치의 이상 시 정지 신호를 표시하게 만드는 방식이 대표적이야.

**고장 허용 설계**는 일부 구성요소가 고장 나더라도 시스템이 요구 기능의 전부 또는 일부를 계속 수행하도록 만드는 설계야. 항공기의 다중 제어계통처럼 고장 후에도 임무를 계속해야 하는 경우에 중요해.

**풀 프루프**는 사용자의 실수나 오조작을 방지하도록 구조를 만드는 접근이야. 서로 다른 규격의 커넥터가 잘못 결합되지 않게 형상을 달리하는 것이 예야.

| 개념 | 핵심 질문 |
|---|---|
| 페일 세이프 | 고장 후 안전한 상태가 되는가 |
| 고장 허용 | 일부 고장 후에도 기능을 계속하는가 |
| 풀 프루프 | 사람이 잘못 조작하기 어렵게 되어 있는가 |

### 2.6 고장 분석 기반 설계

신뢰성 설계에서는 예상 고장을 체계적으로 찾아야 해.

**FMEA**는 구성요소별 고장모드, 원인, 영향과 대책을 아래에서 위로 추적하는 귀납적 분석이야. 부품이나 공정에서 “어떤 고장이 발생할 수 있는가?”라고 묻는 방식이지.

**FTA**는 특정한 최상위 고장사건을 정하고 그 원인을 논리기호로 분해하는 연역적 분석이야. “이 중대한 사고가 발생하려면 어떤 원인 조합이 필요한가?”라고 묻는 방식이야.

FMEA와 FTA는 경쟁 관계가 아니야. FMEA로 폭넓은 고장모드를 발굴하고, 치명적인 결과에 대해서는 FTA로 원인 조합을 깊게 분석할 수 있어.

### 2.7 신뢰성 예측과 시험

설계안이 목표를 만족하는지는 계산과 시험으로 확인해야 해.

1. 부품 고장률 자료를 이용해 시스템 신뢰도를 예측한다.
2. 신뢰성 블록도를 작성해 직렬·병렬 구조를 모델링한다.
3. 가속수명시험으로 짧은 시간 안에 열화 정보를 얻는다.
4. 환경시험으로 온도, 습도, 진동 등의 영향을 확인한다.
5. 시험 결과와 현장 고장자료를 설계에 환류한다.

가속수명시험은 단순히 제품을 거칠게 다루는 시험이 아니야. 실제 사용과 동일한 고장 메커니즘을 유지하면서 스트레스를 높여 고장을 빠르게 관측해야 해. 과도한 스트레스로 현실에서 발생하지 않는 고장을 만들면 수명 추정이 왜곡돼.

### 2.8 방법 선택 절차

실무적인 신뢰성 설계 절차를 한 줄로 연결하면 다음과 같아.

**요구조건 정의 → 목표 신뢰도 설정 → 신뢰성 배분 → 구조 모델링 → 고장모드 분석 → 설계대책 선정 → 신뢰성 예측 → 시험과 검증 → 설계 개선**

예를 들어 산업용 펌프를 설계한다면 운전시간과 온도 조건을 먼저 정하고, 모터·베어링·밀봉장치에 목표를 배분해. 이어서 밀봉 누설과 베어링 마모 같은 고장모드를 분석하고, 부품 정격 여유와 냉각구조를 결정해. 마지막으로 수명시험과 진동시험을 수행하여 목표 달성 여부를 확인하는 식이야.

### 2.9 시험 함정

1. 직렬 시스템 신뢰도는 구성요소 신뢰도의 합이 아니라 **곱**이야.
2. 병렬 시스템 신뢰도는 성공확률을 바로 더하지 않고 **전부 고장 날 확률의 여사건**으로 계산해.
3. 중복설계는 공통원인고장을 자동으로 제거하지 못해.
4. 대기 중복에서는 예비품뿐 아니라 고장감지기와 전환장치의 신뢰도도 중요해.
5. 디레이팅은 부품 정격을 높이는 행위가 아니라 실제 사용 스트레스를 낮추는 설계야.
6. 페일 세이프는 무고장을 보장하는 개념이 아니라 고장 결과를 안전 방향으로 제한하는 개념이야.
7. FMEA는 일반적으로 귀납적이고, FTA는 일반적으로 연역적이야.
8. 가속수명시험에서는 실제 사용과 동일한 고장 메커니즘을 유지해야 해.

## 6. 요약

1. **신뢰성 설계 개념**은 제품이 주어진 조건과 시간 동안 요구 기능을 수행할 확률을 설계 단계에서 확보하는 것이야.
2. 신뢰도는 R(t) = P(T > t)이며, 일정 고장률에서는 R(t) = e^(−λt)를 사용해.
3. 직렬 시스템은 Rₛ = ∏Rᵢ이므로 부품 수가 증가하면 일반적으로 시스템 신뢰도가 낮아져.
4. 병렬 시스템은 Rₚ = 1 − ∏(1 − Rᵢ)로 계산하지만 독립 고장 가정과 공통원인고장을 확인해야 해.
5. **신뢰성 설계 방법**에는 목표 설정과 배분, 단순화, 디레이팅, 중복설계, 페일 세이프, 고장 허용 설계, FMEA·FTA, 신뢰성 시험이 있어.
6. 디레이팅은 고장 발생 가능성을 낮추고, 중복설계는 고장 후 사용할 대체 경로를 제공해.
7. 페일 세이프는 고장 후 안전을, 고장 허용 설계는 고장 후 기능 지속을 중시해.
8. 시험에서는 공식 암기뿐 아니라 직렬과 병렬의 구조, 독립성 가정, 공통원인고장이라는 경계를 함께 판단해야 해.
