공차와 공정능력분석

공차와 규격한계

공차는 제품 특성값에 허용되는 변동 범위야. 목표값이 10.00 mm이고 허용오차가 ±0.05 mm라면 규격하한 LSL은 9.95 mm, 규격상한 USL은 10.05 mm가 돼. 규격폭은 USL − LSL로 계산하므로 이 사례에서는 0.10 mm야. 양쪽 규격이 모두 존재하면 양측규격, 한쪽만 존재하면 편측규격이라고 해.

규격은 고객·설계·법규의 요구에서 정해지고, 관리한계는 실제 공정 데이터에서 계산돼. 규격한계는 제품의 적합 여부를 판단하지만 관리한계는 공정에 이상원인이 있는지 판단해. 공정이 안정되어 있어도 산포가 규격보다 크면 불량품을 안정적으로 생산할 수 있고, 현재 표본이 규격 안에 있다고 해서 공정이 통계적으로 안정됐다고 단정할 수도 없어.

자연공차와 공정산포

공정 특성값이 정규분포를 따르고 평균이 μ, 표준편차가 σ라면 대부분의 관측값은 μ ± 3σ 안에 위치해. 이 범위의 전체 폭인 6σ를 자연공차 또는 자연산포라고 불러. 정규분포에서 μ ± 3σ 안에 포함될 확률은 약 99.73%이므로 평균이 규격 중앙과 일치하고 규격한계가 μ ± 3σ에 있다면 이론상 규격 밖 비율은 약 0.27%, 즉 약 2,700 ppm이야.

공차는 외부에서 요구한 허용폭이고 자연공차는 공정이 실제로 만드는 산포폭이야. 문틀의 너비가 규격폭이고 사람이 걸으며 좌우로 흔들리는 폭이 자연공차라고 생각해봐. 흔들림이 문틀보다 충분히 작고 이동 경로가 중앙에 있어야 안전하게 통과할 수 있어.

공정능력분석의 전제

공정능력은 공정이 주어진 규격을 지속적으로 만족시킬 수 있는 잠재적 또는 실제적 능력이야. 계산 전에 측정시스템이 충분히 정확한지, 공정이 통계적 관리상태인지, 데이터의 분포가 적절한지, 표본이 공정을 대표하는지, 규격한계가 명확한지 확인해야 해.

특별원인 때문에 평균이나 산포가 계속 변한다면 하나의 평균과 표준편차로 미래 성능을 표현하기 어려워. 따라서 일반적으로 관리도로 안정성을 확인한 뒤 공정능력을 평가해. 비정규분포에 정규분포용 공식을 무비판적으로 적용하지 말고 변수변환, 비정규분포 적합 또는 분위수 기반 분석을 검토해야 해.

Cp와 Cpk의 구조

Cp: 산포를 보는 잠재적 공정능력

양측규격에서 Cp = (USL − LSL) / 6σ야. 분자는 고객이 허용한 규격폭이고 분모는 공정의 자연산포야. Cp가 클수록 공정산포가 규격폭보다 작지만, Cp는 평균 위치를 반영하지 않으므로 공정평균이 규격 중앙에 있다고 가정한 잠재적 능력을 나타내.

Cp 값의 일반적인 해석
Cp 범위 일반적 해석
Cp < 1.00 자연산포가 규격폭보다 커서 능력이 부족해.
Cp = 1.00 자연산포와 규격폭이 같아 여유가 거의 없어.
Cp ≥ 1.33 실무에서 흔히 사용하는 양호 기준의 하나야.
Cp ≥ 1.67 높은 능력이 요구되는 경우 활용되는 기준이야.
Cp = 2.00 중심 일치 조건에서 규격한계가 평균으로부터 각각 6σ 떨어져 있어.

축의 규격이 19.70 mm 이상 20.30 mm 이하이고 표준편차가 0.05 mm라면 규격폭은 0.60 mm, 자연공차는 0.30 mm야. 따라서 Cp = 0.60 / 0.30 = 2.00이야. 산포만 보면 잠재적 능력은 매우 좋지만 평균 위치를 아직 확인하지 않았으므로 실제 규격 충족능력을 확정할 수는 없어.

Cpk: 평균의 치우침까지 반영한 공정능력

Cpu = (USL − μ) / 3σ, Cpl = (μ − LSL) / 3σ이며, Cpk = min(Cpu, Cpl)이야. 양쪽 규격한계까지의 거리를 각각 평가하고 더 불리한 쪽을 선택하는 구조야.

앞의 축 공정에서 평균이 20.00 mm라면 Cpu와 Cpl이 모두 2.00이므로 Cpk도 2.00이야. 평균이 20.15 mm로 이동하면 Cpu는 1.00, Cpl은 3.00이 되고 Cpk는 1.00이 돼. 표준편차와 규격폭이 같아서 Cp는 여전히 2.00이지만 평균이 상한 쪽으로 이동했기 때문에 실제 능력인 Cpk가 낮아진 거야.

Cp는 공정의 산포를 보고, Cpk는 산포와 중심 위치를 함께 봐. 같은 데이터와 규격에서는 일반적으로 Cpk ≤ Cp이며 평균이 규격 중앙에 있을 때 Cp = Cpk가 돼.

중심 이탈계수

규격 중심을 M = (USL + LSL) / 2, 규격폭의 절반을 T = (USL − LSL) / 2라고 하자. 중심 이탈계수는 k = |μ − M| / T이며, 양측규격의 일반적 조건에서는 Cpk = Cp(1 − k)가 성립해. 평균이 중앙에 있으면 k = 0이고, 규격한계에 도달하면 k = 1이야. 평균이 규격 밖으로 나가면 Cpk가 음수가 될 수도 있어.

편측규격

불순물 함량처럼 상한만 중요하면 Cpu = (USL − μ) / 3σ를 사용해. 인장강도처럼 하한만 중요하면 Cpl = (μ − LSL) / 3σ를 사용해. 존재하지 않는 반대쪽 규격을 임의로 만들어 Cp를 계산하지 말고 실제 요구조건과 연결된 편측지수를 선택해야 해.

Pp와 Ppk

Cp와 Cpk는 보통 군내 변동에 기반한 단기적·잠재적 능력과 연결되고, Pp와 Ppk는 전체 관측기간의 변동을 사용한 장기적 성능과 연결돼. Pp = (USL − LSL) / 6s전체이고, Ppk는 전체 표준편차를 이용해 양쪽 편측지수 중 작은 값을 선택해.

시간에 따른 이동까지 포함하면 전체 표준편차가 커질 수 있어 Ppk가 Cpk보다 작게 나타나는 경우가 많아. 다만 문제에서 표준편차의 추정방법을 따로 제시한다면 그 조건을 우선 적용해야 해.

공정능력 개선 방향

Cp가 낮으면 설비조건 표준화, 원재료 균질화, 예방보전, 작업방법 개선과 측정오차 감소를 통해 산포를 줄이는 활동이 필요해. Cp는 충분히 크지만 Cpk만 낮다면 평균을 규격 중앙으로 조정하는 것이 핵심이야. 평균만 이동시키면 Cp는 변하지 않지만 Cpk는 개선될 수 있어.

6시그마 혁신활동

정의와 목적

6시그마 혁신활동은 고객에게 중요한 품질특성을 중심으로 결함과 변동의 원인을 데이터로 규명하고 프로세스를 체계적으로 개선하거나 새롭게 설계하는 경영혁신 방법론이야. 시그마 σ는 통계적으로 표준편차를 의미하지만, 6시그마는 단순한 계산기법이 아니야. 고객 요구 정의, 프로젝트 선정, 조직 역할, 통계적 분석, 개선 실행과 성과 유지가 결합된 활동체계야.

6시그마는 고객의 소리를 측정 가능한 CTQ로 바꾸고, 결함을 정량적으로 정의하며, 직관보다 데이터에 근거해 판단해. 결과만 검사하는 데서 벗어나 결과가 만들어지는 프로세스를 개선하고, 개선효과를 고객가치와 경영성과에 연결하며, 관리체계를 통해 성과의 후퇴를 방지해.

시그마 수준과 3.4 DPMO

DPMO는 백만 결함기회당 결함 수이며, DPMO = 결함 수 / (단위 수 × 단위당 결함기회 수) × 1,000,000으로 계산해. 제품 2,000개, 제품당 결함기회 5개, 결함 30개라면 DPMO는 30 / 10,000 × 1,000,000 = 3,000이야.

6시그마에서 널리 알려진 3.4 DPMO는 장기적으로 공정평균이 약 1.5σ 이동할 수 있다는 관행적 가정을 포함해. 평균이 완전히 고정된 단기 정규모형의 규격 외 확률과 같은 값이 아니야. 또한 결함기회의 정의가 조직마다 다르면 DPMO도 달라질 수 있으므로 비교 전에 기회 정의가 일관적인지 확인해야 해.

공정능력과 6시그마의 연결

평균이 규격 중앙에 있고 양쪽 규격한계가 평균에서 각각 6σ 떨어져 있다면 규격폭은 12σ야. 따라서 Cp = 12σ / 6σ = 2.00이 돼. 장기적인 1.5σ 평균 이동을 가정하면 가까운 규격한계까지의 거리는 4.5σ가 되고 Cpk = 4.5σ / 3σ = 1.50으로 연결할 수 있어.

Cp = 2.00, 장기 이동을 고려한 Cpk = 1.50, 3.4 DPMO가 함께 언급되는 이유가 여기에 있어. 하지만 모든 공정이 실제로 정확히 1.5σ만큼 이동한다는 뜻은 아니며, 이 관계는 정규성 및 평균 이동 가정에 의존해.

Define: 문제와 고객 요구 정의

Define에서는 범위, 고객, CTQ, 목표, 일정과 예상효과를 명확히 해. “가공품 품질을 향상한다”보다 “A라인 축 직경의 규격초과율을 6개월 안에 1.2%에서 0.2% 이하로 낮춘다”가 좋은 정의야. VOC는 고객의 소리이고 CTQ는 VOC를 측정 가능한 품질특성으로 번역한 결과야.

Measure: 현재 수준 측정

Measure에서는 먼저 측정시스템의 반복성과 재현성을 확인해야 해. 측정오차가 크면 공정변동과 측정변동을 구별하기 어렵기 때문이야. 그다음 결함 기준, 측정방법, 표본추출 시점과 표본 수를 정하고 불량률, DPMO, 평균, 표준편차, Cp와 Cpk를 이용해 현재 기준선을 설정해.

Analyze: 핵심원인의 검증

Analyze에서는 가능한 원인을 나열하는 데서 멈추지 않고 데이터로 검증해. 특성요인도에 공구 마모를 적었다고 핵심원인이 되는 건 아니야. 공구 사용시간과 치수의 관계를 분석하고, 교대조별 차이가 우연인지 검정해야 해. 상관관계는 인과관계를 자동으로 증명하지 않는다는 경계를 기억해야 해.

Improve: 원인 제거와 최적화

Improve에서는 검증된 원인에 직접 대응하는 해결책을 설계해. 공구 교환주기, 온도 제어, 설비 조건, 부품 구조 등의 대안을 비교하고 파일럿 실행으로 효과와 부작용을 확인해. 여러 인자의 효과와 상호작용을 파악하려면 실험계획법을 활용할 수 있어.

Control: 개선성과 유지

Control에서는 최적조건을 작업표준에 반영하고 책임자와 점검주기를 정하며 관리도와 반응계획을 운영해. 개선 직후 Cpk가 한 번 높게 나온 것만으로는 충분하지 않아. 시간이 지나도 평균과 산포가 안정적으로 유지되는지 확인해야 진짜 성과야.

통합 계산 사례

현재 공정능력 진단

부품 직경의 규격이 49.70 mm에서 50.30 mm이고 현재 평균이 50.12 mm, 표준편차가 0.06 mm라고 해보자. 규격폭은 0.60 mm이고 자연공차는 0.36 mm이므로 Cp = 0.60 / 0.36 = 1.67이야.

Cpu = (50.30 − 50.12) / 0.18 = 1.00이고 Cpl = (50.12 − 49.70) / 0.18 ≈ 2.33이므로 Cpk는 1.00이야. Cp만 보면 산포의 잠재력은 좋지만 평균이 상한 쪽으로 치우친 것이 핵심 문제야.

DMAIC 적용

Define에서는 상한 초과로 인한 조립불량 감소를 목표로 정해. Measure에서는 측정시스템을 검증하고 평균, 표준편차와 Cpk를 기준선으로 기록해. Analyze에서는 설비 보정값, 온도와 공구 마모가 평균 이동에 미치는 영향을 검증해. Improve에서는 조건을 최적화하고 산포를 줄여. Control에서는 관리도, 공구 교환기준과 이상 시 조치계획을 운영해.

개선 후 확인

개선 후 평균을 50.00 mm로 이동시키고 표준편차를 0.04 mm로 줄였다면 Cp = 0.60 / 0.24 = 2.50이야. 평균이 규격 중앙에 있으므로 Cpu와 Cpl도 각각 2.50이고 Cpk는 2.50이 돼. 공정능력분석은 문제의 형태를 보여주고 DMAIC는 원인을 제거해 성과를 유지하는 경로를 제공해.

시험 함정

  1. Cp가 크면 반드시 불량이 적다고 판단하면 안 돼. 평균이 치우치면 Cp가 커도 Cpk가 낮을 수 있어.
  2. Cp의 분모는 6σ이고 Cpu와 Cpl의 분모는 각각 3σ야.
  3. Cpk는 Cpu와 Cpl 중 큰 값이 아니라 작은 값을 선택해.
  4. 공정이 관리상태라는 사실과 공정능력이 충분하다는 사실은 같지 않아.
  5. 규격한계는 관리도에서 계산한 값이 아니라 고객 또는 설계 요구에서 정해져.
  6. 평균이 규격 중앙에 있으면 Cp = Cpk이고, 치우치면 일반적으로 Cpk < Cp야.
  7. 편측규격에서는 존재하지 않는 규격한계를 임의로 사용하면 안 돼.
  8. DPMO 계산에서는 단위당 결함기회 수를 빠뜨리면 안 돼.
  9. 3.4 DPMO는 장기적인 1.5σ 평균 이동 가정과 연결돼.
  10. Analyze에서는 원인 후보를 나열하는 데 그치지 않고 데이터로 검증해야 해.
  11. Control은 단순한 결과 보고가 아니라 개선조건의 표준화와 지속적인 감시 단계야.
  12. Cp와 Cpk 계산 전에 공정 안정성, 분포와 측정시스템의 신뢰성을 확인해야 해.

문제 1

규격상한이 106, 규격하한이 94, 공정 표준편차가 1.5일 때 Cp는 얼마일까?

  2. 1.00
  3. 1.33
  4. 2.00

문제 2

문제 1의 공정평균이 102일 때 Cpk는 얼마일까?

  1. 0.44
  2. 0.67
  3. 0.89
  4. 1.33

문제 3

Cp = 1.80이고 Cpk = 0.90인 공정에 대한 가장 적절한 해석은 무엇일까?

  1. 공정산포가 매우 크고 평균은 중앙에 있다.
  2. 공정의 잠재적 능력은 좋지만 평균이 규격 중앙에서 치우쳐 있다.
  3. 공정은 반드시 통계적 비관리상태다.
  4. 규격폭과 자연공차가 정확히 같다.

문제 4

다음 중 DMAIC의 올바른 순서는 무엇일까?

  1. Define–Analyze–Measure–Improve–Control
  2. Define–Measure–Improve–Analyze–Control
  3. Define–Measure–Analyze–Improve–Control
  4. Measure–Define–Analyze–Control–Improve

문제 5

제품 500개를 조사했고 제품당 결함기회가 4개이며 결함 10개를 발견했어. DPMO는 얼마일까?

  1. 2,000
  2. 5,000
  3. 10,000
  4. 20,000

문제 6

6시그마 혁신활동에 관한 설명으로 옳지 않은 것은 무엇일까?

  1. 고객에게 중요한 CTQ를 중시한다.
  2. 데이터에 근거하여 핵심원인을 검증한다.
  3. 개선 후에는 관리와 표준화가 필요하다.
  4. 3.4 DPMO는 평균 이동을 전혀 고려하지 않은 단기 모형의 값이다.

정답 및 해설

문제 1 정답: 3번

Cp = (106 − 94) / (6 × 1.5) = 12 / 9 = 1.33이야.

문제 2 정답: 3번

Cpu = (106 − 102) / 4.5 ≈ 0.89이고 Cpl = (102 − 94) / 4.5 ≈ 1.78이야. 작은 값을 선택하므로 Cpk ≈ 0.89야.

문제 3 정답: 2번

Cp가 1.80이므로 산포만 본 잠재적 능력은 좋아. Cpk가 0.90으로 낮으므로 평균이 규격 중앙에서 치우쳤다고 판단할 수 있어.

문제 4 정답: 3번

DMAIC는 Define–Measure–Analyze–Improve–Control 순서야.

문제 5 정답: 2번

DPMO = 10 / (500 × 4) × 1,000,000 = 5,000이야.

문제 6 정답: 4번

3.4 DPMO는 장기적으로 평균이 1.5σ 이동할 수 있다는 관행적 가정을 포함하므로 4번이 옳지 않은 설명이야.

요약

  • 공차와 공정능력분석: 공차는 요구된 허용폭이고 자연공차는 공정이 만드는 6σ의 산포폭이야.
  • Cp: 규격폭과 자연공차를 비교하며 평균 위치를 반영하지 않아.
  • Cpk: Cpu와 Cpl 중 작은 값을 사용해 평균의 치우침까지 반영해.
  • 개선 방향: Cp가 낮으면 산포를 줄이고, Cp는 충분하지만 Cpk만 낮으면 평균을 중앙으로 조정해야 해.
  • 분석 전제: 측정시스템, 통계적 안정성, 분포와 표본 대표성을 확인해야 해.
  • 6시그마 혁신활동: 고객 중심, 데이터 기반, 프로세스 중심의 개선체계야.
  • DMAIC: 기존 프로세스를 Define–Measure–Analyze–Improve–Control 순서로 개선해.
  • DPMO: 단위 수와 단위당 결함기회 수를 함께 반영해.
  • 3.4 DPMO: 장기적인 1.5σ 평균 이동 가정과 연결돼.
  • 통합 의미: 공정능력지수는 문제를 수치로 보여주고 6시그마는 원인을 제거하고 성과를 유지하는 실행체계를 제공해.

규격폭 속에 산포가 얼마나 여유 있게 들어가는가가 Cp이고, 산포 덩어리가 한쪽 규격 벽에 가까워졌는지까지 보는 것이 Cpk야. 이 그림을 기억하면 계산식과 해석을 함께 잡을 수 있어.
