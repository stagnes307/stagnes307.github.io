# Ailey & Bailey · CS 통합 개정판

index.html에서 전체 학습 지도를 열고 18강을 선택합니다. ?lesson=01은 통합판 1강이며, 같은 화면에서 보관된 원본도 선택할 수 있습니다.

밝게·어둡게·시스템 설정, 브라우저 답변 보관·자가 진도·답변 내보내기를 제공합니다. 통합판은 외부 Canvas 로딩 없이 본문·그림·기본 연습을 읽습니다. 보관 원본의 외부 런타임 조건은 원래대로입니다.

이 폴더에서 python -m http.server 0 --bind 127.0.0.1을 실행하면 출력된 로컬 주소로 읽을 수 있습니다. 파일을 직접 여는 브라우저에서는 저장이나 프레임 동작 범위가 다를 수 있습니다.

revised/examples/에는 독립 실행 예제 15개가 있습니다. 예제 하나를 내려받았다면 해당 폴더에서 python 파일이름.py로 실행합니다. 실제 명령·출력·해시·한계는 revised/verification.json을 확인하세요. 예제들을 합쳐 실제 제출 서비스의 검증 완료로 말하지 않습니다.
