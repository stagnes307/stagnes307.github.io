# Ailey & Bailey · 시험 대비 CS 원본 수업

본문과 HTML은 사용자가 지정한 크롬 ChatGPT 프로젝트에서 생성했습니다. Codex는 주제 분류, 원본 수집·검토, 목차 화면과 게시를 맡았습니다. `lessons/` 파일은 받은 GPT HTML을 바이트 변경 없이 복사했으며 `provenance.json`에 해시와 생성 대화를 연결합니다.

기존 Codex 집필 교재는 별도 주소에 보존합니다. 전체 18개 수업 중 검증된 것부터 공개하며 미완성 항목은 제작 중으로 표시합니다. 외부 Canvas 런타임·글꼴·CDN이 필요합니다.
