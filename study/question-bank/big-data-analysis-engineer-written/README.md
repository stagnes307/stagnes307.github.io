# 빅데이터분석기사 필기 문제 근거 데이터

이 디렉터리는 시험 문제 원문 저장소가 아니라 **출제 주제 관측 근거 레지스트리**다. 공식 운영기관은 문제와 답안을 공개하지 않으므로, 공개 파일에는 출처 링크·회차·독자 작성 개념 요약·커리큘럼 분류만 둔다.

## 파일럿 범위

- 회차 레지스트리: 제1회부터 제13회까지 13개(취소 1, 시행 11, 예정 1; 2026-08-29 기준)
- 주제 관측: 제2회 17건, 제3회 21건
- 원문·선택지·정답: 0건
- 출처: 공식 일정/시험 안내, 출판 메타데이터, 시험 직후 응시자 회고
- 현행 커리큘럼 매핑: 모든 관측을 64개 leaf Lesson 중 하나에 수동 승인 매핑

제2회와 제3회는 각각 80문항 중 일부만 복기된 파일럿이다. 따라서 회차 coverage가 50%에 미달하며 `analysis-sets.json`은 의도적으로 비어 있다. 이 데이터만으로 중요도 별점이나 회차별 빈도를 단정해서는 안 된다.

## 권리·신뢰 원칙

- 모든 문제 근거 variant는 `content_mode=link_only`이고, `question_text=null`, `choices=[]`이다.
- 정답 주장은 저장하지 않으며 `answer_status=unverified`로 유지한다.
- 블로그 복기는 `reliability=low`인 보조 증거다. 문항번호를 확인할 수 없으므로 `question_number=null`이다.
- `analysis_eligible=true`는 출처가 하나의 구별 가능한 문항 주제를 명시한 경우에만 사용한다. 여러 문항을 묶어 회고한 항목은 승인된 매핑이어도 분석 대상에서 제외한다.
- 과거 회차를 현행 2024–2026 커리큘럼에 연결한 것은 학습 탐색용 분류이며, 당시 출제기준과 완전히 같다는 의미가 아니다.

## 데이터 관계

`question-groups.json`의 appearance가 회차와 Lesson을 연결하고, `question-variants.json`이 출처별 근거 위치를 보존한다. `annotations.json`은 독자 작성 키워드와 요약만 담는다. 예상문제는 `generated_questions.json`에만 들어가며 현재는 비어 있다.
